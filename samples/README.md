# Fixed Sample Dataset

Run `python3 samples/build_sample_db.py` to rebuild every file in this directory.

## `sample_db.sqlite`

Fixed tables and indexes:

- `customers(id, segment, region, created_at)`, index `idx_customers_segment`
- `orders(id, customer_id, status, created_at, total_cents)`, indexes `idx_orders_customer`, `idx_orders_status`
- `products(id, category_id, price_cents)`, index `idx_products_category`
- `feature_flags(id, enabled, name)`, index `idx_flags_enabled`

Rows are inserted in a fixed order. The canonical database digest covers sorted
table/column/index metadata and rows, not raw SQLite file bytes.

## Statistics files

- `stats_snapshot.json`: baseline version 1, effective at logical clock 0.
- `stats_patch_v2.json`: version 2, effective at 2500 ms, changes orders status
  NDV and two index prefix selectivities.
- `stats_patch_rollback.json`: negative version-rollback patch.
- `stats_patch_conflict.json`: negative non-current base-version patch.
- `stats_patch_unknown_column.json`: negative missing-column patch.
- `stats_patch_zero_estimate.json`: changes an index selectivity to zero.
- `stats_snapshot_bad_digest.json`: negative database-digest snapshot.

## Sample streams

Each item contains:

```json
{
  "sample_seq": 1,
  "collected_at_ms": 1000,
  "sql": "SELECT * FROM orders WHERE customer_id = 17",
  "template_id": "tpl_de44a1823009445df386",
  "duration_ms": 81,
  "rows_scanned": 10,
  "rows_returned": 10,
  "index_hit": "idx_orders_customer",
  "session_id": "s1"
}
```

- `slow_queries.json`: sequences 1-10, logical clocks 1000-1800.
- `slow_queries_after_refresh.json`: sequences 11-16, logical clocks 2500-3300.
- `slow_queries_invalid.json`: negative unterminated SQL.
- `slow_queries_zero_case.json`: sequence 101 at clock 3400 for the zero-estimate scenario.

Template IDs are generated by `slowplan.normalize.normalize_sql`; the build
script derives them rather than hard-coding inconsistent values.
