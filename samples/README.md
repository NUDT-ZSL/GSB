# Deterministic samples

Generated by `scripts/generate_samples.py` with seed `20261122`.

- `plan.json`: three-level composite grouping (`endpoint_pair`, `protocol`, `direction`),
  an 0.08 MiB memory budget, 64-row batch limit, fixed scale 1000, and quantiles
  0.5/0.9/0.99.
- `batches/b001.jsonl` through `b010.jsonl`: 480 loopback flow records in ten
  sequential batches.
- `manifest.json`: stable batch order and source SHA-256 values.
- `clock_steps.json`: injected logical-clock boundaries and expected batch
  watermarks.
- `spill/`: intended spill directory for direct sample runs. Demo runs use an
  isolated copy of the plan with a run-local `spill/`.

The endpoint pair is ordered (`src->dst`). Protocol is uppercased and direction
is lowercased before the key tuple is encoded as compact JSON.
