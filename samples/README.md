# 确定性样本说明

本目录由 `scripts/generate_samples.py` 生成，不使用系统时间、随机外部服务或 GPU。

## 模型与配置

- 版本 1 是基线，版本 2 是目标。
- 两层 `encoder.0` / `encoder.1` 与输出头 `head`，共 8 个分片。
- 目标相对基线只改变：
  - `encoder.1` 分片 1；
  - `head` 分片 0。
- 目标预处理为 `pre:v2`，其依赖链为：

```text
pre:v2 -> feature:v2 -> upstream:v2
```

- 目标复用 `post:v1`，用于验证未变化配置可以安全复用。
- 补丁未声明其余 6 个分片，因此这些分片必须继承基线。

## 文件

| 文件 | 说明 |
| --- | --- |
| `models.json` | 配置资源、模型版本与逐层分片摘要 |
| `replicas.json` | 三个副本的基线加载摘要和预热状态 |
| `plan.json` | 目标版本、补丁、三档灰度与回退参数 |
| `patches/v1_to_v2.json` | 两个变化分片的增量补丁 |
| `weights/v1/**` | 基线 float32 分片 |
| `weights/v2/**` | 目标整体替换目录，用于一致性对照 |
| `clock_steps.json` | 正常、回退、回退超窗、预热超时脚本 |
| `generation_manifest.json` | 变化分片与确定性请求 ID 摘要 |

## 副本

- `replica-a`、`replica-b`：灰度成员。
- `replica-control`：非灰度对照副本，验证无关副本推理结果不受更新影响。

## 逻辑时钟

- 更新从 `1000 ms` 开始。
- 预热时长 `100 ms`，预热超时 `200 ms`。
- 灰度档位：`1200 ms @ 0.1`、`1300 ms @ 0.5`、`1400 ms @ 1.0`。
- 回退窗口 `500 ms`，每次降档间隔 `100 ms`。
- 时钟容差 `20 ms`。

所有时间均为调用方传入的逻辑毫秒值。
