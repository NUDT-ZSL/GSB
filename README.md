在游戏动捕配音与多地录制的后期交付场景中，一档节目由多台设备分别录制不同声道段落：设备采样率与位深各不相同（44100/48000/96000，16bit 或 24bit），各自本地时钟启动时刻与运行速率存在偏差，录制中还会缓慢漂移。后期需要先按会话中给出的脉冲同步标记估计每台设备相对参考设备的起始偏移与漂移率，把各声道段映射到统一的参考时间轴并按时间片拼接，再在这条统一时间轴上做门限响度测量与动态范围预算评估，最后输出统一采样率与位深的 WAV 与一致性报告。当前为空工作区，需从零开发一个本地命令行处理引擎。输入为程序按确定性规则生成的多设备 WAV 样本（每段含若干确定性脉冲标记）、一个会话 JSON（设备清单、各段声道布局与增益、同步脉冲理论时刻、漂移模型阶数、统计窗口长度、门限参数、动态范围上下界、目标采样率与位深、时间片长度、并发上限、在途解码缓冲内存预算、状态目录与输入快照标识）。真实难点在于同步标记的可观测性有限：只能依据样本中检测到的脉冲峰值时刻与理论时刻之差估计偏移与漂移，缺失标记或标记落在段外时必须按会话规则降级处理并在报告中给出依据；而拼接、测量与转码在任意并发度与内存预算下必须给出同一结果。运行于 Windows，不使用外部音频库或在线资源。

任务环境与准备：
Windows 环境，安装 Python 3.10 及以上，并将 python 命令加入 PATH。
安装 NumPy（可用 pip install numpy 获取），不使用其他第三方音频库或同步工具。
确认输出目录与状态目录可写；多设备 WAV 样本与会话 JSON 由任务自带生成脚本按确定性规则生成，无需外部录音素材或在线资源。

业务要求：
1. 实现会话描述与多设备 WAV 解析校验：读取会话 JSON 与各设备段文件头，校验采样率属于允许集合、位深为 16 或 24、声道数与声明布局一致、各段起始理论时刻为非负整数毫秒、同步脉冲理论时刻在段内且严格递增、增益为有限数、统计窗口长度为正整数毫秒、漂移模型阶数属于允许集合、目标采样率与位深属于允许集合；非法条目记录设备标识与段标识并返回可区分业务码 E_FORMAT、E_RATE、E_MISSING 的 JSON 错误且不产生输出文件。
2. 实现同步脉冲检测与偏移漂移估计：在各设备段中按会话给出的脉冲搜索窗检测确定性脉冲的峰值采样点，把峰值时刻与理论时刻之差作为观测，按漂移模型阶数用最小二乘估计起始偏移（整数采样点）与漂移率；可用脉冲少于模型所需最小观测数时按会话规则降级为仅偏移估计并返回业务码 E_SYNC 同时记录缺失标记区间，报告中必须列出所用观测点、估计残差与降级依据，不得在无观测时凭空推断。
3. 实现参考时间轴映射与时间片拼接：以参考设备采样率为统一时间轴，按估计偏移与漂移率把每个声道段的采样点映射到参考时间轴，漂移按线性模型逐采样插值补偿，拼接点落在会话给定的时间片边界；拼接后任一参考时刻上各段贡献的相对误差不超过 1 个参考采样点，缝隙处按确定规则填充与标记，空时间片须给出确定结果并计入报告。
4. 实现门限响度测量与同步观测对照：在统一时间轴按统计窗口计算加权均方能量并做绝对门限与相对门限两级筛选，积分响度只由通过门限的窗口决定，末尾不足一窗的样本按会话规则处理，全静音片须给出明确结果；窗口起止按整数毫秒换算为参考采样点并与拼接后的采样点严格对齐，报告中须把每窗能量与由同步观测推导的段归属一并列出，使测量结果可回溯到具体设备段。
5. 实现动态范围预算判定与建议动作：按逐窗口响度序列计算峰值与响度范围，判定是否落在会话给出的动态范围上下界内并给出增益调整量或压限建议；同步估计未达模型阶数要求（E_SYNC 降级）或拼接存在被标记缝隙时，判定须附降级依据且结论只依赖测量值，不受并发完成顺序影响，全部判定与建议按设备段声明顺序写入报告。
6. 实现并行解码与内存预算调度：按并发上限使用有界线程池并行解码并检测各设备段的同步脉冲，同时在途解码缓冲与采样数据总量不得超过会话内存预算，超出预算时按设备段声明顺序让部分段等待而非降低检测精度或截短搜索窗；任一段失败时取消其余待处理段并返回首个错误，已完成合法段的结果仍保留在报告中。
7. 实现输出转码与报告一致性提交：把拼接结果按目标采样率与位深写出，采用有理数比的重采样并保证输出帧数与理论值误差不超过 1 个目标采样点，24 位按小端三字节封装；输出先写临时文件再整体替换，替换前读取已有输出文件的帧数与采样率版本信息，版本不同才替换；报告与音频分别写临时文件后一并替换，任一失败时二者都保持旧版本并返回 E_WR，不得出现只更新其一的中间状态。
8. 实现中断语义、快照版本识别与确定性归并：可处理终止信号只在设备段边界或时间片边界生效，写入中断标记并以约定整数退出码退出，未完成段不得留下可被误认为完成的状态；强制终止后仅依据持久化且摘要有效的已完成段与输入快照标识恢复，输入内容变化导致标识不一致时从头重做，强制终止时不承诺生成退出报告；任意并发度与内存预算下报告条目顺序、同步估计值、响度与判定结论、输出字节必须与并发度为 1 时完全一致。
