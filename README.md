地形烘焙工具在首个版本评审后被反馈：美术在地形高度场上局部雕刻（抬升山脊、压低河谷）或调整光照与相机后，重烘总是整幅地形从头计算，耗时且中间结果无法复用；即使只重算局部，分块边界处的法线与高度也常出现一像素宽的明暗接缝。项目目录当前为空，需要交付一个本地地形高度场离线烘焙引擎与诊断工作台：输入为 JSON 场景描述与按固定种子确定性生成的多块高度场数据，输出灰度地形着色图、高度深度图与一份缓存失效与接缝验证报告。烘焙须建模为分块计算图，在地形子区域编辑、光照参数调整与相机变化后精确判定哪些屏幕分块失效并只重渲它们，同时保证分块拼装结果与全量重渲逐像素一致。

任务环境与准备：
安装 Python 3.11 及以上，并确保 numpy 与标准库 sqlite3 可用，建议执行 python -m pip install "numpy>=1.26"。
准备一个空工作目录作为项目根目录，样本生成脚本与场景 JSON 由实现方在该目录内提供，全部数据本地确定性生成。
运行环境为 Windows，所有路径与临时文件替换逻辑按 Windows 语义实现，不依赖容器、GPU 或外部网络。
首次运行前执行样本生成脚本产出高度场分块、场景描述与编辑脚本，并确认输出目录可写。

业务要求：
1. 实现场景描述与高度场目录解析校验：读取 JSON 场景与多块高度场文件，校验各块行列数为正整数且全局网格覆盖完整世界范围、各轴世界尺度与分辨率像素密度为有限正数、相机目标点与位置不重合、上方向与视线不平行、子区域编辑以整数格索引声明且不越界，非法输入返回带 E_SCHEMA 的 JSON 错误且不产生任何输出。
2. 实现全局高度场采样与分块几何一致性：所有渲染与法线计算都通过全局原点、各轴世界尺度把世界坐标换算到全局格索引后做双线性插值，块边界一律采用半开区间语义保证每个世界位置唯一归属一块，法线由相邻全局采样高度差在世界尺度下换算而非各块局部数据，使拼装结果不出现分块接缝。
3. 实现分块级依赖记录与失效反演：为每个输出分块记录其覆盖的全局格索引范围、对高度值的依赖区间、对光照参数与传递关系的依赖；地形子区域编辑后只把依赖区间与之相交的分块标记失效，光照参数变化使全部分块失效，相机变化使全部分块失效，三类情形的失效集合与理由须逐块写入报告。
4. 实现确定性分块渲染与串行等价：对失效分块按与所选步长匹配的确定性光线步进求首个表面交点，按全局法线计算兰伯特项并输出灰度与以世界单位表示的高度深度；每块只读高度场、相机与光照参数并写回块私有结果，最终拼装须与并发度为 1 时逐像素逐深度值相同。
5. 实现分块级持久化与版本识别恢复：每块完成后把灰度、深度、依赖摘要与由全部高度场内容、相机、光照与步长规范化摘要构成的版本标识原子写入状态目录，先写同目录临时文件再整体替换，替换前比对已有分块版本标识，标识变化时不得直接覆盖旧分块而须归档或标记旧版。
6. 实现中断语义与强制终止恢复边界：可处理终止信号只在分块边界生效，须在写出中断标记并以约定整数退出码退出前保证未完成分块不留下可被误认为已完成的结果；强制终止后重启仅依据已持久化且摘要有效的分块状态恢复，不承诺生成退出报告，未提交分块一律重算。
7. 实现并发调度与资源上限：按场景并发上限使用有界线程池调度待渲染分块，同时处于计算中的分块采样缓冲总量不得超过描述中的内存上限，超出时按分块索引序让后续块等待而非降低步长或插值精度；任一分块异常时取消其余待处理分块并以首个错误终止，报告中记录已成功块。
8. 实现失效与接缝验证报告及结果原子写出：报告含每块失效理由、重渲块数、复用块数、块边界处法线偏差最大值与全量重渲参照的逐像素最大差；最终图像与深度图先写同目录临时文件再整体替换，替换前读取已有输出文件的尺寸与摘要版本，版本不同才替换。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地样本验证局部编辑后仅重渲失效分块且拼装结果与全量重渲逐像素一致，并核对失效与接缝报告。
