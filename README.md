在全新工作区中，需要从零构建一个面向表格二分类模型概率校准的本地可视化与诊断工作台。业务对象是本地确定性生成的样本清单（JSONL，每行含 sample_id、若干数值特征与类别特征、label 与 group 标签）以及一组已训练好的分类器原始分数（由固定种子驱动的确定性打分函数产出，无需真实模型文件）。校准链路被建模为多阶段流程：按 group 切分参考集与评估集→对每个候选校准器（Platt 缩放、保序回归、直方图分箱）在参考集上拟合→在评估集上应用校准器→计算校准指标（校准误差 ECE、Brier 分数、可靠性曲线）并输出诊断报告。核心业务问题是：多个校准器与多个 group 的拟合和打分需要并行调度，但总拟合迭代预算与驻留内存必须受限；同时校准产物必须可按内容寻址缓存，并在配置版本变化时精确失效。用户需要一个可交互的工作台展示调度计划、预算账本、逐 group 校准曲线与误差归因。

任务环境与准备：
安装 Python 3.11 或更高版本，并在命令行确认 python --version 可用。
在项目根目录创建虚拟环境并激活：python -m venv .venv，Windows 下执行 .venv\Scripts\activate。
安装依赖：pip install numpy。
无需数据库、容器、网络服务或真实数据集；样本由固定随机种子在本地确定性生成。
运行前在项目根目录准备本地样本清单与配置文件，具体字段与路径由实现者在示例中给出。

业务要求：
1. 实现确定性的数据切分与特征预处理层：按 group 标签分组，在组内按固定随机种子以可配置比例切分参考集与评估集，并对数值特征做标准化、对类别特征做固定规则编码；同一输入、同一配置与同一种子下必须逐字节产出相同的切分结果与预处理后特征，禁止依赖除固定种子外的任何随机源或系统时间。
2. 实现三种确定性校准器的拟合核心：Platt 缩放用数值稳定的逻辑回归拟合，保序回归用保序回归拟合，直方图分箱按可配置分箱数统计经验频率；所有迭代的初值、比较顺序与停止条件必须显式声明，同分时按样本标识升序打破平局；拟合过程须记录每轮目标函数值与比较次数，使拟合轨迹可复现。
3. 实现校准器在评估集上的应用与指标聚合节点：输出逐样本校准后概率，以及按 group 与整体的 ECE、Brier 分数与可靠性曲线；指标必须可由逐样本概率与真值明细独立重算一致，ECE 分箱边界与分箱内权重口径须显式记录，不得使用未记录口径的平滑或截断。
4. 实现并行调度层：按可配置 worker 数与每批任务数把校准器与 group 的组合分派到本地进程池执行，分块边界、任务派发顺序与归并顺序必须确定性可复现；每个组合的拟合与打分结果必须与单独串行执行逐字节一致，worker 内异常须以结构化业务码与阶段名回传主进程并归因到具体组合，单个组合失败不得静默丢弃。
5. 实现总拟合迭代预算与驻留内存的双重准入裁决：按参考集样本数、校准器类型与分箱数估算每个组合的迭代次数与内存占用，在总预算内决定准入组合集合与执行规模；超限时返回 E_ITER_BUDGET 或 E_MEMORY_BUDGET 并指出被拒组合与缺口，不得以静默降采样掩盖预算不足。
6. 实现校准产物与调度计划的版本化快照及整体替换：校准器参数、调度计划与指标统计各携带单调递增版本号与内容校验和，检测到版本号或校验和变化时必须整体替换旧快照而非增量修补；同一时刻只允许一个调度计划提交生效，并发提交冲突时后到者立即获得 E_STAGE_BUSY 而不阻塞等待，已完成版本不得被旧版本回退覆盖且回退尝试返回 E_SNAPSHOT_ROLLBACK。
7. 实现校准器配置变更后的定向失效传播与追溯重放：区分仅分箱数变化、仅参考集切分比例变化、仅校准器类型切换三类情形，计算受影响节点与受影响 group 集合，复用未受影响的上游产物，仅重算受影响后缀；每条最终指标须记录所用缓存键、配置版本与节点路径，可按记录重放出相同指标，追溯链断裂时返回 E_LINEAGE_BROKEN。
8. 实现输入与配置校验链路、资源上限及跨模块一致性自检：重复 sample_id、特征向量长度不一致、group 标签缺失、校准器类型未知、分箱数或切分比例非法分别返回结构化业务码并指明字段；为单批任务数、驻留概率中间表内存与并行组合数设可配置上限；自检校验各阶段 sample_id 集合一致、指标可由明细重算、快照版本交叉可核对，不一致返回 E_INCONSISTENT。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
