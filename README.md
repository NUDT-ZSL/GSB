材质美术工具项目已通过立项评审，代码仓库仍是空的，团队要在 Windows 本地从零做起。工具需按固定种子生成多组程序化材质纹理（基础色、粗糙度场、法线细节与倍频噪声参数），生成链路为参数校验、多倍频噪声场合成、材质通道映射、按分块网格切片、边界接缝归一化与整幅拼接，并以库函数加命令行示例交付，附带固定样本、可注入异常清单、逐块摘要与一致性报告。真正难的地方在于分块网格的噪声相位、通道归一化与接缝权重必须与整幅同口径，且分块级持久化要在可处理终止与强制终止后都能恢复出确定结果。

任务环境与准备：
安装 Python 3.11 或以上版本，并在命令提示符或 PowerShell 中确认 python --version 可用。
使用 pip 安装 numpy，并在项目中记录实际安装的版本号；题目不依赖任何 GPU、网络或外部数据集。
在空工作区创建项目目录结构，自行编写固定种子样本生成脚本，产出材质清单 JSON 与生成配置 JSON 保存在本地样本目录。
准备异常注入清单 JSON，仅通过输入参数与样本内容注入异常，不得修改源码制造验收失败。
在 Windows 本地准备运行与演示脚本的说明，所有路径使用 Windows 格式，输出目录与状态目录需可独立清理重建。

业务要求：
1. 实现材质参数与分块规格解析校验：读取本地 JSON 材质清单与生成配置，校验基础色分量在 [0,1]、粗糙度与法线细节强度为有限正数、倍频数为正整数、频率严格递增、振幅为正、分块网格行列数能整除纹理宽高、整幅宽高为正整数，非法条目按材质标识返回可区分的 E_xxx 业务码并继续处理其余合法材质。
2. 实现确定性多倍频噪声场合成：以材质种子驱动伪随机梯度表，按频率与振幅逐倍频叠加噪声，任意格点的噪声值只依赖该材质的种子、频率、振幅与倍频数，与调用顺序、分块划分和网格对齐方式无关；同一材质重复合成整幅与分块必须得到逐格相同的噪声值。
3. 实现材质通道映射与法线细节生成：按粗糙度场与噪声参数映射到粗糙度通道，按基础色与噪声扰动生成颜色通道，按高度差分与强度生成切线空间法线通道并归一化；通道映射须在整幅坐标下统一进行，不得因分块边界而使用不同的归一化常量或扰动相位。
4. 实现分块切片生成与整幅一致性裁决：按分块网格逐块生成切片并在接缝处做归一化权重融合，切片结果缓存后可快速预览；所有切片拼接后的纹理必须与同参数整幅生成逐像素误差不超过规格给定容差，容差超限时给出首个不一致像素坐标与分块索引。
5. 实现分块级持久化与版本识别恢复：每块完成后把切片数据、该块参数摘要与由材质参数和生成配置规范化摘要构成的版本标识原子写入状态目录，先写同目录临时文件再整体替换；再次启动时版本标识一致则复用已完成块，不一致则整体重做，禁止新旧版本切片混拼。
6. 实现可处理终止与强制终止语义：外部可发送可处理终止信号使任务在分块边界写入中断标记并以约定整数退出码退出，未完成分块不得留下可被误认为完成的结果；强制终止后重启仅依据已持久化且摘要有效的分块恢复，不承诺生成退出报告。
7. 实现异常注入驱动的错误链路验证：按异常清单在指定材质注入非法振幅、分块不能整除纹理尺寸、缺失通道声明与损坏的已持久化块摘要，组件须对受影响材质返回可区分的业务码并继续生成其余材质，最终报告须汇总注入项、受影响材质、业务码与已产出切片数。
8. 实现并发分块生成与资源上限并原子导出：按并发上限使用有界线程池调度待算分块，同时在途的分块像素缓冲总量受内存预算约束，超出时按材质标识与分块索引序让后续块等待而非降低噪声倍频数或精度；最终整幅纹理与报告先写同目录临时文件再整体替换，替换前读取已有输出的版本标识，标识变化时不得直接覆盖而须归档旧版本。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地确定性材质样本验证分块与整幅逐像素一致、异常业务码及中断恢复，输出可复现报告。
