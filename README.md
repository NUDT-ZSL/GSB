# 地牢关卡离线渲染与校验组件

本仓库实现任务书所述的离线、确定性、仅依赖 NumPy 的地牢格网渲染与分块校验组件。
设计细节见 [DESIGN.md](DESIGN.md)，验证记录见 [VERIFICATION.md](VERIFICATION.md)。

快速开始（Windows PowerShell，Linux/macOS 将 `py -3.11` 换为 `python3`）：

```powershell
py -3.11 -m pip install -r requirements.txt
py -3.11 generate_samples.py
py -3.11 -m dungeon_render.cli samples/level.json samples/render_task.json
py -3.11 -m unittest discover -s tests
py -3.11 run_acceptance.py
```

交付目录：`dungeon_render/`（包代码）、`tests/`（32 个单元测试）、
`generate_samples.py`（固定种子样本）、`run_acceptance.py`（端到端验收）。

## 原始任务书

小组要在 Windows 本地空工作区独立实现一套辅助程序化地牢关卡审阅的离线渲染与校验组件：关卡先由固定种子脚本确定性地生成为按房间与走廊划分的格网地图，再把地图渲染成俯视灰度图与房间边界描边图，并按分块网格切片输出，供设计者逐块预览与拼装核验。全部样本由随工程交付的固定种子脚本生成，不依赖真实引擎、外部资源或网络，输入为 JSON 关卡描述（网格宽高、房间与走廊的格集合、门位置、墙体厚度、光照衰减半径、调色映射表）与一份 JSON 渲染任务描述（输出分辨率、每格像素边长、分块网格、并发上限、在途像素缓冲内存上限、单轮逻辑时间预算、状态目录）。真正的难点是分块坐标系与跨块几何：墙体的方向由相邻格决定，房间边界的描边与光照衰减都会跨越分块边界，若每块从局部原点起算描边与衰减，拼贴后会在块缝出现一像素宽的错位描边与亮度台阶。

任务环境与准备：
在 Windows 机器上安装 Python 3.11 或更高版本，确保 python 与 pip 可在命令行直接调用。
执行 pip install numpy 安装 NumPy，用于格网运算与确定性灰度合成；无需其他第三方库。
将随工程交付的固定种子样本生成脚本放入工作目录并运行一次，生成关卡描述 JSON、渲染任务 JSON 与参照样本，确认产出可被 JSON 解析。
准备空的状态目录与输出目录，确认当前用户对两目录具有读写权限，并确认可向控制台发送可处理终止信号以验证中断路径。

业务要求：
1. 实现关卡描述与渲染任务的解析校验：读取两个 JSON，校验网格宽高为正整数、房间与走廊格坐标在范围内且不重复、门位置必须落在墙格相邻的可通行格上、墙体厚度为不大于最小房间边长的正整数、光照衰减半径为有限正数、调色映射表为单调不减的灰度控制点、每格像素边长与分块行列数为正整数且分块完整覆盖输出分辨率，非法输入返回带 E_SCHEMA 的 JSON 错误且不产生任何输出图像。
2. 实现整幅坐标下的格网光栅化：每个关卡格按每格像素边长映射为输出像素矩形，格内取样点换算回关卡格坐标只依赖整幅坐标与映射参数，与分块划分、遍历顺序和线程调度无关；同一关卡重复光栅化须逐像素相同，且拼装结果与以分块为 1 块直接渲染的结果逐像素一致。
3. 实现跨块一致的墙体描边与房间边界：墙体方向由该墙格在整幅格网中的相邻可通行格决定，描边宽度按墙体厚度在整幅像素坐标上计算，分块边界的描边不得退化为块内局部判定或截断；门位置的描边与开口须在相邻格两侧都正确呈现，不得出现只有一侧开口的结果。
4. 实现整幅口径的光照衰减与灰度合成：每个可通行格的中心到最近光源的格距按整幅格网计算，衰减按光照衰减半径与调色映射表分段线性映射为灰度，再与地板、墙体、门的基础灰度合成；同一格无论落在哪个分块、处于何并发度都得到同一灰度，块与块之间的亮度不得出现台阶，最终量化到 0 至 255。
5. 按可注入逻辑时钟实现单轮逻辑时间预算与在途内存预算的联合裁决：使用有界线程池按并发上限调度分块，同时在途像素缓冲总量不超过任务描述的内存上限；每轮按已处理分块数量与每块像素数确定性推进逻辑时钟，超出单轮预算即结束本轮并让出未准入分块，使任意并发度下的轮次数与准入序列可复现，禁止通过降低每格像素边长或调色级数来满足预算。
6. 实现分块级持久化与版本识别恢复：每块完成后把灰度切片、描边切片、该块在整幅中的像素偏移与覆盖范围、块内容摘要及由关卡描述与渲染任务规范化摘要构成的版本标识原子写入状态目录，先写同目录临时文件再整体替换；再次启动时版本标识一致则复用已完成块只渲缺失块，标识变化时不得直接覆盖旧块而须先归档旧版本；块摘要不匹配、缺失或声明像素数不符时判定该块失效并返回 E_DIGEST 且回退补渲。
7. 处理可处理终止信号与强制终止的差异并原子写出结果：外部可发送的可处理终止信号只在分块边界生效，须在写出中断标记并以约定整数退出码退出前保证未完成块不留下可被误认为已完成的结果；强制终止后重启仅依据已持久化且摘要有效的块状态恢复且不承诺生成退出报告；全部块完成并通过校验后按块行列索引序拼装灰度图与描边图，先写同目录临时文件再整体替换正式输出，替换前读取已有输出的尺寸与版本标识，版本不同才替换。
8. 实现拼接一致性验证报告：报告须逐块给出像素偏移、覆盖范围、失效理由、复用或重渲标记、块边界处相邻像素灰度差的最大值，并给出拼装图与整幅直接渲染参照图的最大逐像素差与超限位置；任一块边界灰度差或整幅偏差超过任务描述中的容差时返回 E_SEAM 并定位首个不一致像素的整幅坐标与所属块，校验通过时同样产出报告与业务码汇总。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地样本验证拼装图与整幅直接渲染逐像素一致、跨块描边与光照无接缝，并验证双预算调度、块摘要校验与中断恢复。
