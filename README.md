在空白工作区从零实现一个本地 SQL 逻辑计划构建与异常注入验证引擎，用于在确定性样本上验证查询解析、逻辑计划构建、计划重写与代价估算的可复现性与异常链路。输入为本地 SQLite 样本库（含表结构、索引与固定数据）与一组 SQL 查询模板（SELECT 子集，支持 WHERE、JOIN、GROUP BY、ORDER BY、LIMIT 与聚合函数）。引擎需实现词法、语法解析生成 AST，基于 AST 构建逻辑计划（Scan、Filter、Project、Join、Aggregate、Sort、Limit 算子），执行谓词下推与常量折叠重写，并用确定性代价模型为计划打分。引擎还需提供异常注入机制：按注入清单在解析、重写与代价估算阶段注入受控异常（如非法谓词、类型不匹配、循环别名引用、代价溢出），验证错误码、事务一致性与恢复后状态。所有样本、注入清单与期望输出均本地固定，不依赖网络、真实账号或外部数据。

任务环境与准备：
安装 Python 3.11 或以上版本并确保 python 与 sqlite3 标准库可用，无需第三方数据库服务。
在项目虚拟环境中安装 pytest 用于本地测试，不依赖网络或额外数据。
准备本地 SQLite 样本库生成脚本，创建固定表结构、索引与确定性数据行。
准备固定 SQL 查询模板文件与异常注入清单 JSON，所有路径在工作区内可复现。
确认工作区可写，SQLite 数据文件与对象目录位于工作区内，不引用外部绝对路径。

业务要求：
1. 实现 SQL 词法与语法解析器，将 SELECT 模板解析为 AST，覆盖 WHERE、JOIN、GROUP BY、ORDER BY、LIMIT 与聚合函数；解析失败时返回 E_PARSE 业务码并包含出错位置与片段，不得抛出未分类异常。
2. 基于 AST 构建逻辑计划，生成 Scan、Filter、Project、Join、Aggregate、Sort、Limit 算子节点；节点需保留来源 AST 位置与列引用信息，计划以稳定 JSON 输出节点类型、子节点顺序与输出列。
3. 实现谓词下推与常量折叠重写规则：Filter 应尽可能下推到 Scan 或 Join 之下，常量表达式在重写阶段折叠；重写后的计划必须与重写前语义等价，并输出重写前后计划差异用于诊断。
4. 实现确定性代价模型为逻辑计划打分：代价依据本地统计信息（行数、NDV、索引列顺序）与算子代价公式计算，相同输入多次运行必须得到逐位一致的结果；代价结果与计划一并输出 JSON。
5. 实现异常注入机制：按本地注入清单在解析、重写或代价估算阶段注入受控异常（非法谓词、类型不匹配、循环别名引用、代价溢出），每种异常映射到不同业务错误码，且不得破坏样本库或引擎持久化状态。
6. 实现持久化与恢复：将解析结果、逻辑计划、重写差异、代价与注入记录原子写入 SQLite；进程被强制终止后，恢复路径依据持久化记录识别未完成的分析轮次并只重放未提交步骤，不得重复计算已提交结果或回退状态。
7. 保证多进程并发时的一致性：同一查询模板的并发分析必须通过 SQLite 事务与文件锁保证只提交一次结果，读取方看到完整提交态而非中间态；重复提交相同模板必须幂等，注入清单变更需识别并作用于新轮次。
8. 提供命令行接口与可重复实验环境：支持 parse、plan、inject、resume、report、verify 子命令，report 以稳定排序输出 JSON；verify 校验持久化状态与输出一致性；使用固定本地样本与注入清单运行两次，输出必须逐字节一致。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地固定样本与注入清单验证解析、逻辑计划、重写、代价及异常错误码，并确认两次运行输出逐字节一致。
