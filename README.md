当前是空白工作区，需要从零实现一个本地训练数据管线的分片缓存与并行调度控制面，用于在确定性样本上复现训练样本分片从生成、缓存、复用到大 batch 组装的完整调度链路，并在 CPU 内存预算与每轮逻辑时间预算的双重约束下做出可复现的调度裁决。本地 JSON 样本给出：数据集清单（数据集名、样本总数、样本特征维度、样本字节数估计、是否可缓存、分片大小）、分片缓存视图（已缓存分片集合、每分片字节大小、缓存代数、最近使用逻辑时钟）、训练作业描述（作业名、所需 batch 大小、epoch 数、数据并行度、每 worker 的预取深度、是否允许分片跨 worker 复用），以及调度配置（每轮总逻辑时间预算毫秒、每数据集并发预取上限、全局内存预算 MiB、缓存容量条目上限、容差参数、逻辑时钟步进）。控制面需为每个 worker 计算所需分片序列，判定缓存命中与需回源生成的分片，在内存预算与逻辑时间预算下并行调度分片生成与预取，并保证同一 batch 内样本顺序固定、跨 worker 无重复样本、缓存整体替换时可识别版本变化。

任务环境与准备：
安装 Python 3.10 或以上版本，创建本地虚拟环境并安装 numpy 与 pytest（版本以本地 wheel 可用为准，无需联网即可复现样本生成）。
确认工作区可创建本地目录与 SQLite 文件，样本 JSON 由题目附带的本地脚本或手工放置在 data 目录下，不依赖任何外部数据集或网络服务。
运行前执行样本库与分片缓存的初始化脚本，生成固定种子下的数据集清单、分片缓存视图与训练作业描述，并记录其内容摘要作为真值来源。

业务要求：
1. 实现数据集清单、分片缓存视图与训练作业描述的解析校验：数据集名与作业名唯一、样本总数与特征维度为正整数、分片大小为正整数且能整除样本总数、每 worker 预取深度非负、数据并行度为正整数、缓存代数单调、缓存条目字节大小与分片声明一致，构建数据集到分片、分片到 worker 的映射模型；非法输入必须返回明确业务错误码且不写入任何持久化状态。
2. 实现分片内容寻址生成与确定性样本切分：按数据集名、分片序号与全局种子确定性生成每个分片的样本摘要与字节大小，相同输入重复生成必须得到逐位一致的分片清单；分片到训练样本的切分边界固定，使任意 worker 按分片序列取出的样本序列在任意运行次数下逐位一致，并记录每个 batch 的样本来源分片与样本序号。
3. 实现缓存命中裁决与回源生成的增量失效：以数据集名、分片序号、缓存代数与样本生成参数为缓存键判定命中，命中时复用缓存分片不再生成，未命中时回源生成并写入缓存；样本生成参数或数据集版本变化必须使受影响分片及其下游 batch 缓存精确失效，未受影响分片缓存必须复用且样本序列不变，失效决策须输出触发来源与被复用项清单。
4. 实现并行预取调度与资源预算裁决：同一轮次内按数据集分组并发调度分片生成与预取，同时受全局内存预算 MiB 与每数据集并发预取上限双重约束；内存预算耗尽时必须放弃剩余未启动分片并记录放弃原因，区分预算内未启动、启动后失败与主动放弃三类结局，已启动分片必须执行完毕并记录内存占用峰值。
5. 实现基于注入逻辑时钟的预取轮次推进与超时语义：分片生成耗时、预取深度对应的提前量、每轮逻辑时间预算判定只依赖注入的逻辑时钟毫秒值，不得读取系统墙钟；超时须由逻辑时钟推进与实际等待共同判定而非事后标注，同一逻辑时钟序列下重复调度必须得到逐位一致的预取顺序与放弃集合。
6. 实现 batch 组装顺序一致性与跨 worker 无重复校验：按固定规则把 worker 所需分片组装为 batch，batch 内样本顺序与 worker 间分片分配必须稳定且不重叠；同时以单进程串行读取计算唯一真值，逐 batch 比对样本摘要，任何不一致须输出首个差异 batch、分歧样本与两条路径的中间状态。
7. 实现持久化状态与强制终止后的恢复一致性：把预取轮次水位、已提交分片清单、缓存条目版本、内存占用账目与逻辑时钟水位以事务原子写入 SQLite，每轮提交识别版本变化并整体替换当前调度快照指针；进程在分片生成或缓存提交中途被强制终止后，恢复路径依据持久化状态识别已提交分片与半提交缓存，只重放未完成分片且不重复计入内存占用。
8. 实现多进程并发一致性、幂等提交与可重复命令行演示：允许多个调度实例并行处理不同数据集，通过 SQLite 事务与文件锁保证同一分片同一缓存代数只被生成提交一次、同一 batch 摘要只被记录一次，重复提交相同分片或 batch 结果必须幂等，读取方只能看到完整已提交轮次；提供 load、schedule、resume、status、verify 子命令，status 以稳定排序 JSON 输出每数据集缓存命中率、内存占用与放弃分片，verify 校验持久化状态与输出一致性。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
