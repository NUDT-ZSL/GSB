当前是空白工作区，没有现存项目、代码或数据附件，需要从零构建一个面向 LLM 推理采样链路的本地可集成算子组件与完整示例。业务对象是本地确定性生成的采样任务清单（JSONL，字段含 case_id、vocab_size、batch_size、seed、k_mode、k_value、temperature、top_p、group_size、dtype、tie_policy、resource_profile），logits 数组由固定种子驱动 NumPy 确定性生成，不依赖任何真实模型权重或网络资源。组件需完成 TopK 候选筛选、阈值截断、温度缩放与确定性采样的组合计算：TopK 阶段按规模选择全排序、堆选择或分块两阶段选路，采样阶段在筛选后的候选上做温度缩放与随机数驱动的确定性抽取。核心业务问题是数据规模变化下的算法取舍与异常处置：不同选路在比较次数、驻留内存与平局裁决上口径不同，必须保证各选路在声明容差与平局规则下给出同一候选集合与同一样本序列；资源上限与选路决策相互牵制，冲突裁决必须可复现且在越限时仍给出可核对的候选与采样结果，异常须沿四阶段链路归因到具体字段。

任务环境与准备：
安装 Python 3.10 及以上与 NumPy，确保工作区可写以便组件与命令行示例生成并读取本地 JSON 与缓存目录。
准备本地确定性样本生成脚本入口说明，样本与 logits 全部由固定种子在运行时生成，不依赖网络、真实模型权重或外部数据集。
无需容器或任何外部服务，所有验证通过本地命令行示例与本地生成样本完成。

业务要求：
1. 实现 TopK 与采样的统一算子入口，按任务清单解析 vocab_size、batch_size、k_mode、k_value、temperature、top_p、group_size 与 dtype，对未知 dtype、vocab_size 与 logits 维度不符、k_value 越界或非正分别返回结构化业务码 E_DTYPE_UNSUPPORTED、E_SHAPE_INVALID、E_K_INVALID 并指明字段。
2. 实现三条 TopK 选路：全排序选路、堆选择选路与分块两阶段选路，同一 case 在三条选路下必须给出相同候选索引集合与相同候选顺序，顺序口径由 tie_policy 显式声明，平局时按索引升序打破；任选路出现候选缺失或重复返回 E_TOPK_INCONSISTENT 并指明 case_id 与首个偏差位置。
3. 实现基于规模的选路决策器：按 vocab_size、batch_size、k_value 与剩余资源估计从三条选路中选择一条，输出含规模观测与比较次数估计的决策记录；同一观测下决策必须逐字节一致，且所选选路在给定资源上限内可执行完毕，不得事后改判选路。
4. 实现温度缩放、top_p 截断与确定性采样阶段：先按 temperature 缩放 logits，再按 top_p 对累计概率截断，最后以 seed 驱动的确定性随机数序列逐 step 抽取样本，禁止使用全局随机状态；同一 case 在同一选路与同一 seed 下必须逐字节产出相同样本序列，平局与边界概率按声明规则裁决。
5. 实现比较次数、驻留内存与候选截断之间的冲突裁决：当全排序比较次数逼近预算、分块两阶段降低内存但放大块边界开销、top_p 截断收紧提升采样质量但可能淘汰应保留候选时，须按显式优先级规则裁决并在决策记录中说明取舍理由；降级须标记降级类别且不得改变已输出候选的正确性。
6. 实现以 float64 全排序路径为参考真值的偏差裁决与误差统计：输出各选路候选分数偏差、采样序列一致性与最大绝对偏差，超出容差返回 E_TOLERANCE_EXCEEDED 并指出 case_id、选路与越界元素；不得以放宽容差或跳过选路掩盖真实不一致。
7. 实现由输入或参数触发的四阶段异常注入框架：在候选筛选、温度缩放、top_p 截断、采样四个阶段分别提供注入点（如 logits 含非有限值、temperature 为零或负、top_p 越界、seed 缺失），注入不得修改源码；每次注入须产生带阶段名、业务码与 case_id 的记录，并沿异常链路归因到具体阶段与输入字段，未被任何阶段归因的异常须汇总到结果中。
8. 提供可集成的领域组件接口与完整示例，并实现配置与统计量快照的版本化及跨选路一致性自检：暴露 topk、sample、决策记录与偏差裁决入口；命令行示例读取本地生成样本输出含候选、样本序列、决策记录、偏差统计、四阶段注入记录与业务码的 JSON；配置与统计量快照各携带单调递增版本号与内容校验和，检测到版本变化时整体替换旧快照，自检校验三条选路候选集合可互相核对、样本序列可由候选与 seed 重放一致，不一致返回 E_INCONSISTENT。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地生成样本验证三条选路候选与采样序列一致、多规模决策与冲突裁决可复现，并核对注入归因及资源越限行为，附运行输出。
