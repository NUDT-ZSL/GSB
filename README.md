在三维扫描资产入库与游戏美术验收场景中，需要从零开发一个本地点云离屏重建渲染引擎：把一组带颜色与法线方向的稀疏三维点，按给定相机参数渲染为二维灰度与深度投影图，用于检查点云的空间分布与遮挡关系，并在渲染过程中支持中断与恢复。输入为一个 JSON 场景描述，包含点云数据文件（每点三维坐标、灰度值、法线方向）、世界尺度与坐标原点偏移、相机参数（位置、目标点、上方向、垂直视场角、宽高比）、渲染分辨率、每像素超采样倍数、点半径与深度衰减参数、分块规格、并发上限、在途采样缓冲内存上限、状态目录，以及异常注入清单。点云由程序按确定性规则生成本地样本，不依赖任何外部模型资源或真实扫描附件。真实难点在于：点云没有面片拓扑，每个点的贡献范围与遮挡顺序必须由深度与半径重新定义；恢复渲染时还必须能在样本被人为改动后识别失效块而不是复用陈旧结果。

任务环境与准备：
安装 Python 3.10 及以上版本，仅使用标准库与 NumPy，无需 GPU、渲染库或任何外部资源。
准备一个空工作区目录，题目所需的点云文件与场景 JSON 由程序按确定性规则在本机生成，不依赖附件或网络。
确认可在 Windows 终端运行 Python 脚本并读写工作区内的状态目录与输出目录，具备发送可处理终止信号与强制终止进程的手段以验证恢复语义。

业务要求：
1. 实现场景描述与点云数据解析校验：读取 JSON 场景与点云文件，校验每点坐标、灰度与法线均为有限数、灰度落在 0 至 1、法线非零、世界尺度为有限正数、垂直视场角在 (0,180) 度内、宽高比为有限正数、分辨率与分块规格为正整数且分块完整覆盖超采样像素网格；非法输入返回带 E_xxx 业务码的 JSON 错误且不产生任何输出文件。
2. 实现点到像素的投影与超采样判定：按相机位置、目标点与上方向构造视图变换（上方向与视线平行时报 E_CAMERA），按垂直视场角与宽高比构造透视投影，把每个点投影到超采样像素网格，并按点半径在屏幕空间的投影范围枚举受影响的采样点，落在视锥外或近平面后的点不计入且需在报告里计数。
3. 实现点云深度遮挡与逐采样点合成：同一超采样点上多个点的贡献按深度比较决定遮挡顺序，最近点的灰度按深度衰减参数衰减后写入，其余更远点不再贡献；深度与衰减计算须在统一的世界坐标单位下进行，保证世界尺度变化时遮挡关系与灰度排序不翻转。
4. 实现确定性分块调度与像素等价：按分块规格把超采样像素网格分块，用有界线程池按并发上限调度，每块只读点云、相机与渲染参数并写回块私有结果，块内对点的过滤与写入次序须与串行逐点处理等价，最终降采样图像与串行结果逐像素相同，且与并发调度完成顺序无关。
5. 实现分块级持久化与版本识别恢复：每块完成后把该块灰度与深度结果、块内容摘要与由点云内容、相机及渲染参数规范化摘要构成的版本标识原子写入状态目录，先写临时文件再整体替换；再次启动比对版本标识，一致则复用已完成块只渲缺失块，不一致则从零重渲，且替换前须识别旧版本块并归档而非直接覆盖。
6. 实现样本改动后的失效块判别与补渲：在恢复时逐块比对块内容摘要，点云局部点被改动后只有覆盖到该点影响范围的块应判定失效，其余块仍可复用；全部块完成后逐块校验，摘要不匹配或声明像素数不符时返回 E_DIGEST 并回退补渲该块，禁止静默使用失效块，并须在报告中列出失效块与重渲块集合。
7. 处理中断信号、强制终止与原子写出：可处理终止信号只在分块边界生效，写入中断标记并以约定整数退出码退出，未完成分块不得留下可被误认作完成的结果；强制终止后仅依赖已持久化且摘要有效的块状态恢复且不承诺生成退出报告；全部块校验通过后按行序拼装灰度图与深度图，先写同目录临时文件再整体替换正式输出，替换前读取已有输出图像的尺寸与摘要版本信息，版本不同才替换并保持两文件同版本。
8. 实现并发资源上限与异常链路：同时处于计算中的分块采样缓冲总量不得超过描述中的内存上限，超出时按分块索引序让后续块等待而非降低超采样倍数；任一分块异常时取消其余待处理分块并返回首个错误，报告中记录已成功块数与失败块索引；异常注入通过场景中的异常注入清单传入（如零半径、非有限法线、越界分块规格），不得通过修改源码制造失败。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
