当前是空白工作区，需要从零实现一个本地服务注册中心的探测结果差分解算引擎，核心业务问题不是探测调度本身，而是把探测观测流转换为可重放、可校验、可差分推进的实例状态账本。注册清单以本地 JSON 给出服务名、实例 ID、回环观测端点、期望状态码集合、租约代数、观测序列化基线与状态世代号；探测观测以本地 JSON 观测流文件形式提供，每条记录含实例 ID、观测序号、注入逻辑时钟毫秒、观测状态码、观测延迟、观测摘要哈希；引擎不发起网络探测，而是把观测流差分解算为每个实例的状态世代、连续失败计数、租约剩余代数与退避阶梯的确定性演进。核心难点在于：观测流可能乱序到达、重复到达、局部缺失或被截断，状态演进必须严格按观测序号与逻辑时钟双键排序裁决，且当观测流被切成多个分片分别加载时，任意分片加载顺序与任意中断恢复点都必须收敛到同一状态账本；跨版本观测摘要的语义兼容、缺失观测的补洞裁决与已提交状态世代的不可回退构成相互耦合的三重约束。

任务环境与准备：
Windows 10/11，安装 Python 3.11 及以上并可用 pip。
安装依赖：pip install numpy pytest（用于确定性哈希、摘要比较与测试用例，无需网络探测库）。
在工作区根目录创建 samples 目录，放入注册清单 JSON、观测流分片样本（含 v1 与 v2 两种格式、乱序与重叠分片）与注入逻辑时钟序列文件；创建 workspace 目录用于账本与运行产物。
确认 Python 内置 sqlite3 可用，文件系统支持临时文件重命名原子操作，无需监听任何端口或访问外部网络。

业务要求：
1. 实现注册清单与观测流的解析校验：服务名与实例 ID 唯一、观测端点为合法回环地址、期望状态码集合非空且元素为三位整数、租约代数为非负整数、状态世代号为正整数、观测序号在同一实例内为正整数、观测摘要哈希与观测字段规范化后的确定性哈希一致；非法条目必须返回明确业务错误码（如 E_BAD_INSTANCE、E_BAD_OBS_SEQ、E_DIGEST_MISMATCH）并整体拒绝该文件，不得写入任何持久化状态。
2. 实现双键排序与乱序观测的确定性归并：观测在实例内先按观测序号严格排序，序号相同则按注入逻辑时钟毫秒裁决，逻辑时钟相同则依据观测摘要哈希做稳定次序；乱序到达的观测不得改动已提交状态世代，只能进入待裁决缓冲区；同一观测序号在缓冲区中出现互斥内容时必须返回 E_CONFLICT_OBS 并保留双方摘要与到达顺序作为诊断字段，且不得静默取舍任一方。
3. 实现观测差分到状态世代的演进规则：成功、状态码不符、缺失观测（补洞）三类结局分别驱动实例在健康、可疑、失联之间迁移，连续失败计数只在真正观测失败时递增，补洞裁决不得冒充成功也不得自动递增失败；租约代数随逻辑时钟推进递减，代数为零时进入失联并以新状态世代记录，同一实例同一状态世代只允许一次迁移提交，世代号必须单调递增且不可回退。
4. 实现分片加载与任意加载顺序下的收敛保证：观测流可拆为多个分片文件独立加载，引擎须记录每个分片的内容摘要与覆盖的实例与观测序号区间；无论分片以何种顺序加载、是否有分片暂时缺失，只要最终全部确定分片到齐，状态账本必须与按单一完整流一次性加载逐字段一致；分片重叠区间必须以观测序号与摘要一致性校验，冲突须报告重叠摘要对而非覆盖。
5. 实现中断恢复与半提交观测的裁决：把每个实例已提交状态世代、连续失败计数、租约代数、待裁决缓冲区内容摘要、已加载分片清单以事务原子写入 SQLite，每批提交以临时表加批次号整体替换当前账本指针；进程被强制终止后，恢复路径依据持久化状态识别已提交观测水位与半提交缓冲，只重放水位之后的观测且不得重复递增连续失败计数，恢复后账本须与未中断运行逐字节一致。
6. 实现观测摘要的跨版本语义兼容与差异报告：观测记录存在 v1（相对延迟毫秒 + 状态码）与 v2（绝对观测毫秒时间戳 + 状态码集合 + 延迟直方图摘要）两种格式，引擎须在同一账本中互操作，v1 相对表示在注入逻辑时钟下换算为绝对时刻并记录换算标度与舍入方向；同一观测在两版本中语义等价时不得重复计一次失败，语义不等价时须输出差异字段清单并将该实例标记为版本冲突待复核，不得直接覆盖已提交状态世代。
7. 实现探测异常的归因与业务错误码隔离：观测摘要不匹配、分片哈希不匹配、观测引用未声明实例、观测序号回退、逻辑时钟回拨超过容差分别映射到不同业务错误码并在差异报告中保留可诊断字段（实例 ID、观测序号、分片名、两个摘要）；单个实例或单个分片的异常不得阻止其他实例或分片的账本提交，也不得使账本进入部分写入态。
8. 提供命令行接口与可重复验证工具：支持 load、reconcile、resume、status、verify 子命令；status 以稳定排序 JSON 输出每实例状态世代、连续失败计数、租约代数、最近一次迁移依据的观测序号与摘要；verify 校验账本指针版本、分片清单、待裁决缓冲区摘要与状态世代单调性三者一致；使用固定本地样本与注入逻辑时钟序列，两次完整运行与一次强制终止恢复运行必须产生逐字节一致的账本快照与相同退出码。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用固定分片观测流与逻辑时钟样本，验证乱序归并、差分演进、跨版本兼容及中断恢复后账本逐字节一致。
