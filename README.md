家居陈设设计师与室内声学顾问要为住宅客厅的立体显示沉浸式方案做评审：设计师按房间尺寸摆放沙发、电视柜、茶几与座椅，并给出投影屏幕的尺寸、分辨率、观看距离、双目间距与零视差平面距离，业主会在不同座位佩戴立体显示设备查看效果。屏幕参数与座位位置一改，部分屏幕区域的水平视差就会超出人眼舒适范围，家具在立体重构中的空间比例随之失真，视觉沉浸区域还可能和声学采样覆盖区域错位。设计师无法靠手工逐座位逐区域推算这些量，更无法在方案微调后快速指出哪些座位与哪些屏幕分块的影响发生了变化。需要一套在本地运行的评估与增量重算内核，装载陈设工程、逐位姿计算视差与重构深度、标记超限区域、核对空间比例与声学对齐，并在参数修改后只重算受影响部分。

任务环境与准备：
在 Linux（WSL Ubuntu）下准备 Python 3 运行环境，仅使用标准库，无需安装第三方包或配置外部服务。
从空工作区创建项目，确定性陈设工程生成器、样本工程与快照文件均放在仓库内由题目自带的固定种子生成或提供。
程序入口以本地命令行方式运行，评估结果以结构化文本或 JSON 输出，无需图形界面与网络服务。

业务要求：
1. 实现陈设工程装载器，解析房间尺寸、家具包围体、屏幕参数、观看向量与声学采样点声明，逐项校验必填字段、数值范围、家具与观看位姿引用完整性以及屏幕分块网格与分辨率的一致性，对每个错误输出包含工程路径定位与错误码的清单，并保证错误清单对同一输入稳定排序。
2. 依据屏幕宽度与水平分辨率、双目间距、观看距离与零视差平面构建双目投影模型，对每个候选观看位姿下的每个屏幕采样点计算水平视差（以像素为单位）与由视差映射得到的重构立体深度，输出逐位姿逐分块的视差统计量，并保证视差符号遵循会聚与发散方向的定义。
3. 按给定的视差舒适区间与深度失真阈值判定每个分块是否超限，输出分块舒适度评分（综合超限像素比例与超限幅度的加权结果）、超限区域掩码与主要成因类别，并保证舒适度评分与掩码在同一输入下可复算，成因分类只依据视差越界方向与越界幅度。
4. 结合家具包围体在重构立体深度下的位置核对客厅空间比例与布局关系，对沙发到电视柜、茶几到屏幕等关键间距计算立体感知距离与标称距离的偏差量，输出比例失真区域定位与偏差数值，并说明该偏差由哪些观看位姿与屏幕分块贡献。
5. 将视觉沉浸区域（由视差舒适分块聚合得到的可行观看区域）与声学采样覆盖区域按房间平面坐标对齐，输出失配采样点编号、失配类型（视觉可达而声学未覆盖或反之）与失配距离，形成供设计迭代使用的对齐摘要。
6. 实现参数变更后的增量重算：当家具位置尺寸、屏幕参数或观看位姿发生变化时，沿陈设与显示参数的依赖关系推导受影响的观看位姿与屏幕分块，仅重算受影响部分，未被波及的分块结果保持既有值不变，并输出受影响范围清单。
7. 提供增量结果与全量重算的逐位姿逐分块一致性比对，输出是否一致与首个分歧位置（位姿编号、分块行列、字段名），并保证同一工程重复执行增量路径得到相同结果。
8. 实现评估结果的快照持久化与查询：按方案版本写入舒适度评分、超限掩码与对齐摘要，支持按位姿与分块范围查询历史版本，并在重载快照后能继续执行增量重算且与未重载路径结果一致。

验收：
对小型客厅布局按投影公式核对视差与掩码，修改陈设后增量与全量逐分块一致且首个分歧可定位。
