在一台没有历史代码的机器上，需要从零构建一个面向二维/三维数值样本的聚类与密度估计诊断工作台。业务对象是本地确定性生成的样本清单（JSONL，字段含 sample_id、feature 向量（2~8 维）、group 标签）与一份建模配置：模型族为高斯混合模型（GMM）与核密度估计（KDE）二选一，分量数或带宽、协方差类型、迭代上限、收敛容差、初始化种子、分块口径与精度档（float64、float32、定点缩放整数）。GMM 用确定性 EM 求解（初始化由种子驱动，分块计算责任度并按显式声明顺序归约）；KDE 用固定带宽的确定性核密度求和。工作台把一次分析建模为多级流水：标准化→分块 E 步/M 步（或对每个查询点的密度贡献分块求和）→归约→收敛判定→批量全量密度/责任度表。用户会以交互方式按 sample_id 查询某样本的密度或责任度、并请求一次批量全量分析。核心业务问题是：交互查询必须在延迟预算内返回，且查询结果必须与批量全量分析结果在声明精度内一致；同时精度档切换、分块口径变化或样本追加之后，缓存与快照必须按版本整体替换并精确失效。

任务环境与准备：
安装 Python 3.10 及以上版本，并确保命令行可调用 python。
安装 NumPy：在命令行执行 python -m pip install numpy，版本 1.24 及以上。
准备任务运行目录，由工作台在首次运行时确定性生成样本清单 JSONL 与建模配置文件，无需外部数据集或真实账号。
确认可写本地缓存目录与快照目录，工作台将在其中以内容哈希与版本号落盘；无需 Docker 或其他容器环境。

业务要求：
1. 实现确定性的标准化与分块核心：数值列按配置做 z-score 或 min-max，GMM 路径按分块口径分块计算责任度并按显式声明的归约顺序归约完成 E 步与 M 步，KDE 路径对查询点分块求和密度贡献；同一输入、同一精度档与同一配置下，样本责任度、对数似然轨迹与最终密度值必须逐字节可复现，禁止依赖除固定种子与输入外的任何系统状态。
2. 实现交互式按 sample_id 查询接口并控制单次延迟预算：查询须返回该样本的责任度分布、所属分量或密度值及置信摘要，延迟以本地计算循环的实际处理计时作为观测，并按样本数、分块数与核函数求值次数给出估算记录；超预算时返回 E_LATENCY_BUDGET 并附带已完成的分块与已消费预算，禁止用预设延迟掩盖真实处理耗时。
3. 实现查询侧与批量侧的结果一致性保证：查询返回的责任度向量、所属分量与密度值，必须与批量全量分析结果中同一 sample_id 的记录在声明精度内一致，且参与计算的分块集合、标准化统计量与精度档完全相同；检测到偏差返回 E_INCONSISTENT 并输出首个偏差位置、查询路径与批量路径上的中间量。
4. 实现可切换精度档的共用算子语义与逐级误差谱归因：float64、float32 与定点缩放整数三档共用同一算子语义，定点档的缩放因子与舍入模式由配置显式给出；以 float64 批量结果为该快照内参考真值，输出标准化、分块求和、定点量化与收敛判定各级的绝对偏差、相对偏差、误差区间与误差放大比，并定位主导来源为分块归约、量化舍入或收敛判定中的一级。
5. 实现收敛判定与分块归约的数值稳定性保护：对收敛容差与最小改善门限提供严格比较与容差带比较两种策略及次正规数保护，保证恰好落在门限附近的迭代轮次在多档精度重复运行下判定不被舍入翻转；容差或门限非法分别返回 E_CONFIG_INVALID 并指明字段，被保护轮次与跳过记录须逐项输出。
6. 实现内容寻址缓存与依赖失效联动：标准化统计量、分块责任度、密度求和中间量与批量结果各以内容哈希落盘，缓存键须纳入样本内容哈希、分块口径、精度档、初始化种子与上游产物哈希；键相同必须复用快照，键不同必须重算；修改单个样本、调整分块口径或切换精度档时计算受影响样本集合，复用未受影响的已提交产物，并输出重算集合与复用集合。
7. 实现分析快照与配置的版本化及整体替换：样本统计量、模型参数（分量均值协方差或带宽）与批量结果快照各携带单调递增版本号与内容校验和，提交时整体替换旧快照而非增量修补；重启加载时识别版本号或校验和变化并整体替换，旧版本不得覆盖新版本，回退尝试返回 E_SNAPSHOT_ROLLBACK，损坏或校验和不符返回 E_SNAPSHOT_CORRUPT 并指明快照类别与版本号。
8. 实现并发提交控制、资源上限、输入校验与跨模块一致性自检：同一时刻只允许一个快照提交生效，并发冲突时后到者立即获得 E_STAGE_BUSY 而不阻塞等待；为驻留责任度中间表内存、单批样本数与并行查询数设可配置上限，超限返回 E_RESOURCE_LIMIT 或降级并标记类别；重复 sample_id、特征维度不一致、分量数或带宽非正、精度档未知分别返回对应业务码；自检须校验查询索引与批量结果可互相核对、误差谱可由偏差明细重算一致、重算集合与复用集合无交集且并集覆盖全部受影响样本。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
