需求方想尽快看到可演示的成果，而工作室当前的工程目录里既没有纹样拼贴组件也没有任何样本文件。首版组件要能按固定种子生成纹样高度场与方向光浮雕灰度，再按可配置网格切片输出，并支持先预览一个切片再补齐其余切片：缓存让预览很快，但切片边界处的噪声相位、方向光梯度与归一化权重必须与整幅生成完全一致，且分块级持久化在可处理终止与强制终止后都要能恢复出确定结果。全部样本由随工程交付的脚本在本地确定性生成，不依赖网络或外部素材。真正的难点在分块坐标系：每块若从局部原点起算梯度与相位，接缝会出现一像素宽的明暗台阶；若统一到整幅坐标，则缓存失效判断与并发拼装又必须与整幅口径严格对齐。

任务环境与准备：
安装 Python 3.11 或以上版本，并安装 NumPy（pip install numpy），确认 pip 可用。
准备空工作目录；随工程交付固定种子样本生成脚本，首次运行时在本地生成配置 JSON、纹样参数与期望的整幅参照图像，不下载任何外部资源。
确认可在 Windows 命令行下运行 Python 脚本；本任务不使用容器、外部服务或网络依赖。
运行前清理状态目录与输出目录，确保每次演示都从确定初始状态开始。

业务要求：
1. 实现配置与样本描述解析校验：读取本地 JSON 配置与由固定种子生成的纹样、光照、相机与切片参数，校验画布宽高、分块行列数为正整数且能整除画布，种子为非负整数，倍频数为正整数且频率严格递增、振幅为正，方向光为单位向量，浮雕强度与归一化容量差为正数，任一项非法即返回带 E_xxx 业务码的 JSON 错误且不写出任何切片。
2. 实现整幅坐标系下的纹样高度场合成：以种子驱动确定性梯度表逐倍频叠加噪声，任意格点高度只依赖该点整幅坐标、种子与倍频参数，与分块划分、调用顺序及数组对齐方式无关；同一配置重复合成整幅高度场须逐格完全相同，且整幅合成结果与先分块再拼装的结果逐格一致。
3. 实现方向光浮雕灰度与整幅归一化：按整幅高度场的相邻格差分与方向光求点积得到灰度，再按整幅统计极值归一化并量化；梯度求取须跨越分块边界取真实相邻格差分，块边界不得使用块内局部差分或重复边界值，最终灰度值域与量化级数须与配置声明一致。
4. 实现预览单块后补齐其余切片：支持先请求任意单块并立即返回，再请求其余全部块；任意单块切片内容只依赖其整幅偏移与覆盖范围，与请求顺序和缓存状态无关；所有切片按整幅坐标拼装后的图像须与同参数整幅直接生成逐像素相同，不满足时报告首个不一致像素的整幅坐标、所属块与通道值。
5. 实现分块级持久化与版本识别恢复：每块完成后把切片数据、整幅偏移与覆盖范围、块内容摘要及由配置规范化摘要构成的版本标识原子写入状态目录，先写同目录临时文件再整体替换；重启时版本标识一致则复用已完成块只补算缺失块，标识变化时须先归档旧版本而不得直接覆盖。
6. 处理可处理终止与强制终止的恢复语义：可处理终止信号只在分块边界生效，写入中断标记并以约定整数退出码退出，未完成块不得留下可被误认为已完成的结果；强制终止后重启只依据已持久化且摘要有效的块恢复，不承诺生成退出报告，且恢复后补齐结果仍须与整幅生成逐像素一致。
7. 实现并发分块渲染与资源上限：按配置并发上限使用有界线程池调度待算分块，同时在途分块像素缓冲总量不得超过内存预算，超预算时按分块行列索引序让后续块等待而非降低倍频数或归一化精度；任一分块异常时取消其余待处理分块并返回首个错误，任一并发度下最终拼装结果逐像素相同。
8. 实现块摘要校验与接缝诊断报告：全部块完成后逐块比对内容摘要，不匹配、缺失或声明像素数与实际不符时判定该块失效并返回 E_DIGEST 且回退补算，不得静默使用失效块；同时输出 JSON 报告，含每块失效理由、重算与复用块数、块边界相邻像素灰度差最大值及与整幅参照的最大逐像素差。
