在空白工作区构建一个面向本地确定性合成版面图像的文档阅读顺序分析引擎与可复现实验环境。输入为一个本地样本目录：若干程序生成的 PNG 版面图像（固定分辨率，由固定种子在浅色背景上绘制正文文字块、标题块、图片块、页眉页脚与分栏留白，每个块为整数像素矩形），并附一份版面真值 JSON，真值给出每个块的行列分组与阅读序号；一份版面分析配置 JSON（二值化阈值、块最小尺寸、分栏间距阈值、投影分析窗口、标题与正文的高度比区间、阅读顺序规则选择项如分栏优先或区域优先、线程池并发数、单批次处理页数预算、交互延迟预算毫秒、快照提交间隔），以及一份元数据 JSON（页面尺寸、样本分组标签、期望的阅读顺序条目数）。引擎需完成版面块检测、块角色判定、分栏结构推断与阅读顺序排序，并在页面规模从数十页放大到数千页时对算法路径做取舍，输出可复现的实验报告与增量运行诊断信息。

任务环境与准备：
准备 Windows 本地工作区，安装 Python 3.10 及以上与 NumPy，无需网络与 GPU。
使用内置固定种子样本生成脚本产出 PNG 版面图、版面真值 JSON、配置 JSON 与元数据 JSON，样本与脚本随项目本地保存。
确认样本目录与工作目录可读写，并在本地磁盘准备快照与报告输出目录。

业务要求：
1. 实现版面图像加载与块检测层：扫描输入目录下所有 PNG 版面图，校验容器头、尺寸与像素模式并解码为灰度数组，按二值化阈值与投影分析窗口切出文本或图片候选块，过滤小于最小尺寸的噪声块，输出每个块的整数边界框、内部像素密度与来源页名；不合规图像或越界阈值输出 E_IMAGE_FORMAT 或 E_CONFIG_INVALID 业务码并进入失败清单。
2. 实现块角色判定器：依据块高度与正文中位高度之比、内部墨迹密度与水平投影周期性，将每个块判定为标题、正文、图片或页眉页脚四类角色，判定规则与阈值取自局部配置，同分或边界相等时按配置给出的固定角色优先级决断；每个块须输出角色、判定依据的指标取值与被否决的次优角色，同一图像在同配置下多次运行角色结果逐项一致。
3. 实现分栏结构推断：结合块的水平区间重叠度与分栏间距阈值，将同页块划分到若干栏组，并对跨栏通栏块做单独标记；栏组划分须处理单栏、双栏、三栏与混排页面，栏组边界冲突时按栏宽稳定性与栏内块数依次决断并记录冲突裁决明细，关闭分栏推断时必须真实退化为单栏结构而不是仅隐藏输出。
4. 实现阅读顺序排序：按配置选择分栏优先或区域优先两种排序规则，分栏优先按栏组顺序再按栏内纵坐标与横坐标定序，区域优先按块的纵带划分再按带内横坐标定序，跨栏通栏块按其在纵向上覆盖的栏组区间插入并影响其后块序号；输出每个块的阅读序号、所属栏组与序号依据，同分时按块左上角坐标字典序决断。
5. 实现数据规模自适应策略选择器：依据页面总数、平均块数、平均栏组数与配置的页数预算，从预置策略表中选择块检测分辨率档位、分栏推断启用状态与排序规则，并输出可审计决策记录，包含所参考的规模指标、候选策略评分、选择理由以及该选择对页数预算估算的影响；同一策略须在决策记录中可追溯其触发条件。
6. 实现增量失效与重算范围判定：为图像内容、块检测、栏组划分与排序各阶段产物计算由上游内容指纹与参数指纹派生的缓存键；当交互修改二值化阈值、分栏间距、排序规则或替换单页图像时，仅使受影响阶段及其下游失效并纳入重算集合，未失效产物必须直接复用且不得重复检测，复用与重算清单须在报告中逐页列出。
7. 保证增量运行与全量重建的阅读顺序一致性，并实现并发执行与串行执行一致：从任意初始状态执行包含阈值调整、排序规则切换、单页图像替换与页面增删的编辑序列，每次增量运行得到的逐页块清单、角色、栏组、阅读序号与诊断摘要，必须与从空白工作区按相同最终输入与配置一次性全量运行的结果逐字段一致；使用线程池并发处理页面时，每个任务携带由页名与阶段名派生的稳定排序键，最大并发数取自配置，最终页面顺序、块顺序与失败清单顺序须与单线程按页名字典序执行一致。
8. 实现阶段快照整体替换、可处理退出语义与实验报告输出：各阶段产物以临时文件写盘后整体替换提交，清单文件记录全局版本号、配置哈希、已完成页列表与产物版本，启动时以版本号与配置哈希判定是否续跑，不一致输出 E_CONFIG_MISMATCH 并拒绝复用旧快照；收到可处理的退出信号时完成当前页产物提交与进度记录后以整数退出码 0 退出；每次完整运行生成 JSON 报告，含逐页阅读顺序条目数、各角色块数、决策记录、复用与重算清单、失败清单与业务码，以及交互命令响应耗时是否超出交互延迟预算。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本验证块检测、分栏与阅读顺序结果，并校验增量与全量、并发与串行一致及异常业务码。
