当前是空白工作区，需要从零实现一个本地模型推理网关的请求路由与预算裁决引擎，用于在确定性样本上复现推理请求随到达规模变化在多个后端副本之间路由、在延迟预算与并发预算约束下做算法取舍，并保证中断恢复后决策一致。本地 JSON 样本给出：推理服务清单（服务名、模型版本、每请求输入 token 数与输出 token 数、每副本算力单位、每副本显存需求 MiB、最小与最大副本数、批处理窗口逻辑毫秒、冷启动逻辑耗时）、节点资源池（节点名、GPU 卡数、每卡显存、每节点实例上限、拓扑域）以及请求轨迹（按可注入逻辑时钟给出每窗口到达率、平均序列长度、预期并发数与每窗口的总 token 预算）。网关需按请求规模与预算约束把请求路由到副本，在数据规模跨越阈值时切换逐请求路由与窗口级批处理路由，并输出可追溯的路由决定链。

任务环境与准备：
安装 Python 3.10 及以上版本，并通过 pip 安装 numpy。
准备本地确定性样本：服务清单、节点资源池与请求轨迹各一份 JSON 文件，放在工作区 samples 目录下。
确保工作区可写，SQLite 数据库文件与本地回环 HTTP 测试服务脚本由任务实现自行生成。
运行环境为 Windows，进程退出码使用整数，业务错误码以 E_xxx 形式出现在 JSON 或 stderr 中。

业务要求：
1. 实现推理服务清单、节点资源池与请求轨迹的解析校验：服务名与节点名唯一、每请求输入输出 token 数为正整数、每副本算力与显存为正整数、最小副本数不大于最大副本数、到达率与序列长度非负有限、每窗口总 token 预算为正整数，构建服务到副本与节点的映射模型；非法输入须返回明确业务错误码且不写入任何持久化状态。
2. 实现基于可注入逻辑时钟的按规模路由裁决：依据请求窗口的到达率、平均序列长度与窗口总 token 预算计算负载等级，在负载低于阈值时采用逐请求直接路由，高于阈值时切换为按 token 预算切批的窗口级批处理路由，切换必须输出实际路由模式、切换触发条件与被否决模式的原因；同一轨迹在任意运行次数下必须得到逐位一致的路由决定链。
3. 实现节点级显存与并发实例双重预算下的副本落点与路由分配：在每卡显存容量、每节点并发实例上限与拓扑域约束下为选定副本确定落点，显存与并发任一不足时不得部分放置；分配须记录每卡剩余显存、被淘汰候选及首个触发约束，且每请求算力需求须在窗口总 token 预算内被扣减，路由目标必须属于已提交的落点分配。
4. 实现并行路由调度的资源预算裁决：同一轮次内按服务分组并发分发请求，同时受每轮总逻辑时间预算与每服务并发分发上限约束；预算耗尽须放弃剩余未分发请求并记录放弃原因，区分预算内未启动、启动后失败与主动放弃三类结局，已启动请求不得被简单截断为超时。
5. 实现基于注入逻辑时钟的批处理窗口与排队演进：批处理窗口边界、请求排队时长与重试退避只依赖注入的逻辑时钟毫秒值，不读取系统墙钟；请求在待路由、排队中、批处理中、已分发、已失败之间按规则迁移，迁移须依据本轮完整结果与持久化状态裁决，重启后不得凭内存残留决定请求状态。
6. 实现强制终止后的恢复一致性：把路由轮次水位、请求阶段、副本落点分配、显存与并发占用、窗口 token 预算消耗与逻辑时钟水位以事务原子写入 SQLite，每轮提交识别版本变化并整体替换当前快照指针；进程在路由或批处理中途被强制终止后，恢复路径依据持久化状态识别已提交请求与半提交请求，只重放未提交请求且不得重复扣减已消耗预算，不承诺强制终止后一定生成退出报告。
7. 实现多进程并发一致性与幂等裁决：允许多个网关实例并行处理同一批服务请求，通过 SQLite 事务与文件锁保证同一请求序号同一版本只被路由一次、同一节点显存与并发实例不被并发超卖、同一窗口 token 预算不被超扣，重复提交相同请求结果必须幂等，读取方只能看到完整已提交轮次快照而非中间态。
8. 实现数据规模变化下的算法取舍评估与异常链路：对同一批服务分别以逐请求路由与批处理路由在不同到达率采样点运行，输出可比较指标（路由完成数以注入逻辑时钟计量、副本利用率、排队时长分位数、失败数）与模式选择依据，并说明估计所依赖的观测与真值来源；上游副本连接拒绝、响应超出单请求预算、响应摘要不匹配、逻辑时钟回拨超阈值分别映射到不同业务错误码并保留可诊断字段，单次异常不得污染同轮其他服务。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用固定本地样本验证路由模式切换、预算裁决、中断恢复与异常错误码，两次运行输出逐位一致。

## 交付与快速开始

实现位于 `gateway/`（引擎）、`samples/`（确定性样本）、`tests/`（43 个 pytest
用例）、`docs/TECHNICAL.md`（算法、错误码与验证结果的技术说明）。

```bash
pip install -r requirements.txt
python -m gateway.cli validate --samples samples
python -m gateway.cli run --samples samples --db artifacts/gateway.db --out artifacts/runs/run.json
python -m gateway.cli evaluate --samples samples --workdir artifacts/eval --out artifacts/runs/eval.json
python -m gateway.cli serve --port 8377   # 本地回环上游测试服务
python -m pytest tests/ -q
```

退出码：0 成功，2 业务/校验错误（stderr 输出含 `E_xxx` 的 JSON），3 模拟
强制终止（`--crash-after`），1 未预期错误。
