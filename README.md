在空白工作区构建一个面向本地确定性样本的语音合成（TTS）声学模型离线渲染与编辑工作台，核心解决声学特征生成过程中状态演进与中断恢复的一致性问题。输入为一个本地样本目录：若干按固定种子程序合成的 16kHz 单声道 16bit PCM WAV 参考音频（含基频轮廓、能量包络与噪声底）、一份音素序列与时长标注 JSONL（每个 utterance 含 utterance ID、音素序列、每音素持续帧数）、一份声学配置 JSON（帧长与帧移毫秒、基频搜索范围与量化档位、频谱包络频带数、清浊判决门限、能量归一化目标、逐帧渲染的最大批大小、并发数与快照提交间隔帧数）以及一份编辑命令流 JSONL（可对指定 utterance 的音素时长、基频缩放、能量缩放与局部帧区间做替换、插入、删除或参数覆盖）。工作台需按音素级状态机推进：逐音素确定清浊与基频轨迹、按频带生成谱包络、做能量归一化与帧级拼接，最终写盘为可回放的 PCM 与声学参数文件。用户在会话中反复提交编辑命令，工作台只重算受影响的音素与帧区间，并须保证任意中断、恢复、编辑序列之后最终声学参数与 PCM 和从零全量渲染的结果逐帧一致。

任务环境与准备：
安装 Python 3.10 及以上版本，并安装 NumPy 与 soundfile（用于 WAV 读写），不依赖网络服务或 GPU。
在本地样本目录准备由固定种子脚本生成的若干 16kHz 单声道 16bit PCM WAV、音素标注 JSONL、声学配置 JSON 与编辑命令流 JSONL，并保留生成种子以便复现。
确认工作目录可写，用于快照临时文件与原子替换；不需要容器、数据库或外部账号。
运行前核对样本采样率、帧长帧移与配置一致，异常样例通过注入配置文件提供而非修改源码。

业务要求：
1. 实现样本与配置加载层：扫描输入目录下所有 WAV 参考音频、音素标注 JSONL 与声学配置，校验容器头、采样率、声道数、位深、utterance ID 唯一性、音素序列与时长数组长度一致、帧长帧移为正且能整除，并发数非正时不得静默降级；不合规输入分别输出 E_AUDIO_FORMAT、E_LABEL_INVALID、E_CONFIG_INVALID 业务码并进入失败清单，失败项之外其余 utterance 必须继续处理。
2. 实现音素级状态机推进：按标注顺序为每个音素依次经过清浊判决、基频轨迹生成、谱包络生成、能量归一化四个子状态，子状态转移条件须显式记录特征值与门限的比较结果；基频按配置范围与量化档位离散化，清浊判决同分时按固定规则决断；每个音素完成时输出其子状态轨迹与中间特征摘要，供恢复时定位到子状态而不只是音素边界。
3. 实现确定性声学特征生成与 PCM 合成：基频轨迹由音素基准值按帧内插值得到，谱包络按频带数以整数谐波叠加生成，能量归一化采用定点缩放与确定性舍入，帧级拼接按帧移重叠相加；所有中间量与最终 PCM 在给定输入、配置与编辑命令序列下必须逐样本一致，禁止随机源；量化档位改变必须真实改变离散化后的基频取值与输出 PCM，不得退化为忽略档位。
4. 实现基于内容指纹的增量失效与精确重算范围：为每个 utterance、每个音素与每个帧区间计算由输入音频片段指纹、标注指纹、配置指纹与编辑历史摘要派生的缓存键；编辑命令只允许使受影响的音素及其下游能量归一化与帧拼接失效，未受影响音素必须直接复用且不得重算；需区分参数覆盖（如基频缩放）导致的失效与纯时长变更导致的失效，并在诊断中给出失效范围与复用范围。
5. 实现阶段快照、版本识别与恢复一致性：将加载校验、逐音素特征生成、帧拼接与写盘划分为阶段，各阶段以临时文件加原子替换方式持久化快照，快照含阶段名、配置哈希、标注哈希、命令游标、已完成音素列表、子状态位置、部分特征摘要与版本号；重启时读取最新快照并校验版本号与配置哈希，不一致输出 E_CONFIG_MISMATCH 并拒绝续跑，一致时从该子状态继续，恢复后的最终参数与 PCM 必须与不中断运行逐样本一致。
6. 实现并发渲染与串行结果一致性：使用线程池并发执行音素级特征生成与帧拼接，最大并发数取自配置；每个任务携带由 utterance ID、音素序号与帧区间起点派生的稳定排序键，无论线程调度顺序与并发度如何，最终音素顺序、逐帧特征顺序、能量归一化累积顺序、失败清单顺序与诊断统计必须与单线程按标注顺序执行逐字段一致。
7. 实现编辑命令中的局部帧区间操作与边界校验：替换、插入、删除帧区间时须校验区间不越界、插入数据帧数与声明一致、删除后音素时长不为零，越界输出 E_RANGE_OUT_OF_BOUND 并保留原状态不写入；局部帧区间操作只能使所在音素与后续受时长影响音素及帧拼接阶段失效，其前序音素必须保持命中；命令按提交序号严格顺序应用，同一序号重复提交须幂等跳过。
8. 实现可处理退出语义与诊断报告输出：收到可处理的退出信号时完成当前音素的子状态与快照原子替换后以整数退出码 0 退出，强制终止后重启仅依据已完整替换的快照恢复并输出恢复点信息，不得承诺一定生成退出报告；每次完整运行输出 JSON 报告，含各 utterance 音素级状态轨迹摘要、清浊统计、基频量化分布、失效与复用范围、恢复点、业务码清单与命令应用记录，字段名须与前述业务码一致。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
