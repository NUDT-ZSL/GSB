产品原型评审通过后，团队在 Linux（WSL Ubuntu）上搭建首个可运行版本，工作区目前没有任何代码或样本。本项目面向领域术语抽取场景，目标是从中文技术文档中识别专有名词并解决同名异义消歧，输出结构化术语索引。全部输入由本地固定种子脚本确定性生成：文档分片 JSONL 每条含 shard_id、doc_id、para_no、text、char_len，另有上下文特征清单、领域术语表以及两套定义不同消歧口径的消歧规则快照。系统将识别链路建模为多级流水线：文档分片校验与规范化→候选术语抽取与置信打分→基于上下文的确定性消歧→术语引用归并与索引导出。核心矛盾是术语规模增长时必须在全量精确匹配与受限近似匹配之间切换，同时保证两条路径的消歧结果可比、规则版本更新能定向失效部分文档、以及强制终止后可从阶段快照恢复。

任务环境与准备：
创建空工作目录，安装 Python 3.10 及以上版本、NumPy 及 SQLite3 标准库支持，确保可运行 Python 脚本。
编写或提供固定种子样本生成脚本，确定性地生成 JSONL 文档分片、领域术语表、上下文特征清单、两套消歧规则快照及任务配置。
运行样本生成脚本产生本地输入文件，将生成脚本与输入文件置于工作目录，确保不依赖外部网络或远程服务。
运行实现的主程序，检查输出术语索引、SQLite 账本和诊断报告；准备强制终止恢复及错误注入测试命令。

业务要求：
1. 实现分片校验、规范化和基于领域术语表的确定性候选术语抽取节点：按术语表做最长优先匹配，输出每个候选术语的码点起止偏移、词表面目、长度等级和命中规则版本，同一 doc_id、术语表版本与配置下必须逐字节产出相同候选集合，同边界候选按术语表条目序号升序裁决；重复 doc_id、char_len 与实际码点长度不符、术语表条目格式错误分别返回 E_DUP_DOC、E_CHAR_LEN_MISMATCH 和 E_TERM_ENTRY_INVALID。
2. 实现候选术语置信打分与上下文特征提取节点：为每个候选术语按长度等级、词典来源权重和所在段落上下文覆盖度加权计算置信分数，逐项记录贡献使最终分数可由明细独立重算；特征范围超过 char_len 或权重为负分别返回 E_CONTEXT_RANGE_INVALID 和 E_WEIGHT_NEGATIVE；同一输入与配置下分数必须确定性一致。
3. 实现两套消歧口径确定的术语消歧节点：对多义候选按上下文特征清单和消歧规则快照计算每个义项得分，依据配置的消歧快照版本选择义项，输出消歧后术语和得分；同分按义项编号升序裁决；消歧规则引用未知上下文特征、义项编号越界或规则口径版本未知分别返回 E_FEATURE_UNKNOWN、E_SENSE_OUT_OF_RANGE 和 E_RULE_VERSION_UNKNOWN。
4. 实现基于数据规模的自适应匹配取舍器：按文档分片数、单文档候选术语数、平均上下文特征数和驻留内存余量，在精确匹配路径与受限近似路径之间选择，输出含规模观测、候选比较次数估计与路径选择的取舍记录；同一观测下决策必须确定性一致，所选路径覆盖全部输入文档，且不得依赖真实系统时间或随机数。
5. 实现精确路径与近似路径的跨路径一致性裁决：对同一文档同时产出两路径的消歧结果时，输出术语集合差异、逐义项置信度偏差和覆盖召回估计，并区分差异来自候选剪枝遗漏还是上下文特征比较口径变化；当差异导致术语索引统计不可比时返回 E_PATH_DIVERGENCE；裁决明细必须可由逐候选贡献重算。
6. 实现候选比较次数与驻留内存双重预算准入裁决：按单文档候选术语数和上下文特征数估算每文档匹配代价，在总比较预算和驻留缓存内存上限内决定准入与降批规模，超限时按显式优先级返回 E_COMPARE_BUDGET 或 E_RESOURCE_LIMIT，并记录被拒文档的规模观测；降批结果须携带降级类别与触发预算项。
7. 实现五阶段状态机、阶段快照版本化整体替换与强制终止恢复：分片校验规范化、候选抽取、置信打分、消歧判定、索引导出五个阶段各自提交带单调递增版本号、已完成文档集合和内容校验和，只有该阶段全部文档完成才原子落盘；若快照目录已有文件，加载时检测到版本号或校验和变化必须整体替换旧快照而非追加；重启时从最后已提交阶段继续，未提交中间状态丢弃并从该阶段起点重建，恢复后的术语索引与全量连续运行一致；快照回退尝试返回 E_SNAPSHOT_ROLLBACK，损坏返回 E_SNAPSHOT_CORRUPT。
8. 实现术语索引导出、跨阶段一致性自检与结果验证工具：按消歧后术语生成索引（术语名、义项编号、首次出现 doc_id、出现次数、置信度摘要），并用 SQLite 账本记录每个文档的候选术语、消歧结果与取舍记录；自检校验索引中每个术语至少对应一条消歧记录、每个 doc_id 的候选集合与账本一致、所有统计量可由逐文档明细独立重算；发现不一致返回 E_INDEX_INCONSISTENT 并输出首个偏差位置。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
