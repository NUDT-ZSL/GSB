电力计量中心的数据科学家正为用电量预测基础模型补充领域词表：计量点编码、电价套餐标识、负荷类型标签与气象关联字段要作为新词元加入，并在少量标注样本上完成嵌入适配，以便上线前判断模型能否识别这些领域标识。三套词表格式版本描述同一批标识，编码分隔符与词元归并规则不同，直接切分会导致同一标识在不同版本下拆成不同子词。新增词元若随机初始化，原有词元嵌入被破坏且少量样本训练不充分；因此需要可逐词元核对的词表扩展与嵌入适配机制。

任务环境与准备：
准备 Python 3.10 或以上运行环境，并安装 NumPy 用于嵌入矩阵计算与相似度核对。
在本地工作目录中创建项目结构，数据由题内确定性生成器按固定种子产出，不依赖外部网络或真实数据集。

业务要求：
1. 读取三套词表格式版本（v1 使用下划线分隔符、v2 使用连字符与斜杠混合分隔、v3 使用点号分隔并允许合并连续数字段）描述的领域标识清单与语料，将编码分隔符归一为统一的分隔语义，输出每个领域标识在三个版本下的归一化切分片段序列及版本间切分差异标记。
2. 依据领域语料频次与新增标识的子词重叠程度确定实际加入词表的新词元集合，对重叠子词数不低于 2 或语料频次不低于 3 的候选保留为扩展词元，其余回退到已有子词覆盖，并为每个新词元记录其切分来源标识与首次出现的样本行号。
3. 对每个新词元，以原有词表中与其共享前缀或后缀的最长已有子词嵌入的逐维均值初始化；若不存在共享子词则使用原有词表嵌入矩阵的全局均值，并输出每个新词元的初始化依据（所引用的已有子词编号）及初始化后的范数。
4. 在少量领域标注样本上训练时，将原有词表对应的嵌入行标记为冻结、仅允许新词元嵌入行与适配层参数更新，适配层为可更新的线性映射；输出每轮训练损失、更新参数下标范围与新词元嵌入的更新幅度统计，并验证原有词元嵌入逐元素保持不变。
5. 分别用扩展前模型和扩展适配后模型对留出的下游预测样本计算损失与领域标识命中率（标注标识作为整体被切分为单一新词元的比例），输出扩展增益数值、逐标识识别明细以及增益方向不确定的标识清单。
6. 对同一领域标识在 v1、v2、v3 归一后应产出相同的词元集合与初始化嵌入；若因分隔符歧义或归并规则冲突导致不一致，输出冲突词元清单，包含各版本下的切分结果与建议人工复核理由。
7. 以独立的嵌入一致性核对检查每个新词元是否仍与原有词表嵌入在共享子词空间中保持合理邻近（以余弦相似度不低于 0.6 为界），并报告超出范围的异常词元、其初始化依据和对应切分来源。
8. 提供本地命令行入口，接受确定性生成器的种子、词表版本选择与样本规模参数，输出词表扩展候选、初始嵌入向量、适配报告、损失对比与冲突清单的 JSON 结果，并保证同一组参数重复运行结果一致。

验收：
以原有嵌入矩阵核对冻结一致性与新词元初始化范数；用含分隔符歧义、重复子词与极低频标识的清单检查切分与频次筛选；扩展前后损失方向正确且同种子可复现。
