玩具结构设计师与装配演示制作人员在评审新结构时，需要把零件渲染图无缝嵌入装配示意底板：零件前景图带透明或纯色背景，目标插入区域掩码标注零件应放置的位置，底板提供纹理与光影。手工贴图在边界处产生明显接缝，且零件内部纹理梯度必须保留。当替换单个零件时，设计师只希望更新该零件覆盖区域，其余已融合部分保持不变，同时要求增量结果与全量重算逐像素一致。团队还需要边界条带的接缝误差报告与替换后的更新区域标注，用于评审追溯。所有输入由固定种子生成器产出，包括底板、前景图、掩码与边界带状标注，不依赖外部图像。

任务环境与准备：
在 Linux（WSL Ubuntu）下准备 Python 3 运行环境，并安装 NumPy 用于像素级数组运算与图像读写。
工作目录从空项目开始，由实现自行创建样本生成、融合求解、报告输出与运行日志所需的文件结构。
运行程序时使用本地生成的固定种子样本，不依赖任何外部图像、网络服务或真实相机数据。

业务要求：
1. 实现确定性样本生成器：按固定整数种子生成装配底板（带纹理与渐变光影的彩色图像）、零件前景图（带透明或纯色背景）、目标插入区域掩码与边界带状区域标注；同一种子必须可复现生成完全相同的像素数据，并将各图像与掩码以保持数组形状的二进制或文本格式落盘，供后续融合与验证使用。
2. 根据零件前景图与目标插入区域掩码构建融合区域的边界条件与内部梯度场：边界条件取底板在掩码边界像素上的颜色值，内部梯度场取前景图在融合区域内的水平与垂直方向梯度；对纯色背景像素须在构造梯度前从前景图提取有效零件像素，并要求梯度场与边界条件以可序列化结构输出供后续求解。
3. 实现泊松方程求解器生成融合图像：在融合区域内部使融合图像梯度逼近前景梯度，在掩码边界上匹配底板颜色；采用离散正弦变换（DST）频域方法或共轭梯度迭代法求解，并保证求解在给定容差内收敛；输出融合后的装配演示图，同时输出求解迭代次数或频域系数矩阵。
4. 计算边界带状区域的接缝误差与梯度保真指标：在掩码边界带状区域内逐像素计算融合图像与底板在边界处的颜色差异，以及融合图像对前景梯度的保真度；输出逐像素误差图与边界保真报告，报告包含带状区域内的最大误差、平均误差与梯度误差分位数，且报告中的数值必须与误差图逐像素统计一致。
5. 支持替换单个零件前景图并增量重算：给定相同掩码与底板，使用新零件前景图重新求解仅受该零件影响的融合子区域；增量结果与全量重算结果逐像素比对，允许误差不超过 1 个量化级，并记录首个超出容差的位置作为增量一致性核验依据；未受替换影响的区域必须保持原有像素不变。
6. 输出融合后的装配演示图与边界误差报告，并标注替换零件后的更新区域：结果以可直接查看的图像文件保存，报告以 JSON 格式记录边界误差指标、更新区域掩码的边界框与像素计数；当替换零件的掩码与上一次不同时，须同时输出旧掩码与新掩码的差集区域，并说明差集区域重新求解与复用旧结果的处理方式。
7. 对融合求解进行输入边界防护与异常处理：当掩码为空、掩码覆盖整幅图像、掩码边界断裂或前景图与底板尺寸不一致时，分别返回可区分的业务错误码与说明信息；在求解不收敛或出现非有限值时，报告具体像素位置与当前迭代信息，禁止静默输出错误融合图像。
8. 提供端到端可运行流程与持久化能力：程序接受底板、前景图与掩码路径作为输入，输出融合图像、误差报告与更新区域标注；多次运行使用同一输入时结果可复现，并将每次运行的输入摘要、关键指标与输出文件路径追加写入运行日志，供评审追溯不同零件组合的融合效果。

验收：
以固定种子样本运行，检查融合图像边界值与底板匹配、内部梯度与前景梯度误差在容差内；替换零件后增量区域与全量重算逐像素差不超过 1 个量化级。
