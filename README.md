在全新工作区中，需要从零实现一个本地慢查询诊断与改写引擎，用于在确定性样本上复现从慢查询原始采样到按归一化模板聚合、生成执行计划画像，再到把画像并行生成任务在并发与内存预算约束下调度、并在中断后恢复续算的完整链路。本地样本给出三部分：SQLite 样本库（表、索引与固定数据，可由脚本确定性重建，作为画像估算的真值来源）；慢查询采样流（采样序号、采集逻辑时钟毫秒戳、SQL 文本、执行耗时毫秒、扫描行数、返回行数、命中索引描述）；统计快照（表行数、列 NDV、索引前缀选择性、快照版本号与生效逻辑时钟）。引擎需把同一归一化模板的采样聚合为画像任务，任务按并发上限与内存预算真实并行执行，结果必须与单线程逐模板串行估算逐字段一致，且任意时刻被强制终止后能依据持久化状态只重做未提交部分。

任务环境与准备：
安装 Python 3.11 或更高版本，创建虚拟环境并激活。
执行 pip install numpy 与 pip install pytest 安装依赖，标准库 sqlite3 与 hashlib 无需额外安装。
在项目目录下放置本地样本：SQLite 样本库重建脚本与固定数据、慢查询采样流 JSON、统计快照 JSON 与统计补丁样本，全部为本地产物，不依赖外部数据库或网络。
准备命令行入口脚本，确保可在 Windows 控制台直接运行 load、sample、plan、resume、status、verify 子命令。

业务要求：
1. 实现样本库摘要、慢查询采样流与统计快照的解析校验：采样序号严格递增且唯一、采集逻辑时钟为非负整数、SQL 文本可被归一化器解析且同文本多次归一化得到同一模板结构、耗时与扫描返回行数为非负整数、统计快照版本号递增且生效逻辑时钟非负，构建样本库表与索引的结构模型；非法输入必须返回明确业务错误码且不写入任何持久化状态。
2. 实现 SQL 到查询模板的确定性归一化与分组聚合：剥离字面量与 IN 列表长度差异得到稳定模板结构，模板标识由结构确定性计算；按模板聚合采样得到样本数、耗时分位数（固定排序与插值规则）、平均扫描行数与实测扫描返回值，聚合顺序固定，使同一采样流在任意运行次数下得到逐位一致的模板聚合结果。
3. 实现执行计划画像构建：对每个模板在样本库上枚举候选访问路径（全表扫描与可用索引），按当前统计快照估算行数与选择性，与实测扫描行数对比得出偏差比与偏差方向；画像结论须记录所依赖的统计快照版本号、候选路径、估算值、实测值与首个偏差来源，并与逐模板串行单线程估算逐字段一致。
4. 实现画像生成任务的并行调度与双预算裁决：把模板画像生成拆分为可并行任务，在每轮并发任务上限与内存预算双重约束下决定启动顺序，每个任务按候选路径数估算内存占用并与剩余预算比较；预算不足时必须显式放弃剩余任务并记录放弃原因，严格区分预算内未启动、启动后失败与主动放弃三类结局，已启动任务必须执行完毕而非事后标注超时。
5. 实现基于注入逻辑时钟的采样窗口切分与画像刷新节奏：窗口边界、统计快照生效判定与画像刷新时机只依赖注入的逻辑时钟毫秒值，不读取系统墙钟；每个采样唯一归属一个窗口且不得同时计入两个窗口，统计快照在生效时刻前不得影响画像，生效后新到达采样须归属新快照版本，同一逻辑时钟序列下重放得到逐位一致的窗口划分与绑定版本。
6. 实现并发上限与内存预算下的进度持久化与强制终止后的恢复续算：把已提交采样水位、窗口摘要、每模板聚合与画像结论、任务阶段与内存占用账目、统计快照指针与逻辑时钟水位以事务原子写入 SQLite；进程在任务执行或窗口提交中途被强制终止后，恢复路径须识别已提交任务与半提交状态，只重做未完成模板且不得重复计入已提交采样或重复占用内存预算。
7. 实现统计快照版本整体替换与失效闭包裁决：每次统计补丁提交产生新快照版本并以临时表加版本号整体替换当前指针而非逐条覆盖，需比较版本号、生效逻辑时钟、统计项摘要与覆盖表集合，判定完整替换、增量追加或无需操作并拒绝版本回退；沿“统计项—索引—模板—画像结论”的依赖关系计算受影响闭包，精确标记哪些模板画像与聚合需重算、哪些可安全复用，未受影响模板画像必须保持不变。
8. 实现多进程并发一致性、幂等提交与可重复命令行演示：允许多个采样处理实例、画像调度实例与统计补丁实例并行，通过 SQLite 事务与文件锁保证同一快照版本只提交一次、同一采样序号只被计入一次、同一模板同一快照版本的画像只提交一次，重复提交相同采样或相同补丁必须幂等，读取方只能看到完整已提交结果；提供 load、sample、plan、resume、status、verify 子命令，status 以稳定排序 JSON 输出画像任务阶段、内存占用、绑定快照版本与预算放弃记录。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
