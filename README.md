当前是空白工作区，没有现存项目、代码或数据附件，需要从零构建一个面向机器翻译流式解码的本地可视化与诊断工作台，核心业务问题是交互延迟与计算结果一致性。业务对象是本地确定性生成的双语翻译任务：源句由固定种子从受控词表拼装成 token 序列，配一份双语句对词表（含源词 token、目标词 token 与词级对齐表），目标端由确定性查表解码器按对齐关系与上下文窗口逐 step 产出 token。解码被建模为多阶段流水：源句编码（确定性哈希嵌入与位置加权池化）→按块预填目标端前缀缓存→逐块增量解码（每块内含若干 step，每 step 做注意力打分、与上一 step 的前缀缓存合并、采样）→整段重解码校验。用户以交互方式逐块请求译文，先请求首块以尽快看到前若干 token，再请求后续块。核心矛盾是：按块增量解码可显著降低首块可见延迟，但块边界处的前缀缓存键、注意力归一化统计量与块内位置偏移必须与整段解码采用同一口径，否则逐块拼接结果与一次性整段解码结果在 token 序列、置信度与对齐投影上出现漂移；同时修改源句、对齐表版本或块大小时只有依赖这些输入的目标端缓存应失效，其余必须复用。

任务环境与准备：
安装 Python 3.11 与 NumPy，确保可创建本地进程池与读写本地临时目录；无需网络与 GPU。
在空白工作区创建项目目录，准备本地确定性样本生成脚本（源句 token 序列、双语句对词表、词级对齐表、固定种子），不引用任何外部数据或账号。
准备业务码约定与 JSON 输出字段清单，确认 Windows 下进程退出码为整数、E_xxx 业务码以 JSON 或 stderr 承载。

业务要求：
1. 实现确定性的源句编码与逐 step 目标端解码核心：源词按固定种子的确定性嵌入与位置加权池化得到编码向量，每个 step 依据词级对齐表与上下文窗口对候选目标词打分、做归一化并取最高分（同分按目标词 token 字典序裁决），产出目标 token、置信度与对齐投影；同一源句、同一配置与同一种子下各阶段中间量与最终译文必须逐字节一致，禁止依赖系统时间或字典遍历顺序。
2. 实现按块增量解码与块边界口径统一：目标端按可配置块大小切块，每块内复用上一块已算出的前缀缓存并增量解码，块内位置偏移与注意力归一化统计量必须与整段解码完全同口径；逐块拼接得到的 token 序列、置信度与对齐投影须与一次性整段解码逐项相同，检测到漂移返回 E_CHUNK_MISMATCH 并输出首个偏差 step 与偏差字段。
3. 实现首块可见延迟预算控制：首块可见延迟以本地解码循环的实际处理计时作为观测，并按块内 step 数、候选打分次数与前缀缓存规模给出估算记录；超预算时返回 E_LATENCY_BUDGET 并附带已完成阶段与已解码 step 数，禁止以无实际工作的等待或占位返回冒充低延迟；整段解码路径与分块路径须各自记录观测计时，不可混用。
4. 实现交互式按块查询与整段结果的一致性保证：对外提供查询已就绪块、单块内逐 step 候选与置信度的接口；查询返回的每块 token 序列、置信度与对齐投影必须与整段解码结果中对应区间的记录在声明精度内一致，并校验参与解码的源句版本与对齐表版本完全相同；检测到偏差返回 E_INCONSISTENT 并指出块号与不一致类别。
5. 实现目标端前缀缓存与依赖失效传播：缓存键须纳入源句编码摘要、词级对齐表版本、块大小、上下文窗口与上游节点哈希；修改源句中未被任何目标词对齐引用的词、替换对齐表版本或调整块大小时，计算受影响的前缀缓存条目与需重算的 step 集合，复用未受影响缓存仅重算受影响后缀；须输出本次重算集合与复用集合，并保证局部修改前后的可复用部分逐字节相同。
6. 实现缓存与配置快照的版本化及整体替换：词表、对齐表、块大小与解码参数快照各携带单调递增版本号与内容校验和，检测到版本号或校验和变化时必须整体替换旧快照而非增量修补，旧版本不得覆盖新版本且回退尝试返回 E_SNAPSHOT_ROLLBACK；损坏或校验和不符的条目在读取时返回 E_CACHE_CORRUPT 并指明条目键与版本号。
7. 实现并发预览请求与资源上限控制：多个块预览请求可并发执行，同一时刻只允许一个分块计划提交生效，并发提交冲突时后到者立即获得 E_STAGE_BUSY 而不阻塞等待；为单句最大 token 数、前缀缓存条目总量与单块驻留内存估算设可配置上限，超限时返回 E_RESOURCE_LIMIT 或按明确策略降级到更小块并标记降级类别，降级不得改变已输出块的字节内容。
8. 实现输入与配置校验链路及跨模块一致性自检：重复 case_id、源句 token 不在受控词表、对齐表引用不存在的目标词、块大小非正、上下文窗口越界分别返回对应业务码（E_DUP_CASE、E_TOKEN_UNKNOWN、E_ALIGN_INVALID、E_CONFIG_INVALID）并指明字段；自检校验缓存键与产物哈希互相可核对、复用集合与重算集合无交集且并集覆盖全部受影响 step、逐块译文可由缓存明细重放出；并提供本地可视化诊断工作台展示块就绪进度、首块观测计时、块大小选取、快照版本、失效传播范围与最近业务错误码。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
