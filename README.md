在游戏角色动画与动捕后期场景中，需要从零开发一个本地桌面工作台：把一段带噪声与缺失帧的骨骼动捕序列推演为满足每帧姿态约束（关节角度上下限、末端IK目标、骨骼长度保持、地面接触）的姿态，并支持在时间轴上拖动预览时保持交互延迟与计算结果一致。输入为程序按确定性规则生成的本地样本：骨架层级定义（骨骼名、父骨、静止位姿、骨段长度）、原始动捕曲线（每骨每帧四元数，含确定性缺失帧）、约束集（角度限值、末端目标轨迹、接触帧标记）与推演参数（迭代上限、阻尼系数、约束容差、帧分块大小、并发上限、内存预算），输出为约束后姿态序列、逐帧约束残差报告与可交互预览。难点在于：交互拖动时必须立即显示已求解帧的结果，而异步补算不得让已展示的帧结果发生跳变；同时约束求解是有状态的迭代过程，中断后恢复必须与一次连续求解逐帧一致。

任务环境与准备：
Windows 本地环境，Python 3.11 及以上，安装 numpy 与 PySide6（pip install numpy PySide6），不依赖 GPU 或外部数据。
提供样本生成脚本，按确定性规则生成骨架定义、原始动捕曲线、约束集与参数 JSON，样本包含缺失帧与未收敛帧；运行工作台的命令写在项目入口说明中。
无容器环境；界面测试使用本地窗口截图与状态导出核对，后台补算与恢复通过命令行入口验证。

业务要求：
1. 实现骨架、动捕曲线与约束集解析：校验骨骼名唯一且父骨可拓扑排序无环、骨段长度为有限正数、原始曲线各骨帧数一致且四元数为有限数（非单位四元数归一化并记录归一化次数）、约束角度限值满足下限不超上限、末端目标帧索引不越界，非法输入返回带 E_xxx 业务码的 JSON 错误且不产生任何姿态输出
2. 实现缺失帧的确定性补齐与帧时间轴：按骨架层级在缺失区间两端做球面线性插值补齐，根骨缺失时按规格规定的静止位姿兜底，补齐后每帧时间戳与帧索引严格对应且总帧数不变，补齐帧须在报告中计数并标注区间，补齐结果只依赖输入内容与帧索引而不依赖处理顺序
3. 实现多约束迭代求解与残差账本：对每帧按约束声明顺序迭代求解角度限值投影、末端IK、骨长保持与地面接触，迭代上限与阻尼系数须同时生效，逐约束记录每帧残差并与规格容差比较给出通过或未收敛结论，未收敛帧附最后一次迭代的残差明细，求解顺序与迭代次数须在报告中可追溯
4. 实现预览拖动与求解结果的延迟一致性：时间轴拖动或逐帧步进时界面只读取已持久化或已完成帧的结果并立即展示，未完成帧以确定的占位状态显示而不阻塞界面响应；后台补算完成后不得改变用户已查看帧的结果，仅在补算帧变为可展示时刷新，已展示与补算完成后的同一帧姿态须逐字段一致
5. 实现可处理终止与中断恢复：外部可处理的终止信号只在帧分块边界生效，写入中断标记并以约定整数退出码退出，未完成分块不得留下可被误认为已求解的帧结果；再次启动时校验由骨架、原始曲线、约束集与参数规范化摘要构成的版本标识，一致则从最近已完成分块续算，不一致则从头重做，强制终止后仅依据已持久化状态恢复
6. 实现分块级持久化与摘要校验：每完成一个帧分块即把该块姿态、逐帧残差与该块内容摘要原子写入状态目录，先写临时文件再整体替换；续算与最终拼装前逐块比对摘要，不匹配、缺失或声明帧数不符时返回 E_DIGEST 并把该块标记失效回退重算，禁止静默使用失效块
7. 实现并发补算与资源上限：按参数中的并发上限使用有界线程池调度帧分块，同时处于求解中的帧姿态与迭代缓冲总量受内存预算约束，超出时按帧块索引序让后续块等待而非降低迭代上限或约束精度；某块异常时取消其余待处理块并返回首个错误，最终姿态序列与串行逐帧求解在容差内一致
8. 实现约束残差报告与姿态导出原子写出：输出 JSON 报告含总帧数、补齐帧区间数、通过帧数、未收敛帧及其残差明细、每约束的通过率，导出姿态序列时读取已有输出的帧数与版本标识并在版本不同时整体替换，报告与姿态导出要么同时更新要么都保持旧版本
