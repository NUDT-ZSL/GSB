交付从新建的代码库开始，需要从零构建一个面向纹理与材质生成场景的本地可交互专业应用与可重复演示。业务对象是本地确定性生成的多材质样本：每个材质由固定种子给出基础色、粗糙度场、法线细节与可配置的噪声参数，纹理生成链路为参数校验→多倍频噪声场合成→材质通道映射→按可配置分块网格切片生成→边界接缝归一化与整体拼接。用户以交互方式先预览一个切片再请求其余切片，切片级缓存让预览很快，但切片边界处的噪声相位、通道归一化与接缝权重必须与整幅生成完全同口径，否则拼接结果与整幅结果不一致。同时参数以修订版本持续到达，需要精确判定哪些切片失效并只重算受影响后缀。

任务环境与准备：
安装 Python 3.11 与 NumPy（pip install numpy），无需显卡、外部服务或网络数据。
在新建工作区创建项目目录并准备本地确定性样本生成脚本，样本与配置均由固定种子产出。
确认 Windows 下本地缓存目录可写，并验证命令行演示入口可完整跑通一次基线运行。

业务要求：
1. 实现确定性的纹理生成流水线：参数校验、多倍频噪声场合成、材质通道映射、分块切片生成、边界接缝归一化与整体拼接五个阶段依次串联，噪声相位与倍频权重由参数与种子显式确定；同一材质、同一种子与同一配置下必须逐字节产出相同的噪声场、通道值与整幅纹理，禁止依赖系统时间或未声明的全局随机状态。
2. 实现按分块网格的切片生成与切片就绪查询接口：能查询单块切片的像素区间与内容摘要，并在整幅生成完成前返回部分结果；首块可查询耗时以本地生成循环的实际处理计时作为观测，并按块内像素数、倍频数与接缝邻域规模给出估算记录，超预算时返回 E_LATENCY_BUDGET 并附带已完成块清单。
3. 实现切片拼接结果与整幅一次性生成结果的逐字节一致性裁决：块边界处的噪声相位、通道归一化统计与接缝羽化权重必须与整幅口径采用同一来源与同一归一化，逐块拼接与整幅逐像素相同；检测到差异返回 E_BLOCK_MISMATCH 并输出首个偏差像素坐标、切片编号与偏差谱。
4. 实现切片与参数的版本化快照及整体替换：参数快照、分块计划与已就绪切片清单各携带单调递增版本号与内容校验和，提交时整体替换旧快照而非增量修补；重启加载时识别版本号或校验和变化并整体替换，旧版本不得覆盖新版本，回退尝试返回 E_SNAPSHOT_ROLLBACK，损坏或校验和不符返回 E_SNAPSHOT_CORRUPT。
5. 实现按内容寻址的切片缓存与参数修订后的定向失效传播：每块切片与接缝归一化产物附带内容哈希落盘，缓存键须纳入参数摘要、种子、分块网格、倍频配置与上游产物哈希；某材质参数以更高修订到达或分块网格变化时计算受影响切片集合，复用未受影响切片仅重算受影响后缀，并输出重算与复用清单。
6. 实现参数修订下的过期结果拒绝与追溯重放：每块已就绪切片须记录所用缓存键、参数修订版本与节点路径，可按记录重放出相同像素与摘要；当缓存键所依赖的任一版本已变化而切片仍来自旧键时返回 E_STALE_SLICE 并指出材质标识、切片编号与过期版本，禁止把过期切片拼接进整幅结果。
7. 实现并发预览请求与提交的资源上限控制：多个切片预览可并发执行，同一时刻只允许一个分块计划提交生效，并发冲突时后到者立即获得 E_STAGE_BUSY 而不阻塞等待；为单材质像素总量、单块驻留内存估算与并行生成切片数设可配置上限，超限返回 E_RESOURCE_LIMIT 或降级为逐块流式生成并标记降级类别。
8. 提供本地可交互专业应用与可重复演示，并实现跨模块一致性自检：展示生成阶段、切片就绪进度、首块实际观测耗时、分块网格与裁决依据、快照版本、一致性校验结论与最近业务错误码；自检校验切片与整幅像素集合一致、缓存键与切片摘要可互相核对、重算与复用切片无交集且并集覆盖全部受影响切片。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本验证首块延迟观测、分块拼接与整幅一致性、增量重算集合与快照整体替换。
