博物馆数字展项的配音师刚录完一批文物讲解音频，三维动画制作员要据此驱动虚拟讲解员的面部动画。麻烦在于：同一段讲解同时以三个工程版本交付，音素标签集、时间基准（毫秒与帧序号）与唇形通道命名各不相同；而语种音素集与唇形可见口型并非一一对应，闭唇音紧邻元音、语速骤变和情绪标签冲突时，直接逐音素映射会造成口型跳变、闭唇音张冠李戴、表情微动与重音错位。换版后同步口径又容易漂移，团队急需一套可逐句核对、跨版本归一的面部动画生成机制，并导出能嵌入展项播放器的通道关键帧文件。

任务环境与准备：
准备 Linux（WSL Ubuntu） 上的 Python 3 运行环境，并安装运行所需的 NumPy 第三方包。
以仓库内确定性生成器按固定种子产出三版本讲解音频、音素时间真值与面部绑定参数样本，无需真实录音或外部服务。
在项目根目录提供命令行入口，通过 argparse 接收版本目录、目标帧率、超阈值与输出路径参数，运行为单进程本地执行。

业务要求：
1. 读取三个工程版本的音素标注与面部绑定参数，建立统一音素时间轴与唇形通道模型，将各版本音素标签、毫秒与帧序号两种时间基准、各版本通道命名归一为同一内部表示，并保证同一音素在三版本下映射到相同可见口型目标。
2. 按归一音素时间轴为每个音素确定下颌开合、唇形宽度、唇角的目标值，生成音素到可见口型的映射表，闭唇音必须映射为零开合目标，同一音素类别在各版本映射结果一致。
3. 以协同发音权重在相邻口型目标间做时间平滑插值，权重与音素时长、间隔相关，使音素边界处通道曲线连续无跳变，并输出逐帧平滑后的通道参数曲线。
4. 按情绪标签以包络方式调制眉部与唇角通道微动，使表情变化与语音重音时刻对齐；当情绪标签与重音位置冲突时按预定优先规则裁决并在差异清单中记录。
5. 按目标帧率对通道曲线重采样并生成口型关键帧序列，同时输出逐句同步账目，包含每句起止帧、口型目标数与最大偏差，供制作员逐句核对。
6. 同一段讲解在三工程版本归一后产出相同的面部通道曲线与关键帧序列，输出跨版本差异清单并标记偏差位置，差异清单内容需可被复现核对。
7. 以独立口型目标参考计算和音素时间真值逐句逐帧核对通道参数与同步偏差，报告首个超阈值的句子及其音素依据，阈值可由命令行参数注入。
8. 导出可被展项播放器直接使用的通道关键帧文件，格式固定并与内部通道曲线逐帧一致；对缺失音素、时间重叠、采样率不符等异常输入给出可定位的错误码并终止，不得静默产出错误片段。

验收：
用三版本同一讲解样本与闭唇音紧邻元音、语速骤变、情绪冲突样本核对归一映射、平滑曲线、逐句账目与跨版本一致性，并验证导出关键帧与内部曲线逐帧一致。
