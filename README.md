当前是空白工作区，没有现存项目、代码或数据附件，需要从零构建一个面向视频预测与运动时序建模的可集成领域组件与完整示例。业务对象是本地确定性生成的视频预测任务：每段序列由固定种子驱动若干目标做可复现运动（匀速、匀加速与周期性轨迹），逐帧生成固定尺寸画布与稀疏运动掩码，序列清单为 JSONL，字段含 clip_id、frame_count、frame_interval_ms、object_count、motion_mode、seed、temporal_policy、model_revision，并附逐帧真值框与运动掩码摘要。组件需把一次视频预测建模为多阶段时序流水：帧对采样与时间轴展开→运动编码（位移估计与目标轨迹特征）→时序聚合（按历史窗口递归外推）→遮挡与掩码处理→逐帧预测框与运动掩码输出→时序质量评估。核心业务问题是可复现验证与异常注入：预测的每一帧结果必须能追溯到所用的时序窗口与历史状态，任何一帧的观测缺失、时间戳倒挂或运动突变都必须在时序链路上被精确定位，且注入异常后仍给出可复现的归因结论。

任务环境与准备：
安装 Python 3.10 及以上与 NumPy、pytest，建议在 Windows 本地虚拟环境中安装，不引入其他第三方依赖。
确认工作区为空目录，样本与真值均由组件内置固定种子在运行时确定性生成，不下载任何外部数据集或模型权重。
准备本地命令行入口的调用方式说明（如 python -m 模块名 或脚本路径），以便演示一次正常运行、一次注入异常运行与一次强制终止后恢复运行。
确认可写入本地缓存与检查点目录，并预留足够磁盘空间存放阶段快照与逐帧报告；中断演示通过操作系统强制终止进程模拟。

业务要求：
1. 实现确定性帧对采样与时间轴展开阶段：按 temporal_policy 与 frame_interval_ms 把帧序列展开为帧对与相对时间步，同分或同间隔时按 frame_index 升序打破平局，并对时间戳倒挂、帧间隔与 frame_count 不符分别返回 E_TIME_ORDER 与 E_TIME_SPAN 并指明 clip_id 与帧位置；同一 clip_id、同一 seed 与同一配置下必须逐字节产出相同的帧对集合与时间轴记录。
2. 实现运动编码阶段：由帧对像素与稀疏运动掩码做确定性位移估计，并为每个目标生成轨迹特征（位移向量、速度、加速度与外推置信度），occluded 目标不得参与速度估计但须保留占位并标记；同一输入与配置下位移、轨迹特征与置信度逐字节可复现，目标数超出 object_count 时返回 E_OBJECT_OVERFLOW 并指明 clip_id 与帧位置。
3. 实现带历史窗口的递归时序聚合阶段：按配置的窗口长度与衰减系数逐帧外推预测框与运动掩码，外推状态须显式携带历史摘要哈希；窗口长度越界或衰减系数非正分别返回 E_WINDOW_INVALID 与 E_DECAY_INVALID；同一历史摘要与同一参数下外推结果必须逐字节一致，禁止依赖除固定种子与显式配置外的任何外部状态。
4. 实现观测缺失与运动突变在时序链路上的定位：对每一缺失帧或加速度突变帧，输出发生位置、受影响目标集合、所用历史窗口摘要与偏差量，并区分“观测缺失外推”与“运动突变失配”两类归因；归因类别不在受控集合或缺帧位置无法定位时返回 E_ATTRIBUTION_FAIL 并保留已定位位置清单。
5. 实现多阶段检查点与强制终止后的恢复：采样、编码、时序聚合、输出四阶段各产生带单调递增版本号与内容校验和的检查点，只有该阶段全部帧完成才提交；重启时从最后已提交阶段继续，已提交帧不得重算，未提交的递归中间状态必须丢弃并从该阶段起点重建，恢复后的逐帧预测与不间断完整运行逐字节一致。
6. 实现快照版本变化与整体替换防护：模型参数快照、temporal_policy 与历史状态快照各携带版本号与内容校验和，检测到任一版本号或校验和变化时必须整体替换旧快照而非增量修补，旧版本不得覆盖新版本且回退尝试返回 E_SNAPSHOT_ROLLBACK；损坏或校验和不符返回 E_SNAPSHOT_CORRUPT 并指明快照类别与版本号。
7. 实现四阶段异常注入框架并区分可处理信号与强制终止：在采样、编码、聚合、输出阶段分别提供由输入或参数触发的注入点（如时间戳倒挂、掩码尺寸不符、窗口全零、外推越界），注入不得通过修改源码制造，每次注入须产生带阶段名、业务码、clip_id 与帧位置的记录；对可处理的停止信号须在帧边界优雅退出并写出已提交检查点，对强制终止不承诺生成退出报告，恢复只依赖已持久化的检查点。
8. 实现时序质量评估、资源上限与跨模块一致性自检：由逐帧预测与真值框计算位移误差、轨迹命中率与时间一致性指标，指标须可由逐帧明细独立重算一致；为单序列帧数、同时驻留的历史窗口数与并行序列数设可配置上限，超限返回 E_RESOURCE_LIMIT 或按明确策略降级并标记降级类别；自检校验各阶段 clip_id 与帧索引集合完全一致、复用集合与重算集合无交集且并集覆盖受影响帧，不一致返回 E_INCONSISTENT 并指出类别。另需提供可集成的组件接口与完整示例：暴露采样、运动编码、时序聚合、归因诊断与验证入口，命令行读取本地确定性样本输出含逐帧预测、归因记录、注入记录、指标、业务码与降级标记的 JSON 报告，并附一次注入异常与一次强制终止后恢复的演示。
