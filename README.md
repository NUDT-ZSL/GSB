当前是空白工作区，没有现存项目、代码或数据附件，需要从零构建一套面向跨模态图文对齐与检索的本地数据处理管线与结果验证工具，核心业务问题是索引的增量更新与依赖失效。业务对象是本地确定性生成的图文对样本：每对由固定种子生成固定尺寸 RGB 像素数组（经确定性分块均值与固定投影得到图像嵌入）与一段由受控词表拼装的文本（经确定性词频加权池化得到文本嵌入），样本清单为 JSONL，字段含 pair_id、image_seed、image_shape、text、text_lang、caption_revision、embed_dim、modality_mask。对齐与检索链路被建模为有向无环计算图：图像编码、文本编码、跨模态对齐投影、检索索引构建（含分块量化码本）与检索打分（top-k）共五级节点。用户会不断修改单对的文本描述、替换某对的图像种子、调整对齐投影参数或升级量化码本版本，此时只有真正依赖这些输入的下游节点与索引分块需要重算，其余必须复用旧快照；同时每条检索结果必须能追溯其当时所用的缓存键与词表版本，旧版本检索结果不得被新快照混用。

任务环境与准备：
安装 Python 3.11 与 NumPy（版本固定在同一 requirements 文件中），确认本地可创建缓存目录与临时目录。
准备本地确定性样本与词表配置：由固定种子生成图文对清单、受控词表、量化码本初始版本与对齐投影参数，全部为本地文件，不访问网络。
确认可用本地进程池与本地文件持久化，验证运行环境为 Windows；准备一份注入异常输入的样本副本用于演示。
准备运行与查看 JSON 报告的本地工具，报告中包含重算与复用集合、追溯重放记录与验证结论。

业务要求：
1. 实现确定性五级计算图：把图像编码、文本编码、对齐投影、检索索引构建、检索打分建成有向无环图，节点连接与量化码本分块由配置字典决定；同一输入、同一配置与固定种子必须逐字节产出相同的中间嵌入、索引码字与 top-k 结果，禁止依赖系统时间、字典插入顺序或任何未声明外部状态。
2. 实现内容寻址缓存与缓存键构造：每级产物附带内容哈希写入本地内容寻址目录，缓存键须纳入该节点全部输入摘要、上游产物哈希、量化码本版本与节点参数；键相同必须复用快照、键不同必须重算，且必须提供入口可按给定键枚举其组成项，供诊断与追溯核对。
3. 实现增量更新的依赖失效传播：修改单对文本描述、替换某对图像种子、调整对齐投影参数或升级量化码本版本时，计算受影响节点与受影响 pair_id 集合，复用未受影响上游快照，仅重算受影响后缀；须输出本次重算节点清单与复用节点清单，并保证局部修改后的检索结果与从零全量重建的对应结果逐字节一致。
4. 实现检索结果追溯与过期结果拒绝：每条检索命中须记录其来源节点路径、所用缓存键、词表与码本版本；可按命中反查并用这些记录重放出相同分数与相同排序；当缓存键任一依赖版本已变化而结果仍来自旧键时返回 E_LINEAGE_BROKEN，禁止把旧版本命中混入新快照结果。
5. 实现量化码本版本演进与索引分块整体替换：码本携带单调递增版本号与内容校验和，检测到版本号或校验和变化时必须整体替换旧快照而非增量修补；须识别哪些索引分块因码本变化受影响，未受影响分块直接复用，且替换后 top-k 必须能由分块码字与残差独立复算一致，不一致返回 E_INCONSISTENT 并指出分块编号与版本号。
6. 实现并发提交控制与资源上限：同一时刻只允许一次增量提交生效，并发提交冲突时后到者立即获得 E_STAGE_BUSY 而不阻塞等待，已完成版本不得被旧版本回退覆盖（回退尝试返回 E_SNAPSHOT_ROLLBACK）；为单次重算 pair 数、码本分块驻留内存估算与缓存条目总量设可配置上限，超限时返回 E_RESOURCE_LIMIT 或降级并在结果中标记降级类别。
7. 实现输入与配置校验链路：重复 pair_id、image_seed 与 image_shape 不匹配、text 为空、modality_mask 取值非法、embed_dim 非正、码本版本回退分别返回对应业务码（E_DUP_PAIR、E_SEED_SHAPE_MISMATCH、E_TEXT_EMPTY、E_MASK_INVALID、E_CONFIG_INVALID、E_SNAPSHOT_ROLLBACK）并指明字段与 pair_id，异常须沿链路归因到具体阶段。
8. 提供结果验证工具与跨模块一致性自检：独立复核计算图拓扑无环、缓存键与产物哈希互相可核对、重算集合与复用集合无交集且并集覆盖全部受影响集合、每条检索命中恰出现一次、top-k 分数顺序合法且可由索引码字与残差重算一致；检测到偏差返回 E_VERIFY_FAIL 并输出首个偏差位置与不一致类别。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地确定性样本跑全量与增量两次构建，核对重算集合、检索结果一致性与追溯重放结果及异常码。
