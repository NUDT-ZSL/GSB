团队准备新建一个项目，用于 LLM 推理采样与解码策略的本地可视化与诊断工作台，核心业务问题是在批量解码请求持续到达时的并行调度与资源预算裁决。业务对象是本地确定性生成的推理任务清单（JSONL，字段含 request_id、prompt_tokens、sampling_params、target_len、seed、priority），logits 序列与词表映射由固定种子驱动 NumPy 生成，不依赖真实模型、外部服务或缺失数据集。系统把一次批量解码建模为多级流水：请求分块采样、温度缩放与 top-k/top-p 截断、确定性随机数序列驱动的 token 抽取、批次调度与预算裁决、结果汇总。所有耗时观测以本地解码循环的实际处理计时为准，所有预算以显式声明的乘加或比较次数估算为准；吞吐与内存指标须与本地样本规模、单进程多 worker 的测量方式相容。

任务环境与准备：
安装 Python 3.11 与 NumPy（pip install numpy），仅使用标准库与 NumPy，无需外部服务或真实模型
在空工作区创建项目，由固定种子确定性生成推理任务清单与 logits、词表样本，样本随项目生成脚本产出
准备本地临时目录用于检查点、快照与缓存落盘，确认单进程多 worker 的本地进程池可正常创建

业务要求：
1. 实现确定性的逐 step 采样核心：按请求的采样参数完成温度缩放、top-k 与 top-p 截断，再用显式声明种子驱动的确定性随机数序列逐 step 抽取 token；同一请求、同一参数与同一 seed 下必须逐字节产出相同 token 序列与逐 step 候选截断明细，同分候选按 token 编号升序打破平局，且禁止依赖系统时间、全局随机状态或浮点微弱差异。
2. 实现批次分块调度层：按可配置并发槽位与每批请求数把请求分组分派到本地进程池，块边界、派发顺序与归并顺序必须确定性可复现；每个请求的 token 序列必须与单独执行结果逐字节一致，检测到差异返回 E_BATCH_INCONSISTENT 并指出 request_id 与首个偏差 step。
3. 实现总采样步数预算、驻留 KV 缓存条目数与并发槽位三重准入裁决：按请求优先级、目标生成长度与缓存规模在预算内决定准入集合与执行顺序；超限请求分别返回 E_STEP_BUDGET、E_KV_BUDGET、E_SLOT_BUDGET 并记录被拒原因与各预算余量，被拒请求不得出现在任何采样摘要中。
4. 实现预算冲突的显式取舍裁决：当扩大并发槽位缩短整体完成时间但逼近驻留缓存上限、延长目标生成长度提升质量但放大采样步数预算、收紧 top-p 减少候选但可能淘汰应保留 token 时，须按配置声明的优先级顺序在进度、内存与采样质量之间裁决，并在调度报告中记录仲裁依据、被降级请求及降级类别。
5. 实现采样产物、预算账本与逐请求决策记录的版本化快照及整体替换：三者各携带单调递增版本号与内容校验和，检测到版本号或校验和变化时必须整体替换旧快照而非增量修补，旧版本不得覆盖新版本，回退尝试返回 E_SNAPSHOT_ROLLBACK，损坏或校验和不符返回 E_SNAPSHOT_CORRUPT 并指明快照类型与版本号。
6. 实现强制终止后的恢复逻辑：执行器在请求边界提交检查点，重启时读取最近一次已提交检查点并从记录的下一请求继续，已提交请求的 token 序列与已消费预算不得重算或重复计入；未提交的中间采样状态必须丢弃并从该请求起点重建；恢复后的完整结果须与不间断完整运行逐字节一致，且只承诺基于已提交检查点的恢复，不承诺强制终止时一定生成退出报告。
7. 实现输入与配置校验链路并沿异常链路归因：重复 request_id、采样参数越界、target_len 非正、seed 不可解析、词表缺失或版本缺失分别返回 E_DUP_REQUEST、E_SAMPLING_INVALID、E_LENGTH_INVALID、E_SEED_INVALID、E_VOCAB_MISSING 并指明字段与 request_id；单个请求失败不得静默丢弃或污染其他请求结果，且须归因到具体阶段。
8. 实现本地可交互诊断工作台并以独立复算完成跨模块一致性自检：展示请求列表、采样参数、逐 step 候选截断与抽取结果、预算账本余量、调度决策依据、恢复报告与最近业务错误码；自检须用参数与 seed 独立复算逐请求结果、核对各阶段 request_id 集合一致，并校验被拒与被降级记录与实际执行一致，不一致返回 E_INCONSISTENT。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地确定性样本验证并行采样与单请求结果逐字节一致、预算裁决与强制终止恢复正确，并产出诊断报告。
