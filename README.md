当前是空白工作区，没有现存项目、代码或数据附件，需要从零构建一个面向依存句法分析结果交换的本地可集成组件与完整示例，核心业务问题是依存弧选择结果在三种并存书写形式下的格式互操作与版本迁移裁决。业务对象是本地确定性生成的依存标注样本：原始句子清单为 JSONL，每行含 sent_id、tokens 列表（每个 token 含 id、word、pos、head_gold、deprel_gold），并附一份受控词性标签集合与依存关系受控集合。同一份弧选择结果需要以三种版本格式持久化并互相转换：v1 为无字段名的竖线分列行式（每行三段：token_id|head|deprel，不含虚拟根标记与置信区间，head 用 0 表示虚拟根）；v2 为带字段名的行式（每行含 token_id、head、deprel、confidence_low、confidence_high，且显式声明整句根标记）；v3 为结构化嵌套格式（含双向弧链声明、每弧置信区间、正逆向 dependency 校验标记与跨句引用字段）。组件需完成三种格式的读取、迁移、跨格式语义等价裁决与往返一致性校验，并保证迁移过程中的信息丢弃或补全可审计。

任务环境与准备：
安装 Python 3.11 与 NumPy（pip install numpy），确认可在 Windows 下运行本地文件读写与 JSON 解析。
创建工作区目录结构与本地确定性样本生成脚本，依存标注样本、受控集合与迁移策略均由固定种子生成，不依赖外部服务或网络。
准备演示入口所需的三种格式样本与注入参数文件，用于触发格式化异常、语义漂移与快照损坏等异常输入。

业务要求：
1. 实现 v1、v2、v3 三种依存弧结果格式的读取器，按格式头或字段集分派解析路径；未知格式版本返回 E_VERSION_UNSUPPORTED，格式头截断、竖线字段数不符、必填字段缺失或数值不可解析返回 E_FORMAT_CORRUPT，并指出出错行号与字段名。
2. 实现三套格式的双向迁移器，把任意格式规范化为统一的内部弧图表示：v1 升级到 v2 或 v3 时补全根标记、置信区间与正逆向校验标记并逐项记录补全来源；v3 降级到 v1 时对 v1 无法表达的双向弧链与跨句引用按显式声明的丢弃规则处理并输出丢弃明细；迁移不得改变 token 与 head 的指向关系。
3. 实现受控集合与根约束的语义校验层：每条弧的 deprel 必须属于所加载版本的受控依存关系集合，head 取值必须在句内 token 编号集合或虚拟根标记之内，整句恰好一个根且不得产生环；违反分别返回 E_DEPREL_INVALID、E_HEAD_RANGE、E_ROOT_VIOLATION、E_CYCLE_DETECTED，并定位到 sent_id 与 token_id。
4. 实现跨格式语义等价裁决：同一句弧选择结果以 v1、v2、v3 三种形式书写时，读取与迁移后必须产出相同弧集合、相同根标记与相同 deprel；当 v1 表达能力不足导致语义无法完全还原时返回 E_SEMANTIC_DRIFT 并列出无法还原的字段与涉及的 token，禁止静默按默认值补全后声称等价。
5. 实现格式往返的弧级一致性校验：任一格式样本经完整往返后，在 token 编号、head 指向与 deprel 上必须逐 token 相同，v2 与 v3 往返还需校验置信区间与正逆向校验标记在声明精度内一致；不一致返回 E_ROUNDTRIP_MISMATCH 并输出首个偏差 token 与偏差字段。
6. 实现受控集合与迁移策略配置的版本化管理及整体替换：受控词性集合、受控依存关系集合与迁移策略各携带单调递增版本号与内容校验和，加载时检测到版本号或校验和变化必须整体替换旧快照而非增量修补；受控集合收缩导致已有弧不再合法时返回 E_LABEL_RETIRED 并给出每个受影响 sent_id 与 token_id；损坏快照返回 E_SNAPSHOT_CORRUPT。
7. 实现配置与输入校验链路及资源上限：重复 sent_id、token id 非连续、pos 标签不在受控集合内、弧图节点数或单句 token 数超出可配置上限分别返回 E_DUP_SENT、E_TOKEN_SEQ、E_POS_INVALID、E_RESOURCE_LIMIT，并指明字段与定位；超限时按明确策略降级为逐句流式迁移并标记降级类别，且降级不得改变已输出句的弧图内容。
8. 提供可集成的领域组件接口与完整示例，并实现跨模块一致性自检：暴露格式加载、双向迁移、等价裁决与往返校验四个入口；自检校验迁移补全与丢弃记录可重放出同一弧图、三种格式视图下同一 sent_id 的弧集合可互相核对、受控集合版本与迁移策略版本可追溯；检测到不一致返回 E_INCONSISTENT 并指出不一致类别、sent_id 与格式版本。
