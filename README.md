在空白工作区构建一个面向表格数据的特征交叉组合与降维实验工作台，用于在数据规模连续变化时诊断不同算法组合的取舍。输入为本地 YAML 实验配置与按固定种子生成的合成表格数据描述：包含数值列、低基数类别列、高基数类别列、缺失值与冗余列，样本量、特征数与类别基数均可从配置放大到多档规模。工作台需完成类别特征交叉组合（组合阶数可配置）、组合后特征的确定性编码、若干降维方法（主成分分析、截断随机投影与基于方差的特征筛选）与下游确定性评估，并在同一配置下支持多档数据规模重复试验，输出可比较的诊断结果。核心挑战在于数据规模变化与算法取舍：交叉组合的基数随规模与阶数迅速膨胀，高基数交叉必须受预算约束并给出可审计的降级决策；降维方法在小样本与大特征、高基数交叉与方差筛选之间各有利弊，工作台必须依据规模选择处理路径并记录取舍依据，同时保证同一最终输入下增量复用与全量重算的结果完全一致。

任务环境与准备：
安装 Python 3.11 及 NumPy、scikit-learn、PyYAML，版本以本地已安装为准，无需联网下载额外数据
准备本地合成数据描述与实验配置样例，覆盖小样本大特征、中等规模与高基数交叉三类规模档
确认工作区为空目录，运行目录具备临时文件写入与原子替换所需的本地文件系统权限
准备一份包含规模切换、组合阶数调整、基数预算变更与降维方法切换的编辑序列样例，用于一致性比对

业务要求：
1. 实现数据与配置加载层：读取本地 YAML 配置，按列描述与固定种子确定性生成表格数据，支持样本量、特征数与类别基数多档放大；对未知列、类型不符、目标列缺失、种子或规模非法输出 E_CONFIG_INVALID 并进入失败清单，合法配置须输出由配置规范化派生的配置指纹用于后续快照校验。
2. 实现类别特征交叉组合器：按配置的组合阶数与参与列白名单枚举列组合，对每个组合计算确定性哈希编码后的交叉特征，并统计其唯一取值数；当组合后唯一取值数超过配置的基数预算时按可配置策略降级（哈希桶截断或跳过该组合），降级决策须记录组合列、原始基数、最终基数与所命中策略以供审计。
3. 实现多方法降维组件：提供主成分分析、截断随机投影与方差筛选三种降维路径，随机投影的投影矩阵由配置指纹派生的固定种子生成，主成分符号须按确定性规则归一；每种方法输出保留维度、各维解释方差或投影摘要，并在输入含常量列或缺失值未填充时给出明确业务码而非静默产生非数值结果。
4. 实现规模自适应策略选择器：依据样本量、编码后总特征数、交叉组合基数预算占用率与小样本比例，从预置策略表中选择降维路径与交叉阶数上限，输出可审计的决策记录，包含所参考的规模指标、候选策略评分与最终选择理由；同一配置指纹与同一规模档必须得到完全相同的决策记录。
5. 实现增量复用与失效判定：为交叉组合、编码、降维与评估各阶段产物计算由上游内容指纹与参数指纹派生的缓存键；当样本规模档、组合阶数、基数预算或降维参数变更时，仅使受影响阶段及其下游失效并纳入重算集合，未失效阶段必须直接复用产物且不得重复执行，复用与重算清单须写入诊断结果。
6. 保证增量与全量的结果一致性：从任意初始状态执行包含规模切换、组合阶数调整、基数预算变更与降维方法切换的编辑序列，每次增量运行得到的最终评估指标、保留特征清单、决策记录与诊断摘要，必须与从空白工作区按相同最终配置与输入全量运行的结果逐字段一致，比较须覆盖多档规模。
7. 实现并发评估与串行结果一致性：使用线程池并发执行各候选规模档或降维路径的评估与交叉统计，最大并发数取自配置；每个候选任务携带由规模档标识与路径名派生的稳定排序键，无论线程完成顺序如何，最终指标表顺序、决策记录顺序与失败清单顺序必须与单线程按排序键顺序执行的结果一致，指标累加须采用固定顺序以保证逐字段可比较。
8. 实现阶段快照恢复、异常隔离与诊断报告：交叉组合、降维、评估各阶段以临时文件加原子替换持久化快照，快照含阶段名、配置指纹、规模档、已处理游标与产物摘要及版本号，恢复时若配置指纹不符输出 E_CONFIG_MISMATCH，收到可处理的退出信号时完成当前阶段快照后以整数退出码 0 退出，强制终止后仅依据已完整替换的快照恢复；单任务异常记录规模档、阶段名、业务码与异常类型后继续其余任务，最终输出 JSON 诊断报告含各规模档指标、保留特征与决策记录、基数预算降级清单、缓存复用与失效数量、快照版本号与失败清单，报告以原子替换写盘。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地合成数据验证多档规模下交叉组合降级、降维取舍决策、增量与全量一致性及快照恢复。
