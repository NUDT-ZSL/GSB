在空白工作区构建一个面向本地确定性样本的图文证据联合判定管线，用于图像区域视觉证据与结构化文本断言的协同推理，并输出可复现的实验报告。输入为一个本地样本目录：每个样本包含程序生成的 PNG 图像（固定分辨率，画面为几何图元与噪声，由固定种子生成）与一份结构化文本断言 JSON（实体、属性与断言列表）；另提供一份融合配置（视觉特征维度与量化档位、文本证据权重、融合温度、置信度阈值、最大证据轮数、并发数）与一份证据关系表（声明文本断言与视觉区域的关联、冲突、补充关系）。管线按证据轮次演进：每轮先抽取区域视觉特征与文本断言特征，再按关系对齐后做 softmax 加权融合，输出判定结论。核心难点在于：同一输入在任意并发度、任意中断恢复点与任意注入故障下都必须产出逐字节一致的结果与统计报告，同时视觉量化档位与融合温度的调整必须精确反映在结论与诊断信息中。

任务环境与准备：
安装 Python 3.11 及 NumPy、Pillow，使用本地固定种子生成样本图像与断言 JSON。
准备融合配置与证据关系表样例，另准备含各类故障的独立注入配置文件。
准备一份样本名与轮序清单，用于对照单线程串行基线结果。

业务要求：
1. 实现多模态样本加载层：扫描输入目录下每个样本的图像与断言文件，校验文件存在性、PNG 容器头与尺寸、JSON 结构完整性，图像解码为 uint8 数组并按配置特征维度做确定性分块，文本解析为实体、属性与断言列表；缺失或不合法样本记录 E_SAMPLE_INVALID 并进入失败清单，不得静默跳过。
2. 实现视觉特征抽取与量化：按配置的特征维度与量化档位，对图像做确定性分块统计（区域均值、梯度强度与主方向直方图），得到每个候选区域的特征向量；量化档位必须真实影响离散化结果，同一图像在同档位下多次运行必须得到逐元素一致的特征，不同档位结果应有可观测差异。
3. 实现文本断言特征与证据关系对齐：将每条断言映射为属性特征向量，并按证据关系表与视觉区域建立关联、冲突、补充三类对齐；引用不存在区域或不存在断言的悬空关系须输出 E_RELATION_DANGLING 并记录涉及的关系条目，不得将悬空关系当作关联处理。
4. 实现逐轮证据融合推理：每轮按融合温度对视觉与文本证据做减去最大值的稳定 softmax 加权融合，冲突关系按配置规则折减置信度，补充关系按权重叠加；输出每轮判定得分、归一化置信度与证据贡献分解，得分低于置信度阈值或达到最大轮数时给出终态结论与触发原因。
5. 实现并发推理与串行结果一致性：使用线程池并发处理样本的多轮特征抽取与融合，最大并发数取自配置；每条样本任务携带由样本名与轮序号派生的稳定排序键，无论线程调度顺序如何，最终每样本结论、证据贡献分解顺序、失败清单顺序与统计汇总必须与单线程按样本名、轮序顺序执行逐字段一致。
6. 实现轮次快照与恢复一致性：每轮结束以临时文件加原子替换方式持久化快照，快照含轮序号、配置哈希、关系表哈希、已处理样本游标、各样本当前得分摘要与版本号；重启时读取最新快照，若配置哈希或关系表哈希不符输出 E_CONFIG_MISMATCH，一致时从游标继续且恢复后最终报告与不中断运行逐字节一致。
7. 实现异常注入与失败隔离：以独立注入配置文件指定图像截断、断言字段缺失、区域越界、非有限特征值与关系悬空等故障，注入到指定样本与指定轮次，注入项编号须写入报告以证明命中；单样本在某轮特征抽取、关系对齐或融合阶段抛异常时记录样本名、轮序号、阶段名与业务码到失败清单并继续其余样本，后续轮次不得再对该样本产出结论。
8. 实现可处理退出语义与诊断报告输出：收到可处理的退出信号时完成当前轮快照保存与失败清单写盘后以整数退出码 0 退出，强制终止后仅依据已完整替换的快照恢复且不得承诺生成退出报告；每次完整运行生成 JSON 报告，含每样本联合结论、最终置信度、各轮得分轨迹、证据贡献分解、配置与关系表哈希、注入项命中清单、失败清单与快照版本号，报告以临时文件加原子替换写盘。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本验证联合判定结果、并发与中断恢复的逐字节一致性及注入故障的业务码与报告。
