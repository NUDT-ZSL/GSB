当前是空白工作区，需要从零构建一个面向搜索推荐精排与重排链路的本地算法实现与可复现实验环境，核心业务问题是数值精度与误差传播。业务对象是本地确定性生成的候选集：由固定种子生成 query 集合（含 query_id、query_text、query_terms），每个 query 关联若干候选 item（含 item_id、item_terms、类目、价格与质量分），精排特征由候选与 query 的确定性交互计算得到（词项匹配度、类目匹配、价格分桶、质量分缩放等），精排模型为线性打分后接 sigmoid，重排阶段对精排 top-N 做多样性约束下的顺序调整（类目惩罚与位置衰减）。用户关注：同一输入在 float64、float32 与定点缩放三档精度下结果差异仅来自精度本身；逐级输出的偏差、误差区间与误差放大比可计算、可归因；门限与 top-k 判定在重复运行下不被舍入翻转；配置与统计量快照可版本化整体替换。

任务环境与准备：
安装 Python 3.10 或以上，创建本地虚拟环境并安装 NumPy、SciPy（用于确定性数组运算与统计，版本不作硬性限定）。
在空白工作区新建项目根目录，准备本地样本生成脚本：按固定种子生成 query 集合与候选 item 集合的 JSONL 文件，并生成对应特征输入，样本规模以单机数分钟内可跑完为准。
准备一份默认配置（特征权重、门限、top-k、三档精度参数、定点缩放因子与舍入模式、容差与降级策略），以 JSON 文件形式存放并可被命令行读取。
准备异常注入参数清单（重复 query_id、空 item_terms、越界数值、未知精度档、非正缩放因子等），以参数或独立输入文件方式传入，不修改源码。
确认可在本地命令行运行，不依赖外部服务、真实账号、GPU 或网络资源；Windows 下使用整数退出码，业务码以 E_xxx 形式出现在 JSON 报告或 stderr 中。

业务要求：
1. 实现确定性的特征构造与精排打分流水线：按 query 与候选的确定性交互计算特征向量（词项匹配度、类目匹配、价格分桶、质量分缩放），经线性打分与 sigmoid 得到精排分数，再按分数降序、同分按 item_id 升序产生 top-N 排序；同一输入、同一配置与固定种子下逐字节一致，禁止依赖字典遍历顺序或外部状态。
2. 实现可切换的精度档执行层：float64、float32 与定点缩放整数三档共用同一算子语义，定点档的缩放因子与舍入模式由配置显式给出；同一输入在不同精度档下结果的差异必须仅来自精度损失本身，切换精度档不得改变特征构造语义与排序打破平局的规则。
3. 实现逐级误差传播计算与主导来源归因：以 float64 档作为该快照内的参考真值，输出特征构造、线性打分、sigmoid、top-N 排序与重排各级的绝对偏差、相对偏差、误差区间与误差放大比，并定位主导误差来源为特征构造、打分缩放、激活函数或排序比较中的哪一级，归因须可追溯至偏差明细。
4. 实现门限判决与 top-k 排序的数值稳定性保护：对精排分数设定可配置的准入门限与 top-k，提供严格比较与容差带比较两种策略及次正规数保护；保证恰好落在门限附近的候选在重复运行下判定不被舍入翻转，门限或容差非法返回 E_CONFIG_INVALID 并指明字段。
5. 实现重排阶段的多样性约束与顺序调整确定：按类目惩罚与位置衰减对精排 top-N 重排，同分按 item_id 升序打破平局；重排结果须满足位置衰减单调性与类目惩罚生效条件，且重排前后候选集合一致但顺序可核对；检测到候选丢失或重复返回 E_INCONSISTENT 并指出类别与 query_id。
6. 实现错误注入与异常链路归因：query 重复、item_terms 为空、价格或质量分越界、精度档未知、缩放因子非正等由输入或参数触发时，分别返回结构化业务码（如 E_DUP_QUERY、E_ITEM_EMPTY、E_VALUE_RANGE、E_PRECISION_UNKNOWN、E_SCALE_INVALID）并指明阶段名与 query_id；下游须按明确策略降级并携带触发它的上游业务码，禁止静默吞掉异常。
7. 实现配置与统计量快照的版本化管理及整体替换：特征权重、门限与 top-k 配置、各精度档统计量各携带单调递增版本号与内容校验和，提交时整体替换旧快照而非增量修补；加载时检测版本号或校验和变化并整体替换，损坏或校验和不符返回 E_SNAPSHOT_CORRUPT 并指明快照类别与版本号。
8. 实现跨级一致性自检与可复现实验环境：校验各级处理的 query_id 集合一致、误差区间顺序合法、定点档偏差可由缩放因子与舍入模式重算出、重排前后候选集合可核对；提供命令行入口读取本地确定性样本，跑完整基线输出含逐级偏差、误差区间、误差放大比、主导来源、业务码与降级标记的 JSON 报告，支持固定种子重跑并比对报告哈希一致，附一次多点注入与一次降级演示。
