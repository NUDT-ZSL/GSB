在空白工作区构建一个面向本地确定性样本的多模态协同推理管线，用于图文配对证据的联合判定。输入为一个本地样本目录，内含若干图文样本包：每个样本包含一段程序生成的图像（PNG，固定分辨率，画面上按固定种子绘制几何图元与噪声）与一段结构化文本描述（JSON，含实体、属性与断言）。另提供一份协同推理配置（视觉特征维度与量化档位、文本证据权重、融合温度、置信度阈值、最大证据轮数、并发数）与一份证据关系表（声明哪些文本断言与视觉区域存在关联、冲突或补充关系）。管线按证据轮次演进：每轮先抽取视觉区域特征与文本断言特征，再按关系表做证据对齐与冲突消解，然后做加权融合推理得到判定与置信度，最后一轮结束后输出联合结论。核心挑战是状态演进与恢复一致性：推理可能在任意轮次被中断，重启后必须从最近一次持久化的轮次快照恢复，使最终结论与不中断运行逐字段一致；快照需识别版本变化，若关系表或融合参数在恢复前被修改则必须拒绝恢复。

任务环境与准备：
准备 Windows 本地工作区，安装 Python 3.11 与 NumPy；图像读写可使用标准库实现 PNG 解码，不得依赖在线资源。
在本地生成确定性图文样本包、证据关系表与协同推理配置，固定随机种子，样例数覆盖少轮与多轮收敛、冲突关系及悬空关系场景。
准备可处理退出信号的触发方式与强制终止场景，确认快照目录可写、临时文件与目标文件位于同一卷以支持原子替换。

业务要求：
1. 实现多模态样本加载层：扫描输入目录下每个样本的图像和文本描述，校验文件存在性、PNG 容器头与 JSON 结构完整性，图像解码为 uint8 数组，文本解析为实体、属性与断言列表；缺失或不合法样本记录样本名、阶段名与业务码 E_SAMPLE_INVALID 到失败清单并继续处理其余样本，不得中断整体运行。
2. 实现视觉特征抽取与量化：按配置的特征维度与量化档位，对图像做确定性分块统计（区域均值、梯度强度与主方向直方图），得到每个候选区域的特征向量；量化档位必须影响特征离散化结果，特征计算禁止随机性，同一图像在相同配置下两次运行的特征向量须逐元素一致，并输出区域边界框坐标。
3. 实现文本断言特征与关系对齐：将每条文本断言映射为属性特征向量，按证据关系表将断言与视觉区域做关联、冲突、补充三类对齐；出现引用不存在区域或不存在断言的悬空关系时记录 E_RELATION_DANGLING，该条关系被跳过而其余关系继续生效，对齐结果须保留关系 ID 与来源顺序。
4. 实现逐轮证据融合推理：每轮依据融合温度对视觉与文本证据做 softmax 加权融合，冲突关系按配置规则做置信度折减，补充关系按权重叠加；输出每轮判定得分、归一化置信度与证据贡献分解，得分低于置信度阈值的样本进入下一轮补充证据，达到最大证据轮数后强制给出联合结论，禁止无界循环。
5. 实现轮次快照与恢复一致性：每轮结束以临时文件加原子替换方式持久化轮次快照，快照含轮序号、配置哈希、关系表哈希、已处理样本游标、各样本当前得分与证据摘要及版本号；重启时读取最新快照，若配置哈希或关系表哈希与当前不一致则输出 E_CONFIG_MISMATCH 并拒绝恢复，一致时从该轮游标继续，恢复后最终结论与不中断运行逐字段一致。
6. 实现并发推理与串行一致性：使用线程池并发处理样本的多轮特征抽取与融合，最大并发数取自配置；每条样本任务携带由样本名与轮序号派生的稳定排序键，无论线程调度顺序如何，最终每样本结论、证据贡献分解顺序、失败清单顺序与快照内样本顺序必须与单线程顺序执行完全一致。
7. 实现异常链路与可处理退出：单样本在某轮特征抽取、关系对齐或融合阶段抛异常时记录样本名、轮序号、阶段名与异常类型到失败清单并继续其余样本，后续轮次不得再对该样本产出结论；收到可处理的退出信号时完成当前轮次快照保存与进度记录后以整数退出码 0 退出；进程被强制终止后重启仅依据已完整替换的快照恢复，不得承诺为未完成轮次生成退出报告。
8. 实现结论报告与版本化输出：每次完整运行生成 JSON 报告，含每样本联合结论、最终置信度、各轮得分轨迹、证据贡献分解、快照版本号、配置与关系表哈希、失败清单及各阶段耗时；报告以临时文件加原子替换方式写盘，字段名与业务码须与前文要求逐字一致。
