当前是空白工作区，没有现存项目、代码或数据附件，需要从零构建一个面向 LLM 预训练语料去重环节的本地可视化与诊断工作台。业务对象是本地确定性生成的语料分片清单（JSONL，字段含 shard_id、doc_id、text、lang、source、token_estimate），以及一份去重校验配置：分块签名长度、相似度阈值、候选比较窗口、校验模式（全量比较或分块摘要比较）与采样种子。工作台把去重校验建模为多级流水：分片摄入与校验→分块签名生成→候选桶划分与签名摘要→候选比较与相似判定→去重剔除标记→分片级统计汇总。用户以交互方式按 doc_id 查询该文档的分块签名、候选比较轨迹、相似判定结论与被剔除原因，并要求该查询结果与批量全量处理结果中的同一记录一致；按分片整体重算耗时较长，因此需要用缓存与失效机制支撑低延迟查询。本任务不使用任何真实语料或网络资源，全部样本由固定种子在本地生成。

任务环境与准备：
准备 Windows 本机环境，安装 Python 3.11 及以上版本，创建独立虚拟环境并可执行 python 命令。
在虚拟环境中安装 NumPy，版本以兼容 Python 3.11 为准，用于确定性样本生成与签名摘要计算；不需要 GPU、外部数据或网络服务。
在空白工作区建立项目目录，用固定种子生成本地语料分片清单与去重校验配置样本，样本规模与配置参数写入项目文档以便重跑。
确认可在本地以命令行方式启动工作台与批量处理入口，并可在同一进程内发起并发查询与快照切换，用于观察一致性、延迟观测与失效效果。

业务要求：
1. 实现确定性的分块签名生成级：按配置的分块签名长度把文档切分为若干块，对每块依据受控哈希与归一化规则生成块签名，再聚合成文档级签名摘要；同一输入与同一配置下必须逐字节产出相同的块签名、摘要与候选桶归属，签名长度非正或文档长度不足以形成签名块时分别返回 E_SIG_LEN_INVALID、E_DOC_TOO_SHORT。
2. 实现候选桶划分与签名摘要比较级：按文档级签名摘要把文档分入候选桶，桶内按配置的候选比较窗口产出候选对，窗口外文档不得比较；文档仅在摘要相同或摘要冲突时才进入候选比较，比较结果须包含命中块位置与相似度；桶内无候选时须形成空候选记录，候选总数与桶数须可复核。
3. 实现候选比较与相似判定级：对每个候选对按命中的块签名位置计算相似度，相似度大于等于配置阈值时判定为近重复并按质量分降序、再按 doc_id 升序保留代表；须记录被剔除文档的相似邻居、命中块位置与阈值比较留痕，保证任一剔除记录可追溯到具体候选对与签名摘要。
4. 实现按 doc_id 的交互查询接口并控制单次延迟预算：查询须返回该文档的块签名、候选比较轨迹、相似判定结论与是否被剔除；延迟以本地查询循环的实际处理计时为观测，并按候选比较次数与签名块数给出估算记录；超预算返回 E_LATENCY_BUDGET 并附带已完成阶段标记，禁止以放大预算或跳过候选比较掩盖真实延迟。
5. 实现查询侧与批量侧的结果一致性保证：查询返回的块签名、候选比较轨迹、相似判定结论与剔除原因，必须与批量全量处理结果中同一 doc_id 的记录在声明精度内一致，且参与比较的候选集合与桶划分完全相同；检测到偏差返回 E_INCONSISTENT 并输出首个偏差文档、所在阶段与两路取值。
6. 实现签名与候选比较产物的内容寻址缓存与失效联动：缓存键须纳入分片内容哈希、签名长度、相似度阈值、候选比较窗口与校验模式，键相同必须复用、键不同必须重算；当阈值、窗口或校验模式变化时必须计算受影响文档集合与受影响缓存条目集合并使相关缓存失效，且须输出本次重算与复用集合。
7. 实现数值门限判定的稳定性与校验模式切换的一致性裁决：对相似度阈值提供严格比较与容差带比较两种策略及次正规数保护，保证恰好落在门限附近的文档在重复运行与不同校验模式下判定不被舍入翻转；当从全量比较切换到分块摘要比较时，须输出两种模式下的剔除集合差异与命中块位置差异，并说明差异来自摘要冲突遗漏还是命中块减少。
8. 实现快照版本化与整体替换、并发查询与资源上限控制，并提供本地可视化诊断工作台：分片统计量与剔除清单快照各携带单调递增版本号与内容校验和，检测到版本号或校验和变化时必须整体替换旧快照而非增量修补，损坏或校验和不符返回 E_SNAPSHOT_CORRUPT，旧版本不得覆盖新版本且回退尝试返回 E_SNAPSHOT_ROLLBACK；为单批文档数、候选比较次数与缓存条目数设可配置上限，超限返回 E_RESOURCE_LIMIT 或降级并标记降级类别；工作台展示分块签名分布、候选桶与候选对、剔除与保留集合、逐文档查询结果、延迟观测、快照版本与最近业务错误码。
