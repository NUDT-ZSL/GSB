当前是空白工作区，没有现存项目、代码或数据附件，需要从零构建一个面向时序预测的本地数据处理管线与结果验证工具，核心业务问题是数值精度与误差传播。业务对象是本地确定性生成的时序样本：用固定种子生成多变量时间序列（含趋势、周期与噪声分量，以及若干外生变量与事件指示列），并配套一份预测配置，声明窗口长度、预测步长、特征工程选项（滞后、滑动统计、差分）、模型族（线性自回归或浅层梯度提升树桩）、训练分块大小、数值精度档（float64、float32 与定点缩放整数）、定点缩放因子与舍入模式、评估指标口径。管线需把一次时序预测建模为可诊断的流水：窗口切分与特征构造→分块训练梯度累加→逐窗口递归预测→误差指标聚合，并在每个阶段输出可复算的中间量。

任务环境与准备：
安装 Python 3.10 及以上版本，并安装 NumPy（如 1.24 及以上）与标准库依赖，无需 GPU 或外部服务。
在 Windows 工作区创建项目目录，准备本地确定性时序生成脚本与配置样例，所有随机源使用显式固定种子。
确认命令行可通过 python 运行入口脚本，报告输出目录可写，不依赖网络、真实数据集或付费资源。

业务要求：
1. 实现确定性的窗口切分与特征构造阶段：按窗口长度、预测步长与特征工程选项生成每个窗口的特征矩阵与目标向量，滞后与滑动统计的边界以样本索引精确确定，训练窗口与测试窗口严格按时间顺序切分且不得重叠；同一输入与同一配置下必须逐字节产出相同的窗口集合、特征矩阵与目标向量，同值窗口按起始索引升序排列。
2. 实现分块训练核心：按配置的分块大小把训练窗口切块，每块计算损失与梯度并按显式声明的归约顺序归约，支持可配置的补偿求和与次正规数保护，全部中间量以 float64 计算；同一分块口径与同一配置下每轮损失、梯度与最终模型参数必须逐字节可复现，同时产出一次性整段训练的对照结果并逐轮比较损失与参数偏差。
3. 实现可切换的精度档执行层：float64、float32 与定点缩放整数三档共用同一算子语义，定点档的缩放因子与舍入模式由配置显式给出；同一输入在不同精度档下结果的差异必须仅来自精度损失本身，切换精度档不得改变窗口集合、特征列顺序与归约顺序，定点档偏差必须可由缩放因子与舍入模式独立复算。
4. 实现逐窗口递归预测：按时间顺序对测试窗口做多步预测，每步以上一步预测值作为滞后输入并受预测步长约束，递归预测不得访问未来真实值；输出每步预测值、置信区间与递归误差累计量，递归深度超过预测步长或访问到未来数据时返回 E_RECURSION_INVALID 并指出窗口索引与步号。
5. 实现逐级误差传播计算与主导来源归因：以同一输入上 float64 整段训练的预测结果为该快照内参考真值，输出窗口切分边界、特征缩放、分块梯度累加、定点量化与递归预测各级的绝对偏差、相对偏差、误差区间与误差放大比，并定位主导误差来源；区间上界小于下界或归因级别不在受控集合内返回 E_ERROR_SPECTRUM_INVALID 并指明窗口与级别。
6. 实现门限判决与指标聚合的数值稳定性保护：对预测准入门限与误差容差提供严格比较与容差带比较两种策略及次正规数保护，保证恰好落在门限附近的样本在多精度档重复运行下判定不被舍入翻转；指标须由逐窗口逐步明细独立重算一致，门限策略变更须留痕，门限或容差非法返回 E_CONFIG_INVALID 并指明字段。
7. 实现指标与配置快照的版本化管理及整体替换：窗口划分统计量、精度档配置与各级误差谱统计各携带单调递增版本号与内容校验和，提交时整体替换旧快照而非增量修补；重启加载时识别版本号或校验和变化并整体替换，旧版本不得覆盖新版本且回退尝试返回 E_SNAPSHOT_ROLLBACK，损坏或校验和不符返回 E_SNAPSHOT_CORRUPT 并指明快照名与版本号。
8. 实现跨级一致性自检与本地结果验证工具：校验各级处理的窗口标识集合完全一致、每步预测可由特征与模型参数独立复算一致、误差谱可由偏差明细重算一致、被保护判决与跳过记录与实际执行一致；不一致返回 E_INCONSISTENT 并指出首个偏差位置；另提供命令行入口读取本地确定性样本，输出含窗口特征摘要、逐轮损失、逐级误差谱、逐窗口预测与指标、业务码的 JSON 报告。
