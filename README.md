当前是空白工作区，需要从零构建一个面向音色克隆与发音建模的本地可集成领域组件与完整示例，核心业务问题是数值精度与误差传播。业务对象是本地确定性合成的语音样本：用固定种子生成若干说话人的基频、共振峰与能量包络参数，按给定发音时间轴拼成 16kHz 单声道 PCM 片段，并为每个说话人生成固定的参考音色片段，另附逐帧真值文件（帧长 20ms，字段含 frame_index、speaker_id、f0_true、energy_true、phoneme_id）与样本清单（JSONL，字段含 utterance_id、speaker_id、ref_id、sample_rate、frame_ms、pos_scale、precision_tier、seed）。组件需完成帧级声学特征提取、参考音色嵌入估计、发音单元对齐打分与克隆音色的相似度裁决，整条链路的中间量经过缩放、归一化、对数变换与相似度累加，浮点精度与舍入策略会沿链路传播并放大，因此必须给出误差传播链、主导误差来源与参考真值的观测口径。

任务环境与准备：
安装 Python 3.10 及以上版本，并安装 NumPy（示例以 NumPy 进行确定性数组生成与浮点运算）。
确认工作目录为空，直接在该目录创建项目，无需任何外部账号、网络服务或预置数据附件。
样本由组件内置的固定种子生成器在本地生成 PCM、参考音色片段与逐帧真值，不依赖外部音频文件。
运行环境为 Windows，命令行走本地文件读写与标准输出，无容器或虚拟化依赖。

业务要求：
1. 实现确定性的帧级声学特征提取层：按 frame_ms 与帧移切分 PCM，帧边界以样本索引精确确定，计算短时能量、过零率与基频候选，输出逐帧特征与帧数；同一 utterance_id、同一 seed 与同一配置下必须逐字节产出相同特征序列，帧数须与真值文件一致，不一致返回 E_FRAME_MISMATCH 并指出首个不符帧索引。
2. 实现参考音色嵌入估计与发音单元对齐打分：由参考片段估计每个说话人的音色统计量，对每帧按确定性相似度指派发音单元并打分；同分时按 speaker_id 升序、再按 phoneme_id 升序打破平局，嵌入维度与统计量口径在结果中显式记录，禁止依赖字典遍历顺序或系统时间。
3. 实现可切换的精度档执行层：float64、float32 与定点缩放整数三档共用同一算子语义，定点档的缩放因子与舍入模式由配置显式给出；同一输入在不同精度档下结果的差异必须仅来自精度损失本身，切换精度档不得改变参与计算的帧集合与单元指派集合，精度档未知或缩放因子非正分别返回 E_CONFIG_INVALID 并指明字段。
4. 实现逐级误差传播计算与主导来源归因：把 float64 档作为该快照内的参考真值并以逐帧真值文件的 f0_true、energy_true 作为观测口径，输出特征缩放、嵌入归一化、对数变换与相似度累加各级的绝对偏差、相对偏差、误差区间与误差放大比，并定位主导误差来源为特征缩放、嵌入归一化、对数变换还是相似度累加，归因须可追溯至偏差明细。
5. 实现音色相似度门限与排序的数值稳定性保护：对克隆音色相似度设定可配置门限与 top-k 排序，提供严格比较与容差带比较两种策略及次正规数保护，保证恰好落在门限附近的样本在重复运行下判定不被舍入翻转；门限越界、容差非正或 top-k 非正返回 E_CONFIG_INVALID 并指明字段。
6. 实现由输入或参数触发的错误注入与异常链路归因：采样率非 16000、seed 与片段形状不匹配、ref_id 缺失、utterance_id 重复、phoneme_id 越界等分别返回结构化业务码并在结果中标注阶段名与 utterance_id；异常通过输入或参数注入而非修改源码制造，未被任何阶段归因的异常须汇总到结果顶层。
7. 实现配置与统计量快照的版本化管理及整体替换：音色嵌入统计量、精度档配置与误差谱统计各携带单调递增版本号与内容校验和，提交时整体替换旧快照而非增量修补，旧版本不得覆盖新版本且回退尝试返回 E_SNAPSHOT_ROLLBACK；重启加载时识别版本号或校验和变化并整体替换，损坏或校验和不符返回 E_SNAPSHOT_CORRUPT 并指明快照类别与版本号。
8. 提供可集成的领域组件接口与完整示例并实现跨级一致性自检：暴露特征提取、音色嵌入、精度档执行、误差谱与注入诊断入口；自检校验各级处理的 frame_index 集合一致、误差区间顺序合法、定点档偏差可由缩放因子与舍入模式重算一致、音色裁决可追溯到偏差明细，不一致返回 E_INCONSISTENT 并指出类别；命令行示例读取本地合成样本输出含误差谱、业务码与降级标记的 JSON。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
