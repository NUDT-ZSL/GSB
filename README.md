某安全研究团队需要在离线 Windows 空白工作区从零开发一个面向自研本地协议 SLP（Session Link Protocol）的状态机脆弱性验证组件。SLP 会话由若干带序号与方向标记的控制报文组成：HELLO、AUTH、NEGOTIATE、DATA、CLOSE，每个报文含会话标识、报文序号、阶段码、长度字段与可选载荷。状态机规定各报文在会话内可迁移的阶段序列，并允许通过可选扩展位声明重协商与半关闭。团队需要在本地确定性样本上复现状态机层面的异常：乱序、重复、阶段跳跃、跨会话报文混入、重协商风暴与半关闭后继续发送，并给出可集成的检测组件与完整可运行的示例。核心难点在于：状态迁移判定与资源控制、异常注入的真实性、批量处理的一致性与恢复边界相互耦合，任何结论必须能由样本内同步标记与真值记录复核，不得依赖系统时钟或缺失信息推断。输入输出语义与错误码须在组件内自洽并保持稳定。

任务环境与准备：
确认 Windows 工作站已安装 Python 3.11 或以上，并使用 python -m venv 创建独立虚拟环境。
在虚拟环境中安装 pytest（建议 7.x 及以上）与标准库即可，无需网络服务、账号或外部数据；若离线安装需提前准备 wheel 包。
在空白工作区建立项目目录与 samples、reports、checkpoints 子目录，确认当前工作目录可读写且进程有权限创建临时文件并执行重命名。
确认系统允许使用文件锁与线程池，运行前清理 reports 与 checkpoints 目录中的残留临时文件。

业务要求：
1. 实现 SLP 会话记录的严格二进制解析：校验固定头魔数 b'SLP1'、版本白名单（仅 1 与 2）、报文数量与声明总长自洽、单报文序号与阶段码取值范围，并校验报文长度字段加偏移不溢出且不超出文件实际长度，越界返回 E_BOUNDS 并给出出错偏移；对未知阶段码与未知扩展位组合返回 E_PHASE 与 E_EXT，不得静默跳过。
2. 实现每会话状态机迁移判定：依据阶段码序列与扩展位重建合法迁移表，识别阶段跳跃、重复报文、AUTH 前发送 DATA、CLOSE 后发送任意报文等非法迁移，分别返回 E_TRANSITION 与 E_AFTER_CLOSE；缺失必需阶段返回 E_INCOMPLETE；结论须按会话标识与会话内序号稳定排序输出，与报文在文件中出现的物理顺序及到达顺序无关。
3. 实现跨会话违规与报文混入检测：识别同一会话标识下方向标记矛盾、同一序号被不同会话复用、扩展位声明重协商但缺少对应协商阶段等情形，返回 E_MIXUP 并列出冲突报文序号；重协商计数须在会话内累计并在超过可配置上限时返回 E_STORM，且该上限变化不得影响其他会话的结论。
4. 实现真实资源隔离：对单会话的报文处理步数与单文件实测耗时设上限，步数超限返回 E_STEPS、实测耗时超限返回 E_TIMEOUT；计时须以真实墙钟测量而非人为延迟或固定常量，超限后须终止该文件后续解析并以业务码记录，不得中断同批其他文件处理，且报告中须给出已处理报文数与终止原因。
5. 实现异常注入复现机制：组件接受口径明确的注入参数对象，可强制指定阶段跳跃位置、报文乱序置换、跨会话混入目标、重协商次数与半关闭后追加报文；注入生成的畸形样本内须显式写入每个报文的同步标记与预期违规业务码作为真值来源，验证端只依据这些同步标记与规范化判定比较，不得使用注入器的中间计算结果作为真值，并报告观测一致与不一致计数。
6. 实现检查点演进与强制终止边界：以已完成文件标识与聚合结论持久化检查点，进程被强制终止后只允许恢复到最后一个完整检查点且不承诺生成退出报告；检测到检查点结构版本或阶段码白名单版本变化时须整体重建而非增量续接，不得把旧版判定与新阶段码表混合；检查点与最终报告均先写临时文件再整体重命名替换，替换前校验内容完整性。
7. 实现并发批处理一致性：支持以可配置并发度对同批样本并发检测，任意并发度下每会话违规清单、观测一致计数与拒绝记录必须与串行执行完全一致；同一工作目录并发写检查点须以文件锁串行化，锁冲突返回 E_LOCK 且不破坏既有状态，报告中须给出批次调度摘要（文件数、成功、超限、失败）。
8. 交付可集成组件与完整示例：组件暴露解析、判定、注入、批处理四类接口并保持业务错误码稳定，另提供命令行入口支持单文件与目录模式、结构化 JSON 报告输出与退出码区分全部成功、部分失败、参数错误；附确定性样本生成脚本与 pytest 测试集，覆盖乱序、重复、阶段跳跃、混入、重协商风暴、半关闭违规、步数与耗时超限、版本变化重建、锁冲突与强制终止恢复。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地确定性样本与注入参数验证状态机判定、资源上限、并发一致性和中断恢复，运行示例并检查报告业务码与退出码。
