上级要求先做一个可运行的最小版本，当前 WSL Ubuntu 工作区没有代码或样本，需要从零构建一个训练推理一体化领域的领域数据编辑与操作应用，用于诊断模型训练与推理一体化链路中的数据规模演进行为。业务对象由固定种子脚本在本地确定生成：首先是一份浮动规模的任务清单，每行含 case_id、data_size、feature_dim、label_dim、dtype、quant_scale、quant_zero_point、block_plan、revision、logical_clock_ms，其中 data_size 用于驱动逐样本数据生成；其次是一份两代共存的配置快照，v1 为单文件 JSON 记录相对生效秒数与扁平超参数，v2 为分片 JSON 加 SQLite 元数据库记录绝对毫秒时刻、配置代数、超参数摘要与失效墓碑。链路的核心是同一组算子要在训练与推理两种模式下均执行，训练模式产出梯度，推理模式产出预测，且接入固定内存预算和可注入逻辑时钟；当数据规模（样本数）变化、配置跨代演进或强制终止发生时，必须保证已提交状态可恢复、受影响产物可定向重算。

任务环境与准备：
在 Linux（WSL Ubuntu）上安装 Python 3.10 及以上版本；使用 numpy 库（1.26 及以上）和标准库 sqlite3、json、threading 或 multiprocessing；在项目根目录创建输入数据目录和输出目录。
随题交付一个固定种子样本生成脚本 sample_generator.py，用于生成任务清单 JSONL、两代配置快照及 v2 所需的 SQLite 元数据库，本地运行生成数据文件。
运行前安装依赖：pip install numpy；检查 Python 环境使用 python3 --version 确认版本；全部输入输出在本地文件路径下完成，不涉及外部网络或服务。

业务要求：
1. 实现固定种子驱动的逐样本数据生成与任务摄入层：按任务清单中的 data_size 生成服从确定性分布的样本矩阵，并依据 feature_dim、label_dim 校验 shape 一致，用显式声明的浮动缩放与定点舍入规则对样本做量化与反量化，同时把每个 case_id 的数据摘要与该任务内容哈希写入样本缓存。
2. 实现训练模式与推理模式的统一算子执行入口：同一算子链按照输入 mode 分别产出梯度、激活留存批次或最终预测，并支持可配置的 block_plan 分块策略与算力优先级，任何影响数值结果的算子顺序与舍入模式必须在代码中显式一致且可重复，不同 mode 下的块边界、并行调度依据与归约顺序必须保持一致。
3. 实现基于逻辑时钟推进和固定内存预算的增量数据规模调度：按每个 case_id 的 logical_clock_ms 按时间序推进任务，并为 total_feature_buffer_size、single_pass_workspace_size 与模型工作内存三个不同层级设预算上限，在训练模式的内存压力、推理模式的吞吐优化与不同 data_size 的批处理之间做出显式取舍，超限返回 E_MEMORY_BUDGET。
4. 实现两代配置快照的读取与双向迁移：v1 单文件 JSON 扁平记录相对生效秒与超参数，v2 分片 JSON 加 SQLite 元数据库记录绝对毫秒、配置代数与摘要，迁移时对缺失字段补全默认值并记录补全来源，对 v2 中 v1 无法表达的代数、墓碑与分片索引按显式丢弃规则处理，迁移后输出每个字段来源与被丢弃字段清单。
5. 实现配置代数切换与数据规模变化后的定向依赖失效传播：以内容寻址缓存键为单元，当 v2 配置代数提升、某任务 revision 提升或 data_size 变化时，分别按仅配置依赖、仅数据依赖和两者皆受影响三类情形计算需要重算的任务集合与重算算子链，复用未受影响上游已提交缓存，仅对受影响后缀重算并输出重用与重算清单。
6. 实现逐步可提交的进度检查点与强制终止恢复：训练或推理执行在批次边界或逻辑时间窗边界持久化带单调递增版本号、已完成 case_id 集合与内容校验和的检查点，仅当检查点内全部任务阶段提交成功才原子替换本次进度，重启时从最近已提交检查点继续执行，已提交任务不得重算，未提交的中间梯度或预测状态必须丢弃并从阶段起点重建。
7. 实现版本化账本的原子整体替换与并发提交控制：任务清单、配置快照、样本缓存与进度账本均携带单调递增版本号与内容校验和，检测到版本号或校验和变化时必须整体替换旧快照而非增量修补，同一时刻只允许一个配置代数、批次进度或缓存快照提交生效，并发冲突时后到者立即返回 E_STAGE_BUSY 而不阻塞等待。
8. 实现跨模块自检与可交互结果验证：提供按 case_id 查询训练或推理完整产物的入口，自检校验重复任务不重复计量、数据规模变化后的重算集合与复用集合无交集且并集覆盖全部受影响任务、各阶段缓存键可由任务内容哈希与配置版本独立计算还原、预算压力与实时任务执行顺序与逻辑时钟一致，并输出可重复生成的诊断报告。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
