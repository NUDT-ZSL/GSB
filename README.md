当前是空白工作区，需要从零构建一个面向搜索排序前链路的查询理解与意图解析组件，并附带可复现的实验环境。输入是本地生成的搜索查询日志（JSONL，字段含 query_id、query_text、session_id、timestamp_ms、locale、raw_clicks 列表）以及本地构建的意图标签体系（domain、intent_class、slot_schema）与领域词典。组件需要完成查询归一化（全半角、大小写、繁简映射表）、分词、span 级槽位识别、层级意图判定（domain→intent_class→slot 组合），输出带置信分数与证据片段的解析结果，并基于点击日志做意图消歧的离线评估。业务关注点是可复现验证与异常注入：同一输入与同一随机种子下解析与评估必须完全可复现；实验环境需要能对归一化、分词、槽位、意图四个阶段分别注入可控异常（词典缺失、标签越界、重复 query_id、伪反馈噪声），验证异常沿链路的归因与降级行为。所有样本、词典与标签体系均本地确定性生成，不依赖外部账号、线上服务或网络。

任务环境与准备：
安装 Python 3.11 与 pip，创建空工作区目录，不引入网络服务或外部账号。
安装依赖：numpy、scikit-learn，并确认本地可离线运行。
编写本地确定性样本生成脚本，产出查询日志 JSONL、意图标签体系、域词典与繁简/全半角映射表，种子固定并可重复生成。
准备四阶段注入参数样例与多点注入演示配置，全部以文件或命令行参数形式提供，不修改源码。

业务要求：
1. 实现确定性查询归一化与分词层：依据随附的繁简映射、全半角映射与领域词典，将原始 query_text 归一化为规范串并产出带码点起止偏移的 token 序列；同一输入与配置下必须逐字节可复现，映射表缺失或词典条目格式错误分别返回 E_MAP_MISSING 与 E_DICT_FORMAT，并指出 query_id 与出错位置。
2. 实现 span 级槽位识别与层级意图判定：基于标签体系与 slot_schema，为每条查询输出 domain、intent_class 与若干槽位 span（含起止偏移、槽位名、正规化值、置信分数），同一查询的 domain 判定必须与所属 intent_class 的父级定义一致，违反时返回 E_LABEL_CONFLICT 并给出冲突标签对。
3. 实现基于点击日志的意图消歧与离线评估：用 raw_clicks 构造伪相关反馈，对歧义查询在候选 intent_class 间做确定性重排序，输出 top-k 意图、NDCG 与 MRR；评估必须记录所用种子、样本范围与对照基线，同一快照同一种子重跑结果必须一致，日志中 query_id 在点击侧出现但解析侧缺失时按明确策略计入曝光未解析并返回 E_CLICK_ORPHAN。
4. 实现四阶段异常注入框架：对归一化、分词、槽位、意图阶段分别提供可配置注入点（如映射表条目缺失、词典截断、标签越界、点击噪声比例），注入必须由输入或参数触发而非修改源码；每个注入点须产生带阶段名、业务码与受影响 query_id 列表的结构化记录，并保证未注入阶段输出与基线逐字节一致。
5. 实现异常归因与降级链路：当某个阶段产出业务码时，下游阶段须按明确策略降级（如跳过槽位识别保留基础意图、回退到域级判定），降级结果必须携带降级类别与触发它的上游业务码；禁止静默吞掉异常，未归因的异常须汇总为 E_UNATTRIBUTED 并附阶段与样本计数。
6. 实现标签体系与配置的版本管理：标签体系与词典携带单调递增版本号与内容校验和，加载时识别版本变化并整体替换旧快照而非增量合并；配置项（种子、top-k、噪声比例、偏移单位）非法或越界分别返回 E_CONFIG_INVALID，版本或校验和不符时返回 E_SNAPSHOT_STALE 并拒绝混合使用新旧版本。
7. 实现跨阶段一致性自检与预算控制：校验槽位 span 首尾落在归一化串的码点范围内且互不非法重叠、意图标签来自受控集合、点击侧与解析侧 query_id 集合可核对，违反时返回 E_INCONSISTENT 并指出类别；同时为单批查询数、候选意图数与评估内存估计设可配置上限，超限返回 E_RESOURCE_LIMIT 或受限模式下执行并在报告中标记。
8. 提供可复现实验环境与命令行入口：读取本地生成样本，跑完整基线并输出含解析结果、评估指标、四阶段注入记录、业务码与降级标记的 JSON 报告；支持用固定种子重跑并比对两次报告哈希一致，另附一次多点注入演示，展示异常归因与降级行为，全部仅依赖本地样本与本地计算。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本验证解析、评估与四阶段异常注入的归因、降级及同种子可复现性，并输出报告。
