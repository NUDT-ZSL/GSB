当前是空白工作区，没有现存项目、代码或数据附件，需要从零构建一个面向长上下文注意力位置编码的本地可集成领域组件与完整示例，核心业务问题是 RoPE 参数及其变体配置在版本演进下的格式互操作与增量缓存失效。业务对象是本地确定性生成的注意力任务清单（JSONL，字段含 case_id、seq_len、head_dim、num_heads、base_theta、pos_encoding_variant、pos_scale、block_size、causal、seed、config_version），以及按 config_version 不同书写形式给出的位置编码配置：v1 为竖线分列行式（无字段名，字段依次为 base_theta、pos_scale、block_size），v2 为带字段名行式（含 base_theta、pos_scale、block_size 与可选 variant），v3 为结构化配置（含变体、分块频率调整与每头缩放）。组件把每次注意力计算建模为有向无环计算图：位置角计算→Q/K 旋转→分块打分→在线 softmax 归一化→输出累加。当配置版本升级、位置缩放或分块大小变化时，只有依赖这些参数的节点需要重算，其余节点复用内容寻址缓存；但 v1 无法表达变体与每头缩放，降级或跨版本加载必须给出明确的语义裁决，不得静默丢弃配置差异。组件须保证同一输入、同一配置快照下旋转角、注意力输出逐字节可复现，并对缓存键、失效传播与版本替换给出可核对记录。

任务环境与准备：
安装 Python 3.10 及以上与 NumPy 1.24 及以上，确保 numpy 可导入；无需网络、GPU 或外部数据。
在空白工作区创建项目目录，由程序按固定种子本地生成注意力任务清单 JSONL 与 Q/K/V 数组，不依赖附件或线上资源。
准备三份同语义不同版本的本地配置样本（v1 行式、v2 带字段名行式、v3 结构化），作为格式互操作与迁移演示的输入。
确认 Windows 下可正常运行本地进程池与文件缓存写读，并保留一次强制终止后重启的演示脚本。

业务要求：
1. 实现 v1、v2、v3 三种位置编码配置的读取器，按版本头或字段集分派解析路径；未知版本返回 E_VERSION_UNSUPPORTED，行字段数不符、必填字段缺失或数值不可解析返回 E_FORMAT_CORRUPT 并指出字段位置；读取结果须携带来源版本与源行定位，同一配置文本重复解析产物逐字节一致。
2. 实现 v1 到 v2、v2 到 v3 的提升与 v3 到 v2、v2 到 v1 的降级迁移器：提升时补全 variant、block_size 与每头缩放的默认值并逐项记录补全来源；降级时对 v3 无法在 v2 或 v1 表达的变体与每头缩放按显式声明的丢弃或展平规则处理并输出丢弃明细；当降级导致位置语义不可完全还原时返回 E_SEMANTIC_DRIFT 并列出不可还原字段。
3. 实现确定性的位置角计算与 Q/K 旋转层：按 variant、base_theta、pos_scale 为每个 token 位置计算逐维旋转角，整数维与半维配对口径显式声明；同一 case、同一配置快照与固定种子下旋转角与旋转后 Q/K 逐字节可复现，禁止依赖系统时间或字典遍历顺序。
4. 实现分块打分与在线 softmax 归一化路径，分块大小由 block_size 给出，causal 语义下禁止访问未来位置；分块路径输出须与不分块整段路径在声明容差内一致，并记录最大绝对偏差与最大相对偏差；分块统计量须可合并还原为整段 softmax 分母，还原偏差超容差返回 E_TOLERANCE_EXCEEDED。
5. 实现位置角计算、Q/K 旋转、分块打分、归一化四个节点的内容寻址缓存与缓存键构造：键须纳入配置版本、base_theta、pos_scale、block_size、causal 语义、分块内容哈希与上游节点哈希；键相同必须复用快照，键不同必须重算，每个缓存条目须携带键组成明细以支持事后核对。
6. 实现增量更新的依赖失效传播：当 base_theta、pos_scale 或 block_size 变化、或配置从 v1 升级到 v3 时，计算受影响节点与受影响 case 集合，复用未受影响上游缓存，仅重算受影响后缀；须输出重算节点清单与复用节点清单，并保证局部修改后的最终注意力输出与一次性全量重算结果逐字节一致，不一致返回 E_INCONSISTENT。
7. 实现缓存与配置快照的版本化及整体替换与并发写控制：缓存条目与配置快照携带单调递增版本号与内容校验和，检测到版本号或校验和变化时必须整体替换旧快照而非增量修补，损坏或校验和不符返回 E_CACHE_CORRUPT；多个任务并发写同一缓存键时须保证恰有一个生效且其余不破坏条目完整性，同一时刻只允许一个配置快照提交生效。
8. 提供可集成的领域组件接口、资源上限与完整示例：暴露配置加载、跨版本迁移、旋转与注意力计算、失效报告与缓存诊断入口；为单次调用分块驻留内存估算、缓存条目总量与并行重算节点数设可配置上限，超限返回 E_RESOURCE_LIMIT 或降级并标记降级类别；命令行示例读取本地确定性样本输出含配置版本视图、迁移补全与丢弃明细、旋转角摘要、分块偏差、重算与复用清单、业务码与降级标记的 JSON，并附一次含跨版本迁移与一次含异常注入的演示。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
