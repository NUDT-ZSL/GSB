特殊教育语言训练师要给不同阅读水平的学习者准备同一篇故事的多个版本，教材编辑则要求每一版都能追溯改动了哪些词、为什么改、有没有把关键情节改动。现在手上有一批由固定种子生成的短篇故事，每篇都带句子级事件标注和关键实体，另外还有三套分级标准，分别规定可用词表、句长上限和同义词替换条目。人工改写时经常出现两种情况：为了压句长把事件压掉了，或者替换词之后句子不通顺；配套的 cloze 填空与错词练习还要和改写句逐句对应，否则训练师无法核对答案。本题要求从零搭建一套本地工作台，用一个确定性的掩码去噪评分器对候选改写逐位置打分，在词表与句长约束下选出改写句，再把情节覆盖、练习扰动和可读性核对串成一条可以重复运行、可以逐句复核的流水线。

任务环境与准备：
在 Linux（WSL Ubuntu）上准备 Python 3 运行环境，仅使用标准库实现评分器、约束改写、情节核对、练习生成与可读性核对。
故事集、事件标注、三套分级标准与扰动种子由工作区内确定性生成器产出，运行前先执行生成步骤写入本地文件。

业务要求：
1. 读取按固定种子生成的故事集与三套分级标准，为每篇故事建立逐句处理单元，并按事件标注把关键实体、事件序号与对应句子关联起来，供后续改写与核对共同引用。
2. 实现基于掩码去噪的改写候选评分器：对每个候选替换位置做掩码，用本地确定的上下文词频与位置打分模型还原被遮词，输出逐位置得分作为该候选的语法与语境依据。
3. 在词表上限与句长上限约束下，对每句做约束解码式简化改写，候选来源包括同义词替换、删除修饰成分与拆分长句，选取得分与约束同时满足的最优候选，约束无法满足时保留原句并记录原因。
4. 改写前后按事件标注核对情节覆盖，逐句判断关键实体是否仍在、事件顺序是否保持，对丢失实体或错序的句子标注为需人工复核，并给出丢失项名称。
5. 输出逐句改写账目，每行记录原句、改写句、被删除或被替换的词、替换依据的分级条目引用，使教材编辑能按账目逐条复核。
6. 对通过核对的改写句生成 cloze 挖空练习：依据掩码模型在各位置的可预测度选择挖空位置，输出挖空句与参考答案，并保证同一句的挖空不与关键实体重合。
7. 为每个改写句生成错词扰动句，扰动词须与原词词性一致且在句法位置合法但不合语境，输出原句、扰动句与被扰动位置，作为改错练习并与 cloze 一一对应。
8. 用独立可读性核对器对三套分级标准的改写结果逐一验证词表与句长约束，输出违规句清单与违规条目，并对同一故事重复运行检查结果完全一致。

验收：
以生成器内嵌的事件标注、词表与句长约束核对改写与练习输出，同种子重复运行结果一致。
