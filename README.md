当前是空白工作区，没有现存项目、代码或数据附件，需要从零构建一个面向表格与图表结构化的本地数值读取引擎，并附带可复现的实验环境。业务对象是本地确定性生成的图表图像：由固定种子在固定尺寸画布上绘制带坐标轴的折线图或柱状图，图中数据点或柱体位置、像素坐标与真实数值同时以真值清单（JSONL，字段含 chart_id、chart_kind、canvas_shape、series、points 列表含 pixel_x、pixel_y、value、axis_min、axis_max、tick_pixels）给出。引擎需要完成坐标轴刻度定位、像素到数值的标定、数据点像素定位、数值反算与结构化输出。核心业务矛盾是数值精度与误差传播：刻度像素定位误差会经线性标定放大到数值反算，数据点中心定位误差又叠加其上，任何取整、插值或反算口径的细微差异都会沿链路传播并改变输出的数值与排序。

任务环境与准备：
安装 Python 3.11 及 NumPy、Pillow，使用本地虚拟环境或系统环境均可，不依赖任何在线资源。
在工作区创建项目目录结构与本地样本生成脚本，样本由固定种子确定性生成，真值清单与图像同源产出。
准备一份示例配置（像素口径、门限、容差、误差统计精度）与故障注入参数文件，用于演示异常与降级链路。
确认 Windows 下命令行入口可执行，报告以 UTF-8 写入本地文件，不访问外部服务或账号。

业务要求：
1. 实现确定性的图表图像解析与刻度定位阶段：从固定种子生成的画布像素中定位坐标轴与刻度线像素位置，输出刻度列表及其像素坐标；同一 chart_id、同一输入与同一配置下必须逐字节产出相同刻度集合，同分时按轴方向像素坐标升序打破平局，并校验刻度数量与真值清单声明一致。
2. 实现像素到数值的线性标定与反算层：用刻度像素与真值刻度值拟合线性映射并应用到数据点像素定位结果，输出每个数据点的反算数值；须显式声明斜率截距求解的精度口径与数值域裁剪规则，禁止在未记录口径的情况下对反算值取整或截断，标定退化（刻度像素重合）时返回 E_CALIB_DEGENERATE 并指明 chart_id。
3. 实现数据点像素定位与候选去重：按图形类型（折线折点、柱体顶边中点）提取候选像素位置，对距离过近的候选按固定规则合并，输出每个序列的数据点像素坐标与置信度；须保证同一序列内点按横轴像素升序、不同序列点不混淆，候选数量超上限或序列为空时返回 E_SERIES_INVALID 并指明序列号。
4. 实现沿链路的误差传播计算：以真值清单中的 value 作为观测口径，输出刻度定位、标定拟合、点定位、数值反算各级的绝对偏差、相对偏差、误差区间与误差放大比，并定位主导误差来源为刻度定位、标定或点定位中的哪一级；误差区间顺序不合法或放大比无法由明细重算时返回 E_ERROR_UNTRACEABLE。
5. 实现数值排序与门限判定的稳定性保护：对反算数值设定可配置的最小可信门限与序列内排序，提供严格比较与容差带比较两种策略及次正规数保护，保证恰好落在门限附近的数据点在重复运行下判定不被舍入翻转；门限或容差非法分别返回 E_CONFIG_INVALID 并指明字段，策略变更须在报告中标记。
6. 实现由输入或参数触发的四类异常注入与归因链路：在刻度定位、标定、点定位、反算阶段分别提供注入点（如刻度像素越界、轴范围非正、点坐标落在画布外、序列号重复），注入不得通过修改源码制造；每次注入须产生带阶段名、业务码与 chart_id 的记录，下游降级结果须携带降级类别与触发它的上游业务码，未被归因的异常须汇总到报告。
7. 实现配置、真值与误差统计的版本化快照及整体替换：各快照携带单调递增版本号与内容校验和，检测到版本号或校验和变化时必须整体替换旧快照而非增量修补，旧版本不得覆盖新版本且回退尝试返回 E_SNAPSHOT_ROLLBACK；损坏或校验和不符的快照加载时返回 E_SNAPSHOT_CORRUPT 并指明快照类别与版本号。
8. 提供命令行入口与可复现实验环境，并实现跨阶段一致性自检：读取本地确定性样本跑完整基线，输出含刻度、标定参数、逐点反算值、误差谱、排序结果、业务码与降级标记的 JSON 报告；自检校验各阶段 chart_id 集合一致、反算值可由标定参数与像素坐标重算一致、误差区间可追溯至偏差明细，不一致返回 E_INCONSISTENT 并指出类别；须支持固定种子重跑并比对两次报告哈希一致。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
