当前是空白工作区，没有现存项目、代码或数据附件，需要从零构建一个面向稀疏矩阵乘（SpMM 与 SpMSpM）的本地可集成算子组件与完整示例。业务对象是本地确定性生成的 CSR 稀疏矩阵样本：由固定种子生成行指针、列索引与值数组并序列化为样例清单（JSONL，字段含 case_id、shape_mnk、nnz_a、nnz_b、dtype、seed、写入批次），矩阵按 seed 与批次确定性还原，不依赖任何真实数据集或外部服务。核心业务问题在于矩阵不是一次性给定的静态输入：CSR 结构以若干写入批次逐步到达，每个批次可能向某些行区间覆盖写入新的列索引与值、声明某些行的非零元集合整体失效、也可能只是重复写入相同内容。组件必须在两种失败模式下保持可用：可处理的写入批次被拒绝隔离、以及进程被强制终止后从精确的中间状态继续。不同写入批次可能重叠同一行区间，后到的批次必须依据显式规则决定是否覆盖先到的写入；被覆盖或失效的行区间需要被重新计入，未被触及的行区间必须原样复用而不能被重建，否则行统计量与累加次序会被悄悄改变并污染批量与增量之间的可核对性。系统需要在统一入口下输出乘法结果、逐批写入状态账本、增量重算报告与以 float64 稠密参考实现为真值来源的偏差报告。

任务环境与准备：
安装 Python 3.11 与 NumPy、SciPy（以本地可安装的稳定版为准），无需 GPU 与外部数据集。
在工作区创建包目录与样本生成脚本，按固定 seed 生成 CSR 样例清单与多批次写入序列。
准备 float64 稠密参考实现作为真值来源，并固化容差、并发上限与资源预算参数。
在命令行验证版本回退写入与校验和不符写入两条路径均返回预期业务码且不改变账本。
准备一次强制终止演示脚本，用于验证从已提交检查点恢复后的结果与账本一致。

业务要求：
1. 实现 SpMM 与 SpMSpM 的统一算子入口，按样例清单解析 CSR 形状、nnz、dtype 与写入批次序列；对形状不合法、dtype 不支持、行指针非单调、列索引越界、nnz 声明与实际存储不符分别返回 E_SHAPE_INVALID、E_DTYPE_UNSUPPORTED、E_CSR_STRUCT、E_NNZ_MISMATCH 并指明 case_id 与出错的 CSR 段。
2. 实现写入批次的隔离与版本化接受：每个批次携带单调递增的写入版本号与内容校验和，对同一行区间的重叠写入按显式声明的覆盖规则裁决；版本号回退、校验和不符、行区间越界或批次内列索引重复的写入必须被整体拒绝并返回 E_WRITE_STALE、E_WRITE_CORRUPT、E_WRITE_RANGE 或 E_WRITE_CONFLICT，且被拒绝批次不得改变任何已接受行区间的存储内容。
3. 实现逐行区间的增量重算：由已接受批次计算出受影响行区间集合，仅对这些区间的乘法贡献重算并替换旧贡献，未受影响行区间必须复用已有结果而不得重建；须输出本次重算区间清单、复用区间清单与触发变更的写入版本，并保证重算结果与在同一最终矩阵上一次性全量计算的 float64 结果在声明容差内一致。
4. 实现增量一致性自检：校验重算区间与复用区间无交集且并集覆盖全部行区间、每个行区间的结果可由记录的行局部贡献独立复算、未被任何写入触及的行其贡献摘要逐字节不变；检测到不一致返回 E_INCONSISTENT 并指出 case_id、区间与不一致类别。
5. 实现写入账本的版本化快照与整体替换：账本与行区间结果快照各携带单调递增版本号与内容校验和，检测到版本号或校验和变化时必须整体替换旧快照而非增量修补，旧版本不得覆盖新版本且回退尝试返回 E_SNAPSHOT_ROLLBACK；损坏或校验和不符的快照在加载时返回 E_SNAPSHOT_CORRUPT 并指明快照类别与版本。
6. 实现强制终止后的恢复逻辑：重启时读取最近一次已提交的执行检查点，从该检查点之后继续推进写入批次，已提交检查点覆盖的行区间不得重算或重复计入；未提交的中间写入与部分重算状态必须丢弃并从检查点记录的下一批次起点重建，恢复后的结果与账本须与不间断完整执行逐字节一致；须区分可处理的批次拒绝与强制终止，强制终止后不得承诺生成完整退出报告。
7. 实现多批次并发写入与公共入口的原子性：多个写入批次可并发提交，同一时刻只允许一个批次影响账本，并发冲突时后到者立即获得 E_WRITE_BUSY 而不阻塞等待；查询侧不得读到半应用的批次或新旧混合的行区间结果；为同时驻留的批次数据、行区间中间缓冲与并行重算区间数设可配置上限，超限时按明确策略返回 E_RESOURCE_LIMIT 或降级并标记降级类别。
8. 提供可集成的领域组件与完整示例：暴露 spmm、spspmm、写入提交、增量重算与自检入口，命令行示例读取本地生成样本输出含结果摘要、写入账本、重算与复用区间清单、偏差报告、业务码与降级标记的 JSON 报告，并附一次版本回退写入与一次校验和不符写入的演示。
