在游戏配乐与交互式音乐制作流程中，制作方需要审阅同一段数字乐谱在不同演奏表情参数下的时间轴演进，并检查演奏表达状态（力度、时值伸缩、连断、踏板）是否在多次编辑与中断续算之间保持一致。当前为空工作区，需从零开发一个本地桌面诊断工作台。输入为程序按确定性规则生成的本地样本：一份 JSON 乐谱（音符序列，含音高、记谱起始拍、记谱时值、声部与力度标记）、一份 JSON 演奏表达参数（速度曲线控制点、力度映射曲线、时值伸缩规则、连断规则与踏板段落），以及一份编辑脚本（按顺序描述对表达参数的增删改）。样本全部为本地产物，不依赖任何真实乐器、音频设备或外部资源。工作台须把乐谱按表达参数展开为以整数 tick 计的实际演奏时间轴，展示每个音符的表达状态演进，并在编辑与中断后给出可诊断的一致性结论。

任务环境与准备：
在 Windows 上安装 Python 3.10 或更高版本，并确保 tkinter 可用（通常随官方安装包提供）。
安装 NumPy：执行 python -m pip install numpy，版本 1.24 及以上。
创建工作区目录与 state 状态子目录、输出目录，样本由程序内置的确定性生成器按题目要求生成，不需要任何外部乐谱或音频文件。
确认能够以命令行方式启动本地脚本，并以整数退出码区分正常完成、可处理终止与业务错误。

业务要求：
1. 实现乐谱、表达参数与编辑脚本解析：读取本地 JSON 样本，校验音符音高在 0 至 127、记谱起始拍为非负整数、记谱时值为正整数、声部标识唯一、速度曲线控制点拍位严格递增且速度为有限正数、力度映射曲线控制点单调、编辑脚本算子类型属于允许集合且引用的目标音符或参数存在，非法输入返回带 E_xxx 业务码的 JSON 错误且不产生任何持久化输出。
2. 实现乐谱拍位到整数 tick 时间轴的确定性展开：按每拍 tick 分辨率把记谱起始拍与记谱时值换算为整数 tick，起点取整规则唯一确定且保证同一 tick 上不出现两个同声部重叠音符，跨声部重叠须记录并在报告中按声部对给出重叠 tick 区间；展开结果只依赖乐谱内容与 tick 分辨率，重复展开得到逐音符相同的 tick 结果。
3. 实现演奏表达状态演进：按速度曲线控制点之间的分段线性插值得到每个 tick 的演奏速度，据此把记谱时值伸缩为实际 tick 时长，应用力度映射曲线把记谱力度转换为实际力度值，按连断规则调整音符发音段与静音段边界，并按踏板段落把踏板状态挂到相应 tick 区间；每个音符在每个 tick 的表达状态（活跃或静音、实际力度、当前速度、踏板是否踩下）须可定位查询。
4. 实现编辑脚本逐步重演与依赖失效：为每个 tick 区间的表达状态记录其依赖的速度控制点、力度控制点、伸缩与连断规则及踏板段落，编辑脚本任一步发生后只把受被编辑参数影响的 tick 区间标记为失效并重算，其余区间复用已有结果；增量重演后的整条时间轴须与同输入从头全量重演在逐 tick 实际时长差不超过时长容差、逐音符实际力度差不超过力度容差。
5. 实现分块级持久化与版本识别恢复：按固定 tick 块把时间轴划分为状态块，每块完成后把该块表达状态、依赖摘要与由乐谱内容、表达参数及编辑脚本规范化摘要构成的版本标识原子写入状态目录，先写同目录临时文件再整体替换；再次启动时比对版本标识，一致则复用已完成块并只计算缺失块，不一致则从头重做且不得直接覆盖旧版本状态目录，强制终止后仅依赖已持久化且摘要有效的块恢复。
6. 处理可处理终止信号、强制终止与原子写出：外部可发送可处理终止信号使任务在 tick 块边界写入中断标记并以约定整数退出码退出，未完成块不得留下可被误认为完成的结果；全部分块完成后逐块校验内容摘要，摘要不匹配、缺失或声明 tick 数与实际不符时返回 E_DIGEST 并回退补算，最终诊断报告与展开时间轴须先写临时文件再整体替换，二者要么同时更新要么都保持旧版本。
7. 实现并发分块重算与资源上限：按编辑脚本声明的并发上限使用有界线程池调度待算 tick 块，同时处于计算中的表达状态缓冲与依赖记录总量受内存预算约束，超出预算时按块索引序让后续块等待而非降低 tick 分辨率或缩小时值插值精度；任一块异常时取消其余待处理块并返回首个错误，最终拼装结果须与并发度为 1 时逐 tick 相同。
8. 实现领域可视化与诊断联动：提供本地桌面视图展示展开时间轴上的音符条带、逐 tick 实际力度与速度曲线、踏板状态轨道以及编辑脚本逐步产生的影响范围列表，支持选择音符或 tick 块高亮其依赖参数与失效区间，并显示业务码与摘要校验结论；视图刷新只读取已持久化的确定性结果，不得自行重算表达状态或修改已校验通过块的结果。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地乐谱样本验证时间轴展开、编辑增量重算与中断恢复，逐 tick 结果与全量重演一致并输出诊断报告。
