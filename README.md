当前是空白工作区，需要从零构建一个面向语义与实例分割离线评估的本地引擎，核心业务问题是增量更新与依赖失效。输入为本地确定性生成的样本清单：每张图由固定种子生成的确定性像素数组（RGB，固定尺寸）与真值标注（语义掩码与实例掩码，标注含类别、实例编号、忽略区域标记）组成，另有一份分割预测结果 JSONL（字段含 image_id、predictions：每个预测含类别、置信度、掩码编码、模型版本）。评估流程建模为有向无环图：像素预处理→语义掩码融合→实例候选匹配→指标聚合（mIoU 与实例 AP），每个阶段产出带内容哈希的可持久化快照并写入本地内容寻址缓存。当用户修改某张图的真值、替换某图预测、调整匹配 IoU 阈值或更换指标口径时，只有依赖这些输入的下游阶段需要重算，其余阶段必须复用旧缓存，且缓存键必须对影响结果的输入保持敏感、对无影响输入保持稳定。持久化快照必须识别版本变化并整体替换，损坏条目不得被当作有效结果使用。

任务环境与准备：
安装 Python 3.10 及以上版本，并安装 NumPy（固定版本写入本地依赖清单）。
准备本地确定性样本生成脚本所需的参数文件，样本由固定种子生成，不依赖任何外部数据集或网络下载。
在工作区内创建缓存目录与报告输出目录，确认目录可写。
确认可在本机启动本地进程池执行并行重算任务。
运行示例前执行一次基线评估并保存报告哈希，供后续重跑比对。

业务要求：
1. 实现确定性的分段评估图：把预处理、语义融合、实例候选匹配、指标聚合建成有向无环图，节点数量与连接由配置字典决定；同一输入、同一配置与固定随机种子必须产出逐字节一致的中间掩码、匹配指派与最终指标，禁止依赖除固定种子与显式配置外的任何外部状态。
2. 实现内容寻址缓存与缓存键构造：每个节点产出附带内容哈希的中间产物写入本地缓存目录，缓存键须纳入真值标注摘要、预测掩码摘要、类别集合、匹配 IoU 阈值与上游节点哈希；键相同的请求必须复用快照，键不同必须重算，且键对仅改变无关图像输入的情形保持稳定。
3. 实现增量更新的依赖失效传播：修改单张图真值、替换某图预测、调整阈值或指标口径时，计算受影响节点与受影响图像集合，复用未受影响上游缓存，仅重算受影响后缀；须输出本次重算节点清单与复用节点清单，并保证局部修改的重算集合是完整重跑结果变化集合的超集。
4. 实现忽略区域与实例候选匹配语义：语义指标按配置口径处理忽略区域类别，实例匹配按类别分组、置信度降序做贪心指派，同分按实例编号升序打破平局；须校验忽略区域不参与计分、实例编号不重复、掩码尺寸与图像尺寸一致，违反时返回 E_MASK_MISMATCH 或 E_INSTANCE_DUP 并指明图像。
5. 实现快照版本与整体替换：评估快照携带单调递增版本号与内容校验和，检测到版本号或校验和变化时必须整体替换旧快照而非增量修补；损坏或校验和不符的条目在读取时返回 E_CACHE_CORRUPT 并按明确策略从该节点重算，禁止把部分可解析的损坏数据当作有效结果。
6. 实现资源与并发控制：为单次评估的驻留内存估算、缓存条目总量与并行重算节点数设可配置上限，超限时按明确策略返回 E_RESOURCE_LIMIT 或在受限并发下执行并标记降级类别；多个任务并发写同一缓存键时必须保证只有一个提交生效，后到者不得破坏已提交快照。
7. 实现跨节点一致性自检与异常链路归因：校验图拓扑无环、缓存键与产物哈希互相可核对、复用节点集合与重算节点集合无交集且并集覆盖全部受影响节点、最终指标可由逐图明细重算一致；检测到不一致返回 E_INCONSISTENT 并指出不一致类别与节点，配置非法返回 E_CONFIG_INVALID 并指明字段。
8. 提供可复现的实验环境与命令行入口：读取本地确定性样本跑完整基线与一次增量运行，输出含计算图拓扑、各节点命中或重算状态、逐图指标明细、重算统计、业务码与降级标记的 JSON 报告；支持用固定种子重跑并比对两次报告哈希一致，另附一次注入损坏快照与一次异常输入的演示，仅依赖本地生成样本与本地进程池。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地确定性样本验证增量重算集合正确、复用缓存结果与完整重跑一致，并覆盖损坏快照与异常输入。
