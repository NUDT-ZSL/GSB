当前是空白工作区，需要从零构建面向全景分割（像素掩码）的数据处理管线与结果验证工具，核心业务问题是格式互操作与版本兼容。本地以固定种子生成确定性样本：每张图有固定尺寸 RGB 像素数组与真值，真值以三种版本格式并存——v1 为单通道类别索引掩码（整数矩阵，全图像素仅表达语义类别，无实例信息），v2 为逐像素双通道编码（一个通道存类别标识，一个通道存实例序号，并附像素级置信度浮点矩阵），外部交换格式为 COCO 风格 JSON（RLE 游程编码压缩的像素掩码、类别与实例列表、忽略区标记，并带格式版本号与字节级校验字段）。预测结果以 JSONL 给出，每行含 image_id、模型版本、掩码载荷与置信度。系统需完成跨格式读取与迁移、语义与实例的像素级合并校验、掩码统计评估，并保证任意格式往返后像素级一致。

任务环境与准备：
确认 Windows 环境可用 Python 3.11 及以上版本，使用 python -m pip 安装 NumPy（版本以本地可获取的稳定版为准），其余只使用标准库。
在空白工作区创建工作目录与本地样本目录，用固定种子生成确定性图像像素、真值掩码与预测结果样本，样本不依赖外部数据集或网络。
准备一份包含损坏游程与未知版本头的注入样本，用于命令行演示；不得通过修改源码制造失败。
运行命令使用 python 直接执行本地脚本，报告输出为 UTF-8 JSON 文件，不经由 Docker 或任何容器环境。

业务要求：
1. 实现 v1、v2 与 RLE 外部格式三种读取器，按版本头与字段集分派解析路径，对未知版本返回 E_VERSION_UNSUPPORTED，对头部截断、游程越界、像素总数与图像尺寸不符返回 E_FORMAT_CORRUPT 并指出字段或游程偏移；同一份样本在三种格式下解析出的像素类别与实例编号必须逐像素一致。
2. 实现三种格式的双向迁移器：v1 升级到 v2 时按配置策略补全实例序号与默认置信度，v2 降级到 v1 时按显式声明的冲突合并规则处理同像素多实例情形并记录丢弃明细；RLE 导出按类别与实例分别编码游程；迁移报告须记录每一步的像素变更计数与所用规则。
3. 实现格式往返的像素级一致性校验：任一格式样本经完整往返后在像素类别上必须逐像素相同，v2 往返还需校验实例序号与置信度在声明精度内一致；不一致返回 E_ROUNDTRIP_MISMATCH 并输出首个不一致像素坐标、通道与两端的值。
4. 实现语义与实例的像素级合并校验：全景分割中每个像素只能属于一个类别与至多一个实例，需校验实例像素集合与类别掩码互不越界、忽略区像素不参与计分、实例编号在同图内唯一；违反分别返回 E_PIXEL_CONFLICT、E_IGNORE_LEAK、E_DUP_INSTANCE。
5. 实现掩码评估统计：基于校验后的真值与预测计算语义 mIoU 与实例 PQ 指标，匹配 IoU 阈值与忽略区口径由配置给出，同分时按实例编号升序打破平局；指标须可由逐图逐像素明细独立重算一致，并输出每类与每实例的明细。
6. 实现格式与快照的版本化及整体替换：格式定义与评估快照各携带单调递增版本号与内容校验和，检测到版本变化时必须整体替换旧快照而非增量修补；损坏或校验和不符的格式定义或快照返回 E_SNAPSHOT_CORRUPT 并指明对象名与版本号。
7. 实现资源上限与异常归因链路：为像素总量、RLE 游程数、驻留掩码内存设可配置上限，超限时按明确策略返回 E_RESOURCE_LIMIT 或降级为逐图流式解析并标记降级类别；解析失败、校验失败与评估失败须归因到具体 image_id、阶段名与业务码，禁止静默吞掉异常。
8. 提供结果验证工具与命令行演示：独立复核每个样本的三格式解析结果、往返报告、合并校验结论与评估明细；命令行读取本地确定性样本输出含格式版本、往返变更计数、校验结论、指标明细、业务码与降级标记的 JSON 报告，并附一次注入损坏游程与一次未知版本头的演示。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本验证三格式互转逐像素一致、合并校验与指标可重算，并正确返回各业务码。
