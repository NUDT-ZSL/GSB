当前是空白工作区，需要从零构建一个面向 LLM 参数高效微调（LoRA/Adapter 类）的可交互专业应用与可重复演示，核心业务问题是多任务并行微调的调度与资源预算。业务对象是本地确定性生成的微调任务清单（JSONL，字段含 job_id、base_model_tag、rank、alpha、target_modules、seq_len、batch_size、steps、lora_seed、priority）以及由固定种子生成的确定性张量样本（用 NumPy 按 seed 生成的小规模权重与激活数组，替代真实大模型权重），应用需把每个微调任务建模为可调度的执行单元：按 rank 计算可训练参数量级、按 batch_size 与 seq_len 估算单步激活与梯度驻留、按 base_model_tag 共享只读基座上下文。调度器需在显存容量、并行槽位与总步数预算下决定哪些任务准入、以何顺序执行、共享基座时如何摊销只读开销；被拒或降级的任务必须给出可复现的准入裁决理由，同一任务集与同一配置重跑必须得到逐字节一致的调度计划与训练摘要。任务运行在本机多个 worker 进程上执行，并需支持中途取消与已完成任务的产物保留。

任务环境与准备：
安装 Python 3.10 或以上（仅标准库与 NumPy，NumPy 版本 1.24 以上），确认本机可在 Windows 上创建本地进程池。
在空白工作区创建项目目录，任务只使用本地确定性生成的 JSONL 任务清单与按种子生成的 NumPy 张量样本，不下载任何模型权重或外部数据。
预先说明估算公式所用常数与计量单位需集中存放于项目配置文件，运行演示与自检所需的命令行入口均由本任务自行提供。

业务要求：
1. 实现确定性的 LoRA 参数量与显存占用量化层：按 rank、alpha、target_modules、seq_len、batch_size 与 steps 估算每任务的可训练参数量级、单步激活驻留、优化器状态与梯度驻留，并以整数计量单位与文档化公式输出估算明细；同一任务描述与同一配置下估算必须逐字节一致，公式中任何常数须集中可查且不得依赖外部环境探测结果。
2. 实现多任务并行调度计划器：在给定显存容量上限、并行槽位数与总步数预算下，决定任务准入集合、执行顺序与并行分组；同 base_model_tag 的任务须共享只读基座并摊销其占用，不同 base_model_tag 不得被计入共享摊销；同优先级任务按 job_id 字典序打破平局，使同一任务集与配置重跑得到逐字节一致的调度计划与准入理由。
3. 实现准入裁决与预算冲突取舍：当显存、并行槽位与总步数三者中任一不足时，须按显式优先级规则在任务优先级、参数量级与共享基座收益之间裁决，输出被拒或降级任务的业务码（如 E_VRAM_BUDGET、E_SLOT_BUDGET、E_STEP_BUDGET）与具体缺口数值；降级策略（如降低并行度、延后低优先级任务、缩小 batch_size 重估）须可配置且裁决理由可重放。
4. 实现 worker 进程池执行与结构化异常回传：按调度计划把任务批次分派到本地进程池执行确定性训练（LoRA 更新用固定 lora_seed 的确定性随机投影与梯度步进），分块与归并顺序必须确定性可复现；worker 内估算失败、张量形状不符、数值溢出等异常须以含阶段名、job_id 与业务码的结构化消息回传主进程，禁止以静默空结果替代失败。
5. 实现中途取消与已完成产物保留：允许在任务执行中发起取消，取消须区分可处理的取消信号与不可中断的当前微步；已提交产物的任务在取消后其状态与产物不得丢失，未完成任务的中间状态标记为不可用并须在重跑时从任务起点重建；恢复后的任务摘要须与未被打断执行同一任务集的结果在产物内容上一致。
6. 实现调度快照版本化与整体替换：调度计划、预算账本与训练摘要各携带单调递增版本号与内容校验和，提交时整体替换旧快照而非增量修补；重启加载时识别版本变化并整体替换，损坏或校验和不符返回 E_SNAPSHOT_CORRUPT 并指明快照类别与版本号，禁止使用部分可解析的损坏数据。
7. 实现并发提交与账本原子性：同一时刻只允许一个调度计划提交生效，并发提交冲突时后到者立即获得 E_STAGE_BUSY 而不阻塞等待；预算账本的扣减与释放须原子生效，查询侧不得观察到一半扣减的中间账本，已完成任务不能被旧版本计划回退覆盖或重复计入预算消耗。
8. 实现跨模块一致性自检与可交互应用：校验准入集合与预算账本可核对、共享基座只读占用被恰计一次、训练摘要中的 job_id 集合与准入集合并集一致、被拒任务不出现在执行摘要中；不一致返回 E_INCONSISTENT 并指出不一致类别与 job_id。应用需展示任务清单、准入裁决理由、显存与槽位预算曲线、并行分组、worker 状态、最近业务错误码，并允许触发一次含超预算拒绝与中途取消的本地确定性演示。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
