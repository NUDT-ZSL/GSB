这项需求没有既有代码，需要从零构建一个面向图像修复与风格迁移场景的本地专业应用与可重复演示，核心业务问题是修复区域的增量更新与依赖失效。业务对象是本地确定性生成的图像与修复任务：底图由固定种子生成固定尺寸 RGB 像素数组与结构纹理，修复掩码由种子在底图上圈定若干封闭区域，风格迁移参数以配置字典给出（风格强度、颜色迁移矩阵、边缘保留系数、迭代步数、精度档），修复链路建模为有向无环计算图：掩码区域解析→边界上下文采样→区域内容确定性补全→风格迁移着色→边界融合与全图输出。用户会不断编辑掩码（扩大、缩小、合并区域）或调整风格参数，要求只重算受影响的区域与下游节点，复用其余已提交的区域结果，并保证局部重算后的整图输出与一次性全图重算逐字节一致。所有输入、配置与观测真值均由本地固定种子脚本生成，不依赖网络、真实图像素材或外部服务。

任务环境与准备：
Windows 本地环境，安装 Python 3.11 或 3.12，无需 GPU、容器或外部服务。
执行 pip install numpy；Tkinter 随 Windows 官方 Python 安装包提供，确认 python -c "import numpy, tkinter" 通过。
在工作区创建 samples 目录，提交按固定种子生成确定性底图、掩码与风格配置样例的脚本，以便复现。
准备本地运行说明，包含启动交互应用、触发增量更新演示与全量重算对比的命令，全部在离线环境执行。

业务要求：
1. 实现确定性的修复与风格迁移计算图：掩码区域解析、边界上下文采样、区域内容补全、风格迁移着色、边界融合与全图输出五个节点串联，节点连接与迭代参数由配置字典决定；同一底图、掩码与参数下必须逐字节产出相同中间区域与整图输出，禁止依赖系统时间或进程级随机状态。
2. 实现区域级内容寻址缓存与缓存键构造：每个区域在每节点的产物附带内容哈希落盘，键须纳入底图内容哈希、区域掩码摘要、边界上下文采样半径、风格参数版本与上游产物哈希；键相同必须复用，键不同必须重算，并提供入口按区域标识查询键组成与产物哈希以核对复用是否真实发生。
3. 实现掩码编辑与风格参数调整后的定向失效传播：扩大某区域须重算该区域及其边界融合下游，缩小区域不得使与本次编辑无关的剩余区域结果被判为失效，仅调整风格强度只重算着色节点及其下游；须输出本次重算区域清单、复用区域清单与触发变更的编辑记录，并保证局部重算结果与全量重算逐字节一致。
4. 实现边界融合的一致性口径：区域内像素与区域外像素在融合带上按显式声明的羽化权重过渡，融合权重和须为 1 且不得跨越掩码外区域；逐区域拼接后的整图与一次全图融合结果逐像素相同，检测到差异返回 E_BLEND_MISMATCH 并指出首个差异坐标与所属区域。
5. 实现修复快照的版本化与整体替换：掩码快照、风格参数快照与整图结果快照各携带单调递增版本号与内容校验和，检测到版本号或校验和变化时必须整体替换旧快照而非增量修补；旧版本不得覆盖新版本，回退尝试返回 E_SNAPSHOT_ROLLBACK，损坏或校验和不符返回 E_SNAPSHOT_CORRUPT。
6. 实现并发编辑提交与资源上限控制：同一时刻只允许一次区域增量提交生效，并发冲突时后到者立即获得 E_STAGE_BUSY 而不阻塞等待；为单图区域数、区域驻留像素内存估算与并行重算区域数设可配置上限，超限时返回 E_RESOURCE_LIMIT 或降级为串行重算并标记降级类别，降级不得遗漏任何受影响区域。
7. 实现输入与配置校验链路：重复区域编号、掩码为空或区域越出画布、风格强度越界、精度档未知、迭代步数非正、边界上下文采样半径非正分别返回结构化业务码并指明区域编号与字段；区域级异常须归因到具体节点与区域，不得静默丢弃该区域或以其未修复像素冒充修复结果。
8. 提供本地可交互专业应用与可重复演示，并实现跨模块一致性自检：展示计算图拓扑、各区域缓存命中或重算状态、失效传播覆盖范围、融合带偏差谱、快照版本与最近业务错误码，支持编辑掩码与参数后触发一次演示——增量更新后与全量重算对比；自检校验重算集合与复用集合无交集且并集覆盖全部受影响区域，不一致返回 E_INCONSISTENT。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
