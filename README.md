为文生图与图生图团队构建一个本地可运行的增量重绘与依赖失效工作台。输入是本地一批场景描述样本：每条样本含样本 id、文本提示词、基准种子、尺寸与一组图层定义，图层定义包含图层 id、依赖的父图层 id、局部提示词、重绘区域掩码（以像素矩形表示）与局部种子。工作区为空，需从零创建项目：一个可交互的 FastAPI 服务，对外提供工程创建、按图层触发增量重绘、查询图层与依赖图状态、导出快照与诊断报告的接口。图像合成采用本地确定性伪渲染器：由提示词与种子的哈希生成低频噪声场，再按掩码逐像素叠加父图层，不使用任何外部模型或网络。核心难点是增量更新：当某个图层的提示词、掩码或种子被修改后，只有其本身与所有下游依赖图层需要失效重绘，其他图层必须复用已有结果；若层叠顺序与掩码范围导致下游结果不变，则需按内容指纹判定并避免无谓重绘。所有状态须落盘，以便进程被强制终止后从已提交进度继续。

任务环境与准备：
安装 Python 3.10 及以上版本，创建本地虚拟环境。
在虚拟环境中安装 fastapi、uvicorn、numpy、pytest 等依赖，使用本地 wheel 或离线安装源，不访问外部网络。
准备本地固定样本目录：场景描述 JSON、图层定义与掩码矩形、变更序列文件，全部随项目生成，不依赖外部数据集或模型。
确认 SQLite 使用 Python 标准库自带模块，缓存目录与数据库文件置于工作区本地可写路径。
启动服务与演示命令须为本地可执行，不需要真实账号、GPU 或线上站点。

业务要求：
1. 工程创建接口接收样本列表与图层定义，须校验依赖图：父图层必须存在、不允许自环与环、图层 id 在工程内唯一、掩码矩形须在尺寸范围内且宽高为正，任一非法返回 E_GRAPH 或 E_MASK 业务码并指出样本 id 与图层 id，且不得写入任何工程状态。
2. 须提供确定性伪渲染器，由局部提示词、种子与掩码区域共同派生低频噪声场并可逐像素叠加父图层；相同输入在任何机器与执行顺序下生成的像素结果必须逐字节一致，渲染器不得依赖全局随机状态或系统时间。
3. 图层须记录内容指纹，指纹由其提示词、种子、掩码、父图层指纹与层叠顺序共同决定；触发更新时须沿依赖图计算受影响集合，仅指纹发生变化的图层及其下游进入失效，未受影响图层必须复用已持久化的渲染结果。
4. 须实现失效抑制：对下游图层在继承新父结果后重新计算指纹，若其最终像素与已有缓存逐像素相同，则不得标记为已重绘并复用旧记录，诊断报告中须区分“被失效评估但结果未变”和“实际重绘”两类图层，并给出计数。
5. 变更须支持批量提交：一次请求可同时修改多个图层的提示词、掩码或种子，所有受影响图层须在同一 SQLite 事务中提交像素缓存与指纹版本；事务中途失败不得留下部分更新的图层或半写缓存文件。
6. 每次成功提交须生成整体替换的版本化快照，快照含工程版本号、各图层指纹与像素摘要；查询快照或导出时若检测到缓存文件与数据库版本不一致、或残留旧版本缓存，须返回 E_STALE 并定位到具体图层，禁止汇入旧数据返回看似正常的结果。
7. 进程被强制终止后重启，须从 SQLite 已提交的图层粒度进度继续，核对每个失效图层的指纹与缓存文件摘要，重算未提交图层且不重复渲染已提交图层；恢复后的图层指纹集合、最终合成图与无中断执行须完全一致。
8. 须提供诊断工作台接口与确定性演示入口，输出依赖图结构、本轮受影响集合、实际重绘图层、失效抑制图层数与快照版本序列；演示使用固定样本与变更序列跑出可重复结果，并给出可用等价参数复现的请求示例。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地固定样本验证增量失效范围、失效抑制、快照版本与强制终止后恢复结果一致，并附请求示例与运行结果。
