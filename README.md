当前是空白工作区，没有现存项目、代码或数据附件，需要从零构建一个面向表格分类的本地数值一致性诊断工作台。业务对象是本地确定性生成的表格样本（JSONL，字段含 row_id、若干数值列与类别列、label）以及一份训练配置：模型族（逻辑回归或浅层决策树桩集成）、正则化强度、迭代上限、收敛容差、标准化方式、数值精度档（float64、float32 与定点缩放整数）、定点缩放因子与舍入模式、分块口径。工作台把一次训练建模为多级流水：标准化→分块梯度计算→分块归约→收敛判定与指标汇总。核心业务矛盾在于：分块训练可降低单次驻留内存并便于中断续算，但分块边界处的累加顺序、定点量化与舍入模式会使损失轨迹与最终参数相对整段训练产生偏移，而收敛判定又依赖损失轨迹，任何数值漂移都可能改变停止轮次从而改变结论。因此工作台必须同时给出分块训练与一次性整段训练的结果对照、逐级误差谱与偏差来源定位，并证明每一档精度下的结果可复现。

任务环境与准备：
安装 Python 3.10 及以上，确认标准库 json、hashlib、statistics 可用。
安装 NumPy（建议 1.24 及以上），仅用于确定性数组运算与本地样本生成，不依赖网络或任何外部模型。
在空白工作区创建样本生成输出目录与快照持久化目录，均使用本地文件系统路径。
运行前清空旧的快照与缓存目录，保证演示从空状态开始。

业务要求：
1. 实现确定性的标准化与分块训练核心：数值列按配置做 z-score 或 min-max，类别列按固定规则编码，模型按分块口径分块计算梯度并按显式声明的归约顺序归约；同一输入、同一精度档与同一配置下，损失轨迹、最终参数、收敛轮次与验证指标必须逐字节可复现，且收敛判定须在迭代上限与收敛容差之间记录判定证据。
2. 实现分块训练与整段训练的一致性对照：对同一任务同时产出按分块口径训练的结果与在同一输入上一次性整段训练的结果，逐轮比较损失、逐参数比较系数，输出每轮最大绝对偏差与最终参数偏差谱，并明确两者在收敛轮次是否一致；偏差超出配置容差返回 E_TOLERANCE_EXCEEDED 并指出首轮越界位置。
3. 实现逐级误差谱与主导偏差来源归因：以 float64 整段训练为该快照内的参考真值，输出标准化、分块累加、定点量化、舍入模式与学习率缩放各级的绝对偏差、相对偏差、偏差分位数与误差放大比，并定位主导来源为哪一级，归因须可追溯至具体分块序号与轮次的明细，禁止用汇总值代替明细。
4. 实现可切换精度档的共用算子语义：float64、float32 与定点缩放整数三档共用同一算子语义，定点档的缩放因子与舍入模式由配置显式给出；同一输入在不同精度档下结果差异必须仅来自精度损失本身，切换精度档不得改变分块口径、归约顺序与收敛判定规则，且定点档结果须可由缩放因子与舍入模式重算出。
5. 实现收敛判定与门限比较的稳定性保护：对收敛容差与最小改善门限提供严格比较与容差带比较两种策略及次正规数保护，保证恰好落在门限附近的轮次在多档精度重复运行下判定不被舍入翻转，门限或容差非法分别返回 E_CONFIG_INVALID 并指明字段，策略变更须在诊断报告中记录并保留可对照的两个判定结论。
6. 实现中断续算：允许在轮次边界发起停止，已提交轮次的参数与损失不得丢失，未完成轮次必须丢弃并在续算时从该轮次起点重建；续算后的完整损失轨迹与最终参数须与不间断运行逐字节一致，续算报告须列出已提交轮次与重建轮次；强制终止依赖持久化已提交轮次，不承诺生成退出报告。
7. 实现精度档与统计量快照的版本化管理及整体替换：标准化统计量、分块划分方案、各精度档误差谱与轨迹摘要各携带单调递增版本号与内容校验和，提交时整体替换旧版本而非增量修补；加载时识别版本号或校验和变化并整体替换，旧版本覆盖新版本返回 E_SNAPSHOT_ROLLBACK，校验和不符返回 E_SNAPSHOT_CORRUPT 并指明阶段名与版本号。
8. 实现配置与输入校验链路并提供本地可交互诊断工作台：精度档未知、缩放因子非正或过大、正则化强度越界、分块口径非正、收敛容差非正分别返回 E_CONFIG_INVALID 并指明字段；重复 job_id 与重复 row_id 返回对应业务码；工作台展示损失轨迹对照、逐级误差谱、主导来源、精度档切换对照、已提交轮次与最近业务错误码，并校验各级样本索引集合一致、轨迹与误差谱可重算一致，不一致返回 E_INCONSISTENT 并指出类别。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本验证分块训练与整段训练一致性、逐级误差谱、精度档切换与中断续算，且结果可复现。
