语义与实例分割的部署项目中，真值掩码由三个独立解算器生成，工作目录目前没有代码和样本；需要从零构建一个本地诊断引擎，核心业务问题是固定种子生成的三种解算器输出在格式版本演进下如何互操作，并管理解算器参数修订引起的依赖失效与结果一致性。输入由随工程交付的固定种子脚本在 Linux（WSL Ubuntu）本地确定性生成：每个样本包含固定尺寸 RGB 图像、v1/v2 两代解算器配置快照、v1 单通道实例掩码、v2 类别-实例双通道加置信度掩码，以及一组本地生成的像素级真值模板；系统需统一解析两代解算器配置，按各自口径计算归一化掩码，进行跨版本语义裁决，并在解算器参数修订时精确重算受影响像素区域。

任务环境与准备：
安装 Python 3.10 及以上版本。
运行 pip install numpy 安装 NumPy。
SQLite3 由 Python 标准库提供，无需单独安装。
在 Linux（WSL Ubuntu）上创建空工作目录，输入由固定种子脚本本地确定性生成。

业务要求：
1. 实现 v1 与 v2 解算器配置的读取器，v1 为单文件 JSON 扁平记录类别集合与相对生效秒，v2 为分片 JSON 加 SQLite 元数据库记录类别-实例映射表、置信度阈值与绝对毫秒时间戳；未知版本返回 E_VERSION_UNSUPPORTED，字段缺失或类别集合不合法返回 E_CONFIG_INVALID。
2. 实现两代配置到统一内部表示的迁移器：v1 升级到 v2 时补全实例与类别的显式映射、置信度阈值默认值和校验和，v2 降级到 v1 时对无法表达的实例级置信度按配置的丢弃或展平规则处理；迁移必须记录补全或丢弃明细，且迁移后像素口径不允许改变。
3. 实现确定性的实例掩码归一化与语义归并：对同一像素位置比较两代掩码及真值模板，按显式声明的优先级规则（真值模板大于 v2 大于 v1，同级按实例编号升序）裁决类别和实例归属，生成统一语义账本；同一输入、同一种子与同一配置下账本逐字节一致。
4. 实现解算器参数修订后的定向依赖失效传播：当 v2 配置的类别-实例映射或置信度阈值调整时，按内容寻址缓存键计算受影响像素区域和账本行集合，复用未受影响像素的已提交结果，仅重算受影响后缀；输出重算集合与复用集合的差异覆盖检查，禁止整幅全量重算。
5. 实现像素级误差传播诊断：以真值模板和 float64 解算结果为参考，输出归一化、阈值判决、语义归并各级的绝对偏差、相对偏差与误差放大比，并定位主导误差来源；阈值判决提供严格比较与容差带比较两种策略及次正规数保护。
6. 实现语义账本与配置快照的版本化整体替换及并发提交控制：账本携带单调递增版本号与内容校验和，检测到版本号或校验和变化时整体替换旧快照而非增量修补；同一时刻只允许一个配置快照提交生效，冲突后到者立即返回 E_STAGE_BUSY 且不阻塞等待。
7. 实现强制终止后的恢复逻辑：在像素区域批量边界持久化检查点，检查点记录已完成区域集合、账本版本号和内容校验和；重启后从最近检查点继续，已提交区域不得重算，未提交中间归并状态丢弃并从检查点起点重建。
8. 实现跨模块一致性自检，校验两代配置迁移前后像素口径一致、账本行可由配置与真值模板独立重算、重算集合与复用集合无交集且并集覆盖全部受影响区域；不一致返回 E_INCONSISTENT 并输出首个偏差位置和业务码。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地确定性样本运行两代配置迁移与语义归并，输出含重算集合、误差谱、账本版本与业务码的诊断报告，并验证恢复与自检一致。
