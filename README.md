珠宝镶嵌工艺师与切面设计审核员在定制流程中，要把微距相机从不同角度拍下的宝石裸石照片以及带纸张弯曲的切面设计图纸，展平到同一正视坐标系，才能比对刻面角度、对称性与镶嵌位是否匹配。拍摄图像存在任意视角倾斜和纸张弯曲，手工调整既无法让同一设计的不同拍摄角度展平结果保持一致，也无法说明展平误差有多大。输入是固定种子生成的合成微距图像集：带已知弯曲形态的切面设计图纸、附标定板与刻面参考网格的实物照片、对应的理想正视参考图，以及单应矩阵与弯曲参数真值；输出是校正后正视图像、控制点残差与弯曲模型参数、刻面网格对齐误差报告、超限区域检查视图和可回读的校正参数快照。

任务环境与准备：
准备 Linux（WSL Ubuntu）环境与 Python 3 运行环境，安装 NumPy 用于矩阵运算与图像重采样。
安装 python3-tk 与 Tk 运行库以启动可交互操作界面，在本地图形会话中运行。
运行前由仓库内固定种子样本生成器产出合成微距图像集、标定板与刻面参考网格、理想正视参考图及单应矩阵与弯曲参数真值文件，不依赖外部数据集或网络服务。
在工作目录中直接执行程序入口启动内核与界面，所有读写均落在仓库内相对路径下。

业务要求：
1. 从每张输入图像中定位标定板角点与刻面参考网格交点，按已知的网格间距与行列编号给特征点赋予稳定身份，剔除重复匹配与离群点，求解初始单应矩阵完成粗透视校正，并输出参与求解的内点数量与单应矩阵。
2. 以粗校正图像与已知弯曲形态的控制点网格为输入，拟合薄板样条弯曲校正模型，生成逐像素反向映射表，重采样时采用双线性插值，并允许在三次多项式模型间按残差对比择优，记录所选模型与拟合参数。
3. 对每张图像输出校正后正视图像，同时计算控制点残差与模型拟合误差，按残差分布生成精度报告，报告须逐图像给出残差中位数、最大值与超阈控制点清单。
4. 依据已知弯曲形态计算曲率，曲率超过阈值的区域划为高曲率区，刻面边缘梯度模糊带依据局部对比度判据标注；对这两类区域采用分块自适应重采样，输出分块结果与置信度图。
5. 将校正后刻面网格与理想参考网格按刻面单元建立对应，计算每单元的角度偏差与对称性误差，判定是否在设定阈值内，输出超限区域清单，清单须能定位到具体刻面单元与图像坐标。
6. 支持更换单张图像或修改弯曲参数后，仅重算受影响区域，且与全量重算的映射表和输出图像逐像素一致；未受影响区域保留原结果，差异超出容差时须拒绝增量结果并回退全量重算。
7. 把单应矩阵、弯曲模型系数、映射表摘要与逐图像残差记录保存为可回读的校正参数快照，加载快照后能重现同一校正结果，快照需识别参数版本变化并拒绝不兼容的旧格式。
8. 提供可交互操作界面，能载入图像集、查看粗校正与弯曲校正前后对比、叠加刻面网格对齐结果与超限区域高亮，并在替换图像或修改参数后刷新受影响区域视图。数据语义与质量验证

验收：
以固定种子合成图像及其单应矩阵、弯曲参数和理想参考真值为基准，检验校正像素误差、网格对齐判定、增量与全量逐像素一致以及快照回读重现。
