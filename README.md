在空白工作区构建一个面向本地中文句子的依存句法分析工作台，核心解决并行解析调度与资源预算问题。输入为一份本地确定性句子样本文件（每行含句 ID 与以空格分隔的词及词性标记）、一份本地小型转移依存解析模型参数 JSON（移进、左归约、右归约、结束四类动作的权重向量，词与词性特征哈希表，特征维度与哈希桶数）以及一份调度配置 JSON（线程池最大并发数、每句最大解析步数、全局总步数预算、每句预算配额、超时观测阈值毫秒、批次大小）。解析器采用移进-归约转移系统，在每一步以权重点积打分选择动作，输出每句的依存弧集合（中心词索引、依存词索引、关系类型）、每步动作轨迹与整句解析对数得分。核心挑战在于：多句并行解析共享有限的全局步数预算，需要在保证并行结果与串行执行逐字段一致的前提下，对预算做公平且可审计的分配，在预算耗尽、单句超限与异常输入并存时仍给出可复现结论。工作台还需持久化阶段性解析快照，使中断后恢复结果与不中断运行一致。

任务环境与准备：
安装 Python 3.11 并确保 numpy 可用（pip install numpy）
准备本地句子样本文件、转移解析模型参数 JSON 与调度配置 JSON，均放在工作区 data 目录
准备异常注入配置文件，包含缺字段、越界预算与畸形样本等注入项
在 Windows 本机以命令行运行工作台，使用本地文件系统作为快照与报告存放位置

业务要求：
1. 实现转移解析核心：从模型参数加载四类动作权重与特征哈希表，对每个句子按当前栈与缓冲构造特征向量并做点积打分，以最高分选择动作，同分时按移进、左归约、右归约、结束的固定优先级决断；输出每步动作、得分与栈缓冲快照，并在缓冲耗尽后生成完整依存弧集合与整句对数得分
2. 实现全局步数预算的并行调度器：多句通过线程池并发解析，最大并发数取自配置；调度器按句 ID 稳定顺序分配每句预算配额，并维护全局剩余步数，某句消耗超出剩余全局预算时该句以 E_BUDGET_EXHAUSTED 业务码终止且不产出部分弧；全局预算耗尽后其余未完成句子按句 ID 升序逐一标记为未调度
3. 保证并行解析结果与串行执行逐字段一致：每条解析任务携带由句 ID 与步序号派生的稳定排序键，无论线程完成顺序如何，最终每句动作轨迹、依存弧顺序、同分决断、失败清单顺序与预算扣减序列必须与单线程按句 ID 顺序执行完全一致，并输出可验证的一致性摘要
4. 实现单句超限与死循环防护：每句解析步数超过每句最大解析步数即终止并记 E_STEP_LIMIT 业务码；某句连续动作仅在移进与归约间循环且未减少缓冲时也必须被上述步数上限终止；不得以线程超时描述为已终止解析，超时观测阈值仅用于统计等待时间，实际终止依据为步数上限
5. 实现阶段性快照与恢复一致性：解析阶段与汇总阶段各自以临时文件加原子替换方式持久化快照，快照包含阶段名、配置哈希、模型参数哈希、已完成句 ID 列表与全局已消耗步数及版本号；启动时读取最新快照，若配置哈希或模型哈希不符输出 E_CONFIG_MISMATCH 并拒绝恢复，一致时从已完成句之后继续，最终结果与不中断运行逐字段一致
6. 实现资源观测与预算报告：统计每句已用步数、配额、是否超限、全局预算消耗曲线与线程峰值占用，报告以 JSON 输出且字段名须与需求中的业务码对应；同时输出各句解析对数得分并按句 ID 升序排列，供审计预算是否被公平分配
7. 实现异常隔离与可处理退出：单句在特征构造或打分阶段抛异常时记录句 ID、步序号、阶段名与异常类型到失败清单并继续其余句；收到可处理的退出信号时完成当前句结果落盘与全局步数快照后以整数退出码 0 退出；强制终止后重启仅依据已完整替换的快照恢复，不承诺一定生成退出报告
8. 实现输入与参数注入校验：配置缺字段、并发数非正、预算小于等于零、模型特征维度与哈希桶数不符、样本行词与词性数量不匹配时分别输出 E_CONFIG_INVALID、E_MODEL_SHAPE_MISMATCH、E_SAMPLE_MALFORMED 业务码并进入失败清单；注入样例须携带编号写入报告以证明命中，校验失败不得修改任何已存在快照
