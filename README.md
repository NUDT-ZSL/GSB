潜水训练视频教学制作人员在课程后期要从一组水下拍摄素材里划出章节：素材里既有潜水员缓慢移动造成的渐变画面变化，也有悬浮颗粒纹理引起的帧间抖动，中途还会出现一次浑浊涌入导致整个画面变灰。分析员希望先得到逐帧的镜头切分边界，再为每个镜头评一个能见度分数并分成浑浊等级，最后把能见度接近的连续镜头并成教学段落；浑浊涌入不能和镜头切换混为一谈，否则章节会在浑浊到来时错误断开，学员看到的段落也就与实际水下过程不符。素材本身就是逐帧缩略画面序列（整数像素矩阵）与每帧采样时间戳，附带真实镜头切分标记用于核对，全部由固定种子的确定性生成器产出。

任务环境与准备：
在 Linux（WSL Ubuntu）上准备 Python 运行环境，并安装运行所需的 NumPy。
确保工作目录可读写，样本生成器与结果文件均落在仓库内，不访问网络与外部素材。

业务要求：
1. 从确定性生成器产出的整数像素帧序列与采样时间戳出发，为每帧计算颜色直方图距离与边缘密度变化，合成联合镜头边界度量，并按自适应阈值判定切分边界，输出按帧号排列的边界清单。
2. 依据采样时间戳与相邻帧采样间隔，剔除只持续单帧的假切点并把过短片段并入相邻片段，输出修正后的稳定镜头切分结果，且修正前后边界差异须能逐条列出。
3. 逐镜头用局部对比度与暗通道先验估计能见度评分，并按评分区间划分浑浊等级，输出逐镜头评分、等级与参与计算的关键统计量。
4. 对能见度评分序列做分段常数拟合，把评分相近且相邻的镜头归并为教学段落，并在拟合结果里定位浑浊突变点，输出段落划分与突变时间点清单。
5. 区分镜头切换与能见度突变两类事件：对同一时间点若两种检测都命中，须按边界度量与评分跳变的相对证据裁定唯一事件类型，输出带类型标注的事件表与浑浊涌入区间清单。
6. 生成可复核的分段报告，按段落记录所辖镜头、能见度等级跨度、包含的突变点与事件类型，并确保报告与切分结果、评分清单三方在镜头归属上完全一致。
7. 以固定种子重新生成同一批样本时，切分边界、评分、段落与事件表必须逐项复现；换用另一个固定种子生成不同浑浊分布时，同一套参数仍须给出与之对应的结果而不崩溃。
8. 写出包含样本生成器、内核与报告输出的可运行入口，运行时直接产出结果文件，并在输入为空帧序列或时间戳非单调时给出明确的业务错误码而非静默成功。

验收：
用固定种子样本核对切分边界、能见度评分等级、段落划分与事件类型，并验证两种子下结果可复现且结构一致。
