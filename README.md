当前是空白工作区，没有现存项目、代码或数据附件，需要从零构建一个面向通话场景静音段能量事件归因的本地可集成领域组件与完整示例。业务对象是本地确定性合成的 16kHz 单声道 PCM 通话录音：每条通话由固定种子生成噪声底曲线（含缓慢漂移与若干突变台阶）、若干说话人的语音活动段与静音段，按给定时间轴与增益拼接，并附带帧级观测文件（帧长 20ms，字段含 frame_index、sample_start、sample_end、noise_floor_true、is_speech、speaker_id）与通话清单（JSONL，字段含 call_id、seed、duration_ms、frame_ms、noise_profile_ref）。组件的核心任务不是判断端点本身，而是以帧级观测为真值口径，完成噪声底分段估计、静音段能量事件归因（每个静音段归因到主导噪声源类别，如平稳底噪、设备突变、串入人声残留）、事件时序合并与通话级静音画像统计；噪声底估计窗口与突变检测灵敏度是可调参数，改动参数后必须能精确判定哪些静音段的事件归因需要重算，并对每个已产出的归因结果追溯其估计窗口与噪声底版本。

任务环境与准备：
Windows 10/11，Python 3.10 或以上，仅使用标准库与 NumPy，通过 pip 安装到本地虚拟环境。
工作区为空目录，无需外部服务、账号或网络；通话样本由组件内固定种子确定性合成，运行前确认当前目录可写。
准备本地输出目录用于噪声底快照、追溯记录与 JSON 报告，运行前清空以避免旧版本快照干扰。

业务要求：
1. 实现确定性的噪声底估计阶段：按可配置的估计窗口与滑窗步长对每帧能量做低分位估计，输出逐帧噪声底曲线与窗口覆盖记录；窗口样本数不足或步长为零分别返回 E_WINDOW_INVALID 并指明 call_id 与帧索引，同一 call_id、同一 seed 与同一配置下噪声底曲线必须逐字节一致，且帧边界以样本索引精确确定。
2. 实现噪声底突变检测与分段：在噪声底曲线上按配置的突变阈值与最小持续帧数识别台阶位置，输出噪声底分段（含起止帧、段内估计值与段内离散度）；不得跨越语音活动帧污染分段，违反返回 E_SEGMENT_SPILL 并指出跨越帧，同分段的判定在重复运行下必须稳定不被舍入翻转。
3. 实现静音段能量事件归因：为每个静音段计算段内能量与噪声底估计的偏离量与波动幅度，归因到受控噪声源类别集合（平稳底噪、设备突变、串入人声残留），归因规则与阈值由配置显式声明；归因类别不在受控集合返回 E_SOURCE_UNKNOWN，同一静音段在同一噪声底版本下必须得到相同归因，同分时按类别编号升序打破平局。
4. 实现事件时序合并与通话级静音画像：把相邻且同归因的静音段按最小间隔合并为事件，输出事件时间轴与通话级画像（各类别总时长、事件数、突变次数）；合并后事件须按时间升序、互不重叠且落在通话时长内，越界或重叠分别返回 E_RANGE_OUT 与 E_OVERLAP，画像须能由逐事件明细独立重算一致，不一致返回 E_INCONSISTENT。
5. 实现估计参数变更的影响判定与局部重算：当噪声底估计窗口、突变阈值或归因阈值变化时，计算受影响帧与受影响静音段集合，复用未受影响的上游噪声底区间，仅重算受影响后缀；须输出重算集合与复用集合并保证结果与从零全量重算逐字节相同，不一致返回 E_INCREMENT_MISMATCH 并指出首个偏离的静音段。
6. 实现归因结果的可追溯重放：对任一带事件编号的静音段归因结果，可按其记录查询当时所用估计窗口、噪声底版本、归因阈值版本与帧区间，并用这些记录重放出相同类别与偏离量；追溯信息缺失或重放结果不符返回 E_LINEAGE_BROKEN 并指出缺失项，重放成功时输出所用版本组合与结果摘要。
7. 实现噪声底版本与配置的版本化及整体替换，并实现并发提交控制：噪声底曲线、归因阈值与画像统计各携带单调递增版本号与内容校验和，检测到版本号或校验和变化时必须整体替换旧快照而非增量修补，损坏或校验和不符返回 E_SNAPSHOT_CORRUPT；同一时刻只允许一个估计快照提交生效，冲突后到者立即获得 E_STAGE_BUSY 且已完成快照不得被旧版本回退覆盖。
8. 实现输入校验、资源上限与跨阶段一致性自检：重复 call_id、duration_ms 与帧级观测帧数不符、noise_profile_ref 缺失分别返回 E_DUP_CALL 与对应业务码，为帧数、驻留噪声底区间与追溯条目数设可配置上限，超限返回 E_RESOURCE_LIMIT 或降级并标记降级类别；自检校验各阶段帧索引集合一致、重算集合与复用集合无交集且并集覆盖受影响集合、每个静音段恰被归因一次。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
