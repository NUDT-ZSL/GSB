在空白工作区构建一个面向表格数据的梯度提升树与随机森林集成训练诊断工作台，核心解决集成学习中的数值精度与误差传播问题。输入为本地 YAML 实验配置与按固定种子确定性生成的合成表格数据描述（数值列、类别列、缺失值、冗余列与二分类目标），配置包含树数量、最大深度、学习率、子采样比例与列采样比例、叶子最小样本数、特征分箱数、精度档位、并发数与快照提交间隔。工作台需完成特征分箱、逐棵树训练、集成打分与特征贡献统计，并对训练链路中分裂增益、叶子值、学习率缩放与集成交付求和三个环节的浮点误差传播做逐级追踪。用户可反复调整树参数与精度档位，每次调整后只需重算受影响阶段，最终诊断报告必须与从零串行执行的结果一致。

任务环境与准备：
安装 Python 3.11 与 NumPy、PyYAML、scikit-learn（仅用于数据生成与基线对照，不依赖任何在线资源或真实账号）
在空白工作区创建项目目录，准备本地合成数据描述与实验配置模板
准备异常注入配置样例与诊断报告输出目录，确保无网络依赖即可在 Windows 上运行测试
确认可用线程数与快照输出目录可写，避免使用容器或任何镜像环境

业务要求：
1. 实现配置与数据加载层：读取 YAML 配置与列描述，按固定种子确定性生成表格数据并做缺失值填充与类别编码；对未知列、类型不符、目标列缺失、学习率为负、深度或树数量非正分别输出 E_CONFIG_INVALID 业务码并进入失败清单，合法输入下同一配置与种子必须生成逐元素一致的数据。
2. 实现特征分箱阶段：按配置分箱数对每个数值列做等频分箱，分箱边界以整数索引表示并在并列值时按固定规则打破；输出每列分箱边界、每样本分箱索引与分箱内容指纹，同一列在相同分箱数下多次运行结果必须逐项一致，分箱指纹作为下游所有阶段缓存键的组成部分。
3. 实现逐棵树训练阶段：按配置的列采样与行采样比例以固定种子为每棵树抽取子集，逐节点选择最大增益分裂点，增益计算使用显式运算顺序，叶子值为落入样本残差均值；输出每棵树结构（节点分裂特征、分箱索引、叶子值与样本数）、逐节点增益与树内容指纹，并列增益按特征索引升序决断。
4. 实现集成打分与特征贡献统计：按固定树序与学习率逐棵累加叶子输出得到集成原始得分，再经稳定归一化得到概率；为每个样本按路径记录各特征在每棵树中的分裂贡献并按特征累加汇总；输出每样本得分、逐树贡献向量与特征贡献汇总，同分或零贡献项须保持确定顺序。
5. 实现逐级误差传播追踪：对分裂增益、叶子值、学习率缩放与集成交付求和三个环节，分别以配置精度档位与高一档精度并行计算，输出各环节逐项差值与首次超过配置容差的环节标注；当最终概率在高一档精度下跨过判定阈值时须记录阈值敏感样本及其主导贡献特征，报告区分误差环节归因与阈值敏感两类情形。
6. 实现增量复用与失效判定：为分箱、每棵树训练、集成打分与贡献统计各阶段产物计算由上游内容指纹与参数指纹派生的缓存键；当树数量增加、深度或学习率变更时仅使受影响阶段及其下游失效并纳入重算集合，未失效产物必须直接复用且不得重复训练，复用与失效清单须可审计。
7. 保证增量训练与全量重建的等价性：从任意初始状态执行包含树数量增加、深度调整、学习率变更、特征分箱数变更与并发度变更的编辑序列，每次增量运行得到的最终集成得分、逐树结构摘要、特征贡献汇总与诊断报告，必须与从空白工作区按相同最终配置一次性全量训练的结果逐字段一致。
8. 实现并发训练、阶段快照恢复、异常隔离与诊断报告：以线程池并发训练彼此独立的树，最大并发数取自配置，每个任务携带由树序号派生的稳定排序键，最终树清单、失败清单与贡献汇总顺序须与单线程按树序执行一致；各阶段以临时文件加原子替换持久化快照，恢复时校验版本号与配置指纹，不一致输出 E_CONFIG_MISMATCH；单树训练异常时记录树序号、阶段名与业务码并继续其余树；报告含误差传播归因、阈值敏感样本、复用清单、快照版本与失败清单，并以整数退出码表达成功或失败。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地合成数据验证分箱、逐树训练、集成打分与贡献统计，确认增量与全量重建一致、误差归因正确。
