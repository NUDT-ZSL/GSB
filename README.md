在空白工作区构建一个面向本地确定性样本的多轮对话意图漂移检测诊断工作台，用于会话监控场景下意图判定结果的增量更新与依赖失效分析。输入为一个本地样本目录：会话事件流 JSONL，每行含会话 ID、轮序号、说话人标识、话语文本与时间戳，文本由固定种子程序从受控中英词表生成以控制长度与词面重合；一份漂移检测配置 JSON，含意图词表版本与类别集合、词面折叠规则、滑窗轮数、漂移判分权重、漂移阈值、精度档位、并发数与快照提交间隔；以及一份分批更新计划 JSON，每批可包含若干轮话语的替换、删除与新增，以及意图词表条目增删或漂移判分权重的调整。工作台需完成确定性词面特征抽取、滑窗意图分布估计、漂移判分与告警标注、分批增量更新与全量重建的等价性验证，并在中断后依据版本化快照恢复。难点在于轮次数据变更、词表变更与权重变更引发的失效范围各不相同：轮次变更只影响覆盖它的滑窗与下游判分，词表变更只影响引用被改词条的轮次特征与统计，权重变更只影响判分与告警而不应重算特征，三类失效必须被精确区分且不相互污染。

任务环境与准备：
安装 Python 3.10 及以上版本，并准备 NumPy 1.24 及以上版本（离线 wheel 安装）。
在空白工作区创建样本目录，编写受控中英词表与固定种子生成脚本以产出会话事件流 JSONL、漂移检测配置、分批更新计划与注入配置。
确认工作区具备可写临时目录与原子替换能力，快照与报告均写入工作区内子目录。
准备单线程与多线程两种运行入口参数，以便执行并发与串行结果比对。

业务要求：
1. 实现会话事件流加载与确定性词面特征抽取层：逐行解析会话 JSONL，校验会话 ID 非空、轮序号在同一会话内严格递增且无空洞、话语非空、时间戳可解析；按配置的词面折叠规则归一化话语并切分为词项，以固定哈希函数映射到意图词表类别，输出每轮词项计数向量、命中词条集合与内容指纹；不合法行输出 E_TURN_INVALID 业务码并进入失败清单，不得中断其余行。
2. 实现滑窗意图分布估计与漂移判分：按配置滑窗轮数对每个会话的连续轮次构造滑窗，以窗内词项计数估计意图分布并做稳定归一化，与前序滑窗分布计算确定性距离得到漂移得分，得分按精度档位保留并与漂移阈值比较；输出每窗意图分布、漂移得分、是否告警以及逐词条贡献分解，同分告警判定按窗起始轮序号升序决断，窗口不足轮数时输出可审计的跳过原因。
3. 实现轮次级与词条级依赖指纹：为每轮计算由归一化话语指纹、词表版本、词面折叠规则版本与类别集合派生的缓存键，为每个词条维护引用它的轮次集合，为每个滑窗记录其覆盖轮次与所引用词条集合；当某轮被替换或删除时给出受影响滑窗集合，当某词条被增删时给出受影响轮次集合，且被其他轮引用的词条不得被误判为无关。
4. 实现分批更新的精确失效传播：依据更新计划依次应用轮次替换、删除与新增，以及意图词表条目增删与漂移判分权重调整；轮次变更使覆盖它的滑窗、判分与告警失效，词表变更使引用该词条的轮次特征及其滑窗与下游失效，权重变更只使判分与告警失效而不使特征与意图分布失效；每批输出失效清单，按来源分为轮次失效、词表失效与参数失效三类并给出受影响数量。
5. 保证增量更新与全量重建的结果一致性：从任意初始状态施加任意批次序列后，增量运行得到的每轮词项计数向量、每窗意图分布、漂移得分、告警标记、贡献分解与失败清单排序，必须与从空白工作区按相同最终输入与配置一次性全量运行的结果逐字段一致；比较须在相同精度档位与相同最终输入状态下进行，不一致项须列出具体会话 ID、轮序号或窗起始号与字段名。
6. 实现版本化快照整体替换与强制终止后的恢复判定：每批完成时将特征抽取、滑窗估计、判分告警三阶段产物以临时文件加原子替换方式写盘，以清单文件记录全局版本号、配置哈希、词表哈希、各阶段产物版本与已完成批次号；启动时读取最新快照，配置哈希或词表哈希不符输出 E_CONFIG_MISMATCH 并拒绝续跑；进程被强制终止后仅依据清单中已完整替换的产物恢复并输出恢复点信息，不得承诺生成退出报告。
7. 实现并发处理与串行结果一致性：使用线程池并发执行轮次特征抽取与滑窗判分，最大并发数取自配置；每个轮次任务携带由会话 ID 与轮序号派生的稳定排序键，每个滑窗任务携带由会话 ID 与窗起始轮序号派生的排序键；无论线程完成顺序与并发度如何，最终轮次顺序、滑窗顺序、失败清单顺序与失效统计内容必须与单线程按同样键序执行逐字段一致，并输出并发比对摘要。
8. 实现异常注入隔离与诊断报告输出：以独立注入配置指定缺字段行、轮序号空洞、漂移得分恰好等于阈值、空词项集合、非法权重与词条引用越界等样例，注入项编号写入报告以证明命中；单轮在特征抽取阶段或单窗在估计判分阶段抛异常时记录会话 ID、轮序号或窗起始号、阶段名、业务码与异常类型并继续其余项；每次完整运行输出 JSON 报告，含失效来源统计、边界告警清单、并发比对摘要、快照版本号与失败清单，并以临时文件加原子替换写盘。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本与注入配置验证增量与全量结果逐字段一致、三类失效分类正确及快照恢复，附运行报告。
