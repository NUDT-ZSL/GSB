在空白工作区从零实现一个本地 Kubernetes 声明式配置漂移收敛引擎，用于在确定性样本上复现集群期望状态与实际状态的差异计算、收敛计划生成与规模变化下的算法取舍。本地 JSON 样本给出：期望资源清单（Deployment、Service、ConfigMap 三类对象，含命名空间、名称、副本数、镜像、端口、标签选择器与数据键值）、实际资源清单（由本地模拟器按不同漂移场景生成，含缺失对象、多余对象、字段值不一致、副本数不一致与标签选择器不匹配）、以及收敛配置（每轮最大并发操作数、单对象操作超时预算毫秒、小规模精确比对阈值、大规模摘要比对采样比例、容差参数、逻辑时钟步进）。引擎需计算期望与实际的漂移差异，生成收敛计划（创建、删除、更新、无操作），在并发与超时预算约束下推演收敛过程，并输出每次漂移的判定依据与收敛后的一致性校验结果。核心难点是：当资源规模跨越阈值时必须在逐字段精确比对与基于内容摘要的采样比对之间切换算法，同时保证两种路径对同一漂移给出等价判定；收敛操作之间的依赖（如先创建命名空间相关对象、删除前需确认无引用）与并发预算冲突；以及中断后恢复时不能重复执行已提交操作。

任务环境与准备：
安装 Python 3.11 或以上版本，确认 sqlite3 标准库可用；通过 pip 安装 numpy 用于分层摘要与分位数计算。
在工作区创建 samples 目录，放置本任务自带的期望资源清单、实际资源清单与收敛配置文件（JSON 格式），样本应覆盖缺失、多余、字段不一致与选择器不匹配四类漂移以及规模跨越阈值场景。
确认无需任何网络访问、容器运行时或外部服务；所有对象清单与模拟的实际状态均由本地文件提供。
在执行前运行 python --version 与 python -c "import sqlite3, numpy" 确认依赖可用。

业务要求：
1. 实现期望资源与实际资源清单的解析校验：校验三类对象的命名空间与名称组合唯一、副本数、端口与数据键值类型合法、标签选择器语法可解析、实际资源引用关系闭合；非法对象必须返回明确业务错误码（如 E_BAD_RESOURCE、E_DUP_KEY）并隔离报告，不得中断其他对象的漂移计算。
2. 实现期望与实际的漂移差异计算：按对象身份匹配后逐字段比对，输出漂移类型（缺失、多余、字段不一致、副本数不一致、选择器不匹配）、涉及字段路径、期望值与实际值，结果以稳定排序 JSON 输出，相同输入多次运行必须逐位一致。
3. 实现数据规模变化下的比对算法取舍：当单命名空间对象数或单对象字段数超过配置阈值时，从逐字段精确比对切换到基于内容摘要的分层采样比对，分层摘要须保留可估计的差异召回率与误差上界；切换后输出实际使用的比对模式、切换触发条件及两种模式对同一漂移的判定一致性结论。
4. 实现收敛计划生成与操作依赖裁决：为每个漂移生成创建、删除、更新或维持操作，并依据对象引用关系（如 Service 选择器引用 Deployment 标签、ConfigMap 被 Deployment 挂载）建立操作间先决与互斥约束；计划须满足依赖拓扑序，删除操作必须先确认无存活引用，违反约束的计划不得提交。
5. 实现并发与超时预算下的收敛推演：在同一轮次内按命名空间分组并发执行收敛操作，同时受每轮最大并发操作数与单对象操作超时预算约束；预算耗尽时必须放弃剩余未启动操作并记录放弃原因，已启动操作不得被简单截断为超时，须区分预算内未启动、启动后失败与主动放弃三类结局。
6. 实现基于注入逻辑时钟的收敛轮次状态机与持久化推进：所有超时、重试退避与轮次边界只依赖注入的逻辑时钟毫秒值，不读取系统墙钟；对象在待收敛、收敛中、已收敛、收敛失败、已放弃之间迁移，迁移须依据本轮完整结果与 SQLite 持久化状态裁决，重启后不得凭内存残留决定状态。
7. 实现强制终止后的恢复与幂等提交：把轮次水位、对象收敛阶段、已提交操作摘要、并发占用与逻辑时钟水位以事务原子写入 SQLite；进程在操作执行或轮次提交中途被强制终止后，恢复路径依据持久化状态识别已提交与半提交操作，只重做未提交操作且不得重复执行已提交操作，重复提交相同操作结果必须幂等。
8. 实现收敛结果一致性校验与可重复命令行演示：收敛完成后重新计算期望与实际的新差异，校验差异集合为空或仅含被显式放弃的对象，并输出每个风险对象的判定依据链；提供 load、diff、plan、apply、resume、status、verify 子命令，status 以稳定排序 JSON 输出各对象收敛阶段、当前比对模式与逻辑时钟水位，verify 校验持久化状态与收敛结论一致。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
