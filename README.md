户外露营教学应用的三维内容制作人员需要把帐篷杆件、折叠炉具、背包织带等装备的高精度三角网格压缩成移动端可实时加载的轻量资产包，学员在交互教学中点选部件查看搭建步骤。同一装备存在多套导出网格：顶点顺序、拓扑索引位宽、属性分量排列不一致；帐篷杆件细长、炉具支架棱角尖锐、背包织带材质通道在量化边界附近波动。若直接均匀量化，杆件会因量化步长过粗而变细，支架棱角错位，材质颜色偏移，导致部件拾取与结构辨识失真。为此需要一套本地可复现的内核，在给定压缩预算与误差容限内完成自适应量化编码、解码重建、几何与材质误差评估、按部件拾取索引构建，并支持步骤切换后仅重建受影响部件。

任务环境与准备：
准备 Linux（WSL Ubuntu）工作目录，确保 Python 3 运行环境和 NumPy 第三方包可用；使用 Python 标准库 sqlite3 访问本地 SQLite 数据库文件。
题目自带确定性露营装备模型生成器，按固定种子在本地生成多套导出的三角网格与材质属性文件，不依赖网络或外部数据集。

业务要求：
1. 读取同一露营装备的多套网格导出文件，将顶点坐标顺序、法线分量顺序、纹理坐标与材质属性分量顺序归一为统一内部网格模型；索引位宽不同时按实际索引值重排顶点顺序，输出归一网格与每个顶点的来源导出标识及原始顶点序号。
2. 基于归一网格各部件包围盒尺寸与曲率估计，为每个部件自适应分配顶点坐标量化位深，保证量化步长不超过该部件外观误差容限对应的局部尺度上限，同时满足全局存储预算；输出逐部件量化参数与位深分配依据。
3. 按分配的位深对顶点坐标执行基于包围盒的均匀量化，对归一网格的三角形索引做差分编码并记录索引位宽，生成包含量化几何、属性编码与索引重建数据的轻量资产包。
4. 对顶点法线与材质属性逐通道做量化，并计算从量化值到原始值的残差补偿量写入资产包；解码重建装备几何与材质外观，输出重建三角网格与材质属性数组，其中法线需重新单位化。
5. 以重建顶点到原始网格最近三角形的点面距离统计几何误差，以角度偏差统计法线误差，以材质基础色、粗糙度、金属度的逐通道偏差统计外观误差；按部件分别判定是否满足教学辨识容限，输出误差报告并标记超限部件。
6. 依据原始网格按部件建立包围体拾取索引，对每个部件记录包围盒与占位三角形集合；给定教学交互射线与命中部件，输出命中结果与高亮轮廓所需的部件边界环，并验证细长杆件与尖锐棱角部件的拾取命中不因量化而丢失。
7. 在教学步骤切换或单部件量化参数修改后，仅解码重建受影响部件，其余部件直接复用已提交资产包中的解码结果；输出局部重建结果并与全量重建结果逐部件比较顶点位置与材质属性，确保一致。
8. 将轻量资产包、逐部件量化参数、误差报告与部件重建检查点持久化到本地 SQLite 数据库；支持从已提交资产包恢复并续算局部重建，恢复前后对相同步骤切换序列产生相同的逐部件输出。

验收：
通过固定种子生成的露营装备工程，核对归一网格、自适应位深、解码重建、误差报告、拾取命中及局部重建与全量重建一致性。
