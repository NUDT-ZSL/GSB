验收清单已经先行下发，要求在 Windows 本机空目录里从零做出一个程序化网格地形分块离屏渲染引擎，并对逐分块渲染任务做并行调度与双预算裁决。输入为一份 JSON 渲染任务描述与固定种子脚本生成的本地样本：地形网格行列数与各轴世界尺度、每个格点的整数高度值、两盏方向光方向与环境光系数、正交相机参数与输出分辨率、每像素超采样数、分块规格、并发上限、每轮逻辑时间预算、在途高度采样缓冲内存上限、分块状态目录，以及一份按追加批次到达的地形编辑清单（局部抬升、压低、平滑某矩形区域）。用户先请求预览某个分块再请求其余分块，分块级缓存让预览很快，但分块边界处的梯度、法线与光照必须与整幅渲染完全同口径，且当地形编辑以更高批次追加时只能重渲受影响的分块，追加结果须与从零全量渲染逐像素一致。

任务环境与准备：
安装 Python 3.11 或 3.12，执行 pip install numpy 与 pip install pytest；标准库自带 sqlite3 与 json，无需外部数据库或渲染库。
在 Windows 工作区根目录创建项目骨架与 samples 目录，用随题交付的固定种子脚本生成地形网格 JSON、渲染任务描述、地形编辑追加清单与异常注入清单，不依赖网络、账号或外部资产。

业务要求：
1. 实现渲染任务描述与地形样本的解析校验：读取 JSON 与网格数据文件，校验行列数为正整数、各轴世界尺度为有限正数、高度为有限整数且数量与行列数一致、分块规格完整覆盖输出分辨率、超采样数为正整数、相机上方向与视线不平行；非法输入返回带 E_xxx 业务码的 JSON 错误且不产生任何输出文件。
2. 实现整幅坐标系下的梯度与法线求取：任意格点的法线由其在全局格索引中的相邻高度差按各轴世界尺度换算得到，网格边界格采用确定的一侧差分规则，分块边界处必须跨块取真值而不是退化为块内局部差分；同一格点无论被哪个分块引用，法线必须逐分量完全相同，也不得随分块划分或调用顺序变化。
3. 实现逐超采样点的地形表面求交与着色：沿相机视线在毫米世界坐标中步进求首个地形表面交点，采样点换算回全局格索引后做双线性插值取高度，按插值法线与两盏方向光计算兰伯特项再加环境光，输出灰度图与以世界单位表示的高度深度图；每块只读高度场与相机参数，重复渲染同一分块须逐像素相同。
4. 实现并行调度、单轮逻辑时间预算与在途内存预算的联合裁决：按并发上限使用有界线程池调度分块，同时处于计算中的分块高度采样缓冲总量不得超过内存上限；按可注入逻辑时钟计量每轮耗时，超出单轮预算即结束本轮并让出未准入分块，准入与延后序列须由分块处理量与预算确定性决定，使任意并发度下的轮次与准入顺序可复现。
5. 实现地形编辑的依赖记录与失效闭包：为每个分块记录其覆盖的全局格索引范围及因法线求取而依赖的邻接格扩展范围，追加编辑清单中的每次编辑只把依赖范围与该矩形相交的分块标记失效，其余分块复用已持久化结果；报告须逐条列出失效理由、重渲块数与复用块数，且增量重渲结果与同输入从零全量渲染逐像素一致。
6. 实现分块级持久化与版本识别：每个分块完成后把灰度、深度、依赖摘要与由地形高度内容、相机与光照参数规范化摘要构成的版本标识写入状态目录，先写同目录临时文件再整体替换，替换前比对已有分块的版本标识，标识变化时不得直接覆盖而须先归档旧结果，避免新旧分块混合。
7. 处理可处理终止信号与强制终止的差异并原子写出：可处理终止信号只在分块边界生效，写出中断标记并以约定整数退出码退出，未完成分块不得留下可被误认为已完成的结果；强制终止后重启仅依据已持久化且摘要有效的分块恢复且不承诺生成退出报告；最终图像与深度图先写临时文件再整体替换，替换前读取已有输出的尺寸与摘要版本信息。
8. 实现异常注入下的错误链路与摘要校验：按描述中的异常清单在指定分块注入高度数量不符、分块不可整除、损坏的分块摘要与越界编辑矩形，引擎须对受影响分块返回可区分的业务码并继续处理其余合法分块；恢复时逐块校验摘要，不匹配、缺失或声明像素数不符时返回 E_DIGEST 并回退补渲，不得静默使用失效块。
