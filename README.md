在空白工作区构建一个可集成的语音端点检测（VAD）领域组件与完整示例，用于本地确定性语音样本的语音段切分与可复现验证。输入为本地合成的多段 WAV 音频（16kHz 单声道 16bit PCM，由固定种子程序生成：平稳底噪、若干段带包络的谐波语音片段、段间静音及少量突变pop噪声），另提供一份 VAD 配置 JSON（帧长与帧移毫秒、能量门限、过零率门限、频谱平坦度门限、双门限迟滞参数、最短语音段与最短静音段毫秒、噪声底估计窗帧数、并发数）以及一份异常注入清单 JSON（按样本名与帧序号指定注入项）。组件需完成逐帧特征计算、双门限状态机判决、端点合并与后处理，输出语音段列表及可复现诊断报告。核心难点在于判决状态机在迟滞带来的状态依赖、并发结果与串行一致性、恢复快照与配置版本识别之间的强耦合，且异常注入必须真实改变输入数据而非修改源码制造失败。

任务环境与准备：
安装 Python 3.11 及 NumPy、soundfile 等纯本地依赖，全程不依赖网络服务与容器环境。
准备本地确定性 WAV 样本生成脚本与注入清单，样本内容、底噪与语音片段位置由固定种子确定。
准备 VAD 配置 JSON 与异常注入清单 JSON 样例，字段与题面业务码一一对应，运行前确认目录可写。

业务要求：
1. 实现音频读取与逐帧分帧层：扫描输入目录下所有 WAV 文件，校验容器头、采样率、声道数与位深，不合规时输出 E_AUDIO_FORMAT 业务码并进入失败清单；按配置帧长与帧移切帧，末帧不足帧长时按补零处理并在帧记录中标记补零标志；帧序号从 0 开始，时间戳以整数毫秒由帧号与帧移换算，禁止浮点累积误差
2. 实现逐帧特征计算：对每帧计算短时能量（均方根，以自然对数为单位）、过零率与频谱平坦度（几何均值与算术均值之比），所有特征以 float64 计算并按配置保留有效位数写入结果；平稳底噪样本上的统计量必须在多次运行中逐位一致，特征计算不得引入随机性
3. 实现双门限迟滞状态机：以噪声底估计窗帧数给出自适应低门限，结合配置中的高门限与迟滞参数实现静音、疑似语音、语音、拖尾四个状态的转移；状态转移表须显式输出每帧所处状态与触发转移的判据；同分或门限边界相等时按固定优先级决断，保证连续帧判决只依赖当前状态与当前帧特征
4. 实现端点合并与后处理：将状态机判定的语音区间合并，短于最短语音段的区间丢弃，短于最短静音段的间隔并入相邻语音段，首尾静音裁除；输出每段起始帧、结束帧、起始毫秒、结束毫秒与段内平均能量；区间合并后的段列表与裁除记录须可追溯，裁除原因使用固定业务码 E_SEG_TOO_SHORT 与 E_GAP_MERGED
5. 实现异常注入实验台：按注入清单对指定样本的指定帧施加真实输入扰动（单帧幅度突变、连续帧削波、全静音片段、采样值非有限数），注入项编号写入报告以证明命中；非有限采样值必须在读取阶段输出 E_NONFINITE_SAMPLE 并使该样本进入失败清单，不得因数值异常而崩溃整个运行
6. 保证并发执行结果与串行一致：使用线程池并发处理多个音频样本，最大并发数取自配置；每个样本任务携带由文件名派生的稳定排序键，无论线程完成顺序如何，最终样本顺序、帧记录顺序、语音段顺序与失败清单顺序必须与单线程按文件名字典序执行逐字段一致，并输出并发与串行比对的摘要
7. 实现阶段快照与恢复一致性：特征计算与端点判决各阶段以临时文件加原子替换方式持久化快照，快照包含阶段名、配置哈希、注入清单哈希、已处理样本游标、部分结果摘要与版本号；重启时读取最新快照并校验版本号与配置哈希，不一致则输出 E_CONFIG_MISMATCH 拒绝恢复，一致则从游标继续且最终结果与不中断运行完全一致
8. 实现诊断报告与退出语义：每次完整运行生成 JSON 报告，包含各样本语音段列表、每帧状态轨迹摘要、噪声底估计值、注入项命中清单、并发比对摘要、快照版本号、配置与注入清单哈希及失败清单；报告以临时文件加原子替换写盘；收到可处理的退出信号时完成当前样本结果与快照落盘后以整数退出码 0 退出，强制终止后仅依据已持久化快照恢复

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地合成 WAV 与注入清单验证端点判决、并发与串行一致及快照恢复，附运行结果与诊断报告。
