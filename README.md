当前是空白工作区，没有现存项目、代码或数据附件，需要从零构建一个面向搜索推荐场景 CTR 预估的本地数据处理管线与结果验证工具。业务对象是本地确定性生成的曝光日志与特征字典：曝光样本 JSONL 每行含样本标识、用户特征向量索引与取值列表、候选物品特征索引与取值列表、交叉特征槽位、点击标签；特征字典 JSONL 给出每个特征索引的维度、类型与取值基数。管线把一次 CTR 训练建模为多阶段流水：样本分片摄入与校验→特征散列与交叉特征展开→分块梯度计算→分块归约→收敛判定与 AUC/LogLoss 指标汇总，核心业务问题是这条流水在限定 worker 数与计算预算下的并行调度，以及分块口径与整段口径之间必须可核对的一致性。

任务环境与准备：
安装 Python 3.10 及以上版本，并安装 NumPy；无需 GPU、外部服务或网络访问。
在工作区预留可写的本地数据目录与缓存目录，用于存放生成的样本、特征字典与快照文件。
确认可用本地进程池（multiprocessing）执行并行任务，先以单个 worker 跑通小规模样本。
准备本地确定性样本生成脚本入口，使同一随机种子可重复生成曝光日志与特征字典。

业务要求：
1. 实现确定性的样本摄入与特征展开阶段：按样本标识升序读取曝光样本，依据特征字典解析用户与物品特征索引，校验索引存在、取值维度合法与交叉槽位可解析，展开为定长稀疏特征向量；同一输入与同一字典版本下必须逐字节产出相同的特征向量与非零索引顺序，禁止依赖字典遍历顺序或系统时间。
2. 实现分块梯度计算与显式归约顺序：按可配置分块大小把样本切块，每块计算损失与梯度并按声明顺序归约，同一分块口径与同一配置下每轮损失、梯度与最终系数必须逐字节可复现；同时产出一次性整段训练的对照结果，输出每轮最大绝对偏差与最终参数偏差谱并标注收敛轮次是否一致。
3. 实现并行调度层：按可配置 worker 数与每批样本数把分块分配给本地进程池任务，分块边界、任务派发顺序与归并顺序必须确定性可复现；worker 内异常须以结构化业务码与阶段名回传主进程并归因到具体批次与分块序号，单块失败不改变其他块已产出的结果。
4. 实现计算与内存双预算准入裁决：按样本数、特征非零数与分块数估算每批代价，在总乘加预算与驻留内存预算内决定准入集合与分块规模，超限时返回 E_COMPUTE_BUDGET 或 E_MEMORY_LIMIT 并按明确策略降级到受限模式；受限模式须在结果中标记降级类别，且不得改变已准入样本的计算口径。
5. 实现精度、资源与进度之间的冲突裁决：当放大分块减少归约开销但逼近驻留内存、增加 worker 缩短整体耗时但分摊预算、缩小特征维度降低内存但损失交叉表达能力时，须按显式优先级规则裁决，并在调度报告中记录裁决依据、各批次所走路径与取舍理由，同一观测下裁决结果必须可复现。
6. 实现跨阶段一致性自检与结果验证工具：校验各阶段样本标识集合完全一致、分块归约中间量可重算出最终系数、AUC 与 LogLoss 可由逐样本分数明细独立重算一致、被拒样本不出现在训练摘要中；检测到不一致返回 E_INCONSISTENT 并指出不一致类别与首个偏差位置，验证工具须能处理降级模式输出。
7. 实现调度计划、预算账本与训练摘要的版本化快照及整体替换：三者各携带单调递增版本号与内容校验和，检测到版本号或校验和变化时整体替换旧快照而非增量修补；重启加载时识别版本变化并整体替换，损坏或校验和不符返回 E_SNAPSHOT_CORRUPT 并指明对象名与版本号。
8. 实现并发提交控制与配置输入校验链路：同一时刻只允许一个调度计划提交生效，并发提交冲突时后到者立即获得 E_STAGE_BUSY 而不阻塞等待，账本的扣减与释放须原子生效；分块大小或 worker 数非法、特征字典维度非正、重复样本标识、标签非零一分别返回 E_CONFIG_INVALID 或 E_DUP_SAMPLE 并指明字段。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地确定性样本验证分块与整段训练一致性、并行调度、预算裁决及异常码，并附运行结果。
