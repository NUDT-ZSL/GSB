在空白工作区构建一个面向本地确定性样本的指令微调数据构造与诊断工作台，核心解决指令样本合成与打分过程中的数值精度与误差传播问题。输入为一个本地样本目录：基础指令种子（JSONL，每条含任务类型、指令模板、可选输入槽位与参考答案），本地小型词表与子词切分规则文件，一份构造配置（每任务类型的目标样本数、模板变体权重、槽位填充来源权重、答案质量打分权重、长度惩罚系数、去重相似度阈值、精度档位、并发数），以及一份打分参数表（各质量维度的权重与基准分）。工作台需完成：按权重确定性采样模板变体与槽位内容生成候选指令样本；用预置打分参数表对每条样本做多维度质量打分并做加权求和；在单精度与双精度档位下计算得分、长度惩罚与相似度，输出可复现的中间量；基于子词相似度做近重复样本剔除。难点在于质量总分由多个连续量加权合成，长度惩罚与相似度阈值判定会放大中间误差，导致同一配置在不同精度档位下产生不同的保留样本集合，且模板权重与槽位权重共同决定采样分布，必须在误差传播链路中可观测、可诊断、可复算。

任务环境与准备：
安装 Python 3.11 及以上版本，并安装 NumPy，确认 python 与 pip 可在命令行直接调用。
在空白工作区创建项目目录，准备本地样本子目录，自行生成种子 JSONL、词表与子词规则文件、构造配置、打分参数表与注入配置，所有文件使用 UTF-8 编码。
确认运行环境无网络依赖，所有样本与配置均由本地确定性生成或手工提供，不使用真实模型或外部数据。
在 Windows 命令行下测试线程池并发与信号处理路径，确认可处理退出路径与强制终止路径均可单独触发以观察恢复行为。

业务要求：
1. 实现确定性样本生成器：读取种子 JSONL、词表与构造配置，按任务类型目标数与模板变体权重、槽位填充来源权重做加权采样，随机源为输入种子指纹派生的固定种子，同一配置与输入必须产出完全相同的候选样本序列；每条候选携带样本 ID、任务类型、模板变体 ID、槽位来源、生成序号与采样权重，权重为零或目标数为零的任务类型不得产出候选并记录跳过原因。
2. 实现多维度质量打分器：按打分参数表对每条候选计算指令清晰度、答案正确性、格式合规性与长度合规性四个维度的分数，各维度分数由本地确定性规则和长度惩罚系数共同决定，再按权重加权求和得到总分；所有打分以可配置精度档位（单精度或双精度）执行，输出每维度中间量、加权分量与总分，浮点运算顺序固定以保证同一档位下逐位可复现。
3. 实现精度档位对比与误差传播追踪：对每条候选分别在单精度与双精度档位下完整计算得分链路，输出两档位各维度分数、加权分量与总分的差值，并逐级标注误差来源（维度打分、长度惩罚、权重乘法、加权求和）；当总分差值超过可配置阈值时标记为精度敏感样本，报告中须给出敏感样本清单及其首个超阈值环节。
4. 实现长度惩罚与相似度阈值的边界判定诊断：长度惩罚按分段线性函数计算，相似度按子词集合的 Jaccard 系数计算；对每个恰好落在惩罚分段点或去重阈值附近的候选，输出其双精度参考值与两档位判定的差异，若两档位在是否触发惩罚或是否判为重复上结论不一致，必须记录 E_PRECISION_DIVERGENCE 业务码与候选 ID 到诊断清单，且去重结果以双精度参考判定为准。
5. 实现近重复剔除与代表样本选择：基于子词相似度对候选做近重复分组，同组保留总分最高者，总分相同按双精度参考总分再比较，仍相同按样本 ID 字典序决定；被剔除样本须记录其代表样本 ID 与相似度值，分组结果与执行顺序无关，且不得因并发调度改变任何样本的保留判定。
6. 实现并发构造与串行结果一致性：使用线程池并发执行候选打分与相似度计算，最大并发数取自配置；每个候选任务携带由样本 ID 与处理阶段派生的稳定排序键，无论线程调度顺序如何，最终样本输出顺序、诊断清单顺序、剔除清单顺序与报告内容必须与单线程顺序执行逐字段一致。
7. 实现阶段快照与中断恢复一致性：生成、打分、去重三个阶段各自以临时文件加原子替换方式持久化快照，快照含阶段名、配置哈希、打分参数哈希、精度档位、已处理游标、结果摘要与版本号；启动时读取最新快照并校验版本，配置或参数哈希不符时输出 E_CONFIG_MISMATCH 并拒绝恢复，一致时从游标继续，恢复后的最终样本集与诊断报告须与不中断运行完全一致。
8. 实现异常注入隔离、退出语义与诊断报告：以独立注入配置指定缺字段候选、越界权重、空子词集合与故意超阈值精度敏感样例，注入项编号写入报告以证明命中；单条候选在任一阶段抛异常时记录样本 ID、阶段名、业务码与异常类型到失败清单并继续其余候选；收到可处理的退出信号时完成当前阶段快照后以整数退出码 0 退出，强制终止后仅依据已持久化快照恢复；最终报告 JSON 含各任务类型实际样本数、保留与剔除数、精度敏感清单、边界诊断清单、失败清单、快照版本号与各阶段耗时，并以临时文件加原子替换写盘。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
