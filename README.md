在空白工作区构建一个面向本地确定性样本的多模态图生文（图像到文本描述）互操作与版本兼容诊断工作台。输入为程序生成的 PNG 图像样本（固定分辨率，画面含几何图元、颜色块与噪声，由固定种子生成描述真值）、一份图像区域关系表（声明区域之间的包含、并列、遮挡关系）、一份描述生成配置（区域特征量化档位、描述模板权重、置信度阈值、格式版本目标、并发数），以及两个版本的描述交换文件：v1 为按固定宽度字段拼接的纯文本行（字段含实例 ID、类别、边界框的四个整数坐标与置信度千分比整数），v2 为 JSON 数组（含实例 ID、类别、边界框浮点坐标、置信度 0 至 1 浮点、区域关系引用列表与命名颜色表）。两种格式在坐标精度、置信度表示、关系表达能力与元数据上不等价。工作台需完成图像区域特征抽取与确定性分类、描述生成、双版本序列化与反序列化、格式互转与信息保留、跨版本渲染一致性校验，并输出可复现诊断报告。

任务环境与准备：
安装 Python 3.11 及以上版本，并安装 numpy 与 Pillow 依赖（可用 pip 安装），无需联网模型或 GPU。
准备本地确定性样本：脚本按固定种子生成 PNG 图像、区域关系表、描述生成配置、v1 纯文本描述文件与 v2 JSON 描述文件。
准备独立注入配置 JSON，覆盖缺字段行、非法 JSON、边界框越界、置信度超出范围与关系引用悬空样例。
在 Windows 控制台确认可写入工作目录与临时目录，用于快照目录与 manifest 的原子替换。

业务要求：
1. 实现图像区域加载与特征抽取：扫描输入目录下 PNG 样本，校验容器头与尺寸，按配置的区域划分规则（颜色连通域）切出候选区域，计算每个区域的面积、平均颜色、边界框与形状紧凑度特征；面积为零或超出图像边界的区域记 E_REGION_INVALID 并进入失败清单，合法区域的边界框坐标以整数像素表示并做裁剪。
2. 实现基于区域特征的确定性类别判定与置信度计算：依据配置中各类别的特征阈值与权重，对每个区域做加权打分并取最高类别，同分按类别名称字典序决断；置信度以整数千分比表示并裁剪到 0 至 1000；判定结果须记录每个区域的得分分解，同一图像在任意运行中必须得到逐字段一致的类别与置信度。
3. 实现双版本描述交换文件的解析器与统一中间表示：v1 纯文本行按固定宽度字段解析出实例 ID、类别、整数边界框与千分比置信度；v2 JSON 解析出实例 ID、类别、浮点边界框、0 至 1 浮点置信度、区域关系引用与命名颜色表；统一转换为以整数像素为坐标、千分比置信度为标量的中间表示，并保留来源版本号与原始精度信息；解析失败按 E_PARSE_INVALID 记录行号或数组索引。
4. 实现格式双向转换与信息保留策略：v1 升 v2 时将整数坐标与千分比置信度转换为浮点并生成默认命名颜色条目，把整数来源标记写入旁路元数据；v2 降 v1 时对浮点坐标做四舍五入到整数并重新计算千分比置信度，把逐区域舍入残差与丢失的关系引用汇总写入降级损失清单；转换后再反向转换必须能还原出原版本的关键字段，降级损失清单须可审计。
5. 实现跨版本渲染一致性校验与边界诊断：对同一内容的 v1 与 v2 描述分别反序列化并渲染为覆盖图（在空白画布上按类别颜色填充边界框），计算逐像素通道最大差与差异像素数；对每个置信度恰好落在判定阈值附近或坐标舍入差恰为半个像素的区域，输出其双精度参考值与两版本判定差异，差异归属记录为 E_BOUNDARY_SENSITIVE 并写入诊断报告。
6. 实现版本化快照整体替换与恢复一致性：以 manifest 记录全局版本号、配置哈希、关系表哈希、各区域描述版本与覆盖图版本，写入时先落临时目录再整体替换；启动时以 manifest 版本号、配置哈希与关系表哈希判定是否命中，版本不符须整体重建而非混用新旧产物；收到可处理的退出信号时完成当前区域描述落盘与进度记录后以整数退出码 0 退出，强制终止后仅依据已完整替换的 manifest 恢复。
7. 实现并发处理与串行结果一致性：使用线程池并发执行区域特征抽取、类别判定与描述序列化，最大并发数取自配置；每个区域任务携带由图像文件名与区域序号派生的稳定排序键，无论线程完成顺序如何，最终区域列表顺序、描述输出顺序、降级损失清单顺序与失败清单顺序必须与单线程按文件名及区域序号顺序执行逐字段一致。
8. 实现异常注入隔离与诊断报告输出：以独立注入配置指定缺字段行、非法 JSON、边界框越界、置信度超出范围与关系引用悬空等样例，注入项编号写入报告以证明命中；单区域在解析、判定或转换阶段抛异常时记录图像名、区域序号、阶段名与业务码并继续其余区域；每次完整运行生成 JSON 报告，含双版本渲染差异摘要、降级损失清单、边界敏感区域、快照版本号、失败清单与各阶段耗时，报告以临时文件加原子替换方式写盘。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本执行双版本转换与渲染，校验中间表示一致、降级损失与边界敏感记录及业务码正确。
