当前是空白工作区，需要从零构建一个面向语音端点检测（VAD）的本地组件与完整示例。业务对象是本地确定性合成的 16kHz 单声道 PCM 音频样本，由多段语音活动区与静音区拼接而成，并附带逐帧真值标记文件（帧长 10ms，字段含 frame_index、is_speech、sample_start、sample_end）与样本清单（JSONL，字段含 clip_id、duration_ms、seed、sample_rate、frame_ms）。组件需实现短时能量与过零率特征、自适应噪声底估计、双门限滞回判决，输出语音段起点与终点的毫秒级时间轴，并对照真值计算帧级与段级指标。核心业务难点在于可复现验证与异常注入：同一 clip 与同一配置下判决与指标必须逐字节可复现；需要在不修改源码的前提下，通过输入或参数在特征提取、噪声底估计、判决、段合并四个阶段分别注入可控异常，验证降级、归因与一致性自检链路。

任务环境与准备：
安装 Python 3.10 及以上与 NumPy，使用本地 pip 源，无需联网账号。
在空白工作区创建项目目录，准备本地确定性 PCM 合成脚本参数（种子、时长、语音与静音区间）与真值标记生成规则。
确认运行环境为 Windows，命令行示例以本地文件读写完成，不依赖外部服务或音频设备。

业务要求：
1. 实现确定性的帧级特征提取层：按 frame_ms 与帧移切分 PCM，计算短时能量与过零率，帧边界以样本索引精确确定；同一 clip、同一配置下必须逐字节产出相同的特征序列与帧数，且帧数须与真值标记文件的帧数一致，不一致时返回 E_FRAME_MISMATCH 并指出 clip_id 与实际帧数。
2. 实现自适应噪声底估计与双门限滞回判决：噪声底按不活跃帧的确定性分位数更新，高门限与低门限由配置的倍数给出，语音段以低门限进入、高门限退出的滞回规则判定；同一输入与配置下判决结果必须可复现，且门限、帧索引与起止样本的换算关系须在结果中显式记录以便复核。
3. 实现语音段时间轴后处理：对判决得到的候选段做最短语音时长与最短静音间隔合并，输出毫秒级 start_ms/end_ms 列表，保证按时间升序、互不重叠、落在音频时长内；违反不变式分别返回 E_OVERLAP、E_OUT_OF_RANGE 并注明 clip_id 与段序号。
4. 实现段级与帧级指标计算：以真值标记计算帧级准确率、召回率、误报率与段级命中判定（重叠比阈值可配置），输出混淆统计与逐段判定明细；指标必须可由逐帧判决与逐段明细独立重算一致，不得使用未记录口径的平滑或截断。
5. 实现四阶段异常注入框架：在特征提取、噪声底估计、判决、段合并四个阶段分别提供由输入或参数触发的注入点（如 PCM 样本越界、噪声底分位非法、门限颠倒、段长非正），每次注入须产生带阶段名、业务码与 clip_id 的结构化记录；注入不得通过修改源码实现，且相同注入配置必须复现相同记录序列。
6. 实现异常归因与降级链路：当某阶段产出业务码时，下游阶段按明确策略降级（如跳过段合并保留原始段、回退到固定门限判决），降级结果必须携带降级类别与触发它的上游业务码；禁止静默吞掉异常，未归因异常须汇总到结果顶层并标注所属阶段。
7. 实现配置与输入校验及资源上限：采样率非 16000、frame_ms 非法、门限倍数非正、帧移超过帧长分别返回 E_CONFIG_INVALID 并指明字段；为单 clip 最大时长、总帧数与驻留特征内存设可配置上限，超限返回 E_RESOURCE_LIMIT 或按明确策略分段处理并标记降级类别。
8. 提供可集成的领域组件接口与完整示例：暴露特征提取、判决、指标与注入入口，命令行示例读取本地合成样本输出含帧级判决、语音段、指标、四阶段注入记录、业务码与降级标记的 JSON 报告；支持固定种子重跑并比对两次报告哈希一致，另附一次多点注入演示，且提供跨阶段一致性自检入口，检测到帧数、段集合或指标不可核对时返回 E_INCONSISTENT 并指出不一致类别。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地合成 PCM 跑完整流程，核对语音段、帧级指标、四阶段注入归因与可复现哈希，并附报告。
