在游戏大地形渲染管线中，需要从零开发一个本地离屏遮挡剔除与场景流式加载数据处理管线，把地形分块场景渲染为灰度图像与深度图，并输出遮挡剔除验证报告。输入为一个 JSON 场景描述：地形高度场分块目录（由程序按确定性规则生成，每块覆盖固定世界尺寸并给出行列数）、全局原点与各轴世界尺度、相机参数（位置、目标点、上方向、垂直视场角、宽高比）、渲染分辨率、遮挡体（由网格描述文件给出的局部包围盒）、分块规格、并发上限、在途采样缓冲内存上限、流式加载窗口参数、流式加载队列容量上限与状态目录。核心难点在于数据规模变化下的算法取舍：小块场景可对每个分块逐像素精确渲染，而大场景必须依赖遮挡剔除与流式加载才能在内存预算内完成；剔除判定与流式加载顺序会互相影响（被剔除块不应占用加载窗口，而延迟加载又可能导致错误剔除），同时必须保证启用遮挡剔除后的图像与不做剔除的全量参考渲染在未被错误剔除的像素上逐像素一致。

任务环境与准备：
Windows 本地环境，安装 Python 3.10 及以上版本，并安装 NumPy 作为唯一第三方依赖。
在空工作区创建项目目录，准备生成确定性分块高度场样本与遮挡体网格描述样本的本地脚本，不依赖任何外部模型或网络资源。
准备本地测试脚本用于发送可处理终止信号并校验约定整数退出码，样本与测试全部在本地运行。

业务要求：
1. 实现场景描述与高度场目录解析：读取 JSON 描述，校验各轴世界尺度为有限正数、分块行列数为正整数且覆盖完整世界范围、垂直视场角在 (0,180) 度内、宽高比为有限正数、并发上限与内存预算为正整数、流式窗口参数满足不小于分块半径且不超过可用块数，非法输入返回带 E_xxx 业务码的 JSON 错误且不产生任何输出文件。
2. 实现全局高度场采样与分块归属：按全局原点与各轴世界尺度把世界坐标换算为高度场采样坐标并做双线性插值，块边界采用半开区间语义保证每个世界位置唯一归属一块，块切换处不出现采样缝隙或重复采样，采样结果只依赖高度场内容与坐标换算参数而不依赖加载顺序。
3. 实现分块包围盒与视锥剔除：为每个地形分块计算包含其高度极值的世界空间包围盒，按相机视锥做保守相交测试，只把通过视锥测试的块送入渲染队列；被视锥剔除的块必须计入报告且不消耗流式加载窗口，剔除判定在相机参数不变时必须确定且与分块遍历顺序无关。
4. 实现遮挡体遮挡剔除：从遮挡体网格描述构建遮挡体包围盒集合，对通过视锥测试的块做遮挡查询，仅当一个块的包围盒被遮挡体完全遮蔽时才判定为被遮挡剔除；遮挡查询所需的遮挡体数据须来自流式加载窗口内已加载的数据，窗口内遮挡体缺失时该块只能保留为未剔除，不得基于缺失数据判定剔除。
5. 实现流式加载窗口与队列资源控制：按相机位置与流式窗口参数维护已加载块集合与待加载队列，队列容量受上限约束，超出容量的加载请求按确定规则等待或丢弃并计数；从窗口驱逐的块须按依赖关系释放其采样缓冲，同时在途采样缓冲总量不得超过内存预算，任一加载失败时取消其余待处理加载并以首个错误终止。
6. 实现确定性分块并发渲染：对通过剔除的块使用有界线程池按并发上限调度，每块只读高度场、相机与光照参数并写回块私有颜色与深度结果，最终按固定块序与行序拼装，拼装结果须与固定并发度为 1 时的结果逐像素相同，任意调度完成顺序不得改变图像或深度。
7. 实现剔除结果验证与全量参考比对：在同一场景与相机下以禁用遮挡剔除、全量加载的方式生成参考图像与参考深度，逐像素比对开启剔除后的结果，被剔除块覆盖的像素不得出现与参考不一致的颜色或深度，未剔除像素误差须为零，比对结论与不一致像素坐标写入验证报告。
8. 实现分块级持久化、版本识别与原子写出：每块完成后把其颜色与深度结果、块摘要及由高度场内容、相机与渲染参数规范化摘要构成的版本标识写入状态目录，先写同目录临时文件再整体替换，替换前比对已有分块的版本标识，可处理终止信号只在块边界生效并写入中断标记后以约定整数退出码退出，强制终止后仅依据已持久化且摘要有效的块恢复；全部块完成后逐块校验摘要，不匹配或声明像素数不符时返回 E_DIGEST 并补渲，校验通过后先写临时文件再整体替换正式图像与验证报告。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地生成的分块地形样本验证剔除与流式加载下的图像、深度和参考比对报告，并验证中断恢复与摘要校验。
