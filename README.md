本机工作区没有任何材料，团队需要从头构建一个训练推理一体化领域的本地数据编辑与操作应用，用于诊断模型训练与推理链路中数据规模演进时的数值和缓存一致性问题。业务对象由固定种子脚本在本地确定性生成：首先是浮动规模的任务清单，每行含 case_id、data_size、feature_dim、label_dim、dtype、quant_scale、quant_zero_point、block_plan、revision、logical_clock_ms；其次按 case_id 给出样本张量描述，声明各特征块与标签块的形状、数值分布参数与摘要哈希；还有度量算子补丁流，每条补丁引用 case_id、目标块区间、新摘要与逻辑时钟，并标明是权重更新还是激活重算，且新旧补丁可能针对同一块区间冲突。系统需要在可注入逻辑时钟下调度算子缓存生成、块级失效重算与推理结果裁决，同时处理两代配置快照：v1 为单文件 JSON，记录相对生效秒数与扁平缓存策略；v2 为分片 JSON 加 SQLite 元数据库，记录绝对毫秒、策略代数与失效墓碑。核心矛盾在于数据规模演进会改变块划分收益，并行预算约束下缓存复用与重算代价必须可追溯，并且强制终止后恢复不能重复计入已提交算子。

任务环境与准备：
Python 3.10 或更高版本，安装 sqlite3 模块（标准库自带），NumPy 用于张量运算。
在本地目录创建 data/ 子目录存放由固定种子脚本生成的 JSON 样本文件，不依赖网络或外部服务。
使用随题交付的固定种子脚本生成任务清单、样本张量描述、算子补丁流和两代配置快照，保持固定随机种子以确保可复现。
确认 SQLite 数据库文件可写，所有命令在 WSL Ubuntu 下执行。

业务要求：
1. 实现任务清单、样本张量描述、算子补丁流与两代配置快照的解析校验：case_id 唯一，data_size 与 feature_dim 为正整数，dtype 枚举合法，量化参数为有限正数，块区间不越界且摘要哈希与内容一致，补丁逻辑时钟非负，v1 相对秒数为非负整数，v2 分片哈希与策略代数单调，任何非法输入返回独立业务错误码。
2. 在可注入逻辑时钟下依据两代配置合并结果生成算子缓存块：块边界由 block_plan 与数据规模共同决定，缓存内容按摘要寻址原子落盘，相同摘要重复生成必须复用同一文件；生成与查询时间判定只依赖注入逻辑时钟，不读取系统墙钟，同一输入重复运行逐位一致。
3. 实现块级失效闭包计算与冲突裁决：算子补丁流按逻辑时钟排序，同一块区间存在新旧冲突补丁时依据补丁代数与逻辑时钟裁决最新版本，并沿引用关系标记所有受影响缓存块和重算任务；未冲突或未受影响的缓存块不得重算，其摘要与已提交结果必须保持可用。
4. 在每轮逻辑时间预算与并发块重算上限双重约束下调度缓存失效重算：每轮按 case_id 和块序稳定排序挑选候选，预算或并发不足必须放弃剩余候选并区分预算内未启动、启动后失败与主动放弃三类结局，已启动重算不得被截断或重复提交，放弃原因与剩余工作量写入轮次记录。
5. 维护推理结果裁决账本与定点误差账本：每个算子缓存块的重算结果须登记 decision_id、绑定配置代数、输入摘要链与量化换算记录；对整批推理结果按定点标度累计误差上界，当两个候选结果差小于容差且裁决依赖该差值时标记精度敏感并输出误差来源链。
6. 实现配置快照整体替换的版本变化识别与进行中任务的版本绑定：收到新配置包时比较清单版本号、策略代数下限、各分片哈希与缓存键集合摘要，判定完整替换、增量追加或无需操作，版本回退必须拒绝；完整替换采用临时表加版本号原子切换指针，进行中的缓存生成或重算须绑定其开始时的配置版本直到完成。
7. 实现持久化状态与强制终止后的恢复一致性：将已提交缓存块摘要、失效闭包结果、调度轮次水位、推理裁决账本、定点误差账本、配置版本指针与逻辑时钟水位以事务原子写入 SQLite；进程在块生成、重算或配置替换任一阶段被强制终止后，恢复路径依据持久化状态识别已提交与半提交块，只重放缺失部分且不重复累计误差或账本。
8. 实现多进程并发一致性、异常链路隔离与可重复命令行接口：允许多个生成、重算与裁决实例并行处理不同 case 或块，通过 SQLite 事务和文件锁保证同一块同一版本只被物化一次、同一配置快照只被整体替换一次、重复提交幂等；分片哈希不匹配、块区间越界、补丁代数回退、逻辑时钟回拨超容差分别映射到独立业务错误码并保留可诊断字段，提供 load、generate、patch、resume、status、verify 子命令。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用固定种子样本验证算子缓存、块级失效重算与推理裁决在配置演进和强制终止恢复下的一致性。

## 实现交付入口

本仓库已在上述题目要求之上交付可运行的 `dataplane` Python 包：

```bash
python3 -m pip install -r requirements.txt
bash scripts/acceptance.sh data
python3 -m pytest tests/test_dataplane.py -q
```

常用命令：

```bash
python3 -m dataplane seed --data-dir data
python3 -m dataplane load --data-dir data --clock-ms 1000
python3 -m dataplane generate --data-dir data --clock-ms 2000
python3 -m dataplane patch --data-dir data --clock-ms 3000
python3 -m dataplane resume --data-dir data --clock-ms 3100
python3 -m dataplane status --data-dir data
python3 -m dataplane verify --data-dir data --strict
```

额外提供 `reconfigure` 与 `adjudicate` 子命令。架构、状态机、错误码和并发恢复说明见 `docs/ARCHITECTURE.md`，实际验证记录见 `docs/VERIFICATION.md`。
