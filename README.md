在空白工作区构建一个面向表格数据的线性模型正则化训练与状态演进实验台，用于在反复调整正则化方案时验证训练状态的一致性与可恢复性。输入为本地 YAML 实验配置与按固定种子确定性生成的合成表格数据描述（数值列、类别列、缺失值、冗余列与目标列），配置包含正则化方案集合（L2 岭回归、L1 套索、弹性网络三种，含各自的惩罚系数与混合比例）、优化器参数（学习率、最大迭代数、收敛容差、批量大小）、训练/验证划分比例、并发数与快照提交间隔。实验台需支持用户通过交互命令反复切换正则化方案或修改惩罚系数，后台对线性模型执行确定性梯度训练，记录每轮的系数更新、损失轨迹与正则项贡献，并输出可审计的决策记录与训练报告。核心约束是状态演进与恢复一致性：训练过程可被中断，重启后必须从最近一次持久化快照恢复，保证最终模型系数、损失轨迹与不中断运行完全一致；若正则化配置在恢复前被修改，必须识别版本变化并判定复用或失效。

任务环境与准备：
安装 Python 3.10 及以上版本与 NumPy、PyYAML，全部为本地依赖，无需网络服务或 GPU。
在工作区创建配置文件、数据描述文件与交互命令脚本样例，固定随机种子，确保数据可按描述确定性再生。
准备可重复演示用的命令序列与预期观测点说明，不预置任何项目代码或既有数据附件。

业务要求：
1. 实现配置与数据加载层：读取 YAML 实验配置与数据描述，按列类型与固定种子确定性生成表格数据，完成缺失值填充与类别列编码；对未知列、类型不符、目标列缺失、惩罚系数为负或并发数非正分别输出 E_CONFIG_INVALID 业务码并进入失败清单，不得中断整体流程。
2. 实现三种正则化目标函数与确定性梯度下降：L2、L1 与弹性网络的损失须分别显式包含对应的正则项与梯度贡献，弹性网络按混合比例线性组合两种惩罚；优化器按固定批量划分与固定批量顺序执行，逐轮记录损失值与参数更新范数，收敛判定基于连续两轮损失差值小于容差。
3. 实现训练状态快照与恢复一致性：每轮结束将当前系数、轮次、损失轨迹、优化器状态与配置哈希以临时文件加原子替换方式持久化；启动时读取最新快照并校验配置哈希与版本号，一致时从该轮次继续训练，不一致时输出 E_CONFIG_MISMATCH 并拒绝恢复，恢复后的最终系数与完整损失轨迹须与不中断运行逐字段一致。
4. 实现交互式方案切换与失效判定：交互命令可切换正则化方案或修改惩罚系数，每次切换后依据由方案名、惩罚系数、混合比例与数据指纹派生的缓存键判定哪些轮次结果可复用；同一方案配置重放时直接复用已验证的收敛结果且不得重复训练，复用与重算清单须写入报告。
5. 保证批量划分与串行结果一致：使用线程池并发计算各批次的梯度与损失贡献，最大并发数取自配置；每个批次任务携带由轮次与批量序号派生的稳定排序键，无论线程完成顺序如何，最终逐轮系数、损失轨迹、失败清单顺序与报告内容必须与单线程按固定批量顺序执行的结果逐字段一致。
6. 实现数值稳定性与精度可观测保障：梯度累加与损失计算使用固定运算顺序，L1 次梯度在系数为零处采用固定取值规则，正则项贡献与数据项损失须分别记录；同一输入与配置在不同并发度与不同恢复点运行得到的每轮损失与最终系数差值不得超过预先声明的容差，超出时记 E_NUMERIC_DRIFT 并写入报告。
7. 实现可处理退出信号与强制终止后的状态判定：收到可处理的退出信号时完成当前轮次快照原子替换与进度记录后以整数退出码 0 退出；进程被强制终止后重启仅依据已完整替换的快照恢复并输出恢复点信息，不得承诺强制终止时一定生成退出报告，也不得将线程超时表述为已终止训练。
8. 实现异常链路隔离与训练报告输出：单轮或单批在目标计算、梯度更新或快照写入阶段抛异常时记录轮次、批次序号、阶段名、业务码与异常类型到失败清单并继续可恢复流程；每次完整运行生成 JSON 报告，包含各方案最终系数、损失轨迹、正则项贡献、复用与重算清单、快照版本号、失败清单与业务码，报告以临时文件加原子替换方式写盘。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地合成数据验证三种正则化训练、并发与串行一致、快照恢复及配置变更失效判定，附运行结果。
