当前为空白工作区，需要从零构建一个面向语音识别（ASR）转写数据编辑与操作的本地应用。业务对象是一段本地确定性合成的单声道 16kHz 语音，其转写真值以多个格式版本并存：内部规范切片格式 v1（JSON，含 utterance_id、start_ms、end_ms、text、tokens、speaker、confidence 字段）、v2（在 v1 基础上引入 token 级时序、分段标签与 confidence 区间，时间单位改为微秒）以及外部交换格式（SRT 与 WebVTT 字幕，时间以冒号和逗号表示）。用户需要在该应用中打开一条 ASR 样本、编辑转写文本与时间轴、对比不同格式版本、并导出为任意目标格式。核心矛盾在于格式互操作与版本兼容：v1 与 v2 对时间精度、字段必填性、tokens 与 text 的一致性约束不同，字幕格式在毫秒截断、重叠切片序列化与跨行文本换行规则上存在额外限制，任意一次编辑都必须能双向无损地映射回规范格式，且必须在本地确定性可复现。

任务环境与准备：
安装 Python 3.10 及以上，创建本地虚拟环境。
安装 NumPy 与 PyYAML，版本按 requirements 锁定；不引入需要网络的 ASR 模型或音频编解码库。
准备本地确定性样本生成脚本所需的随机种子与参数配置文件，样本与真值均由脚本在本地生成，不依赖真实账号或线上站点。
确认工作区为空目录，具备可写权限以创建缓存与快照目录。

业务要求：
1. 实现 v1 与 v2 内部规范格式的读取器，按版本分别校验必填字段、时间单位（毫秒与微秒）与字段类型；对缺失必填字段、时间非整数、start 大于等于 end、utterance_id 重复分别返回 E_FIELD_MISSING、E_TIME_TYPE、E_TIME_ORDER、E_DUP_UTTER，并指出所在记录索引与版本。
2. 实现版本迁移器，把 v1 提升为 v2 时补全 token 级时序与 confidence 区间（区间由单点置信度与给定扩展半径确定性推导），把 v2 降级回 v1 时按明确舍入规则把微秒归并为毫秒并丢弃 v2 独有字段；迁移前后须记录字段级差异清单，要求同一输入同一参数重跑产出一致。
3. 实现规范格式与 SRT、WebVTT 的双向映射：导出时按各字幕格式的时间表示与换行规则序列化，时间截断策略在配置中显式声明；导入时重建 utterance 边界。任一规范样本导出再导入后，在毫秒精度与文本内容上须与原样本可核对一致，字幕格式无法表达的字段（如 speaker）须在映射报告中列为丢失项而非静默丢弃。
4. 实现编辑操作与切片不变式维护：支持修改文本、调整起止时间、拆分与合并切片；编辑后须保证切片按时间升序、同一样本内不重叠、text 与 tokens 拼接保持一致，违反时返回 E_OVERLAP、E_TOKEN_TEXT_MISMATCH 或 E_ORDER，并指出涉及的两个 utterance_id。编辑提交后不得直接改写已持久化的原始快照。
5. 实现基于音频的切片边界一致性校验：用本地合成的确定性 PCM 样本，对每个切片区间计算能量与过零率特征，检测时间轴是否越界到音频长度之外或出现零长度区间，分别返回 E_AUDIO_RANGE 与 E_ZERO_LEN；校验须给出每个切片的观测特征值与判定依据，不得从缺失信息推断真值。
6. 实现版本快照与整体替换：每次提交编辑产生带单调递增版本号与内容校验和的规范快照，重启或重新加载时检测版本变化并整体替换旧快照；损坏或校验和不符的快照在加载时返回 E_SNAPSHOT_CORRUPT，进行中未提交的编辑不得出现在已加载快照中，编辑历史须可回退到任一已提交版本。
7. 实现配置与资源边界：为切片数量上限、单样本音频时长上限、导入文件大小上限设可配置阈值，超限时返回 E_RESOURCE_LIMIT 或按明确策略拒绝；导入时对非法时间字符串、非法头部、编码错误分别返回 E_TIME_PARSE、E_HEADER、E_ENCODING，且所有异常须沿链路归因到具体文件与行号。
8. 提供一个本地可交互的编辑与操作应用，展示当前规范版本、切片列表、格式映射报告、校验结果与最近业务错误码，允许切换 v1/v2/字幕视图并触发一次演示：加载本地合成样本，执行一次编辑与一次跨版本导出导入往返，演示中注入非法时间与越界切片并呈现对应业务码。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地合成音频与样本，验证 v1/v2 与字幕往返一致、编辑不变式、快照替换及错误码。
