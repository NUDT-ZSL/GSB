当前是空白工作区，需要从零构建一个面向 LLM 指令微调（SFT）数据构造的本地可视化与诊断工作台，核心业务问题是数值精度与误差传播。输入是本地确定性生成的原始样本（JSONL，字段含 sample_id、instruction、input、output、source、quality_notes）以及一份构造配置：质量打分权重、去重相似度阈值、采样配比目标与数值格式精度。工作台需把数据构造建模为多级流水：质量打分（文本长度、重复率、噪声字符比例的加权分数）→ 近重复检测（签名相似度）→ 按来源与任务类型做配比采样 → 输出训练清单。每一级都在浮点域上累加、加权、归一化与门限判定，分数会沿级联传播：质量分决定样本是否进入去重候选，相似度决定剔除，配比权重又反过来影响采样的取舍，任何缩放、次正规数保护、舍入与门限比较策略都会沿链路放大并改变最终清单。用户需要能在工作台上看到每一级的分数区间、误差来源与最终清单的可核对关系。

任务环境与准备：
确认 Windows 本地已安装 Python 3.10 及以上，并可用 pip 安装 NumPy，无需网络下载数据集
在工作区创建项目目录并生成确定性样本：给定固定种子构造含 sample_id、instruction、input、output、source、quality_notes 的 JSONL 以及配置样例，样本覆盖门限附近分数与异常字段
准备异常注入输入（非法权重、越界门限、重复 sample_id、空 output、损坏快照文件），仅通过输入或参数注入触发，不修改源码
准备一次性演示脚本的入口约定与本地视图运行方式，所有依赖限于本地文件与本地进程

业务要求：
1. 实现确定性的质量打分与近重复检测级：质量分由文本长度、重复率与噪声字符比例按配置权重加权得到，相似度基于文档给出的签名相似度计算；同一输入同一配置下必须产出逐字节一致的质量分、相似度与候选保留集合，并给出每个分数的 float64 中间量口径。
2. 实现分数沿级联的误差传播与区间输出：质量分传入去重门限、相似度传入配比权重后，工作台须为每个样本输出最终采样权重的置信区间与误差放大比，并定位主导误差来源为加权打分、归一化或门限比较中的哪一级，同时记录各级数值偏差量。
3. 实现配比采样与欠配归因：在每来源与每任务类型的样本目标配额下做确定性采样，优先满足总量并允许受限欠配；清单须记录每个配额目标的实际达成量、欠配原因与采样种子，使同一快照同一配置重跑得到相同清单与相同欠配归因，且每个任务类型须由样本的 source 与 instruction 前缀确定性推导，推导规则随配置给出并可复核。
4. 实现门限判定的数值稳定性策略：对相似度与质量分设定可配置门限，提供可切换的比较策略（严格比较、容差带比较）与次正规数保护，保证恰好落在门限附近的样本判定可复现且不被舍入翻转，门限策略变更必须在诊断报告中显式记录；容差带比较须给出落入容差带内的样本清单及其两侧距离，使判定可人工复核。
5. 实现构造配置的校验与异常链路归因：权重不为正、门限越界、配额目标为负、精度配置非法分别返回 E_CONFIG_INVALID 并指明字段；解析失败、签名长度不一致、output 为空等样本级异常须归因到具体 sample_id 与所处级，未归因异常汇总上报而非静默吞掉。
6. 实现快照版本与整体替换：每次构造提交产生带单调递增版本号与内容校验和的清单快照与统计量快照，检测到版本变化时整体替换旧快照而非增量修补；损坏或校验和不符的快照加载时返回 E_SNAPSHOT_CORRUPT 并指明快照类别与版本号。
7. 实现资源上限控制：为单批样本数、签名比较候选数与清单内存估算设可配置上限，超限时按明确策略返回 E_RESOURCE_LIMIT 或降级到受限比较模式，降级必须在结果中标记降级类别且不得改变已输出样本的质量分口径；受限比较模式下须输出被跳过比较的候选对计数，供诊断判断剔除集是否受降级影响。
8. 实现可视化与诊断工作台及跨级一致性自检：展示各级分数分布、误差传播链、剔除集与保留集、配额达成情况与最近业务错误码；并校验保留集与剔除集无交集、清单样本均可追溯到质量分与相似度、各配额实际量与清单可重算一致，违反时返回 E_INCONSISTENT 并指出不一致类别与涉及的 sample_id。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
