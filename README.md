当前是空白工作区，没有现存项目、代码或数据附件，需要从零构建一个面向多标签图像分类的本地诊断工作台。业务对象是本地确定性生成的图像样本：每张图由固定种子生成固定尺寸 RGB 像素数组，并附多标签真值集合（标签来自受控标签集，允许一张图对应多个标签，部分标签标记为不确定）。分类链路建模为有向无环图：预处理→特征提取（分块统计与固定投影）→逐标签打分→多标签判决→指标聚合。核心业务问题是：当标签集版本演进、特征投影参数更新或单张图标注被修正时，需要精确识别受影响的样本与计算节点，仅重算必要部分，同时确保缓存复用与整体替换不影响最终指标的正确性。

任务环境与准备：
安装 Python 3.10 或以上版本，并确保 NumPy 可用（例如 pip install numpy）。
创建空工作目录，无需下载任何数据集、模型或外部服务。
准备本地确定性样本生成脚本或配置，确保图像种子、标签集版本与投影参数可在配置中显式声明。
确认本地缓存目录可写，并预留足够空间存放中间特征与指标明细。

业务要求：
1. 实现确定性的多标签分类计算图：把预处理、特征提取、逐标签打分、多标签判决与指标聚合五个节点建成有向无环图，节点连接与逐标签门限由配置字典决定；同一输入、同一配置与固定种子下必须逐字节产出相同的中间特征、逐标签分数与最终判决，禁止依赖除固定种子与显式配置外的任何外部状态。
2. 实现内容寻址缓存与缓存键构造：每个节点产物附带内容哈希写入本地缓存目录，缓存键须纳入该节点全部输入摘要、上游节点产物哈希、标签集版本与节点参数；键相同的请求必须复用快照，键不同的必须重算，且必须提供入口可按给定缓存键查询产物来源与命中状态。
3. 实现增量更新的依赖失效传播：修正单张图标注、调整某张图的标签集版本或替换特征投影参数时，计算受影响节点与受影响图像及标签集合，复用未受影响的上游缓存，仅重算受影响的后缀节点；须输出本次重算节点清单与复用节点清单，并保证局部更新后的指标与在修改后全量数据上从零计算的结果一致。
4. 实现不确定标签与多标签判决语义：被标记为不确定的标签须按配置策略（忽略、计入正例或单独统计）处理且策略显式记录在结果中；每个样本的判决标签集合允许为空或含多个标签，但不得包含受控标签集之外的标签；违反分别返回 E_LABEL_UNKNOWN 与 E_DECISION_INVALID 并指明样本与标签。
5. 实现指标聚合的可重算一致性：由判决结果与真值计算 micro/macro F1、逐标签 precision/recall 与 hamming loss，指标须可由逐样本逐标签明细独立重算一致；当某标签在真值中无正例时按配置口径处理并在报告中标记，指标口径未记录不得用于对外输出，重算偏差超出容差返回 E_METRIC_MISMATCH。
6. 实现标签集与特征投影快照的版本化整体替换：标签集、投影参数与指标统计各携带单调递增版本号与内容校验和，检测到版本号或校验和变化时必须整体替换旧快照而非增量修补；旧版本不得覆盖新版本，回退尝试返回 E_SNAPSHOT_ROLLBACK，损坏或校验和不符返回 E_CACHE_CORRUPT 并指明节点。
7. 实现并发提交控制与资源上限：同一时刻只允许一次增量提交生效，并发冲突时后到者立即获得 E_STAGE_BUSY 而不阻塞等待；为单次重算图像数、特征驻留内存估算与并行重算节点数设可配置上限，超限时按明确策略返回 E_RESOURCE_LIMIT 或降级并在结果中标记降级类别。
8. 提供本地可交互诊断工作台与跨模块一致性自检：展示计算图拓扑、各节点缓存命中或重算状态、失效传播覆盖的图像与标签、逐标签分数、判决结果与指标明细、快照版本与最近业务错误码；自检校验图拓扑无环、缓存键与产物哈希互相可核对、重算集合与复用集合无交集且并集覆盖全部受影响集合、指标可由明细独立重算一致，不一致返回 E_INCONSISTENT。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地确定性样本验证增量更新后指标与全量重算一致，并输出诊断报告与业务码。
