当前是空白工作区，需要从零实现一个本地段式日志存储引擎的写入放大诊断与合并策略裁决工具，用于在确定性样本上复现从键值写入流到段文件生成、段内索引、墓碑积累与分层合并的完整链路，并专项处理写入放大估算与合并策略选择的数值精度与规模自适应问题。本地 JSON 样本给出：写入轨迹（记录序号、键、值字节数、操作类型为写入或删除、注入逻辑时钟毫秒戳）、存储配置（内存表容量字节、段文件大小上限、合并层级数与每层触发阈值、墓碑保留代数、压缩块大小、单轮合并字节预算、逻辑时钟步进）以及诊断配置（定点标度、浮点容差、误差上界预算、采样比例）。引擎需把写入流按内存表刷盘规则切成不可变段，为每段建立稀疏索引与布隆占位摘要，按分层策略计算每层合并增益与写入放大估算，并在合并字节预算约束下裁决是否发起合并及选择哪些段参与。核心矛盾是：写入放大估算依赖每个键在多层中的重复次数与字节权重，这些量由整数字节与小数压缩比、比率混合换算而来，舍入方向与累计次序可能使两层或两种合并候选的收益比较翻转，进而使实际放大的结论失真。

任务环境与准备：
确认 Windows 上可用 Python 3.11 及以上，并使用 venv 创建隔离虚拟环境。
安装依赖：pip install numpy pytest；SQLite 使用 Python 标准库 sqlite3，decimal 使用标准库，无需额外安装。
在空白工作区预置固定样本：写入轨迹 JSON、存储配置 JSON 与诊断配置 JSON，以及可注入逻辑时钟的步进表。
准备进程强制终止的本地测试脚本用于验证恢复路径；全部样本与测试在本地运行，不使用容器或外部服务。

业务要求：
1. 实现写入轨迹与存储配置的解析校验：记录序号严格递增且唯一、键格式合法、值字节数为非负整数、操作类型枚举闭合、逻辑时钟毫秒为非负整数、内存表容量与段大小上限为正整数、合并层级数与每层触发阈值为正整数序列、墓碑保留代数非负、定点标度与容差合法；非法输入必须返回明确业务错误码（如 E_BAD_TRAJECTORY、E_BAD_LEVELS、E_BAD_TOLERANCE）且不写入任何持久化状态。
2. 实现内存表刷盘与段文件生成：按内存表容量字节切分写入流为不可变段，每段记录段序号、键区间、每键最新版本序号、墓碑标记与内容摘要，段内容以确定性字节序写入本地段目录并以临时文件加重命名原子落盘；同一写入轨迹重复运行必须得到逐段逐字节一致的段文件与段清单。
3. 实现段内稀疏索引与查找代价估算：为每段建立按键排序的稀疏索引与布隆占位摘要，记录索引条目数、摘要位宽与误判率上界估计，并据此估算单次精确键查找需读取的段数与块数；估算必须说明所依赖的观测（段序号、每段键区间与摘要参数），同一索引反复估算得到逐位一致结果。
4. 实现分层合并增益与写入放大估算：对每层计算键重复率、墓碑占比与压缩比，据此估算该层写入放大贡献与合并增益，并按层序累计为整库写入放大估算；压缩比与比率须按声明定点标度换算并记录换算标度、舍入方向与换算前原始值，整库累计运算顺序固定使结果逐位可复现。
5. 实现双通路误差账本与精度敏感标记：为每个层的写入放大贡献与整库累计量同时计算定点通路值与基于 decimal 高精度全量重算的真值通路值，输出两通路数值、绝对偏差与相对偏差；累计每次乘加的误差上界，当两层或两种合并候选的增益差值小于给定容差且裁决依赖该差值时标记为精度敏感，并输出误差来源链（含层号、参与换算步骤与舍入余量位置）。
6. 实现合并字节预算下的段选择与墓碑清理裁决：在单轮合并字节预算与目标层容量约束下选择参与合并的段集合，墓碑仅在保留代数耗尽且无更低层旧版本引用时可实际清除；预算不足须放弃剩余候选并记录放弃原因，区分预算内未选中、选中后取消与主动放弃三类结局，并输出每个被选段的选择依据与首个触发约束。
7. 实现强制终止后的恢复一致性：把段清单版本、内存表已刷盘水位、各层段集合摘要、合并决策与逻辑时钟水位以事务原子写入 SQLite，每次决策提交以临时表加层号整体替换当前层视图指针；进程在刷盘或合并中途被强制终止后，恢复路径依据持久化状态识别半写入段文件与未提交合并，只清理无引用临时文件并只重放未完成步骤，不得承诺一定生成退出报告。
8. 实现多进程并发一致性与可重复命令行诊断：允许多个诊断实例并行处理同一写入轨迹的不同段区间，通过 SQLite 事务与文件锁保证同一段序号同一版本只提交一次、同一层视图版本只被整体替换一次，重复提交相同段或相同合并决策必须幂等，读取方只能看到完整已提交层视图；提供 load、flush、diagnose、compact、resume、status、verify 子命令，diagnose 以稳定排序 JSON 输出各层写入放大、偏差、精度敏感标记与误差来源链，verify 校验持久化状态与输出一致。
