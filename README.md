需要在空白工作区中实现一个面向本地 SQLite 数据库的查询计划代价估算与索引选择组件。组件接收逻辑查询描述（表、过滤谓词、等值与范围条件、排序键、连接关系）与本地统计元数据，生成候选访问路径（全表扫描、单列索引、组合索引），估算各路径的行数、选择率与代价，并选定执行计划输出为可集成模块与完整示例。真实数据库的列统计来自样本直方图与等值频次表，浮点选择率在多层谓词与连接之间会传播误差，导致不同候选路径的代价次序可能翻转，组件必须在数值精度、计划稳定性和索引建议之间做取舍：既不能因舍入让代价近乎相等的路径反复抖动，也不能因过度保守的容差而选出明显更差的路径。组件需在 Windows 上离线运行，统计元数据与测试样本全部本地生成，不依赖任何数据库服务、附件或网络。

任务环境与准备：
安装 Python 3.11 与 pytest，使用标准库 json、sqlite3、decimal、itertools，无第三方网络依赖。
在 Windows 工作区创建样本目录，生成确定性统计元数据 JSON 与查询描述文件，随机种子固定。
确认本机可用本地 SQLite 库，测试全部离线执行，不连接外部数据库服务。

业务要求：
1. 实现统计元数据模型与载入：每个列维护行数、不同值数、空值比例、等值频次表与有序分位点直方图，元数据以 JSON 文件载入并做结构校验，非法元数据须返回业务码 E_BAD_STATS 且不得进入估算流程。
2. 实现单谓词选择率估算：等值谓词优先用等值频次表，缺失时按不同值数回退；范围谓词用分位点直方图插值；空值比例与否定谓词需按 SQL 三值逻辑处理，估算结果须落在闭区间 [0,1] 内并记录所用估算来源。
3. 实现多谓词与连接的选择率传播：同表谓词按独立性假设逐层相乘，跨表连接按连接列不同值数的较大者估算；必须记录各中间选择率的十进制有效位并给出误差区间，使调用方能判断传播误差是否显著。
4. 实现候选访问路径枚举与索引建议：对每张表枚举全表扫描、已有单列索引与可新建组合索引（前缀须匹配谓词列序），生成覆盖给定排序键的候选；对不含前导谓词列的索引必须标注为不可用候选，不得参与最终选优。
5. 实现代价估算模型与数值精度控制：扫描代价按页读取数、索引代价按树高与回表比例建模，浮点代价按相对容差 0.02 比较。代价在容差内视为并列时，须按更少回表、更低内存、更短索引的确定性次序裁决，保证相同输入始终产出相同计划。
6. 实现计划稳定化输出：输出结构包含选定计划、被拒候选及拒绝原因、估算误差区间与并列裁决依据；当最佳与次佳候选代价差小于容差时必须在输出中显式标记并列并附裁决键，且输出 JSON 字段顺序与数值格式需固定以保证可重复比对。
7. 实现连接顺序的贪心选择与回退：多表连接按行数估计递增顺序构造，若全部顺序的估算误差区间重叠且超过容差则回退为按输入连接关系原序，避免误差传播导致计划抖动；连接谓词列类型不一致时必须返回 E_TYPE_MISMATCH 拒绝估算。
8. 提供完整示例与测试：附带本地样本数据库元数据与若干查询描述，示例需展示命中索引、并列裁决、误差区间标记与类型不匹配拒绝；pytest 用例须在 Windows 离线覆盖上述路径并在固定随机种子下可重复通过。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
