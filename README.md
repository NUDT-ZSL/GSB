项目初始状态是空目录，需要从零实现一个本地化故障隔离与容灾切换的诊断工作台，用于在确定性样本上复现主备切换、隔离域冻结与切换前后计算结果一致性之间的冲突。本地 JSON 样本给出服务拓扑（服务名、实例 ID、所属隔离域、上游依赖、健康权重）、容灾策略（每服务切换模式为主备或双活、切换触发阈值、隔离域冻结顺序、切换冷却逻辑毫秒、回切阶梯比例）以及按可注入逻辑时钟给出的事件流（事件序号、实例 ID、指标名、指标值、所属观测窗口）。工作台需在注入逻辑时钟下驱动隔离域冻结与主备切换，维护每服务主副本指针，并在切换前后对同一批聚合查询给出逐位一致的结果。为满足交互延迟预算，需并行执行冻结探测与切换探测，但并行推进不得让进行中的查询看到混合主备或冻结与未冻结混用的状态。所有阈值判定、冷却窗口与回切阶梯只依据注入逻辑时钟，不得读取系统墙钟；多个工作进程并行时同一服务同一轮次只能被切换一次，进程被强制终止后须依据持久化状态裁决已提交与半提交的切换结果。

任务环境与准备：
安装 Python 3.11 或以上，并在空目录创建虚拟环境：python -m venv .venv 与 .venv\Scripts\activate。
安装依赖：pip install fastapi==0.110.0 uvicorn==0.29.0 numpy==1.26.4。
准备本地确定性样本：生成服务拓扑、容灾策略与指标事件流 JSON，以及主备数据副本的派生种子；样本放在 samples 目录并由脚本可重建。
确认 SQLite 可用（Python 标准库 sqlite3 自带），工作区根目录需对当前用户可读写以创建状态数据库与快照文件。
运行方式：以 uvicorn 启动 FastAPI 应用提供 load、switch、resume、status、verify 端点；全部在 Windows 本机执行，不依赖外部服务或网络。

业务要求：
1. 实现服务拓扑、容灾策略与事件流的解析校验：服务名与实例 ID 唯一、隔离域引用闭合且冻结顺序包含全部已声明隔离域、上游依赖无自环且实例归属已声明服务、触发阈值与冷却逻辑毫秒为非负整数、回切阶梯比例严格递减并以零收尾、事件序号严格递增、指标值有限；非法输入须返回明确业务错误码且不写入任何持久化状态，并输出首个失败字段路径。
2. 实现基于注入逻辑时钟的隔离域冻结与主备切换驱动：冻结批次划分、切换冷却窗口与回切阶梯推进只依赖注入逻辑时钟毫秒值，不读取系统墙钟；每服务必须唯一归属一个隔离域且任一时刻只有一个主副本指针，同一逻辑时钟序列下重复运行得到逐位一致的切换序列与主副本指针轨迹。
3. 实现切换前后聚合查询结果一致性裁决：对每服务在切换前后执行同一批固定聚合查询，结果以稳定排序 JSON 输出并逐字段比对；主备数据副本由样本按确定性规则派生，切换不得改变已提交查询的结果，不一致时须输出首个分歧字段、主备两侧原始值与所绑定的主副本指针版本。
4. 实现并行探测与切换的交互延迟预算约束：同一轮次内按隔离域分组并发执行冻结探测与切换探测，同时受每轮并发上限与每轮逻辑时间预算约束；预算耗尽须放弃剩余未启动探测并记录放弃原因，严格区分预算内未启动、启动后失败与主动放弃三类结局，已启动探测必须执行完毕，不得以事后标注代替真实预算判定。
5. 实现查询的配置版本绑定与读取隔离：每个查询必须绑定其开始时的容灾策略版本号与主副本指针版本，进行中的查询不得观察到新冻结域或新主副本，读者不得看到新旧策略混合的状态；策略版本每次变更产生新版本号并以内容摘要整体替换当前指针而非逐条覆盖，版本回退须被拒绝。
6. 实现切换轮次的持久化推进与强制终止后的恢复裁决：把已提交轮次水位、隔离域冻结状态、每服务主副本指针、已提交查询摘要与逻辑时钟水位以事务原子写入 SQLite，每次提交识别版本变化并整体替换快照指针；进程在冻结或切换中途被强制终止后，恢复路径须识别已提交切换与半提交状态，只重放未完成部分且不得重复计数任何切换结果。
7. 实现多进程并发一致性与幂等提交：允许多个诊断实例并行处理不同隔离域，通过 SQLite 事务与文件锁保证同一服务同一轮次同一版本只被切换一次、同一策略版本只被整体替换一次、重复提交相同轮次结果必须幂等；读取方只能看到完整已提交轮次，不得读到半提交的切换结果或冻结状态。
8. 实现异常链路隔离与可重复诊断服务：隔离域冻结顺序冲突、切换目标实例缺失、回切阶梯比例非法、策略版本回退、样本摘要不匹配、逻辑时钟回拨超过容差分别映射到不同业务错误码并保留可诊断字段（服务名、隔离域、轮次号）；单个隔离域异常不得中断其他隔离域的冻结与切换；以 FastAPI 提供 load、switch、resume、status、verify 端点，status 输出稳定排序 JSON。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
