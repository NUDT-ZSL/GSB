美术外包团队把同一套游戏地表贴图拆成多块交回，各块由不同人员在不同时间扫描，块间存在数十像素以内的整体平移、轻微的亮度与对比度偏差，以及需要按掩码融合的重叠区。团队目前只有目标要求，尚无任何系统与代码，工作目录是空的。需要从零实现一条本地数据处理管线与结果验证工具，全部样本由随工程交付的固定种子脚本确定性生成：灰度分块素材、真值偏移清单，以及两代掩码与配准结果描述——v1 为单文件 JSON，以相对秒数记录扁平整数偏移与像素级硬掩码；v2 为分片 JSON 加 SQLite 元数据库，记录绝对毫秒时间戳、亚像素配准结果、软掩码权重与墓碑标记。管线要完成相位相关配准、亚像素重采样、掩码互操作裁决、加权融合、整幅拼接与逐块核验，最终输出拼接图与配准核验报告。

任务环境与准备：
安装 Python 3.11（Windows 官方安装包，安装时勾选 Add to PATH）。
执行 python -m pip install numpy==1.26.4 pillow==10.3.0。
在空工作区建立工程目录，运行任务自带的固定种子样本生成脚本，产出灰度分块素材、真值偏移清单与两代掩码/配准描述。
确认工作区可读写；SQLite 使用 Python 标准库 sqlite3，全程不连接网络或外部服务。

业务要求：
1. 实现输入解析与校验：读取本地生成的灰度分块素材、真值偏移清单与两代掩码/配准描述，校验图像尺寸与重叠区声明一致、偏移为有限数、v1 相对秒可换算为绝对毫秒、v2 亚像素偏移与软掩码权重落在定义域内、分块排布覆盖整幅尺寸；任一项非法时返回带 E_xxx 业务码的 JSON 错误且不产生拼接图。
2. 实现相位相关配准与亚像素细化：在重叠区内用 FFT 互相关求整数平移，再以互相关峰附近三点做抛物线插值求亚像素偏移，并输出归一化相关峰作为置信度；对给定样本的整数偏移误差为 0 像素、亚像素误差不超过给定容差，置信度低于声明阈值的块须在报告中标注为待人工确认而非静默采用。
3. 实现小数像素重采样与亮度对比度归一：按亚像素偏移做确定性插值重采样，越界采样点按零填充；同时估计并校正该块相对参考块的线性亮度与对比度偏差，重采样核与校正应用顺序在整条链路中保持单一确定口径，校正后重叠区同一位置的相邻块灰度差须显著小于未校正情形。
4. 实现两代掩码互操作与冲突裁决：把 v1 像素级硬掩码与 v2 软掩码权重换算到统一融合口径，同代同标识按代数取新、墓碑优先于无墓碑记录，两代对同一重叠区像素给出不一致归属时按代数与生效时刻裁决并逐条输出冲突项，冲突项须定位到来源描述、分块标识与像素坐标。
5. 实现重叠区融合与整幅拼接：按归一后的软掩码权重在重叠区做加权融合、非重叠区直接取样，输出尺寸与分块排布由描述声明决定，固定以块标识升序与像素行序归并，使任意并发度下融合结果逐像素相同，并与逐块串行融合的结果完全一致。
6. 实现分块级持久化与版本识别恢复：每块完成配准、重采样与融合后把中间量、融合结果、块摘要与由素材内容、真值清单及两代描述规范化摘要构成的版本标识原子写入状态目录，先写临时文件再整体替换；再次启动时比对版本标识，一致则复用已完成块只补缺失块，标识变化时不得直接覆盖旧块而须归档。
7. 实现中断语义、块级摘要校验与并行资源上限：可处理终止信号只在分块边界生效，写出中断标记并以约定整数退出码退出，未完成块不得留下可被误认为完成的结果；强制终止后仅依据已持久化且摘要有效的块恢复。按并发上限使用有界线程池，并限制在途像素与频谱缓冲总量，摘要不匹配、缺失或声明像素数不符时报 E_DIGEST 并回退补算。
8. 实现配准核验报告与产物原子导出：报告含每块整数偏移、亚像素偏移、置信度、与真值的误差、亮度对比度校正系数、采用的掩码来源、冲突项、逐块摘要校验结果与业务码列表；拼接图与报告先写同目录临时文件再整体替换，替换前读取已有产物的版本标识，版本不同才替换。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本验证配准精度、两代掩码裁决、融合拼接一致性与中断恢复，并输出核验报告。
