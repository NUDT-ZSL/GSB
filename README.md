互动叙事项目在架构评审通过后进入首个版本实现，工作区目前只有空目录，需要在其中落地一个可集成的推演组件与完整示例。剧本由场景节点、带前置条件与副作用的事件以及分支选择构成，玩家选择会改变角色关系值、持有物品、已揭示线索与节点标志。评审确定的核心约束是关系值与数值阈值必须以定点数参与判定与副作用累加，同时保留 float64 参考路径用于误差诊断，因为关系值沿事件链逐步累加，浮点舍入会让本应可触发的事件被判为不可达，进而改变整条因果链。剧本、状态声明与选择序列全部由固定种子在本地确定性生成，不依赖任何外部服务。

任务环境与准备：
Windows 10 或 11 本地开发机，安装 Python 3.11 或 3.12，并执行 pip install numpy 安装 NumPy 1.26 及以上版本。
无需数据库、容器、外部账号或网络服务；剧本、状态声明与选择序列由仓库内固定种子脚本生成到本地样本目录。
运行前确保样本目录与状态目录可由当前用户读写，且不与已有文件冲突。

业务要求：
1. 实现剧本描述解析与校验：读取本地 JSON 剧本，校验场景节点标识唯一、事件前置条件与副作用引用的状态键均已在状态声明表中定义、选择指向的节点存在、关系值与数值阈值均为有限数且在声明定义域内，非法输入返回带 E_SCHEMA 业务码的 JSON 错误且不产生任何输出文件。
2. 实现定点数学层与浮点参考对照：所有关系值、阈值与副作用累加以规格给定的定点标度量化后参与前置条件判定，同量同时保留 float64 参考值逐事件累加；逐事件记录定点值与参考值的绝对差值，标出首次超过残差容差的事件序号、状态键与节点，最终可触发事件集合与终局状态只依据定点结果。
3. 实现确定性事件推演内核：在每个场景节点内按优先级与声明顺序确定性选择可触发事件，前置条件求值只依赖当前世界状态，副作用按声明顺序以定点累加应用到状态，同一剧本与同一选择序列重复推演必须得到逐字段相同的世界状态、可触发事件集合与事件执行顺序。
4. 实现分支路径推演与终局统计：按选择序列推进所有可达分支路径，统计每条路径的节点数、事件数与终局状态摘要，对任一节点若所有选择在任意可达状态下都无可行事件则标记死锁分支并给出该节点的定点状态快照，死锁判定不得因分支枚举顺序不同而变化。
5. 实现逐状态变化的因果链记录：每次状态键变化记录触发事件标识、该事件被满足的前置条件及其定点判定值、决定该事件可达的上游选择与节点序列，因果链须指向真实执行的事件记录而非事后重演，报告中状态值须与推演日志逐条对应。
6. 实现分步状态快照与版本识别：每成功应用一个事件后把世界状态、已执行事件序号、定点标度与由剧本内容及状态声明规范化摘要构成的版本标识原子写入状态目录，先写同目录临时文件再整体替换，替换前比对已有快照的版本标识，标识变化时不得直接覆盖而须先归档旧版本。
7. 实现中断与续算恢复语义：外部可发送可处理终止信号，使推演只在事件边界写入中断标记并以约定整数退出码退出，未完成事件不得留下可被误认为已完成的状态；再次启动时版本标识一致则从最近事件继续推演，不一致则从头重做；强制终止后重启仅依据已持久化且摘要有效的快照恢复，不承诺生成退出报告。
8. 实现快照摘要校验、并发预计算与资源上限：对每份快照计算内容摘要并与记录摘要比对，不匹配、缺失或声明事件序号与实际不符时判定失效并返回 E_DIGEST，恢复须回退到最近有效快照；大规模分支预计算按并发上限使用有界线程池，在途预计算结果受内存预算约束，任一分块异常时取消其余任务并返回首个错误。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
