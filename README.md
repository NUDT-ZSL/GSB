当前是空白工作区，没有现存项目、代码或数据附件，需要从零构建一个面向手写数字图像 OCR 识别的本地可集成领域组件与完整示例，核心业务问题是识别门限与判定规则的增量校准及其判定追溯。业务对象是本地确定性生成的数字图像样本：每张图由固定种子在 28×28 灰度画布上绘制一个 0-9 的手写数字（笔画模板由显式规则拼出），并附带真值标签与不确定标记；同时提供一份识别配置，声明像素归一化口径、投影特征维度、每类模板原型、距离度量、拒识门限与置信度分档门限。识别链路为：图像归一化与特征提取→按类原型计算距离→门限判决与置信度分档→指标汇总。核心矛盾是：调整门限或替换模板原型只需重算少量节点，但必须保证复用结果与全量重算逐字节一致；且每个判决需可追溯到当时所用特征、模板与门限版本，版本变化后旧判决必须被拒绝或重放为一致结果。

任务环境与准备：
确认 Windows 环境已安装 Python 3.9 及以上版本，并安装 NumPy 1.24 及以上版本（pip install numpy）
创建空白工作区目录，无需预先准备样本文件，所有数字图像、真值标签与识别配置由本地固定种子确定性生成
确保本地进程池可创建子进程（Windows 下使用 spawn 启动方式），运行时不使用任何网络、容器或外部服务

业务要求：
1. 实现确定性的图像归一化与特征提取节点：按配置完成灰度归一化与固定维数的投影特征计算，帧边界与像素索引用显式规则确定；同一 image_id、同一 seed 与同一配置下必须逐字节产出相同特征向量，同分或同距离时按类别编号升序、再按样本编号升序打破平局，禁止依赖系统时间或未声明随机源。
2. 实现按类模板原型的距离打分与拒识判决节点：对每个类别计算特征到原型的距离，按配置的拒识门限与置信度分档门限输出预测类别、拒识标记与置信度档位；须校验拒识标记与置信度档位的组合合法（拒识样本不得给出高置信档），违反返回 E_CONFIDENCE_CONFLICT 并指出 image_id。
3. 实现按节点内容寻址的特征、距离与判决产物缓存：每个节点产物以内容哈希落盘，缓存键须纳入图像内容哈希、归一化参数版本、模板原型集合哈希、距离度量与门限参数版本及上游产物哈希；键相同必须复用快照，键不同必须重算，且每个缓存条目须记录可独立核对的键组成。
4. 实现门限或模板变更后的定向失效传播：调整拒识门限只需重算判决节点，替换某类原型需重算该类距离及下游判决，改变归一化参数需重算特征及其下游全部节点；复用未受影响上游产物后，最终判决必须与全量重算逐字节一致；须输出本次重算节点清单与复用节点清单，不一致时返回 E_INCREMENTAL_MISMATCH 并指出首个偏差 image_id。
5. 实现判决追溯与过期判决拒绝：每条最终判决须记录所用特征版本、原型集合版本、门限版本与节点路径，可按这些记录重放出同一类别、拒识标记与置信度档；当依赖版本已变化而判决仍来自旧记录时返回 E_LINEAGE_STALE 并指出 image_id 与失效版本。
6. 实现特征驻留内存与并行重算节点数的可配置上限，超限时返回 E_RESOURCE_LIMIT 或降级为串行重算并标记降级类别；降级不得改变任何已提交判决，且降级后的重算范围仍须覆盖全部受影响节点，不得遗漏。
7. 实现配置与统计量快照的版本化及整体替换：归一化参数、原型集合与指标统计各携带单调递增版本号与内容校验和，检测到版本号或校验和变化时必须整体替换旧快照而非增量修补，旧版本不得覆盖新版本且回退尝试返回 E_SNAPSHOT_ROLLBACK；损坏或校验和不符返回 E_SNAPSHOT_CORRUPT 并指明快照名。
8. 实现跨模块一致性自检与可集成的完整示例：暴露单图识别、批量识别、增量校准、追溯重放与自检入口；自检校验各节点处理的 image_id 集合一致、预测类别属于受控标签集、距离与判决可由特征与门限独立重算、重算集合与复用集合无交集且并集覆盖全部受影响节点；检测到不一致返回 E_INCONSISTENT 并指出类别，命令行示例读取本地确定性样本输出含预测、距离、缓存键、重算与复用清单、业务码与降级标记的 JSON 报告。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
