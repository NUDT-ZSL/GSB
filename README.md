某安全团队需要在离线 Windows 空白工作区从零开发一个固件镜像分区映射审计引擎，用于对本地确定性构造的固件镜像与差分补丁做完整性与越权写入风险检测。固件镜像为带版本声明的二进制文件：32 字节头（魔数 b'FWIM'、格式版本 uint16 小端、分区数量 uint32 小端、分区表偏移 uint64 小端、镜像声明总长 uint64 小端、保留区 8 字节），其后为若干分区描述记录（分区名长度 uint16 小端、分区类型 uint8、目标槽位 uint8、载荷偏移 uint64 小端、载荷长度 uint64 小端、分区名 UTF-8 字节），载荷区紧随分区表。差分补丁为独立文件：16 字节补丁头（魔数 b'FWDF'、补丁版本 uint16 小端、操作数量 uint32 小端、基镜像标识 uint32 小端），随后为若干操作记录（目标分区名长度 uint16 小端、写入偏移 uint64 小端、写入长度 uint32 小端、分区名字节、新载荷摘要 32 字节）。引擎需在镜像增量换代过程中重建分区映射、识别补丁越界写入与跨槽位越权、检测分区表项重叠与自引用，并输出可复现的 JSON 审计报告与人工可读的分区映射图数据。核心难点在于补丁判定必须同时依赖镜像分区表的区间语义与补丁操作顺序，两者在增量换代中互相约束：一次基镜像替换会令全部未重新校验的补丁结论失效，而补丁又可在无镜像更新的情况下积累成越权写入链。所有样本与测试均在本地生成，不依赖网络、账号或外部数据。

任务环境与准备：
确认 Windows 工作站已安装 Python 3.11 及以上，并把 python 与 pytest 加入 PATH；在空白工作区新建项目目录。
执行 python -m venv .venv 并激活，随后执行 python -m pip install pytest 安装测试依赖，使用本地已有包源或离线 wheel，全程不需要网络账号。
创建 samples 与 reports 输出目录，确认当前用户对工作目录具有读写权限，以便文件锁与临时文件重命名正常执行。
确保所有固件镜像与差分补丁均由仓库内样本生成器现场生成，不依赖任何外部镜像、站点或付费资源。

业务要求：
1. 实现固件镜像头与分区表的严格解析：校验魔数、格式版本白名单（仅 1 与 2）、分区数量与分区表偏移及镜像声明总长自洽、分区名长度与 UTF-8 合法性，任何越界或非法取值返回带错误偏移的 E_HEADER 或 E_PART 业务码，分区表项载荷偏移加长度不得溢出 64 位整型。
2. 重建分区映射并检测结构冲突：识别任意两个分区载荷区间的部分交叉与完全包含返回 E_OVERLAP 并给出冲突分区名对，检测分区载荷引用分区表自身区段的自引用返回 E_SELFREF，并校验分区类型与目标槽位取值白名单，所有结论须与分区表项物理排列顺序无关。
3. 实现差分补丁的解析与写入边界校验：逐条校验补丁头魔数与版本、操作数量与文件长度自洽、目标分区名在基镜像分区集中存在、写入偏移加写入长度不超出该分区载荷区间，越界返回 E_PATCH_BOUNDS，跨槽位写入目标分区槽位与补丁基镜像槽位不一致返回 E_SLOT_ESCALATION，并报告违规操作序号与目标分区名。
4. 实现补丁累积写入链的越权检测：同一分区上多条操作按写入偏移归一化排序后合并区间，若合并区间跨越分区边界或覆盖分区表项描述区则判定为越权写入链并返回 E_WRITE_CHAIN，链中须列出参与合并的操作序号与合并后区间端点。
5. 实现基镜像增量换代后的依赖失效传播：当基镜像标识或格式版本变化时，把所有基于旧基镜像、尚未以新镜像重新校验的补丁判定为失效并返回 E_STALE_BASE，失效集合须依据补丁基镜像标识与镜像代次水位计算；新补丁与换代镜像任意交错导入时最终失效集合必须一致。
6. 实现规模相关的校验策略与真实资源预算：以镜像字节数与补丁操作数为观测值，低于阈值时逐操作完整校验，超过阈值切换为分块校验并在报告中标记降级模式、已覆盖操作比例与未覆盖面；并发度、单补丁实测耗时上限与单补丁操作处理上限可配置，超时以真实计时判定返回 E_TIMEOUT、超操作上限返回 E_OPS，超预算补丁不得中断同批其他补丁且未校验部分不得报告为通过。
7. 实现检查点演进与原子快照整体替换：按已处理镜像代次水位与聚合结论持久化检查点，恢复时只从最后一个完整检查点继续，检测到检查点结构版本或校验策略版本变化须整体重建而非增量续接；检查点、审计报告与分区映射图数据均先写临时文件再整体重命名替换，同一工作目录并发写入以文件锁串行化，锁冲突返回 E_LOCK，强制终止后不承诺生成退出报告。
8. 实现结构化审计报告、确定性样本生成器与 pytest 测试集：报告为可解析 JSON，含文件级结论、每分区映射状态、每补丁操作状态、业务错误码、出错偏移与降级覆盖信息，且另输出分区映射图数据（分区节点、槽位标记、越权链边）；单份补丁失败不中断同批其他补丁，退出码区分全部成功、部分失败与参数错误；生成器以注入参数产出合法与畸形样本并在镜像内写入分区真值同步标记（分区载荷区间、槽位、声明摘要）作为唯一真值来源，验证端只依据这些标记与重算结果比较，测试须断言业务码、出错偏移、覆盖比例与退出码。
