# UV 接缝亮度核对工具

场景美术交付的烘焙光照贴图接入引擎前，核对 UV 接缝两侧亮度是否突变，定位需要返工的接缝。

## 环境

- Python 3.10+（本机验证：Python 3.10.20）
- 依赖：`pip install Pillow NumPy`（本机验证：Pillow 12.3.0 / NumPy 2.2.6）
- Windows 命令行直接运行，无需容器、无需外部素材

## 启动方式

```powershell
# 1. 生成确定性样例（贴图 PNG + UV 边 JSON，重复运行结果一致）
python make_samples.py

# 2. 运行核对
python seam_check.py --image samples/lightmap.png --edges samples/edges.json --out out

# 满规模样例（2048x2048、500 条接缝）
python seam_check.py --image samples/full/lightmap_full.png --edges samples/full/edges_full.json --out out_full
```

产物（输出到 `--out` 目录）：

| 文件 | 内容 |
|---|---|
| `preview.png` | 标注预览图：红=超差，绿=合格，黄=无法判定（三色互异） |
| `checklist.csv` | 逐接缝核对列表：面片编号升序、同面片按输入首次出现顺序，含判定结果与亮度差值 |
| `summary.txt` | 汇总：各状态接缝数、全部判定面片数、含无法判定接缝的面片数 |

## 输入格式

```json
{
  "canvas": {"width": 512, "height": 512},
  "tolerance": 10.0,
  "edges": [
    {"face_id": 2, "material": "wall", "p1": [256, 100], "p2": [256, 200]}
  ]
}
```

判定方法：沿每条边取 8 个采样点，向两侧各偏移 2 像素，按 Rec.601 加权亮度
（0.299R+0.587G+0.114B）分别求两侧平均亮度，差值超过容差判为超差；
透明像素不参与计算；采样点越界或某侧全部透明记为无法判定并附原因；
缺面片编号的边跳过并记录原因；同编号不同端点的边各自独立判定。

## 验收记录（本机实际运行结果）

| # | 验收项 | 操作 | 结果 |
|---|---|---|---|
| 1 | 画布尺寸不一致 | 配置画布宽 +10（`edges_bad_canvas.json`）运行 | 报错“贴图像素尺寸与配置画布尺寸不一致：贴图实际 512x512，配置画布 522x512”，退出码 2，无 preview/列表产物 ✅ |
| 2 | 超差判定与差值 | face 2 跨 100/160 亮度台阶 | 判为超差，列表差值 60.0000，手工重算（两侧均值 160-100）= 60.0 一致 ✅ |
| 3 | 容差缺失/为负 | 去掉容差字段、容差改 -1 分别运行 | 分别提示“配置缺少容差字段 tolerance…”“容差字段 tolerance 为负值（-1.0）…”，均含“容差”字样，退出码 2，无列表与标注图 ✅ |
| 4 | 越界采样 | face 4 端点 (560,540) 越出 512 画布 | 该边记“无法判定（采样点越界 (512,511)，贴图尺寸 512x512）”；删除该边后重跑，其余接缝结果逐行一致 ✅ |
| 5 | 重复/缺失编号 | face 7 两条不同端点边 + 1 条无编号边 | 两条 face 7 各自独立判定（均合格）；无编号边记“跳过：缺少面片编号 face_id” ✅ |
| 6 | 三类标记 | 基础样例出图 | 红（face 2 超差）/绿（合格）/黄（face 4、5 无法判定）三色互异，标记位置与列表端点坐标一致 ✅ |
| 7 | 列表排序 | 输入按 5,2,7,1,(无编号),4,7,3,6 乱序 | 列表顺序为 1,2,3,4,5,6,7,7，跳过条排末尾；差值可复算 ✅ |
| 8 | 透明像素 | face 5 全透明、face 6 部分透明 | face 5 无法判定（法线+侧采样点全部透明）；face 6 透明点被剔除后正常判定（差值 0.0000），相邻接缝差值不受影响 ✅ |
| 9 | 满规模性能 | 2048×2048、500 条接缝 | `Measure-Command` 实测 1.71 秒，preview.png / checklist.csv / summary.txt 齐全 ✅ |
| 10 | 汇总两类面片数 | 基础样例 | 全部判定面片数 7，含无法判定接缝的面片数 2（face 4、5），产物齐全 ✅ |

附加：同一输入连续运行两次，`checklist.csv` 逐字节一致（FileHash 相同），结果可复现。
