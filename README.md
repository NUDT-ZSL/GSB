在空白工作区构建一个面向本地确定性语音样本的说话人识别与分离交互工作台，核心解决交互延迟与计算结果一致性问题。输入为程序合成的多段 WAV 音频（16kHz 单声道 16bit PCM，由固定种子生成：若干说话人声纹片段按区间交替出现、部分区间重叠、段间静音与平稳底噪），一份分离与识别配置 JSON（帧长与帧移毫秒、声纹特征维度与量化档位、能量与谱平坦度门限、说话人聚类距离阈值、最短语音段与最短静音段毫秒、最大并发数、交互延迟预算毫秒、快照提交间隔）以及一份在线编辑命令流 JSONL（每行包含命令序号、命令类型（修改聚类阈值、裁掉某时间区间、合并或拆分说话人、替换某区间音频）与参数）。工作台需要完成逐帧声纹特征抽取、语音活动区间切分、说话人聚类与区间归属判定，并支持用户反复下发编辑命令后增量重算，同时保证多次交互后的最终分离结果与从空白状态按相同最终输入串行执行完全一致。交互延迟预算只影响摘要返回时机，不得以后台线程超时声称失控计算已被终止。

任务环境与准备：
安装 Python 3.11 或更高版本，并安装 numpy、soundfile 与 pytest，全部为本地包，不访问网络资源。
在本地生成合成 WAV 样本目录：使用固定种子脚本产出若干 16kHz 单声道 16bit PCM 文件，包含交替与重叠的声纹片段、静音段与平稳底噪，样本与脚本置于工作区 data 目录。
准备分离与识别配置 JSON 与在线编辑命令流 JSONL 样例，覆盖聚类阈值修改、时间区间裁除、簇合并拆分与区间音频替换四类命令，并准备一份异常注入清单用于验证格式与参数校验路径。
确认 Windows 本地文件系统上临时文件加原子替换可正常执行，并为快照目录预留可写空间；不依赖任何外部服务、GPU 或线上账号。

业务要求：
1. 实现音频读取与逐帧特征抽取层：扫描输入目录下所有 WAV 文件，校验容器头、采样率、声道数与位深，不合规时输出 E_AUDIO_FORMAT 并进入失败清单；按配置帧长与帧移切帧，末帧不足帧长按补零处理；每帧计算能量对数、过零率与按配置维度与量化档位确定的声纹谱特征，计算过程禁止随机性，同一音频在任意运行中必须得到逐帧一致的特征与帧指纹。
2. 实现语音活动切分与重叠区间标注：依据配置的能量与谱平坦度门限做双门限迟滞判定，得到语音区间与静音区间，并对声纹特征相似度高于配置阈值的相邻语音区间标记为疑似重叠；输出每段起止帧、起止毫秒、是否重叠以及判定所依据的门限值；短于最短语音段的区间并入相邻静音，持续短于最短静音段的间隔并入相邻语音，区间合并后的段顺序按起始帧升序。
3. 实现说话人聚类与区间归属判定：以语音区间平均声纹特征为输入，按配置的聚类距离阈值做确定性凝聚聚类，簇间距离同分时按簇内最小帧序号决断；每段区间归属距离最近的簇，距离相同按簇标识字典序决断；输出说话人簇清单、每簇成员区间与每区间归属得分，并支持在命令流中合并两个簇或拆分某簇为两个子簇。
4. 实现基于内容指纹的增量失效与重算范围判定：为特征抽出、活动切分、聚类、归属判定各阶段产物计算由上游内容指纹与参数指纹派生的缓存键；当编辑命令修改聚类阈值、裁掉时间区间、合并或拆分簇或替换某区间音频时，仅将受影响阶段及其全部下游标记失效并纳入重算集合，未失效阶段必须直接复用产物且不得重复计算，复用与失效清单须写入结果。
5. 实现交互延迟预算与预算内响应语义：每条编辑命令触达后在配置的交互延迟预算内，优先返回当前可用的最新说话人分离摘要与受影响区间清单；超预算部分转为后台继续计算并以 E_INTERACT_BUDGET_PENDING 标记未完成项，预算耗尽不得以延迟代替计算，后台完成后须以原子替换更新摘要版本，摘要须标明是否为预算内结果；该标记只表示未完成，不声称后台计算已中止。
6. 保证多次交互后增量结果与串行全量一致：从任意初始状态执行任意编辑序列，每次命令后增量运行得到的说话人簇划分、区间归属、簇内成员顺序、复用清单与最终诊断摘要，必须与从空白工作区按相同最终输入与配置一次性串行执行的结果逐字段一致；该一致性须在两种量化档位与两种聚类阈值下分别验证并写入比对摘要。
7. 实现并发处理与串行一致性以及异常隔离：使用线程池并发执行帧特征与区间归属计算，最大并发数取自配置，每个任务携带由文件名、帧序号或区间序号派生的稳定排序键，无论线程完成顺序如何，最终帧记录顺序、区间顺序、失败清单顺序必须与单线程顺序执行一致；单帧或单区间在任阶段抛异常时记录标识、阶段名与异常类型并继续其余项，全部处理完成后输出失败清单。
8. 实现阶段快照恢复、退出语义与诊断报告：各阶段以临时文件加原子替换方式持久化快照，快照含阶段名、配置哈希、命令游标、已完成区间列表与产物版本号；收到可处理的退出信号时完成当前命令的快照提交后以整数退出码 0 退出，强制终止后仅依据已完整替换的快照恢复，恢复后继续执行所得结果须与不中断运行一致；最终生成 JSON 报告含簇划分、区间归属、复用与失效统计、每命令响应耗时与是否超预算、快照版本号与失败清单。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地合成音频与编辑命令流验证分离结果、增量与全量一致性、预算标记及恢复后结果一致，输出诊断报告。
