在游戏活动录像与赛事取证的后期流程中，团队会收到来自多台设备的多条音视频素材，需要把不同采样率、位深的音频通道与多个视频片段按各自的本地时间戳合并成一条可追溯的统一时间轴，并对拼接结果做完整性取证：任何一段素材的偏移、增益、静音区间、裁剪范围以及在时间轴上的位置都必须可被独立复核。当前为空工作区，需从零开发一个本地桌面工作台。输入为程序按确定性规则生成的本地样本：多段 WAV 音频（单声道或立体声，16bit 或 24bit，16k/44.1k/48kHz）与一个 JSON 取证工程描述（各素材文件、声明的本地起始时刻毫秒、增益、静音区间、裁剪区间、目标采样率与位深、目标声道布局、分块规格、并发上限、内存预算、状态目录与编辑脚本）。音频内容样本自带写入文件头的确定性同步标记说明，用于核对偏移来源。工作台需支持统一时间轴对齐、逐段取证记录、编辑后增量重算、中断续做与导出可复核的取证报告。

任务环境与准备：
确认 Windows 上安装 Python 3.10 及以上，并能导入 NumPy 与标准库 tkinter（无需额外图形库）。
在工作区创建项目目录，准备一个生成本地确定性样本的脚本：按固定种子生成多段 WAV 音频及其 JSON 取证工程描述，音频文件头写入同步标记说明。
准备测试用状态目录与输出目录，确认可写入同目录临时文件并执行整体替换。
不依赖任何真实素材、在线服务、GPU 或外部音视频工具。

业务要求：
1. 实现取证工程描述与素材解析校验：读取工程 JSON 与各 WAV 文件头，校验采样率属于允许集合、位深为 16 或 24、声道数与声明一致、起始时刻为非负整数毫秒、增益为有限浮点、裁剪与静音区间不越出源时长，非法素材记录其索引并返回业务码 E_MEDIA，合法素材继续处理。
2. 实现统一时间轴对齐与采样级误差控制：以目标采样率为真值时间轴，按起始时刻把各素材映射到整数采样点位置，采样率转换采用有理数比多相重采样，映射误差不超过 1 个目标采样点；同时按素材中的同步标记说明核对偏移来源，偏移核对结果与映射结果不一致时须在报告中标出并返回 E_SYNC。
3. 实现逐段静音、裁剪与增益处理：静音区间与裁剪区间以源素材时间声明，须在重采样与偏移对齐后落到成品时间轴上准确生效，边界不得出现越界衰减或泄漏；线性增益按声明应用，发生超满量程时按可预期规则处理并逐段计数，处理后的波形与该段独立参考计算在容差内一致。
4. 实现逐段取证记录与因果可复核账本：为每段素材记录原始时长、映射后起始与结束采样点、裁剪前后有效采样点数、增益后峰值与静音区间生效结果，记录只依赖输入快照与确定性计算顺序，不允许以后来的成品反推；报告中的成品采样点可由这些记录独立复算出且与成品逐点一致。
5. 实现编辑脚本的增量重算：按编辑脚本顺序应用对增益、起始时刻、静音区间、裁剪区间与素材启停的修改，任一步只把沿时间轴与被修改参数影响到的区间标记为失效并重算，其余区间复用已持久化结果；增量结果与同输入从头全量计算逐采样差不超过 1 个量化级。
6. 实现分块级持久化与版本识别恢复：按固定采样点块把成品时间轴分块，每块完成后把该块音频结果、块摘要与由全部素材内容、工程参数规范化摘要构成的版本标识原子写入状态目录，先写同目录临时文件再整体替换，替换前比对版本标识，标识变化时不得直接覆盖而须归档旧版本；续做时复用摘要有效块只算缺失块。
7. 处理可处理终止信号、强制终止与封装原子写出：可处理终止信号只在采样点块边界生效，写入中断标记并以约定整数退出码退出，未完成块不得留下可被误认为完成的结果；强制终止后重启仅依据已持久化且摘要有效的块状态恢复，不承诺生成退出报告；成品 WAV 与取证报告须整体替换并保持版本一致。
8. 实现并发素材解码与资源上限及桌面诊断视图：按工程并发上限使用有界线程池并行解码与重采样素材，同时在途解码缓冲与重采样中间量总量受内存预算约束，超出时按素材声明顺序等待而不降低精度；任一段失败时取消其余待处理段并返回首个错误，且最终结果与并发度为 1 时逐采样一致；本地桌面视图展示时间轴素材条带、逐段取证账本与失效块列表，可选中素材或时间点并高亮其对应的账本记录与重算范围。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地样本验证多轨对齐、逐段取证账本可独立复算成品、编辑增量一致性与中断续做，并附报告输出。
