航天任务演示与遥测可视化制作组要把多波段空间观测相机拍下的行星表面与目标航天器影像整理成可用于评审的反射率素材：原始数字量化值里同时叠着传感器暗电流、镜头暗角衰减和大气路径辐照，直接按波段亮度比较会把同一种地表材质误判成不同材质。制作组手里只有同一场景的太阳定标板、对应暗电流帧、逐波段入射与观测几何、传感器增益和位深，以及几块已知地物区域的真值反射率；部分波段的定标板还被云影或过曝污染，各波段之间还存在整体偏移。需要在评审前得到逐波段反射率图、合成真彩影像和能说清每个判据的标定记录，并在替换单波段定标点或暗角参数后快速给出可比对的新结果。

任务环境与准备：
准备 Linux（WSL Ubuntu）与 Python 3 运行环境，并安装 NumPy 用于多波段影像的数组运算、最小二乘求解与重采样。
在工作目录中从零建立项目，样本由程序自带确定性生成器按固定种子产出，不依赖外部影像或真实相机数据；启动本地演示入口后可执行逐波段查看与替换重算。

业务要求：
1. 从固定种子生成的观测工程中逐波段读取原始辐射影像、暗电流帧、暗角衰减场参数、定标板像素坐标与已知反射率，先做暗电流减法再按暗角场除法校正，输出校正后辐射影像及记录每个波段实际减去与除去的量级摘要，暗电流全零与暗角场近似均匀的波段必须与普通波段同样可被处理且记录不产生除零或空记录。
2. 以定标板各采样点已知反射率与逐波段太阳入射角、观测角建立辐射传输线性模型，用最小二乘联合求解该波段增益与大气路径辐照项；对残差超过阈值的定标点做迭代剔除并给出每轮剔除的点位与残差，定标点仅剩两点时仍要求解并明确记录解的自由度与不可唯一判定的分量。
3. 利用求解的增益与大气项把各波段校正后辐射值换算为地表反射率，逐波段输出反射率图，并按固定波段映射合成一张真彩反射率影像；合成时必须对反射率做上限截断而不允许负值或超界值进入影像，同时保留截断前的原始数值供偏差统计。
4. 在波段之间以特征点估计整体平移偏移，把各波段反射率重采样到统一网格，输出每个波段的配准参数与重采样记录以及对齐残差；面对波段间大偏移样本时必须给出偏移超限判定，不能把超限的波段静默拼进合成影像。
5. 针对每块已知地物区域计算反射率与解析真值的偏差，并对定标板局部过曝、定标点不足、配准偏移超限三类问题分别标记不可信波段及原因；同一波段若同时触发多条原因需要全部列出而不是只留一条，且不可信波段在真彩合成中被替换或剔除的处理必须在记录中可查。
6. 在替换单波段定标点集合或暗角参数后只重算受影响波段及其关联区域，与全量重算的逐波段反射率图、偏差报告和不可信标记逐项比对一致性；版本识别必须依据标定参数快照的版本变化而非文件时间，未受影响的波段结果应保持逐字节一致。
7. 将各波段标定参数、残差、配准参数、不可信标记和区域偏差报告持久化为可回读的快照，重开工作台后从快照恢复出与上次一致的标定状态并允许继续做替换重算；快照损坏或字段缺失时要拒绝加载并指出缺失项，不得用默认值补全后静默续算。
8. 提供本地可交互的演示入口，能够逐波段切换查看原始影像、校正后辐射、反射率图与真彩合成并叠加区域偏差与不可信原因；切换与重算触发时界面数值必须与内核记录同源，重算期间不阻塞退出并保证退出后重开从最近一次完整快照恢复。

验收：
用解析真值核对区域反射率偏差与增益、大气项系数，验证污染定标板剔除、不可信标记、增量与全量结果逐波段一致及快照恢复。
