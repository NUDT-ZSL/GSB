为本地中文 NLP 处理链路构建一个可集成的分词与词性标注级联组件。输入是 UTF-8 文本行（字段含 doc_id、line_no、text）以及随附的字符偏移表与标点类别标注；组件需要完成确定性分词、词性标注、置信度打分，并输出带字符级偏移与分数区间的标注结果。业务关注点在于数值精度与误差传播：分词边界的字符偏移必须精确到码点，分词候选的分数经过对数概率累加、归一化与合并后传给词性标注阶段，标注阶段使用这些分数做加权打分，因此任何缩放、下溢保护、舍入策略都会沿链路传播并改变最终标签与置信区间。初始工作区为空，需从零创建项目，并交付可被其它模块直接调用的领域组件、命令行示例与本地确定性样本。

任务环境与准备：
确认使用 Windows 与 Python 3.11 及以上，安装 numpy 到本地虚拟环境。
在工作区创建项目目录并准备本地确定性样本：标注文本行、词典、字符偏移表与参考标签，均由脚本生成或固定写入。
准备一组用于注入异常的变体输入（格式错误词典、偏移长度不符、重复 doc_id、非法词性标签），供示例演示使用。

业务要求：
1. 实现确定性的词典驱动分词器：基于随附词典构造最大匹配与最短路径候选，每条候选边携带对数概率分数；对同一文本在同词典同参数下必须产出完全相同的切分序列与逐词分数，并给出字符级起止偏移，偏移以 Unicode 码点为单位。
2. 实现分数聚合的数值策略层：对候选路径使用对数域累加并在候选数超过阈值时接受可配置的缩放与次正规数保护；提供可切换的舍入模式，且所有中间量以 float64 计算，对外输出统一为带明确精度的区间形式，禁止用 float32 静默降级。
3. 实现从分词分数到词性标注的误差传播计算：标注阶段以分词分数为权重做加权打分，组件须同时输出传播后的置信上界与下界，并给出误差放大比；当输入权重无法归一时返回业务码 E_NORM_FAIL 并在结果中保留原始未归一化量。
4. 实现可解释的误差归因：对最终标签与参考标签不一致的行，输出从字符边界分数到标注分数的逐级贡献分解，定位主导误差来源为分词路径选择、权重归一化或标注加权中的哪一级，并记录各级的数值偏差量。
5. 实现配置与输入的校验链路：词典条目格式错误、偏移表长度与文本码点长度不一致、重复 doc_id、词性标签不在受控集合内分别返回 E_DICT_FORMAT、E_OFFSET_LEN、E_DUP_DOC、E_POS_TAG 并在 stderr 给出可定位行号；校验失败不得产生部分标注输出。
6. 实现受控的资源上限与降级：为候选数量、每行最大码点数、总内存估计设置可配置上限，超限时返回 E_RESOURCE_LIMIT 或按明确策略截断候选；降级必须在结果中标记降级类别，且降级不得改变字符偏移的精确性。
7. 提供可集成的领域组件接口与完整示例：组件以函数或类形式暴露分词、标注、归因三个入口，命令行示例读取本地样本并输出 JSON 结果（含偏移、分数区间、传播比、业务码），并附带一次注入异常输入的演示，使示例在无外部服务下可重复运行。
8. 实现跨阶段一致性自检：校验每条输出词的偏移首尾相接且覆盖全行、标注标签来自同一受控集合、分数区间顺序合法，检测到违反时返回 E_INCONSISTENT 并指出不一致类别与 doc_id、line_no；同时保证同一输入多次运行结果逐字节一致。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
在本地确定性样本与注入异常输入上验证分词词性结果、分数区间与误差归因一致且业务码正确。
