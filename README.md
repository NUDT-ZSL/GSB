当前是空白工作区，需要从零实现一个本地块存储快照与回滚组件，用于在确定性样本上复现快照链的增量更新、链分叉依赖失效与中断恢复一致性问题。本地 JSON 样本给出：卷描述（卷 ID、块大小、块数量、每个块的初始内容），快照计划（快照序号、父快照 ID、创建逻辑时钟毫秒、覆盖的块区间与每块写时复制数据），以及回滚请求清单（目标快照 ID、回滚逻辑时钟、是否保留回滚后新增快照）。组件需把卷与快照物化为本地内容寻址的块文件，维护快照链与块级归属映射，支持从任意存活快照回滚卷内容并继续创建新快照。核心难点是：回滚到目标快照后，目标快照之后创建的兄弟分支快照必须依据引用关系判定失效或标记为孤儿，孤儿快照的块引用不得继续阻止垃圾回收；同时回滚过程被强制终止后，必须依据持久化状态恢复到一致视图，不能出现块归属映射与引用计数脱节。

任务环境与准备：
安装 Python 3.11 及以上版本，并确认可创建虚拟环境。
在虚拟环境中安装 numpy 与 pytest，SQLite 使用 Python 标准库 sqlite3，无需额外安装。
创建工作区目录，并在其中准备样本 JSON 文件：卷描述、快照计划与回滚请求清单，均放入本地 samples 子目录。
确认本地磁盘可写，用于块目录、临时文件与 SQLite 数据库文件的落盘。
Windows 环境下以 python -m 方式运行命令行入口，路径分隔符在代码内统一处理。

业务要求：
1. 实现卷、快照计划与回滚请求的解析校验：卷 ID 与快照序号唯一，块大小与块数量为正整数，父快照必须存在且创建逻辑时钟严格晚于父快照，覆盖块区间不越界且每块写时复制数据的摘要与内容一致；构建含父链与分叉的快照链模型，非法输入必须返回明确业务错误码且不写入任何持久化状态。
2. 实现内容寻址的块存储：每个块按确定性规则计算 SHA-256 摘要写入本地块目录，采用临时文件加重命名保证原子落盘，相同块内容重复写入必须复用同一摘要文件且不产生重复副本；块摘要到引用来源的映射必须持久化，使恢复后能据此重建引用计数，摘要文件被篡改时须通过与快照清单登记值比对识别并拒绝使用。
3. 实现快照创建与写时复制：新建快照时只对被覆盖块写入新块并记录块级归属（块号到摘要），未覆盖块沿用父快照归属；快照清单须记录父快照 ID、覆盖块区间、每块摘要与逻辑时钟，任意快照的可见卷内容必须能通过沿父链回溯逐块计算得到，且该结果与全量重放全部快照计划得到的块归属逐块一致。
4. 实现回滚的状态演进与依赖失效闭包：回滚到目标快照时卷的块归属整体切换为目标快照的可见内容，沿快照父子引用关系计算失效闭包，把目标快照之后创建的兄弟分支快照判定为孤儿并记录其触发来源与引用路径，孤儿快照的块引用不得继续阻止垃圾回收；回滚失败或回退请求须被拒绝并返回业务错误码，不得留下部分切换的卷视图。
5. 实现块级引用计数与垃圾回收：块摘要被卷当前视图、存活快照与未提交事务引用时计数为正，回收只能删除零引用块；回收必须与快照链视图版本绑定，避免回收正在被分叉裁决或回滚过程引用的块，回收动作须逐块记录保留原因或删除依据，使同一输入重复运行得到逐位一致的回收清单。
6. 实现强制终止后的恢复一致性：把快照链视图版本、块归属映射、引用计数、回滚阶段与逻辑时钟水位以事务原子写入 SQLite；进程在快照创建、回滚切换或回收任一阶段被强制终止后，恢复路径依据持久化状态识别已提交与半提交步骤，只重放未完成部分，不得重复递增引用计数或提前删除被引用块，恢复后 verify 须通过。
7. 实现多进程并发一致性与幂等：允许多个实例并行创建快照、回滚与回收，通过 SQLite 事务与文件锁保证同一快照序号同一版本只提交一次、同一块摘要只被原子物化一次、同一回滚请求重复提交幂等；读取方只能看到完整已提交的链视图而非回滚中间态，并发回滚冲突须以稳定规则裁决胜出者并拒绝落败请求。
8. 提供命令行接口与可重复演示：支持 load、snapshot、rollback、gc、resume、status、verify 子命令，status 以稳定排序 JSON 输出当前链视图版本、每个快照的存活或孤儿状态与块引用计数摘要，verify 校验持久化链视图、块归属映射与引用计数三者一致并附运行结果。
