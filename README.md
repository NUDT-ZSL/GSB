在空白工作区构建一个面向表格分类模型的并行训练任务调度与资源预算工作台，用于在本地确定性合成的表格数据上批量试验多组传统 ML 分类模型（逻辑回归、决策树、k 近邻），并对训练任务做并发调度与 CPU 时间预算控制。输入为一份本地实验配置 YAML（数据描述：样本量、数值列与类别列定义、缺失率、类别不平衡比例、生成种子；模型网格：每个模型类型的学习率或邻居数、最大迭代数、树的深度等超参数候选；调度参数：最大并发任务数、全局训练时间预算毫秒、单任务预算配额毫秒、随机种子列表、快照提交间隔）以及一份按固定种子确定性生成的表格数据描述。工作台需按网格展开训练任务，调度器在全局时间预算约束下把任务分配到线程池执行，每个任务产出交叉验证准确率与逐折指标，并支持在超预算时留下可判定的中间状态。核心难点是：并发数与全局时间预算共同约束任务选择顺序，而同一任务在不同并发度下必须得到完全一致的模型指标与预测结果；时间预算的度量必须使用可观测的单调时钟统计真实训练耗时，而非以线程超时宣称已终止计算。

任务环境与准备：
安装 Python 3.10 或以上，以及 NumPy 与 PyYAML（使用本地已安装版本或离线 wheel，不依赖网络上的额外包）。
在空白工作区创建项目目录，自行按约定放置实验配置 YAML 与数据描述文件，样本数据由程序内的固定种子生成，不引入外部数据集。
确认运行环境的系统单调时钟可用，测试命令以本地进程方式直接运行，不使用任何容器或远程服务。
准备重复演示的固定输入配置与两次不同并发数的运行命令，用于人工核对结果一致性。

业务要求：
1. 实现配置与合成数据加载层：读取实验配置 YAML 与数据描述，按列类型与固定种子确定性生成表格数据，完成缺失值填充（数值列取训练折中位数，类别列取众数）与类别编码，并按配置的类别不平衡比例重复采样少数类；对未知列、类型不符、目标列缺失、生成种子非整数、类别列基数超上限分别输出 E_CONFIG_INVALID，并进入失败清单而非中断整体运行。
2. 实现三种分类模型的确定性训练与交叉验证：逻辑回归按固定批量顺序与固定学习率执行梯度下降并记录每轮损失，决策树按固定分裂增益运算顺序与固定并列打破规则构建，k 近邻按固定距离度量与固定邻居排序规则预测；三者的交叉验证折划分必须由配置种子与样本序号派生且互不重叠，同一配置与数据多次运行得到的逐折准确率、混淆矩阵与预测标签必须逐项一致。
3. 实现按超参数网格展开的任务调度器：依据模型网格枚举全部训练任务，调度器维护就绪队列并按其稳定键排序取出任务分配给工作线程，最大并发数取自配置；每个任务记录入队序号、开始与结束的单调时钟读数、估算代价与实际耗时，调度决策须输出可审计记录（含被选中任务键与选择依据）。
4. 实现全局时间预算与单任务配额的资源控制：调度器累计各任务真实耗时并与全局预算比较，超出全局预算时不再启动新任务，未启动任务以 E_BUDGET_EXHAUSTED 标记并保留其在就绪队列中的位置；单任务耗时超出单任务配额时须在该任务内部的可中断点检查并中止，输出 E_TASK_TIMEOUT 并保留已完成的轮次损失轨迹；中止必须由模型循环自身的检查实现而非依赖线程超时终止。
5. 保证不同并发度下的结果与串行执行完全一致：同一配置分别以并发数 1 与并发数大于 1 运行，最终各任务的逐折准确率、混淆矩阵、预测标签、任务完成顺序清单、调度决策记录顺序与预算消耗汇总必须逐字段一致；每个任务携带由任务稳定键与折号派生的排序键用于结果归并，禁止因线程完成顺序影响任何输出顺序或数值。
6. 实现阶段化快照与恢复一致性：将网格展开、任务训练、结果汇总划分为阶段，各阶段以临时文件加原子替换方式持久化快照，快照包含阶段名、配置哈希、数据指纹、已完成任务键列表、已消耗时间预算、部分结果摘要与版本号；重启时读取最新快照并校验版本号、配置哈希与数据指纹，不一致输出 E_CONFIG_MISMATCH 并拒绝续跑，一致时从该阶段游标继续且恢复后的最终结果与不中断运行逐字段相同。
7. 实现异常隔离与可处理退出语义：单个训练任务在数据折划分、迭代训练或预测阶段抛异常时记录任务键、阶段名、业务码与异常类型到失败清单并继续调度其余任务，失败任务不得进入结果汇总；收到可处理的退出信号时完成当前任务的指标落盘与快照原子替换后以整数退出码 0 退出；进程被强制终止后重启仅依据已完整替换的快照恢复并输出恢复点信息，不得承诺生成退出报告。
8. 实现预算调度报告与可重复演示输出：每次完整运行生成 JSON 报告，包含每个任务的超参数、逐折准确率、混淆矩阵、开始与结束耗时、预算配额内是否超时、全局预算剩余、被 E_BUDGET_EXHAUSTED 标记的任务清单、失败清单、快照版本号与配置哈希；报告以临时文件加原子替换方式写盘，并在末尾按固定格式输出一段可逐字比对的摘要行供重复演示核对。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
以本地合成数据验证并行调度、全局预算与单任务配额中止、快照恢复及不同并发度结果逐字段一致，附运行输出。
