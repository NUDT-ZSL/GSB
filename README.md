在空白工作区构建一个面向长上下文 LLM 位置编码外推能力的诊断工作台，核心解决位置编码方案在训练长度之外外推时的可复现验证与异常注入问题。输入为本地确定性合成样本目录：一份位置编码配置 JSON（方案名可选旋转位置编码、线性内插、NTK 感知缩放三种，基频参数、训练上下文长度、外推目标长度、维度、缩放因子、精度档位、并发数），一份合成注意力打分样本 JSONL（每行含样本 ID、查询位置、键位置列表、按固定种子生成的维度特征向量），以及一份异常注入清单 JSON（指定在哪些样本的哪些阶段注入非有限维度值、位置越界、基频为零与缩放因子不合法等故障）。工作台需对每种位置编码方案在训练长度内与外推目标长度上分别计算注意力打分，追踪外推误差随相对距离与位置的传播，并输出可复现的诊断报告与可视化摘要。

任务环境与准备：
安装 Python 3.10 及以上版本，并安装 NumPy；无需 GPU、网络或外部服务。
在空白工作区创建项目目录，准备本地样本生成脚本以生成位置编码配置 JSON、注意力打分样本 JSONL 与异常注入清单 JSON。
确认工作目录可读写，用于快照临时文件与原子替换；Windows 上须使用整数退出码。

业务要求：
1. 实现位置编码方案集与统一接口：提供旋转位置编码、线性内插与 NTK 感知缩放三种方案，均按给定位置索引与维度生成位置向量或旋转对；三种方案须共用同一查询与键特征输入接口，同一配置与输入下每种方案的输出必须逐元素可复现，方案名与版本号写入产物元数据，未知方案名输出 E_SCHEME_UNKNOWN。
2. 实现注意力打分计算与训练长度内外分层：按样本的查询位置与键位置列表计算点积注意力打分，并区分键相对距离落在训练上下文长度内与外推区间的样本；外推区间内同一相对距离下的打分与训练长度内同距离打分须分别汇总，输出各方案在内外区间的分数分布、极值与分层样本计数。
3. 实现外推误差逐级追踪：以训练长度内位置编码结果为参考，计算外推位置上位置向量、点积打分与归一化注意力权重三个环节的偏差，逐级标注误差首次超过配置容差所在环节；偏差计算使用 float64 并在报告中保留足够有效位数，超差样本须记录其位置、相对距离与主导环节。
4. 实现基频与缩放因子的边界敏感性诊断：对每个方案扫描配置给出的基频与缩放因子邻域取值，输出外推区间打分偏差随参数变化的敏感性排序；当某参数取值恰好使外推位置编码发生维度级截断或缩放溢出时，记录边界敏感样本并输出其双精度参考值，不得以浮点比较误差掩盖真实边界。
5. 实现异常注入与确定性执行：按注入清单对指定样本的指定阶段施加真实输入故障，包括非有限维度特征、键位置越界、基频为零与缩放因子非正；注入后工作台须以确定性顺序执行并输出每条样本命中的注入项编号，对应业务码为 E_NONFINITE_FEATURE、E_POS_OUT_OF_RANGE、E_BASE_ZERO 与 E_SCALE_INVALID，注入配置哈希纳入报告。
6. 实现基于内容指纹的增量失效与重算范围判定：为每种方案的位置编码、打分与误差追踪结果计算由方案参数指纹、样本内容指纹与精度档位派生的缓存键；当切换方案、修改基频、缩放因子或训练长度时，仅使受影响样本与阶段失效并纳入重算集合，未失效部分必须直接复用且不得重复计算，复用与重算清单写入报告。
7. 保证并发计算与串行执行逐字段一致：使用线程池并发处理样本与方案组合，最大并发数取自配置；每个任务携带由方案名、样本 ID 与阶段名派生的稳定排序键，无论线程调度顺序与并发度如何，最终方案输出顺序、样本打分顺序、误差追踪清单顺序与失败清单顺序必须与单线程按方案名再按样本 ID 顺序执行完全一致。
8. 实现阶段快照整体替换、恢复一致性与诊断报告输出：各阶段以临时文件加原子替换方式持久化快照，清单文件记录全局版本号、配置哈希、注入配置哈希、已完成方案与样本列表；启动时以版本号与配置哈希判定是否续跑，不符则输出 E_CONFIG_MISMATCH 并拒绝恢复；收到可处理的退出信号时完成当前阶段快照后以整数退出码 0 退出，强制终止后仅依据已完整替换的快照恢复；每次完整运行生成 JSON 报告，含各方案内外区间分数统计、误差追踪摘要、敏感性排序、注入命中清单、复用与重算清单、快照版本号及失败清单，报告原子写盘。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
在本地样本上验证三种位置编码的外推误差追踪、异常注入命中与并发增量结果一致性，并生成原子写盘的诊断报告。
