当前是空白工作区，没有现存项目、代码或数据附件，需要从零构建一个面向文档图像版面阅读顺序分析的本地算法实现与可复现实验环境。业务对象是本地确定性生成的版面样本：由固定种子在固定尺寸画布上按若干版面模板绘制文本框（含文本行、栏、标题、图注、页眉页脚等类型），每个文本框带像素级外接矩形与类型，样本清单为 JSONL（字段含 page_id、canvas_shape、blocks 列表，每块含 block_id、x1、y1、x2、y2、block_type、text_len、reading_index 真值，另含 layout_family、seed），真值阅读顺序以 reading_index 给出。分析链路被建模为：块几何归一化与特征构造→候选后继边构造与代价打分（上下相邻、同栏、跨栏、跨区）→全局顺序求解（受版面约束的指派）→顺序一致性校验与指标汇总。核心业务难点是数据规模变化下的算法取舍：页内块数小、同栏密度高时精确求解顺序最优但候选边与比较次数膨胀；大页跨栏跨区多时精确求解超出候选预算与驻留内存，退回贪心或分带近似又可能破坏同栏保序。需要给出可复现的取舍裁决与可核对的实验报告。

任务环境与准备：
安装 Python 3.10 及以上，并安装 NumPy（建议 1.24 及以上），无需外部服务或数据集。
在空白工作区建立项目目录与虚拟环境，确认可执行 python 命令并能够 import numpy。
准备本地确定性版面样本生成脚本，用固定种子产出固定尺寸画布与文本框清单及 reading_index 真值。
确认工作目录可写，用于存放快照、缓存条目与实验报告 JSON 文件。

业务要求：
1. 实现确定性的块几何归一化与候选后继边构造：按画布尺寸归一化块外接矩形并派生同栏、上下相邻、跨区等特征，为每块生成候选后继边；同分边按来源块 block_id 升序、再按目标块 block_id 升序打破平局，同一输入与配置下候选边集合与逐边代价必须逐字节一致。
2. 实现候选边代价打分层：由类型先后约束、列号关系、垂直间距与水平重叠组合成边代价，类型顺序违规须施加可配置惩罚；每条边记录各分项贡献，使总代价可由分项明细独立重算一致，权重或惩罚配置非法时返回 E_CONFIG_INVALID 并指明字段。
3. 实现受版面约束的全局顺序求解：在每块恰有一个后继、一个前驱、顺序为单一链路的约束下求解最小总代价顺序，输出阅读顺序序列与总代价；检测到违反单链或块集合未全覆盖时返回 E_ORDER_INCONSISTENT 并指出缺失或重复的 block_id。
4. 实现基于数据规模的自适应算法取舍器：按页内块数、候选边数、跨栏比例与驻留内存余量在精确求解、分带求解与贪心近似三条路径中选择，输出含规模观测与代价估计的取舍记录；同一观测下决策必须逐字节一致，且所选路径与后续求解路径彻底对应。
5. 实现比较次数、驻留内存与路径精度之间的冲突裁决：精确求解提升顺序准确率但逼近比较次数预算，分带求解降低比较次数但可能割裂同栏保序，贪心最快但易违反类型先后；须按显式优先级规则裁决并在取舍记录中说明理由，未达准确率要求时返回 E_ACCURACY_FLOOR 并标明降级路径。
6. 实现路径结果的可核对性：对同一页同时产出所选路径结果与在较小规模子集上可承受的精确路径参考结果，输出顺序位置偏差谱与相邻块对正确率，并记录哪些页因规模未取得参考值；禁止用声明无法取得参考值掩盖本应可比较的页。
7. 实现快照版本化与整体替换及资源上限：版面统计量、代价权重与顺序结果各携带单调递增版本号与内容校验和，检测到版本变化必须整体替换旧快照而非增量修补，损坏或校验和不符返回 E_SNAPSHOT_CORRUPT；为候选边总数、比较次数与驻留内存设可配置上限，超限返回 E_RESOURCE_LIMIT 或降级并标记降级类别。
8. 实现可复现实验环境与跨模块一致性自检：命令行入口读取本地确定性样本跑完整基线与一次规模变化追踪，输出含所选路径、取舍记录、顺序结果、位置偏差谱、页码级指标、业务码与降级标记的 JSON 报告；自检校验候选边集合与顺序结果可互相核对、块集合无遗漏、复用与重算记录对应，不一致返回 E_INCONSISTENT 并指出类别。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地确定性样例验证多规模版面顺序求解、取舍裁决与偏差谱可复现，并核对业务码与报告。
