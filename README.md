当前为空白工作区，需要从零实现一个面向本地解析链路的 DNS 解析与缓存工作台，用于在离线环境下复现真实 DNS 缓存机制的格式互操作与版本兼容问题。工作台接收客户端查询（查询名、查询类型、递归期望），按配置的上游转发链逐级解析，命中本地缓存时直接应答，未命中时按区域转发规则向本地确定性上游解析桩发起查询，并把应答按 TTL 写入缓存。缓存需支持负缓存（NXDOMAIN 与 NODATA）、CNAME 链展开、通配符记录合成与大小写不敏感匹配，并保留原始响应报文以便二次应答。真实问题来源是格式互操作：缓存中的持久化条目可能来自两个格式版本（v1 为行式文本段，v2 为带头部的二进制段），上游返回的报文在压缩指针、EDNS 附加段与大小写保留上存在差异，工作台必须以只读兼容方式读取旧格式缓存并在写出时统一落到当前格式，同时支持显式迁移。

任务环境与准备：
确认 Windows 上可使用 Python 3.11 及以上版本，创建虚拟环境并安装 pytest，sqlite3 使用 Python 自带模块，无其他强制第三方依赖。
准备空工作区目录结构：源码目录、样本缓存目录（含预置 v1 与 v2 段样本及一个 CRC 损坏段）、上游桩配置目录与测试目录，样本须随项目提交且可离线复现。
确认本机允许绑定回环地址上的本地 UDP 与 TCP 端口用于上游桩与查询接口，端口可通过配置指定并支持冲突重试。
所有时间相关判定使用可注入的时钟接口，在测试中以固定逻辑时间驱动，避免依赖真实等待。

业务要求：
1. 实现 DNS 报文的解析与序列化：按报文头部字段解析问题段与资源记录段，正确处理名称压缩指针（含跨段指针与循环指针检测）、TTL 为 32 位无符号数与 A、AAAA、CNAME、NS、SOA、TXT 记录类型。压缩指针成环或越界须返回 E_BAD_PTR，截断报文须返回 E_TRUNCATED，序列化输出须能被自身的解析器逐字段还原。
2. 实现两个格式版本的缓存段互操作：v1 行式文本段与 v2 二进制段须有自描述段头（魔数、格式版本、条目数、CRC32），同一缓存目录可混合存在两种版本段；打开时按段头版本分派读取器，v1 段须以只读兼容方式参与命中与扫描，写入一律以 v2 落盘；遇到未声明的版本须返回 E_UNSUPPORTED_VERSION 并列出支持的版本集合，不得仅因版本未知而丢弃整个目录。
3. 实现显式格式迁移：提供按段迁移接口把 v1 段升级为 v2，须先写临时段并校验 CRC 与条目数后再原子替换，替换前旧段保持可读；迁移中途中断重启后须依据持久化的迁移标记识别未完成迁移并回滚到迁移前状态，同时保留原 v1 段的可读性，迁移成功后再删旧段。
4. 实现正向与负向缓存及 TTL 语义：正向缓存按 RR 类型与查询名（大小写不敏感）索引，负缓存须区分 NXDOMAIN 与 NODATA 并各自使用 SOA 最小 TTL 截断；TTL 以写入时刻的绝对时间戳加原始 TTL 计算剩余值，命中应答时须按剩余 TTL 递减输出，剩余为零的条目须视为过期并不再命中；负缓存与正向缓存共用同一版本化段格式。
5. 实现 CNAME 链与通配符合成：查询命中 CNAME 时须沿链继续解析至最终类型或超过链长上限，链中任一环节的负缓存须向上传播且链长超限返回 E_CNAME_LOOP；通配符合成仅在最具体匹配不存在时启用，合成记录的名称须采用查询名而非通配符名，且大小写差异不得造成重复缓存条目；跨版本段中同一名称的 CNAME 与 A 记录混合时必须得到一致结果。
6. 实现大小写与 EDNS 的格式兼容处理：缓存键使用规范化小写名称但保留首次应答的原始大小写用于回显，来自 v1 段的小写化名称与 v2 段的原始大小写名称须被视为同一键；上游应答携带 EDNS OPT 记录时须在缓存条目中标记其 UDP 载荷大小，客户端未携带 EDNS 时回显须剥离 OPT 且不得改变其余字段，携带不兼容 EDNS 版本时须按报文规则返回 E_EDNS_VERSION。
7. 实现并发查询与缓存写入的一致性：多个客户端并发查询同一名称时须只向上游发起一次查询（在途合并），其余查询等待同一结果；命中读取不得看到写入一半的段，段替换须以原子重命名完成；并发写入同一缓存键时后写覆盖前写但版本段摘要须可校验，进程重启后未完成的在途查询须被丢弃而不写入缓存。
8. 提供本地确定性上游桩与可重复测试：实现可配置应答（含压缩指针、CNAME 链、负应答、EDNS、大小写混合与故障注入）的本地 UDP 与 TCP 上游桩，不依赖外网；pytest 用例须在 Windows 离线覆盖 v1 只读命中、未知版本拒绝、迁移中断回滚、负缓存 TTL 截断、CNAME 环检测、EDNS 剥离、在途合并与重启后缓存一致性。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地上游桩与双版本缓存样本验证解析、格式互操作、迁移回滚与并发查询一致性。
