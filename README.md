# 工具结果格式演进诊断工作台

面向 LLM 检索增强与工具调用链路的本地诊断工作台，解决工具结果在
v1/v2/v3 格式版本演进下的一致性重组、增量失效回溯与快照整体替换问题。
全程本地确定性运行，**不依赖容器、不访问网络**；运行时仅用 Python 标准
库，NumPy 仅用于固定种子的样本生成。

## 环境要求

- Python 3.10+（验证环境 3.10.12）
- NumPy 1.24+（验证环境 1.26.4）
- 标准库 `pathlib` / `hashlib` / `json`

## 目录

```
diagwb/          # 领域模块（读取、迁移、缓存、DAG、来源、快照、工作台）
tests/           # unittest 测试套件（26 个用例）
docs/ARCHITECTURE.md  # 技术说明与机制设计
run_demo.py      # 端到端验证驱动，产出报告与运行结果
data/            # 确定性样本（请求清单 + 三格式结果仓库 + 格式定义）
runtime/         # 内容寻址缓存、结果仓库、快照运行态
reports/         # HTML/JSON 诊断报告与验证结果文本
```

## 一键验证

```bash
python3 run_demo.py                       # 端到端场景并写报告
python3 -m unittest discover -s tests -v  # 完整测试套件
python3 -m diagwb.cli .                   # 交互式诊断工作台
```

## 业务能力对照

1. 三格式读取器、版本分派、损坏行号/字段偏移定位。
2. 双向迁移、升级补全审计、降级丢弃明细（丢弃不静默）。
3. DAG 片段合并与答案组装、合并冲突拒绝、逐片段独立重算。
4. 内容寻址缓存（纳入原始哈希/版本/结构摘要/参数摘要/上游哈希）与增量失效。
5. 过期结果 `E_RESULT_STALE` 拒绝与逐跳来源重放、断链定位。
6. 跨格式语义等价裁决、能力缺口与 `E_SEMANTIC_DRIFT`、全格式往返校验。
7. 三部件版本化快照整体替换、回退/损坏检测、非阻塞并发写控制。
8. 交互诊断视图、跨模块自检、可配置资源上限与降级类别标记。

错误码定义见 `diagwb/errors.py`，机制细节见 `docs/ARCHITECTURE.md`，
实际运行结果见 `reports/verification_results.txt`。
