当前是空白工作区，没有现存项目、代码或数据附件，需要从零构建一个面向语音识别（ASR）转写数据治理的本地可视化与诊断工作台，核心业务问题是 ASR 切片与识别配置的跨版本格式互操作，同时在数据规模变化下做算法取舍，并使切片改写后的下游产物可追溯失效。业务对象是本地用固定种子确定性合成的 16kHz 单声道 PCM 样本（若干语音活动段与静音段拼接，叠加可配置平稳底噪），其转写标注以三个版本并存：v1 为扁平行式切片表（每行以竖线分列存放 utterance_id、start_ms、end_ms、text，无字段名，无置信度），v2 为带字段名的行式（含 start_us、end_us、tokens、speaker、confidence 与词表版本绑定），v3 为结构化 JSON（含 token 级微秒时序、分段标签、置信度区间与增量修订号）。此外还有一份识别配置，声明帧长帧移、能量门限倍数、最短切片时长、最大切片数量、并行 worker 数与量化精度档。工作台需要把一次处理建模为有向无环计算图：PCM 分帧特征→切片边界初判→跨版本切片规范化→按音频特征的边界一致性校验→配置与统计快照汇聚，并在切片改写、词表或配置版本演进时只重算受影响后缀。

任务环境与准备：
确认 Windows 本地已安装 Python 3.10 及以上，并能导入 NumPy；无需网络与其他外部服务。
在空白工作区创建项目目录结构，自行生成确定性 PCM 合成样本、三种格式切片样本与识别配置，样本与种子由题目内参数固定。
准备本地运行与演示命令入口，确保合成样本、迁移演示与失效传播演示可重复执行；不依赖真实音频文件、模型权重或线上站点。

业务要求：
1. 实现确定性的 PCM 分帧与切片边界初判节点：按帧长与帧移切分 16kHz PCM，帧边界以样本索引精确确定，计算短时能量与过零率，按可配置高门限与低门限做滞回判决并合并为候选切片，输出毫秒起止区间与逐帧特征；同一 clip_id、同一 seed 与同一配置下必须逐字节产出相同的帧数、特征与候选区间，同分或同能量时按起始样本索引升序打破平局。
2. 实现 v1、v2、v3 三种 ASR 切片书写形式的读取器，按格式头或字段集分派解析路径；未知格式版本返回 E_FORMAT_VERSION_UNSUPPORTED；行字段数不符、键名缺失、时间字段非整数、start 大于等于 end、utterance_id 重复分别返回 E_FORMAT_CORRUPT、E_TIME_INVALID、E_DUP_UTTERANCE 并指明 clip_id 与行定位。
3. 实现三套书写形式的双向迁移器：v1 升级到 v2、v3 时补全 tokens、speaker、置信度区间与微秒时序并逐项记录补全来源；v3 降级到 v1 时对 v1 无法表达的 token 级时序与置信度区间按显式声明的丢弃规则处理并输出丢弃明细；迁移不得静默改写超出格式能力的字段。
4. 实现跨格式裁决与语义漂移检测：同一切片集以 v1、v2、v3 三种形式书写时，加载与迁移后必须产出相同切片集合、相同毫秒级起止与相同文字内容；当 v1 表达能力不足导致语义不可完全还原时返回 E_SEMANTIC_DRIFT 并指出不可还原字段与受影响切片；不得以默认可接受掩盖漂移。
5. 实现基于数据规模的自适应算法取舍器：按切片数量、帧总数、说话人数与驻留特征内存余量在精确路径（细帧移、逐帧边界精修、全量跨切片比对）与逼近路径（粗帧移、分位边界估计、分块比对）之间选择，输出含规模观测与比较次数估计的取舍记录；同一观测下决策必须逐字节一致，所选路径不得改变已定稿切片的毫秒时间轴语义。
6. 实现切片改写后的增量依赖失效传播与追溯拒绝：修正单条切片标注、提升词表版本、调整门限或帧移时，计算受影响节点与受影响切片集合（未受新词表涉及且旧切片时间轴未变的切片不得判为受影响），复用未受影响上游产物仅重算受影响后缀；每条最终切片须记录所用缓存键、输入版本与节点路径，可用这些记录重放出同一时间轴与同一校验结论，缓存键任一依赖版本已变而结果仍来自旧键时返回 E_LINEAGE_STALE 并指出依赖项。
7. 实现切片的音频一致性校验与资源上限：用分帧特征对每个切片区间校验是否越出音频长度、是否为零长度以及区间内是否存在可观测语音活动，分别返回 E_AUDIO_RANGE、E_EMPTY_SLICE、E_NO_ACTIVITY 并给出切片定位；为单样本切片数、驻留特征内存与并行重算分块数设可配置上限，超限返回 E_RESOURCE_LIMIT 或降级并标记降级类别，降级不得改变已通过的校验结论。
8. 实现快照版本化整体替换、并发写控制与本地可视化诊断工作台：切片集、词表与识别配置快照各携带单调递增版本号与内容校验和，检测到版本号或校验和变化时必须整体替换旧快照而非增量修补，旧版本不得覆盖新版本且回退尝试返回 E_SNAPSHOT_ROLLBACK，损坏或校验和不符返回 E_SNAPSHOT_CORRUPT；同一时刻只允许一次提交生效，冲突时后到者立即获得 E_STAGE_BUSY 而不阻塞等待；工作台展示格式版本视图、取舍路径、失效传播覆盖范围、追溯链与最近业务错误码，并支持一次含跨版本迁移与改写失效的演示运行。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
