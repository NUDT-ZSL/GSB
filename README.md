当前是空白工作区，没有现存项目、代码或数据附件，需要从零构建一个面向语音端点检测（VAD）逐帧判决的本地可集成组件与完整示例，核心业务问题是门限参数与帧级特征的增量校准及其判决追溯。业务对象是本地确定性合成的 16kHz 单声道 PCM：由固定种子生成若干语音活动段与静音段并拼接，叠加可配置的平稳底噪，附逐帧真值文件（帧长 10ms，字段含 frame_index、is_speech、sample_start、sample_end）与样本清单（JSONL，字段含 clip_id、seed、duration_ms、sample_rate、frame_ms）。判决链路为：帧级特征（短时能量与过零率）→底噪分位估计→双门限滞回判决→段级合并。核心矛盾是校准参数（分位、倍数、滞回门限、最短段长）一旦调整，已产出的帧级判决与段级结果必须按依赖关系精确失效，而不是全量重算；同时每一条历史帧判决与段结论都要能追溯到当时所用的特征版本、底噪估计版本与门限版本，并在追溯链断裂时定位到具体阶段。

任务环境与准备：
安装 Python 3.10 或以上，并安装 NumPy（仅用于确定性 PCM 与数组生成）。
在工作区根目录创建项目骨架与本地样本目录，音频与真值均由固定种子在运行时生成，不依赖外部附件或网络。
确认可创建本地缓存目录与持久化快照文件，并具备本地进程池的运行条件。

业务要求：
1. 实现确定性的帧级特征节点：按 frame_ms 与帧移切分 PCM（帧边界以样本索引精确确定），计算短时能量与过零率，输出逐帧特征矩阵与帧数；同一 clip_id、同一 seed 与同一配置下逐字节产出相同特征矩阵，帧数须与真值文件一致，不一致返回 E_FRAME_COUNT 并指明 clip_id。
2. 实现底噪分位估计节点：对不活跃帧的短时能量按可配置分位与分位窗口做确定性估计，输出底噪标量及所用帧索引集合；分位越界或可用帧数不足以估计时分别返回 E_PERCENTILE_INVALID 与 E_NOISE_UNESTIMABLE，且所用帧索引集合须可按版本重放出同一标量。
3. 实现双门限滞回判决与段级合并节点：高低门限由底噪与配置倍数给出，语音段以低门限进入、高门限退出，再按最短语音时长与最短静音间隔合并为毫秒级段列表，保证按时间升序、互不重叠、落在音频时长内；违反分别返回 E_OVERLAP 与 E_OUT_OF_RANGE。
4. 实现按节点内容寻址的产物缓存与缓存键构造：特征、底噪估计、帧判决、段列表各自以内容哈希落盘，缓存键须纳入 PCM 内容哈希、帧移、分位与倍数参数版本、最短段长与上游节点哈希；键相同必须复用、键不同必须重算，且键的每一项组成须可按节点逐项导出用于诊断。
5. 实现校准参数变更后的定向失效传播：调整分位、倍数、滞回门限或最短段长时，须判定受影响的帧区间与段集合（仅凭门限倍数变化不影响特征节点，最短段长变化不影响帧判决节点），复用未受影响上游产物，仅重算受影响后缀；须输出重算与复用节点清单，并保证局部调整后的结果与从零全量重算逐字节一致。
6. 实现帧判决与段结论的可追溯重放：任一帧判决或段结论须记录所用特征版本、底噪估计版本、门限版本与节点路径，可按这些记录重放出同一判决；追溯记录缺失或重放结果不符返回 E_LINEAGE_BROKEN 并指明断裂节点与首个不一致字段。
7. 实现缓存与参数快照的版本化整体替换及并发提交控制：快照携带单调递增版本号与内容校验和，检测到版本号或校验和变化时必须整体替换旧快照而非增量修补，损坏或校验和不符返回 E_CACHE_CORRUPT；多个任务并发写同一缓存键时只有一方提交生效，冲突方立即获得 E_CACHE_BUSY 而不阻塞等待。
8. 实现配置与输入校验、资源上限、跨节点一致性自检及完整示例：采样率非 16000、frame_ms 非法或帧移超过帧长、分位与倍数越界、重复 clip_id 分别返回结构化业务码；为逐帧特征驻留内存、缓存条目总量与并行重算节点数设可配置上限，超限返回 E_RESOURCE_LIMIT 或降级并标记；命令行示例读取本地合成样本输出含帧判决、段列表、重算与复用清单、追溯记录与业务码的 JSON，并自检复用与重算集合无交集且并集覆盖受影响集合。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地合成音频验证校准参数定向失效、判决追溯重放与缓存整体替换的一致性。
