当前是空白工作区，需要从零实现一个本地列式聚合与窗口计算引擎及其可复现实验环境，用于在确定性样本上复现分组聚合与滑动窗口计算在并行分片调度与资源预算双重约束下的完整执行链路。本地 JSON 样本给出：列式批次文件（批次序号、行数、按列存储的整数/浮点/布尔数组、批次内容摘要）、查询描述（分组键、求和均值方差计数等聚合表达式、窗口行长与步长）、执行配置（全局并行任务数上限、每任务内存预算 MiB、定点标度、浮点容差、逻辑时钟步进）以及注入清单路径。引擎需把批次切分为并行分片任务，在并行上限与内存预算约束下调度推进，维护分组聚合状态与跨分片部分窗口缓冲，并在进程被强制终止后按持久化状态续算。核心矛盾在于：并行分片为压低交互延迟而乱序完成，但聚合结果与滑动窗口必须与单流全量重算逐位一致；内存预算必须对并行任务真实生效，预算不足时必须显式放弃而非事后标注，且放弃不得污染已提交状态。

任务环境与准备：
安装 Python 3.11 及以上版本，并确保可通过 pip 安装 NumPy，sqlite3 随 Python 标准库自带。
在工作区根目录创建样本目录，放置本地列式批次文件、查询描述 JSON 与注入清单，均以 UTF-8 编码保存，不依赖任何外部数据源或网络。
确认工作区可写，用于生成本地分片临时文件与 SQLite 状态库文件；准备一次可重复的任务执行命令入口，不要求任何 GPU 或特定硬件。

业务要求：
1. 实现列式批次文件、查询描述与注入清单的解析校验：列名唯一、各列数组长度与批次行数一致、批次序号严格递增且内容摘要与列内容一致、分组键与聚合表达式引用的列存在且类型可比、窗口行长与步长为正整数且步长不大于行长、并行上限与内存预算为正整数、定点标度合法；非法输入必须返回明确业务错误码且不写入任何持久化状态。
2. 实现确定性并行分片切分：把每个批次按行切分为固定数量的分片任务，分片边界与分片摘要只由批次序号、行数与配置决定，相同输入重复切分必须得到逐位一致的分片清单；每个分片任务声明其预估内存占用，预估口径须说明依赖的观测（列类型、行数、窗口缓冲深度）。
3. 实现向量化分片执行：过滤、投影、分组聚合与滑动窗口以 NumPy 整块数组运算完成而非逐行循环，浮点运算顺序与聚合顺序固定，使相同输入在任意运行次数与任意分片完成顺序下逐位一致；NaN 与无穷输入按统一规则处理并计入误差谱，定点溢出须与浮点异常区分。
4. 实现分组聚合与滑动窗口的跨分片状态合并：每个分组维护计数、求和、平方和与均值，滑动窗口维护跨分片的部分窗口缓冲并在后续分片补齐后才产出最终结果；分片状态合并顺序不得影响结果，最终聚合与窗口结果必须与单流全量重算的唯一真值逐位一致，不一致时输出首个差异分组或窗口及来源分片。
5. 实现并行调度与内存预算的真实生效：在全局并行任务数上限与每任务内存预算双重约束下决定分片启动顺序，预算不足时须真实释放未启动分片的占用并显式放弃，记录放弃原因；已启动分片必须执行完毕，不得以线程超时描述为已终止失控代码，须区分预算内未启动、启动后失败与主动放弃三类结局。
6. 实现定点与浮点双通路误差诊断：对每个聚合与窗口结果记录定点换算的标度、舍入方向与误差上界，当两个分组或两个窗口结果差小于容差且结论依赖该差值时标记为精度敏感并输出误差来源链（参与分片、批次、换算步骤）；精度敏感标记必须可复算，不得随分片完成顺序变化。
7. 实现强制终止后的恢复与并发幂等：把算子状态、分片水位、内容摘要、已提交分片结果与逻辑时钟水位以事务原子写入 SQLite；进程在调度或执行中途被强制终止后，恢复路径识别已提交分片与半提交算子，只重放缺失分片且不得重复累加计数与求和；多执行实例并行时通过事务与文件锁保证同一分片同一算子版本只提交一次、内存预算不被并发超卖，重复提交相同分片结果必须幂等。
8. 实现数据规模变化下的分片粒度自适应取舍与可重复命令行：当单批次行数或分组基数超过配置阈值时，在细粒度分片与合并粒度分片之间按明确规则切换并输出实际模式、切换触发条件与被否决模式原因，切换不得改变最终结果；提供 run、resume、status、verify 子命令，status 以稳定排序 JSON 输出分片水位、算子状态与预算占用，verify 校验持久化状态与结果真值一致。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
