当前是空白工作区，需要从零构建一个面向本地搜索与推荐前链路的倒排索引构建与压缩查询的数据处理管线与结果验证工具。业务对象是本地确定性生成的文档集合与查询集合：文档为 JSONL，字段含 doc_id、terms 列表（含 term 与词频）、doc_len；查询为 JSONL，字段含 query_id、terms 列表与 top_k。管线需要把文档集合构建为倒排索引，对每个 term 的倒排表实施分块与压缩存储，并在压缩索引上完成 BM25 类打分与 top-k 检索。核心业务问题是状态演进与恢复一致性：索引构建过程可能因强制终止而中断，索引快照需要携带版本号与内容校验和，并在重启后整体替换或从已提交快照继续，同时保证查询侧不会读到半构建的倒排表或新旧混合的统计量。

任务环境与准备：
安装 Python 3.10 或更高版本，并安装 NumPy（用于确定性样本生成与数值计算）。
准备本地确定性样本生成脚本：按固定随机种子生成文档 JSONL（含 doc_id、terms 与词频、doc_len）与查询 JSONL（含 query_id、terms、top_k），样本规模可配置但默认使用小规模样本以便复现。
准备本地持久化目录用于存放阶段快照、压缩倒排表与缓存条目，确保运行前目录为空或可清理。
确认运行环境无网络依赖，所有测试均在本地完成，运行平台为 Windows。

业务要求：
1. 实现确定性的倒排索引构建：从文档 JSONL 按 doc_id 升序、term 字典序排出每个 term 的倒排表，记录词频与文档长度统计，生成词项字典与文档总数、平均文档长度等打分统计量；同一输入与配置下倒排表、统计量与构建摘要必须逐字节一致，禁止依赖字典遍历顺序或未声明的随机性。
2. 实现倒排表分块与压缩编码：按可配置的每块 posting 数量把每个倒排表切成分块，采用差分编码加变长整数编码压缩 doc_id 与词频，块头记录块内条数、首 doc_id 与压缩字节长度；须保证任意块可独立解码且解压后 posting 序列与原始倒排表逐项相同，分块数或压缩参数非法分别返回 E_CONFIG_INVALID。
3. 实现压缩索引上的打分与 top-k 检索：查询时按查询词项定位倒排表，逐块解码参与 BM25 类打分，输出含 doc_id、分数、命中词项的 top-k；分数必须与在未压缩原始倒排表上计算的基线分数在声明精度内一致，检测到偏差返回 E_SCORE_MISMATCH 并指出 query_id、doc_id 与偏差量。
4. 实现索引构建的阶段状态机与持久化快照：文档摄入与校验、倒排表分块压缩、统计量汇总三个阶段各自产生带单调递增版本号、已完成文档集合与内容校验和的阶段快照，只有该阶段全部文档处理完成才提交；提交顺序与阶段状态必须在本地持久化存储中原子可见，部分完成的阶段不得提交为已完成，阶段名与版本号须在快照头中显式可读。
5. 实现强制终止后的恢复逻辑：重启时读取已提交阶段快照，从最后一次已提交阶段继续推进，已提交阶段的文档与倒排表不得重算或重复计入；未提交的中间压缩块与统计量必须丢弃并从该阶段起点重建，恢复后的完整索引与查询结果须与不间断完整运行逐字节一致；强制终止后的恢复以持久化快照为准，不承诺生成退出报告。
6. 实现索引快照版本变化与整体替换防护：检测到版本号或内容校验和变化时必须整体替换旧快照而非增量修补，旧版本快照不得覆盖新版本已提交阶段，回退尝试返回 E_SNAPSHOT_ROLLBACK；损坏或校验和不符的快照在加载时返回 E_SNAPSHOT_CORRUPT 并指明阶段名与版本号，禁止使用部分可解析的损坏数据。
7. 实现并发查询与构建的原子切换控制及资源上限：多个查询可并发执行，构建提交与快照切换须原子生效，查询侧不得读到半构建的倒排表或新旧混合的统计量；同一时刻只允许一个构建提交生效，并发提交冲突时后到者立即获得 E_BUILD_BUSY 而不阻塞等待；为倒排表总 posting 数、解码后驻留内存与缓存分块条目数设可配置上限，超限返回 E_RESOURCE_LIMIT 或降级到流式逐块解码并标记降级类别。
8. 实现结果验证工具与跨模块一致性自检：独立复核每个 term 的分块解压结果、任意查询的基线分数与压缩索引分数可重算一致、top-k 集合与分数顺序合法、快照中统计量与逐表明细可核对；并校验重算集合与复用集合（降级路径所涉 term 单独记录）无交集且并集覆盖全部受影响 term，检测到不一致返回 E_INCONSISTENT 并指出类别与首个偏差位置。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
在本地样本上验证索引构建、分块压缩、BM25 检索、阶段快照恢复与整体替换的一致性，并检查异常码与降级标记。
