# wavconcat — PCM16 单声道 WAV 清单拼接工具

按 UTF-8 JSON 清单顺序拼接多条 PCM16 单声道 WAV 片段，在相邻接缝处做短线性淡变消除爆音。
仅使用 Python 标准库（`wave` / `struct` / `argparse` / `json`），需 Python 3.10+。

## 文件

| 文件 | 作用 |
|---|---|
| `wavconcat.py` | 命令行工具本体 |
| `make_samples.py` | 确定性生成测试样本与清单（无随机、无外部附件） |
| `verify.py` | 14 条验收项对应的 17 项自动检查 |
| `demo.run.json` | 终端录屏交付配置 |

## 用法

```
python make_samples.py                                  # 生成样本到 samples/
python wavconcat.py samples/manifest.json out/concat.wav
python verify.py                                        # 回归全部验收项
```

清单格式：

```json
{"files": [{"path": "a.wav", "fade_ms": 10}, {"path": "b.wav"}, ...]}
```

`fade_ms` 可省（默认 0），取 0..500 的整数；第 i 项的 `fade_ms` 作用于第 i 与 i+1 项之间的
接缝：前段尾部淡出、后段头部淡入，帧数相同（`fade_ms * 采样率 / 1000`）。首片段头部与末片段
尾部不做淡变。路径相对清单所在目录解析，越出该目录即拒绝。

## 关键设计

- **格式校验**：仅接受未压缩 PCM、16 位、单声道、8000..48000 Hz；其余报“格式不支持”并非零退出。
- **全部校验先于写出**：清单解析 → 路径越界检查 → 逐片段读取/格式校验 → 采样率一致性 →
  淡变帧数不超过片段帧数一半，任一失败都不产生输出。
- **线性整数增益**：淡出第 k 帧增益 `(N-k)/N`，淡入第 k 帧增益 `k/N`（N 为淡变帧数）；
  乘法在 Python 大整数域完成后向零取整（正负对称），再饱和裁剪到 [-32768, 32767]，不会溢出回绕。
- **原子输出**：先写输出同目录 `.wavconcat-*` 临时文件，`os.replace` 原子替换目标；
  失败时删除临时文件，旧输出字节不变。
- **摘要**：成功时 stdout 打印片段数、采样率、总帧数、时长与输出路径。

## 实际验证结果（Python 3.13.9 / Windows 11）

`python verify.py` 输出：17 项检查全部 PASS，退出码 0。要点摘录：

| 验收项 | 结果 |
|---|---|
| 1 立体声 / 24 位 / 6000Hz 拒绝 | PASS，stderr 均含“格式不支持”，退出码 1 |
| 2 缺 path | PASS，`files[1] 缺少 path 字段` |
| 3 混合 44100/48000 | PASS，错误信息含两个采样率值，无输出 |
| 4 fade_ms=600 / 1.5 | PASS，stderr 分别指明 `files[0]` / `files[1]` |
| 5 短片段长淡变 | PASS，`帧数不足: 片段共 40 帧，两端淡变合计 22050 帧…超过帧数一半` |
| 6+14 三片段拼接 | PASS，输出 12000 帧 = 4000+3000+5000，stdout 三项数值与 wave 读取一致 |
| 7 单片段 | PASS，输出与输入逐样本（字节级）完全一致 |
| 8 线性增益 | PASS，恒定 12000 片段接缝处淡出尾帧 27=12000·1/441、淡入首帧 0，全序列与整数线性公式逐点相等 |
| 9 满幅 ±32767/-32768 | PASS，无符号翻转，幅度不超界，单元级饱和检查通过 |
| 10 路径越界 | PASS，`路径越界: '../outside.wav' 解析后越出清单目录` |
| 11 缺失/损坏片段 | PASS，整体失败且输出路径不存在 |
| 12 原子替换 | PASS，预置旧输出触发失败后字节未变，无残留临时文件 |
| 13 空清单 / 0 帧片段 | PASS，均非零退出且无输出文件 |
