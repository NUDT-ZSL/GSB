算子优化小组准备在刚初始化的本地目录中落地第一个可运行的诊断组件，Linux（WSL Ubuntu）工作区里暂时没有代码或数据。目标是构建一个本地算子诊断引擎，验证低精度量化卷积与插值算子在定点与浮点两代量化配置下执行时，数值误差如何沿量化、块内乘加、跨块归约与反量化路径传播，以及配置代数或任务修订触发缓存失效时如何精确重算受影响后缀。业务对象由固定种子脚本在本地确定性生成：任务清单为 JSONL，每行含 job_id、op_kind（conv2d 或 interpolate）、input_shape、kernel_shape 或 scale 参数、stride、padding、interp_mode、quant_scale、quant_zero_point、block_size、logical_clock_ms、revision；矩阵数组由固定种子驱动 NumPy 生成；量化配置快照 v1 为单文件 JSON 记录相对生效秒与扁平参数，v2 为分片 JSON 加 SQLite 元数据库记录绝对毫秒、配置代数与失效墓碑。引擎需在可注入逻辑时钟下完成算子执行、误差账本写入与缓存一致性裁决。

任务环境与准备：
Linux（WSL Ubuntu）环境，已安装 Python 3.9+，无需额外第三方包。
在工作区创建 gen_samples.py 脚本，使用固定种子 20250501 生成任务清单 JSONL、卷积核与输入矩阵，确保每次运行样本一致。
工作区需包含本地 SQLite 库（Python 内置 sqlite3 模块）用于 v2 配置元数据库。
所有输入与输出均使用本地文件，禁止依赖网络、真实模型或外部服务。

业务要求：
1. 实现浮点基线路径与定点量化路径的算子执行：对每个 job 解析输入形状、卷积核形状或插值 scale、stride、padding、interp_mode，浮点路径以 float64 逐块执行 conv2d 或 interpolate 并归约，定点路径依据 quant_scale 与 quant_zero_point 对输入与中间结果量化后执行定点标度累加，两路径共用同一块划分与循环顺序，保证结果差异仅来自数值精度损失。
2. 建立以内容哈希、量化参数版本与块大小为键的内容寻址缓存四节点体系：输入校验与块划分、块内算子执行、跨块归约、反量化输出；缓存键纳入输入内容哈希、op_kind、quant_scale、quant_zero_point、block_size、stride、padding、interp_mode、logical_clock_ms、revision 和上游产物哈希，键相同必须复用缓存快照，键不同必须重算，且缓存条目以临时文件写入后原子替换。
3. 实现两代量化配置快照的双向互迁：v1 升级到 v2 时补全逻辑时钟绝对毫秒、配置代数与失效墓碑并逐项记录补全来源，v2 降级到 v1 时对无法表达的失效墓碑按显式丢弃规则处理并输出丢弃记录，迁移后的内部配置表示在语义上必须等价，任何因表达能力不足导致的差异返回 E_SEMANTIC_DRIFT。
4. 实现任务修订与配置代数提升后的定向依赖失效传播：区分仅 revision 变化（影响该 job 输入校验及下游）、仅配置代数提升（影响所有使用该配置的 job）、block_size 或 interp_mode 变化（影响块划分、块内算子执行与跨块归约）三类情形，按缓存键计算受影响 job 集合与受影响缓存节点，复用未受影响上游产物，仅重算受影响后缀并输出重算清单与复用清单。
5. 实现以 float64 浮点路径为参考真值的逐级误差传播诊断：输出输入量化、块内算子执行、跨块归约、反量化各级的最大绝对偏差、相对偏差、误差放大比与主导误差来源级别，偏差超过配置容差时返回 E_TOLERANCE_EXCEEDED 并指出 job_id、层级与位置，误差账本可独立重放验证。
6. 实现强制终止后的恢复逻辑：引擎在阶段边界提交带单调递增版本号、已完成 job 集合与内容校验和的检查点，重启后读取最近已提交检查点继续推进，已提交 job 不得重算或重复写入账本，未提交的中间量化结果与缓存指向必须丢弃并从检查点重建，区分可处理退出信号与强制终止。
7. 实现并发提交控制与资源上限裁决：同一时刻只允许一个配置快照或一次增量提交生效，冲突时后到者立即获得 E_STAGE_BUSY 而不阻塞等待，旧版本回退尝试返回 E_SNAPSHOT_ROLLBACK；为驻留矩阵内存、每批 job 数、缓存条目数与并行重算任务数设置可配置上限，超限时返回 E_RESOURCE_LIMIT 或降级到串行重算并标记降级类别。
8. 实现输入与配置校验链路及跨模块一致性自检：重复 job_id、输入形状与数据维度不符、quant_scale 非正、revision 回退分别返回 E_DUP_JOB、E_SHAPE_MISMATCH、E_PARAM_INVALID、E_REVISION_ROLLBACK；自检校验各节点处理 job 集合一致、缓存键可还原产物、重算与复用集合无交集且并集覆盖全部受影响集合、最终输出可由缓存明细独立复算一致。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
完成低精度量化卷积与插值算子诊断引擎，验证双路径数值误差、缓存失效与恢复一致性。
