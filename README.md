焊接培训中心的实训指导教师需要让学员在模拟舱内凭听感判断手工电弧焊的熔池状态：学员戴多通道耳机、握操作手柄，系统按焊接工艺参数与熔池状态实时驱动电弧、熔滴、熔池与飞溅声源的空间位置和强度，使电弧稳定与失稳在听感上可分辨。训练段落结束后，指导教师要回看声场快照与听感对照报告。同类问题存在两种常用渲染路径：逐声道解析分配适合少量声源与已知主方向，按矢量基幅值平移做全向渲染则在声源密集、方位连续变化时更可控；两者在声源靠近监听者背面、飞溅事件密集时结果差异明显，需要选定一种路径并说清其边界。

任务环境与准备：
准备 Python 运行环境，并安装本题所需的 NumPy 与 Flask 第三方包。
在仓库内放置确定性焊接训练工程生成脚本与四个边界样本，按固定种子产出工艺参数、熔池状态、声源类别与监听者轨迹。
训练段落与声场快照写入工作目录下的本地文件，不依赖外部数据库或网络服务。
通过本地 Flask 服务访问训练段落列表、快照回放与对照报告接口，服务默认只监听本机回环地址。

业务要求：
1. 解析焊接训练工程的工艺参数序列、熔池状态序列、声源类别表、发声强度映射曲线与监听者头部朝向轨迹，按时间步建立声源对象列表并输出每个对象的发声强度映射参数与有效时间区间。
2. 依据电流、电压、送丝速度与熔池尺寸、温度、振荡幅值，计算电弧声、熔池沸腾声与飞溅声的逐时刻强度，输出各声源对象的强度曲线及熔池稳定与失稳时段的强度起伏统计。
3. 按焊枪姿态角与飞溅事件确定各声源对象在监听者坐标系中的方位角、仰角与距离，输出逐时刻空间位置轨迹，并标出飞溅事件密集时段中距离突变的时刻。
4. 采用矢量基幅值平移结合距离衰减把各声源渲染到不少于四声道的输出，并按监听者头部朝向旋转方位；输出逐时刻多声道音频与各声道增益曲线，同时在评估记录中说明声源位于监听者背面与正前方时该路径的适用条件与误差表现。
5. 统计声场能量在水平方位的分布摘要，生成熔池稳定与失稳时段听感特征（强度起伏、方位聚集度）对照报告，报告须能从强度曲线与方位轨迹反算复核。
6. 对同一训练段落分别执行实时逐步渲染与复盘整段回放，逐时刻比对多声道增益与声源方位，输出一致性校验结果；快照以整段声场状态整体替换写入，回放时按快照版本识别后复现，已写快照在后续训练段落追加时不得被就地改动。
7. 通过 Flask 本地服务提供训练段落列表、声场快照回放与对照报告查询接口，回放请求须携带快照版本号，版本不存在或已被替换时返回业务码并保持服务可用。
8. 以确定性生成器按固定种子构造焊接训练工程，并针对监听者正对声源、背对声源、飞溅密集、熔池尺寸突增四类边界生成样本，用解析方位与距离公式及能量守恒容差核对渲染输出，输出可复算的校验记录。

验收：
核对矢量基渲染的方位、距离、能量守恒与听感统计，并验证实时与回放逐时刻增益一致、快照版本替换可识别。
