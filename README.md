游戏外设团队在 Windows 开发机上只有一个空工程目录，需要先落地一套本地触觉反馈指令流合成引擎，把设计稿中的触觉事件脚本转换为多台触觉设备各自的驱动指令流。设备清单、触觉事件脚本与同步锚点声明全部由随工程交付的固定种子脚本确定性生成，不依赖真实外设、驱动或网络。设备清单给出设备标识、采样率、帧时长、支持强度范围与量化档位、每帧最大指令数；事件脚本给出事件类型、起始毫秒、持续毫秒、强度曲线控制点与目标设备；另给出全局并发上限、在途指令缓冲上限、对齐容差与状态目录。合成链路在设备采样点域生成强度包络、按帧装箱并合并同强度连续采样点，同时受每设备每帧指令数上限与全局在途缓冲预算双重挤压。工程难点在于：压缩量化精度或截短持续采样点都会破坏指令流与采样点的严格对应；并发调度、强制终止与帧块快照会让指令流顺序与预算账本出现不一致。

任务环境与准备：
安装 Python 3.11 及以上版本，执行 python -m pip install numpy 装好 NumPy 后即可运行。
准备空工作区目录，并在其中放置随工程交付的固定种子脚本，用于在本地生成设备清单与事件脚本样本。
确认运行环境为 Windows，状态目录、临时文件与导出目录均位于工作区内可写路径，不需要网络、真实外设或额外音频库。

业务要求：
1. 实现设备清单与事件脚本解析校验：校验设备标识唯一且非空、采样率与帧时长为正整数、每帧最大指令数为正整数、量化档位为不小于 2 的整数、强度范围下限小于上限、事件起始毫秒为非负整数、持续毫秒为正整数、包络控制点时刻严格递增且强度落在目标设备强度范围内，非法输入返回带 E_xxx 业务码的 JSON 错误且不写出任何指令流。
2. 实现设备采样点域的强度包络合成：按每个设备采样率把事件持续区间换算为整数采样点起止，在包络控制点之间做分段线性插值得到逐采样点连续强度，再按该设备量化档位落为整数级；事件起止采样点与逐采样强度只依赖事件声明、设备采样率与量化档位，不依赖合成顺序或并发度。
3. 实现每设备每帧的确定性指令装箱：把设备采样点按帧时长装箱，同帧内被量化强度相同的连续采样点合并为一条带持续采样点数的指令，装箱后该帧指令条数不得超过设备每帧最大指令数；超限时按确定规则把超出部分拆到后续帧并记录拆分次数与原因，同一设备同一事件脚本的逐帧指令序列在任意合法分帧下必须一致。
4. 实现全局在途缓冲预算与并行设备合成：以设备为单位并行推进各自采样时钟合成指令，同时处于在途的指令缓冲总量不得超过全局上限；超出时按设备标识确定顺序让部分设备等待，禁止通过降低量化精度、截短持续采样点或丢弃指令来通过预算，最终每设备指令流与逐设备串行合成结果逐条相同。
5. 实现设备间同步锚点对齐诊断：按脚本中的同步锚点标记检查各设备指令流中对应锚点的实际采样点位置，以采样点与换算毫秒双重表示相对参考设备的对齐偏差，任一对齐偏差超过规格对齐容差时返回 E_SYNC 并定位首个越限锚点、涉及设备与偏差值，不得用平均偏差掩盖单点越限。
6. 实现帧块级持久化与版本识别：每设备每帧块完成后把该块指令、已完成采样点范围、块内容摘要与由设备清单及事件脚本规范化摘要构成的版本标识原子写入状态目录，先写同目录临时文件再整体替换；再次启动时版本标识一致则只补算缺失帧块，不一致则归档旧状态并重做全部设备。
7. 处理可处理终止信号与强制终止的差异：外部可发送的可处理终止信号只在帧块边界生效，写入中断标记并以约定整数退出码退出，未完成帧块不得留下可被误认为已完成的结果；强制终止后重启仅依据已持久化且摘要有效的帧块恢复且不承诺生成退出报告，续算结果须与不中断一次跑完的指令流逐条一致。
8. 实现块级摘要校验、并发资源上限与指令流原子导出：全部块完成后逐块比对内容摘要，不匹配、缺失或声明指令条数不符时返回 E_DIGEST 并回退补算该块；按并发上限用有界线程池调度，超出内存预算时按设备标识与帧序等待而非降低量化精度；导出指令流与报告先写临时文件再整体替换，报告须含逐设备指令条数、拆分计数、锚点偏差与业务码列表。
