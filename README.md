在空白工作区构建一个面向本地确定性样本的 LLM 偏好对齐奖励建模诊断工作台，核心解决奖励模型增量更新与依赖失效判定的问题。输入为一个本地样本目录：偏好对数据 JSONL（每行含对 ID、提示词、被选回答、被拒回答、标注者 ID 与时间戳，文本由固定种子程序从受控词表生成以控制长度）、一份特征抽取配置 JSON（子词切分规则、特征维度与哈希桶数、文本归一化开关、打分权重、奖励差值阈值、并发数、快照提交间隔）、一份分批更新计划 JSON（每批可包含若干偏好对的替换、删除与新增，以及打分权重与阈值的调整），以及一份依赖关系声明 JSON（声明哪些特征桶、哪些数据批次、哪些汇总统计之间存在上下游依赖）。工作台需要完成确定性偏好对特征抽取、成对奖励打分、奖励差值判别与汇总统计，支持用户按批次反复施加更新，并在每次更新后只重算受影响的特征、打分与统计阶段，最终结果必须与从空白工作区按最终输入全量运行一致。

初始状态：工作区仅有上述配置与样本文件，无任何既有代码或缓存。用户可多次修改偏好对数据、打分权重或阈值后重新运行，工作台须识别失效并仅重算受影响部分，同时保持统计产物与完整重建一致。

任务环境与准备：
确认 Windows 上已安装 Python 3.10 或更高版本，并可在命令行直接调用 python 与 pip。
创建空白工作目录，在其中建立样本子目录，放入题目所述的偏好对 JSONL、特征抽取配置、分批更新计划与依赖关系声明文件，文本由固定种子程序生成。
准备独立注入配置文件，覆盖缺字段对、奖励差值恰好等于阈值、空子词集合与非法权重等样例，注入项带编号。
安装 NumPy 作为唯一的第三方数值依赖，其余功能仅使用 Python 标准库的 json、threading、hashlib 与 os 模块。
运行前确认工作目录可写，用于存放阶段产物、临时目录与清单文件，路径中不包含需要特殊转义的非 ASCII 字符。

业务要求：
1. 实现偏好对加载与确定性特征抽取层：逐行解析偏好对 JSONL，校验对 ID 唯一、提示词与被选被拒回答非空、时间戳可解析；按配置的归一化开关与子词切分规则对三段文本切分，并以固定哈希函数映射到配置的特征桶，输出每对的特征桶计数向量与阶段指纹；非法行分别输出 E_SAMPLE_INVALID、E_EMPTY_TEXT 业务码并进入失败清单，不得中断其余对的加载。
2. 实现成对奖励打分器：依据特征桶计数向量与打分权重计算被选回答得分与被拒回答得分，得分以固定运算顺序计算并按配置精度保留，奖励差值为两者之差；当奖励差值的绝对值小于配置阈值时标记为边界样本并记录其双精度参考差值，判定结果须能区分差距明确与差距临界两类，同分时按对 ID 字典序决定边界样本的归并顺序。
3. 实现偏好对级与特征桶级依赖指纹：为每对计算由归一化文本内容指纹、特征维度与哈希桶数、子词规则版本派生的缓存键，为每个特征桶记录引用它的对集合，为汇总统计记录其引用的批次与桶集合；当某个偏好对被替换或删除、或特征维度与桶数变更时，须精确判定受影响的对集合与桶集合，未被引用的缓存产物必须直接复用而不得重新抽取。
4. 实现分批更新的失效传播：依据分批更新计划依次应用替换、删除与新增偏好对，并处理打分权重与奖励差值阈值的调整；权重或阈值变化只使打分、判别与汇总统计失效而不使特征抽取失效，数据变更则使对应特征、打分与统计全部失效；每批完成后输出失效阶段清单、复用阶段清单与重算对数量，任何批次不得出现应失效却复用的产物。
5. 保证增量更新与全量重建的结果一致性：从任意初始状态施加任意批次序列后增量运行得到的每对特征桶向量、成对得分、奖励差值、边界标记、汇总统计与失败清单排序，必须与从空白工作区按相同最终输入与配置一次性全量运行的结果逐字段一致；比较须覆盖只改权重、只改数据与两者混合三类批次序列，且每类至少记录一次比对结论。
6. 实现版本化快照整体替换与强制终止后的恢复判定：每批完成时将特征抽取、打分判别与汇总统计各阶段产物以临时文件加原子替换方式写盘，并以清单文件记录全局版本号、配置哈希、数据指纹、各阶段产物版本与已完成批次游标；读取时以清单版本号与配置哈希判断是否为最新有效快照，目录结构整体替换时须识别旧版本避免混用；收到可处理的退出信号时完成当前批三类产物提交与清单原子替换后以整数退出码 0 退出，进程被强制终止后重启仅依据清单中已完整替换的产物恢复并输出恢复点信息。
7. 实现并发处理与串行结果一致性：使用线程池并发执行特征抽取与打分，最大并发数取自配置；每个偏好对任务携带由对 ID 与阶段名派生的稳定排序键，无论线程完成顺序如何，最终偏好对清单顺序、特征桶顺序、失败清单顺序与汇总统计内容必须与单线程按对 ID 升序执行逐字段一致，并发度变化不得改变任何结果字段。
8. 实现异常注入隔离与诊断报告输出：以独立注入配置指定缺字段对、奖励差值恰好等于阈值、分组内相似度极值、空子词集合与非法权重等样例，注入项编号写入报告以证明命中；单对在特征抽取、打分或判别阶段抛异常时记录对 ID、批次号、阶段名、业务码与异常类型并继续其余对；每次完整运行生成 JSON 诊断报告，含各批次失效与复用阶段、边界样本清单及双精度参考差值、奖励差值分布摘要、快照版本号、配置与数据指纹及失败清单，报告以临时文件加原子替换方式写盘。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
以本地偏好对样本执行多批增量更新，验证失效传播、快照恢复及结果与全量重建逐字段一致，并输出诊断报告。
