当前是空白工作区，没有现存项目、代码或数据附件，需要从零构建一个面向模型压缩与部署的本地专业应用与可重复演示，核心业务问题是在低精度量化推理前处理阶段完成权重量化、离线校准与实际前向推理，并在权重数据以新版本到达、校准统计更新或进程被中断时，保证推理进度可恢复、结果可复现、旧版本产出不被误用。业务对象是本地确定性生成的模型包清单（JSONL，字段含 model_tag、layer_id、layer_index、layer_shape、weight_revision、quant_dtype、zero_point、scale_hint、calibration_split）以及由固定种子和层形状生成的权重数组与校准用输入张量。处理链路为：模型包校验→逐层权重量化（按 scale/zero_point 缩放与舍入）→校准统计→逐层确定性推理→输出摘要。核心矛盾是：层与层之间的推理存在依赖，某一层权重以新版本到达时只能让该层及其下游层重算，且中途被强制终止后重启必须从最近一次已提交的进度点继续；但版本序更高的权重不得被旧进度点掩盖，权重版本变化还须整体替换对应缓存产物。要求全程使用 NumPy 在本地完成，延迟以本地运算循环的实际处理计时观测并附估算记录，内存以按层形状与量化档计算的估算值为准，两者只作为预算观测依据，不替代真实的资源上限与隔离。输入仅来自本地生成的确定性样本，不依赖真实账号、线上站点、付费资源或特定 GPU。

任务环境与准备：
Windows 本地环境，安装 Python 3.10 及以上与 NumPy，无需 GPU、容器或任何网络服务。
在工作区内创建确定性样本生成脚本，按固定种子生成模型包清单、各层权重数组与校准输入张量并写出到本地目录。
准备持久化进度点与缓存目录，确保目录可写，并提前规划用于强制终止演示的子进程启动方式。
准备包含既有提交、并发提交尝试与损坏进度点的用例样本，供恢复与异常注入演示使用。

业务要求：
1. 实现模型包校验与逐层确定性量化阶段：按清单中的 layer_index 与 layer_shape 生成权重数组，依据 quant_dtype、scale_hint 与 zero_point 完成缩放、舍入与反量化，输出每层量化参数、反量化权重与量化误差统计；同一 model_tag、同一 weight_revision 与同一配置下必须逐字节产出相同的量化参数与反量化权重，禁止依赖系统时间、字典遍历顺序或未声明的随机源。对缺失必填字段、layer_shape 与权重数组长度不符、scale_hint 非正、zero_point 越界分别返回 E_PACKAGE_FORMAT、E_SHAPE_MISMATCH、E_SCALE_INVALID、E_ZP_OUT_OF_RANGE，并指明 model_tag 与 layer_id。
2. 实现按 layer_index 串联的确定性推理链路，每层输入来自上一层输出，输出摘要包含逐层激活校验和与最终预测向量；推理所用权重必须是当前提交的量化快照中的反量化权重，同一快照与同一校准输入重跑得到逐字节一致的激活校验和与预测向量，且预测向量不得受层重算顺序影响。
3. 实现“模型包校验、逐层量化、校准统计、逐层推理”四阶段进度快照，每个进度点携带单调递增的进度版本号、已完成层集合与内容校验和，只有该阶段全部层处理完成才提交进度点；进度点提交顺序与视角必须在持久化存储中原子可见，部分完成的阶段不得被当作已完成，供后续恢复使用。
4. 实现强制终止后的恢复逻辑：重启时读取最近一次已提交进度点，从该进度点记录的下一层继续执行，已提交层的量化参数与激活不得重算或重复计入；进行中未提交的中间层结果必须丢弃并从该层起点重建；完整流程被中途强制终止后重启恢复得到的最终预测向量与逐层激活校验和，必须与不间断完整运行逐字节一致。强制终止不生成退出报告，恢复只依赖已持久化的已提交进度点。
5. 实现权重数据版本变化的依赖失效与整体替换：当某层权重以更高 weight_revision 到达、或校准统计更新时，计算受影响层集合（该层及其全部下游层），复用未受影响层的进度与缓存产物，仅重算受影响层及其下游；更高版本不得被更早提交的进度点掩盖，旧版本进度点与缓存产物必须被整体替换而非增量修补，旧版本接受为已提交时返回 E_SNAPSHOT_ROLLBACK，损坏或校验和不符的进度点与缓存条目读取时返回 E_CACHE_CORRUPT 并指出层号与版本。
6. 实现并发提交控制与算力或内存双预算上限：同一时刻只允许一个阶段提交生效，并发提交冲突时后到者立即获得 E_STAGE_BUSY 而不阻塞等待，已完成阶段不得被旧版本回退覆盖；为单阶段层数、同时驻留的反量化权重估算内存与缓存条目总量设可配置上限，超限时按明确策略返回 E_RESOURCE_LIMIT 或降级到逐层流式量化与推理并在结果中标记降级类别，降级不得改变已提交层的反量化权重与激活。
7. 实现由输入或参数触发的异常注入与异常链路归因：在包校验、量化、校准、推理四个阶段分别提供注入点（如权重数组在读取过程中被截断、quant_dtype 未知、校准样本数与层形状不符、推理输入维度不符），注入只能由输入或参数触发，不得修改源码制造；每次注入须产生带阶段名、业务码与层号的记录，下游阶段按明确策略降级并携带降级类别与触发它的上游业务码，未被任何阶段归因的异常须汇总到结果中。
8. 实现跨模块一致性自检与本地可交互专业应用：校验四阶段处理的层集合完全一致、每层量化参数与反量化权重互相可核对、进度点重算层集合与复用层集合无交集且并集覆盖全部受影响层、最终预测可由逐层激活与量化快照独立重算一致，不一致返回 E_INCONSISTENT 并指出类别与层号；应用展示当前阶段、进度版本、各层量化误差、受影响层范围与最近业务错误码，允许触发一次演示——执行流程、在指定层后强制终止、重启从已提交进度点恢复并对比恢复结果与完整运行，演示仅使用本地确定性样本。
