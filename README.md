当前是空白工作区，没有现存项目、代码或数据附件，需要从零构建一个面向对话语音情感分析的本地领域组件与完整示例。业务对象是本地确定性合成的多说话人对话语音：用固定种子生成若干说话人的基频、共振峰、能量包络与语速参数，按给定对话时间轴与增益叠加为 16kHz 单声道 PCM，并附逐帧真值文件（帧长 20ms，字段含 frame_index、speaker_id、valence、arousal、is_speech）、对话清单（JSONL，字段含 dialog_id、sample_rate、duration_ms、speaker_ids、gain）与注册样本清单（JSONL，字段含 speaker_id、seed、duration_ms）。组件把一次情感分析建模为有向无环图：分帧特征、说话人嵌入估计、逐帧指派、段级回归、对话级聚合五个节点串联。核心业务问题是增量更新下的特征缓存与旧分数追溯：追加注册样本、修正单段真值标签或调整帧移与切段阈值时，只有依赖这些输入的节点与帧段需要重算，其余必须复用缓存；且任一历史分数必须能按其记录的缓存键与节点路径重放出相同结果。

任务环境与准备：
安装 Python 3.10 及以上版本，并安装 numpy 与 scipy（pip install numpy scipy），不依赖任何外部服务或真实音频数据。
准备本地确定性样本生成脚本：按固定种子合成多说话人 16kHz 单声道 PCM、逐帧真值文件（帧长 20ms）、对话清单与注册样本清单，所有样本写入本地工作目录。
准备本地缓存目录与快照存储目录，确保进程可读写；任务不要求容器或任何容器化环境。
运行命令行示例前确认工作目录下已生成样本与配置文件，示例输出 JSON 报告到本地文件。

业务要求：
1. 实现确定性的分帧特征图节点：按 frame_ms 与帧移切分 PCM，帧边界以样本索引精确确定，计算短时能量、过零率、谱质心与谱滚降，输出逐帧特征矩阵与帧数；同一 dialog_id、同一 seed 与同一配置下必须逐字节产出相同特征矩阵与帧数，帧数须与逐帧真值文件的行数一致，不一致返回 E_FRAME_MISMATCH 并指出 dialog_id 与两侧帧数。
2. 实现说话人嵌入估计与逐帧指派的图节点：由注册清单中固定种子与时长确定性合成注册片段，估计每个说话人的嵌入统计量，对每帧按确定性相似度打分并指派说话人编号，同分按 speaker_id 升序打破平局，输出逐帧标签与连续段边界；须校验标签落在对话清单声明的 speaker_ids 内，越界返回 E_SPEAKER_UNKNOWN 并指明帧号。
3. 实现段级情感回归与对话级聚合的图节点：按说话人连续段对 valence 与 arousal 做确定性回归并给出每段置信区间，对话级按段时长加权聚合并显式记录权重口径；聚合结果须能由逐段明细与权重独立重算一致，区间顺序非法或重算不一致返回 E_INCONSISTENT 并指出会话与段号。
4. 实现内容寻址缓存与缓存键构造：每个节点产物附带内容哈希写入本地缓存目录，缓存键须纳入音频分块内容哈希、注册样本版本、帧移与切段阈值、真值修正版本与上游节点哈希；键相同必须复用缓存快照，键不同必须重算，且每个缓存条目须可导出键的组成字段以供审计，键组成不可导出返回 E_KEY_UNEXPOSED。
5. 实现增量更新的依赖失效传播：追加注册样本、修正单段真值标签、调整帧移或切段阈值时，计算受影响节点与受影响帧或段集合，复用未受影响上游缓存，仅重算受影响后缀；须输出本次重算节点清单与复用节点清单，并保证局部修改后的最终分数与在修改后输入上全量重算的结果逐字节一致。
6. 提供旧分数追溯能力：对任一此前产出的段级或对话级分数，可按其记录查询当时所用缓存键、输入版本与节点路径，并用这些键重放出相同分数；追溯链断裂或键无法复现分数时返回 E_LINEAGE_BROKEN 并指出缺失环节与分数标识，禁止用当前版本数据冒充历史版本重放。
7. 实现缓存与配置的版本化整体替换及并发写控制：缓存条目与配置快照携带单调递增版本号与内容校验和，检测到版本号或校验和变化时必须整体替换旧快照而非增量修补，损坏或校验和不符返回 E_CACHE_CORRUPT；多个任务并发写同一缓存键时须保证只有一个写入生效且其余读到完整快照，并发冲突时后到者立即获得 E_STAGE_BUSY 而不阻塞等待。
8. 实现配置与输入校验链路、资源上限、跨节点一致性自检及完整示例：采样率非 16000、frame_ms 非法或帧移超过帧长、重复 dialog_id、注册清单缺失 speaker_id 分别返回结构化业务码并指明字段；为单次重算帧数、缓存条目总量与驻留特征内存设可配置上限，超限返回 E_RESOURCE_LIMIT 或降级并标记降级类别；自检校验各节点处理的帧索引集合完全一致、复用集合与重算集合无交集且并集覆盖受影响集合、缓存键与产物哈希可互相核对，不一致返回 E_INCONSISTENT；命令行示例读取本地合成样本输出含逐段分数、缓存命中与重算统计、追溯回放结果与业务码的 JSON 报告，并附一次增量更新演示。
