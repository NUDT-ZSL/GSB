架构评审确认首版由一人独立交付，当前 Linux（WSL Ubuntu）工作区尚未产生任何代码或样本，需要从零构建一个面向模型参数高效微调（PEFT）训练过程的本地可交互诊断应用，核心业务问题是训练快照、优化器状态与增量补丁在格式版本和修订演进下的互操作与版本兼容，以及中断恢复后的状态一致性。全部输入由随工程交付的固定种子脚本在本地确定性生成，不依赖真实模型、外部服务或网络。业务对象包括浮动规模的 PEFT 任务清单（JSONL，每行含 case_id、base_model_rev、adapter_type、adapter_dim、num_layers、lr、steps、micro_batch、seed、revision、logical_clock_ms），以及按任务种子确定性生成的分片训练快照与优化器状态，其描述以两种格式并存：v1 为单文件 JSON 记录相对生效秒数与扁平的层到参数摘要映射；v2 为分片 JSON 加 SQLite 元数据库记录绝对毫秒时刻、快照代数、参数分片内容哈希与失效墓碑。用户可注入参数修订或快照损坏，应用需在已提交阶段快照基础上恢复并输出诊断报告。

任务环境与准备：
Linux（WSL Ubuntu）环境，Python 3.10 及以上，安装 NumPy 与 SQLite3（Python 内置）
随工程提供的固定种子脚本生成本地任务清单 JSONL、v1/v2 快照及 SQLite 元数据库，均放在工作区本地目录，无需网络或外部服务

业务要求：
1. 实现确定性的 PEFT 任务摄入与适配器结构校验：按 case_id 与 logical_clock_ms 升序解析任务清单，依据 base_model_rev 与 adapter_type 校验适配器层数、维度与可训练参数总数，并对 layer_idx、key、shape、seed 等字段做类型和范围校验，未知版本或字段缺失返回 E_UNSUPPORTED 或 E_FORMAT；同一输入、同一种子与同一配置下必须逐字节产出相同的规范化任务字典与参数摘要。
2. 实现分片训练快照与优化器状态的读取与统一内部表示：v1 单文件 JSON、v2 分片 JSON 加 SQLite 元数据库均需按版本头分派解析路径，校验各分片内容哈希与元数据库记录一致，相对秒与绝对毫秒通过显式声明的换算基准互转；v2 增量修订携带单调递增代数与失效墓碑，读取时只采纳代数更高且未被墓碑标记的分片内容，任何哈希不匹配返回 E_SNAPSHOT_CORRUPT。
3. 实现 v1 与 v2 快照格式的双向迁移与语义等价裁决：v1 升级到 v2 时补全绝对毫秒、快照代数、参数分片哈希及失效墓碑默认值并逐项记录补全来源；v2 降级到 v1 时对无法表达的增量修订与分片边界按显式丢弃或展平规则处理，迁移后的内部表示必须逐字节相同，否则返回 E_SEMANTIC_DRIFT 并指出首个差异的层键和字段。
4. 实现基于固定训练步数与微批量规模的梯度累加状态推进：对每个任务按 lr、steps、micro_batch 与 seed 执行确定性微调状态更新，每步记录参数摘要、优化器动量/方差累积量与 step 序号，状态更新仅使用已提交快照与显式配置，不得使用系统时间或随机源，必须支持从指定 step 边界继续推进且与连续训练结果一致，同分时按 case_id 升序打破平局。
5. 实现阶段快照与任务检查点的版本化原子提交及中断恢复：把微调训练建模为参数初始化、梯度累加、优化器更新、汇总导出四阶段，每阶段对全部任务处理完成后才提交带单调递增版本号、已完成任务集合与内容校验和的持久化快照；可处理退出信号在提交边界优雅结束并生成报告，强制终止后从最近已提交检查点恢复，已提交任务不得重算，未提交中间状态必须丢弃并从阶段起点重建。
6. 实现参数修订或训练配置变化的定向依赖失效传播：当某任务的 revision 提升、适配器维度调整、学习率变化或分片快照被替换时，按内容寻址缓存键计算受影响任务集合与受影响训练阶段，复用未受影响的已提交快照与优化器状态，仅重算受影响后缀；同一时刻只允许一次修订提交生效，并发冲突后到者立即返回 E_STAGE_BUSY，且重算后的任务摘要必须与整体重算一致。
7. 实现训练产物与快照的追溯重放和过期结果拒绝：每条最终任务摘要须记录所用快照版本、配置代数、参数修订号、关键阶段缓存键与训练步数，可按这些记录在该任务上独立重放出相同的最终参数摘要与优化器状态；当依赖的任一版本已变化而记录未更新时返回 E_STALE_RESULT 并指出任务与字段，重放过程不得使用旧快照修补。
8. 实现输入与配置校验链路、资源上限及本地可交互诊断应用：重复 case_id、学习率非正、steps 与 micro_batch 不匹配、revision 回退分别返回结构化业务码并指明字段；为单任务驻留内存、缓存条目数、同时打开分片数与重算任务数设可配置上限，超限时按显式优先级降级并记录；提供命令行或轻量界面展示任务状态机、缓存命中和失效传播范围、异常业务码与阶段恢复说明。
