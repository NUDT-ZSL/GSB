在空白工作区从零实现一个本地分布式训练梯度同步模拟与一致性校验引擎，用确定性的方式复现多工作进程在同步 SGD 中的 AllReduce 交互过程。样本由本地 JSON 训练计划给出：模型层清单（层名、参数量、参数分片方式）、同步策略（环形 AllReduce 分片数、桶大小、是否使用梯度累积）、随机种子与超参。模拟器启动多个本地工作进程（Python multiprocessing），每个进程持有一份按策略切分的全精度梯度分片，按环形或树形拓扑进行多轮收发，最终每个进程必须得到与单进程串行聚合在容差内一致的全局梯度。通信通过本地 socket 或管道进行，可注入乱序到达、丢包重传、慢节点响应延迟与消息分片损坏等故障。引擎还需模拟梯度累积步与训练步的边界，保证中断恢复后累积状态与同步轮次一致。所有参数、拓扑与故障均来自本地样本，不依赖网络集群或 GPU。

任务环境与准备：
安装 Python 3.11 及以上与 NumPy、pytest，确认 python 与 pytest 命令在 PATH 中可用。
准备本地 JSON 训练计划样本、故障注入清单与固定随机种子，放在工作区 samples 目录下。
确认 SQLite 通过 Python 标准库 sqlite3 可用，无需外部数据库服务。
在 Windows 上确认本地 socket 或命名管道可用，多进程启动方式使用 spawn。
预留可写的临时目录用于对象与持久化文件，验证脚本以固定样本重复执行两次。

业务要求：
1. 实现训练计划解析与分片模型：读取本地 JSON 计划，校验层参数总量、分片数、桶大小与累积步的整除/边界关系，构建每进程的参数分片映射；非法参数（分片数大于参数量、桶大小为零、层名重复）必须返回明确业务错误码并保持初始状态不变。
2. 实现多进程梯度产生与确定性样本：每个工作进程按全局种子与进程号生成固定梯度向量，相同种子与计划必须逐位复现；梯度需按层与分片边界正确切分，并为串行单进程聚合提供唯一真值来源，真值与分布式结果可逐元素比对。
3. 实现环形与树形 AllReduce 通信协议：基于本地 socket 或管道实现分片轮次收发（reduce-scatter 与 all-gather 阶段），消息带轮次号、分片号、校验和与版本标签；接收方必须按轮次与分片索引装配，乱序到达的消息应缓存而非误用，协议需保证最终每进程的全局梯度与串行聚合在给定容差内一致。
4. 实现故障注入与重传语义：按本地故障清单在指定轮次注入消息丢失、分片字节损坏与慢节点延迟，接收方依据校验和与轮次号识别损坏或缺失并触发该分片重传；重传次数受预算约束，超预算必须返回对应业务错误码并让该轮次进入可诊断的失败状态，不得把损坏分片结果当作有效梯度提交。
5. 实现梯度累积与同步轮次边界：按计划累积步累加梯度，只在边界轮触发 AllReduce，并保证累积缓冲在轮次间不被通信写入污染；累积步中途失败后重试同一轮时不得重复累加已计入的梯度，需以持久化轮次与累积计数裁决。
6. 实现强制终止后的恢复：将轮次号、累积计数、每层梯度摘要哈希、分片提交状态与同步结果原子写入 SQLite；进程被强制终止后，恢复路径依据持久化状态识别未完成轮次与已提交分片，只重发未确认分片，不得承诺一定已生成退出报告。
7. 实现并发一致性与幂等提交：多个工作进程以及重复启动的恢复实例共享同一 SQLite 状态，通过事务与文件锁保证同一轮次同一分片只被提交一次，重复提交换算结果必须幂等；读取方只能看到完整已提交轮次的同步结果，不得读取中间态分片装配。
8. 提供命令行接口与可重复演示：支持 plan、run、inject、resume、verify、report 子命令，report 以稳定排序输出每轮次、每层梯度摘要、校验和比对与故障统计；verify 校验分布式结果与串行真值在容差内一致；使用固定本地样本运行两次输出逐字节一致。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本验证多进程梯度同步结果与串行真值一致、故障重传与终止恢复正确，重复运行输出一致。
