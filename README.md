预算与交付周期确定后，团队在空目录上开启一个新项目：Windows 本地从零实现一个离线 HTTP 请求走私检测与证据链验证工具。输入全部由本地确定性脚本按固定种子生成，不依赖真实站点、外部网络或账号：样本目录给出一组原始 HTTP 报文流（每条记录含连接标识、方向、报文序号、逻辑毫秒戳、原始字节的十六进制载荷），以及两代检测规则快照——v1 为单文件 JSON，记录规则名、相对生效秒数、扁平匹配串列表与启用标记；v2 为分片 JSON 加 SQLite 元数据库，记录规则规范名、绝对生效毫秒时间戳、规则代数、规范化匹配模式、作用方向与墓碑标记。另有一份并行检测计划，声明并发上限、单连接真实耗时上限、整批任务预算与输出路径。工具需按记录序号重组每连接的报文字节流，切分为报文边界后依据合并后的规则视图判定请求走私类歧义（内容长度与传输编码并存、重复取值、块长度畸变、报文边界夹带），并以可复现的账本记录每次判定所用规则代数与字节偏移；强制终止后只允许从最后一个完整检查点恢复。

任务环境与准备：
Windows 本地环境，安装 Python 3.11 或以上，并在项目虚拟环境中执行 pip install numpy pytest；SQLite 使用 Python 标准库 sqlite3，无需额外安装。
工作区为空目录，样本由任务内的确定性生成脚本按固定种子产出，不依赖网络、真实站点、账号或外部数据集；运行前执行生成脚本创建报文流、两代规则快照与并行检测计划。
确认本地文件锁与临时目录可写，测试使用 pytest 在本地执行，全部处理离线完成。

业务要求：
1. 实现原始报文流与两代规则快照的严格解析规范化：校验连接标识与方向合法、报文序号在连接内单调唯一、十六进制载荷为偶数长度可解码、逻辑毫秒戳为非负整数；v1 记录规则名与相对生效秒数与启用标记，v2 记录规范名、绝对生效毫秒时间戳、规则代数、作用方向与墓碑标记，对非法记录输出含来源类别与记录序号的拒绝清单并继续处理其余记录。
2. 实现按报文序号与逻辑毫秒戳的报文边界重组：处理乱序到达、重复投递、缺口与跨连接混入，重复按首次出现为真值并在报告中记录重复次数，缺口返回 E_MSG_GAP 并给出缺失序号区间，跨连接混入返回 E_MIXED_CONN；边界识别须支持内容长度与分块两种报文定界口径，不得以连接末字节视为唯一真值。
3. 实现两代规则快照的合并与代数识别：以规范名为同一规则实体键，按规则代数与绝对生效毫秒时间戳裁决权威来源，墓碑标记必须覆盖较早的非墓碑记录；规则集合任一增删、规则代数变化或作用方向变化均视为快照整体替换，不得把旧代规则与新一代规则混用在同一连接判定中，报告须标注每条判定所用规则代数与生效时刻。
4. 实现请求走私歧义判定：识别内容长度与传输编码头并存、同名头重复且取值冲突、块长度十六进制畸变与尾部夹带字节、报文边界前后存在无法归属的剩余字节，分别给出稳定的业务码与出错字节偏移；判定结论须以合并后规则视图中该连接生效的规则代数为准，且须记录命中模式与偏移区间以便复核。
5. 实现并行调度的资源预算控制：按连接把检测任务切分为独立任务，以可配置并发度执行，并设置整批任务预算、单连接真实耗时上限与待处理队列上限；耗时须以真实墙钟测量判定而非人为延迟常量，超时返回 E_TIMEOUT 并真实终止该连接后续处理，队列超限返回 E_QUEUE_FULL 且被拒任务计入报告，预算耗尽须按稳定键停止接纳新任务而不中断已在途任务。
6. 保证调度结论与并发、到达顺序无关：相同输入在任意并发度与任意规则快照与报文流的交错导入顺序下，每条连接的判定结论、所用规则代数、命中偏移区间与拒绝清单必须完全一致；报告中的连接与命中项顺序须按稳定键归一化，批级摘要须含任务数、成功数、超时数、队列拒绝数与预算停止数。
7. 实现检查点演进与强制终止后的恢复边界：按已完成连接标识与聚合判定状态持久化检查点到 SQLite 与本地快照文件，恢复时只从最后一个完整检查点继续并重放校验以识别半写残留；检查点结构版本或规则代数口径版本变化时须整体重建而非增量续接；检查点、快照与判定报告均先写临时文件再整体重命名替换，同一工作目录并发写入须以文件锁串行化，锁冲突返回 E_LOCK 且不破坏既有状态。
8. 交付可交互命令行、确定性样本生成器与本地测试：提供导入、检测、查询判定、校验检查点四类子命令与结构化 JSON 报告输出，单条连接检测失败不得中断同批其他连接，退出码区分全部成功、部分失败与参数错误；样本生成器在真值文件中显式记录每条连接发送端原始报文边界同步标记与预期命中业务码，验证模块只依据这些同步标记与输出比较，测试覆盖乱序、重复、跨连接混入、规则版本替换、超时、队列超限与检查点中断恢复。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
