本地需要构建一个面向 LLM 预训练语料治理的可交互专业应用，处理多来源文本分片（JSONL，字段含 shard_id、doc_id、lang、domain、token_count、text、minhash_sig）。核心流程是：逐批摄入分片→做近重复检测（MinHash/SimHash 加 LSH 分桶）→按领域与语言 token 目标做配比采样→输出训练清单。该流程必须支持长时间运行中的状态演进：摄入、去重、配比三个阶段各自成为可持久化的阶段快照，进程被强制终止后重启能从最近一次已提交快照继续，而不是从头开始；重启后必须能识别快照版本变化并整体替换旧快照。还需要在配比阶段处理并发提交与资源上限，并提供可重复的演示：同样的输入序列和注入的异常必须得到相同的清单输出与业务错误码。

任务环境与准备：
安装 Python 3.11 及以上版本，并安装 FastAPI、Uvicorn、NumPy 与 pytest（建议使用虚拟环境）。
在空白工作区创建项目目录与本地持久化目录，确认无需外部网络与数据库服务。
准备一个本地确定性样本生成脚本，按固定随机种子生成多语言多领域 JSONL 分片以及重复、坏格式、空文本等注入样本。
确认 Windows 控制台可运行应用并按 README 所列本地命令执行演示与测试。

业务要求：
1. 实现分片摄入与近重复检测管线，使用文档给出的 shard_id/doc_id 语义做确定性 MinHash 签名比较与 LSH 分桶，对同一 doc_id 重复出现、签名长度不一致、text 为空分别给出稳定业务码 E_DUP_DOC、E_SIG_SHAPE、E_EMPTY_TEXT，并保证被拒绝的文档不进入后续阶段。
2. 实现摄入、去重、配比三个阶段的状态机，每阶段产生带单调递增版本号与内容校验和的阶段快照，只有阶段完整结束才提交快照；提交顺序、阶段状态与版本号必须在持久化存储中原子可见。
3. 实现强制终止后的恢复逻辑：重启时读取已提交快照，识别快照版本与校验和变化并整体替换旧快照，从最后一次已提交阶段继续；进行中未提交的中间工作不得当作已完成结果使用，损坏或不一致快照返回 E_SNAPSHOT_CORRUPT 且不覆盖旧可用快照。
4. 实现配比采样器，在给定的每语言与每领域 token 目标下做确定性采样，在去重已剔除的语料上优先满足总量目标并允许受限欠配；清单需记录每个目标的实际达成量、欠配原因与采样种子，使同一快照同一配置重跑得到逐字节一致的清单。
5. 实现并发的配比提交控制，使同一时刻只允许一个阶段提交生效；并发提交冲突时后到者立即获得 E_STAGE_BUSY 而不阻塞等待，已完成阶段不能被旧版本回退覆盖，冲突不得破坏已提交快照的完整性。
6. 实现资源上限与异常处理：为摄入批大小、去重候选比较次数、配比内存占用设置可配置上限，超限时按明确策略降级或返回 E_RESOURCE_LIMIT；解析失败、磁盘写入失败等异常必须沿异常链路归因到具体阶段与 shard_id，不得静默跳过或把失败当作成功。
7. 提供一个本地可交互应用，展示当前阶段、快照版本、去重统计、配比达成情况与最近业务错误码，并允许触发一次演示运行；演示使用本地生成的确定性样本与注入的异常输入，不依赖外部服务。
8. 保证跨模块一致性：摄入统计、去重剔除集与清单中的文档集合必须彼此可核对，任何文档不得同时出现在保留集与剔除集；提供一致性自检入口，检测到不一致时返回 E_INCONSISTENT 并指出不一致类别与版本。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地确定性样本核验摄入去重配比全流程，验证强制终止续跑、并发冲突与一致性自检。
