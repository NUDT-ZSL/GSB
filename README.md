当前只有一台干净的开发机，需要从零构建一个面向 LLM 长上下文位置编码变体切换的本地可集成领域组件与完整示例，核心业务问题不是配置文件的格式迁移，而是同一批注意力任务在不同位置编码变体（经典 RoPE、位置插值、NTK 感知缩放、分块频率调整）之间切换时，如何按声明的映射关系裁决旋转角与注意力打分是否等价，并让变体快照与缓存状态在并发提交和强制终止后保持一致。业务对象是本地确定性生成的变体裁决任务清单（JSONL，字段含 case_id、seq_len、head_dim、num_heads、base_theta、variant_pair、scale_ratio、freq_block、block_size、causal、seed），以及由固定种子驱动的 NumPy 生成的 Q/K/V 数组；变体快照以单调递增版本号与内容校验和标识。引擎需对每个 case 同时产出两种变体的旋转角与注意力输出，输出变体间的角度映射残差谱、打分偏差与等价结论，并把旋转角、旋转后 Q/K、分块打分与归一化统计作为可内容寻址缓存的有向无环节点。

任务环境与准备：
安装 Python 3.10 或以上版本，并确保 pip 可用。
执行 pip install numpy 安装 NumPy（建议 1.24 及以上），无需其他第三方依赖。
在本地工作目录下准备可写的缓存目录与报告输出目录，用于存放内容寻址缓存产物与 JSON 报告。
任务执行前无需下载任何模型、数据集或访问网络，注意力任务样本与 Q/K/V 数组均由固定种子在本地确定性生成。

业务要求：
1. 实现同一 base_theta 下四种位置编码变体的确定性旋转角生成：经典 RoPE、位置插值（按 scale_ratio 压缩位置）、NTK 感知缩放（按 scale_ratio 调整频率底数）、分块频率调整（按 freq_block 分块使用不同频率段），半维配对口径显式声明；同一 case、同一变体快照与固定种子下必须逐字节产出相同旋转角与旋转后 Q/K，禁止依赖系统时间或未声明随机源。
2. 实现变体间角度映射关系的声明与裁决：为每个 variant_pair 声明一种映射（如位置插值下的角度等于经典角度乘以 scale_ratio 的倒数、NTK 缩放下的角度按频率幂次重标定、分块频率调整下的角度在块内与块间分段对应），逐维计算实测角度与映射预测角度的残差，输出残差谱与最大残差；映射未声明或残差超出容差分别返回 E_MAPPING_UNDECLARED 与 E_MAPPING_DRIFT 并指明 case_id、维度索引与偏差量。
3. 实现两种变体下的分块注意力打分与在线 softmax 归一化，分块大小由 block_size 给出，causal 语义下禁止访问未来位置；须校验每个变体的分块路径与不分块整段路径在声明容差内逐元素一致，并输出变体间注意力打分的最大绝对偏差与排序一致性比率；分块路径与整段路径不一致返回 E_BLOCK_MISMATCH 并输出首个偏差元素位置与偏差值。
4. 实现旋转角、旋转后 Q/K、分块打分与归一化统计四类节点的内容寻址缓存：键须纳入变体名、base_theta、scale_ratio、freq_block、block_size、causal 语义、分块内容哈希与上游节点哈希，不得把仅快照版本号不同的相同语义视为不同键；键相同必须复用缓存产物，键不同必须重算，并提供入口按 case_id、变体名与节点名查询键组成与产物哈希以核对复用是否真实发生。
5. 实现变体快照切换时的定向失效传播：当 scale_ratio 变化时仅重算位置插值与 NTK 缩放相关节点、当 freq_block 变化时仅重算分块频率调整相关节点、当 block_size 变化时重算分块打分与其下游、base_theta 变化时重算全部变体的位置角及其下游；须输出本次重算节点清单、重算 case 清单与复用集合，且切换后的最终输出须与在全量重算下逐字节一致，局部不重算的节点其产物哈希不得变化。
6. 实现变体快照的版本化与整体替换：快照携带单调递增版本号与内容校验和，检测到版本号或校验和变化时必须整体替换旧快照而非增量修补，回退到更小编号返回 E_SNAPSHOT_ROLLBACK，损坏或校验和不符返回 E_SNAPSHOT_CORRUPT 并指明 case_id 与变体名；快照切换须原子生效，裁决计算不得读到新旧快照混合的变体参数。
7. 实现并发提交控制与资源上限：多个裁决任务可并发执行，同一时刻只允许一个变体快照提交生效，冲突时后到者立即获得 E_STAGE_BUSY 而不阻塞等待且不得影响进行中任务的结果；为单次调用的分块驻留内存估算、缓存条目总量与并行重算节点数设可配置上限，超限返回 E_RESOURCE_LIMIT 或按明确策略降低并行重算节点数并标记降级类别，降级不得改变已提交快照或已产出节点的产物哈希。
8. 提供可集成的领域组件接口与完整示例，并实现跨模块一致性自检：暴露变体旋转计算、角度映射裁决、分块注意力计算、快照切换与缓存诊断入口；命令行示例读取本地确定性样本输出含变体角度残差谱、变体间打分偏差、重算与复用集合、业务码与降级标记的 JSON 报告；自检校验两变体处理的 case_id 集合一致、四类节点缓存键与产物哈希互相可核对、重算集合与复用集合无交集且并集覆盖全部受影响节点。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地确定性样本验证变体间角度映射裁决、分块与整段一致性及快照切换后的定向失效，输出 JSON 报告。
