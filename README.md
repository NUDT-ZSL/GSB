当前只有一台干净的开发机，需要从零实现一个本地实验追踪与版本管理系统的领域可视化与诊断工作台，用于在确定性样本上复现 ML 训练实验的指标增量刷新、超参与数据版本变更引发的依赖失效闭包，并给出可追溯的诊断结论。本地 JSON 样本给出三部分：实验谱系（实验 ID、父实验 ID、超参键值、数据集版本、代码提交占位标识、基线指标与逻辑时钟毫秒戳）；指标轨迹流（指标记录序号、实验 ID、指标名、步号、指标值、逻辑时钟毫秒戳、记录摘要）；以及两代追踪快照——v1 为单文件 JSON，记录实验别名、指标名、相对刷新秒数与扁平指标到实验的映射；v2 为分片 JSON 加 SQLite 元数据库，记录规范实验 ID、绝对刷新时刻毫秒、追踪代数、指标摘要与失效墓碑。工作台需合并两代快照形成统一追踪视图，按注入逻辑时钟推进实验指标增量刷新，在超参、数据集版本或上游实验变更时沿谱系与指标引用关系计算失效闭包，并只在依赖确实失效时重算，其余结论必须逐字复用。所有时间判定只依赖注入的逻辑时钟毫秒值，不读取系统墙钟。

任务环境与准备：
安装 Python 3.11 或更高版本，并创建独立虚拟环境。
执行 pip install flask numpy 安装运行依赖，SQLite 使用 Python 标准库 sqlite3。
准备本地确定性样本目录，包含实验谱系 JSON、指标轨迹流 JSON、v1 单文件快照、v2 分片 JSON 与 SQLite 元数据库占位文件。
所有命令在 Windows 命令提示符或 PowerShell 中运行，不依赖容器、网络或外部服务。

业务要求：
1. 实现实验谱系、指标轨迹流与两代追踪快照的解析校验：实验 ID 唯一、父实验引用存在且谱系无环、超参键值类型合法、指标步号单调且指标值为有限数、v1 别名唯一且指纹与实验声明一致、v1 相对刷新秒数为非负整数、v2 分片文件哈希与追踪代数单调合法；非法输入须返回明确业务错误码且不写入任何持久化状态。
2. 实现跨版本快照合并与统一追踪视图构建：同一实验别名在两代快照中同时存在时，依据快照声明的逻辑时钟与追踪代数裁决最新条目，逻辑时钟相同则按来源格式优先级裁决；合并后每条目须保留来源版本、原始时间表示、原始绝对刷新时刻的换算标度与舍入方向以及裁决依据，使任意合并结论可被逐字段追溯。
3. 实现基于注入逻辑时钟的指标增量刷新与刷新窗口切分：指标记录按窗口边界归并，窗口边界与刷新时刻只依赖注入的逻辑时钟毫秒值；每个指标记录必须唯一归属一个窗口且不得同时计入两个窗口，v1 相对刷新秒数换算为绝对刷新时刻时须登记换算标度与余量；同一轨迹在任意运行次数下必须得到逐位一致的刷新序列与指标摘要。
4. 实现超参与数据版本变更驱动的依赖失效闭包裁决：以补丁形式提交超参、数据集版本或父实验引用的修改，沿“实验—父实验—指标引用—刷新窗口摘要”的关系计算受影响闭包，精确标记哪些实验指标与刷新结论需重算、哪些可安全复用；未受影响实验的指标摘要与刷新结论必须逐字保持不变，失效清单须记录触发来源与被否决的复用候选。
5. 实现基线指标对比与失效重算的唯一真值对照：对每个实验在合并视图下比较各指标相对基线的偏差方向与幅度，运算顺序与聚合顺序固定使结果逐位可复现；同时以从原始谱系与轨迹全量重算得到唯一真值，两条路径逐指标比对，不一致时须输出首个分歧实验 ID、指标名、参与窗口号、两条路径数值及所依赖的快照版本。
6. 实现快照整体替换的版本变化识别与读取隔离：收到新追踪快照包时比较清单版本号、追踪代数下限、各分片哈希与指标摘要集合，判定完整替换、增量追加还是无需操作，版本回退必须被拒绝并返回独立业务错误码；完整替换须以临时表加版本号整体切换当前快照指针而非逐条覆盖，进行中的刷新必须绑定其开始时的快照版本直至结束，读者不得观察到新旧快照混合的指标或失效结论。
7. 实现持久化状态与强制终止后的恢复裁决：把快照版本指针、指标刷新水位、窗口摘要、失效事件、基线对比结论与逻辑时钟水位以事务原子写入 SQLite；进程在窗口提交或快照替换中途被强制终止后，恢复路径须识别已提交窗口与半提交失效事件，只重放未完成部分且不得重复计入指标或改变已提交结论，恢复后结果与未中断运行逐位一致。
8. 实现多进程并发一致性与可重复诊断命令行：允许多个刷新实例与快照更新实例并行，通过 SQLite 事务与文件锁保证同一快照版本只提交一次、同一实验同一窗口同一版本只提交一次、同一补丁重复提交幂等；提供 load、refresh、patch、diagnose、resume、status、verify 子命令，status 以稳定排序 JSON 输出各实验指标摘要、失效来源链、精度敏感标记与当前快照版本，verify 校验持久化状态与全量重算真值一致。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
