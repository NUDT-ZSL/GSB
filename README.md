在角色动画制作与引擎装配场景中，需要从零开发一个本地骨骼动画动作重定向工作台：把一套源骨架的动作数据重定向到目标骨架，并在骨骼层级、绑定参数或动作曲线被编辑后只重算受影响的骨骼与时段。输入为程序按确定性规则生成本地样本：源骨架与目标骨架的层级定义（骨骼名、父骨骼、静止位姿平移与旋转、缩放）、重定向映射表（源骨到目标骨的对应、各骨旋转偏移与缩放补偿）、动作数据（每骨的关键帧时间与四元数旋转、根位移曲线）、编辑脚本（按时间顺序描述对骨骼映射、绑定补偿、关键帧的增删改）、重定向参数（采样帧率、插值方式、根位移是否迁移、有效帧区间）以及并发上限与在途采样缓冲内存上限。核心难点在于每目标骨的重定向结果依赖其源骨链、映射表与绑定补偿，任一处编辑都会沿层级向下游传播失效，而未受影响骨骼与时段必须复用既有结果，最终整段动作必须与不做增量、从头全量重定向得到的逐帧四元数在容差内一致。

任务环境与准备：
安装 Python 3.11 及 NumPy、PySide6（建议在虚拟环境中安装并确认可导入）。
确认可在 Windows 本地运行 Python 脚本并可创建临时目录与状态目录，样本与输入文件由确定性规则在本机生成，不需外部资源或真实账号。
运行前清空或新建专用的输出与状态目录，避免与既有文件混用；确认无外部网络依赖。

业务要求：
1. 实现骨架、映射表、动作数据与编辑脚本解析：校验骨骼名唯一且父骨骼先于子骨骼声明或可拓扑排序、无环、映射表引用的源骨与目标骨均存在且目标骨不被重复映射、关键帧时间为有限非负数且严格递增、四元数为有限数并在读入后归一化（零范数四元数按 E_ROT 拒绝）、编辑脚本步骤序号递增；非法输入返回带 E_xxx 业务码的 JSON 错误且不产生输出文件。
2. 实现重定向核心计算：按映射表把源骨旋转与目标骨静止位姿、映射旋转偏移和缩放补偿合成为目标骨局部旋转，根位移按参数决定迁移到目标根骨或保留在原点，任意目标骨在任意采样帧的结果只依赖其源骨链、映射表、绑定补偿与有效性区间，与骨骼遍历顺序和块调度完成顺序无关，重复运行得到逐字段相同的输出。
3. 实现依赖图与失效传播：为每目标骨建立对其源骨链、映射条目、绑定补偿及所涉关键帧区间的依赖记录，编辑脚本任一步发生后只把沿层级可达的下游骨骼与被编辑曲线覆盖的帧区间标记为失效，其余骨骼与时段必须保持原结果不变并在诊断报告中列出失效骨骼集合与失效帧区间；失效记录须可追溯到触发编辑的具体步骤与字段。
4. 实现增量重算与全量结果一致：只对失效骨骼的失效帧区间重算并在相邻保留帧处做边界衔接，插值与根位移迁移必须在衔接点连续；增量重算后的整段动作与同输入从头全量重定向的结果每一帧每一骨旋转差不超过角度容差、根位移差不超过距离容差，越界时以 E_DIVERGE 报告首个越界骨骼与帧号。
5. 实现分层持久化与版本识别恢复：按骨骼与帧区间分块，每块完成后把该块结果与该块依赖摘要、以及由骨架、映射表、动作数据与重定向参数规范化摘要构成的版本标识原子写入状态目录；再次启动时比对版本标识，一致则复用已完成块只重算缺失与失效块，不一致则从头重做；快照整体替换前须比对已有版本标识并归档旧版本，禁止新旧版本混写。
6. 实现并发重算与资源上限：按并发上限使用有界线程池调度待算块，同时处于计算中的关键帧采样与四元数插值缓冲总量不得超过内存预算，超出时按骨骼层级序让后续块等待而非降低采样精度；任一块异常时取消其余待处理块并返回首个错误，最终拼装结果与串行逐块结果完全一致。
7. 实现编辑脚本逐步重演诊断：按编辑脚本顺序逐步应用并输出每步的失效骨骼集合、重算块数、变更帧区间与业务码摘要，同时保留每步之后可供回看的结果版本；诊断报告须与持久化块状态对应，报告中断或摘要不符时判定该步状态失效并返回 E_DIGEST，不得静默使用失效结果。
8. 处理中断语义与输出原子写出：可处理终止信号只在块边界生效，写入中断标记并以约定整数退出码退出，未完成块不得留下可被误认为已完成的结果；强制终止后重启仅依据已持久化且摘要有效的块状态恢复且不承诺生成退出报告；全部块完成后校验块摘要，失效块补算，通过后把重定向动作与诊断报告先写同目录临时文件再整体替换正式文件，失败时保留旧文件。
