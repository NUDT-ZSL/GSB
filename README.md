开发环境刚准备好，项目目录还是空的，需要从零交付一个可集成的目标检测候选匹配验证组件与完整示例。组件处理本地确定性生成的图像样本、候选框与真值框，并把候选匹配结果（TP/FP/FN 指派、IoU 分数、类别聚合统计）写入两代格式账本：v1 为单文件 JSON，只记录图像标识、相对提交秒数与扁平的匹配行；v2 为分片 JSON 加 SQLite 元数据库，记录绝对逻辑毫秒、匹配代数、候选框内容哈希与真值框版本。样本由固定种子脚本生成本地文件，不依赖真实图像、在线标注或 GPU。候选框与真值框来自同一随机源，每张图含候选框 x1/y1/x2/y2、score、class_id，真值框含 label、difficulty、遮挡标记与修订号。匹配链路建模为：样本摄入与校验→按类别分组贪心指派→匹配账本双版本写入与快照→账本重放→结果验证。核心矛盾在于：账本版本演进、真值框修订与配置阈值调整都会触发增量失效，而匹配判定必须跨版本复现且在任何中断后重放一致。

任务环境与准备：
安装 Python 3.10 及以上版本，并安装 numpy 库；SQLite 使用 Python 标准库 sqlite3。
在本地工作目录中创建 samples、ledgers、checkpoints 子目录，无需预置任何文件；随题交付的固定种子脚本 generate_samples.py 用于生成本地确定性 JSON 样本与真值框清单。
样本包含候选框 JSONL、真值框 JSONL、两代账本模板及可注入逻辑时钟参数；所有路径使用相对路径，依赖仅限 numpy 与标准库。

业务要求：
1. 实现确定性的样本摄入与校验阶段：解析候选框与真值框 JSONL，校验图像标识唯一、坐标数值非负且 x2>x1、y2>y1、class_id 落在受控标签集合内，并按图像标识与框序号稳定排序；同一输入、同一配置下必须逐字节产出相同的中间表示与排序，重复标识或非法坐标分别返回 E_DUP_IMAGE 与 E_BAD_BOX。
2. 实现按类别分组贪心指派阶段：在每个图像内按 class_id 分组，组内按 score 降序、同分按左上坐标字典序升序依次与真值框计算 IoU，达到阈值则指派为 TP，否则尝试下一真值框，未被匹配的真值框记为 FN、未匹配候选记为 FP；每次比较记录交集面积、并集面积与比较结果，使任意指派可被逐项复算。
3. 实现匹配账本 v1 与 v2 的双格式写入与读取：v1 为单文件 JSON，按图像标识与相对提交秒扁平写入匹配行、TP/FP/FN 状态与聚合分数；v2 为分片 JSON 加 SQLite 元数据库，记录绝对逻辑毫秒、匹配代数、每行内容哈希与真值框修订号；读取器按版本头分派，未知版本返回 E_VERSION_UNSUPPORTED，字段缺失或数值不可解析返回 E_FORMAT_CORRUPT。
4. 实现 v1 到 v2 与 v2 到 v1 的双向账本迁移：升级时补全匹配代数、候选框内容哈希与真值框修订号默认值并逐项记录补全来源；降级时对 v2 中 v1 无法表达的代数与哈希按显式丢弃规则处理并写入降级记录；迁移后两代账本在同一图像上的 TP/FP/FN 集合与聚合分数必须一致，不一致返回 E_MIGRATION_MISMATCH。
5. 实现真值框修订与配置阈值调整的定向失效传播：当某图像真值框以更高 revision 到达、或 IoU 阈值变化时，按内容寻址缓存键计算受影响图像与受影响账本行集合，复用未受影响图像已提交匹配结果，仅重算受影响图像并重写相关账本行；若账本版本本身变化（v1↔v2）则必须先整体迁移再应用增量，禁止在旧版账本上打补丁。
6. 实现账本行与图像匹配结果的双向重放验证：对任一账本行，可按记录的候选框哈希、真值框修订号、IoU 计算明细与当时配置重放出相同 TP/FP/FN 状态与分数；对任一图像，从双版本账本重放出的指派结果必须逐行一致；重放链缺失或结果不符返回 E_REPLAY_MISMATCH。
7. 实现匹配账本的版本化快照、中断恢复与并发提交控制：v1、v2 账本、真值框清单与配置快照各携带单调递增版本号与内容校验和，检测到版本号或校验和变化时必须整体替换旧快照而非增量修补，回退尝试返回 E_SNAPSHOT_ROLLBACK，损坏账本返回 E_SNAPSHOT_CORRUPT；在图像批次边界原子提交账本与元数据，重启时读取最近已提交批次，从下一图像继续，已提交图像不得重算，同一时刻只允许一个账本提交生效，并发冲突时后到者立即返回 E_STAGE_BUSY。
8. 实现输入与配置校验、资源上限与跨模块一致性自检，并提供可集成的组件接口与完整示例：阈值越界、真值修订号回退分别返回结构化业务码并指明字段；为驻留候选框内存、同时打开分片数与重算图像数设可配置上限，超限返回 E_RESOURCE_LIMIT 或降级并标记；自检校验双版本账本行数一致、各图像 TP/FP/FN 可互推、重放与原始匹配一致，不一致返回 E_INCONSISTENT。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
