在空白工作区构建一个可集成的 CSR 稀疏矩阵乘（SpMM）算子组件与完整示例，面向本地确定性合成的 CSR 稀疏矩阵与稠密矩阵，计算 C = alpha*A*B + beta*C，其中 A 为 M×K 的 CSR 稀疏矩阵，B 为 K×N 的稠密 float32 矩阵，C 为 M×N 稠密 float32 矩阵。核心挑战是稀疏结构敏感的逐元素误差传播：每行非零元个数从个位数跨越到数千，行内 axpy 累加链长度差异极大，同一输出元素由哪些非零元、以何顺序贡献会直接改变舍入误差；B 的元素跨数量级时单精度长累加链会吞掉小项，而每行非零元的位置分布又决定累加链中大小项的相邻关系。组件需要把每个输出元素的误差按贡献链归因到具体非零元与累加位置，而不仅给出整体误差摘要，并据此判断误差主导来源。输入为形状描述与固定种子生成的稀疏结构，输出计算结果、逐元素误差归因、稀疏结构分层敏感性与统计报告，全部在 Windows 本地可复现执行。

任务环境与准备：
安装 Python 3.10 及以上版本，并确保 numpy 可用（pip install numpy）。
在空白工作区创建项目目录与本地样本配置、注入配置示例文件，无需网络与外部数据集。
确认可在 Windows 本地运行 Python 脚本，并准备输出报告目录用于原子替换写盘测试。

业务要求：
1. 实现 CSR 稀疏结构构造与校验层：按形状描述与固定种子生成每行非零元个数（支持均匀、幂律与极不均匀三种分布），列索引须严格递增，并生成浮点数值；校验列索引范围、行偏移单调性与非零元总数一致性，非法时输出 E_CSR_INVALID 并进入失败清单；为每个非零元生成由行号、列号与生成序号派生的稳定非零元标识，结构指纹与逐元标识都须写入报告用于复现。
2. 实现单精度 SpMM 参照内核：对每行按列索引升序遍历非零元，对 B 的对应行做 axpy 式累加，再按 alpha 缩放并与 beta*C 合并；结果不做重排，每行记录非零元个数、累加顺序标识与行结果指纹，作为后续误差归因的基线；同时提供 float64 参考路径输出严格参考值，两路径须共用同一 CSR 结构与同一非零元标识。
3. 实现稀疏行分块内核与累加顺序变体：支持按每行非零元个数切块（块大小可配置）并对块内部分和做二次累加，块内累加顺序支持升序、降序与按对应 B 行元素绝对值降序三种；边界块须精确裁剪，零非零元行须输出可追踪的零结果；每种顺序须能对不同输出元素产生可观测的数值差异，并输出逐元素与参照内核的差值。
4. 实现逐元素误差贡献链归因：对每个输出元素，以 float64 参考值为真值计算绝对误差与相对误差，并沿其累加链把误差归因到具体非零元所在累加位置；输出每个超差元素的前若干贡献非零元标识、各贡献对应的局部舍入量与累计占比；归因结果须能区分误差由长链累积、由大小项相邻抵消还是由单个大数量级非零元主导，容差由配置给出，容差为零时输出 E_TOLERANCE_INVALID。
5. 实现稀疏结构分层敏感性分析：按每行非零元个数区间与 B 行元素数量级比分区间对输出元素分层，统计各层最大相对误差、超差比例与平均归因份额，并给出每层误差主导因素结论；结论须以可审计分层表输出，同分时按区间下界升序排列；分层边界须与归因的逐元素标识可交叉引用，保证任一超差元素能从报告回溯到其所属层。
6. 实现自适应策略选择器与双精度档位对比：依据 M、K、N、非零元总数、每行非零数分布类型与数量级比指标，从预置策略表选择分块大小与累加顺序，输出含参考指标、候选策略评分与选择理由的决策记录；同一策略须在 float32 与 float64 两档位下完整计算，输出逐元素档位差值与档位差超阈元素清单，档位差主导来源须与误差归因口径一致。
7. 实现并发计算与串行结果一致性：使用线程池按行块并发执行分块乘加，最大并发数取自配置；每个行块任务携带由行块起止行号派生的稳定排序键，无论线程调度顺序如何，最终 C 的逐元素结果、误差归因清单与排序、决策记录顺序、分层表与统计报告必须与单线程按行升序执行逐字段一致；线程只允许改变执行时机，不得改变任何输出元素的累加顺序。
8. 实现异常注入隔离、快照恢复与报告输出：以独立注入配置指定非有限元素、形状不一致、分块参数越界与容差为零等样例，注入项编号写入运行报告以证明命中，异常记录形状、阶段名、业务码与异常类型并继续其余样例；每次完整运行以临时文件加原子替换方式输出 JSON 报告，含结构指纹、策略决策、逐元素误差归因摘要、分层表、档位对比、失败清单与业务码；运行可处理的退出信号时，须先完成当前行块结果与进度记录的原子写盘再以整数退出码 0 结束，重启后依据已完整写盘的记录判定恢复起点，不承诺强制终止后一定产出完整报告。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
