从无到有搭建时，需要构建一个面向机器翻译数据准备的本地数据处理管线与结果验证工具，核心业务问题是数据规模变化下的算法取舍。业务对象是本地确定性生成的双语平行语料：源句与目标句由固定种子从受控词表拼装成 token 序列，另附词级对齐表与样本清单（JSONL，字段含 pair_id、src_tokens、tgt_tokens、align 列表含源与目标位置、src_len、tgt_len、noise_level、domain_tag）。管线把一次翻译数据准备建模为多阶段流程：分片摄入与校验→双语分词与词对齐验证→子词候选切分与词表构建→长度比与噪声过滤→去重与配比采样→导出数据集与指标报告。在语料从数千对增长到数十万对时，全量比对、全局最优子词切分与穷举去重的代价迅速逼近比较次数与驻留内存上限，系统需要在精确路径与近似路径之间做取舍，并保证取舍记录可复现、结果可核对。

任务环境与准备：
在 Windows 10/11 上使用 Python 3.11（或 3.10）创建全新虚拟环境：python -m venv .venv 并激活。
安装依赖：pip install "numpy>=1.24,<2" "pytest>=7,<9"。
在本地新建 data 目录，准备受控词表、词级对齐表与语料清单 JSONL 文件；清单字段含 pair_id、src_tokens、tgt_tokens、align、src_len、tgt_len、noise_level、domain_tag，由本地脚本按固定种子确定生成，不依赖外部数据与网络。
确保工作目录可写，用于落盘缓存、快照与 JSON 报告目录。

业务要求：
1. 实现确定性的分片摄入与词对齐验证阶段：按 pair_id 升序读取平行语料，校验源与目标 token 均落在受控词表、align 位置在两侧 token 长度范围内且方向合法，输出对齐校验摘要与每对的码点区间；同一输入、同一词表版本与同一配置下必须逐字节产出相同的摄入摘要与校验结论，重复 pair_id、空句、对齐越界分别返回 E_DUP_PAIR、E_EMPTY_SENT、E_ALIGN_RANGE 并指明 pair_id 与位置。
2. 实现双子词候选切分与词表构建阶段：对源与目标 token 序列按可配置的子词候选生成规则产出候选切分，按词频与切分长度组合打分选出每句最优切分，同分时按切分边界数降序、再按切分字典序升序裁决，并合并为共享子词词表；须输出每句切分结果、子词编号与词表规模，同一输入与同一配置下切分与词表必须逐字节可复现，词表空或候选规则非法分别返回 E_VOCAB_EMPTY 与 E_CONFIG_INVALID。
3. 实现长度比与噪声过滤阶段：按源与目标子词长度比、noise_level 及可配置门限判定样本保留或剔除，同分或同判定冲突时按 pair_id 升序打破平局，门限提供严格比较与容差带比较两种策略并配次正规数保护，保证恰好落在门限附近的样本在重复运行与多精度档下判定不被舍入翻转；输出逐样本判定明细与剔除原因，门限策略或容差非法返回 E_THRESHOLD_INVALID，指标须可由逐样本明细独立重算一致。
4. 实现基于数据规模的自适应算法取舍器：按语料对数、词表规模、平均对齐长度与驻留内存余量在精确路径（全量对齐比对、全局最优子词切分、穷举去重）与近似路径（候选剪枝、分块切分、签名摘要去重）之间选择，必要时走流式分批执行；输出含规模观测与比较次数估计的取舍记录，同一观测下决策必须逐字节一致且所选路径须覆盖全部输入，路径未覆盖全部输入时返回 E_PATH_INCOMPLETE 并指明遗漏 pair_id。
5. 实现精确路径与近似路径的跨路径一致性裁决：对同一语料同时产出两路径结果时，输出保留样本集合差异、子词切分一致率与词表规模偏差，并区分差异来自候选剪枝遗漏还是平局规则应用不同；当差异导致语料统计口径不可比时返回 E_PATH_DIVERGENCE 并输出首个分歧 pair_id 与分歧类型；差异谱须可由逐样本明细重算一致。
6. 实现比较次数与驻留内存的双重预算准入：按语料对数、词表规模与平均候选数估算对齐比对与切分比较代价，在总比较预算与驻留词表及特征内存上限内决定准入规模与是否降批；超限分别返回 E_COMPARE_BUDGET 与 E_RESOURCE_LIMIT，降批须在结果中标记降级类别且不得改变已提交样本的判定。
7. 实现子词词表与过滤配置的版本化管理及整体替换：词表、过滤门限与配比目标各携带单调递增版本号与内容校验和，检测到版本号或校验和变化时必须整体替换旧快照而非增量修补；重启加载时识别版本变化并整体替换，旧版本不得覆盖新版本且回退尝试返回 E_SNAPSHOT_ROLLBACK，损坏或校验和不符返回 E_SNAPSHOT_CORRUPT。
8. 实现导出数据集与指标报告并完成跨阶段一致性自检：导出符合声明顺序的 TSV 双语数据与含取舍记录、逐样本判定明细、词表规模、长度比统计、保留率与业务码的 JSON 报告；自检校验各阶段 pair_id 集合完全一致、被剔除样本不出现在导出中、词表可由逐句切分重算、指标可由明细独立重算、取舍记录所选路径覆盖全部输入；不一致返回 E_INCONSISTENT 并指明首个分歧位置。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地固定种子样本运行管线，核对跨路径一致性、双预算拒绝与快照回退业务码并附 JSON 报告。
