当前是空白工作区，需要从零构建一个面向 OCR 文字检测识别的本地数据处理管线与结果验证工具，核心业务问题是交互延迟与计算结果一致性。业务对象是本地确定性生成的文档图像样本：每张图由固定种子生成固定尺寸的灰度像素数组，图上按固定布局绘制若干文本行（每行由确定性笔画模板拼出，附带真值框 x1,y1,x2,y2 与真值字符串），并配有 OCR 任务清单（JSONL，字段含 page_id、image_seed、image_shape、行数、字符集版本、policy）。管线被建模为三阶段：文本行检测（基于投影与连通域得到候选行框）、区域裁剪与识别（对每行区域做确定性特征提取与模板匹配打分得到识别字符串与置信度）、页面聚合（排序、去重、输出页面级结果与指标）。系统对外提供交互式查询：按 page_id 与行号查询该行的框、识别串、置信度与参与打分的候选明细。核心矛盾是：为压低首行可见延迟，识别阶段采用按行分块与结果缓存，但分块边界处的特征归一化统计量与整页一次性识别口径必须一致；缓存复用、预取与并发查询会与识别结果的可复现性、延迟预算和资源上限产生冲突，需要显式裁决。

任务环境与准备：
Windows 本地安装 Python 3.10 及以上，创建独立虚拟环境并用 pip 安装 numpy；样本图像、真值框与 OCR 任务清单由脚本按固定种子本地确定性生成，不依赖外部数据集、账号或网络站点。
确认本地可用的进程与文件权限，为缓存目录与快照目录准备独立的本地路径；字符模板库与字符集版本以本地文件形式提供，版本号与内容校验和在生成时写入。
准备一次注入异常输入与一次超预算查询的演示参数并写入本地配置文件，运行前核对 Python 与 NumPy 版本，以保证分块识别与整页识别比对在同一环境下执行。

业务要求：
1. 实现确定性的文本行检测阶段：按固定种子生成灰度页面像素，用行方向投影与连通域规则得到候选文本行框，框坐标以像素整数表示，同分时按 y 坐标升序、再按 x 坐标升序打破平局；同一 page_id、同一输入与同一配置下必须逐字节产出相同的候选行框集合与真值覆盖率统计，禁止依赖系统时间、字典遍历顺序或任何外部状态。
2. 实现确定性识别阶段与页面级指标：对每个候选行区域提取确定性特征并与字符模板库做模板匹配打分，输出识别字符串、置信度与候选明细；由识别结果与真值字符串计算字符准确率与行准确率，指标须可由逐行明细独立重算一致；模板库版本或字符集版本变化时必须改变打分并可追溯，同一快照重跑得到相同字符串与相同指标。
3. 实现按行分块识别与整页一次性识别的逐字节一致性：块边界处的特征归一化统计量、行间去重阈值与置信度量化口径必须与整页口径完全相同，逐块拼接结果与一次整页识别结果逐行逐字符相同；检测到差异返回 E_CHUNK_MISMATCH 并指出首个差异 page_id、行号与差异类别，禁止以放宽比对口径掩盖差异。
4. 实现交互式按行查询的延迟预算控制：按 page_id 与行号查询该行框、识别串、置信度与候选明细，须在配置的单次延迟预算内返回；延迟以本地识别循环的实际处理计时观测并按行像素数与匹配候选数给出估算记录，超预算返回 E_LATENCY_BUDGET 并附带已完成阶段与已就绪行号，禁止用线程超时或延迟等待伪造真实超时或已完成状态。
5. 实现识别结果缓存与失效联动：缓存键须纳入页面图像内容哈希、行框摘要、字符模板库版本、识别参数与分块口径，键相同必须复用缓存快照，键不同必须重算；当模板库版本提升、字符集收缩或页面像素变化时必须计算受影响缓存条目集合并仅失效这些条目，需输出本次重算行清单与复用行清单，且缓存命中与否不得改变最终识别结果。
6. 实现精度、延迟与内存的冲突裁决：当缩小分块可降低首行延迟却增加边界中间态与一致性校验开销、放大分块可减少归约开销却逼近驻留内存上限时，须按显式优先级规则在首行延迟、识别精度与内存之间裁决，并在解码计划中记录裁决依据、所选分块大小与受影响行范围；裁决结果在相同观测下必须逐字节可复现，不得以牺牲已输出结果的正确性换取预算达成。
7. 实现识别产物与配置快照的版本化及整体替换：字符模板库、识别参数与页面结果快照各携带单调递增版本号与内容校验和，提交时整体替换旧快照而非增量修补；重启加载时识别版本号或校验和变化并整体替换，损坏或不符返回 E_SNAPSHOT_CORRUPT 并指明快照类别与版本号，禁止使用部分可解析的损坏数据；同一时刻只允许一个快照提交生效，并发冲突时后到者立即获得 E_STAGE_BUSY 而不阻塞等待。
8. 实现结果验证工具与跨模块一致性自检：独立复核每页行框覆盖完整、识别串长度与候选明细可核对、缓存键与产物哈希可互相核对、查询侧单行结果与页面级结果在声明精度内一致；并校验重算行集合与复用行集合无交集且并集覆盖全部受影响行、行框互不越界重叠、页面级指标可由逐行明细重算一致，不一致返回 E_INCONSISTENT 并指出不一致类别与 page_id；另附本地命令行演示含一次注入异常输入与一次超预算查询。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
