# 地形高度标量场等值线查看器

关卡美术本机核对地形高度分层的工具：读取网格 JSON，绘制带刻度与级别标注的
等值线图，支持悬停定位、拖拽框选放大与一键重置。纯本地运行，仅依赖
Python + PySide6，不访问网络与任何外部服务。

## 环境要求与安装

- Python 3.10 及以上
- PySide6 6.5 及以上：`pip install "PySide6>=6.5"`

本机已验证：Python 3.10.20 + PySide6 6.5.3（Windows 11）。
（首次导入 PySide6 时终端可能打印一段 NumPy 版本提示，来自环境中的
shiboken6，与本程序无关，程序不使用 NumPy，可忽略。）

## 启动说明

```bash
# 1. 生成确定性业务样例（写入 samples/，纯公式生成，可复现）
python gen_samples.py

# 2. 启动查看器（省略路径时默认打开 samples/sample_normal.json）
python contour_viewer.py samples/sample_normal.json

# 3. 自动化自检（覆盖任务要求 1-14，截图存入 results/）
python run_tests.py
```

窗口交互：

- **悬停**：状态栏显示最近网格点的行列号、坐标与高度值；移出网格范围
  提示“超出网格范围”；悬停无数据（NaN）单元格显示“无数据”。
- **拖拽框选**：按住左键拖出矩形后视图缩放到该区域，坐标轴刻度同步更新；
  框选宽度或高度小于一个网格间距时取消该方向缩放并提示“区域太小”。
- **重置视图**：工具栏按钮或按 `R`，恢复完整范围并清除状态栏悬停信息。
- **关闭窗口**：进程正常退出，无错误对话框。

## 网格 JSON 格式

```json
{
  "rows": 61,                "行数（y 方向网格点数，2..200）"
  "cols": 81,                "列数（x 方向网格点数，2..200）"
  "x_range": [0.0, 8.0],     "x 最小/最大值"
  "y_range": [-3.0, 5.0],    "y 最小/最大值"
  "matrix": [[...], ...],    "rows 行 x cols 列；null 或 NaN 表示无数据单元格"
  "levels": [-0.44, ...]     "等值线级别，1..20 个"
}
```

`matrix[j][i]` 对应网格点 `(x_i, y_j)`，`j = 0` 为 y 最小值所在的行。
缺少必需字段、维度与行列数不符、值类型非法时，程序在终端打印明确错误
并以退出码 2 终止，不创建任何窗口。

## 业务样例（由 gen_samples.py 确定性生成）

高度场为两座高斯峰/谷 + 缓坡 + 波纹的确定公式，61x81 网格，
x∈[0, 8]，y∈[-3, 5]，数据值域 [-0.7649, 3.3282]。

| 文件 | 说明 |
|---|---|
| `sample_normal.json` | 正常样例，10 个级别（-0.44 … 3.12） |
| `sample_nan.json` | 中央矩形区域 + 散布点共若干 null（无数据）单元格 |
| `sample_levels_out_of_range.json` | 级别含 -2.76、5.33，超出数据值域 |
| `sample_mixed.json` | NaN 单元格 + 超范围级别混合异常 |
| `bad_missing_field.json` | 非法：缺少必需字段 `levels` |
| `bad_dim_mismatch.json` | 非法：`rows` 与矩阵实际行数不符 |
