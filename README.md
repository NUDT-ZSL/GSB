在游戏资产入库与三维打印前处理场景中，美术与工程团队会收到大量带缺陷的三角网格：存在非流形边、退化面、孔洞、自相交与法线翻转。修复流程往往不可逆，修复算法在对顶点坐标做拉普拉斯平滑、孔洞三角化与退化面移除时，会把浮点误差沿着拓扑邻接关系向外传播，导致修复后体积、曲面曲率与包围盒出现肉眼不可见但超过工程容差的偏差。当前为空工作区，需从零开发一个本地桌面工作台：加载程序按确定性规则生成的网格样本与修复脚本，逐步骤执行修复算子，量化每步修复引入的几何误差并追踪其沿拓扑邻接的传播范围，给出可复现的误差诊断结论。工作台需支持中断与续算：修复过程在算子边界可被打断，重启后须从持久化状态恢复且结果与不中断连贯执行逐顶点一致。

任务环境与准备：
确认 Windows 环境可运行 Python 3.11，并可使用 pip 安装依赖
安装依赖：pip install numpy PySide6，使用固定版本以保证界面与数值结果可复现
无需 GPU、外部模型或网络资源；网格样本与修复脚本由工作台自带的确定性生成程序在本地生成
准备一个可写的状态目录与输出目录，并确保磁盘空间足以容纳步级网格快照

业务要求：
1. 实现网格与修复脚本解析校验：读取本地三角网格文件与 JSON 修复脚本，校验顶点坐标与面索引均为有限数、面索引不越界、脚本中算子类型属于允许集合、坐标容差与迭代参数为有限正数；非法输入返回带 E_SCHEMA 或 E_INDEX 业务码的 JSON 错误且不写出任何输出文件。
2. 实现拓扑邻接构建与非流形诊断：构建顶点到面、面到邻接面的邻接结构，统计非流形边、边界边、退化面与孤立顶点，并用整数拓扑不变量（顶点数、面数、边界环数）计算欧拉示性数；诊断计数须与对网格文件逐面重扫的结果一致，修复前后报告使用同一统计口径。
3. 实现修复算子链的确定性执行：按脚本顺序执行孔洞三角化、退化面移除、法线重定向与拉普拉斯平滑，各算子对顶点与面的修改顺序只依赖网格索引确定性顺序与脚本声明的迭代次数，同一输入重复执行必须得到逐顶点坐标完全相同的网格与相同算子执行计数。
4. 实现浮点参考与定点量化的误差对照：坐标累加同时保留 float64 参考值与规格定点标度下的整数值，逐顶点记录两者差值并在报告中标出首次超过坐标容差的顶点与算子序号，最终判定结论只依据定点结果，float64 值仅作对照展示。
5. 实现误差沿拓扑邻接的传播追踪：以每个算子中被直接改动的顶点为传播源，按邻接距离向外记录受影响顶点集合与各层最大坐标偏差，给出传播层数与衰减结论；传播记录须可定位到具体源顶点、算子序号与层号，不得用事后全网格差异替代逐层追踪。
6. 实现步级持久化与中断续算恢复：每个算子执行完成后把网格快照、算子序号与由输入网格内容及脚本规范化摘要构成的版本标识原子写入状态目录，先写临时文件再整体替换，替换前比对已有快照版本标识，标识变化时不得直接覆盖旧快照而须先归档；可处理终止信号只在算子边界生效并以约定整数退出码退出，强制终止后重启仅依赖已持久化且摘要有效的快照恢复。
7. 实现并发评估与资源上限：按规格中的并发数用有界线程池并行计算各算子的候选诊断统计（如逐层传播误差与逐面退化判定），同时处理的顶点与面缓冲总量受内存预算约束，超出预算时按顶点索引序让后续任务等待而非降低容差精度，结果按固定索引归并，参考并发度变化不得改变诊断数值。
8. 实现可交互诊断工作台：展示修复前后网格三维视图或二维投影、逐顶点误差热力着色、算子执行时间线、传播层统计与业务码列表，支持选择算子或顶点后高亮对应传播源与受影响区域；视图数据只读取已持久化的确定性结果，摘要不符的步级快照须在界面标记为失效且不得用于恢复。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地网格样本与修复脚本验证诊断报告、误差传播定位、中断续算与失效快照拒绝，并附运行结果。
