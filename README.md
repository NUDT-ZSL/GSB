在空白工作区从零实现一个本地弹性伸缩指标驱动控制面，交付领域数据编辑与操作应用。业务对象是一组声明式伸缩策略：工作负载、指标源、伸缩规则、资源预算与冷却窗口，对象间以 ID 引用（规则引用指标源与工作负载，预算约束工作负载的最大副本数与每副本资源需求）。本地 JSON 样本给出工作负载清单（名称、当前副本数、最小最大副本数、每副本 CPU 毫核与内存 MiB、拓扑域）、指标源清单（指标名、聚合方式为平均值或分位数、采样窗口逻辑毫秒、目标值与告警阈值）、伸缩规则（工作负载、指标源、方向、步长与百分比、优先级、冷却窗口）以及全局资源预算（池总核时与内存上限、每轮伸缩动作总逻辑时间预算毫秒、每工作负载并发动作上限、冻结窗口）。指标采样流按可注入逻辑时钟给出连续采样值。控制面须在指标驱动下计算目标副本数，在全局资源预算与冷却窗口约束下并行下发伸缩动作，并在进程被强制终止后保证账目与决策可恢复。

任务环境与准备：
Windows 10/11 或 Windows Server，安装 Python 3.11 及以上并确保 python 命令可用。
安装依赖：pip install numpy（版本 1.26 及以上），SQLite 使用 Python 标准库 sqlite3，无需额外安装数据库服务。
在工作区根目录建立 samples 目录，放入题目所需的固定本地 JSON 样本（工作负载、指标源、伸缩规则、资源预算、指标采样流与规则补丁清单），所有样本由本地确定性生成，不访问网络。
确认运行用户对工作区目录与 SQLite 文件所在目录具有读写权限，用于对象落盘、快照替换与临时文件重命名。
准备进程强制终止验证方式（如通过任务管理器结束或发送终止信号），用于恢复一致性验证，不依赖任何容器环境。

业务要求：
1. 实现工作负载、指标源、伸缩规则与资源预算四类对象的解析校验：名称唯一、最小副本数不大于最大副本数、每副本毫核与内存为正整数、指标聚合方式与分位数参数合法、规则引用的工作负载与指标源存在、冷却窗口与冻结窗口为合法正区间、优先级唯一；非法引用或非法数值必须返回明确业务错误码且不写入任何持久化状态。
2. 实现策略对象的依赖图与增量规则补丁：以补丁形式提交对象的新增、修改、删除，计算受影响工作负载闭包，精确标记哪些目标副本数缓存、冷却窗口计时与预算预扣必须失效重算、哪些可安全复用；未受影响工作负载在补丁后其伸缩决策与账目必须逐字段保持不变，失效决策须输出触发来源与被影响对象链。
3. 实现指标采样流的确定性聚合：按采样窗口与聚合方式计算每指标源的窗口聚合值，分位数按固定排序与插值规则计算，浮点与定点两条通路必须逐位可复现且换算标度与舍入方向被记录；窗口边界只依赖注入逻辑时钟毫秒值，不得读取系统墙钟，逻辑时钟回拨超过容差时返回业务错误码并保持聚合状态不变。
4. 实现指标驱动的目标副本数计算：依据窗口聚合值、目标值、告警阈值与规则步长和百分比计算目标副本数，多规则命中同一工作负载时按优先级与方向裁决并给出被否决规则及原因；向上取整与夹在最小最大副本数之间的次序固定，相同采样流在任意运行次数下得到逐位一致的目标副本数。
5. 实现全局资源预算下的伸缩动作并行调度：在池总核时与内存上限、每轮总逻辑时间预算与每工作负载并发动作上限四重约束下决定动作启动顺序，预算不足时必须放弃剩余动作并记录放弃原因，区分预算内未启动、启动后失败与主动放弃三类结局，已启动动作须执行至确定结局而不得被当作已超时。
6. 实现冷却窗口、冻结窗口与连续失败退避的演化：动作成功后进入该规则冷却窗口，失败按连续失败次数计算确定性指数退避并受上限与抖动规则约束，冻结窗口内不得下发任何扩容动作；再决策时刻必须与每轮预算和并发上限共同裁决，预算不足以覆盖全部到期动作时按优先级与稳定次序截断并记录被截断对象。
7. 实现持久化状态与强制终止后的恢复一致性：把已提交采样水位、各工作负载副本数与预算账目、在途动作、冷却与退避截止时刻以事务原子写入 SQLite，每轮提交识别版本变化并整体替换决策快照指针；进程在动作下发或账目提交中途被强制终止后，恢复路径依据持久化状态识别已提交与半提交动作，只重试未确认动作且不得重复扣减或超卖池核时与内存。
8. 实现多进程并发一致性、幂等提交与可重复命令行演示：多个控制面实例并行处理不同工作负载时，通过 SQLite 事务与文件锁保证同一工作负载同一轮次同一规则版本只被裁决并下发一次、池预算不被并发超卖，重复提交相同动作结果幂等；提供 load、apply、decide、dispatch、resume、status、verify 子命令，status 以稳定排序 JSON 输出各工作负载副本数、预算余额、冷却与退避截止时刻，verify 校验持久化账目与决策快照一致。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用固定本地样本验证指标聚合、预算约束下的伸缩裁决、增量补丁失效与强制终止恢复，两次运行输出一致。
