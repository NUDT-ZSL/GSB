数字展馆穹幕影院的投影系统集成工程师需要为半球穹顶布置多台投影机，使画面在穹顶经纬网格上无缝覆盖；内容播放操作员在切换影片或更换投影机后，必须依据穹顶几何与投影机参数重新生成逐像素几何校正查找表与融合遮罩，并在现场做微调。当前工作区为空，需要从零交付一套本地可复现的校正融合内核与可交互操作界面：工程师导入穹顶几何、各投影机位姿与视场、分辨率及镜头畸变、标定控制点与融合带参数，内核完成从投影机像素到穹顶表面的反向映射、控制点残差校正、重叠区检测与亮度权重优化，输出映射纹理与对齐误差、亮度一致性报告；操作员在界面中查看结果并微调融合带羽化参数。

任务环境与准备：
在 Linux（WSL Ubuntu）下准备 Python 3 运行环境，安装 NumPy 用于数值计算，安装 Tkinter 及系统提供的 Tk 运行库用于交互界面。
在空工作区创建项目，样本工程由固定种子生成器产出，不依赖真实投影设备、线上服务或外部数据集。
运行入口包括命令行校正融合与 Tkinter 交互界面两种方式，二者共享同一内核，校正数据以文件形式持久化保存供加载与回滚。

业务要求：
1. 实现固定种子的穹幕投影样本生成器：根据半球半径、中心、倾斜角，以及各投影机的位置、朝向、视场角、分辨率与径向畸变系数，生成结构一致的多机布局与带小量扰动的标定控制点，扰动幅度随控制点编号确定，同一随机种子必须产出完全相同的数据。
2. 实现投影机像素到穹顶经纬参数的反向映射：对每台投影机的每个像素，经镜头畸变反解与视锥射线求交得到穹顶表面点，超出投影机有效视锥或未击中穹顶的像素必须标记为无效；生成的逐像素校正查找表保存经纬坐标与有效性掩码，并与样本真值逐像素比对，有效像素的反向映射误差需满足容差。
3. 基于标定控制点求解薄板样条残差修正场，叠加到反向映射上，使投影画面与穹顶经纬网格对齐；对控制点数量少、近共线或残差分布不均的情形给出可识别的降级处理，不得因奇异线性系统输出发散坐标，须以控制点交叉验证误差说明修正质量。
4. 计算相邻投影机在穹顶表面的重叠区域，按重叠宽度与羽化曲线参数生成每台投影机的融合遮罩，并对重叠区亮度权重做归一化优化；重叠区域内各投影机权重之和需一致，羽化带内权重单调过渡，窄重叠带或三机交叠处不得出现亮度跳变。
5. 将几何查找表与融合遮罩合成为逐投影机的映射纹理，并渲染到穹顶经纬网格上得到融合预览，输出几何对齐误差统计与亮度一致性报告，标注超限像素与主要误差来源分类。
6. 当部分标定控制点或单台投影机参数变更时，仅重算受影响投影机的查找表与关联融合遮罩，增量结果须与全量重算逐像素一致；同时记录各投影机的版本号，加载或回滚快照时须识别版本变化，避免使用过期数据。
7. 提供 Tkinter 交互界面：操作员可载入样本工程或已保存快照，选择投影机查看其查找表与融合遮罩，调整融合带羽化参数后触发受影响投影机的重算，并查看对齐误差与亮度报告；参数调整与重算结果须与命令行路径保持一致。
8. 对异常输入做可诊断处理：控制点数量不足、控制点近共线、投影机视场与穹顶无交叠、畸变参数越界、分辨率与样本不一致等情形，须以业务错误码与说明返回，并保持已有校正数据不被破坏，界面与命令行均能展示错误信息。

验收：
依据固定种子样本验证反向映射误差与重叠区亮度均匀性，并核对增量重算与全量重算的查找表及遮罩逐像素一致。
