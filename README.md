当前是空白工作区，没有现存项目、代码或数据附件，需要从零构建一个面向客服通话质检场景的本地情感分档引擎，交付算法实现与可复现实验环境。业务对象是本地确定性合成的多说话人对话音频：用固定种子生成若干说话人的基频、共振峰与能量包络，按给定对话时间轴与增益叠加为 16kHz 单声道 PCM，并附逐帧真值文件（帧长 20ms，字段含 frame_index、speaker_id、valence、arousal、is_speech）与对话清单（JSONL，字段含 dialog_id、sample_rate、duration_ms、chunk_ms、tier_schema）。引擎需支持两种互相约束的使用方式：离线批处理对整段对话产出逐帧情感档位与段级汇总；在线按到达分块（chunk_ms）做流式增量更新，并在任意检查点给出与离线批处理一致的当前视图。核心业务问题是同一份音频在流式增量聚合与离线全量聚合两条路径上必须给出相同分档，而分档窗口跨越分块边界时统计口径极易漂移。所有输入与真值由本地脚本按固定种子生成，不依赖真实数据集或外部服务。

任务环境与准备：
在 Windows 上安装 Python 3.11 与 NumPy（pip install numpy），无需其他外部服务、GPU 或数据集。
在工作区创建项目目录结构，自行编写本地确定性合成脚本，按固定种子生成 16kHz PCM、逐帧真值与对话清单样本。
为命令行示例约定输入样本路径与配置文件的默认位置，并运行一次冒烟检查确认依赖与样本生成可用。

业务要求：
1. 实现确定性的帧级情感打分与分档层：按帧长与帧移切分 PCM，帧边界以样本索引精确确定，由能量、过零率与基频候选派生逐帧 valence 与 arousal 估计，并按 tier_schema 把每帧映射到情感档位；同一 dialog_id、同一配置与固定种子下必须逐字节产出相同逐帧分数与档位，禁止依赖系统时间、字典遍历顺序或未声明的浮点累加顺序。
2. 实现按 chunk_ms 分块的流式增量提交与离线全量聚合两条路径：两条路径必须共用同一档位映射、同一滑窗统计口径与同一平局规则，流式路径在任意检查点给出的当前档位统计与段级汇总，须与离线路径在该检查点已到达帧上的结果在声明精度内一致；检测到偏差返回 E_STREAM_BATCH_MISMATCH 并输出首个偏差帧与两条路径的统计值。
3. 实现跨越分块边界的滑窗统计口径统一：滑窗长度、边界填充与不足窗口的记法必须显式声明且在两条路径上完全相同，禁止流式侧用近似累计替代离线全量重算；须能对任意单帧反算其所在窗口的统计值与档位，反算结果与批量结果不一致时返回 E_WINDOW_RECOUNT。
4. 实现分档门限与档位切换的数值稳定性保护：对档位门限提供严格比较与容差带比较两种策略及次正规数保护，保证恰好落在门限附近的帧在流式与离线两条路径、以及重复运行下判定不被舍入翻转；须记录门限附近的滞留帧与切换次数，门限策略非法返回 E_CONFIG_INVALID 并指明字段。
5. 实现逐帧说话人归属与段级汇总的强耦合约束：逐帧说话人标签须落在对话声明的说话人集合内，段级汇总按说话人连续段切分且段边界与标签切换点严格对齐，段级 valence 与 arousal 汇总须可由逐帧明细与段内帧权重独立重算一致；标签越界返回 E_SPEAKER_LABEL_INVALID，段边界与标签切换点不一致返回 E_SEGMENT_BOUNDARY 并指出首个偏离帧。
6. 实现按真实处理耗时的延迟观测与超前到达保护：流式路径须以本地上报分块的处理循环实际计时作为观测记录每块从头帧到可查询的耗时，并按帧数、窗口长度与说话人数给出估算记录；分块时间戳倒挂、分块序号缺号或重复、分块跨越对话时长边界分别返回 E_CHUNK_ORDER、E_CHUNK_GAP、E_CHUNK_RANGE，且不得用固定延时冒充超时判定。
7. 实现逐帧分数与分档产物的内容寻址缓存及配置变更的失效联动：缓存键须纳入 PCM 内容哈希、帧长与帧移、滑窗参数版本、门限策略与档位映射版本；键相同必须复用、键不同必须重算，调整滑窗或门限时必须重算受影响帧与段集合而不得整段重建；须输出重算帧区间与复用帧区间，并保证复用与重算无交集且并集覆盖全部帧。
8. 实现快照版本化整体替换与跨模块一致性自检：逐帧结果、段级汇总与窗口统计各携带单调递增版本号与内容校验和，检测到版本号或校验和变化时必须整体替换旧快照而非增量修补，旧版本不得覆盖新版本且回退尝试返回 E_SNAPSHOT_ROLLBACK，损坏或校验和不符返回 E_SNAPSHOT_CORRUPT；自检须对账两条路径的帧集合、段边界与档位切换序列，并提供命令行示例输出含逐帧档位、段级汇总、延迟观测、偏差明细、业务码与降级标记的 JSON 报告。
