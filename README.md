当前是空白工作区，没有现存项目、代码或数据附件。需要从零构建一个面向表格与流式特征数据的特征漂移监控本地专业应用与可重复演示，核心业务问题集中在三处高度耦合的约束上：其一是监控配置以 v1、v2、v3 三种并存的书写格式到达，需要完成互操作读取、双向迁移与整体替换；其二是参考窗口滑动后，已移出窗口批次的统计贡献必须被精确移除，同时要能区分窗口内统计量与全量累计统计量；其三是每份告警都必须可追溯回当时所用的窗口范围、配置版本与中间统计快照，配置或参考窗口变化后旧告警必须被判定为过期而拒绝继续使用。业务对象是本地确定性生成的特征批次流：以固定随机种子按批次生成若干数值列与类别列的样本，可在指定批次注入分布漂移（均值平移、方差放大、类别占比变化、缺失率上升）；监控配置以三种格式并存——v1 为无字段名的竖线分列行式，v2 为按键值对的行式，v3 为带检验方式链与分位数口径的结构化格式。整个链路为：配置读取与互操作迁移→分批复核与统计量累积→逐特征漂移检验→告警工件生成与追溯，不允许依赖任何外部账号、在线服务或缺失数据；要求的清单、统计量与告警均来自本地确定性样本与固定种子。

任务环境与准备：
确认操作系统为 Windows，Python 3.10 及以上可用，并已安装 NumPy（建议 1.24 及以上），无需其他第三方依赖与网络访问。
在空白工作区新建项目目录，仅准备本地确定性特征批次流样本（固定随机种子、含可注入漂移的批次）与三份不同格式的监控配置样本，不引入任何真实业务数据或外部数据源。
确认本地持久化目录可写，用于存放统计量缓存、告警工件与版本快照，并预留可通过输入参数触发分布漂移、非法配置与资源超限的演示配置。
确认可用命令行入口运行演示并能输出 JSON 报告，演示只使用本地样本和本地计算，不依赖任何在线服务、账号或付费资源。

业务要求：
1. 实现 v1、v2、v3 三种监控配置的读取器，按格式头或字段集分派解析路径；未知版本返回 E_VERSION_UNSUPPORTED，格式头截断、竖线字段数不符、键名缺失或阈值不可解析返回 E_FORMAT_CORRUPT 并指出行号与字段名；读取器须记录每份配置的来源格式版本，且同一配置在多格式视图下解析出的受监控特征集合与阈值必须完全相同。
2. 实现三套配置格式的双向迁移器：v1 升级到 v2 或 v3 时补全检验方式、分位数口径与最小样本数并逐项记录补全来源；v3 降级到 v1 时对 v1 无法表达的检验方式链与分位数口径按显式声明的丢弃或冻结规则处理并输出丢弃明细；同一配置经完整往返后，逐特征阈值、检验方式与参考窗口长度须逐项一致，不一致返回 E_ROUNDTRIP_MISMATCH 并指出首个差异特征。
3. 实现确定性的分批复核与统计量累积层：按列类型（数值、类别）累积均值、方差、分位数与类别占比，类别列与数值列口径显式区分；同一输入批次、同一配置与固定随机种子下必须逐字节产出相同统计量与批次指纹，禁止依赖字典遍历顺序或系统状态；列类型不支持、批次内样本数为零、特征值含非法标记分别返回结构化业务码并归因到批次号与特征名。
4. 实现逐特征漂移检验：数值列按配置的检验方式（均值漂移或分位数距离）计算漂移量与判定阈值，类别列按占比距离计算；同漂移量时按特征名升序打破平局，输出每特征漂移量、判定结果与严重度等级，并记录所用窗口起止批次与检验方式；检验方式未知或阈值越界分别返回 E_CONFIG_INVALID 并指明字段。
5. 实现参考窗口滑动与窗口外贡献移除：滑窗后移出窗口的批次贡献必须从窗口内统计量中精确扣除而非增量近似，须显式区分窗口内统计量与全量累计统计量，并在报告中记录窗口起止批次与移除量；窗口长度非正或滑动步长大于窗口长度分别返回 E_WINDOW_INVALID，且窗口内统计量须可由窗口内批次明细独立重算一致。
6. 实现监控产物以内容寻址方式缓存：每特征的统计量与检验结果附带内容哈希落盘，缓存键须纳入参考窗口内样本内容哈希、检验方式与阈值、统计口径版本、特征列定义摘要与上游产物哈希；键相同必须复用快照、键不同必须重算，且须提供入口按给定缓存键重放出相同统计量与相同判定；键组成不可还原时返回 E_CACHE_KEY_INVALID。
7. 实现增量更新的依赖失效传播：参考窗口滑动、单特征统计口径调整、某特征被禁用或启用、某列被重定义为另一类型时，计算受影响特征与受影响批次集合，复用未受影响上游产物，仅重算受影响后缀；须输出本次重算集合与复用集合，并保证局部修改后的结果与从零全量重算逐字节一致；两集合出现交集返回 E_INCONSISTENT 并指出类别。
8. 实现告警工件的版本化整体替换、过期告警拒绝、资源上限与本地可交互应用：告警工件与配置快照各携带单调递增版本号与内容校验和，检测到版本号或校验和变化时必须整体替换旧工件而非增量修补，旧版本不得覆盖新版本且回退尝试返回 E_SNAPSHOT_ROLLBACK；对任一旧告警可按记录查询当时所用缓存键、窗口范围与配置版本并重放出相同告警，所用依赖版本已变化而告警仍来自旧键时返回 E_ALERT_STALE；为单批样本数、缓存条目总量与同时驻留统计量内存估算设可配置上限，超限返回 E_RESOURCE_LIMIT 或降级并标记降级类别；应用展示参考窗口范围、逐特征漂移量与严重度、命中或重算状态、失效传播覆盖范围、告警列表与最近业务错误码，并允许触发一次演示——注入分布漂移后查看告警，再滑动一次参考窗口观察失效。
