在空白工作区从零实现一个本地列式聚合与窗口计算引擎及结果验证工具，用于在确定性样本上复现分组聚合与滑动窗口计算中的数值精度问题与误差传播。本地 JSON 样本给出：列式批次文件（每批含列名、按列存储的整数/浮点数组、批次序号与行数）、查询描述（分组键、聚合表达式如求和、均值、方差、计数、窗口函数如滑动求和与滑动均值、窗口行长与步长）、以及精度配置（累加类型可选 float64 或定点整数、定点标度、相对容差、逻辑时钟步进）。引擎需按批次流式执行分组聚合与滑动窗口计算，维护每个分组与每个窗口的中间状态，在可注入逻辑时钟下推进批次并允许中断恢复。

任务环境与准备：
Windows 10 或更高版本，安装 Python 3.11 及以上并确保 python 与 pip 可在命令行直接调用。
安装依赖：pip install numpy；SQLite 使用 Python 标准库 sqlite3，无需额外安装。
在空白工作区准备工作目录，把本地列式批次 JSON 样本、查询描述文件与精度配置放置于工作目录下的固定相对路径，样本内容确定性生成且不依赖网络。
确认可在 PowerShell 中执行项目提供的命令行入口，并预先清理工作目录下由历史运行产生的 SQLite 文件与输出目录以保证首次运行一致。

业务要求：
1. 实现列式批次与查询描述的解析校验：校验列名唯一、各列数组长度与批次行数一致、批次序号严格递增、分组键与聚合表达式引用的列存在且类型可比、窗口行长与步长为正整数且步长不大于行长、定点标度合法；非法输入必须返回明确业务错误码（如 E_BAD_BATCH、E_BAD_QUERY）且不写入任何持久化状态。
2. 实现定点与浮点双累加通路：按精度配置把数值列换算为受控定点整数或保持 float64，记录每项换算的标度与舍入方向，并保证两种通路对同一输入都能产生可复现结果；换算前的原始浮点值必须保留用于误差溯源，同一输入多次换算逐位一致。
3. 实现分组聚合的流式状态演进：按批次逐块更新每个分组的分组键、计数、求和、平方和与均值，浮点通路聚合顺序固定，定点通路按整数精确累加；状态只能依据已提交批次的完整结果推进，推进前校验批次内容摘要，摘要不匹配时拒绝推进并保持状态不变。
4. 实现滑动窗口计算的窗口状态与边界处理：对每个分组维护按行序切分的滑动窗口缓冲，窗口行长与步长决定窗口归属，跨批次的部分窗口必须保留中间缓冲并在后续批次补齐；窗口结果须与对同一序列执行全量重算得到的唯一真值逐窗口比对，边界不足行长时按明确规则输出或标记。
5. 实现数值误差传播检测与精度敏感标记：对每个聚合与窗口结果记录定点换算与浮点累计的误差上界，当两个分组或两个窗口的结果差小于给定容差且排序或结论依赖该差值时标记为精度敏感，并输出误差来源链，包含输入列、批次序号与中间累计值；误差上界计算方式必须与所用累加通路一致。
6. 实现强制终止后的恢复与并发幂等提交：把算子状态、批次水位、内容摘要、每批输出摘要与误差谱以事务原子写入 SQLite；进程被强制终止后恢复路径识别已提交批次与半提交算子，只重放缺失批次且不得重复累加持续型缓冲；允许多个执行实例并行推进不同批次，文件锁与事务保证同一批次同一版本只提交一次，读取方只能看到完整已提交状态。
7. 实现执行计划整体替换与版本变化识别：计划更新时以版本号与内容摘要整体替换当前计划快照，判定完整替换、增量追加或版本回退；替换后受影响算子的既有状态按依赖裁决复用或重建，未受影响算子状态不得被重算，版本回退必须被拒绝并返回业务错误码，替换审计记录须持久化。
8. 实现异常链路隔离与可重复命令行验证工具：某批摘要不匹配、类型不匹配、定点溢出、状态版本落后时该批与受影响算子进入明确失败态并返回对应业务错误码，其他不受影响算子的已提交状态不得被回滚或污染；提供 load、execute、resume、status、verify 子命令，status 以稳定排序 JSON 输出每算子水位、累计行数、当前累加通路与失败态，verify 校验持久化状态与输出一致性，固定样本两次运行输出逐位一致。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
