在空白工作区构建一个面向本地确定性样本的卷积与插值算子编辑器与操作应用，服务于多层特征图处理管线的反复调参与结果复现。输入为一份算子图描述 JSON（节点为二维卷积、双线性插值、最近邻插值三类算子，边表示张量流转，每个节点含参数：卷积的核尺寸、步长、填充、通道数，插值的输出尺寸或缩放因子与对齐模式）与一份按固定种子生成的输入张量描述（形状、数值分布、特殊值位置）。应用需对算子图做拓扑调度、逐节点执行确定性卷积与插值、支持用户以交互命令编辑节点参数或替换子图，并在编辑后只重算受影响节点。核心问题在于算子图状态演进与恢复一致性：每次编辑产生新的图版本与节点产物版本，进程可能在任意阶段中断，恢复后最终张量与逐节点中间结果必须与不中断执行完全一致。

任务环境与准备：
安装 Python 3.10 及以上版本，并安装与版本匹配的 NumPy，仅使用标准库与 NumPy，不引入其他第三方依赖。
在空工作区创建项目目录，准备由固定种子生成算子图描述 JSON、输入张量描述 JSON、图编辑序列脚本与中断点注入配置各一份。
确认可运行本地命令行入口执行一次完整算子图执行、一次含编辑的增量执行与一次中断恢复执行，并生成对应 JSON 报告。
准备可处理的退出信号触发方式与强制终止复现步骤，仅使用本地进程与文件系统，不依赖网络或外部服务。

业务要求：
1. 实现算子图加载与拓扑校验层：解析算子图 JSON，校验节点 ID 唯一、边两端存在、无环且每个输入张量只有一个生产者；对卷积核尺寸、步长、填充、通道数与插值缩放因子的取值合法性做检查，非法时输出 E_GRAPH_INVALID 或 E_PARAM_OUT_OF_RANGE 业务码并纳入失败清单，合法图按拓扑序输出可执行节点序列。
2. 实现确定性二维卷积算子：对每个卷积节点按核尺寸、步长与填充做互相关计算，填充值取自配置，边界不足处按填充规则补齐；通道维逐通道累加，运算顺序固定为输出行优先、核行优先、核列优先，同分或数值零值不做额外特殊处理；同一输入与参数在任意运行中必须得到逐元素相同的 float64 结果，并输出输出形状与每节点张量摘要。
3. 实现双线性与最近邻插值算子：按输出尺寸或缩放因子计算采样坐标，双线性插值采用固定对齐模式并做边界裁剪，最近邻插值按固定取整规则选择源像素；对齐模式与取整规则的组合必须显式记录在节点产物元数据中，关闭插值节点或改变对齐模式必须使该节点及其下游产物失效，不得沿用旧对齐模式的缓存结果。
4. 实现基于内容指纹的节点级失效传播：为每个节点产物计算由节点参数指纹、输入张量内容指纹与算子实现版本号派生的缓存键；编辑节点参数或替换子图后，仅将受影响节点及其全部下游标记失效并纳入重算集合，未失效节点必须直接复用产物且不得重新执行；重算与复用节点清单须在报告中逐节点列出。
5. 实现图版本与阶段快照的恢复一致性：每次成功编辑将拓扑调度、逐节点执行、产物汇总划分为阶段，各阶段以临时文件加原子替换方式持久化快照，快照含全局图版本号、配置哈希、已完成节点列表、部分张量摘要与产物版本；恢复时以快照版本号与当前图内容指纹判断命中，配置或图指纹不符输出 E_CONFIG_MISMATCH，一致时从游标继续且最终逐节点中间结果与不中断执行逐元素一致。
6. 实现编辑序列下增量与全量的等价性：从任意初始状态施加包含节点参数修改、子图替换、节点删除与新增的编辑序列，每次编辑后增量运行得到的最终张量、逐节点中间结果摘要与失效清单，必须与从空白工作区按相同最终图与输入全量运行的结果完全一致；等价性须在至少包含插值对齐模式变更的序列上成立。
7. 实现并发执行与串行结果一致性：使用线程池并发执行拓扑序中彼此无依赖的节点，最大并发数取自配置，每个节点任务携带由拓扑序位次与节点 ID 派生的稳定排序键；无论线程调度顺序如何，最终逐节点产物、失败清单顺序与重算复用清单顺序必须与单线程按拓扑序执行完全一致；收到可处理的退出信号时完成当前节点产物与快照原子替换后以整数退出码 0 退出，强制终止后仅依据已完整替换的快照恢复。
8. 实现异常注入隔离与状态演进报告：以独立注入配置指定非有限输入元素、形状不一致的边、越界填充、非法缩放因子与中断点位置，注入项编号写入报告以证明命中；单节点在参数构造或计算阶段抛异常时记录节点 ID、阶段名、业务码与异常类型到失败清单并继续处理其余可执行节点，报告含图版本号、各节点重算或复用状态、失效传播链、张量摘要与失败清单，以临时文件加原子替换写盘。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地样本执行编辑序列与中断恢复，验证逐节点产物与全量重跑逐元素一致，并核对失效清单与业务码。
