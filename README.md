当前为空白工作区，没有现存项目、代码或数据附件，需要从零构建一个面向会议同传后处理的本地可交互专业应用与可重复演示。业务对象是本地确定性合成的会议混合音频：用固定种子生成若干说话人的基频、共振峰与能量包络，各生成一段 16kHz 单声道语音活动段，按给定时间轴与增益叠加为混合信号，并保留逐说话人逐帧真值（帧长 20ms，字段含 frame_index、speaker_id、is_speech、sample_start、sample_end）作为分段与身份指派的观测口径。分段与分离配置以三种并存的书写形式到达：v1 为竖线分列行式（时间轴参数｜说话人数上限｜门限倍数），v2 为带字段名行式（增加帧长、帧移、归一化口径与变体名），v3 为结构化格式（增加逐说话人增益、分离掩码模式与精度档声明）。核心业务问题有三处相互牵制：三种配置在分段、掩码与重识别阈值上的语义必须逐项对齐；配置版本升级或降级后已产出的分段与分离结果不得被静默沿用；分段结果以毫秒对外交付而内部必须以样本索引为唯一时间基准，任何换算偏差都会造成段与帧错位。

任务环境与准备：
安装 Python 3.10 及以上，并安装 NumPy（如 1.26 系列），无其他第三方依赖。
在空白工作区创建项目目录，本地通过固定种子与显式参数生成确定性合成样本、逐帧真值清单、注册片段清单与三版本配置样例，不依赖网络或外部数据。
确保本地持久化目录可写用于快照与演示中的替换重跑；不需要容器或任何外部服务。

业务要求：
1. 实现本地确定性会议音频合成与帧级特征层：按固定种子生成说话人基频、共振峰与能量包络，叠加为 16kHz 单声道 PCM，并按配置帧长与帧移切分计算短时能量与过零率；同一会话、同一种子与同一配置下必须逐字节产出相同 PCM 与特征序列，帧边界以样本索引精确确定且帧数须与真值帧数一致。
2. 实现确定性的语音分段与说话人分离掩码：按双门限滞回产出候选段，再按说话人数上限与帧级特征生成分离掩码并重建各说话人时间轴段；同一输入与同一配置下掩码与段列表逐字节一致，同分时按说话人编号升序、再按段起始样本索引升序裁决，段间不得重叠且须落在音频时长内。
3. 实现毫秒交付与帧索引之间的唯一时间基准层：所有段的起止内部以样本索引与帧索引表示，对外换算为毫秒时采用显式声明的取整规则，且任一段的毫秒起止反算回帧索引必须唯一且可核对；当毫秒起止与帧索引无法互相对应或段跨度为零帧时返回 E_TIME_BASE_MISMATCH 并指明段与帧区间。
4. 实现 v1、v2、v3 三种分段与分离配置的读取器，按版本头或字段集分派解析路径；未知版本返回 E_VERSION_UNSUPPORTED，字段数不符、字段缺失或数值不可解析返回 E_FORMAT_CORRUPT，并在错误中给出配置行号与字段名。
5. 实现三套配置格式的双向迁移器：v1 升级到 v2 或 v3 时补全帧长、归一化口径与精度档并逐项记录补全来源，v3 降级到 v1 时对无法表达的逐说话人增益与掩码模式按显式丢弃或展平规则处理并输出丢弃明细；降级中遇到无法保真字段须返回 E_SEMANTIC_LOSS 并附字段清单。
6. 实现配置快照的版本化与整体替换：分段参数、分离掩码模式与重识别阈值快照各携带单调递增版本号与内容校验和，检测到版本号或校验和变化时必须整体替换而非增量修补；旧版本不得覆盖新版本，回退尝试返回 E_SNAPSHOT_ROLLBACK，损坏快照返回 E_SNAPSHOT_CORRUPT 并指明项与版本。
7. 实现基于注册样本的说话人重识别与逐段身份指派，并输出逐段身份与置信区间：由本地合成注册片段估计每个说话人嵌入统计量，对分离段确定性相似度打分并指派，同分按说话人编号升序打破平局；身份标签须来自会话声明的说话人集合，越界返回 E_SPEAKER_UNKNOWN，且逐段身份须与逐帧真值说话人编号可核对。
8. 提供本地可交互应用与可重复演示，并实现跨模块一致性自检：展示会话波形与真值段、分离段与逐段身份、当前配置版本与三视图、迁移补全与丢弃明细、毫秒与帧索引对照、快照版本与最近业务错误码；自检校验分段段集合与掩码帧集合互相覆盖、身份指派与分离段一一对应、毫秒起止与帧索引可互相反算一致，不一致返回 E_INCONSISTENT。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
