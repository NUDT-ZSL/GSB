在 Windows 上开发一个适用于医学可视化的体数据光线投射渲染组件。输入为本地合成的三维标量体数据（例如 128×128×128 的 uint16 体素，模拟 CT 值分布），支持导入预生成的 .npy 样本，不需要外部医学影像数据。需要实现基于光线投射的体渲染管线，输出 RGBA 图像，并提供与外部 UI 集成的离屏渲染接口。核心难点在于数值精度与误差传播的控制：传输函数映射的非线性、三线性插值误差、积分步长选择、半透明合成中的浮点累加误差都会影响最终图像质量与诊断可靠性。组件需提供可量化的误差评估手段，并在给定输入参数下保证渲染结果确定且可重复。要求包含一个完整示例程序，演示从体数据加载、传输函数配置、渲染到误差报告的全流程。

任务环境与准备：
安装 Python 3.10 或以上版本，并创建独立虚拟环境。
安装 NumPy、PyOpenGL、PyOpenGL_accelerate、Pillow 等依赖，版本需支持 Windows 上的离屏 FBO 渲染。
准备本地合成体数据生成脚本（用 NumPy 生成 128×128×128 uint16 的球体与柱状结构），保存为 .npy 样本文件，无需外部医学影像数据。
确认当前 Windows 机器具备支持 OpenGL 3.3 或以上版本的显卡驱动，以便离屏 FBO 创建与回读。
示例程序须在无可见窗口环境下运行，并输出 PNG 与 JSON 报告到工作区目录。

业务要求：
1. 实现体数据光线投射核心管线：对每条光线按固定步长采样，使用三线性插值获取体素值，经传输函数映射为 RGBA，再按从前到后的合成公式累积颜色与不透明度。输出线性空间的 float32 RGBA 缓冲，并提供 sRGB 转换选项。步长、采样起点与终点须根据体数据包围盒和相机参数精确计算，支持可选的 early-ray termination 阈值，且该阈值同时参与不透明度累积终止判断。
2. 设计传输函数组件：支持分段线性映射与不透明度校正曲线，输入体素值范围可配置。传输函数须可序列化为确定性 JSON 描述，并在渲染前完成校验（控制点单调递增、不透明度位于 [0,1]）。组件提供将标量值映射为 RGBA 的接口，渲染循环不得重复解析 JSON，须使用预构建查表。
3. 控制数值误差传播：实现基于解析导数的三线性插值误差上界估计，并在每条光线累积时记录最大局部误差与累积误差。误差报告须包含每像素误差估计的最大值、均值与 95 分位，且与实际采样配置一致。当误差超过用户阈值时输出业务码 E_ERROR_BOUND 并给出超限像素比例。
4. 实现自适应步长策略以权衡性能与精度：在传输函数梯度高的区域自动减半步长，低梯度区域使用基础步长；提供开关与最大细分级别。同一场景下，自适应模式与固定步长模式的误差报告须可比较，且自适应模式误差指标不高于同基础步长的固定模式。步长调整只改变采样密度，不得改变光线几何或传输函数映射。
5. 提供确定性渲染保证：给定体数据、传输函数、相机参数与步长配置，两次运行须输出逐字节相同的 float32 缓冲。使用固定随机种子（若涉及抖动采样），避免多线程非确定性归约，浮点累加顺序固定。提供哈希校验接口，输出 RGBA 缓冲的 SHA-256 摘要用于集成验证。
6. 定义并实现离屏渲染上下文：用 PyOpenGL 创建不可见 FBO，将光线投射结果输出为纹理并回读像素。上下文初始化失败时返回业务码 E_GL_CONTEXT，回读缓冲区大小不符时返回 E_BUFFER_SIZE。离屏渲染须支持指定分辨率（如 512×512）且不依赖可见窗口系统，能与外部 UI 通过共享纹理或回读数组集成。
7. 实现异常链路与资源管理：对非法体数据维度（非三维、含 NaN）、传输函数越界、步长小于体素间距的 0.1 倍、光线方向为零向量等输入，分别返回 E_VOLUME_SHAPE、E_TF_RANGE、E_STEP_TOO_SMALL、E_RAY_DIR，并以结构化 JSON 形式上报。GPU 纹理、FBO 与着色器须在上下文销毁时释放，多次创建-销毁循环不得泄漏显存，异常路径同样执行释放。
8. 提供完整示例与误差验证：示例程序加载本地合成的 128×128×128 uint16 体数据（含球体与柱状结构），配置传输函数，分别以固定步长与自适应步长渲染 256×256 图像，输出误差报告与 RGBA 哈希，并将结果保存为 PNG 供人工复核。示例须在无可见窗口环境下可重复运行，两次运行的哈希与误差统计完全一致。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地合成的 128³ 体数据，验证两次渲染缓冲哈希一致、误差报告符合采样配置，并覆盖非法输入的业务错误码。
