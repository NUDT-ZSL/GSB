当前是空白工作区，没有现存项目、代码或数据附件，需要从零构建一个面向通话场景静音段能量事件归因的本地领域数据编辑与操作应用。业务对象是本地用固定种子确定性合成的 16kHz 单声道 PCM 通话录音：每条通话由种子生成噪声底曲线（含缓慢漂移与若干突变台阶）、若干说话人语音活动段与静音段，按给定时间轴与增益拼接，并附帧级观测文件（帧长 20ms，字段含 frame_index、sample_start、sample_end、noise_floor_true、is_speech、energy、zero_crossing_rate）与通话清单（JSONL，字段含 call_id、duration_ms、seed、sample_rate、frame_ms、noise_profile_ref）。系统需把一次批处理建模为多阶段状态演进：帧级特征统计→噪声底拟合→静音段能量事件归因→归因画像聚合，各阶段可持久化并在强制终止后从已提交阶段恢复。后续用户可能修正某段真值标签、提升噪声底配置版本或替换部分 PCM 观测，系统须识别快照版本变化、整体替换旧快照，并保证归因结果与聚合统计可追溯、可重放、跨阶段可核对。

任务环境与准备：
确认 Windows 上安装 Python 3.10 及以上与 NumPy，并可在命令行执行 python 与 pip。
在空白工作区建立项目目录，准备本地确定性样本生成脚本：按通话清单种子生成 PCM、噪声底曲线、帧级观测文件与通话清单，不依赖任何外部音频或网络资源。
准备本地持久化目录用于阶段快照与追溯记录，确认可读写；准备进程终止手段（子进程强制结束）用于验证恢复逻辑，不依赖容器。
运行前检查采样率固定为 16000、帧长 20ms，样本与配置参数均随项目本地生成，供首次运行使用。

业务要求：
1. 实现确定性的帧级特征统计阶段：按 frame_ms 与帧移切分 PCM，帧边界以样本索引精确确定，计算短时能量与过零率并与帧级观测文件逐帧对齐，输出逐帧特征矩阵与帧数；同一 call_id、同一 seed 与同一配置下必须逐字节产出相同特征与帧数，且帧数与观测文件帧数严格一致，不一致返回 E_FRAME_MISMATCH 并指明 call_id 与帧号。
2. 实现噪声底拟合阶段：按可配置的估计窗口与滑窗步长对每帧能量做低分位估计，输出逐帧噪声底曲线与窗口覆盖记录，并在曲线上按突变阈值与最小持续帧数识别台阶，产出噪声底分段（含起止帧、段内估计值、段内离散度）；窗口样本数不足或步长为零分别返回 E_WINDOW_INVALID 与 E_STEP_INVALID 并归因到 call_id。
3. 实现静音段能量事件归因阶段：为每个静音段计算段内能量对噪声底估计的偏离量与波动幅度，归因到受控噪声源类别集合（平稳底噪、设备突变、串入人声残留），归因规则与阈值由配置显式声明；归因类别不在受控集合返回 E_LABEL_INVALID，且不得跨越语音活动帧污染静音段边界，越界返回 E_SEGMENT_SPLIT。
4. 实现归因画像聚合阶段：把相邻且同归因的静音段按最小间隔合并为事件，输出事件时间轴与通话级画像（各类别总时长、事件数、突变次数），事件须按时间升序、互不重叠且落在通话时长内，越界或重叠分别返回 E_EVENT_RANGE 与 E_EVENT_OVERLAP；画像统计须可由事件明细独立重算一致。
5. 实现帧级特征统计、噪声底拟合、静音段归因、画像聚合四个阶段的可持久化阶段快照，每阶段提交带单调递增版本号、已完成 call_id 集合与内容校验和；快照提交顺序与阶段状态必须在本地持久化存储中原子可见，该阶段全部通话完成前不得提交为已完成，部分完成的阶段不得参与下游读取。
6. 实现强制终止后的恢复逻辑：重启时读取最后一次已提交阶段快照，从该阶段继续推进，已提交通话的帧特征、噪声底与归因结果不得重算或重复计入；未提交的中间估计与归因状态必须丢弃并从阶段起点重建；恢复后的最终归因与画像须与不间断完整运行逐字节一致，恢复报告须列出已提交阶段与重建阶段。
7. 实现噪声底配置变更或真值标签修正后的定向依赖失效与快照整体替换：估计窗口、突变阈值、归因阈值或真值版本变化时，须判定受影响帧区间、静音段与通话集合，复用未受影响上游快照，仅重算受影响后缀；检测到版本号或校验和变化时必须整体替换旧快照而非增量修补，旧版本不得覆盖新版本且回退尝试返回 E_SNAPSHOT_ROLLBACK，损坏快照返回 E_SNAPSHOT_CORRUPT。
8. 实现归因结果的来源追溯与解释输出并实现跨阶段一致性自检：每个静音段事件须记录所用特征版本、噪声底估计版本、归因阈值版本与阶段快照版本，可按这些记录重放出相同类别与偏离量，追溯链缺失或重放不符返回 E_LINEAGE_BROKEN 并指出事件编号；自检校验各阶段 call_id 集合完全一致、复用集合与重算集合无交集且并集覆盖受影响集合、事件时间轴可由分段明细重算一致，不一致返回 E_INCONSISTENT。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地合成通话样本验证归因、强制终止后的阶段恢复、快照整体替换与来源追溯，输出含业务码的 JSON 报告。
