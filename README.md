品牌包装设计师在护肤品与食品打样阶段，需要依据包装刀版与瓶身曲面建立三维展示场景，在柔和棚拍光下核对标签、瓶盖与磨砂玻璃表面的渲染预览。逆光轮廓处会出现细于一个像素的纤维与喷砂颗粒，常规点采样会在缩略图与全尺寸预览之间产生闪烁与断裂，且纤维密度或不透明度调整后无法判断覆盖率变化来自哪根纤维。现有工作区为空，需交付一个可集成的 Python 领域组件与本地 Flask 演示服务，读入自带确定性生成器按固定种子产出的包装工程，完成逐像素次像素覆盖率计算与可追溯诊断。

任务环境与准备：
准备 Linux（WSL Ubuntu）的 Python 3 运行环境，并安装 NumPy 与 Flask 两个第三方包。
在空工作区创建项目目录，运行实现自带的确定性生成器产出品牌包装展示工程样本与解析覆盖参考数据。
本地启动 Flask 服务前确认 SQLite 数据库文件路径可写，首次运行自动建表。

业务要求：
1. 装载品牌包装展示工程，解析刀版轮廓、瓶身与瓶盖曲面参数化、标签贴图坐标及主光/补光/逆光参数，校验每根纤维与颗粒曲线的起点、切向与长度在包装轮廓坐标系内一致，输出工程摘要与不一致曲线清单
2. 将每根纤维与颗粒曲线按相机投影到屏幕空间，以解析线段与像素方格求交并按相交线段长度与曲线半径估算像素内覆盖面积，输出逐像素次像素覆盖率图
3. 按每根曲线的不透明度对覆盖率进行逐像素累加，输出每根纤维对像素的覆盖率贡献表及按标签、瓶盖、磨砂玻璃材质区域划分的覆盖率统计
4. 由全尺寸覆盖率图按面积平均下采样生成声明尺寸的缩略图，保持总覆盖量与全尺寸一致，并与缩略图尺寸下直接渲染结果比对，在覆盖率差异超过容差的像素输出可见度衰减与断裂标记
5. 在纤维密度、半径或不透明度局部调整后，仅重算受影响像素与曲线的覆盖率贡献，未受影响像素的覆盖率与缩略图结果保持逐像素不变，并输出重算范围与耗时记录
6. 对逆光轮廓处的覆盖连续性做核验，沿轮廓逐段检查相邻像素覆盖率是否低于连续阈值，输出轮廓断裂像素定位及导致断裂的纤维编号列表
7. 将已提交的覆盖率图、缩略图与逐纤维贡献表持久化到本地 SQLite 数据库，进程中断后可从最近一次提交续算，提交前须识别版本变化避免混用旧覆盖率
8. 提供本地 Flask 服务，展示全尺寸覆盖率叠加图、逐纤维贡献查询、缩略图对比与断裂诊断视图，并允许通过参数接口触发局部重算并返回重算范围

验收：
以独立解析参考重算逐像素覆盖率并在容差内一致，缩略图面积平均总覆盖守恒，局部重算与全量重算结果一致且未受影响像素不变。
