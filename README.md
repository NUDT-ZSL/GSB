团队刚接手一项图像修复与风格迁移的数值精度诊断任务，工作目录尚未动工，需要从零构建一个本地可交互的专业应用与可重复演示，用于验证修复区域分块处理时的数值精度与误差传播。业务对象由固定种子脚本确定性生成：底图为固定尺寸 RGB 像素数组，修复掩码圈定若干封闭区域，风格迁移参数配置含风格强度、颜色迁移矩阵、边缘保留系数、迭代步数与精度档。修复链路建模为五阶段有向无环计算图：掩码区域解析、边界上下文采样、区域内容确定性补全、风格迁移着色、边界融合与全图输出。核心矛盾在于分块处理能加速首区域预览，但块边界处的采样权重、风格迁移归一化与融合羽化必须与整幅一次性口径完全一致，否则拼接结果与整幅参考结果出现可观察偏差，且误差会经定点量化与浮点累加逐级放大。全部样本由随题交付的固定种子脚本在 Linux（WSL Ubuntu）本地生成，不依赖真实图像、外部服务或网络。

任务环境与准备：
准备 Linux（WSL Ubuntu）环境，确保 Python 3.10 或更高版本可用。
执行 pip install numpy 安装 NumPy，SQLite 使用 Python 内置模块。
运行随题交付的固定种子脚本生成本地样本，生成底图、掩码、风格参数与区域配置到指定工作目录。

业务要求：
1. 实现确定性的五阶段修复计算图，按固定种子生成底图、修复掩码与风格参数，依次完成掩码区域解析、边界上下文采样、区域内容补全、风格迁移着色与边界融合输出，每个阶段的输入输出与中间特征需显式记录；同一底图、掩码与参数下必须逐字节产出相同的中间特征与最终图像，禁止使用系统时间或非种子随机源。
2. 实现按区域分块处理与整幅一次处理的双路径对照，分块路径中每个区域的边界采样权重、风格迁移归一化统计量与融合羽化权重必须与整幅路径同源，逐块拼接结果与整幅结果在 float64 下逐像素一致；检测到差异时返回 E_BLOCK_MISMATCH 并输出首个偏差像素位置、所属区域与偏差量级。
3. 实现可切换的精度档执行层，float64、float32 与定点缩放整数三档共用同一算子语义，定点档的缩放因子与舍入模式由风格参数配置显式给出；切换精度档只能引入数值差异，不得改变区域集合、处理顺序或候选判定，且同一精度档下分块与整幅路径的差异必须可复现。
4. 实现逐级误差传播计算与主导来源归因，以同一输入上 float64 整幅路径为参考真值，输出边界采样、分块补全、风格迁移着色、定点量化与融合羽化各级的绝对偏差、相对偏差与误差放大比，并定位主导误差来源级别；误差区间超出声明容差时返回 E_TOLERANCE_EXCEEDED 并附级联偏差明细。
5. 实现边界残差与风格强度门限的数值稳定性保护，对分块边界残差与风格强度设定可配置门限，提供严格比较与容差带比较两种策略及次正规数保护，保证恰好落在门限附近的像素在重复运行与多精度档下判定不被舍入翻转；门限策略或容差非法时返回 E_THRESHOLD_INVALID。
6. 实现基于内容寻址的区域级缓存与依赖失效传播，每个区域在每个节点的产物以内容哈希落盘，缓存键纳入底图内容哈希、区域掩码摘要、边界采样半径、风格参数版本与上游产物哈希；当掩码区域编辑或风格参数修订时，仅重算受影响区域及下游节点，复用未受影响区域缓存，输出重算与复用清单并保证增量结果与全量重算一致。
7. 实现修复快照与配置的版本化整体替换及并发提交控制，掩码快照、风格参数快照与整图结果快照各携带单调递增版本号与内容校验和，检测到版本号或校验和变化时必须整体替换旧快照而非增量修补，旧版本不得覆盖新版本且回退尝试返回 E_SNAPSHOT_ROLLBACK；并发区域增量提交时后到者立即获得 E_STAGE_BUSY。
8. 实现强制终止后的恢复逻辑与本地可交互专业应用，在区域或阶段边界持久化已提交检查点，重启后从最近检查点继续，已提交区域不得重算；提供演示界面展示分块边界偏差谱、逐级误差谱、缓存命中与重算状态、快照版本及业务错误码，并以固定种子样本演示一次正常增量与一次回退场景。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
