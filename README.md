在一台没有历史代码的机器上，需要从零构建一个面向长对话记忆压缩与摘要的本地可集成领域组件与完整示例，核心业务问题是摘要记忆条目在多轮对话持续追加与修订时的增量失效，以及记忆条目三种并存的持久化格式在版本演进下的互操作。业务对象是本地确定性生成的多轮会话清单（JSONL，字段含 session_id、turn_no、speaker、text_tokens、token_len、timestamp_ms、revision），每个会话的文本由固定种子从受控词表拼装 token 序列；记忆条目以三种格式并存：v1 为竖线分列的行式（session_id|turn_range|summary_tokens|importance），v2 为带字段名的行式并引入条目序号、来源轮次集合与摘要置信区间，v3 为结构化嵌套描述并引入记忆链引用、合并来源与逐条修订号。系统需把一次记忆压缩建模为有向无环计算图：会话摄入与校验→轮次窗口切分→窗口摘要生成→记忆条目合并与链引用→重要性打分与记忆预算裁剪。

任务环境与准备：
安装 Python 3.11（Windows 64 位）并确保 python 与 pip 在 PATH 中。
执行 python -m pip install numpy==1.26.4 以安装唯一的第三方数值依赖。
创建本地工作目录，按背景字段说明生成小规模确定性多轮会话清单与三种格式的记忆条目样本；样本生成只依赖固定整数种子。
准备一个本地临时目录用于存放缓存产物、记忆条目快照与运行报告，路径通过命令行参数传入，不写入系统级共享位置。

业务要求：
1. 实现 v1、v2、v3 三种记忆条目格式的读取器，按格式头或字段集分派解析路径；未知版本返回 E_VERSION_UNSUPPORTED，竖线字段数不符、必填字段缺失或数值不可解析返回 E_FORMAT_CORRUPT 并指明会话与行号。
2. 实现 v1 到 v2、v2 到 v3 的升级迁移器与 v3 到 v1 的降级迁移器：升级时补全条目序号、来源轮次集合与摘要置信区间并逐项记录补全来源；降级时对 v1 无法表达的链引用与逐条修订号按显式声明的丢弃规则处理并输出丢弃记录；迁移后必须产出逐字节一致的内部记忆条目表示。
3. 实现确定性的轮次窗口切分与窗口摘要生成：按可配置窗口 token 上限与重叠 token 数切分会话轮次，窗口边界以 token 索引精确确定，摘要 token 由受控词表按词频权重确定性选取，同分按 token 字典序升序裁决；同一会话、同一配置与同一受控词表版本下必须逐字节产出相同窗口集合与摘要 token 序列。
4. 实现记忆条目合并与链引用节点：同一会话内相邻窗口摘要按重叠 token 合并为记忆条目，跨会话共享来源轮次的条目按配置门槛建立记忆链引用，须校验任一窗口恰属于一个条目、链引用不得成环，违反分别返回 E_WINDOW_DUP_ENTRY 与 E_CHAIN_CYCLE。
5. 实现重要性打分与记忆预算裁剪：重要性由条目覆盖 token 数、来源轮次跨度与摘要置信度组合打分，逐项记录贡献使总分可由明细独立重算一致；在可配置记忆预算内按重要性降序裁剪，同分按条目序号升序裁决，裁剪须保留被裁条目与未裁条目的可核对轨迹。
6. 实现三类节点的内容寻址缓存与追加轮次后的定向失效传播：窗口切分、窗口摘要、记忆条目各自以内容哈希落盘，缓存键须纳入会话内容哈希、受控词表版本、窗口参数版本与上游产物哈希；当某会话追加轮次、修正某轮文本或调整窗口上限时计算受影响窗口与条目集合，复用未受影响上游缓存，并输出重算与复用集合。
7. 实现记忆条目快照与迁移配置的版本化整体替换及并发提交控制：快照携带单调递增版本号与内容校验和，检测到版本号或校验和变化时必须整体替换而非增量修补，回退尝试返回 E_SNAPSHOT_ROLLBACK，损坏或校验和不符返回 E_SNAPSHOT_CORRUPT；同一时刻只允许一次增量提交生效，冲突时后到者立即获得 E_STAGE_BUSY 而不阻塞等待。
8. 提供可集成的领域组件接口与完整示例，并实现跨模块一致性自检：暴露格式加载、双向迁移、窗口摘要、记忆合并、裁剪与失效报告入口；自检校验三格式视图下同一会话的记忆条目集合一致、迁移补全与丢弃记录可重放出同一内部表示、重算集合与复用集合无交集且并集覆盖全部受影响窗口，不一致返回 E_INCONSISTENT 并指出首个偏差。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本验证三格式互操作、记忆压缩增量失效、快照整体替换与迁移一致性自检。
