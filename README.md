当前是空白工作区，需要从零构建一个面向 LLM 推理采样与解码链路的本地可交互专业应用，核心业务问题是采样配置与 tokenizer 词表的格式互操作与版本兼容。业务对象是本地确定性生成的推理请求：请求清单为 JSONL，字段含 request_id、prompt_tokens（已由外部词表编码的整数序列）、tokenizer_version、sampling_profile（含 temperature、top_k、top_p、repetition_penalty 的原始文本表示）以及可选的一批 logits 样本（由固定种子生成的 float64 矩阵，形状为每步 vocab 维）。采样配置存在三个版本：v1 为扁平 JSON（仅 temperature 与 top_k，温度以字符串保存且无约束）、v2 在 v1 基础上引入 top_p、repetition_penalty 与词表版本绑定并新增字段单位标记、v3 交换格式为行式键值文本（采样参数以带单位的键值对书写，支持科学计数法）。应用需完成版本升级与降级、参数归一化、逐 step 的确定性采样、以及跨版本一致性裁决，且必须在本地样本上与 float64 参考采样结果对齐。

任务环境与准备：
安装 Python 3.11 及 NumPy（建议 1.26 或 2.x），使用标准库 json 与 pathlib，不引入其他第三方运行时依赖。
在空白工作区创建项目目录，准备本地确定性样本生成脚本：按固定种子生成请求 JSONL、logits 矩阵与三版本采样配置文本样本，样本随项目一同存放。
确认本地可运行命令行与本地进程内交互界面（可用标准库实现的命令行菜单或轻量本地 HTTP 服务），不依赖任何外部账号、线上站点或容器环境。
准备异常输入样本集（截断头部、越界温度、超出词表 token、维度不符 logits、损坏校验和快照），用于在演示中触发对应业务码。

业务要求：
1. 实现 v1、v2 与 v3 行式交换格式三种采样配置的读取器，按版本头与字段集分派解析路径；未知版本返回 E_VERSION_UNSUPPORTED，头部截断或必填字段缺失返回 E_FORMAT_CORRUPT 并指出字段名，温度以字符串保存时须按容错解析规则读出并记录原始字面量。
2. 实现 v1 到 v2 的升级与 v2 到 v1 的降级迁移器：升级时补全 top_p、repetition_penalty 与词表版本绑定的默认值并记录补全项；降级时对 v2 中 v1 无法表达的字段按显式声明的丢弃与量化规则处理并输出丢弃明细，迁移结果须可被对应版本读取器重新读出。
3. 实现采样参数归一化层：将 temperature、top_k、top_p、repetition_penalty 归一为受控取值域，对 temperature 为零或负、top_k 非正、top_p 越出开区间、repetition_penalty 非正分别返回 E_PARAM_RANGE 并指明字段与原始值；归一化后的参数须写入请求级决策记录。
4. 实现逐 step 的确定性采样器：按 temperature 缩放 logits、施加 repetition_penalty、按 top_k 与 top_p 截断候选，再用显式声明的固定随机种子做确定性抽样；同一请求、同一 logits 样本与同一配置下输出的 token 序列必须逐字节一致，且采样中间量（截断后候选集与权重）须可追溯。
5. 实现跨版本采样的结果裁决：同一语义配置在 v1、v2 与 v3 三种书写形式下经加载与归一化后必须产出相同 token 序列；当因 v1 表达能力不足导致语义不可完全还原时，须返回 E_SEMANTIC_GAP 并列出无法还原的参数与受影响 step，禁止静默按默认值替代。
6. 实现 tokenizer 词表版本与采样配置的绑定校验：请求声明的 tokenizer_version 与配置绑定的词表版本不一致时返回 E_VOCAB_VERSION_MISMATCH；对 prompt_tokens 中出现超出词表大小的 token id、logits 维度与词表大小不符分别返回 E_TOKEN_RANGE 与 E_LOGITS_SHAPE，并归因到具体 request_id 与 step。
7. 实现推理请求产物与配置快照的版本化及整体替换：词表版本表、归一化参数与采样决策记录各携带单调递增版本号与内容校验和，提交时整体替换旧快照而非增量修补；加载时识别版本号或校验和变化并整体替换，损坏或校验和不符返回 E_SNAPSHOT_CORRUPT 并指明条目与版本号。
8. 提供本地可交互应用与跨模块一致性自检：展示请求列表、当前配置版本与视图、归一化参数、逐 step 候选截断与采样结果、一致性裁决结论与最近业务错误码，支持在 v1、v2、v3 视图间切换并触发一次含迁移与降级丢弃的演示；自检校验同一请求的决策记录与 token 序列可重算一致、迁移补全项与丢弃明细可追溯到字段，不一致返回 E_INCONSISTENT 并指出类别与 request_id。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
