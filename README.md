纪录片后期合成师要把历史档案显微翻拍与当代微距素材逐镜头做景深合成：同一场景在多个对焦距离下拍摄，每帧只有一段清晰。手动蒙版效率低且无法说明每个像素取自哪个焦平面，电影资产的质量审查因此卡住。合成师需要一套可反复运行的本地内核，输入焦点堆栈与对焦距离元数据，输出全清晰融合图像、逐像素选择图与贡献账本，并能在替换单帧后只重算受影响区域且与全量结果一致。

任务环境与准备：
准备 Linux（WSL Ubuntu）环境与 Python 3 运行环境，并安装 NumPy 用于像素数组计算。
在空工作区中创建项目，按题目要求实现确定性样本生成器、融合内核、增量更新与持久化目录；无需外部数据集或网络服务。
运行入口由项目内脚本或模块提供，样本由固定种子生成器产出，测试与演示均在本机完成。

业务要求：
1. 装载多组焦点堆栈序列与元数据：每组含若干焦平面的整数像素图像、对焦距离、放大率和景深范围；校验帧尺寸一致、景深范围覆盖全部对焦距离、放大率单调变化关系，输出每组每帧的像素统计摘要（均值、方差、拉普拉斯能量），元数据冲突时给出可定位的拒绝原因。
2. 逐像素计算清晰度度量序列：对每个焦平面用不同窗口半径的拉普拉斯能量与梯度幅值构造局部清晰度图，窗口半径随图像尺寸和景深步长自适应选取；在像素的候选焦平面集合内比较清晰度，生成初始对焦平面选择图及逐像素置信度（峰值与次峰值之差归一化）。
3. 对初始选择图施加邻域一致性约束：以置信度加权的多数投票平滑选择图，识别并校正被高置信度邻域包围的孤立选择像素，同时把选择不确定区域（峰值临界、邻域投票分歧）标记为边界带，输出平滑后的选择图与边界带掩码。
4. 按选择图与归一化清晰度权重执行多平面加权融合：对每个像素按选择焦平面及其邻域参与平面计算权重，输出全清晰融合图像；同时生成逐像素贡献账本，记录每个焦平面在该像素的权重份额与来源，账本总和归一化。
5. 生成融合质量报告：在边界带与全图统计焦点区域边界的误判标记数量、局部对比度改善比率（融合前后局部方差之比）以及各焦平面参与像素的分布，报告按区域给出可复核证据，并区分高置信区域与不确定区域的统计口径。
6. 支持增量更新：替换或新增单个焦平面图像后，只重算受影响的像素块（由清晰度变化传播范围确定），未受影响区域的选择图与融合图像逐像素保持不变；增量结果与全量重算在给定容差内一致，并在账本中标注重算范围与版本变化。
7. 提供确定性样本生成器：按固定种子生成带解析真值的焦点堆栈序列（含局部对焦区域、离焦模糊与传感器噪声），每个像素的理想对焦平面索引与清晰度参考值由生成器直接记录；同一参数重放两次，生成结果与融合输出完全可复现。
8. 持久化融合结果与账本：把融合图像、选择图、置信度、边界带掩码和贡献账本按序列号与版本目录保存，中断后可从已保存的焦平面状态续算；恢复时识别输入版本变化，拒绝加载与当前元数据不一致的中间状态。

验收：
以独立参考融合器逐像素重算的选择图与融合图像为基准，比对容差内一致；替换单帧后的增量结果与全量重算逐像素相同，重放两次输出完全可复现。
