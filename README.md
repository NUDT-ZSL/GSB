当前只有一台干净的开发机，需要从零构建一个面向三维场景表示优化的本地算法实现与可复现实验环境，核心业务问题是多视角观测下的点云配准、几何融合、纹理烘焙与网格简化过程中，分块融合的数值误差会沿配准变换、融合权重、纹理投影逐级放大，并在场景修订到达时与已提交快照耦合。业务对象是本地确定性生成的场景清单与多模态观测：场景清单为 JSONL，字段含 scene_id、scene_revision、camera_poses（每台相机的位姿与内参）、point_cloud_seed、texture_seed、geometry_mode、target_face_budget、priority；多模态观测由固定种子驱动的 NumPy 数组生成，不依赖任何外部数据集或真实图片。系统需把一次场景表示优化建模为五个阶段：观测摄入与点云配准、几何融合与网格简化、纹理烘焙与多视角一致性检查、分块路径与整段参考路径的数值对照、结果汇总与验证。用户后续可能以更高 scene_revision 替换部分相机观测或切换 geometry_mode，需要只重算受影响场景与阶段，并让旧快照不可回退覆盖。

任务环境与准备：
确认 Windows 开发机已安装 Python 3.11 或 3.12，并执行 python -m venv .venv 与 .venv\Scripts\activate 创建并激活虚拟环境。
执行 pip install numpy==1.26.4 安装唯一第三方依赖，无需 GPU、无需联网数据集或外部服务。
在项目根目录预留 samples 与 cache 两个本地目录，样本由任务内置的固定种子生成器在没有外部文件时也能确定性产出。
确认工作区为空目录，任务不依赖任何已有代码、配置文件或历史快照。

业务要求：
1. 实现确定性的观测摄入与点云配准阶段：按 point_cloud_seed 生成三维点云，以相机位姿为初值做迭代最近点配准精化，同分时按点索引升序打破平局；同一 scene_id、同一种子与同一配置下必须逐字节产出相同的点云、配准变换矩阵与残差，且残差须可由点云与变换矩阵独立重算一致。
2. 实现几何融合与网格简化阶段：在 target_face_budget 下对融合网格做确定性简化，简化中边选择同分时按顶点索引升序裁决；输出网格顶点、面片与简化前后统计，面片数不得超过预算，违反返回 E_FACE_BUDGET_EXCEEDED 并指明 scene_id 与超支面数。
3. 实现纹理烘焙与分块纹理积分路径：按 texture_seed 与相机观测把颜色烘焙到网格表面，分块权重、边界归一化与整段口径同源，分块拼接结果须与一次性整段烘焙在 float64 下逐像素一致，不一致返回 E_TEXTURE_BLOCK_MISMATCH 并输出首个偏差的像素坐标与偏差谱。
4. 实现逐级误差传播计算与主导来源归因：以 float64 整段路径为该快照内参考真值，输出配准残差、融合权重归一化、简化边坍缩、分块纹理积分各级的绝对偏差、相对偏差、误差区间与误差放大比，并定位主导误差来源级别；区间顺序非法返回 E_ERROR_SPECTRUM_INVALID。
5. 实现配准残差门限与简化度门限的数值稳定性保护：提供严格比较与容差带比较两种策略及次正规数保护，保证恰好落在门限附近的场景在重复运行下判定不被舍入翻转；门限策略或容差非法分别返回 E_THRESHOLD_POLICY_INVALID 与 E_TOLERANCE_INVALID 并指明字段。
6. 实现场景修订与 geometry_mode 切换后的定向失效传播：区分仅相机观测替换、仅 target_face_budget 变化、geometry_mode 切换三类情形计算受影响阶段与场景集合，复用未受影响上游已提交产物，仅重算受影响后缀，并保证结果与从零全量重算逐字节一致，不一致返回 E_INCREMENTAL_INCONSISTENT 并输出首个偏差 scene_id。
7. 实现各阶段产物内容寻址缓存与并发提交控制：缓存键须纳入场景内容哈希、相机位姿摘要、geometry_mode、target_face_budget 与上游产物哈希，键相同复用、键不同重算；同一时刻只允许一次增量提交生效，冲突时后到者立即获得 E_STAGE_BUSY 而不阻塞等待。
8. 实现场景快照与配置的版本化整体替换、资源上限、跨模块一致性自检及结果验证工具：快照携带单调递增版本号与内容校验和，检测到版本号或校验和变化时整体替换而非增量修补，回退尝试返回 E_SNAPSHOT_ROLLBACK，损坏返回 E_SNAPSHOT_CORRUPT；为驻留网格与纹理内存、单场景面片数与并行重算场景数设上限，超限返回 E_RESOURCE_LIMIT 或降级并标记；自检校验各阶段 scene_id 集合一致、重算与复用集合无交集且并集覆盖受影响集合。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地确定性样本跑基线与一次修订增量运行，核对分块与整段一致、误差谱及快照替换行为。
