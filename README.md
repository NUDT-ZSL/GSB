在空白工作区从零实现一个本地 CI/CD 流水线制品缓存的容量水位与晋升裁决引擎，核心业务问题不是跨版本清单合并，而是：在有限的缓存容量预算下，依据任务制品的复用频次与新鲜度把制品在冷、温、热三级缓存档之间晋升与降级，并在容量水位逼近上限时裁决哪些制品保留、哪些淘汰、哪些需要回收其磁盘对象。本地样本以 JSON 给出：任务清单（任务名、依赖的上游任务列表、制品名、制品字节大小、写入逻辑时钟毫秒、最近命中逻辑时钟毫秒、累计命中次数、是否为固定保留制品），流水线描述（流水线名、引用的任务序列、每次运行的逻辑时钟），以及容量配置（每档容量字节上限、晋升所需最小命中次数、降级空闲时长逻辑毫秒、淘汰批量大小、单轮回收字节预算、定点标度与比对容差、逻辑时钟步进）。制品字节内容由确定性生成器按任务名与写入时刻派生，摘要可校验。引擎需把制品物化到本地内容寻址目录，在可注入逻辑时钟下按流水线运行逐个判定命中并更新频次与档位，容量水位超限时按裁决规则执行晋升、降级与淘汰并回收零引用对象，且支持进程被强制终止后的恢复和多进程并发提交。

任务环境与准备：
安装 Python 3.10 或以上版本，并确认标准库 sqlite3 与 hashlib 可导入。
准备本地样本目录：任务清单 JSON、流水线描述 JSON、容量配置 JSON，均由确定性脚本生成，不依赖网络、账号或外部数据。
确认工作区可创建本地内容寻址对象目录、SQLite 状态库文件与临时目录，用于原子落盘与恢复演练。

业务要求：
1. 实现任务清单、流水线描述与容量配置的解析校验：任务名唯一、依赖上游存在于任务清单且无环、制品字节大小为正整数、命中次数为非负整数、写入与最近命中逻辑时钟为非负整数且最近命中不早于写入毫秒、每档容量上限与淘汰批量大小为正整数、晋升命中次数阈值为正整数，非法输入返回 E_BAD_TASK 等业务错误码且不得写入任何持久化状态。
2. 实现制品内容寻址物化与摘要校验：按任务名与写入逻辑时钟确定性派生制品字节块并计算 SHA-256 摘要，以临时文件加重命名原子写入本地对象目录，相同摘要重复写入必须复用同一对象文件且不产生重复副本；制品记录须保存档位、引用它的流水线运行序号与最近访问逻辑时钟，作为后续频次统计与回收的唯一观测来源。
3. 实现按流水线运行的命中判定与频次回归：按流水线描述顺序与注入逻辑时钟逐次运行，每次运行对引用的每个任务判定制品是否命中，命中须更新累计命中次数、最近命中逻辑时钟并记录运行序号；同一运行序号重复提交必须幂等而不得重复累加命中次数，命中判定只依据持久化的制品写入时刻与逻辑时钟，不得读取系统墙钟。
4. 实现冷、温、热三级档位的晋升与降级演进：制品命中次数达到晋升阈值时晋升一档，空闲超过降级时长逻辑毫秒时降级一档，固定保留制品不得降级；档位迁移只能依据已提交运行结果与持久化状态裁决，重启后不得凭内存残留决定档位，每次迁移须记录触发条件、迁移前档位与依据的运行序号区间。
5. 实现容量水位超限时的淘汰裁决与对象回收：任一档位容量之和超过上限时按档位从低到高、档位内按空闲时长与命中次数组成的稳定次序选择淘汰候选，淘汰批量与单轮回收字节预算共同约束每轮淘汰数量；预算不足以覆盖全部候选时须放弃剩余候选并记录放弃原因，被淘汰制品的对象只在其引用计数归零后回收，回收字节数须与放弃记录一并输出。
6. 实现频次与容量账目的误差记录及精度敏感标记：累计命中次数、档位容量字节与空闲时长的换算记录标度、舍入方向与换算前原始值，并累计每次加法与乘法的误差上界；当两个淘汰候选的裁决得分差小于比对容差且淘汰顺序依赖该差值时标记为精度敏感，输出参与候选、各自误差上界与若改用更高标度是否改变淘汰结果。
7. 实现强制终止后的恢复一致性与多进程幂等：把已提交运行水位、各制品档位与频次、各档容量账目、淘汰与回收记录、精度敏感记录与逻辑时钟水位以事务原子写入 SQLite；进程在命中更新、档位迁移或对象回收中途被强制终止后，恢复路径识别已提交运行与半提交账目，只重放未完成部分且不得重复累加命中次数、误回收藏活对象或重复扣减容量；多个实例并行提交同一流水线运行时通过事务与文件锁保证同一运行序号只被处理一次。
8. 实现异常链路隔离与可重复命令行验证：任务缺失、摘要不匹配、逻辑时钟回拨超容差、容量配置版本回退、淘汰候选引用不存在的制品分别映射到不同业务错误码并保留可诊断字段（运行序号、任务名、档位）；提供 load、run、judge、evict、resume、status、verify 子命令，judge 以稳定排序 JSON 输出每任务命中结论、档位、误差上界与精度敏感标记，单次异常不得中断其他任务的运行处理。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地样本验证档位晋升降级、容量淘汰与回收、恢复后频次与容量账目一致，并检查异常错误码。
