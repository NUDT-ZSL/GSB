古籍数字化项目的版面分析员需要把扫描书页加工成可检索的结构化标注：一页古籍上既有竖排正文列，又穿插双行小字夹注、页眉眉批、藏书印章与插图，阅读顺序不能按现代横排习惯从上到下、从左到右直接读出。项目组用固定种子生成了带人工标注的书页样本，同一页还以三种分辨率与压缩方式各存一份图像。分析员希望从原图出发自动得到文字块边界、块类型（正文列、双行夹注、眉批、插图、印章）与块的阅读顺序，并保证三种格式版本给出同一结论，最终输出可逐块追溯版式规则依据的标注报告。

任务环境与准备：
在 Linux（WSL Ubuntu）上准备 Python 3 运行环境，并安装 NumPy 与 Pillow 作为图像读写与矩阵运算依赖。
题目自带的确定性样本生成器按固定种子输出三种格式版本的古籍书页图像与人工标注 JSON，无需外部数据集或网络下载。
工作区从零创建，批量入口、结果文件路径与报告文件命名在运行说明中固定，便于重复执行复现。

业务要求：
1. 从每页图像的灰度投影出发，按列方向与行方向的投影低谷切出候选连通域，再结合字距与行距把碎片合并成文本块，同时保留插图与印章区域，输出每块的轴对齐边界框与置信度分数；对细笔画区域不得因二值化阈值过激而把同一列切成多段。
2. 为每个文本块判定类型标签（正文列、双行夹注、眉批、插图、印章）：依据块宽与列间距分布区分窄列夹注与常规正文列，依据上边距与块高判定眉批，依据内部笔画密度与形状判定印章和插图；类型判定必须给出触发该标签的可量化特征值，以便报告追溯。
3. 根据块类型与几何关系构建阅读顺序有向邻接图：正文列按横向位置从右至左排序形成主链，每个夹注块挂接到与其横向重叠最大的主列并插入该主列之后，眉批按其与主列链的相对位置决定置于正文之前或之后，插图与印章挂接到紧邻的正文列；图中每条边需记录其依据的版式规则名称。
4. 对邻接图执行拓扑排序得到阅读顺序序列，并在存在规则冲突或环（例如夹注同时与两列重叠且无法判定主列）时输出无法唯一确定顺序的块集合及冲突边，而不是静默选一个顺序；冲突处置结果需出现在最终报告的独立小节中。
5. 同一书页的三种图像格式版本（不同分辨率与压缩）分别进入上述管线后，需先按原始页面尺寸归一坐标，再比对块分割与阅读顺序，输出跨版本差异清单，列出边界偏差超限、类型翻转或顺序位次变化的块及其两种版本的取值。
6. 生成逐页版式标注报告，包含每块边界、类型、顺序索引、判定依据的版式规则与关键特征值，以及该页的阅读顺序序列；报告需能让人工标注员仅凭报告复算出顺序，不依赖原始图像。
7. 实现独立的版式规则核对器，对任意给定的阅读顺序结果检查竖排从右至左、夹注紧随主列、眉批插入约束是否成立，并报告违反约束的块对编号；核对器不得复用顺序生成阶段的中间数据结构，仅接受最终报告与块特征表作为输入。
8. 在样本目录上提供批量运行入口，输出每页标注结果、跨版本差异清单与汇总指标（块分割边界 IoU、类型分类正确率、顺序序列与人工标注的 Kendall 秩相关系数），并将整体结果写入固定的结果文件供复现。

验收：
在生成器样本上产出块分割、类型标签与阅读顺序报告，三种格式版本结论一致，独立核对器确认版式约束成立且冲突块被记录。
