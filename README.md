声乐教师在给学员做课后反馈时，手上只有一段手机录下的清唱片段和一份打印好的歌词，需要知道每个字唱在什么音高上、哪里偏低哪里拖拍，才能逐句讲评。制作人拿到同一批素材时更关心能不能把偏掉的音修回去，因此音高轨迹的连续性与歌词音节的时间边界同样重要。现有做法是把录音丢进通用测音软件看一条曲线，再靠耳朵把歌词逐字对回去，遇到长音、滑音和辅音起音时经常对错位置。本题要求交付一套本地工具，从单声道清唱录音出发，同时得到逐帧基频、音符切分、歌词音素时间对齐、音节映射和演唱评分，并用独立手工标注核对结果。

任务环境与准备：
准备 Python 3 运行环境，并安装 NumPy 用于音频分帧、自相关、倒谱与数值计算；样本音频与手工标注由本地确定性生成脚本产出，不依赖网络或外部服务。
在 Linux（WSL Ubuntu）下从工作区创建项目，样本目录包含若干单声道 WAV 清唱片段、对应歌词文本、参考音高序列与逐帧逐音素的手工标注文件，所有路径通过命令行参数传入。
运行时以命令行入口执行单个样本或整个样本目录，报告输出到指定目录；不要求 GPU，单次处理在普通 CPU 上完成。

业务要求：
1. 对单声道清唱录音逐帧估计基频，输出每帧的时间戳、频率与浊音判定，频率换算为带小数位的 MIDI 音高；帧长、帧移由配置给出，清音帧必须显式标记为无音高而不是填零。
2. 在自相关与倒谱两种基频估计之间按帧选择：自相关在低音区稳健但易受八度错误影响，倒谱对高音区谐波结构更敏感，需要依据谐波能量分布与浊音度给出选择依据，并在输出中记录每帧采用的估计方法与浊音度。
3. 对逐帧基频轨迹做中值平滑与八度跳变纠正，纠正时必须保留原始观测以便回溯；平滑窗口随局部音高变化率自适应调整，滑音段不得被抹平为单音。
4. 将连续音高轨迹切分为音符，给出每个音符的起始时间、结束时间、代表音高与置信度；音符边界需同时参考音高跃变、浊音度下降与能量包络下凹，短于最短时长的碎片合并到相邻音符。
5. 依据歌词文本与音频做强制对齐，输出每个音素的起止时间与置信度；对齐代价需结合音素类别（元音或辅音）与浊音段、能量段的一致性，辅音不得被强行拉伸到整个长音上。
6. 把音符切分结果映射到歌词音节，一个音节跨多个音符时按元音位置指定主音符，并校验映射后的音节数与歌词文本一致；无法映射的音符需单独列出并说明原因。
7. 以用户提供的参考音高序列（音名加时间区间）为基准，计算音准偏差与节奏稳定性指标；参考音高按半音容差判定命中，偏差以音分表示，并给出逐音符的偏高偏低方向。
8. 生成音高与歌词对齐报告，标出低置信度帧、低置信度音素和未映射音符所在的区间，报告需可由程序读取以支持教师批量核对，同时保留人类可读的逐句摘要。

验收：
用带手工音高与音素边界的清唱样本核对：基频命中率、音符切分边界误差、音素对齐误差与音节映射一致均达到标注容差。
