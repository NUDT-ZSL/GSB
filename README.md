当前是空白工作区，没有现存项目、代码或数据附件，需要从零构建一个面向语音合成（TTS）的本地专业应用与可重复演示，核心业务问题是语音合成配置的增量更新与依赖失效。业务对象是本地确定性合成的语音片段：用固定种子生成若干说话人的基频、共振峰与能量包络参数，按给定时间轴与增益拼成 16kHz 单声道 PCM，并附逐帧真值文件（帧长 20ms，字段含 frame_index、speaker_id、f0_true、energy_true）与合成任务清单（JSONL，字段含 utterance_id、text、speaker_id、style_tag、prosody_scale、sample_rate、duration_ms、seed）。合成流程被建模为有向无环计算图：文本归一化→音素切分→声学特征生成（基频、能量包络与时长）→声码器合成波形→逐帧对齐与韵律校验。合成配置以 v1、v2、v3 三种并存的书写形式到达，分别对应扁平行式、带字段名行式与结构化嵌套描述，配置项覆盖说话人、风格、韵律缩放与精度档。系统需在配置增量更新时精确定位受影响的合成节点与语音片段，并保证旧产物不被误用。

任务环境与准备：
安装 Python 3.10 及以上版本，并安装 NumPy（建议 1.24 及以上），用于确定性 PCM 合成与逐帧特征计算。
在工作区根目录创建项目结构，准备本地确定性样本生成脚本：按固定种子生成说话人参数、合成任务清单（JSONL）与逐帧真值文件（JSONL）。
准备 v1、v2、v3 三种合成配置样例文件各一份，确保包含说话人、风格、韵律缩放、精度档与声码器参数，并覆盖可触发迁移补全与丢弃的场景。
确认本地磁盘可写，用于缓存目录、快照持久化与日志输出；无需任何外部服务、真实账号或网络访问。

业务要求：
1. 实现确定性的四阶段合成计算图：文本归一化与音素切分、声学特征生成（基频、能量包络与时长）、声码器确定性合成波形、逐帧对齐与韵律校验依次串联，节点连接由配置字典决定；同一 utterance_id、同一 seed 与同一配置下各阶段中间产物与最终 PCM 必须逐字节一致，禁止依赖系统时间或未声明的随机源。
2. 实现 v1、v2、v3 三种合成配置的读取器，按版本头或字段集分派解析路径；未知版本返回 E_VERSION_UNSUPPORTED，头部截断、竖线字段数不符、必填字段缺失或数值不可解析返回 E_FORMAT_CORRUPT，并指明行号与字段名；读取结果须保留来源版本以便后续迁移与追溯。
3. 实现 v1 与 v2、v3 的双向迁移器：升级时补全风格标签、韵律缩放、精度档与时长缩放默认值并逐项记录补全来源；降级时对 v1 无法表达的嵌套风格继承与逐音素时长曲线按显式声明的丢弃或展平规则处理并输出丢弃明细；迁移产物须携带来源版本与目标版本。
4. 实现跨方言裁决：同一合成语义以 v1、v2、v3 三种形式书写时，经加载与迁移后必须产出相同音素序列、相同声学特征与逐字节相同的 PCM；当 v1 表达能力不足导致语义不可完全还原时返回 E_SEMANTIC_DRIFT 并指出无法还原的配置项，禁止静默以默认值替代后继续合成。
5. 实现内容寻址缓存与缓存键构造：每个节点产物附带内容哈希写入本地缓存目录，缓存键须纳入文本内容哈希、音素序列摘要、说话人嵌入版本、风格与韵律参数、精度档、声码器参数版本与上游节点哈希；键相同必须复用快照，键不同必须重算，且每个缓存条目须可反查其键组成。
6. 实现增量更新的依赖失效传播：修改某说话人的基频与共振峰参数、调整某 utterance 的风格标签或韵律缩放、或提升声码器参数版本时，计算受影响节点与受影响 utterance_id 集合，复用未受影响上游缓存，仅重算受影响后缀；须输出本次重算节点清单与复用节点清单，并保证局部修改后的最终 PCM 与从零全量合成逐字节一致。
7. 实现合成产物追溯与过期结果拒绝：任一段合成 PCM 须记录所用缓存键、配置版本与节点路径，可按这些记录重放出相同 PCM；当缓存键任一依赖版本已变化而产物仍来自旧键时返回 E_LINEAGE_BROKEN 并指出 utterance_id 与变化的依赖项；追溯链缺失或重放不符同样返回该码。
8. 实现配置与统计量快照的版本化整体替换、并发提交控制及资源上限，并提供本地可交互专业应用：快照携带单调递增版本号与内容校验和，检测到版本号或校验和变化时必须整体替换旧快照而非增量修补，旧版本不得覆盖新版本且回退尝试返回 E_SNAPSHOT_ROLLBACK；同一时刻只允许一次增量提交生效，冲突时后到者立即获得 E_STAGE_BUSY；为单次重算 utterance 数、缓存条目总量与并行重算节点数设可配置上限，超限返回 E_RESOURCE_LIMIT 或降级并标记降级类别；应用展示计算图拓扑、缓存命中与重算状态、失效传播覆盖范围、三视图切换、快照版本与最近业务错误码，并支持触发一次演示。
