在空白工作区构建一个面向本地确定性合成语音样本的语音情感与对话理解领域组件与完整示例，核心解决数据规模连续变化（片段数从数十到数千、对话轮次从单轮到多轮、情感类别从粗粒度到细粒度）时的特征提取、情感判定与对话级融合的算法取舍问题。输入为一个本地样本目录：若干 WAV 音频（16kHz 单声道 16bit PCM，由固定种子程序合成，含基频轮廓、能量包络、语速节奏与噪声，不同情感类别在基频均值、基频方差、能量动态范围与语速上具有可控差异）与一份对话脚本 JSON（记录每段音频的说话人、轮次序号、前后文衔接关系与可选文本意图标签），另提供一份配置 JSON（帧长与帧移毫秒、声学特征集合、情感类别粒度、分类器类型选择项、对话融合窗口与衰减系数、特征维度上限、规模档位、并发数、快照提交间隔）与一份异常注入清单 JSON。组件需完成逐段声学特征提取、段级情感打分、对话级上下文融合与最终意图-情感联合输出，并提供可重复运行的诊断报告。要求全程无随机性、结果可复现，且在样本规模放大时保持确定性的算法取舍记录与结果一致性。

任务环境与准备：
安装 Python 3.10 及以上版本，并安装 NumPy（任务所需唯一第三方依赖，按官方 wheel 在 Windows 上安装）。
准备本地工作区目录，用于放置合成的 WAV 样本、对话脚本 JSON、配置 JSON 与异常注入清单 JSON；样本由随组件提供的固定种子生成脚本在本地生成，不依赖任何外部音频数据。
在 Windows 上确认 WAV 读写与文件原子替换（写入临时文件后 os.replace）行为可用，并确认线程池可正常创建。
准备运行命令的终端与足够的本地磁盘空间用于阶段快照与产物文件，不依赖网络、真实账号、GPU 或容器环境。

业务要求：
1. 实现音频读取与逐帧声学特征提取层：扫描输入目录下所有 WAV 文件，校验容器头、采样率、声道数与位深，不合规时输出 E_AUDIO_FORMAT 并进入失败清单；按配置帧长与帧移切帧，末帧不足按补零处理，逐帧计算基频轮廓粗估、短时能量、过零率与语速节奏指标，基频采用自相关峰搜索并以固定量化档位输出；同一音频在任意运行中必须得到逐帧一致的特征序列，且特征维度受配置上限约束。
2. 实现段级情感打分器：依据配置的情感类别粒度（粗粒度三档或细粒度六档）与分类器类型选择项（最近质心或加权逻辑回归），以固定运算顺序计算每段音频在各情感类别上的确定性得分并做稳定归一化；分类器类型切换必须真实改变打分路径，同分时按情感类别名称字典序决断；每段输出各类别得分、最高类别与边界样本标记，边界样本需给出参考精度下的得分差值。
3. 实现对话级上下文融合：按对话脚本中的轮次序号与前后文衔接关系，以可配置融合窗口与衰减系数对相邻轮次情感得分做加权平滑，同一说话人的轮次权重与跨说话人权重按配置区分；融合后输出每轮的情感判定、意图标签联合结果与上下文贡献分解；当融合窗口中前驱轮次缺失时按可配置规则回退并在结果中显式标注回退来源。
4. 实现数据规模自适应的算法取舍选择器：依据片段总数、平均时长、对话轮次数与情感类别粒度，从预置策略表中选择特征集合子集、分类器类型与对话融合窗口，并输出含所参考规模指标、候选策略评分与选择理由的决策记录；规模跨越配置的放大档位时策略选择必须随之变化，且同一规模与配置下选择结果必须完全可复现。
5. 实现增量复用与失效判定：为特征提取、段级打分与对话融合各阶段产物计算由上游内容指纹、配置指纹与规模档位派生的缓存键；当情感类别粒度、分类器类型、融合窗口或某段音频内容变更时，仅使受影响阶段及其下游失效并纳入重算集合，未失效阶段必须直接复用且不得重复计算，复用与重算清单须写入结果摘要。
6. 保证增量运行与全量重建的结果一致性：从任意初始状态执行包含规模档切换、类别粒度调整、分类器切换、融合参数变更与单段音频替换的编辑序列，每次增量运行得到的最终逐轮情感与意图结果、各类别得分、决策记录与诊断摘要，必须与从空白工作区按相同最终输入与配置一次性全量运行的结果逐字段一致。
7. 实现并发处理与串行结果一致性：使用线程池并发执行帧特征提取与段级打分，最大并发数取自配置；每个样本或轮次任务携带由文件名、轮次序号与阶段名派生的稳定排序键，无论线程完成顺序如何，最终样本顺序、逐帧记录顺序、轮次结果顺序与失败清单顺序必须与单线程顺序执行完全一致。
8. 实现阶段快照恢复、异常注入隔离与诊断报告输出：各阶段以临时文件加原子替换方式持久化快照，快照含阶段名、配置哈希、注入清单哈希、已处理游标、产物摘要与版本号，恢复时版本号或配置哈希不符输出 E_CONFIG_MISMATCH；以独立注入配置指定非有限采样值、零时长片段、缺失前驱轮次与非法类别粒度等样例，注入项编号写入报告以证明命中，单段异常记录文件名、阶段名、业务码与异常类型并继续其余段；收到可处理的退出信号时完成当前阶段快照提交后以整数退出码 0 退出；每次完整运行生成 JSON 报告，含各类别得分、逐轮融合结果、规模决策记录、缓存命中与失效统计、注入命中清单、失败清单与快照版本号。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地合成语音与对话样本验证特征提取、情感判定、规模自适应取舍及增量与全量结果一致，并提供诊断报告。
