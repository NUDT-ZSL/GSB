在空白工作区构建一个面向本地确定性样本的多模态证据协同推理组件，服务于图文配对证据的联合判定与数值可信度诊断。输入为一个本地样本目录：每个样本包含一张由固定种子程序生成的 PNG 图像（固定分辨率，画面为几何图元与噪声）与一份结构化文本断言 JSON（实体、属性与断言列表），另提供一份融合配置（视觉特征维度与量化档位、文本证据权重、融合温度、置信度阈值、定点小数位宽、并发数）与一份证据关系表（声明文本断言与视觉区域的关联、冲突、补充关系）。组件需按固定轮次完成视觉特征抽取与量化、文本断言映射、加权融合判定与置信度收敛，并在每轮输出可复现的中间得分。核心问题是数值精度与误差传播：量化档位与定点小数位宽会逐级作用于特征离散化、softmax 融合与置信度比较，需明确追踪每级误差来源，并保证在任一精度档下结论判定可解释、可复现、可诊断。

任务环境与准备：
确认 Windows 上可用 Python 3.10 及以上版本，并能创建本地虚拟环境。
安装 NumPy 与 Pillow 用于数组计算和 PNG 读取，版本以本地包索引可用为准。
在空白工作区准备样本目录，用脚本按固定种子生成 PNG 图像与对应文本断言 JSON，并放置融合配置与证据关系表。
准备一份非法样本（缺失图像或结构不合法）用于验证失败清单与业务码，运行前不修改实现源码。

业务要求：
1. 实现多模态样本加载层：扫描输入目录下每个样本的图像与文本断言文件，校验 PNG 容器头、尺寸与 JSON 结构完整性，图像解码为 uint8 数组并按配置特征维度做确定性分块，文本解析为实体、属性与断言列表；缺失文件、结构不合法或图像尺寸不符时输出 E_SAMPLE_INVALID 并进入失败清单，其余样本继续处理。
2. 实现视觉与文本特征的定点量化：视觉特征按区域均值与梯度强度计算后，依配置量化档位与定点小数位宽转为定点整数表示；文本断言特征按关系表映射到对应视觉区域后以同样位宽定点化；量化过程须记录每个特征的舍入残差，残差绝对值超过位宽允许半单位时计入误差来源清单，同一输入在任何运行中量化结果一致。
3. 实现逐轮加权融合推理：每轮以可配置融合温度对视觉与文本证据做 softmax 加权融合，冲突关系按固定折减规则降低置信度，补充关系按权重叠加；所有中间量以定点整数运算，softmax 采用减去最大值的稳定形式并记录每次指数近似的截断位置；每轮输出判定得分、归一化置信度与各证据贡献分解。
4. 实现误差传播的逐级追踪：对每条样本，分别以配置档位与高一档位定点位宽完整计算同一融合链路，输出特征量化、softmax 指数与归一化、加权求和三个环节的差值，并标注误差首次超过配置容差所在的环节；当最终判定类别在两档位间发生翻转时，该样本须标记为精度敏感样本并单独列出，不得静默归并。
5. 实现置信度阈值边界诊断：对每轮归一化置信度与判定阈值的比较，输出该置信度在高一位宽下的参考值及二者差值；当样本置信度落在阈值邻域且两档位判定不一致时，记录边界敏感样本并给出其证据贡献主项，最终报告须区分精度敏感样本与边界敏感样本两类计数。
6. 实现并发推理与串行结果一致性：使用线程池并发处理样本的多轮融合，最大并发数取自配置；每条样本任务携带由样本名与轮序号派生的稳定排序键，无论线程完成顺序如何，最终每样本结论、证据贡献分解顺序、精度与边界敏感清单及失败清单顺序必须与单线程按样本名顺序执行逐字段一致。
7. 实现轮次快照与强制终止后的恢复判定：每轮结束以临时文件加原子替换方式持久化快照，快照含轮序号、配置哈希、关系表哈希、定点位宽、已处理样本游标、各样本当前得分摘要与版本号；重启时读取最新快照，配置或关系表哈希不符输出 E_CONFIG_MISMATCH，版本变化按整体替换语义识别；强制终止后仅依据已完整替换的快照恢复，不得承诺生成退出报告。
8. 实现异常链路与诊断报告输出：单样本在特征量化、融合或误差追踪阶段抛异常时记录样本名、轮序号、阶段名与业务码并继续其余样本，后续轮次不得再对该样本产出结论；收到可处理的退出信号时完成当前轮快照保存后以整数退出码 0 退出；每次完整运行输出 JSON 报告，含每样本结论、各轮得分轨迹、逐级误差差值、敏感样本分类计数、快照版本号与失败清单，报告以临时文件加原子替换方式写盘。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地图文样本验证定点融合结论、逐级误差追踪与敏感样本分类，并检查配置不符与恢复行为。
