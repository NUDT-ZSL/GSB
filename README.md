当前为空白工作区，需要从零构建一个面向交叉组合与降维的专业可视化诊断工作台，核心业务问题是数据规模变化下的算法取舍。输入为本地确定性生成的表格或高维稠密样本：由固定种子生成的特征矩阵（字段含 row_id、若干数值列与类别列、label）以及一份降维配置，包含候选方法（PCA 主成分、随机投影、以及 PCA 之后再随机投影的两段式组合）、目标维度、随机投影的种子与投影矩阵密度、是否先做标准化、数值精度标记与匹配的随机投影种子。工作台需把一次降维运行建模为可诊断的计算过程：标准化→降维→可选的组合补维→把降维结果与标签做简单邻域类一致性评估，并输出降维坐标、累计解释方差或投影误差、每候选方法的取舍记录与诊断报告。难点在于数据规模（行数、列数、目标维度）变化时，不同方法在保真度、耗时估计与内存占用上的取舍必须可解释且可复现，同时工作台要能点选单样本查看其降维坐标在各方法间是否可核对，并保证降维坐标可追溯到具体方法与配置版本，禁止依赖任何外部数据或随机环境。

任务环境与准备：
安装 Python 3.11 与 NumPy、Matplotlib（版本写入运行说明），无需网络服务。
在本地以固定种子生成确定性表格样本与降维配置 JSON，放入工作区。
准备一次非法配置样本（如目标维度超过原始维度、投影密度越界）用于注入演示。

业务要求：
1. 实现确定性的标准化与降维核心：按配置决定是否对数值列做 z-score、类别列按固定规则编码，再执行 PCA 或随机投影；随机投影矩阵须由配置中的固定种子与投影矩阵密度确定性生成；同一输入、同一配置与固定种子必须产出逐字节一致的降维坐标与统计量，禁止依赖全局随机状态或时间。
2. 实现基于数据规模的方法取舍器：按行数、列数与目标维度选择候选方法，输出每种候选的保真度估计、耗时与内存代价估计及取舍理由；当目标维度超过有效秩或接近原始维数时须给出明确取舍说明（如投影近似或保留主成分），同一规模与配置下决策必须可复现。
3. 实现 PCA 与随机投影组合的两段式路径：先用 PCA 降到中间维度再随机投影到目标维度，中间维度与投影矩阵密度由配置给出；须记录两段各自的参数与中间维度，并校验中间维度不超过原始维度与目标维度，违反时返回 E_DIM_INVALID 并指明字段。
4. 实现数值精度与保真度诊断：对每种候选方法输出累计解释方差或投影后重构误差、与同一输入上 float64 参考实现的最大绝对与相对偏差，并给出保真度容差判定；超容差返回 E_TOLERANCE_EXCEEDED 并指出越界元素位置与偏差量，不得以放宽容差掩盖真实错误。
5. 实现降维坐标的邻域类一致性评估：在降维结果上做确定性的 k 近邻类一致性统计并与原始空间的基线对比，近邻同分时按 row_id 升序打破平局，输出分类别的一致率与下降幅度；同一快照与配置重跑得到相同数值，且评估必须记录所依据的降维坐标版本与 k 值口径。
6. 实现配置与算法的版本化快照及整体替换：标准化统计量、降维投影矩阵或主成分、各类评估统计量分别携带单调递增版本号与内容校验和，提交时整体替换旧快照；加载时检测版本变化并整体替换，校验和不符返回 E_SNAPSHOT_CORRUPT 并指明快照类别与版本号。
7. 实现资源上限与规模变化下的降级：为降维矩阵的内存估算、投影中间缓冲与特征数设可配置上限，超限时按明确策略返回 E_RESOURCE_LIMIT 或降级到随机投影等低内存路径，降级须在结果中标记降级类别与触发上限，且不得改变已输出坐标的可追溯性。
8. 实现跨方法一致性自检与诊断工作台：校验同一输入下随机投影与两段式路径在投影参数相同时结果一致、单样本坐标可从方法与快照重建、评估所用坐标版本与当前快照一致，不一致返回 E_INCONSISTENT 并标明类别；工作台展示方法取舍、保真度曲线、邻域一致性对比、降维散点、最近业务错误码，并支持固定种子重跑与一次注入非法配置的演示。
