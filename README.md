手语教学视频制作团队在制作公共服务场所的手语导览内容时，需要把动画师制作的手语动作关键帧绑定到虚拟手模型骨骼上，并渲染成手指与手掌形变自然、没有穿插的示范动画。虚拟手表面用若干球、胶囊与椭球的有符号距离场基元组合描述，团队希望沿视线做球面追踪来获得稳定可复现的手部渲染图像，并在重点手势时刻检查手指之间或手指与手掌之间是否出现表面穿插。现有工作区为空，需要交付可集成的 Python 领域组件与本地运行示例，读入确定性手语动作工程，输出逐帧渲染图像、穿插清单与形变核验报告。

任务环境与准备：
准备 Linux（WSL Ubuntu）上的 Python 3 运行环境，并安装 NumPy 用于骨骼变换、SDF 组合查询与球面追踪中的向量化计算。
在工作区中提供确定性手语动作工程生成器与本地运行示例入口，输入文件与输出目录均使用相对路径。
运行示例时确保输出目录可写，用于保存逐帧渲染图像序列、穿插清单与形变核验报告。

业务要求：
1. 解析手语动作工程中的骨骼层级与关键帧轨道，按每个关节的旋转角与根部位移依关键帧插值曲线生成逐帧关节变换，完成手部顶点线性蒙皮，并输出每个关键帧时刻的骨骼世界变换与蒙皮后顶点坐标供后续距离场组合查询。
2. 将掌部椭球与各指节胶囊、球等 SDF 基元按所属骨骼变换到世界空间并组合为统一距离场，实现给定采样点上的距离值计算与梯度方向求解，同一基元组合在重复查询下输出一致。
3. 沿相机射线以自适应步长执行球面追踪，以步进距离与射线行进距离的关系控制步长并求首次过零交点，按梯度估计表面法线完成朗伯光照着色，逐帧输出手部渲染图像序列。
4. 在重点手势时刻检测属于不同骨骼的 SDF 基元之间的负距离重叠区域，输出穿插清单，含涉事基元、所属骨骼、帧号与最大穿插深度，深度按组合距离场在该区域的极小值计算。
5. 对重点手势时刻比较蒙皮前后指定指节表面采样点的距离场值与近似体积变化，标记因蒙皮导致表面收缩或异常膨胀的指节，输出形变核验报告并说明判定所依阈值。
6. 对同一手语动作重复执行渲染时，交点位置、法线与穿插判定在给定容差内一致，并将渲染图像序列与核验报告按工程版本持久化，供导览终端按版本取回。
7. 处理指间紧密贴合、极端腕部旋转、基元完全重叠等边界输入时，球面追踪不得穿透表面或漏检穿插，并在射线步进达到最大次数或交点超出相机远平面时给出明确的业务状态码而非静默丢弃。
8. 提供本地运行示例，读入确定性生成器产出的手语动作工程与重点时刻清单，在一组固定参数下完整执行蒙皮、着色、穿插检测与形变核验，并将渲染快照、清单与报告写入指定输出目录。

验收：
用确定性手语动作工程运行内核，核对逐帧渲染图像、穿插清单与形变核验报告，确认交点与法线误差在容差内且结果可复现。
