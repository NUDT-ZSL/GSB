农业生态观测站的野外观测数据管理员要为下一季推广决定是否替换当前的参考样地推荐排序策略：旧策略按物种相似度推荐，新策略在此基础上叠加样地邻近度与环境属性匹配。站里多年积累的观测日志只记录了旧策略上线期间的曝光与观测者是否采纳推荐样地的结果，新策略从未上线，直接比较历史命中率会因策略偏差和样地分布差异而失真。管理员需要一套本地服务，在仅有部分反馈的日志上做出无偏的反事实命中率估计、新旧策略价值差与置信区间，并识别新策略在哪些样地和观测者群体上可能失效。

任务环境与准备：
准备 Python 3 运行环境，安装 NumPy 用于重加权与自助法计算。
从零创建项目目录，用本地确定性样本生成器产出观测日志与内嵌多策略完整反馈矩阵的基准文件，样本与基准文件随仓库提供。
使用 Python 标准库 http.server 与 sqlite3 承载本地服务与结果存储，无需外部数据库服务；启动命令与服务端口在本地说明中给出。

业务要求：
1. 从历史观测日志的每条推荐曝光记录中解析出当次执行的策略版本与倾向得分，只保留倾向得分合法的曝光进入评估样本，并输出重加权所需的样本清单，对被丢弃的曝光给出可按原因聚合的统计。
2. 实现逆倾向得分与自归一化逆倾向得分两条估计路径，在给定新策略对被推荐样地的打分后，估计其反事实命中率点值，并保证自归一化版本在权重整体放大或缩小时结果不变。
3. 对每次策略比较输出新旧策略价值差与相对提升，用自助法给出置信区间，同时报告有效样本量、倾向得分最小值与权重最大值等诊断量，并把诊断量超阈值的比较标记为不可靠。
4. 提供倾向得分裁剪参数，当裁剪导致参与估计的曝光集合变化时，重算并保留裁剪前后两套估计结果，说明裁剪对偏差与方差的影响方向，使调用方可以对照选择。
5. 按样地与观测者两个维度分别做分层反事实评估，输出各组的新策略命中率估计与样本量，并识别出估计值显著低于旧策略的分组，标注为新策略的失效候选群体。
6. 构建本地 HTTP 接口与 SQLite 结果存储：提交评估请求后返回估计结果与分组报告，重复提交同一策略配置时能识别已有结果并返回一致内容，评估历史可按策略版本查询。
7. 用确定性构造的日志样本做自检，样本内嵌多策略完整反馈矩阵作为独立基准，报告离策略估计值与真实策略价值的偏差以及自助法置信区间对真实值的覆盖情况，并输出倾向得分随机化检查的结论。
8. 生成策略比较报告，汇总反事实命中率对比、提升幅度、置信区间、分组异质性、失效候选群体与不可靠标记，形成可直接用于推广决策的本地文本与结构化结果。

验收：
以完整反馈矩阵为基准核对离策略估计的偏差与置信区间覆盖率，并确认分组失效标注、不可靠标记与报告结果一致可复现。
