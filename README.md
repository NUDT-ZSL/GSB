在空白工作区从零实现一个本地 HTTP/2 多路复用连接的状态演进与恢复一致性诊断工作台，不依赖任何真实网络对端。连接行为由本地 JSON 场景脚本描述：脚本按可注入逻辑时钟给出帧级事件序列，包括 HEADERS、DATA、RST_STREAM、WINDOW_UPDATE、SETTINGS 及其 ACK、PING、GOAWAY；每条流声明流 ID、初始窗口、请求权重与期望的最终状态。工作台需实现多路复用连接的核心机制：同一连接上并发推进多条流，维护每流与连接两级的发送/接收窗口、流量控制额度分配、流状态机（idle、open、half-closed 及错误态）、CONTINUATION 与 HEADERS 分片、流优先级权重、重置与 GOAWAY 后的存活流收敛。全部状态演进需以不可分割的事务提交到 SQLite，使进程在任意帧处理后被强制终止时，恢复路径能依据持久化状态还原连接与各流状态，只重放未提交事件，不得出现连接级窗口与流级窗口账目不相符、已关闭流被复活或窗口额度被重复计入。用于验证的核心是状态推演结果与恢复结果的一致性，以及窗口账目在多次运行中的逐位可复现。

任务环境与准备：
安装 Python 3.11 及以上版本，并确认 sqlite3、asyncio、hashlib、json 标准库可用。
在空白工作区创建项目目录，题面所述的场景脚本、流声明与帧事件序列均使用本地生成的确定性 JSON 样本，不依赖外部网络或真实 HTTP/2 对端。
准备一个可重复的本地样本生成方式（如固定种子的脚本），使连接窗口、流初始窗口与事件序列在多次运行间保持一致。
确认具备强制终止本地进程的手段（如任务管理器或 kill 命令），用于触发中断恢复路径的验证。
所有运行、恢复与验证均在 Windows 本地执行，无需容器环境。

业务要求：
1. 实现场景脚本解析与连接初态构建：校验流 ID 单调且奇偶性符合发起方角色、初始窗口为正整数、权重在合法区间、事件逻辑时钟非降序、引用的流必须已声明、GOAWAY 最后一流 ID 不越界；非法脚本须返回明确业务错误码（如 E_BAD_SCENARIO、E_UNKNOWN_STREAM）且不写入任何持久化状态。
2. 实现连接级与流级双层流量控制账目：任一时刻已发送未确认字节不得超过 min(流发送窗口, 连接发送窗口)，WINDOW_UPDATE 只能增加对应层级额度且溢出上限必须被拒绝并返回业务错误码；每帧处理后输出两级窗口余额与可发送额度，累计账面必须可逐帧对账。
3. 实现流状态机演进：依据 HEADERS、END_STREAM、RST_STREAM 与 GOAWAY 驱动每条流在 idle、open、half-closed-local、half-closed-remote、closed 及错误态之间迁移；非法迁移（如已关闭流再次收 DATA、idle 流直接 RST_STREAM）必须被拒绝并记录原因，已进入 closed 的流不得因任何后续帧复活。
4. 实现 HEADERS 与 CONTINUATION 分片重组以及优先级权重调度：跨帧重组头部块并校验 END_HEADERS 标记，缺失或顺序错乱须映射到独立业务错误码；在连接发送额度受限时必须按流权重与已发送字节的确定性规则分配额度，同一输入多次分配序列逐位一致。
5. 实现基于注入逻辑时钟的帧处理与事务提交：所有窗口、状态与调度推进只依赖注入的逻辑时钟毫秒值，不读取系统墙钟；每处理一帧须把连接状态、全部流状态、两级窗口余额、逻辑时钟水位与帧摘要以单事务原子写入 SQLite，读取方只能看到帧边界上的完整一致快照。
6. 实现强制终止后的恢复一致性：进程在任意帧处理中途被强制终止后，恢复路径依据持久化状态识别已提交帧水位与半提交帧，只重放水位之后的帧且不重复计入任何窗口额度；恢复后必须重新构造出与未中断运行逐字段一致的连接与流状态，不得承诺生成可能不存在的退出报告。
7. 实现 RST_STREAM 与 GOAWAY 的收敛语义与幂等重放：RST_STREAM 后该流的在途窗口额度必须按规则回收至连接级且不得被该流再次占用，GOAWAY 后新流 ID 不得超过最后一流 ID 且已声明存活的流必须能推进到终态；对已提交帧的重复处理必须幂等，不得二次回收额度或二次迁移状态。
8. 提供命令行接口与一致性验证工具：支持 run、resume、status、verify 子命令，status 以稳定排序 JSON 输出连接窗口、每流状态、窗口余额与逻辑时钟水位；verify 校验持久化状态与推演轨迹摘要的一致性，使用固定本地样本连续运行两次（含一次中断恢复）输出结果完全一致。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本验证多路复用状态推演、两级窗口账目与强制终止后恢复结果的一致性，附运行输出。
