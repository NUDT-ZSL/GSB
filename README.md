当前是空白工作区，需要从零构建一个面向会议同传场景的本地语音活动区间编辑与回放应用，核心业务问题是语音活动区间的增量改写及其回放一致性。业务对象是本地用固定种子确定性合成的 16kHz 单声道 PCM：由若干段语音活动与静音按给定时间轴与增益拼接而成，叠加可配置平稳底噪，并附区间标注清单（JSONL，字段含 clip_id、segment_id、start_ms、end_ms、speaker_label、label_revision、confidence）与样本清单（字段含 clip_id、sample_rate、duration_ms、seed、frame_ms）。系统把一次分析建模为有向无环计算图：分帧包络统计→活动区间初判→区间边界精修→说话人归属标注→区间清单导出五个节点依次串联。当某区间标注被修正、底噪参数调整或帧移变化时，只有依赖这些输入的下游节点与被覆盖的时间区间需要重算，其余复用旧快照；每次导出的区间清单必须可按当时缓存键回放并逐项复现。全部计算只依赖固定种子、显式配置与本地样本。

任务环境与准备：
确认 Windows 上可用 Python 3.10 及以上版本，并安装 NumPy 与 pytest（仅用于本地样本与测试）。
在工作区新建项目目录，准备固定的全局随机种子约定与 16kHz 单声道 PCM 合成参数配置文件。
编写本地确定性样本生成脚本，产出样本清单、区间标注清单与 PCM 数据，全部落盘于本地样本目录。
准备本地快照目录与回放记录目录，确保可写可删，用于验证版本整体替换与损坏快照处理。
无需任何真实账号、外部服务、GPU 或线上数据。

业务要求：
1. 实现确定性的分帧包络统计节点：按 frame_ms 与帧移切分 PCM，帧边界以样本索引精确确定，计算逐帧短时能量与过零率并做可配置平滑，输出逐帧包络曲线与帧数；同一 clip_id、同一 seed 与同一配置下必须逐字节产出相同包络，帧数须与由 duration_ms 推算的帧数一致，不符返回 E_FRAME_MISMATCH 并指明 clip_id 与期望帧数。
2. 实现活动区间初判节点：以可配置分位估计底噪，按高低双门限滞回与最短静音间隔产出候选活动区间，同分或同能量时按起始样本索引升序打破平局；输出的区间必须按时间升序、互不重叠且落在音频时长内，违反分别返回 E_OVERLAP 与 E_OUT_OF_RANGE 并指明区间标识。
3. 实现区间边界精修节点：在候选区间两端按可配置搜索窗口与能量斜率规则细化起止毫秒，精修幅度不得超过搜索窗口，且精修后区间不得与相邻区间产生重叠或吞并另一区间；越界或吞并返回 E_REFINE_INVALID 并指明受影响区间标识与允许边界。
4. 实现说话人归属标注与区间清单导出节点：按区间内确定性声学统计量与受控说话人标签集合做归属打分，同分按 speaker_label 字典序、再按 segment_id 升序裁决，导出含起止毫秒、归属、置信区间与标注版本的区间清单；置信区间上下界顺序非法返回 E_INTERVAL_INVALID，标签不在受控集合返回 E_SPEAKER_UNKNOWN。
5. 实现按内容寻址的节点产物快照与缓存键构造：每个节点产物附带内容哈希落盘，键须纳入音频分块内容哈希、帧移与门限参数版本、区间标注修正版本及上游节点哈希；键相同必须复用快照，键不同必须重算，且每个快照条目必须能输出可读的键组成明细，损坏或校验和不符返回 E_CACHE_CORRUPT 并指明条目与版本。
6. 实现增量依赖失效传播：修正某区间标注、调整底噪分位或改变帧移时，计算受影响节点与受影响时间区间集合，复用未受影响上游快照，仅重算受影响后缀；须输出本次重算节点清单与复用节点清单，并保证局部修改后的导出清单与从零全量重算逐字节一致，否则返回 E_INCONSISTENT 并指出首个差异区间。
7. 提供区间清单回放能力与版本化整体替换：任一次导出的区间清单须记录所用缓存键与各节点输入版本，可据此回放并逐项复现起止毫秒、归属与置信区间，追溯链缺失或回放不符返回 E_LINEAGE_BROKEN；配置与快照携带单调递增版本号与内容校验和，变化时必须整体替换旧快照而非增量修补，旧版本不得覆盖新版本且回退尝试返回 E_SNAPSHOT_ROLLBACK。
8. 实现输入配置校验、资源上限、跨节点一致性自检及本地可交互应用：采样率非 16000、frame_ms 非法或帧移超过帧长、重复 clip_id、区间标注缺失 segment_id 分别返回结构化业务码；为驻留包络内存与快照条目数设可配置上限，超限返回 E_RESOURCE_LIMIT；自检校验帧覆盖无遗漏、区间首尾相接无重叠、复用集合与重算集合无交集且并集覆盖受影响集合；应用展示各节点状态、重算统计、回放查询与最近业务错误码。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
