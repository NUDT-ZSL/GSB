林区防火通信调度员要依靠巡护终端上报的日志评估信号覆盖与火险分布，但偏远林区的火险上报稀疏、热点区域的日志又极为密集，按区域、频段与时间窗口组合查询时，默认选择率让优化器频繁选错连接顺序与索引，巡护统计查询响应时快时慢。调度员与巡护终端管理员希望先得到一个本地可复现的基数估计内核：装载巡护员、终端、区域、频段与逐条巡护日志，依据统计摘要中的等深直方图与采样信息估算各连接结点的基数，给出连接顺序与索引候选建议，并把估计值与逐条扫描的真实连接行数对照，形成偏差可解释、摘要可更新的评估记录。

任务环境与准备：
准备 Linux（WSL Ubuntu）与 Python 3 运行环境，并安装 NumPy 用于直方图与选择率的数值计算。
题目从空工作区开始，需自行创建巡护日志与查询的固定种子生成器、估计内核入口和 SQLite 存储目录。
SQLite 通过 Python 标准库 sqlite3 以本地文件方式使用，无需外部数据库服务；运行前确认工作目录可读写。

业务要求：
1. 从巡护日志库中装载巡护员、终端、巡护路线与区域划分、通信频段与基站以及逐条巡护日志，校验统计摘要中记录的基表行数与直方图桶计数是否与基表一致，输出带表名、列名和失效原因的摘要失效清单。
2. 针对区域、频段与时间窗口三类谓词，按等深直方图桶边界与采样行数计算单谓词选择率，给出命中桶区间、桶内均匀假设下的部分覆盖比例及最终选择率数值。
3. 对区域与频段的多谓词连接，分别在属性独立性假设和区域频段组合直方图两种口径下修正联合选择率，并逐连接结点累乘基数，输出每个结点上的估计基数与所用口径标记。
4. 在连接键值域重叠程度上修正结点基数，依据修正后基数与连接键值域重叠程度比较候选连接顺序与索引候选的代价，输出推荐连接顺序及每条索引取舍的理由说明。
5. 对每条查询逐条扫描完成真实连接，按连接语义统计实际行数，输出估计基数、真实行数、相对偏差以及首个偏差超过阈值的连接结点标识。
6. 基于偏差清单判定需要重建直方图的列与需要新建的区域频段组合统计，生成摘要更新建议，并在应用更新后重算同一批查询估计，核验偏差整体收敛。
7. 将巡护日志与查询按固定种子确定性生成，构造偏远区域稀疏上报与热点区域密集上报并存的偏斜分布，使生成结果在多次运行中逐字节一致且不依赖任何线上数据源。
8. 把每次评估的统计摘要版本、逐结点估计、真实行数与偏差原因持久化到 SQLite 快照，支持按版本回看并在摘要更新前后对比同一查询的估计变化。

验收：
以手工构造的小型巡护日志与直方图摘要独立核对逐结点基数估计，并以逐条扫描真实行数验证偏差清单与更新后的偏差收敛。
