在空白工作区构建一个面向本地确定性样本的跨语言相关性检索管线，用于中英混合查询与文档之间的相关性建模。输入为一个本地样本目录：多语言文档库 JSONL（每行含文档 ID、语言标签、标题与正文字段，文本由固定种子程序从受控中英词表生成）、查询集 JSONL（每行含查询 ID、查询文本与语言标签）、一份跨语言翻译对照表（中英词项对及对齐置信度）、一份相关性标注真值文件（查询 ID 与文档 ID 的相关等级），以及一份管线配置 JSON（分词与归一化规则、语言识别开关、翻译桥接权重、BM25 参数、相关性打分融合权重、分批大小、快照提交间隔与并发数）。管线需完成文本归一化与语言识别、单语与跨语言检索、相关性打分融合、结果评估，并输出可验证的诊断报告。核心约束是状态演进与恢复一致性：管线可在任一批次被中断或参数被修订，重启或续跑后最终检索结果与评估指标必须与不中断运行完全一致，且不得重复或遗漏批次。

任务环境与准备：
Windows 本地环境，安装 Python 3.10 及以上版本与 NumPy，无需数据库、网络服务或外部账号。
在空白工作区创建项目目录，按题目约定生成文档库 JSONL、查询集 JSONL、翻译对照表、相关性真值文件与管线配置 JSON，文本由固定随机种子的本地脚本生成。
准备用于异常注入的独立配置样例与恢复验证脚本，确认可触发退出信号与配置哈希不一致两类路径。
运行入口与报告输出路径在项目内约定，确保所有产物写在本地目录下，不依赖额外附件或下载数据。

业务要求：
1. 实现文档与查询加载及归一化层：读取文档库、查询集与翻译对照表，校验文档 ID 与查询 ID 唯一、语言标签在配置枚举内、字段非空，并按配置做大小写折叠、全半角折叠与空白合并；不合法条目输出 E_RECORD_INVALID 并记录文档或查询标识、阶段名与条目索引后继续处理。
2. 实现语言识别与单语倒排检索：对每条文本依据词表脚本分布与翻译对照表覆盖率判定语言并输出判定依据；按语言建独立倒排索引与文档频率统计，使用可配置 BM25 参数在查询同语言文档上检索，同分按文档 ID 字典序决断，输出候选文档、分项得分与命中词项。
3. 实现跨语言检索桥接：对查询中的未对齐词项，按翻译对照表中的词项对与对齐置信度生成跨语言扩展词项，扩展得分按翻译桥接权重衰减后并入检索得分；同一词项存在多个翻译时按置信度降序、词项字典序决断并记录被抑制翻译；扩展词项须标记来源，不得与原生词项混淆。
4. 实现相关性打分融合与阈值判定：将单语得分与跨语言扩展得分按配置融合权重合成相关性得分并做稳定归一化，按相关等级阈值判定预测等级；融合分相同按单语得分、再按文档 ID 字典序决断；输出每个查询的排序结果、分项得分分解与预测等级，供后续评估使用。
5. 实现分批执行与阶段快照：将归一化、索引构建、检索打分、评估划分为阶段，按配置分批大小执行，每批完成时以临时文件加原子替换方式持久化快照，快照含阶段名、配置哈希、翻译表哈希、已完成批次号、部分结果摘要与版本号。
6. 实现恢复一致性判定：启动时读取最新快照并校验版本号、配置哈希与翻译表哈希，不一致输出 E_CONFIG_MISMATCH 并拒绝续跑；一致时从已完成批次之后继续，恢复后的检索结果、评估指标与中断前未发生时不中断运行的结果逐字段一致，且批次不重复不遗漏。
7. 实现并发检索与串行结果一致性：使用线程池并发处理查询批次，最大并发数取自配置；每个查询任务携带由查询 ID 与阶段名派生的稳定排序键，无论线程调度顺序如何，最终查询结果顺序、候选文档顺序、翻译抑制清单与失败清单顺序必须与单线程按查询 ID 顺序执行完全一致。
8. 实现异常隔离、可处理退出与评估报告：单条查询或文档在任一阶段抛异常时记录标识、阶段名、业务码与异常类型并继续其余项；收到可处理的退出信号时完成当前批次快照提交后以整数退出码 0 退出；每次完整运行输出 JSON 报告，含各相关等级精确率与召回率、平均融合得分、复用与失效条目数、快照版本号、配置与翻译表哈希及失败清单，报告以原子替换方式写盘。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
