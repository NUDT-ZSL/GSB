需要为面向科技文献的中文 NLP 流水线构建一个可集成的分词与词性标注组件，重点解决数值精度与误差传播问题。输入为本地 UTF-8 文本，以及一份词典文件和一份词性表：词典条目包含词形、粗粒度词性、对数频率权重；词性表声明合法词性集合与相邻词性的转移权重。另有若干本地标注语料用于评估，每条标注含句文本、词的字符区间与词性。组件需实现基于词典的前向最大匹配与一元语言模型打分的融合切分，再对切分结果做词性序列解码，输出词边界、词性、逐词置信度与句级不确定度，使下游能判断是否回退到规则结果。全部计算在进程内完成，不依赖线上模型、网络或预训练权重。工作区为空白，从新项目开始创建，需提供可集成的模块与可直接运行的完整示例。

任务环境与准备：
在 Windows 上安装 Python 3.11 与 NumPy，创建本地虚拟环境，全程离线运行。
准备本地 UTF-8 词典文件（词形、词性、对数频率权重）、词性表（标签集合与转移权重）与小型标注语料，随项目放在本地目录。
约定输出 JSON 结构、配置项与业务码常量，用 Windows 命令行运行示例与评估入口。

业务要求：
1. 组件须提供分词接口与词性标注接口，输入为单句字符串和加载后的词典、词性表对象；输出按起始字符下标升序排列的词序列，每项含词形、起止字符下标（按 Unicode 字符计数而非字节）、词性标签与来源标记，空文本返回空列表而非抛异常。
2. 切分须同时生成前向最大匹配候选与基于词典对数频率的一元语言模型最优候选，并按可配置融合权重做统一打分选择；两种候选的分数与最终来源标记须在结果中可查询，同一输入与配置下输出必须完全可重复。
3. 所有路径概率计算须在对数域累加，禁止直接连乘；词典中不存在的词使用可配置平滑项参与打分，平滑项取值须保证任何候选的对数分数为有限实数，配置越界或非有限值时返回 E_PARAM 且不产生部分结果。
4. 词性标注须基于切分结果与词性转移权重做序列解码，输出每词一个标签；对词典未收录词须回退到字符模式规则与默认词性，回退次数与涉及字符区间须在结果统计中给出，缺失词不得导致整句失败。
5. 每个输出词须附带置信度，定义为该词在融合候选集合上的归一化后验；置信度须在整句范围内构成有效概率分布，用 log-sum-exp 计算避免下溢，归一化误差超过配置容差时返回 E_PRECISION 而非静默输出。
6. 误差传播须显式输出句级不确定度：由逐词置信度的对数损失按句累加，并结合词性转移链上的条件概率传播；句级分数与逐词超阈标记须同时给出，超阈词须能定位到具体字符区间。
7. 须提供评估入口：给定本地标注语料计算分词边界 F1 与词性准确率，并按置信度分桶统计误差率与覆盖比例；分桶边界由配置给出且互不重叠，同一输入重复运行的统计结果须完全一致。
8. 词典格式错误、词性表缺失标签或标注语料字符区间越界时，须分别返回 E_DICT、E_TAG、E_LABEL 业务码并给出出错的行号或区间，且不得写出任何结果文件；正常输出与错误输出须共用同一 JSON 结构约定。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
