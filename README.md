在全新工作区中，需要从零构建一个面向表格与图表结构化的数据处理管线与结果验证工具，核心业务问题是增量更新与依赖失效。业务对象是本地确定性生成的图表图像样本：每张图由固定种子在固定尺寸画布上绘制带坐标轴的折线图或柱状图，图中数据点或柱体的像素位置、真实数值与轴范围同时以真值清单给出；管线把一次结构化解析建模为多阶段计算图：图像解码与坐标轴定位→刻度识别与数值标定→数据点定位→序列归属与排序→结构化输出与指标聚合。用户会以增量方式修正部分真值标注、替换某图的图像种子或调整识别参数，要求仅重算受影响的部分并保证结果可复现。

任务环境与准备：
安装 Python 3.11 及以上版本，并安装 NumPy 1.26 及以上版本（可用 pip install numpy）。
在全新工作区创建项目目录，无需任何外部数据集或网络服务。
准备本地确定性样本生成脚本，使用固定随机种子生成图表真值清单与画布像素。
在 Windows 上验证命令行入口可执行，缓存目录使用 workspace 内相对路径。

业务要求：
1. 实现确定性的坐标轴定位与刻度识别阶段：从固定种子生成的画布像素中定位坐标轴与刻度线像素位置，输出刻度列表及其像素坐标，同一 chart_id、同一输入与同一配置下必须逐字节产出相同刻度集合，同分时按像素坐标升序、再按刻度序号升序打破平局，刻度像素越界或轴范围非正时返回 E_AXIS_INVALID 并指明 chart_id 与刻度序号。
2. 实现像素到数值的线性标定与数据点像素定位阶段：用刻度像素与真值刻度值拟合线性映射并应用到数据点像素定位结果，输出每个数据点的反算数值；须显式声明斜率截距求解的精度口径与数值域裁剪规则，禁止在未记录口径的情况下对反算值做截断，标定残差超出容差返回 E_CALIBRATION_DRIFT 并输出残差最大的前若干个刻度。
3. 实现内容寻址缓存与缓存键构造：刻度定位、标定拟合、点定位、数值反算各节点产物附带内容哈希写入本地缓存目录，缓存键须纳入图表图像内容哈希、轴范围、序列数、识别参数版本与上游节点哈希；键相同必须复用快照，键不同必须重算，并提供入口按 chart_id 查询键组成与产物哈希以核对复用是否真实发生。
4. 实现增量更新的依赖失效传播：修正单张图的真值标注、替换图像种子或调整识别参数时，计算受影响节点与受影响 chart_id 集合，复用未受影响上游缓存，仅重算受影响后缀；须输出本次重算节点清单与复用节点清单，并保证局部修改后的结果为未受影响产物与全部重算产物的确定性组合，而非整体重建。
5. 实现结构化输出与逐级误差传播计算：以真值清单中的 value 作为观测口径，输出刻度定位、标定拟合、点定位、数值反算各级的绝对偏差、相对偏差、误差区间与误差放大比，并定位主导误差来源为刻度定位、标定或点定位中的哪一级，使最终结构化输出可由各级明细独立重算一致。
6. 实现数值排序与门限判定的稳定性保护：对反算数值设定可配置的最小可信门限与序列内排序，提供严格比较与容差带比较两种策略及次正规数保护，保证恰好落在门限附近的数据点在重复运行下判定不被舍入翻转；门限或容差配置非法时返回 E_CONFIG_INVALID 并指明字段。
7. 实现结果快照的版本化与整体替换并实现并发提交控制：结构化输出、标定参数与误差统计快照各携带单调递增版本号与内容校验和，提交时整体替换旧快照而非增量修补，检测到版本号或校验和变化时必须整体替换，损坏或校验和不符返回 E_SNAPSHOT_CORRUPT 并指明快照类别与版本号；同一时刻只允许一次增量提交生效，并发冲突时后到者立即获得 E_STAGE_BUSY 而不阻塞等待。
8. 实现结果验证工具与跨模块一致性自检：独立复核各阶段 chart_id 集合一致、缓存键与产物哈希互相可核对、重算集合与复用集合无交集且并集覆盖全部受影响集合、结构化输出的数据点可由标定参数与像素坐标独立复算一致；自检不一致返回 E_INCONSISTENT 并输出首个偏差位置，且验证工具须能重放任一 chart_id 的增量前后结构化输出。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

使用本地样本验证增量重算范围正确、结构化输出可复算且快照版本整体替换与异常码一致。
