当前为空白工作区，没有现存项目、代码或数据。需要从零构建一个面向低精度与量化卷积算子的本地数据处理管线与结果验证工具，核心业务问题是权重量化参数与校准统计在增量更新时的依赖失效。业务对象是本地确定性生成的量化卷积任务清单（JSONL，字段含 job_id、input_shape（N,C,H,W）、kernel_shape（K,C,Kh,Kw）、stride、padding、quant_scale、zero_point、acc_dtype、weight_revision、calib_revision、seed、block_size），激活与卷积核由 seed 驱动 NumPy 确定性生成浮点数组，并按 quant_scale 与 zero_point 量化为 int8 输入。每个卷积任务被建模为有向无环计算图：量化输入准备→权重量化→分块定点乘加与 int32 累加→累加器归约与反量化输出。当某任务的权重量化参数或校准统计以更高版本到达时，只有依赖这些参数的下游节点与相关 job 区间应收影响并重算，其余产物必须复用。管线需提供内容寻址缓存、失效传播报告、以 float64 反量化路径为真值的偏差谱，以及跨节点一致性自检。

任务环境与准备：
安装 Python 3.10 及以上版本，并确认 numpy 已安装且可导入（pip install numpy）。
在空白工作区创建项目目录并准备本地确定性样本生成脚本，样本仅由固定种子与配置文件生成，不依赖任何外部数据集或网络。
确认命令行可执行 python 与项目入口脚本，缓存与快照目录可由配置指定并位于本地可写路径。

业务要求：
1. 实现量化输入准备与低精度分块卷积核心：按 quant_scale 与 zero_point 完成激活与权重的量化与反量化，支持 int8 乘加与 int32 累加器，并支持可配置的按块累加与偏差补偿；同一 job_id、同一 seed 与同一配置下逐字节产出相同的量化输入、反量化权重与卷积输出。
2. 构建量化输入准备、权重量化、分块乘加累加、归约反量化四个节点的内容寻址缓存，缓存键须纳入输入张量内容哈希、quant_scale 与 zero_point、acc_dtype、block_size 与上游节点产物哈希；键相同必须复用，键不同必须重算，且每个缓存条目可按键独立重放。
3. 实现权重量化参数与校准统计以更高版本到达时的依赖失效传播：区分仅权重量化参数变化（影响权重量化节点及其下游）与仅校准统计变化（影响归约反量化节点）两类情形，计算受影响节点与受影响 job 集合，复用未受影响上游缓存，仅重算受影响后缀并输出重算与复用清单。
4. 以 float64 反量化路径为该快照的参考真值，输出量化输入、定点乘加、累加器归约、反量化输出各级的最大绝对偏差、相对偏差、偏差分位数与误差放大比，并定位主导误差来源级别；超出容差返回 E_TOLERANCE_EXCEEDED，并给出首个越界元素位置与偏差量。
5. 实现旧结果追溯与过期结果拒绝：任一卷积输出须记录所用缓存键、权重量化版本与校准版本，可按记录重放出相同输出；当缓存键任一依赖版本已变化而结果仍来自旧键时返回 E_STALE_RESULT 并指出 job_id 与版本差异，追溯链缺失返回 E_LINEAGE_BROKEN。
6. 实现并发提交控制与资源上限：同一时刻只允许一次增量提交生效，冲突时后到者立即获得 E_STAGE_BUSY 而不阻塞等待；为单次重算 job 数、分块驻留内存估算与并行重算节点数设可配置上限，超限返回 E_RESOURCE_LIMIT 或降级到更小分块并标记降级类别。
7. 实现输入与配置校验链路：重复 job_id、input_shape 维度不符、quant_scale 非正、zero_point 越界、acc_dtype 不支持、weight_revision 回退分别返回结构化业务码并指明 job_id 与字段；单个任务校验失败须归因到具体节点且不得静默丢弃其他任务。
8. 实现结果验证工具与跨模块一致性自检：独立复核每个节点缓存键可还原产物、四节点处理的 job_id 集合完全一致、重算集合与复用集合无交集且并集覆盖全部受影响集合；不一致返回 E_INCONSISTENT 并指出节点与 job_id，命令行输出含失效报告与偏差谱的 JSON。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
