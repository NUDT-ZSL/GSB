某安全团队需要在离线 Windows 空白工作区从零开发一个文件系统权限与路径检查审计引擎，用于对本地确定性构造的路径与权限声明清单做越权风险检测。输入是一批本地 JSON 清单文件：每条记录声明一个受检对象的标识、目标路径（可能含点段、父目录段、长名段、Unicode 规范化变体与大小写变体）、路径上的符号链接与硬链接声明、访问主体、操作类型（读、写、执行、删除），以及权限数值表示——权限位以整数位掩码或八进制字符串两种口径给出，另含一组 ACL 条目（主体、允许或拒绝、权限掩码、继承标记）与路径比较所用的规范化策略参数。工作区须重建每条记录的路径规范化结果与权限有效值，判定路径穿越、权限位口径混用导致的越权、拒绝项被允许项覆盖、继承传播偏差等问题，并把路径与权限判定中的数值误差（位掩码解析偏差、八进制舍入口径、路径比较的编码误差传播）量化输出。核心难点在于：权限数值在多种口径间转换时存在精度与舍入偏差，这种偏差会沿 ACL 继承与父目录权限传递链传播，而路径规范化又会因 Unicode 与大小写口径改变比较结果，两者耦合导致同一记录在不同规范化策略下得出不一致的越权结论；必须给定观测、同步标记与真值来源，使结论可复核。

任务环境与准备：
Windows 工作站，安装 Python 3.10 及以上版本，并将 python 与 pytest 加入 PATH；建议使用独立虚拟环境 venv。
安装 pytest（如 pip install pytest），全部依赖在本地离线可获取，不访问任何网络站点、账号或外部数据集。
在空白工作区创建项目根目录，预留样本生成目录、检查点目录与报告输出目录；工作区须位于 NTFS 卷以支持文件锁与临时文件原子重命名。
确认工作区可创建符号链接与硬链接（如 Windows 开发者模式或具备创建符号链接权限的账户）；若环境不允许创建真实链接，样本中的链接声明仅作为路径解析输入参与判定，不依赖实际文件系统链接对象。
生成器与测试全部使用本地确定性样本，不使用系统当前时间作为真值来源。

业务要求：
1. 实现路径与权限清单的解析规范化层：逐条解析本地 JSON 清单，校验目标路径语法、主体标识唯一性、操作类型取值在读写执行删除白名单内、权限数值表示口径标记只能为整数掩码或八进制字符串，对非法记录输出含记录序号与业务错误码 E_PARSE 的拒绝记录并继续处理其余记录，不得中止整批。
2. 实现路径规范化比较模块：按可配置规范化策略（是否折叠大小写、是否做 Unicode NFC 规范化、是否解析符号链接）把目标路径转为规范比较键，并单独量化每一步变换引入的比较误差传播来源（编码归一化差异、大小写折叠差异、链接解析步数），对含父目录段回退或绝对路径越出受检根目录的记录返回 E_TRAVERSAL 并给出越界深度。
3. 实现权限数值口径转换与误差界推导：对整数位掩码与八进制字符串两种口径统一解析为规范化权限位，按八进制字符串解析规则给出舍入与截断误差上界，并沿父目录权限与 ACL 继承链累计传播误差界；当累计误差界跨越允许与拒绝的判定阈值时须显式标记为临界不确定，不得直接给出确定越权结论。
4. 实现 ACL 有效权限裁决：按主体匹配、允许与拒绝项、继承标记计算每个主体的有效权限，检测拒绝项被同级或更近的允许项覆盖的情况返回 E_DENY_SHADOW，检测继承标记使子路径获得父路径未授权权限的传播返回 E_INHERIT，并保证同一 ACL 集合在任意条目排列顺序下有效权限与违规清单完全一致。
5. 实现路径穿越与链接跳转的越权判定：依据规范化比较键与链接声明重建实际可达路径，识别经符号链接或硬链接跳转后落点超出受检根的记录返回 E_LINK_ESCAPE，识别同一路径在不同规范化策略下结论不一致的冲突记录返回 E_POLICY_CONFLICT，并列出冲突所涉策略组合。
6. 实现基于同步标记的真值对照机制：本地确定性样本生成器在清单内显式记录每条记录发送端的原始权限数值、原始路径字节、同步标记与预期误差界区间，验证模块只依据这些同步标记与规范化结果比对，不得把生成器的中间计算结果当作真值；报告须给出观测一致计数与不一致明细。
7. 实现真实资源预算与并发审计：并发度、单文件实测耗时上限与单文件处理记录数上限均可配置，耗时以真实墙钟测量判定而非人为延迟，超时返回 E_TIMEOUT 且以真实机制终止该文件后续处理，超记录数返回 E_BUDGET；任意并发度下每记录的越权结论与违规清单须与串行执行完全一致，被超限终止的文件不得中断同批其余文件。
8. 实现检查点演进、原子报告与强制终止边界：按已完成文件标识与聚合审计状态持久化检查点，恢复时只从最后一个完整检查点继续，检测到检查点结构版本或规范化策略版本变化时整体重建而非增量续接；检查点与 JSON 审计报告均先写临时文件再整体重命名替换，报告含文件级结论、每记录路径规范化键、有效权限、业务错误码、误差界与临界标记；同一工作目录并发写检查点须以文件锁串行化并在冲突时返回 E_LOCK，进程被强制终止后不承诺生成退出报告。附加确定性样本生成器与 pytest 测试集覆盖穿越、链接逃逸、口径混用、拒绝覆盖、继承越权、策略冲突、超时与超预算、并发等价与中断恢复，断言业务码、误差界方向与退出码。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地确定性样本验证路径规范化、权限误差界传播与越权判定在各并发度下一致，并核对异常码与恢复边界。
