当前是空白工作区，没有现存项目、代码或数据附件，需要从零构建一个面向跨文档事件共指链构建的本地可视化与诊断工作台。业务对象是本地确定性生成的多文档事件集合：每篇文档由固定种子从受控词表与实体词典拼装句子，句中标出实体提及、事件触发词与论元，事件以局部编号在同一文档内唯一；跨文档层面需要把指同一现实事件的局部事件聚成共指链，链携带跨文档证据（共享论元实体、共享时间表达式、触发词词形相似度与文档来源可信度）。核心业务问题是：新文档到达时只对受影响的共指链做增量合并，而合并可能引发链间冲突（同一事件被并入两条链）与链内论元矛盾，必须在不重建全量链的前提下仲裁并给出可追溯的仲裁记录。工作台需要展示共指链拓扑、增量合并与冲突仲裁、论元证据谱与最近业务错误码。

任务环境与准备：
确认 Windows 本地已安装 Python 3.11 及以上，并可用 pip 安装 NumPy 与 Flask（离线环境可改用自带 venv 内已安装版本）。
创建空白工作目录，准备固定种子的文档与实体词典生成脚本及受控词表文件，所有样本在本地确定性生成，不依赖真实数据集或外部服务。
在工作目录内创建本地持久化目录用于快照与仲裁记录，确认进程可写并在启动前清空空目录状态。
以本地回环地址启动 Flask 工作台，浏览器访问同一端口完成演示，不配置任何外网依赖。

业务要求：
1. 实现确定性的文档解析与局部事件抽取层：按固定种子与受控词表生成文档句子，抽取带码点起止偏移的实体提及、触发词与论元，事件以文档内局部编号标识；同一文档集与同一种子必须逐字节产出相同的局部事件集合，同分或同偏移时按文档内局部编号升序裁决，偏移越界或触发词重复占用返回 E_SPAN_INVALID 并指明文档与事件编号。
2. 实现跨文档事件相似度打分与候选共指对生成：由共享论元实体、共享时间表达式、触发词相似度与来源可信度组合成相似度，并记录各分项贡献使总分可由明细独立重算一致；为每个局部事件只生成相似度不低于配置下限的候选对，同分时按文档序号与局部编号升序打破平局，下限非法或权重含负值返回 E_CONFIG_INVALID 并指明字段。
3. 实现共指链的增量合并：新文档到达时只对与新增事件存在候选对的既有链做合并判定，未涉及新增事件的链必须复用既有链状态而不得重建；合并须保证每个局部事件恰属于一条链、链内事件集合按首次出现顺序可复现，违反单归属或重复归属分别返回 E_CHAIN_DUP_MEMBER 与 E_CHAIN_MISSING。
4. 实现链间冲突仲裁与链内论元矛盾裁决：当同一局部事件被候选并入两条链时按链证据强度、链规模与首次出现顺序的显式优先级仲裁，输出被拒绝的并入方向与仲裁理由；同一链内同一论元角色出现取值冲突时按证据贡献与来源可信度选出胜出论元并保留落选论元明细，无法裁决时返回 E_ARBITRATION_UNRESOLVED 并列出争用证据。
5. 实现增量合并的一致性自检：校验增量结果与在全部文档上一次性全量重建的共指链在链成员集合与链间仲裁结论上一致，并输出首次偏差所在链与事件；同时校验候选对集合可重算出合并与仲裁所用全部证据，任何局部事件不得遗漏候选扫描，不一致返回 E_INCREMENTAL_DRIFT 并定位文档与链编号。
6. 实现增量产物的内容寻址缓存与失效传播：局部事件、相似度分项、链状态各自以内容哈希落盘，缓存键须纳入文档内容摘要、受控词表版本、相似度权重版本与上游产物哈希；修正文档句子、调整相似度下限或更新可信度表时计算受影响链集合与受影响候选对，仅重算受影响后缀并输出重算链清单与复用链清单。
7. 实现链状态与仲裁记录的版本化快照及整体替换：链状态、可信度表与仲裁记录各携带单调递增版本号与内容校验和，检测到版本号或校验和变化时必须整体替换旧快照而非增量修补，旧版本不得覆盖新版本，回退尝试返回 E_SNAPSHOT_ROLLBACK，损坏或校验和不符返回 E_SNAPSHOT_CORRUPT 并指明快照类别与版本号。
8. 实现资源上限、并发提交控制与本地诊断工作台：为单文档事件数、候选对比较次数与驻留链状态内存估算设可配置上限，超限时返回 E_RESOURCE_LIMIT 或降级为只合并不低于更高相似度的候选对并标记降级类别；同一时刻只允许一次增量提交生效，并发冲突时后到者立即获得 E_STAGE_BUSY 而不阻塞等待；工作台展示共指链拓扑、增量合并与冲突仲裁明细、论元证据谱、重算与复用链清单、快照版本与最近业务错误码，并允许触发一次含冲突仲裁与一次含降级的演示。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地文档样本验证增量合并、链间冲突仲裁与全量重建一致性，并附运行报告。
