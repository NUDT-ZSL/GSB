博物馆数字展陈团队需要为馆藏文物制作短循环展示动画，展陈脚本用自然语言描述动作，如“缓慢旋转一周”“沿水平轴来回摆动”。动画师需把描述转为模型运动轨迹与相机环绕关键帧，并保证不越出展柜边界、不穿模。现有流程依赖人工在三维软件中手动调关键帧，方向、幅度、周期常与脚本意图不符，且相机运动与模型运动节奏脱节。本题要求构建本地工作台：解析脚本中的动作语义为结构化参数，结合文物包围盒与展柜约束求解可行运动范围，用样条插值生成模型轨迹与同步相机环绕动画，输出关键帧序列、运动摘要及与脚本的核对报告。输入包括文物顶点与面片数据、材质分区、脚本条目、相机视角与画面比例约束；输出为可嵌入播放器的关键帧动画片段及逐条动作的参数解析结果。

任务环境与准备：
在WSL Ubuntu上准备Python 3.10+运行环境，使用pip安装NumPy与Flask，无需数据库或外部服务。
工作区为空目录，从零创建项目；样本数据由本地脚本生成：构造一个简化的文物模型OBJ文本文件（顶点、面片、材质分区），展陈脚本为JSON或文本行数组，展柜边界与相机约束以JSON配置提供。
运行入口为Flask应用，通过HTTP接口提交模型与脚本，返回JSON响应；另提供命令行脚本用于批量生成样本与运行核对。

业务要求：
1. 从展陈脚本文本中逐条抽取动作方向（如绕Z轴旋转、沿X轴平移）、幅度范围（角度或距离）、周期时长与缓动类型（线性、缓入缓出、正弦），输出结构化JSON解析结果，每条脚本对应一个动作对象，包含原始文本与解析出的字段，方向与缓动类型限定为预定义枚举值。解析需依据脚本中的关键词与数值修饰语，不得依赖外部模型或网络接口。
2. 读取文物模型的顶点数组与面片索引，计算轴对齐包围盒及材质分区顶点子集，再结合展柜边界（矩形空间范围）与脚本解析出的幅度，求解每个动作的实际可用运动范围：当描述幅度导致模型越界时，按包围盒与边界的最小间隙等比压缩幅度，并标记该动作的边界约束状态与调整前后幅度值，输出到约束求解记录。
3. 根据解析出的运动属性与约束后的幅度，为每个动作生成模型轨迹关键帧序列：旋转动作绕指定轴在周期内按缓动曲线插值角度，平移动作沿指定轴按缓动曲线插值位置，展开动作按材质分区沿法向外扩。关键帧时间戳按固定帧率等间隔分布，每个关键帧存储模型各顶点的变换后位置或变换矩阵、时间戳与缓动进度值，方向需与脚本描述一致。
4. 为每个模型动作同步生成相机环绕动画关键帧：相机在展柜外部沿以模型中心为圆心的圆弧运动，半径根据视角约束与画面比例计算，高度与俯仰角满足展陈视角要求，且相机视锥不与模型包围盒相交。相机关键帧时间戳与模型轨迹对齐，输出相机位置、朝向四元数及视场角。
5. 对生成的模型轨迹与相机轨迹逐关键帧做速度连续性与加速度平滑检查：计算相邻关键帧间的速度与加速度，统计最大速度、最大加速度与超出预设平滑阈值的帧数，输出平滑度指标。对超阈值片段采用时间重采样修正：在不改变动作总周期的前提下调整局部时间步长并重新插值关键帧，使速度与加速度回到阈值内，输出修正后的轨迹与原轨迹的对比摘要。
6. 同一脚本输入重复生成时，输出的关键帧序列（含模型顶点位置、相机位姿）必须逐帧数值一致（浮点按固定精度比较），并生成运动摘要报告，包含每条动作的方向、约束后幅度、周期、边界占用比例（模型包围盒在展柜空间中的体积占比）与平滑度指标。摘要报告以JSON格式供展陈播放器读取。
7. 构建独立动作语义核对检查：从生成的关键帧轨迹反算方向主轴、实际幅度与周期，与脚本文本解析结果比较，当方向偏差超过15度、幅度相对误差超过5%或周期相对误差超过2%时，在核对报告中标记该片段为偏差超阈值，并列出期望值与实测值。核对过程不得复用生成阶段的中间参数，须从关键帧数据重新计算。
8. 提供本地HTTP服务接口，接收文物模型数据、脚本文本、展柜边界与相机约束，返回关键帧动画片段（JSON格式含模型轨迹与相机轨迹）、解析结果、运动摘要与核对报告；对脚本中无法解析的动作描述返回业务错误码（如E_UNPARSED）并在响应中指明条目索引，服务须能处理合法与非法输入并保持状态独立。

验收：
用人工标注方向、幅度、周期与缓动的展陈脚本集运行工作台，检查关键帧轨迹在方向、幅度、周期上的偏差是否在阈值内，相机是否不穿模，重复生成是否一致。

## 实现交付

本工作区已实现完整本地工作台，代码位于 `museum_anim/` 包与 `app.py`：

- 运行说明见 `USAGE.md`；依赖见 `requirements.txt`。
- HTTP 入口：`python3 app.py`（`/health`、`/api/parse`、`/api/animate`）。
- 命令行：`python3 -m museum_anim.cli generate|run|check-determinism|acceptance`。
- 自动化测试：`python3 -m unittest discover -s tests`。
- 人工标注验收集：`museum_anim/labeled_dataset.py`，核对逻辑 `museum_anim/acceptance.py`。
