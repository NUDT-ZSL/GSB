当前是空白工作区，需要从零构建一个面向音频事件检测（AED）场景的可集成领域组件与完整示例，核心业务问题是数据规模变化下的算法取舍。业务对象是本地确定性合成的多说话人对话音频：用固定种子生成若干说话人的基频、共振峰与能量包络参数，按给定对话时间轴与增益叠加为 16kHz 单声道 PCM，并注入若干类音频事件（如敲门、咳嗽、键盘敲击、笑声），每类事件由确定性波形模板拼出，伴随逐帧真值文件（帧长 20ms，字段含 frame_index、event_id、event_type、speaker_id、is_speech）与对话清单（JSONL，字段含 dialog_id、sample_rate、duration_ms、modality_mask）。组件需完成帧级声学特征提取、事件候选检测、事件类型分类与事件时间段后处理，并针对不同数据规模在精细路径与逼近路径之间自适应选择，输出可复现的检测结果与取舍记录。

任务环境与准备：
安装 Python 3.10 及以上版本，并安装 NumPy 1.24 及以上版本（pip install numpy）。
确保工作区可写，用于生成合成音频样本、逐帧真值文件和输出 JSON 报告。
无需外部音频文件、模型权重或网络服务，所有样本由固定种子在本地确定性生成。

业务要求：
1. 实现确定性的帧级声学特征提取层：按配置的帧长与帧移切分 PCM，帧边界以样本索引精确确定，计算短时能量、过零率、谱质心与谱滚降，输出逐帧特征矩阵与帧数；同一 dialog_id、同一配置与固定种子下必须逐字节产出相同特征序列，帧数须与逐帧真值文件一致，否则返回 E_FRAME_MISMATCH 并指明 dialog_id 与真值帧数。
2. 实现基于确定性波形模板的事件候选检测与类型分类：对每个帧窗口计算候选事件得分，同分时按事件类型编号升序、再按帧索引升序打破平局，输出候选事件列表（含起止帧、类型、置信度）；须校验事件类型来自受控集合、起止帧落在 [0, 帧数) 内，违反分别返回 E_EVENT_TYPE、E_EVENT_RANGE 并指出 dialog_id 与事件位置。
3. 实现事件时间段后处理：对候选事件按最短事件时长与最短间隔合并，输出毫秒级 start_ms/end_ms 列表，保证按时间升序、互不重叠、落在音频时长内；违反分别返回 E_OVERLAP 与 E_OUT_OF_RANGE 并指出 dialog_id 与区间。
4. 实现基于数据规模的自适应算法取舍器：按对话数、总帧数、平均每帧事件候选数、说话人数与特征维度在精细路径（高维特征、短帧移、迭代分类、精确后处理）与逼近路径（降维特征、长帧移、单遍分类、阈值后处理）之间选择，输出含决策依据的规模观测与所选路径；同一观测下决策必须逐字节一致，且所选路径必须覆盖全部帧与对话。
5. 实现帧级与事件级指标计算：以逐帧真值计算帧级事件准确率与召回率，以重叠比阈值判定事件级命中，输出混淆统计与逐事件判定明细；指标必须可由逐帧判决与逐事件明细独立重算一致，不得使用未记录口径的平滑或截断。
6. 实现精度、内存与比较次数的冲突裁决：当精细路径提升事件召回但逼近驻留内存上限、候选比较次数预算或帧数规模时，须按显式优先级规则在精度、内存与进度之间裁决，并在取舍记录中说明理由与各对话所走路径；裁决结果必须可复现且不同路径结果不得混用统计口径。
7. 实现输入与配置校验链路：采样率非 16000、frame_ms 非法或帧移超过帧长、重复 dialog_id、事件类型不在受控集合、增益或对话时间轴越界分别返回 E_CONFIG_INVALID、E_DUP_DIALOG、E_EVENT_TYPE、E_TIMELINE_INVALID 并指明字段与对话标识。
8. 提供可集成的领域组件接口与完整示例，并实现跨阶段一致性自检：暴露特征提取、事件检测、后处理、取舍决策与指标入口；命令行示例读取本地合成样本输出含逐事件明细、指标、所选路径、取舍依据、业务码与降级标记的 JSON 报告；自检校验各阶段处理的帧索引集合完全一致、事件时间段首尾相接且覆盖全部检测帧、指标可由明细独立重算一致，不一致返回 E_INCONSISTENT 并指出类别与 dialog_id。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
