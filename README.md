当前是空白工作区，没有现存项目、代码或数据附件，需要从零构建一个面向表格与传感器数据的无监督异常检测引擎，交付算法实现与可复现的实验环境。业务对象是本地确定性生成的样本：用固定随机种子生成若干正态簇的正常数据，并按可配置比例注入远离簇心的异常点，样本清单为 JSONL，字段含 sample_id、feature 向量、group 标签与是否为注入异常的内部标记；同时提供检测配置，声明候选方法（孤立森林类随机切分、K 近邻距离、马氏距离）、每种方法的超参数候选集、并行 worker 数、单批样本数、内存上限与总比较次数预算。引擎的核心矛盾在于：三种方法对同一数据的计算代价与内存足迹差异很大，K 近邻在比较次数预算内可精确但代价高，随机切分近似精度可控但结果受随机种子影响，马氏距离需要协方差逆矩阵从而在维度升高时内存压力陡增；引擎必须在总预算内并行调度多方法候选、对每种方法给出可复现的异常分数与排名、在预算不足时按确定性规则裁剪候选并记录取舍理由，同时保证并行执行与串行执行、分块执行与整体执行得到可核对的结果。

任务环境与准备：
安装 Python 3.10 及以上与 NumPy，不依赖容器或外部服务。
在工作区创建项目目录与本地样本生成脚本约定：由固定随机种子生成正常簇、注入异常点与样本清单 JSONL，所有样本在本地生成，不下载任何外部数据集。
准备 multiprocessing 可用的本地进程环境，确认 Windows 下进程池启动方式与任务函数可被序列化。
不预置任何现成实现、数据附件或故障文件，全部功能从空工作区开始开发。

业务要求：
1. 实现三种无监督异常检测方法：孤立森林类随机切分（切分特征与阈值由方法内固定种子确定性驱动）、K 近邻距离、马氏距离；每种方法在同一输入、同一超参数与同一随机种子下必须逐字节产出相同的异常分数与降序排名，同分时按 sample_id 字典序打破平局，并输出每种方法的分数明细与所用超参数。
2. 实现并行调度层：按可配置 worker 数与单批样本数把方法-超参数组合分配到本地进程池执行，任务派发顺序、分块边界与归并顺序必须确定性可复现；worker 内异常须以结构化业务码与阶段名回传主进程并归因到具体方法名与批次序号，单个任务失败不得使整个批次失去已成功任务的结果。
3. 实现总比较次数预算与内存上限的双重准入裁决：按样本数、特征维度与 K 近邻的邻居数估算每种组合的比较代价，按协方差矩阵与方法中间数组估算驻留内存，在预算内决定准入的组合集合与执行规模；超限时返回 E_COMPARE_BUDGET 或 E_MEMORY_LIMIT 或按确定性裁剪规则缩小候选集，裁剪必须记录被裁掉的方法、超参数与被裁理由。
4. 实现并行执行与串行基线的结果等价性验证：对所有被准入且未降级的组合，并行调度执行得到的异常分数与排名必须与按固定顺序逐组合串行执行的结果在声明精度内一致；降级组合须以缩小后的参数单独执行并与单独基线核对，输出偏差谱与首个不一致位置。
5. 实现精度、内存与进度之间的冲突裁决：当增加 K 近邻邻居数提升检出质量但放大比较次数、提高随机切分树数提升精度但放大内存、纳入马氏距离提升对相关维度异常的敏感度但逼近内存上限时，须按显式优先级规则裁决，并在调度报告中记录所选路径、裁决依据与每个组合的资源消耗估算。
6. 实现检出质量评估与集合一致性自检：以注入异常的内部标记为观测口径计算 AUC、平均精度与固定配额下的检出率，指标须可由逐样本分数明细独立重算一致；同时校验每种方法输出的样本集合与输入样本标识集合完全相同、异常分数无 NaN 或无穷、排名中每个 sample_id 恰出现一次，违反返回 E_INCONSISTENT 并指出类别。
7. 实现调度计划、预算账本与检测结果摘要的版本化快照及整体替换：三者各携带单调递增版本号与内容校验和，检测到版本号或校验和变化时必须整体替换旧快照而非增量修补，旧版本不得覆盖新版本且回退尝试返回 E_SNAPSHOT_ROLLBACK，损坏或校验和不符返回 E_SNAPSHOT_CORRUPT；并发提交时后到者立即获得 E_STAGE_BUSY 而不阻塞等待，预算账本的扣减与释放须原子可见。
8. 实现输入与配置校验链路并提供可复现实验环境：重复 sample_id、特征向量长度不一致、方法名未知、邻居数或树数非正、内存或比较预算非正分别返回结构化业务码并指明字段；命令行入口读取本地确定性样本，跑完整基线与一次预算冲突降级运行，输出含各方法异常分数摘要、检出指标、调度报告、偏差谱、快照版本与业务码的 JSON，并支持固定种子重跑两次比对完整输出哈希一致。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
