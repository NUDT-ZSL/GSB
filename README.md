需要为新工作区构建一个本地运行的时序事件聚合组件，用于处理传感器采样数据流。事件带有单调事件时间戳（整数微秒）、观测值（float64）与设备序号。数据流中会混入迟到事件：其事件时间早于当前水位线，但仍可能落入尚未关闭的时间窗口。组件需提供可集成的 Python API 与完整示例，能按固定窗口与滑动窗口两种策略聚合观测值（求和、均方根、带权重均值），并把窗口结果与中间累加状态持久化到 SQLite，使进程被强制终止后从持久化状态恢复并保证已关闭窗口的结果不可变。数值精度是核心难点：浮点累加顺序随迟到事件到达顺序变化，同一集合的事件在不同到达顺序下必须产生可复现的聚合结果，并且组件需给出每一步聚合的误差估计上界。

任务环境与准备：
Windows 环境，安装 Python 3.10 及以上与 NumPy（pip install numpy），SQLite 使用标准库 sqlite3，无需外部服务。
确保工作区为空目录，演示样本由脚本根据固定随机种子本地生成，不依赖网络、账号或外部数据集。
以普通用户权限运行，允许在项目目录内创建 SQLite 数据库文件与日志文件。

业务要求：
1. 实现事件模型与窗口调度器：支持固定窗口与滑动窗口两种策略，窗口由事件时间与窗口长度参数确定，每个窗口具备 open/closed 两态；关闭由水位线推进触发，水位线取已观测最大事件时间减去允许迟到阈，状态迁移必须落库且非法迁移返回 E_WINDOW_STATE。
2. 实现基于补偿求和的数值聚合核心：求和、均方根与加权均值均使用可复现的累加算法（如 Kahan 或 Neumaier 补偿求和），确保同一事件集合在任意到达顺序下聚合结果逐位一致，并输出每一步的误差估计上界，误差上界由观测值量级与已知的浮点机器精度推导而非硬编码常数。
3. 解决迟到事件处理与窗口关闭的一致性冲突：迟到事件落在 open 窗口时以补偿方式并入已有累加状态并更新误差上界；落在 closed 窗口时按丢弃策略记录到迟到丢弃日志并计入统计，不得改写已关闭窗口结果；允许迟到阈值可通过配置参数注入验证。
4. 持久化中间累加状态与窗口结果到 SQLite，累加状态需保存补偿项与误差估计所需的中间量，进程被强制终止后通过持久化状态恢复续跑，恢复时识别水位线与未关闭窗口，已关闭窗口结果在恢复后逐位不变。
5. 实现幂等事件接入：以事件唯一键（设备序号加事件时间戳加序号）去重，重复投递不得重复计入聚合；在并发或多调用场景下由数据库约束保证唯一性，冲突时返回业务码 E_DUPLICATE 并保留首条已计入的观测值。
6. 提供误差报告与真值对照能力：对每个关闭窗口输出聚合值、误差估计上界与基于高精度参考（使用 decimal 或 math.fsum 计算的真值）的实测偏差，示例需展示实测偏差不超过所报误差上界这一可验证关系，超出时标记 E_ERRBOUND。
7. 提供异常注入与恢复边界：通过配置参数注入迟到超阈值、窗口长度非法、事件时间回退、数据库写冲突等异常，分别返回 E_LATE_DROP、E_WINDOW_PARAM、E_TIME_REGRESS、E_DB_CONFLICT；异常链路不得污染已提交的窗口结果，强制终止后的恢复只依赖持久化状态，不承诺生成退出报告。
8. 交付可集成领域组件与完整示例：以 Python 包形式暴露聚合 API 与误差查询接口，随包提供确定性演示脚本，从生成的本地事件样本跑完整管线并打印窗口结果、误差上界、实测偏差与恢复前后的窗口计数汇总，重复运行得到相同输出。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地生成的乱序事件样本验证聚合结果逐位一致、误差上界成立、迟到事件与恢复行为正确，并附运行输出。
