在游戏体积雾与医学式体数据预览共用的离线渲染管线中，设计者会在既有体数据上做局部修改（替换某个子区域的值、调整传递函数控制点、改变相机），并要求只重渲受影响的屏幕区域，从而把长耗时渲染变成可反复迭代的编辑循环。当前是空白工作区，需从零开发一个本地体数据离屏渲染管线的数据处理与结果验证工具：输入为一个 JSON 渲染任务描述与程序按确定性规则生成的本地体数据文件，输出为灰度投影图、深度图与一份缓存失效验证报告。核心难点不是渲染本身，而是局部编辑之后必须精确判定哪些屏幕分块失效：体数据子区域被改动后，只有光线实际穿过该子区域的分块才应失效；传递函数变化则影响所有非空分块；相机变化使全部缓存失效。判定过于保守会让迭代失去意义，判定过于激进会让图像与从头全量渲染不一致，二者之间的取舍必须由报告逐块给出可复核的判据。

任务环境与准备：
在 Windows 上安装 Python 3.11 及以上，并安装 NumPy（以 pip 可获取的稳定版为准）。
新建空白工作目录作为项目根目录，不放置任何预置代码或数据附件。
准备本地确定性样本生成入口：按固定随机种子生成体数据标量场，并生成包含局部子区域编辑、传递函数调整与相机变化的若干 JSON 任务描述，写入工作目录下的样本目录。
确认工作目录可读写、可创建临时文件与状态目录，运行过程不访问网络，不使用容器或外部数据集。

业务要求：
1. 实现渲染任务与体数据解析校验：读取 JSON 任务描述与体数据文件，校验三维尺寸为正整数、各轴体素间距为有限正数、传递函数控制点标量严格递增且不透明度与灰度值在定义域内、相机位置与目标点不重合且上方向与视线不平行、分块规格能完整覆盖输出像素网格、并发上限与内存预算为正整数；非法输入返回带 E_xxx 业务码的 JSON 错误并指明字段路径，且不产生任何输出文件。
2. 实现体数据子区域编辑的确定性应用：按编辑清单顺序应用子区域替换、中心与尺寸以体素索引整数表示且不得越界、替换值落在体数据标量域内，重叠子区域按编辑清单声明顺序后者覆盖前者；编辑后的体数据与编辑清单内容一一对应，同一编辑清单重复应用必须得到逐体素相同的结果，编辑不改变体数据三维尺寸与各轴间距。
3. 实现光线穿行分块反演与失效判据：对每个输出像素分块，沿其像素中心光线在毫米世界坐标中求与体数据包围盒的交段，按各轴体素间距把交段换算到体素索引空间，反演出该分块覆盖的体素索引包围范围；当某个被编辑子区域与该范围相交、且编辑后该范围内的标量确实发生变化时判定该分块失效；不穿过任何被改动体素的分块必须判为可复用，判据与采样步长无关而只依赖编辑区域与分块光线覆盖范围的几何关系。
4. 实现传递函数与相机变化的整体失效识别：传递函数任一带宽或灰度控制点变化时，所有采样到非空标量的分块都判定失效，仅覆盖全零标量区域的分块保持可复用；相机位置、目标点、上方向、视场角或宽高比任一变化时全部分块失效；同一轮渲染内多类变化同时发生须按上述规则的并集判定，报告须逐块给出触发失效的具体变化类别，不得以单一标记掩盖原因。
5. 实现确定性渲染与串行等价：对需重渲分块按毫米世界坐标光线步进采样并三线性插值，结合传递函数前向合成灰度与透过率，同时记录首个有效采样点的深度（以毫米表示）；每块只读体数据、传递函数与相机参数，最终拼装图像须与并发度为 1 时逐像素相同，深度图尺寸与投影图严格一致，空场景按确定规则给出背景值与最大深度而非未定义值。
6. 实现分块缓存持久化与版本识别：每个分块完成后把灰度、深度、该块所依赖的编辑清单摘要与由体数据内容、传递函数、相机参数规范化摘要构成的版本标识原子写入状态目录，先写同目录临时文件再整体替换；再次启动时版本标识一致的块直接复用，标识不一致时不得直接覆盖旧块而须先归档旧版本，恢复后缺失块数量与失效判据给出的数量必须一致。
7. 实现并发分块渲染与资源上限、异常取消：按描述中的并发上限使用有界线程池调度待重渲分块，同时处于计算中的分块采样缓冲总量不得超过内存预算，超出时按分块索引序让后续块等待而非降低采样步长或插值精度；任一分块异常时取消其余待处理分块并返回首个错误，已持久化块保持有效且其复用判定不受取消影响。
8. 实现中断语义、块级校验与失效报告原子提交：可处理终止信号只在分块边界生效，写入中断标记并以约定整数退出码退出，未完成分块不得留下可被误认为完成的结果；强制终止后重启仅依据已持久化且摘要有效的块状态恢复且不承诺生成退出报告；全部分块完成后逐块比对摘要，不匹配或声明像素数不符时返回 E_DIGEST 并回退补渲；校验通过后才按行序拼装并原子替换图像与报告，报告含逐块失效类别、复用数、重渲数、光线穿行体素范围与业务码分布，二者要么同时更新要么都保持旧版本。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
