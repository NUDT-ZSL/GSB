当前是空白工作区，没有现存项目、代码或数据附件，需要从零构建一个面向对话语音情感分析的本地可集成领域组件与完整示例，核心业务问题是大规模对话语音情感打分时的增量更新与依赖失效追溯。业务对象是本地确定性合成的多说话人对话语音：用固定种子生成若干说话人的基频、共振峰、能量包络与语速参数，按给定对话时间轴与增益叠加为 16kHz 单声道 PCM，并附逐帧真值文件（帧长 20ms，字段含 frame_index、speaker_id、valence、arousal、is_speech）、对话清单（JSONL，字段含 dialog_id、sample_rate、duration_ms、speaker_ids、seed）与说话人注册样本清单。该组件并非从头构建完整分析链路，而是在已有分帧特征产物之上增加；但分帧阶段本身依赖一整套可替换的声学特征提取参数。组件把一次分析建模为四阶段流水：分帧特征提取→说话人嵌入与逐帧指派→段级情感回归→对话级聚合，核心难点在于：当数据规模从数十条对话扩展到数千条、且参数与标注频繁变动时，如何以增量方式维持结果可复现、可追溯。缓存键必须同时编码特征参数版本、注册样本版本、真值修正版本与上游节点哈希，任一版本变化都会沿不同路径产生不同失效范围；同时段级与对话级结果必须能由历史缓存键重放，而不只是从当前版本重新计算。上述多重约束互相牵制，构成本题的主要复杂度。

任务环境与准备：
安装 Python 3.10 及以上版本，并安装 NumPy（版本 1.24 及以上），用于确定性 PCM 合成与数组运算。
确认工作区为空白目录，并在项目内创建样本生成脚本，用固定种子生成 PCM、逐帧真值、对话清单与注册样本清单，所有样本随项目本地生成，不依赖外部下载。
在 Windows 命令行中准备可运行 Python 脚本与 pytest 的本地环境，用于运行组件示例与自检入口。
无需容器、外部服务、账号或网络访问。

业务要求：
1. 实现确定性的分帧特征提取阶段：按 frame_ms 与帧移切分 PCM，帧边界以样本索引精确确定，计算短时能量、过零率、谱质心与谱滚降，输出逐帧特征矩阵与帧数；同一 dialog_id、同一 seed 与同一配置下必须逐字节产出相同特征与帧数，且帧数须与逐帧真值文件一致，不一致返回 E_FRAME_COUNT。
2. 实现说话人嵌入与逐帧指派阶段：由注册样本清单中固定种子与时长确定性合成注册片段，估计每个说话人的嵌入统计量，对每帧按确定性相似度打分并指派说话人编号，同分按 speaker_id 升序打破平局，输出逐帧标签与连续段边界；标签须落在对话声明的 speaker_ids 内，越界返回 E_SPEAKER_UNKNOWN。
3. 实现段级情感回归与对话级聚合阶段：按说话人连续段对 valence 与 arousal 做确定性回归并给出每段置信区间，对话级按段时长加权聚合并显式记录权重口径；聚合结果须能由逐段明细与权重独立重算一致，区间上下界顺序非法返回 E_INTERVAL_INVALID，同一输入与配置重跑得到相同分数与排序。
4. 实现内容寻址缓存与缓存键构造：每个节点产物附带内容哈希写入本地缓存目录，缓存键须纳入音频分块内容哈希、声学特征参数版本、注册样本版本、帧移与切段阈值、真值修正版本与上游节点哈希；键相同必须复用快照，键不同必须重算，且每个缓存条目须记录键组成以便追溯。
5. 实现增量更新的依赖失效传播：追加注册样本、修正单段真值标签、调整帧移或切段阈值以及修改声学特征参数时，计算受影响节点与受影响帧或段集合，复用未受影响上游缓存，仅重算受影响后缀；须输出本次重算节点清单与复用节点清单，并保证局部修改后的完整结果与全量重算结果逐字节一致。
6. 提供旧分数追溯能力：对任一此前产出的段级或对话级分数，可按其记录查询当时所用缓存键、输入版本与节点路径，并用这些键重放出相同分数；追溯链断裂或键无法复现分数时返回 E_LINEAGE_BROKEN 并指出断裂的节点与版本号，禁止用当前版本数据替代历史版本重放。
7. 实现缓存与配置的版本化整体替换及并发写控制：缓存条目与配置快照携带单调递增版本号与内容校验和，检测到版本号或校验和变化时必须整体替换旧快照而非增量修补，损坏或校验和不符返回 E_CACHE_CORRUPT；多个任务并发写同一缓存键时须保证只有一个写入生效，冲突方获得 E_CACHE_BUSY 而不阻塞等待。
8. 实现配置与输入校验链路、资源上限及跨节点一致性自检并提供完整示例：采样率非 16000、frame_ms 非法或帧移超过帧长、重复 dialog_id、注册清单缺失 speaker_id 分别返回结构化业务码；为单次分析帧数、缓存条目总量与驻留特征内存设可配置上限，超限返回 E_RESOURCE_LIMIT 或降级并标记降级类别；自检校验各节点处理的 frame_index 集合一致、复用与重算集合无交集且并集覆盖受影响集合，不一致返回 E_INCONSISTENT。
