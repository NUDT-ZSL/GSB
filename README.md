当前是空白工作区，没有现存项目、代码或数据附件，需要从零构建一个面向 OCR 文字检测识别的本地领域数据编辑与操作应用，核心业务问题是多阶段识别流程的可复现验证与异常注入。业务对象是本地确定性生成的页面样本：由固定种子在固定尺寸灰度画布上按版面模板绘制若干文本行（字形用确定性笔画模板拼出），每行带真值框与真值字符串，页面清单为 JSONL（字段含 page_id、image_seed、image_shape、line_count、charset_version、policy）。系统把一次整页识别建模为四阶段流水：像素预处理与二值化→行检测与框排序→行区域特征与字符模板匹配识别→页面指标聚合。要求同一页面与同一配置下各阶段产物逐字节一致，并在输入或参数注入异常时按阶段给出业务码、沿链路归因并降级，同时通过阶段快照支持强制终止后的恢复。

任务环境与准备：
安装 Python 3.10 及以上版本，并安装 numpy 与 Pillow（用于确定性灰度画布生成与像素数组处理），确保无需联网即可导入。
在工作区准备本地样本生成脚本所需的固定种子与字符集版本配置，字形笔画模板与字符模板库均由脚本确定性生成，不依赖任何外部图像或字体文件。
确认运行环境提供本地可写的缓存目录与临时文件替换能力（用于快照原子落地），并允许本地进程池并发提交测试。
准备异常注入所需的参数化输入样例清单（越界像素、非法行框、未知字符集版本等），全部由本地样本派生，不通过修改源码制造失败。

业务要求：
1. 实现确定性的四阶段识别流水：像素预处理与二值化、文本行检测与框排序、行区域特征与字符模板匹配识别、页面指标聚合依次串联，同一 page_id、image_seed、字符模板库版本与同一配置下各阶段中间产物、逐行识别串与最终报告必须逐字节一致，禁止依赖系统时间、字典遍历顺序或任何未声明的随机源；行检测同分时按 y 升序再按 x 升序裁决。
2. 实现分块识别与整页一次性识别的参考对照：为同一页面另行产出不分块、以 float64 特征与精确模板匹配处理的高精度参考结果，分块路径与参考路径必须共用同一行框口径与同一特征归一化统计量，块边界不得引入额外平滑或截断；输出逐行逐字符差异明细与最大坐标偏差，超出容差返回 E_TOLERANCE_EXCEEDED 并给出首个差异行号与字符位置。
3. 实现四阶段异常注入框架：在预处理、行检测、识别打分、指标聚合四个阶段分别提供由输入或参数触发的注入点（如像素值越界、行框坐标越出画布、字符模板维度不符、字符集版本未知、门限非正），注入不得修改源码制造；每次注入须产生带阶段名、业务码、被注入样本 page_id 与行号的记录，并保证同一注入序列重跑产生逐字节相同的注入日志。
4. 实现异常归因与降级链路：某阶段产出业务码时下游须按显式策略降级（如行检测失败时回退到真值框布局、模板匹配失败时回退到低分辨率模板集并标记），降级结果须携带降级类别与触发它的上游业务码；未被任何阶段归因的异常须显式记录为未归因并计入自检失败，禁止静默吞掉异常或用空结果顶替失败行。
5. 实现四阶段可持久化快照与强制终止后的恢复：每阶段快照携带单调递增版本号、已完成 page_id 集合与内容校验和，只有该阶段全部页面处理完成才提交，提交以临时文件写入后原子替换落地；重启时从最后已提交阶段继续，已提交页面不得重算，未提交的中间行框与匹配中间表必须丢弃并从该阶段起点重建，恢复后报告须与不间断完整运行逐字节一致。
6. 实现字符模板库与识别配置的版本识别与整体替换：模板库、识别参数与页面结果快照各携带版本号与内容校验和，检测到版本号或校验和变化时必须整体替换旧快照而非增量修补，旧版本不得覆盖新版本，回退尝试返回 E_SNAPSHOT_ROLLBACK，损坏或校验和不符返回 E_SNAPSHOT_CORRUPT 并指明阶段名与版本号；模板库升级时须计算受影响页面集合，仅重算受影响的识别与聚合阶段。
7. 实现并发提交控制与资源上限，并实现输入与配置校验链路：同一时刻只允许一个阶段提交生效，并发冲突时后到者立即获得 E_STAGE_BUSY 而不阻塞等待；为单页行数、模板匹配候选比较次数与驻留特征内存估算设可配置上限，超限返回 E_RESOURCE_LIMIT 或降级为逐行流式识别并标记降级类别；重复 page_id、image_shape 维度不符、charset_version 不在受控集合内分别返回对应业务码并指明字段。
8. 提供本地可交互的领域数据编辑与操作应用并实现跨模块一致性自检：支持编辑页面行框与真值字符串、手动触发一次含注入与一次含降级的演示，并展示阶段状态、快照版本、逐行识别串与置信度、注入记录、降级链路、恢复报告与最近业务错误码；自检校验四阶段 page_id 集合完全一致、识别串长度与字符模板候选明细可核对、重算页面集合与复用页面集合无交集且并集覆盖受影响集合，不一致返回 E_INCONSISTENT 并指出阶段与页面。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地确定性样本运行四阶段识别，核验逐字节可复现、注入归因降级与快照恢复结果及业务码。
