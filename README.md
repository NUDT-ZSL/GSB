体育训练动作演示系统开发人员与教练团队需要一套本地可复现的内核：训练场地里，视频片段、骨骼动画关键帧、标注提示、传感器触发事件与节目单被采集为一份演示工程，视频帧率、骨骼采样率、传感器时基和节目单调度时基各不相同。教练希望在回放时看到与运动员动作对齐的虚拟骨骼和标注，并能跳到某个时刻继续演示。需要把这份工程按统一时间码轴归一，插值骨骼姿态，生成逐帧呈现计划，并在跳转、调速后重建一致的计划，同时给出动作偏差摘要与时间码一致性报告。

任务环境与准备：
准备 Linux（WSL Ubuntu）上的 Python 3 运行环境，仅使用标准库。
在空工作目录中建立项目结构，由实现自行编写确定性演示工程生成器，按固定种子产出视频片段、骨骼关键帧、标注、传感器事件与节目单。
准备本地样本输出目录与快照目录，用于存放逐帧呈现计划、动作偏差摘要、时间码一致性报告与跳转快照。

业务要求：
1. 解析演示工程中的视频片段、骨骼动画关键帧、标注提示与传感器事件，按各自声明的帧率或时间戳归一为统一整数帧序，输出归一后的帧号、原始时间戳与来源标识，并在输入中检测帧号回绕、时间戳倒序等异常结构并给出可追溯标记。
2. 对骨骼动画关键帧按统一帧序做四元数球面线性插值，处理关键帧稀疏区间与首尾外插，输出逐帧各关节旋转角与根位移，插值结果满足单位四元数不变量，并在关键帧缺口超过阈值时输出外插标记而非静默填充。
3. 按节目单的片段起止时间、播放速度与叠加图层，逐帧确定当前激活的视频帧指针、激活的骨骼姿态与标注显示内容，输出逐帧呈现计划，并处理片段重叠、图层可见性与速度变更处的帧归属冲突。
4. 在节目单时间轴任意位置跳转或调整播放速度后，从该位置重建后续逐帧呈现计划，重建结果必须与全量连续生成在同一区间的逐帧结果一致，并输出跳转点前后呈现状态快照以核验连续性。
5. 根据传感器触发事件与当前呈现帧的骨骼姿态，计算触发时刻动作类型对应的关键关节角度偏差与时间偏移，输出动作偏差摘要，并对落在标注区间边界或关键帧缺口附近的触发给出可信度标记。
6. 校验视频帧时间码、骨骼动画时间戳与传感器触发时刻在统一帧轴上的对齐关系，标记时基漂移超过阈值的片段，输出时间码一致性报告，报告需包含漂移量估计与受影响帧区间。
7. 提供本地命令行入口，从工程目录读取输入并输出逐帧呈现计划、动作偏差摘要、时间码一致性报告与跳转快照到指定目录，输入非法时以非零退出码和业务错误码 E_ 前缀标识，便于教练在训练后复算与比对。
8. 将呈现计划与偏差摘要持久化为可版本化快照，支持同一节目单不同版本之间的快照比较，比较时识别版本变化并报告逐帧差异摘要，用于训练复盘时定位动作对齐变化来源。

验收：
以确定性工程样本与边界样本运行，核对骨骼姿态参考插值一致、跳转重建逐帧一致、偏差摘要与真值吻合、漂移标记与植入片段一致。
