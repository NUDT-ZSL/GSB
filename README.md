在游戏引擎的材质参数逆向拟合场景中，需要从零开发一个本地可微渲染离线管线：给定一组由程序按确定性规则生成的目标图像与材质参数真值，对材质参数（漫反射率、粗糙度）做基于梯度的迭代拟合，使渲染结果逼近目标图像，并输出拟合参数、损失曲线与梯度一致性验证报告。渲染采用简化的微表面着色模型，损失函数为逐像素颜色差平方和，梯度须由解析反向传播得到而非数值差分。当前为空工作区，不依赖任何渲染库、自动微分框架、GPU 或外部资源，目标图像与真值由程序生成本地样本。真实难点在于：解析梯度必须与数值差分的参考值在容差内一致，同时整条管线要在固定的迭代预算、分块并行调度与内存上限下保持逐位可复现的结果，任何调度顺序变化都不得改变最终参数。

任务环境与准备：
确认 Windows 环境已安装 Python 3.10 及以上并可在命令行调用。
安装 NumPy 1.x 稳定版本，仅使用本地库，不引入自动微分框架或渲染引擎。
在空工作区创建项目目录，运行环境不要求 GPU、网络或外部数据。
目标图像与材质真值样本由程序按确定性规则生成，运行前无需下载任何资源。

业务要求：
1. 实现场景与样本描述解析及校验：读取 JSON 描述，校验相机分辨率与超采样倍数为正整数、材质参数真值落在定义域内（漫反射率在 [0,1]、粗糙度为正的有限数）、光源方向为单位向量、迭代次数与学习率以及梯度容差为有限正数，非法输入返回带 E_SCHEMA 的 JSON 错误且不产生任何输出文件。
2. 实现前向渲染与解析反向传播：按微表面着色模型逐采样点计算法线与两盏方向光下的颜色，并将损失对材质参数的梯度用解析链式法则回传；同一组参数下前向颜色与解析梯度须与规格给出的数值差分参考在梯度容差内一致，参考差分步长与比较方式由描述显式给出。
3. 实现确定性梯度聚合与参数更新：把逐像素梯度按规格规定的归并顺序（固定像素下标序而非调度完成序）累加为整图梯度，再按学习率更新参数；无论分块并发度如何，同一输入与迭代次数必须得到逐位相同的参数轨迹与损失序列，禁止依赖浮点累加顺序可变的归约。
4. 实现收敛判定与失败诊断：按损失相对变化与梯度范数双阈值判定收敛，达到迭代上限仍未收敛时返回 E_CONVERGE 并在报告中给出最后若干次迭代的损失与梯度范数；参数越出定义域时按规格的回退规则投影回边界并记录投影次数，诊断信息须定位到具体参数名。
5. 实现分块并行渲染与内存预算：按分块规格把像素网格分块，用有界线程池按并发上限调度，同时处于计算中的分块采样缓冲与梯度缓冲总量不得超过描述中的内存上限，任一分块异常时取消其余待处理分块并返回首个错误，串行与并行结果必须在梯度容差内一致。
6. 实现迭代状态持久化与版本识别恢复：每完成若干次迭代把当前参数、迭代序号与由目标图像内容、场景参数与优化超参数规范化摘要构成的版本标识写入状态目录，先写临时文件再整体替换，替换前比对已有状态版本标识，标识变化时不得直接覆盖而须归档旧版本；再次启动时标识一致则从最近迭代继续。
7. 处理可处理终止信号与强制终止恢复：可处理终止信号只在迭代边界生效，写入中断标记并以约定整数退出码退出，未完成的迭代不得留下可被误认为已完成的参数状态；强制终止后重启仅依据已持久化且摘要有效的迭代状态恢复，不承诺生成退出报告，状态摘要不匹配时判定失效返回 E_DIGEST 并回退到最近有效状态。
8. 实现拟合报告与结果原子写出：输出 JSON 报告含每轮损失、最终参数与真值偏差、解析梯度与数值差分的最大偏差、投影次数与收敛判定，并把拟合参数与损失的最终结果先写同目录临时文件再整体替换正式输出，版本不同才替换，失败时保留旧文件并返回 E_WRITE。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本运行拟合，验证解析梯度与数值差分一致、参数可复现及中断恢复后结果不变。
