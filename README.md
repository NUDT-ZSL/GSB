在游戏过场动画与无障碍字幕呈现流程中，字幕需要根据时间轴事件增量更新：当某条字幕的文本、样式规则或时间窗被编辑时，只应重排受影响的字幕与画面区域，而不是全量重排。当前是空白工作区，需从零开发一个本地字幕排版与无障碍呈现引擎。输入为 JSON 描述：字幕事件清单（每条含起止毫秒、文本、说话人、语言、阅读速率上限、是否关键音效、屏幕区域锚点）、样式规则（字号、行高、最大行数、内边距、对比度增强开关、背景遮罩不透明度）、每帧画面尺寸与安全区、编辑脚本（按顺序修改文本、样式或时间窗）。引擎需输出可渲染的字幕布局帧序列与无障碍呈现报告。核心难点在于：编辑脚本任一步后，样式规则的变化会波及大量字幕，而单条字幕的文本变化又可能改变其换行与阅读速率，从而影响后续时间窗内字幕的可见区域；同时排版需在毫秒级时间轴上保持确定性与可中断恢复。

任务环境与准备：
安装 Python 3.10 或更高版本，并安装 NumPy；无需网络、GPU 或外部媒体工具。
在工作区创建 samples 目录，编写确定性生成脚本按 JSON 规格生成本地字幕事件与样式规则样本，不依赖真实字幕文件或附件。
确保 Windows 本地文件系统可写，并为状态目录与输出目录预留独立路径，运行前清理旧状态目录以避免版本混淆。
使用命令行运行引擎并准备一个可发送可处理终止信号的本地测试脚本，用于验证中断与恢复语义。

业务要求：
1. 实现字幕事件与样式规则解析校验：读取 JSON 描述，校验每条字幕起止毫秒为非负整数且结束大于开始、文本非空、阅读速率上限为正整数、屏幕锚点落在安全区内、样式字号与行高为有限正数、最大行数为正整数、对比度增强开关为布尔值；非法条目返回带 E_xxx 业务码的 JSON 错误且不产生输出帧。
2. 实现字幕文本自动换行与阅读速率约束：按样式字号与安全区宽度把每条字幕文本切分为不超过最大行数的行，单行宽度超出时在词边界换行，换行结果只依赖文本内容、字号与安全区宽度；同时根据文本字符数与阅读速率上限计算最小显示时长，若时间窗不足则标记该字幕为速率超限并记录所需最小毫秒数，不得静默截断文本。
3. 实现逐帧字幕布局与安全区合成：在每帧画面尺寸上按锚点、内边距与行数计算字幕包围盒，背景遮罩不透明度与对比度增强开关参与合成灰度帧，关键音效字幕须带确定性视觉标记；帧与帧之间同一字幕的包围盒只在其时间窗内出现，时间窗之外不得残留像素，空帧须为确定背景值。
4. 实现样式规则依赖图与失效判定：为每条字幕的布局记录其对字号、行高、最大行数、内边距、对比度增强开关及安全区的依赖，为每个帧区间记录其可见字幕集合；编辑脚本任一步发生后，只把受被编辑样式规则影响的字幕与被文本或时间窗变化波及的帧区间标记为失效，其余帧区间必须复用已持久化布局结果。
5. 实现分块级持久化与版本识别：按固定毫秒块把输出帧序列分块，每块完成后把该块帧数据、块摘要与由字幕事件清单、样式规则与编辑脚本规范化摘要构成的版本标识原子写入状态目录，先写同目录临时文件再整体替换；再次启动时比对版本标识，一致则只重算失效块，不一致则从头重做，替换前不得直接覆盖不同版本的结果。
6. 实现中断信号与强制终止的恢复语义：外部可发送的可处理终止信号只在毫秒块边界生效，写入中断标记并以约定整数退出码退出，未完成块不得留下可被误认为完成的结果；强制终止后重启仅依据已持久化且摘要有效的块状态恢复，不承诺生成退出报告；全部块完成后逐块校验内容摘要，摘要不匹配或声明帧数不符时返回 E_DIGEST 并回退补算。
7. 实现并发分块重算与资源上限：按描述中的并发上限使用有界线程池调度待算帧块，同时处于计算中的帧缓冲与布局中间量总量不得超过内存预算，超出预算时按块索引序让后续块等待而非降低换行精度或安全区尺寸；任一分块异常时取消其余待处理分块并返回首个错误，最终拼装结果须与并发度为 1 时逐像素相同。
8. 实现布局帧序列与无障碍呈现报告原子导出：报告含每条字幕的换行结果、最小显示时长、速率超限标记、包围盒起止帧、失效重算块数、逐块摘要与业务码；导出时先写同目录临时文件再整体替换正式输出，读取已有输出文件的帧数与版本标识并在版本不同时整体替换，报告与帧序列要么同时更新要么都保持旧版本。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本验证字幕增量排版、样式依赖失效、中断恢复与原子导出，并核对帧序列与报告一致。
