在空白工作区构建一个面向低精度量化卷积算子的领域数据编辑与操作应用，用于在本地确定性合成张量上反复调参并验证量化卷积结果。输入为一份算子图描述 JSON（节点为量化卷积，含输入通道、输出通道、核尺寸、步长、填充、权重与激活的量化位宽与缩放因子）、一份按固定种子生成的输入张量与权重量化包（整数存储的小端二进制文件与配套形状描述），以及一份调度配置 JSON（线程池最大并发数、全局乘加计算预算、单节点预算配额、缓存驻留预算以字节计、快照提交间隔、首帧响应预算毫秒）。应用需完成整数域量化卷积、缩放因子反量化归约、跨节点并行调度与预算分配，支持用户以交互命令修改节点量化位宽、缩放因子或替换子图，编辑后仅重算受影响节点，且多次编辑后的最终结果必须与从空白工作区按相同最终配置全量运行一致。

任务环境与准备：
确认 Windows 上可用 Python 3.10 及以上版本，并能执行 python --version。
创建空白工作区目录，安装 numpy 依赖（建议 1.24 及以上），无需网络账号或外部数据。
准备本地样本生成脚本所需参数：算子图 JSON、固定种子张量形状描述、调度配置与注入配置，均由任务内描述字段确定，不依赖外部附件。

业务要求：
1. 实现算子图与量化包加载层：解析算子图 JSON，校验节点 ID 唯一、边两端存在、无环且每个输入张量只有一个生产者，校验卷积参数与量化位宽、缩放因子取值合法，非法时输出 E_GRAPH_INVALID 或 E_QUANT_PARAM 业务码并进入失败清单；量化包须校验容器头、元素数与小端字节序，与形状描述不符时输出 E_PACK_SHAPE_MISMATCH，不得静默截断或补零。
2. 实现整数域量化卷积内核：按核尺寸、步长与填充对整数激活与整数权重做定点乘加，累加使用固定位宽的整数缓冲并在溢出前按配置溢出策略处理，越界时输出 E_ACC_OVERFLOW 并记录节点 ID 与累加位置；边界不足处按填充规则补齐，输出通道逐通道计算，运算顺序固定为输出行优先、核行优先、核列优先、输入通道升序，结果须可逐元素复现。
3. 实现缩放因子反量化归约：将整数累加结果乘以权重缩放因子与激活缩放因子之积并做确定性舍入，舍入模式取自配置且必须在节点产物元数据中显式记录；关闭量化或改换位宽时必须真实改变中间整数段与反量化结果，不得退化为浮点路径直接计算；同一输入与配置下反量化结果须逐元素一致。
4. 实现基于内容指纹的节点级失效传播：为每个节点产物计算由节点量化参数指纹、输入张量内容指纹与算子实现版本号派生的缓存键；编辑节点位宽、缩放因子或替换子图后，仅将受影响节点及其全部下游标记失效并纳入重算集合，未失效节点必须直接复用产物且不得重复执行，复用与重算的节点清单须在诊断报告中列出。
5. 实现全局乘加预算的并行调度器：多节点通过线程池并发执行，最大并发数取自配置；调度器按拓扑序稳定顺序为每个就绪节点分配单节点预算配额并维护全局剩余预算，累计乘加量超出全局预算时对未完成节点输出 E_BUDGET_EXHAUSTED 并保留可审计的预算消耗记录；不得以线程超时描述为已终止计算，预算判定须基于真实乘加计数。
6. 实现并发结果与串行结果一致性：每个节点任务携带由拓扑序位次与节点 ID 派生的稳定排序键，无论线程调度顺序与并发度如何，最终逐节点输出张量、失效清单顺序、预算扣减序列与失败清单顺序，必须与单线程按拓扑序逐一执行逐字段一致；该一致性须在至少两种并发度与两种预算规模下可复现验证。
7. 实现阶段快照与强制终止后的恢复判定：将图加载校验、整数卷积、反量化归约、产物汇总划分为阶段，各阶段以临时文件加原子替换方式持久化快照，快照含全局图版本号、配置哈希、已完成节点列表、部分张量摘要与产物版本；收到可处理的退出信号时完成当前节点产物与快照提交后以整数退出码 0 退出；强制终止后仅依据已完整替换的快照恢复，配置哈希不符输出 E_CONFIG_MISMATCH。
8. 实现异常注入隔离与诊断报告输出：以独立注入配置指定非有限缩放因子、位宽越界、累加溢出、缓存驻留预算为零等样例，注入项编号写入报告以证明命中；单节点在参数构造、整数卷积或反量化阶段抛异常时记录节点 ID、阶段名、业务码与异常类型并继续可调度节点；每次完整运行输出 JSON 报告，含逐节点缓存命中与失效、重算耗时、预算消耗、误差摘要、快照版本号与失败清单，报告以原子替换写盘。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本验证量化卷积、并行预算调度、增量失效与断点恢复，结果可复现。
