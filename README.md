当前是空白工作区，没有现存项目、代码或数据附件，需要从零构建一个面向多视角图像拼接渲染的本地可集成领域组件与完整示例。业务对象是本地确定性生成的场景样本：由固定种子在固定尺寸画布上生成若干视角的 RGB 像素数组与对应相机参数（内参、外参、畸变系数、曝光增益），视角之间通过已知单应变换重叠。拼接渲染链路为：视角参数解析与校验→几何对齐（单应变换与重采样）→曝光与颜色增益补偿→重叠区羽化融合→全景输出。场景参数以 v1、v2、v3 三种版本格式到达：v1 为竖线分列的行式（相机编号|焦距|主点x|主点y|外参平铺|畸变k1,k2|曝光增益，无字段名与重叠区声明），v2 为带字段名的键值对（含单应矩阵、重叠区权重、曝光增益模式），v3 为结构化格式（含逐视角畸变模型链、曝光曲线参数、融合羽化半径与色域标记）。核心业务问题是三版本参数格式的互操作读取与双向迁移、迁移语义漂移的裁决、以及通过输入或参数注入异常验证异常在阶段间的归因与降级，最终保证同一语义参数在不同版本书写下产出逐字节一致的全景图。

任务环境与准备：
安装 Python 3.10 及以上与 NumPy；在 Windows 本地工作区创建项目目录，不引入容器、镜像或外部服务。
编写本地确定性样本生成脚本，按固定种子生成固定尺寸 RGB 视角数组与相机参数，并写出三版本参数文件、样本清单与配置 JSON。
准备命令行入口与本地缓存目录，确认中间产物按内容哈希命名；运行前清空缓存以对比首次运行与固定种子重跑的完整输出哈希。

业务要求：
1. 实现 v1、v2、v3 三种视角参数格式的读取器，按版本头或字段集分派解析路径；未知版本返回 E_VERSION_UNSUPPORTED，行字段数不符、必填字段缺失或数值不可解析返回 E_FORMAT_CORRUPT 并指出字段偏移；读取结果须产出统一的视角参数内部表示，包含内参、外参、畸变系数与曝光增益。
2. 实现 v1 到 v2、v3 的升级迁移器与 v3 到 v2、v1 的降级迁移器：升级时补全单应矩阵、重叠区权重、曝光增益模式与融合羽化半径并逐项记录补全来源；降级时对 v1 或 v2 无法表达的畸变模型链与曝光曲线参数按显式声明的丢弃或展平规则处理，输出丢弃明细；往返迁移后的可表达字段必须逐项可核对。
3. 实现确定性的几何对齐与重采样阶段：按单应变换与畸变系数把各视角重采样到全景坐标，重采样采用显式声明的插值口径，边界外像素标记为无效；同一语义参数下必须产出逐字节一致的重采样图像与无效掩码，同分或同坐标冲突时按视角编号升序裁决。
4. 实现曝光与颜色增益补偿及重叠区羽化融合阶段：按曝光增益模式对视角做确定性增益校正，重叠区按羽化半径与权重做加权融合；融合后须校验全景中每个有效像素至少来自一个视角、无效像素不被填充、重叠区权重和为 1（允许声明舍入容差），违反分别返回 E_OVERLAP_GAP、E_INVALID_FILLED、E_WEIGHT_SUM 并输出位置。
5. 实现跨版本语义等价裁决：同一场景参数以 v1、v2、v3 三种形式书写时，读取与迁移后必须产出相同的内部参数表示、相同的全景图像与相同的无效掩码；当 v1 表达能力不足导致语义不可完全还原时返回 E_SEMANTIC_DRIFT 并列出不可还原字段；当往返迁移导致可表达字段发生变化时返回 E_ROUNDTRIP_MISMATCH 并指出首个差异字段。
6. 实现四阶段异常注入框架并沿异常链路归因：在参数解析、几何对齐、增益补偿、羽化融合四个阶段分别提供由输入或参数触发的注入点（如外参维度不符、单应矩阵奇异、曝光增益为零、羽化半径负值），注入不得通过修改源码制造；每次注入须产生带阶段名、业务码与上下文快照的记录，某阶段产出业务码时下游按明确策略降级（如奇异变换跳过该视角、增益无效回退到单位增益）并携带降级类别与触发它的上游业务码，未被任何阶段归因的异常须汇总并标记为未归因。
7. 实现参数与全景结果的版本化快照及整体替换：视角参数快照、迁移记录与全景结果快照各携带单调递增版本号与内容校验和，检测到版本号或校验和变化时必须整体替换旧快照而非增量修补，旧版本不得覆盖新版本且回退尝试返回 E_SNAPSHOT_ROLLBACK；损坏或校验和不符返回 E_SNAPSHOT_CORRUPT 并指明版本号与不一致字段；版本相同的快照必须复用而不得重建。
8. 实现资源上限与并发提交控制，并提供本地可交互诊断应用与跨模块一致性自检：为单次拼接的像素内存估算、缓存条目数与并行重采样任务数设可配置上限，超限时返回 E_RESOURCE_LIMIT 或降级并标记降级类别；同一时刻只允许一个参数快照提交生效，并发冲突时后到者立即获得 E_STAGE_BUSY 而不阻塞等待；诊断应用展示三版本视图、迁移补全与丢弃明细、注入与降级记录、重叠区权重图、全景图与最近业务错误码，自检校验全景有效像素覆盖完整、迁移往返可表达字段一致、降级链路可追溯，不一致返回 E_INCONSISTENT 并输出差异明细。
