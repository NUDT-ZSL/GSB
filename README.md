在空白工作区从零实现一个本地压测与容量评估引擎，用于在确定性样本上复现负载状态演进与中断恢复一致性问题。本地 JSON 场景文件给出：目标服务描述（由本地 Python 测试服务模拟，监听回环地址，可按路径返回固定状态码、注入慢响应与连接拒绝）、负载阶段计划（阶段序号、并发数、持续逻辑时长、请求节奏）、SLO 阈值（成功率下限、P95 延迟上限）与逻辑时钟步进配置。引擎需按阶段驱动负载，把每个阶段的观测窗口摘要（请求数、成功数、延迟分位数、错误分类计数）持久化到 SQLite，依据 SLO 裁决阶段通过、降级或中止，并在中断后从持久化观测恢复评估状态；同一场景重放两次必须得到逐位一致的阶段摘要与容量结论。

任务环境与准备：
确认本地已安装 Python 3.10 及以上版本与 sqlite3 标准库模块，使用内置 http.server 搭建本地测试服务，无需网络访问。
在空白工作区创建项目目录，准备固定本地场景 JSON 样本与本地测试服务的可配置响应规则样本。
不依赖容器、真实账号或外部服务，所有测试目标均监听回环地址并在本机启动与关闭。

业务要求：
1. 实现场景文件与负载阶段计划的解析校验：校验阶段序号唯一且递增、并发数与持续逻辑时长为正、请求节奏参数合法、SLO 阈值区间有效，构建每个阶段的负载描述；非法场景必须返回明确业务错误码（如 E_BAD_SCENARIO、E_BAD_SLO），不得启动任何负载或写入观测记录。
2. 实现确定性负载驱动与逻辑时钟：请求节奏、阶段持续时长与观测窗口划分全部按注入的逻辑时钟推进，不得读取系统墙钟，使相同场景在任意运行次数与机器上产生相同的请求序列与窗口归属；请求序号、阶段与窗口归属必须可稳定复现。
3. 实现阶段观测窗口摘要与错误分类：按窗口统计请求数、成功数、按状态码与连接拒绝、响应超时、畸形响应分类的错误计数，并以确定性规则计算延迟分位数（固定排序与插值规则）；摘要写入 SQLite 时须带场景内容摘要与阶段版本号。
4. 实现容量结论与阶段状态机：依据每阶段摘要与 SLO 阈值裁决阶段通过、降级通过或中止，并据此决定后续阶段是否继续推进；状态迁移必须依据持久化的前置阶段结论裁决，重启后不得凭内存残留决定阶段是否已通过。
5. 实现强制终止后的恢复一致性：负载驱动在任一阶段被强制终止后，恢复路径依据 SQLite 中的阶段结论、窗口摘要与已提交请求序列号识别未完成窗口与未提交阶段，只补算未完成窗口并继续推进；不得承诺一定生成退出报告，恢复结论仅依赖持久化状态。
6. 实现并发一致性与幂等提交：允许多个评估实例并行驱动不同阶段，通过 SQLite 事务与文件锁保证同一阶段同一窗口摘要只提交一次，重复提交相同窗口结果必须幂等；读取方只能看到完整已提交的阶段结论而非中间态，不得出现阶段已裁决而窗口摘要缺失。
7. 实现异常链路与超时隔离：目标连接拒绝、响应超出单请求超时、响应状态码不符合预期、目标进程意外退出分别映射到不同业务错误码并在摘要中保留可诊断字段；超时必须由真实等待计时与主动中止共同实现而非事后标注，单个请求异常不得中断阶段主循环或污染同窗口其他请求的统计。
8. 提供命令行接口与可重复验证工具：支持 run、resume、status、report、verify 子命令，status 以稳定排序输出 JSON 显示各阶段状态、窗口进度与逻辑时钟当前位置，report 输出容量结论与各阶段摘要，verify 校验持久化观测与阶段结论的一致性；演示脚本使用固定本地场景与本地测试服务运行两次，输出完全一致。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
