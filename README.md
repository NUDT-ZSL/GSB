在空白工作区构建一个面向本地确定性样本的多波段遥感瓦片语义分割增量推理管线，核心问题是大范围瓦片集合上的全局状态收敛与局部重算预算控制。输入为一个本地样本目录：若干多波段瓦片（PNG，固定尺寸，波段语义为红、绿、近红外与高程，像素值由固定种子程序生成，包含农田、水体、建筑、道路四类地物与噪声），一份瓦片索引 JSON（记录行列号、空间范围、邻接关系与波段顺序版本），一份分割配置 JSON（滑窗尺寸与步长、上下文重叠像素、特征阈值、分类权重、类别后处理最小连通面积、重叠区融合策略、并发数、局部重算预算），以及一份叠加层描述（可对指定瓦片局部区域打补丁替换波段值）。管线需完成逐瓦片滑窗特征提取、像素级确定性分类、跨瓦片重叠区融合与类别后处理；用户可反复编辑配置、叠加层与索引版本，每次编辑后只重算受影响的瓦片与融合区域，并在全局一致性与局部重算预算约束下收敛，且增量结果必须与从零全量运行逐像素一致。

任务环境与准备：
安装 Python 3.11 与本地已可用的 NumPy、Pillow 包；若缺失，从本地轮子目录离线安装。
在空白工作区准备样本目录：由固定种子脚本生成的若干多波段 PNG 瓦片、瓦片索引 JSON、分割配置 JSON、叠加层描述文件与多批次编辑序列脚本。
无需网络、无外部账号、不使用容器环境；所有测试在 Windows 本地目录执行。

业务要求：
1. 实现多波段瓦片加载与索引校验层：读取瓦片索引与各 PNG 瓦片，校验波段数、尺寸、行列号唯一性与邻接关系对称性，不合法时输出 E_INDEX_INVALID 或 E_TILE_SHAPE_MISMATCH 业务码并进入失败清单；合法瓦片解码为带行列号、空间范围与波段版本号的数组对象。
2. 实现滑窗特征提取与像素级确定性分类：按配置的窗口尺寸、步长与上下文重叠对每个瓦片生成滑窗，从多波段计算植被指数、归一化水体指数、边缘密度与高程坡度特征，再按分类权重做确定性打分取最高类别，同分按类别编号升序决断；输出每瓦片像素类别图与逐像素得分，禁止任何随机性。
3. 实现跨瓦片重叠区融合与类别后处理：按指定融合策略对相邻瓦片重叠地带做加权投票，权重由重叠像素到瓦片边界的距离确定，平票按瓦片行列号字典序决断；再按最小连通面积剔除碎小类别区域并回填邻接主类别，输出融合后的全局类别栅格与每类面积统计。
4. 实现瓦片级依赖指纹与全局失效判定：为每瓦片计算由波段内容指纹、索引波段版本、分类配置指纹派生的缓存键，为融合区域计算由参与瓦片缓存键与融合策略派生的依赖指纹；当配置或叠加层变更时仅将受影响瓦片及其波及融合区域标记失效并重算，未失效瓦片必须直接复用且不得重复执行特征提取。
5. 实现局部重算预算与收敛调度：每次增量运行依据失效集合与配置中的局部重算预算决定本批次重算的瓦片与融合区域，预算不足时按行列号稳定顺序保留待重算项并以 E_RECOMPUTE_BUDGET_PENDING 记录未收敛项，后续批次继续完成任务；任何批次结束后已收敛部分的全局类别栅格必须与全量结果在对应区域逐像素一致。
6. 实现版本化全局快照整体替换与强制终止恢复：以 manifest 记录全局版本号、配置哈希、索引版本、各瓦片结果版本与融合结果版本，先写临时目录再整体替换；收到可处理退出信号时完成当前瓦片结果与 manifest 的原子落盘后以整数退出码 0 退出；强制终止后重启仅依据已完整替换的瓦片结果与 manifest 判断可复用部分，不得承诺生成完整报告。
7. 实现编辑序列下增量与全量的一致性：从任意初始状态施加包含配置阈值、分类权重、索引邻接与局部波段补丁的编辑序列，每次增量运行得到的全局类别栅格与各瓦片得分图必须与从空白工作区按相同最终输入全量运行的结果逐像素一致；补丁坐标越界或波段长度不符时输出 E_PATCH_OUT_OF_RANGE 并保持该瓦片旧结果与旧指纹不变。
8. 实现并发调度、异常隔离与诊断报告：使用线程池并发执行瓦片特征提取与分类，最大并发数取自配置，每条瓦片任务携带由行列号派生的稳定排序键，最终输出顺序、融合投票顺序与失败清单顺序必须与单线程按行列号顺序执行完全一致；单瓦片异常记录行列号与阶段名后继续其余瓦片；完整运行结束输出 JSON 诊断报告，含各批次失效与复用瓦片数、未收敛项、各阶段耗时、快照版本号、类别面积统计与失败清单。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地瓦片样本执行多批次编辑序列，验证增量与全量逐像素一致、预算未收敛记录及快照版本校验。
