游戏公司的线下活动报名表单需要批量数字化，团队目前只有一个空工作目录和一台装好 Python 的 Windows 开发机，尚未建立任何代码与样本文件。全部输入将由随工程交付的固定种子脚本确定性生成本地样本：每张表单是固定尺寸灰度画布，由确定性笔画模板绘制若干文字块（含印刷体标题与手写字段），并叠加轻度倾斜、噪点与表格线；同时给出逐文字块真值清单（块标识、外接矩形、文本串、置信度下限）与一份 JSON 任务描述，声明检测阈值、识别词表、分块网格、内存预算、单轮逻辑时间预算、并发上限与状态目录。工作台需完成从版面检测、分块归一化、模板匹配识别到整表结果聚合的链路，核心问题是分块并行执行时的预算准入、结果一致性以及中断后的续算恢复。

任务环境与准备：
Windows 10/11，安装 Python 3.11 或 3.12，并执行 pip install numpy 与 pytest。
使用标准库 sqlite3 建立账本数据库，不需要数据库服务或其他外部依赖。
运行随工程交付的固定种子脚本在本地生成灰度表单图像、真值清单与任务描述 JSON，不依赖真实扫描件或网络。
准备输出目录与状态目录，确保当前用户对二者有读写权限。

业务要求：
1. 实现任务描述、图像样本与真值清单的解析校验：读取本地 JSON 任务与灰度图像，校验图像尺寸与声明一致、检测阈值与置信度下限在 [0,1]、分块网格行列数为正整数且能整除图像、并发上限与内存预算为正整数，非法输入返回 E_SCHEMA 或 E_IMAGE 并说明字段位置，且不产生任何输出文件。
2. 实现整幅坐标系下的版面检测：按表格线投影与笔画密度在整幅图像上求候选文字块外接矩形，检测结果只依赖像素内容与阈值参数，不得因分块切分产生被截断的块；同一图像重复检测须得到完全相同的矩形集合，矩形须按左上角坐标字典序输出以便与真值清单逐一比对。
3. 实现分块归一化与模板匹配识别：对每个候选文字块按统一缩放与栅格对齐归一化，再用由词表确定性构造的模板做匹配打分，输出文本串与置信度；归一化缩放比与模板集合须在整表口径下统一，块边界处理不得使用块内局部极值，识别结果对每块只依赖该块像素与词表。
4. 实现并行分块调度与双预算准入：按并发上限使用有界线程池调度分块归一化与识别，同时处于计算中的像素缓冲总量不得超过内存预算；按可注入逻辑时钟计量每轮耗时，超出单轮逻辑时间预算即结束本轮并让出未准入分块，使任意并发度下的轮次数与准入序列可复现。
5. 实现 SQLite 账本与结果一致性裁决：每块识别完成后在同一事务内写入图像标识、块序号、文本串、置信度与内容摘要，只有某图像全部块落入账本后才允许聚合整表结果；聚合结果须与逐块串行识别的结果逐块一致，不得因调度顺序或续算导致同一图像出现重复或缺失的文字块。
6. 实现分块级持久化与断点恢复：状态目录中每块保存归一化中间量与内容摘要，并以由图像内容与任务参数规范化摘要构成的版本标识标注；再次启动时版本一致则复用已完成块只补缺失块，版本不一致则整图重做；强制终止后仅依据账本与已持久化块恢复，不承诺生成退出报告。
7. 处理可处理终止信号与结果原子写出：可处理终止信号只在分块边界生效，写出中断标记并以约定整数退出码退出，未完成块不得留下可被误认为完成的结果；整表结果与诊断报告先写同目录临时文件再整体替换正式文件，替换前读取已有输出的版本标识，版本不同才替换且替换前归档旧版本。
8. 实现异常注入驱动的错误链路与资源释放验证：按任务描述中的异常清单在指定图像注入损坏像素、无法整除的分块声明、账本摘要不符与词表缺失项，工作台须对受影响图像返回可区分的业务码并继续处理其余图像，同时在任一块异常时取消其余待处理块并释放其像素缓冲。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
在本地固定样本上运行工作台，核验分块识别结果与整表一致性、预算调度可复现及中断续算恢复。
