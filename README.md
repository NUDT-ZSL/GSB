音乐院校钢琴伴奏教师与琴房管理记录员需要依据学生课后练习的逐音时序诊断演奏速度稳定性，并决定是否增加陪练。练习记录由确定性生成器按固定种子产出，每个学生有若干曲目的逐音高与起始时刻序列（右手旋律与左手伴奏两路声部，附音符时值标注），以及练习日期序列和该曲目的教师标注参考速度曲线。同一内容以三种格式版本描述：音高编码（MIDI 整数与音名加八度）、时刻单位（毫秒与拍）、速度曲线采样方式（按秒与按拍）各不相同。教师需要把逐音序列转为可核对的逐段速度曲线预测，定位练习中的速度突变与节奏偏移片段，按曲目段落汇总波动评分并给出陪练分配建议，同时保证三种格式版本的预测口径一致，输出需人工复核的片段清单。

任务环境与准备：
在 Linux（WSL Ubuntu）工作区中创建 Python 项目，使用 Python 3.10 及以上版本。
安装第三方包 NumPy 与 SciPy，用于数值计算、局部加权回归、插值与统计检验。
通过固定种子运行仓库内的确定性练习序列生成器，生成三种格式版本的样本数据与内嵌速度真值；不依赖外部音频文件或网络服务。
准备配置文件描述平滑带宽、预测区间水平、稳健标准化阈值与跨版本容差，并提供运行示例脚本。

业务要求：
1. 实现三个格式版本练习序列的归一化读取器：将 MIDI 整数音高与音名加八度音高统一为同一个音高编号，将毫秒与拍的起始时刻统一换算为以拍为单位的浮点时刻（拍速取自每条记录的曲目元数据），将按秒与按拍采样速度曲线插值到统一的时间网格，并保留声部标记与音符时值，输出统一的逐音事件序列对象。
2. 由归一后的逐音事件按音符时值计算每个音的瞬时速度（以拍每分钟计），对左右手声部分别处理，并使用局部加权回归（低带宽参数由输入配置给出）在等间隔时间网格上平滑得到逐段速度曲线，同时输出平滑带宽与网格步长。
3. 对每段平滑速度曲线做滚动窗口的平稳性检验与基于残差累计和的变点检测，定位练习中速度突变（加速或减速超过设定阈值）和节奏偏移（相邻音间隔与参考速度曲线偏离超过阈值）的时间区间，输出每个异常区间的起止时刻、方向与偏移量。
4. 构建趋势项加自回归残差的组合预测模型：趋势项由分段线性拟合给出，残差项用固定阶数的自回归模型拟合，滚动预测后续段的速度波动区间（如 90% 预测区间），并一并输出区间覆盖的置信度与模型参数摘要。
5. 以滚动预测残差的稳健标准化（基于中位数与中位数绝对偏差）判定异常跳音与节奏偏移片段，标准化阈值由输入配置给出，输出异常片段清单及每条对应的证据区间（原始观测、预测残差与标准化值）。
6. 按曲目段落汇总每个学生的波动评分（综合速度变点数量、区间宽度与异常片段占比），映射为练习建议优先级，并按学生分组生成陪练分配建议排序，同时输出每个学生各段落的评分明细。
7. 对同一练习记录在三个格式版本下运行完整处理链，输出跨版本差异清单：逐段速度曲线最大偏差、波动区间起止时刻偏差、异常片段定位差异，并保证归一后速度曲线与异常清单在容差内一致；差异超限的片段须标记为需人工复核。
8. 生成器内嵌的逐音速度真值与人工标注的曲目难点片段作为独立依据，计算逐段速度曲线偏差、波动区间对真实后续速度的覆盖率与异常片段命中情况，报告偏差超阈值的片段清单和整体统计，并支持通过配置文件注入人工构造的含故意提速、停顿与跳音的练习片段来验证异常判定逻辑。

验收：
组件能对三版本练习记录产出统一速度曲线与异常清单，并与真值及标注核对覆盖率与命中率。
