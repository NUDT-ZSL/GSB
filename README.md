项目从零开始，需要构建一个面向 Transformer 前向计算中 Softmax 与 LayerNorm 两类核心算子的本地可视化与诊断工作台。核心业务问题是：当算子任务清单以增量批次持续到达、且分块参数（block_size、axis、eps、dtype）可能被修订时，如何精确判定哪些已算产物失效、仅重算受影响后缀，并保证增量结果与从零全量重算逐字节一致。业务对象是本地确定性生成的算子任务清单（JSONL，字段含 job_id、op_kind（softmax 或 layernorm）、input_shape、block_size、axis、eps、dtype、seed、batch_no、revision）以及由 seed 驱动 NumPy 确定性生成的输入张量。任务被切分为输入校验与分块计划、分块统计、归一化累加、输出写回四个阶段，每个阶段产生带单调递增版本号与内容校验和的产物；用户会追加新批次、修订某任务的 block_size 或 eps、或提升 dtype 精度档。工作台需要展示计算图拓扑、每个阶段产物的缓存命中或重算状态、失效传播覆盖的 job 集合、分块与整段路径的偏差谱、以及最近业务错误码。

任务环境与准备：
使用 Windows 10/11，安装 Python 3.11 或 3.12，并执行 pip install numpy==1.26.4；不依赖容器、GPU、外部服务或真实数据集。
在全新工作目录中创建项目结构，任务清单与输入张量由固定种子在本机确定性生成，无需下载附件。
本地缓存目录与快照目录置于工作区内，执行前确保目录为空或由程序自行初始化。
命令行入口使用 python -m 或脚本方式运行，所有输入、输出与业务码均通过本地文件与标准输出呈现。

业务要求：
1. 实现 Softmax 与 LayerNorm 的统一分块执行入口，按任务清单解析 op_kind、input_shape、block_size、axis、eps、dtype 与 revision，对未知 op_kind、axis 越界、eps 非正分别返回 E_OP_UNSUPPORTED、E_AXIS_INVALID、E_EPS_INVALID 并指明 job_id 与字段；同一 job_id、同一 seed 与同一配置下分块统计、归一化累加与输出必须逐字节可复现。
2. 实现内容寻址缓存与缓存键构造：输入校验与分块计划、分块统计、归一化累加、输出写回四类节点产物各附带内容哈希写入本地缓存目录，缓存键须纳入输入张量内容哈希、op_kind、input_shape、block_size、axis、eps、dtype 与上游产物哈希；键相同必须复用快照，键不同必须重算，并可按 job_id 与阶段名查询键组成与产物哈希以核对复用是否真实。
3. 实现增量更新的依赖失效传播：追加新批次、修订某任务的 block_size 或 eps、将某任务 dtype 提升为更高精度档、或修改输入张量时，计算受影响节点与受影响 job 集合，复用未受影响上游缓存，仅重算受影响后缀；须输出本次重算节点清单、重算 job 清单与复用节点清单，并保证增量结果与从零全量重算逐字节一致。
4. 实现分块路径与一次性整段路径的 float64 一致性裁决：记录最大绝对偏差、最大相对偏差与超出容差的元素位置，超出容差返回 E_TOLERANCE_EXCEEDED 并输出越界位置与偏差谱；Softmax 的在线分母与 LayerNorm 的均值方差跨块归约统计量须能由分块明细合并还原为整段口径，还原偏差超出声明容差返回 E_STAT_MISMATCH。
5. 实现数值稳定性保护：对 eps 下限、分块最大值与归一化分母提供可配置的严格比较与容差带比较两种策略及次正规数保护，保证恰好落在门限附近的元素在重复运行与不同精度档下判定不被舍入翻转；须记录受保护元素位置与保护介入次数，策略或容差非法返回 E_POLICY_INVALID。
6. 实现快照版本识别与整体替换防护：分块计划、容差配置与各 job 统计量快照各携带单调递增版本号与内容校验和，检测到版本号或校验和变化时必须整体替换旧快照而非增量修补，旧版本不得覆盖新版本，回退尝试返回 E_SNAPSHOT_ROLLBACK，损坏或校验和不符返回 E_CACHE_CORRUPT。
7. 实现并发提交控制、四阶段异常注入与异常链路归因：同一时刻只允许一次增量提交生效，并发冲突时后到者立即获得 E_STAGE_BUSY 而不阻塞等待；在输入校验、分块统计、归一化累加、输出写回四阶段分别提供由输入或参数触发的注入点，注入不得修改源码制造，每次注入产生带阶段名与业务码的记录，下游按显式策略降级并携带降级类别与触发它的上游业务码，未被任何阶段归因的异常不得静默吞掉。
8. 提供本地可交互诊断工作台与跨模块一致性自检：展示计算图拓扑、各节点命中或重算状态、失效传播覆盖的 job 集合、分块与整段偏差谱、增量与全量一致性裁决结论、跳过记录理由、降级链路、快照版本与最近业务错误码；自检校验四阶段 job_id 集合一致、重算集合与复用集合无交集且并集覆盖全部受影响集合、分块统计可合并还原整段口径、偏差谱可由偏差明细重算一致，不一致返回 E_INCONSISTENT。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地样本验证增量更新后分块结果与全量重算逐字节一致，并核对失效传播、异常注入与快照整体替换。
