当前为空白工作区，需要从零构建一个面向文生图与图生图场景的本地可视化诊断工作台，核心业务问题是增量更新与依赖失效。系统把一次生成任务建模为有向无环的计算图：文本提示经分词与嵌入得到条件张量，随机种子驱动潜空间初始噪声，采样器按步数逐步去噪，最后由解码模块输出图像。每个节点产出带内容哈希的中间产物并写入本地内容寻址缓存，缓存命中时可跳过重算。当用户修改提示中的词项、调整某几步采样参数、替换局部蒙版或改变种子时，只有依赖这些输入的下游节点需要重算，其余节点必须复用旧缓存；但缓存键必须精确反映所有影响结果的参数，否则会出现张量形状不符或结果被错误复用。图生图路径还需在蒙版区域内部分重绘，区域外像素必须与输入图像逐像素一致。工作台需展示计算图、缓存状态、失效传播范围、重绘前后差异与业务错误码，并暴露本地可视化诊断能力，全部依赖本地确定性样本，不访问网络或真实模型。

任务环境与准备：
安装 Python 3.11 或以上版本，并在本地创建虚拟环境。
安装 NumPy、Pillow、PySide6 以及 pytest，版本以本地可安装的稳定版为准；安装说明仅列为前置条件，未做验证。
准备本地确定性样本目录：以固定种子生成的初始图像与蒙版文件、参数字典 JSON、异常输入样本（非法步数、越界蒙版、重复任务标识），不依赖网络或真实模型权重。
确认工作区为空目录，禁用容器与外部服务，所有任务通过本地进程或线程池执行。

业务要求：
1. 实现确定性生成计算图：把提示分词、嵌入、噪声初始化、逐步采样、解码建成有向无环图，节点数量与连接由参数字典决定；同一输入参数与种子必须产出逐字节一致的中间张量与最终图像，并禁止依赖除固定随机种子与参数之外的隐式全局状态。
2. 实现内容寻址缓存与缓存键构造：每节点产出附带内容哈希的中间产物写入本地缓存目录，缓存键须纳入提示文本、种子、采样步数与调度参数、蒙版摘要、上游节点哈希；键相同的请求必须复用产出的快照，键不同必须重算，不得以文件名或修改时间判断命中。
3. 实现增量更新的依赖失效传播：修改提示中单个词项、调整某段采样步数、替换蒙版或改变种子时，计算受影响节点集合，复用未受影响上游缓存，仅重算受影响后缀；需输出本次重算节点清单与复用节点清单，并保证局部修改后结果等价于从零全量重算的结果。
4. 实现图生图蒙版局部重绘：在蒙版为真的区域内用重算结果合成，蒙版外像素与输入图像逐像素一致；合成后须校验区域外差异为零、区域内像素来自本次重算结果，否则返回业务码 E_MASK_MISMATCH 并指出越界坐标。
5. 实现缓存版本与整体替换：缓存条目携带单调递增的键版本与内容校验和，检测到键版本变化时必须整体替换旧快照而非增量修补；损坏或校验和不符的条目在读取时返回 E_CACHE_CORRUPT 并按明确策略重算该节点，不得把损坏产物传给下游。
6. 实现资源与并发控制：为单次生成的内存估算、缓存条目总量与并行重算节点数设可配置上限，超限时按明确策略返回 E_RESOURCE_LIMIT 或在受限并发下执行；多个任务并发写同一缓存键时须保证只有一个生效、其余读取一致结果，冲突不得破坏已提交条目。
7. 实现可视化与诊断工作台：用本地界面展示计算图拓扑、各节点缓存命中或重算状态、失效传播覆盖范围、重绘前后差异图、本次重算统计与最近业务错误码，并允许点击节点查看缓存键组成与内容哈希，支持触发一次含局部修改的演示运行。
8. 实现跨模块一致性自检与异常链路归因：校验计算图拓扑无环、缓存键与产物哈希互相可核对、复用节点集合与重算节点集合无交集且并集覆盖全部受影响节点；检测到不一致返回 E_INCONSISTENT 并指出不一致类别与节点标识，输入解析失败、磁盘写入失败、参数非法须沿异常链路归因到具体节点或参数名。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地确定性样本验证增量重绘的缓存复用、失效范围与蒙版外像素一致性，并附异常输入下的业务码输出。
