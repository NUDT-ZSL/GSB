当前是空白工作区，需要从零实现一个本地推理服务动态批处理调度与诊断工作台。与既往工作不同，本题的核心业务问题不是批窗口切分与优先级插队本身，而是“批级估算量的精度谱如何在队列水位演进中传播”，并以诊断为主交付：本地 JSON 样本给出模型描述（层名与每层参数量、每请求输入输出 token 数）、副本清单（副本 ID、可用算力单位、显存上限 MiB、最大批大小、最大序列长度、每批次调度配额）、请求轨迹（请求序号、到达逻辑时钟毫秒、服务等级标记、输入 token 数、期望输出 token 数、期望截止逻辑时钟）以及精度诊断配置（每批算力占用与显存占用的估算公式参数、定点标度、浮点容差、误差上界预算、诊断采样比例、逻辑时钟步进）。工作台需在可注入逻辑时钟下推进按调度配额约束的队列水位，把请求组装为批次，按公式估算每批的算力占用、显存占用与队列等待量，专项构建“精度谱”：逐批记录每个估算量的定点串或浮点串、标度、舍入方向、累计误差上界与跨批传播来源，并识别队列水位对估算量误差的放大效应（同一误差项在积压增长时因乘性累计而扩散）。诊断输出以稳定排序 JSON 呈现逐批精度谱、放大标记与可追溯依据；进程被强制终止后须依据持久化状态恢复并继续推进，不承诺一定生成完整退出报告。

任务环境与准备：
安装 Python 3.11 或以上版本，并安装 NumPy 与 pytest（在 Windows 上可离线获取或使用本地 wheel 安装）。
在工作区创建 samples 目录，放置任务自带的确定性 JSON 样本：模型描述、副本清单、请求轨迹、精度诊断配置，以及用于触发放大标记的长积压轨迹与用于触发精度敏感判定的近容差轨迹；样本不依赖网络、账号或外部数据集。
确认 SQLite 由 Python 标准库 sqlite3 提供，无需额外服务；所有测试与演示使用本地文件系统路径，不启用容器或其他虚拟化环境。
准备启动脚本与命令说明，明确各子命令的工作目录与样本路径参数，确保在 Windows 命令行下可直接复现。

业务要求：
1. 实现模型描述、副本清单、请求轨迹与精度诊断配置的解析校验：副本 ID 唯一、算力为正有限数、显存上限与最大批大小为 正整数、最大序列长度不小于任一请求的输入输出 token 数之和、每批次调度配额为正整数、请求序号唯一、到达与截止逻辑时钟为非负整数且截止不早于到达、服务等级标记枚举闭合、定点标度合法，非法输入返回明确 E_ 业务码且不写入任何持久化记录。
2. 实现按调度配额约束的队列水位推进与批次组装：每个逻辑时钟步进从队列取出至多配额个请求并在算力与显存上限内组装为批次，队列水位须显式持久化并随到达与出队确定性演进；同一轨迹在任意运行次数下得到逐位一致的出队序、批次划分与逐时步水位，逻辑时钟回拨超过容差时返回业务码并保持状态不变。
3. 实现每批估算量的双通路计算与精度谱条目生成：每批的算力占用、显存占用与队列等待量须分别走受控定点通路与 float64 通路计算，记录每个量的标度、舍入方向、换算前原始值、每步加法乘法的累计误差上界以及该量在上一步的传播来源（上一批、队列水位或公式参数）；同一输入重跑两通路结果与精度谱逐字段一致。
4. 实现队列水位对估算误差的放大效应诊断：当队列积压超过配置阈值时，须判定哪些估算量的误差上界因水位参与乘性累计而超出误差上界预算，输出放大标记、超预算的首个时步、超预算倍数与参与累计的批号链；不得以后验拟合代替逐步累计，放大标记须仅由已提交批次的精度谱推导，且相同轨迹重复判定结论逐字一致。
5. 实现估算量精度敏感判定与结论翻转追溯：当两个候选批次或两个副本的估算差值小于浮点容差且批次组装裁决依赖该差值时标记精度敏感，输出参与请求序号、换算步骤、误差上界与若换用定点通路是否翻转结论；精度敏感标记与放大标记必须在同一诊断报告中互不覆盖，且均能定位到具体精度谱条目与批次号。
6. 实现请求在队列水位演进下的结局演进与持续状态：请求在排队待入批、已入批、已完成、已超期之间迁移，迁移只依据已提交批次的精度谱与持久化水位裁决，重启后不得凭内存残留决定状态；已超期与执行失败须使用不同结局与业务码区分，同一请求不得被重复累计到任何批的估算量中。
7. 实现强制终止后的恢复与精度谱续算：把时步水位、已提交批次清单与精度谱、队列内容摘要、累计误差状态与逻辑时钟水位以事务原子写入 SQLite；进程在批次提交或精度谱写入中途被强制终止后，恢复路径识别已提交批次与半提交精度谱条目，只重放未完成时步且不得重置累计误差上界，恢复后续算的精度谱与不中断运行逐字段一致。
8. 实现多进程并发一致性、样式化诊断输出与可重复命令行演示：多个诊断实例并发推进同一副本时，通过 SQLite 事务与文件锁保证同一时步同一版本只提交一次、同一请求同一版本只入批一次、队列水位不被并发超扣，重复提交相同批次结果幂等；提供 load、advance、spectrum、resume、status、verify 子命令，spectrum 以稳定排序 JSON 输出逐批精度谱、放大标记与精度敏感标记，verify 校验持久化状态与诊断报告一致并在不一致时返回 E_STATE_MISMATCH。
