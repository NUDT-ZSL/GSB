当前是空白工作区，没有现存项目、代码或数据附件，需要从零构建一个面向 Transformer 输入侧 Embedding 查表与 Gather 组合算子的本地可集成组件与完整示例，核心业务问题是数值精度与误差传播。业务对象是本地确定性生成的算子任务清单（JSONL，字段含 job_id、vocab_size、embed_dim、table_dtype、index_set 描述、gather_axis、reduction_mode、pad_index、scale、quant_scale、quant_zero_point、seed），以及由固定种子驱动的 NumPy 生成的嵌入表、索引数组与位置权重数组。组件把一次调用建模为多级流水：索引校验与越界掩码→按 table_dtype 与量化参数生成嵌入表（低精度档以定点缩放与零点表示）→按索引查表（Gather）→按 gather_axis 与 reduction_mode 做归约或拼接→与位置权重逐元素相乘累加→输出逐 token 向量。业务关注点在于：低精度嵌入表在查表前需反量化，索引重复命中与 padding 索引处理会改变归约权重，定点缩放与舍入模式的选择会沿查表、归约、加权累加三级累积传播；同一任务必须在固定种子与显式配置下逐字节可复现，并能给出以 float64 全精度路径为快照内参考真值的逐级偏差谱与主导误差来源归因。

任务环境与准备：
安装 Python 3.10 及以上与 NumPy 1.24 及以上，仅使用标准库与 NumPy，不引入其他第三方依赖。
在空白工作区创建项目目录，准备本地确定性样本生成脚本，按题目给出的任务清单字段与固定 seed 生成嵌入表、索引数组与位置权重，不依赖任何外部数据集。
提供命令行入口脚本，确保在 Windows 默认终端下可直接运行样例并写出 JSON 报告。
确认工作区无容器环境依赖，所有测试与演示均在本地进程内完成。

业务要求：
1. 实现索引校验与越界掩码阶段：解析索引数组并校验取值落在 [0, vocab_size) 内，pad_index 合法范围内重复出现须形成独立的 padding 掩码，越界索引不得静默截断而须返回 E_INDEX_OUT_OF_RANGE 并指明首个越界位置与 job_id；同一清单与配置下掩码结果必须逐字节可复现。
2. 实现定点嵌入表的反量化与查表（Gather）阶段：按 table_dtype 与 quant_scale、quant_zero_point 生成嵌入表并反量化为浮点权重，再按索引与 gather_axis 取出逐 token 向量；quant_scale 非正或 zero_point 越界须返回 E_QUANT_INVALID，反量化后的表须可由量化表、缩放因子与零点独立重算一致。
3. 实现带 padding 掩码的归约与加权累加阶段：按 reduction_mode 与 gather_axis 对重复命中索引做归约，padding 位置的贡献须按配置口径排除或以零权重计入，并与位置权重逐元素相乘后累加；同一索引重复命中时归约权重须显式记录（命中次数与权重明细），使输出向量可由明细与嵌入表独立重算一致。
4. 实现以 float64 全精度路径为参考真值的逐级误差传播计算：输出反量化、查表、归约、加权累加各级的绝对偏差、相对偏差、误差区间与误差放大比，并定位主导误差来源为反量化、归约权重或加权累加中的哪一级，同时记录观测到的数值分辨率与最大偏差元素位置；主导来源判定须可由逐级偏差明细复核。
5. 实现舍入模式与次正规数保护策略：反量化与加权累加须提供可切换的舍入模式与可配置的次正规数保护，所有中间量以 float64 计算，对外输出统一为带明确精度的区间形式；禁止以放大容差或跳过低精度档掩盖真实偏差，容差策略必须显式记录并可由偏差明细复核。
6. 实现由输入或参数触发的错误注入与异常链路归因：vocab_size 与嵌入表维度不符、索引数组为空、scale 为负、精度档未知、重复 job_id 等分别返回结构化业务码（如 E_SHAPE_MISMATCH、E_INDEX_EMPTY、E_DUP_JOB），每次注入须带阶段名与 job_id 归因；未被任何阶段归因的异常须汇总到结果中，禁止静默吞掉异常。
7. 实现配置、量化参数与误差谱统计的版本化快照及整体替换：三者各携带单调递增版本号与内容校验和，加载时检测到版本号或校验和变化必须整体替换旧快照而非增量修补，旧版本不得覆盖新版本且回退尝试返回 E_SNAPSHOT_ROLLBACK，损坏或不符快照返回 E_SNAPSHOT_CORRUPT。
8. 提供可集成的领域组件接口与完整示例，并实现跨模块一致性自检：暴露 gather_embedding、reduce_and_weight、误差谱诊断与注入诊断入口；自检校验各级处理的 token 位置集合一致、误差区间顺序合法、输出向量可由嵌入表与权重明细重算一致；命令行示例读取本地确定性样本输出含逐级偏差谱、精度档切换、注入记录、业务码与降级标记的 JSON 报告。
