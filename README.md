当前只有一台干净的开发机，需要从零实现一个本地图数据存储引擎的并行遍历与分片索引组件，作为可集成库加完整示例交付。样本以本地目录给出两代图快照：v1 为单文件 JSON，按节点记录节点 ID、标签、邻接表（出边目标与边标签扁平数组）、节点权重与相对写入秒数，并附带按节点 ID 排序的线性索引；v2 为分片 JSON 加 SQLite 元数据库，记录节点规范 ID、出边集合、分片代数、绝对写入毫秒时间戳与删除墓碑。组件需把两代快照合并为统一内存索引，支持精确查询、标签前缀查询与一跳两跳可达遍历，并在每轮并行遍历任务数上限与内存预算双重约束下调度遍历批次；进程被强制终止后必须依据持久化状态只重放未提交批次并给出逐位一致的遍历结论。

任务环境与准备：
安装 Python 3.11 或以上，并执行 pip install pytest 以获得测试运行器；标准库 sqlite3 与 json 即可满足需求，无需第三方图数据库。
在本地磁盘创建样本目录，准备 v1 单文件图快照 JSON、v2 分片 JSON 与对应 SQLite 元数据库，分片哈希与节点摘要由样本脚本预先写入。
确认工作目录具备 SQLite 文件读写权限与临时表创建能力，禁止依赖网络、真实线上站点或任何容器环境。
运行前清空输出目录中的历史状态库以避免残留版本指针干扰；进程终止验证使用操作系统强制终止方式，恢复仅依赖已持久化状态。

业务要求：
1. 实现两代图快照的解析与校验：v1 校验节点 ID 唯一、邻接表条目与出边声明一致、节点权重有限、相对写入秒数为非负整数、线性索引覆盖全部节点且有序；v2 校验分片文件哈希、SQLite 元数据中分片代数单调、绝对写入毫秒时间戳为整数、墓碑标记只出现在已存在节点上；非法条目返回明确业务错误码且不写入任何持久化状态。
2. 实现跨版本合并与统一内存索引构建：同一节点在两代快照中同时出现时依据声明的逻辑时钟与分片代数裁决最新版本，逻辑时钟相同按来源格式优先级；合并出边集合须去重并保留每条边来源版本，冲突边裁决依据可追溯输出；v1 相对写入秒数按注入逻辑时钟换算为绝对写入时刻并记录换算标度、舍入方向与舍入前原始值，墓碑节点须排除出遍历可见集但保留审计记录。
3. 实现统一内存索引的结构与构建顺序：以节点 ID 为键，标签前缀索引、出边目标索引与边标签索引三者在同一构建轮次中按节点 ID 稳定顺序建立，使相同合并视图重复构建得到逐项一致的索引摘要；索引摘要须覆盖节点数、边数与标签前缀集合，并作为后续遍历结论一致性校验的基准。
4. 实现受限遍历执行与结果确定性：支持精确查询、标签前缀查询、一跳与两跳可达及带边标签过滤与深度上限的遍历，BFS 层序、邻居访问顺序与最终结果排序规则固定，边权重只参与过滤不参与累加以规避浮点顺序依赖；同时以单线程逐节点展开计算唯一真值，两条路径逐条比对，不一致须输出首个差异节点、所在层与来源快照版本。
5. 实现并行遍历批次调度与资源预算裁决：同一轮次内按起始节点分组并发执行遍历批次，同时受每轮并行任务数上限与内存预算双重约束，每个候选批次先估算邻接展开占用的索引条目数并与剩余预算比较；预算不足须显式放弃剩余批次并记录放弃原因，严格区分预算内未启动、启动后失败与主动放弃三类结局，已启动批次必须执行完毕，不得以线程超时描述为已终止。
6. 实现遍历进度与索引水位的持久化推进：把索引快照指针、合并裁决、迁移决策、已提交遍历批次水位、批次内容摘要与每批结果摘要以事务原子写入 SQLite，推进前校验批次内容摘要，摘要不匹配须拒绝推进并保持状态不变；状态只能依据已提交批次结果裁决，读取方只能看到完整已提交批次，不得观察到半提交索引与半提交遍历混合的视图。
7. 实现快照整体替换的版本变化识别与强制终止后的恢复：收到新快照包时比较清单版本号、逻辑时钟下限、节点数上下界与各分片哈希，判定完整替换、增量追加或无需操作，版本回退须拒绝并返回业务错误码；整体替换以临时表加版本号整体切换索引指针而非逐条覆盖；进程在合并、替换或遍历中途被强制终止后，恢复路径识别已提交批次与半提交索引，只重放未完成部分且不得重复计入已提交批次结果。
8. 实现多进程并发一致性、幂等提交与可重复命令行验证：多个遍历进程与快照替换进程并行时，通过 SQLite 事务与文件锁保证同一快照版本只提交一次、同一索引版本只被整体替换一次、同一遍历批次同一版本只提交一次，重复提交相同批次结果必须幂等；节点不存在、边标签非法、深度上限非正、分片哈希不匹配、逻辑时钟回拨超阈值分别映射到不同业务错误码，并提供 load、merge、traverse、resume、status、verify 子命令，status 以稳定排序 JSON 输出索引版本、节点数、批次水位与放弃批次原因。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地两代图快照样本验证并行遍历、预算放弃、恢复与结果一致性，并附运行输出。
