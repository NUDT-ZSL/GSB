从无到有搭建时，需要从零构建一个可集成的 RoPE 位置编码分块注意力算子组件与完整示例，核心业务问题集中在旋转位置编码变体配置、分块算子的状态演进与中断恢复一致性上。业务对象是本地确定性生成的注意力任务清单（JSONL，字段含 case_id、seq_len、head_dim、num_heads、base_theta、pos_encoding_variant、pos_scale、kv_revision、block_size、layers、causal、seed），Q/K/V 由固定种子驱动 NumPy 确定性生成，不依赖任何真实模型、线上服务或附件。组件把一次多批次注意力调用建模为多级算子流水，要求在不引入容器的前提下，使用本地文件持久化与本地进程池完成计算，并保证阶段快照的原子提交、强制终止后的恢复以及算子缓存增量失效传播的真实可验证。

任务环境与准备：
确认操作系统为 Windows，Python 3.10 或以上已安装，执行 python -V 可见版本号。
执行 python -m pip install --upgrade pip 后安装 python -m pip install numpy，版本以 pip 解析到的稳定版为准。
在空工作目录下创建项目，运行前确认已生成任务清单 JSONL、缓存目录与快照目录可写。
示例运行命令为 python -m rope_attn.demo --tasks tasks.jsonl --cache .cache --state .state --out report.json，本机不依赖网络与外部服务。

业务要求：
1. 实现确定性的旋转位置编码层与分块注意力打分核心：按 pos_encoding_variant、base_theta、pos_scale 为每个 token 位置计算逐维旋转角并对 Q/K 做半维配对旋转，整数维与半维配对口径显式声明；随后按 block_size 分块完成打分与在线 softmax 归一化，causal 语义下禁止访问未来位置；同一 case_id、seed 与配置下各层中间激活必须逐字节一致。
2. 实现分层分块算子流水线的阶段状态机：把多 batch 执行建模为位置角计算、Q/K 旋转、分块打分与在线归一化、输出写回四个阶段，每阶段对全部层与全部 batch 处理完后才允许提交带单调递增版本号、已完成键集合与内容校验和的阶段快照，快照写入须先落临时文件再原子替换落地，部分完成的阶段不得出现在已提交记录中。
3. 实现基于强制终止的恢复逻辑：执行器在阶段边界提交检查点，进程经外部强制终止后重启时读取最近一次已提交快照，从该快照记录的下一阶段或下一批次继续，已提交阶段的层与 batch 不得重算或重复计入；未提交的中间旋转角与归一化统计量必须丢弃并从阶段起点重建；恢复后的完整输出摘要须与不间断完整运行逐字节一致，同时须区分可处理的 KeyboardInterrupt（在提交边界优雅落盘并输出退出报告）与强制终止（只承诺基于已提交快照的恢复）。
4. 实现算子中间产物的内容寻址缓存与缓存键构造：位置角、旋转后 Q/K、分块打分、归一化统计各自以内容哈希落盘到本地目录，缓存键须纳入该节点全部输入摘要、上游产物哈希、base_theta、pos_scale、block_size、causal 语义与 kv_revision；键相同必须复用快照，键不同必须重算，并提供入口按 case_id 与块序号查询键组成与产物哈希以核对复用是否真实发生。
5. 实现 K/V 修订增量更新的依赖失效传播：当某层某 batch 的 K/V 以更高 kv_revision 追加或替换时，区分仅 K/V 内容变化（影响分块打分与归一化节点）与仅 block_size 变化（影响分块边界与全部下游节点）两类情形，计算受影响节点集合，复用全部未受影响上游缓存，仅重算受影响后缀；须输出本次重算节点与复用节点清单，并校验两者无交集且并集覆盖全部受影响节点，违反返回 E_INCONSISTENT。
6. 实现跨分块在线 softmax 的数值稳定性保护与整段对照：分块最大值与归一化分母以 float64 累加，提供可配置的次正规数保护与舍入模式，并要求各分块统计量可合并还原为整段 softmax 分母，还原偏差超出声明容差返回 E_NUMERIC_UNSTABLE 并指出 case_id、层号与块序号；同时输出分块路径与不分块整段路径逐元素最大绝对偏差与最大相对偏差，偏差明细须可独立重算。
7. 实现并发提交控制与资源预算上限：同一时刻只允许一个阶段快照或一次增量提交生效，并发冲突时后到者立即获得 E_STAGE_BUSY 而不阻塞等待，已完成版本不得被旧版本回退覆盖且回退尝试返回 E_SNAPSHOT_ROLLBACK；为单次调用分块驻留内存估算、缓存条目总量与并行重算节点数设可配置上限，超限时返回 E_RESOURCE_LIMIT 或按明确策略降级到受限并发并在结果中标记降级类别。
8. 实现输入与配置校验链路、异常链路归因以及跨模块一致性自检与完整示例：重复 case_id、seq_len 与数组维度不符、head_dim 为奇数导致配对越界、base_theta 越界、pos_scale 非正、kv_revision 回退、dtype 不支持分别返回结构化业务码并指明字段与 case_id，worker 内异常须以业务码与阶段名回传主进程并归因到具体层号与块序号；自检校验阶段快照版本与阶段名一一对应、缓存键与产物哈希互相可核对、整段分母可还原、重算集合与复用集合无交集且并集覆盖全部受影响节点，命令行示例输出含逐阶段完成计数、偏差明细、失效报告与业务码的 JSON 结果。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
