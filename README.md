需要为一个本地播客与游戏配音制作流程实现离线多轨音频转码引擎。制作方提供若干条单声道或立体声轨道，每条轨道带自己的采样率、位深与起始偏移，要求合成为一条指定采样率与声道布局的成品，并且任意时刻听到的声音都对应正确的源时间点。成品还需要生成逐时段响度统计与可恢复任务状态。输入为本地 WAV 文件清单（JSON 描述每轨文件、目标起始时间毫秒、增益、静音区间）以及输出规格。运行环境为 Windows，依赖本机 ffmpeg 与 ffprobe 可执行文件，样本由程序按要求生成，不依赖任何在线资源。所有错误以 JSON 业务码返回，进程退出码使用整数。

任务环境与准备：
安装 Python 3.10 及以上，安装 NumPy，并将 ffmpeg 与 ffprobe 可执行文件加入 PATH，启动前用 ffmpeg -version 与 ffprobe -version 确认可用。
准备任务执行目录，由角色按题目要求在运行时用脚本生成本地 WAV 样本与轨道清单，不预置二进制音频附件，不访问网络。
确认 Windows 终端可发送 Ctrl+C 类中断信号，并准备用于强制终止的进程结束方式以验证恢复路径。

业务要求：
1. 实现描述文件解析与输入校验：读取多轨 JSON 清单与输出规格，校验轨道文件存在、采样率与位深字段、起始偏移为非负整数毫秒、增益为有限浮点数，非法输入返回带业务码的 JSON 错误且不产生输出文件。
2. 实现时间轴重采样对齐：每条轨道按自身采样率读取后重采样到成品采样率，并按照毫秒偏移换算为整数采样点对齐到统一时间轴，保证轨道间相对时序误差不超过 1 个成品采样点，并在边界处做正确的零填充。
3. 实现多轨混音与声道布局转换：将单声道与立体声轨道按声道映射规则混合到目标声道布局，应用每轨线性增益，超出满量程时按可预期规则做限幅或缩放，混音结果与逐轨叠加的数值参考在容差内一致。
4. 实现静音区间语义：清单中的静音区间按轨道源时间表示，在重采样与偏移对齐后应在成品时间轴上准确静音，与相邻有声片段之间不得出现越界衰减或泄漏，需要在时间轴层面而非文件层面处理。
5. 实现分段响度统计：按输出规格中的统计窗口长度对成品逐窗口计算 RMS 与峰值，写入 JSON 报告，报告中的窗口起止时间与成品采样点严格对应，包含总时长与窗口数量，空窗口也要有确定数值。
6. 实现可恢复的离线任务状态：转码过程按阶段写入持久化状态文件，记录阶段、已完成轨道和输入快照标识；中途被强制终止后再次运行能识别快照版本变化并选择从头重做或复用已完成阶段，强制终止时不承诺生成退出报告。
7. 处理信号与退出语义：外部可发送可处理的终止信号使任务在阶段边界写入中断状态并以约定整数退出码退出，强制终止则依赖已持久化状态恢复；输出文件必须先写临时文件再原子替换，避免留下半成品。
8. 实现并发轨道加载与资源上限：按规格中的并发数并行读取与解码轨道，使用有界线程池和内存预算控制同时在处理的数据量，任一线程失败时取消其余任务并返回首个错误，最终混音顺序与结果不受并发调度影响。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地生成的 WAV 样本运行转码，核对输出时长、时间轴对齐、响度报告与中断恢复行为。
