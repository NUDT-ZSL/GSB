在空白工作区构建一个面向关系与事件抽取结果的领域数据编辑与操作应用，核心解决抽取结果的工程交换格式互操作与版本兼容问题。输入为一个本地确定性样本目录：程序生成的标注文档 JSONL（每行含文档 ID、以空格分隔的词序列及词位置）、一份本地规则抽取配置 JSON（关系触发词表、事件触发词表与论元角色表、实体类型词表、置信度分档）、一份 v1 工程交换文件（每行按固定宽度字段拼接的关系三元组，头部与主体字段均为整数位置与千分比置信度，事件行以关系行尾部追加定长论元段的方式编码）、一份 v2 工程交换文件（JSON，关系与事件分为两个数组，位置用浮点起止秒等价的时间偏移量表示，置信度为 0 至 1 浮点数，带角色命名表与文档级元数据），以及一份编辑命令流 JSONL（加载工程、调整触发词表条目、合并或拆分关系、平移文档内位置偏移、切换目标版本与回放）。应用需把两版工程解析为统一中间表示，执行编辑后按目标版本序列化，并在版本互转时保留降级信息。

任务环境与准备：
Windows 本地环境，安装 Python 3.11 及以上，并安装 NumPy（pip install numpy），无需网络账号或外部服务。
在空白工作区创建项目目录，按题面字段自行准备本地确定性样本：标注文档 JSONL、规则抽取配置 JSON、v1 定宽工程文件、v2 JSON 工程文件与编辑命令流 JSONL，样本可由固定种子程序生成。
准备一份异常注入配置样例，覆盖定宽行超长、置信度越界、事件论元悬空、位置平移越界与角色名非法等注入项。
确认工作区可读写临时目录与目标目录，用于原子替换写盘与快照目录整体替换。

业务要求：
1. 实现双版本工程解析器与统一中间表示：v1 定宽二进制文本行需按字段宽度解析出关系三元组、整数位置与千分比置信度，事件行以其尾段论元定长结构解析出事件类型与论元角色列表；v2 JSON 需解析出浮点偏移位置、0 至 1 置信度、角色命名表与文档元数据；两者统一为关系与事件两级结构，保留来源版本号、原始字段值与原置信度表示；字段宽度不足、行截断、JSON 缺键或位置非递增时分别输出 E_FORMAT_TRUNCATED、E_JSON_INVALID 或 E_SPAN_ORDER 业务码并进入失败清单。
2. 实现版本互转的信息保留与降级策略：v1 升 v2 时把整数位置按可配置换算表转成浮点偏移、千分比置信度除以一千转成浮点并生成角色命名表条目，把原始整数位置与整型置信度写入旁路元数据文件；v2 降 v1 时浮点位置按可配置取整规则折算回整数、置信度重新量化到千分比，并把精度损失明细、无法写入定宽字段的超长角色名与文档元数据汇总成降级损失清单，清单内容参与降级产物指纹计算。
3. 实现关系与事件编辑操作集：提供调整触发词表条目、合并两个同类关系、按词边界拆分关系、对文档内位置偏移整体平移、替换论元角色五类编辑，每次编辑必须同步更新统一中间表示与降级损失清单，并校验编辑后的位置递增、角色在角色表内、事件论元不越出所属事件范围；违反时输出 E_EDIT_INVALID 且不改变当前工程状态，编辑日志记录操作序号与影响条目。
4. 实现版本化快照整体替换与恢复一致性：每次成功编辑或版本切换后以临时文件加原子替换方式写盘快照，快照含全局版本号、统一中间表示内容指纹、降级损失清单哈希、来源版本与操作序号；启动恢复时以快照版本号与当前工程文件内容指纹判断命中与否，命中则跳过重解析，未命中则重解析并输出 E_SNAPSHOT_STALE 后继续；快照须识别来源版本变化，禁止把不同来源版本的条目混入同一快照。
5. 实现跨版本一致性校验与诊断报告：对同一内容分别以 v1 与 v2 序列化再反序列化，比较关系与事件条目数、位置偏差、置信度偏差与论元角色名还原情况，输出 JSON 报告包含逐条目的位置偏差直方图、最大置信度偏差、降级损失条目、往返是否等价标记与业务码摘要；报告须区分可逆降级与不可逆降级，并证明同一输入两次运行的报告逐字节一致。
6. 实现异常注入隔离与失败链路：以独立注入配置指定定宽行超长、置信度越界、事件论元引用不存在关系、位置平移后越界、角色名不在角色表内等异常样例，注入项编号写入报告以证明命中；单条目在解析、编辑、转换任一阶段抛异常时记录文档 ID、条目索引、阶段名、业务码与异常类型并继续处理其余条目，全部命令执行后失败清单非空则以整数退出码 1 结束。
7. 实现并发处理与串行结果一致性：使用线程池并发执行文档解析、编辑影响计算与版本序列化，最大并发数取自配置；每个条目任务携带由文档 ID、条目索引与阶段名派生的稳定排序键，无论线程完成顺序如何，最终关系与事件清单顺序、降级损失清单顺序、编辑日志顺序与失败清单顺序必须与单线程按文档顺序执行逐字段一致。
8. 实现可处理退出语义与编辑序列回放：收到可处理的退出信号时完成当前编辑的快照原子替换与进度记录后以整数退出码 0 退出，进度记录含最后完成的操作序号与快照版本号，恢复后从该操作之后继续；强制终止后仅依据已完整替换的快照恢复并输出恢复点信息，不得承诺生成退出报告；回放整段编辑命令流时从空白工作区重放得到的最终统一中间表示与降级损失清单必须与逐条交互执行的结果一致。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
