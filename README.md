当前是空白工作区，需要从零构建一个面向树模型与集成学习的本地可视化与诊断工作台，核心业务问题是数值精度与误差传播。输入是本地确定性生成的表格样本：由固定种子生成的数值列与类别列特征矩阵及回归目标，以及一份训练配置（树数量、最大深度、学习率、行采样比例、列采样比例、叶节点最小样本数、分裂候选阈值数量、量化档配置、精度模式）。工作台需把梯度提升回归建模为可诊断的多级流水：分裂候选扫描（对每个特征按量化候选阈值统计梯度与二阶导直方图）→ 增益计算与分裂选择→ 叶权重求解→ 逐轮累加更新预测。每一级都产生带内容哈希的中间产物并交由下一级消费，误差会沿直方图量化、分裂增益比较、叶权重除法、学习率缩放与多轮加法累加逐级传播，最终预测偏差可能来自任何一级，因此工作台必须为每个样本与每轮输出误差区间与放大比，并定位主导误差来源，同时保证同一快照同一配置下逐字节可复现。

任务环境与准备：
安装 Python 3.11 与 NumPy，使用本地虚拟环境；不依赖网络与外部服务。
在空白工作区创建项目目录与本地样本生成脚本，样本与配置由固定种子确定性生成并随任务准备好。
准备单机可用的命令行入口与本地界面所需的最小依赖，均本地安装。
准备强制终止与重启的本地演示脚本，用于验证快照恢复与整体替换行为。

业务要求：
1. 实现确定性的梯度提升回归核心流水：按配置的树数量、深度、学习率与采样比例逐轮生成分裂候选、计算增益、求叶权重并累加更新预测，行采样与列采样由固定种子驱动且采样顺序显式可复现；同一输入与同一配置下逐轮预测、中间直方图与最终模型必须逐字节一致，禁止依赖字典遍历顺序、系统时间或任何未声明的外部状态。
2. 实现分裂候选的量化直方图与增益计算层：对每个特征按配置的候选阈值数量做确定性分箱统计梯度与二阶导之和，增益比较须有明确的同分打破规则（按特征索引与阈值升序），并记录每次比较的两个候选及其差值；当候选阈值重复、分箱边界退化或某节点样本数不足时按明确策略跳过并记录跳过类别，不得静默丢弃。
3. 实现叶权重求解的数值稳定性策略：叶权重按负梯度之和与二阶导之和之商求解，须对二阶导之和接近零的叶施加配置化的下限保护，提供可切换的舍入模式与次正规数保护，并保证保护介入与否在每轮报告中标记；保护阈值非法返回 E_CONFIG_INVALID 并指明字段，不得以放大学习率掩盖数值失效。
4. 实现逐级误差传播计算与主导来源归因：以同一输入上的 float64 全精度单轮参考实现为真值，输出量化档、增益计算、叶权重除法、学习率缩放与多轮加法累加各级的绝对偏差、相对偏差、误差区间与误差放大比，并定位主导误差来源为哪一级；偏差明细须可独立重算出误差区间，区间顺序非法返回 E_INCONSISTENT。
5. 实现分裂门限与排序的判定稳定性保护：为分裂增益设定可配置最小增益门限，提供严格比较与容差带比较两种策略；保证恰好落在门限附近的候选在多轮重复运行下判定不被舍入翻转，门限或容差非法分别返回 E_CONFIG_INVALID；策略切换后受影响的分裂须在诊断报告中列出并给出判定翻转计数。
6. 实现训练快照的版本化管理与整体替换：逐轮模型参数、分箱边界与误差统计量各携带单调递增版本号与内容校验和，提交时整体替换旧快照而非增量修补；加载时识别版本号或校验和变化并整体替换，损坏或校验和不符返回 E_SNAPSHOT_CORRUPT 并指明快照类别与版本号，禁止使用部分可解析的损坏数据继续训练。
7. 实现资源上限控制与降级执行：为单轮节点数、特征分箱总数与驻留直方图内存估算设可配置上限，超限时按明确策略返回 E_RESOURCE_LIMIT 或降级到减少候选阈值数量与限制树深的受限模式；降级须在结果中标记降级类别且不得改变已提交轮次的模型与预测，受限模式下的预测须单独标记并能与完整模式核对。
8. 实现跨级一致性自检与可交互诊断工作台：校验各级处理的样本索引集合完全一致、每轮预测可由初始预测与各树贡献独立累加复算一致、误差归因可追溯至偏差明细、被保护叶与跳过分裂记录与实际执行一致；不一致返回 E_INCONSISTENT 并指出不一致类别。工作台展示逐轮损失曲线、误差传播链、主导误差来源、门限翻转计数、快照版本与最近业务错误码，支持触发一次含门限容差切换与一次含降级执行的演示，演示仅用本地确定性样本。
