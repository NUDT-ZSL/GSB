在空白工作区构建一个可集成的中文意图识别领域组件与完整示例，面向本地客服与工单场景的单句意图分类与槽位标注，核心解决可复现验证与异常注入问题。输入为本地合成的 JSONL 语料：每行含样本 ID、中文原始句子、意图标注与可选槽位片段；另提供本地小型资源包，含意图词表（意图名、特征词、权重）、实体词典（品牌、地点、数量、时间四类词条）、字级 BIESO 序列标注参数 JSON（字嵌入哈希表、发射权重、转移权重、特征维度与哈希桶数）、规则表（同义归一与意图冲突规则）以及一份意图识别配置 JSON（并发数、最大编辑批大小、置信度阈值、精度档位、快照提交间隔、可处理退出等待毫秒）。组件需完成句子归一化、意图打分、最大匹配槽位抽取、BIESO 维特比序列标注与结果合并，输出逐样本意图、槽位、置信度与中间得分，并支持以独立注入配置对指定样本施加真实输入故障后复现同一结果。

任务环境与准备：
准备 Windows 上的 Python 3.10 或以上，创建虚拟环境并用 pip 安装 numpy 与 pytest，版本以本地可用索引为准。
在空白工作区创建项目目录结构、配置示例与命令行入口，不得依赖外网模型或真实账号。
准备本地确定性样本：按种子生成中文语料 JSONL、意图词表、实体词典、BIESO 参数 JSON 与规则表，并附一份可选的注入配置样例。
准备 pytest 测试用例所需的本地输入样本与资源文件，使运行不依赖网络与缺失数据集。

业务要求：
1. 实现句子归一化与语料加载层：逐行解析 JSONL 语料与本地资源包，校验样本 ID 唯一、句文本非空、意图标注在意图词表范围内、字序列与槽位片段的位置连续且不越界；对空句、非法 JSON、未知意图与越界槽位分别输出 E_EMPTY_SENTENCE、E_BAD_RECORD、E_UNKNOWN_INTENT、E_SPAN_OUT_OF_RANGE 业务码并进入失败清单，其余样本继续处理。
2. 实现基于词表特征与规则权重的确定性意图打分：从意图词表加载特征词与权重，按命中长度加权、位置衰减与规则表冲突扣分合成每类意图得分，再以减去最大值的稳定形式做归一化得到 0 至 1 置信度；同分按意图名字典序决断，得分与置信度须按精度档位以固定运算顺序保留并写入逐样本结果，禁止任何随机性。
3. 实现实体槽位最大匹配抽取与意图对齐：对归一化文本做品牌、地点、数量、时间四类词典最大匹配，重叠候选按最长优先、同长按词典优先级、再按起始位置升序消解，并把槽位类型与当前意图做兼容校验；被吞并候选记为被抑制项，兼容性冲突时按配置规则降权并记录原因，输出槽位列表、被抑制项与被降权项明细。
4. 实现字级 BIESO 维特比序列标注与结果合并：对句子按当前字、前后字与词表命中长度构造哈希特征，点积打分后在对数域执行 BIESO 解码，输出最优标签序列、路径总分与逐位置候选标签得分；再将序列标注得到的碎片与最大匹配槽位合并，冲突时按来源优先级决断并记录被覆盖片段，合并结果的实体起止字位置须连续且互不重叠。
5. 实现基于内容指纹的增量失效与重算范围判定：为归一化、意图打分、槽位抽取、序列标注与合并各阶段产物计算由上游内容指纹与参数指纹派生的缓存键，为每个意图词条与实体词条记录引用它的样本集合；当词条单条增删或替换、规则表条目变更、模型参数变更时，只使受影响样本的对应阶段及其下游失效并纳入重算集合，未失效产物必须直接复用且不得重复计算。
6. 实现阶段化快照整体替换与恢复一致性：各阶段以临时文件写盘后整体替换提交，快照含阶段名、配置哈希、资源包哈希、已完成样本列表、部分结果摘要与版本号；启动时读取最新快照并校验版本号、配置哈希与资源包哈希，不一致输出 E_CONFIG_MISMATCH 并拒绝续跑，一致时从已完成样本之后继续；恢复运行得到的最终意图、槽位、置信度与失败清单必须与不中断运行逐字段一致。
7. 实现确定性异常注入实验台：按独立注入配置文件对指定样本的指定阶段施加真实输入故障，包括空句文本、字序列缺失、实体词条移除、规则冲突对、置信度恰好等于阈值与非有限模型权重；注入后组件以确定性顺序执行，每条样本须记录命中的注入项编号，同一注入配置与同一输入多次运行的逐样本结果、命中编号与报告字段必须完全一致。
8. 实现并发处理、异常隔离与诊断报告输出：使用线程池并发执行样本各阶段，最大并发数取自配置，每个样本任务携带由样本 ID 与阶段名派生的稳定排序键，最终样本结果顺序、槽位顺序、失败清单顺序与置信度统计须与单线程按样本 ID 串行执行逐字段一致；单样本在任一阶段抛异常时记录样本 ID、阶段名、业务码与异常类型并继续其余样本，收到可处理的退出信号时完成当前样本结果落盘与快照提交后以整数退出码 0 退出，强制终止后仅依据已完整替换的快照恢复；每次完整运行输出 JSON 报告，字段含意图分布、逐阶段耗时、缓存命中与失效次数、注入命中清单、快照版本号与失败清单。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本加注入配置运行，校验意图与槽位结果、失效复用、快照恢复及业务码，输出 JSON 报告。
