在视频剪辑与游戏音频制作中，多轨音频需要离线转码为统一格式，并保持各轨相对时间轴严格对齐。当前为空工作区，需从零开发一个本地命令行工具。输入为多个 WAV 单声道轨（8kHz/16kHz/44.1kHz，16/24bit）及一个 JSON 时间轴清单，清单指定每轨起始偏移（以目标采样率帧数表示，可为负）、裁剪区间、线性增益、目标采样率与目标位深。输出为多轨混音后的 WAV 文件及一次对齐报告 JSON。工具需在目标采样率域内完成对齐、位深归一、增益混音与封装，保证多轨间采样级同步，不依赖外部账号或网络。时间轴真值统一以目标采样率帧索引定义，报告中的帧数与该真值一致。

任务环境与准备：
安装 Python 3.10 及以上，并通过 pip 安装 NumPy 与 soundfile；确认 soundfile 自带 libsndfile 可读写 16/24bit WAV，无需网络。
在本地准备确定性多轨 WAV 样本（8kHz/16kHz/44.1kHz，16/24bit，单声道）与时间轴清单 JSON，样本中的偏移、裁剪与增益值固定可复算。

业务要求：
1. 实现输入解析：读取清单 JSON 与各 WAV 文件，校验采样率属于允许集合、位深为 16 或 24、声道数为 1，对不合规轨记录轨索引并返回业务码 E_FORMAT，其余合法轨继续处理。
2. 实现采样率转换：将各轨按清单目标采样率统一，转换采用有理数比的多相重采样；转换后帧数按四舍五入确定，且与裁剪区间共同决定的有效帧数与理论值误差不超过 1 个目标采样点。
3. 实现位深转换：读取 16/24bit PCM 后统一转成 32bit float 中间表示，24bit 需手写小端三字节解析，归一化除以满量程；转换过程按轨记录是否发生超满量程截断，并写入报告。
4. 实现时间轴对齐：以目标采样率帧索引为真值，按清单起始偏移与裁剪区间将各轨映射到统一时间轴，正偏移前补静音、负偏移从轨头部裁剪，输出总时长取所有轨有效结束帧最大值，空结果时返回业务码 E_EMPTY。
5. 实现增益与混音：按清单增益对每轨应用线性增益后逐帧求和，混音做软限幅且限幅只作用于最终混音；报告中输出每轨在增益后混音前的峰值电平与最终混音峰值，增益顺序与测量点须与报告字段语义一致。
6. 实现输出封装：将混音结果写为指定采样率与目标位深的 WAV，先写同目录临时文件并在成功后整体替换正式文件；替换前读取已有输出文件的帧数与采样率版本信息，版本不同才替换，失败时保留旧文件并返回 E_WRITE。
7. 实现对齐报告：输出 JSON 报告，含每轨输入帧数、转换后帧数、起始帧、结束帧、状态码、错误摘要与混音峰值，业务码统一为 E_xxx 形式；报告须在输出封装成功前写入独立临时文件，二者要么同时更新要么同时保持旧版本。
8. 实现异常处理：对缺失文件、清单字段缺失或非法采样率分别返回可区分业务码 E_MISSING、E_SCHEMA、E_RATE，并在任一轨失败时确保不写出半成品混音；已成功轨的结果不得部分污染正式输出文件。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
