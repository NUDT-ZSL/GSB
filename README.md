项目初始状态是空目录，需要从零构建一个面向音色克隆与发音建模的本地可交互专业应用。业务对象是本地确定性合成的多说话人语音：用固定种子生成若干说话人的基频、共振峰与能量包络参数，按给定发音时间轴拼成 16kHz 单声道 PCM，并为每个说话人生成固定的参考音色片段，另附逐帧真值文件（帧长 20ms，字段含 frame_index、speaker_id、f0_true、energy_true、phoneme_id）与样本清单（JSONL，字段含 utterance_id、speaker_id、ref_id、sample_rate、duration_ms、phoneme_count、clone_seed）。系统需完成参考音色嵌入估计、逐帧发音单元对齐、跨精度档克隆相似度打分，并在数据规模变化时于精确与近似路径间自适应取舍。核心矛盾是参考音色嵌入随注册样本追加而漂移、精度档切换引入误差，而克隆相似度门限判定与发音单元对齐必须跨路径、跨精度档保持可核对的一致性。

任务环境与准备：
安装 Python 3.11（Windows 官方安装包）并确保 python 与 pip 在 PATH 中可用。
安装依赖：python -m pip install numpy==1.26.4。
创建本地工作目录，样本由固定种子在程序内确定性合成，无需下载任何外部数据集、模型或音频附件。
运行前确认工作目录可写，用于存放缓存目录、快照文件与诊断报告；不依赖 GPU、容器或任何真实账号与线上服务。

业务要求：
1. 实现确定性的帧级声学特征提取与发音单元对齐层：按 frame_ms 与帧移切分 PCM，帧边界以样本索引精确确定，计算短时能量、过零率与基频候选，并对每帧按确定性相似度指派发音单元；同一 utterance_id、同一 seed 与同一配置下必须逐字节产出相同特征与对齐标签，同分时按 speaker_id 升序、再按 phoneme_id 升序打破平局，且对齐标签必须落在样本声明的受控音素集合内，越界返回 E_PHONEME_OUT_OF_RANGE 并指明 utterance_id 与帧索引。
2. 实现参考音色嵌入估计与漂移检测：由参考片段估计每个说话人的音色统计量，注册样本追加时须以内容哈希判定参考片段是否变化，仅对变化说话人重估嵌入并输出嵌入漂移量与受影响帧区间；须保证嵌入漂移量可由新旧嵌入与参考片段版本独立复算一致，未变化的说话人嵌入摘要逐字节不变，参考片段缺失返回 E_REF_MISSING。
3. 实现可切换的精度档执行层：float64、float32 与定点缩放整数三档共用同一算子语义，定点档的缩放因子与舍入模式由配置显式给出；同一输入在不同精度档下结果的差异必须仅来自精度损失本身，切换精度档不得改变对齐标签与音素归属，精度档未知或缩放因子非正返回 E_PROFILE_INVALID 并指明字段。
4. 实现逐级误差传播计算与主导来源归因：以 float64 档作为该快照内的参考真值并以逐帧真值文件的 f0_true、energy_true 作为观测口径，输出特征缩放、嵌入归一化、对数变换与相似度累加各级的绝对偏差、相对偏差、偏差分位数与误差放大比，并定位主导来源为哪一级；误差区间顺序非法或某级偏差无法由明细重算时返回 E_ERRPROP_INCONSISTENT。
5. 实现基于数据规模的自适应算法取舍器：按说话人数、总帧数、受控音素数与驻留特征内存余量在精确路径（细帧移、全量相似度比较、精确嵌入归一化）与近似路径（粗帧移、候选剪枝、分块相似度估计）之间选择，输出含规模观测与比较次数估计的取舍记录；同一观测下决策必须逐字节一致，且所选路径必须覆盖全部受控音素，不得遗漏任一受控音素的对齐候选。
6. 实现音色相似度门限与 top-k 排序的数值稳定性保护，以及精确路径与近似路径的跨路径一致性裁决：对克隆音色相似度设定可配置门限与 top-k，提供严格比较与容差带比较两种策略及次正规数保护，保证恰好落在门限附近的样本在多精度档重复运行下判定不被舍入翻转；两路径结果须输出相似度一致率、对齐偏移差异与置信偏差谱，当差异导致相似度不可比对时返回 E_PATH_DRIFT 并说明差异来源。
7. 实现快照版本化管理与整体替换，以及由输入或参数触发的错误注入与异常链路归因：音色嵌入统计量、精度档配置与误差谱统计各携带单调递增版本号与内容校验和，提交时整体替换旧快照而非增量修补，旧版本不得覆盖新版本且回退尝试返回 E_SNAPSHOT_ROLLBACK；采样率非 16000、seed 与片段形状不匹配、ref_id 缺失、utterance_id 重复、phoneme_id 越界分别返回结构化业务码并在结果中标记注入阶段与错误码，下游按显式策略降级并携带降级类别。
8. 提供可交互的专业应用与可重复演示，并实现跨级一致性自检：展示当前版本音色嵌入、逐帧对齐标签、精度档切换结果、误差谱、取舍记录、注入与降级链路、快照版本与最近业务错误码；自检校验各级处理的 frame_index 集合一致、误差区间顺序合法、定点档偏差可由缩放因子与舍入模式重算出、重算集合与复用集合无交集且并集覆盖全部受影响帧，不一致返回 E_INCONSISTENT 并输出首个差异位置。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
