当前是空白工作区，没有现存项目、代码或数据附件，需要从零构建一个面向 LLM 偏好对齐与奖励建模数据准备的本地可视化与诊断工作台，核心业务问题是数值精度与误差传播同增量失效追踪的耦合。业务对象是本地确定性生成的偏好对样本（JSONL，字段含 pair_id、prompt、chosen、rejected、annotator_group、quality_notes），以及一份构造配置：质量打分各分项权重、去重相似度阈值、标注者一致性平滑系数、采样配额目标、数值精度档（float64、float32 与定点缩放整数）、定点缩放因子与舍入模式。工作台把构造建模为多级流水：质量打分（长度、重复率、噪声字符比例加权）→ 近重复检测（文档给出的分词与签名相似度）→ 标注者一致性加权 → 配比采样 → 奖励建模数据集清单，每级产物落内容寻址缓存并记录缓存键。每一级输出数值都作为下一级输入权重，缩放、下溢保护、门限比较与舍入策略沿级联传播并改变最终采样权重；同时修正单个标注者样本、调整权重或门限时会触发部分级重算，而重算后的误差统计必须与全量重跑口径一致。工作台需同时输出每样本权重置信区间、误差放大比、主导误差来源归因与失效传播覆盖范围，并保证同一快照同一配置重跑结果逐字节一致。

任务环境与准备：
确认 Windows 本地可用的 Python 3.10 及以上解释器，并安装 NumPy（安装说明仅作准备，未实际验证）。
在空白工作区创建项目目录，全部样本（偏好对 JSONL、配置、签名参数）由程序按固定种子确定性生成，不依赖外部数据或网络。
运行前确认工作区可写入本地缓存目录与快照目录，用于内容寻址缓存与版本化快照的持久化。
诊断工作台采用本地进程内界面或本地静态页面，仅读取本地生成样本与持久化快照，不依赖在线站点、账号或付费资源。

业务要求：
1. 实现确定性的质量打分与近重复检测级：质量分由长度、重复率与噪声字符比例按配置权重加权得到，相似度按文档给出的签名相似度口径计算；同一输入同一配置下必须产出逐字节一致的质量分、相似度与候选保留集合，同分时按 pair_id 升序打破平局，并输出每个样本的分项贡献明细使加权分可由明细重算一致。
2. 实现可切换精度档的执行层：float64、float32 与定点缩放整数三档共用同一算子语义，定点档的缩放因子与舍入模式由配置显式给出；同一输入在不同精度档下结果差异必须仅来自精度损失本身，切换精度档不得改变样本参与集合与级联顺序，并要求记录每档的中间量位宽与缩放记录。
3. 实现分数沿级联的误差传播计算：以 float64 档为该快照内参考真值，输出质量加权、相似度门限比较、一致性平滑、采样权重归一化与定点量化各级的绝对偏差、相对偏差、误差区间与误差放大比，并定位主导误差来源为加权打分、门限比较、归一化或定点量化中的哪一级，同时给出归因所依据的偏差明细。
4. 实现门限与一致性平滑的数值稳定性保护：对相似度门限与质量分门限提供严格比较与容差带比较两种策略及次正规数保护，标注者一致性平滑须对零样本或极小分母施加配置化下限保护，保证恰好落在门限附近的样本判定在多精度档重复运行下不被舍入翻转，保护介入与否必须逐样本标记。
5. 实现配比采样与欠配归因：在每标注者组与每质量档的采样配额下做确定性采样，优先满足总量并允许受限欠配；清单须记录每个配额目标的实际达成量、欠配原因与采样种子，使同一快照同一配置重跑得到相同清单与相同采样权重，且清单中每条样本的最终权重可由逐级明细独立重算一致。
6. 实现增量修正的依赖失效传播：当修正某标注者组样本、调整质量权重或相似度门限时，按内容哈希缓存键计算受影响级与受影响 pair_id 集合，复用未受影响上游缓存产物，仅重算受影响后缀；须输出本次重算级清单与复用级清单，并保证重算后的误差统计与从零全量重跑在同一精度档下逐字节一致。
7. 实现配置校验与样本级异常的异常链路归因：权重不为正、门限越界、平滑系数非法、精度档未知、缩放因子非正或过大、重复 pair_id、chosen 或 rejected 为空分别返回结构化业务码并指明字段与 pair_id；样本级异常不得中断其余样本处理，须汇总归因到具体样本与阶段，且异常样本不得计入清单与误差统计，禁止静默吞掉异常。
8. 实现快照版本化整体替换、资源上限与可交互诊断工作台：清单、统计量与误差谱快照各携带单调递增版本号与内容校验和，版本或校验和变化时整体替换而非增量修补，回退尝试返回对应业务码，损坏快照返回 E_SNAPSHOT_CORRUPT 并指明类别与版本；为单批样本数、签名比较候选数与清单内存估算设可配置上限，超限返回 E_RESOURCE_LIMIT 或降级并标记降级类别且不改变权重口径；工作台展示各级分数分布、误差传播链、失效传播覆盖范围、保留集与剔除集、配额达成与最近业务错误码，并校验保留集与剔除集无交集、清单可追溯。
