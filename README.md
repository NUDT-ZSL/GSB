当前是空白工作区，需要从零构建一个面向搜索排序前链路的查询理解与意图解析组件，并附带可复现的实验环境。输入是本地确定性生成的搜索查询日志（JSONL，字段含 query_id、query_text、session_id、timestamp_ms、locale、raw_clicks 列表）以及本地构建的意图标签体系（domain、intent_class、slot_schema）、领域词典与繁简/全半角映射表。组件需要完成查询归一化、分词、span 级槽位识别、层级意图判定，并用点击日志做离线评估。核心业务难点是数据规模变化下的方法取舍：小规模查询集上可以做全词典精确匹配与两段式消歧，规模变大后必须切换到受限候选剪枝与近似消歧，而两种路径产出的意图与槽位必须保持口径可比，同时规模跃迁时预算与精度之间的取舍要可解释、可复现。

任务环境与准备：
安装 Python 3.11 与 NumPy，使用虚拟环境隔离，无需联网。
在本地生成确定性查询日志、意图标签体系、领域词典、繁简与全半角映射表样本，固定随机种子。
准备固定点击日志样本与预期指标口径说明，作为离线评估输入。
确保工作目录具备本地持久化写入权限，用于快照与报告落盘。

业务要求：
1. 实现确定性查询归一化与分词层：依据随附繁简映射、全半角映射与领域词典，将原始 query_text 归一化为规范串并产出带码点起止偏移的 token 序列；同一输入与配置下必须逐字节可复现，映射表缺项与词典截断须返回 E_MAP_MISSING 与 E_DICT_TRUNCATED。
2. 实现 span 级槽位识别与层级意图判定：基于标签体系与 slot_schema 输出 domain、intent_class 与槽位 span（含起止偏移、槽位名、正规化值、置信分数），偏移以规范串码点计；span 必须落在规范串范围内且互不非法重叠，同分时按槽位名升序打破平局。
3. 实现基于点击日志的意图消歧与离线评估：用 raw_clicks 构造伪相关反馈，对歧义查询在候选 intent_class 间做确定性重排序，输出 top-k 意图、NDCG 与 MRR；评估须记录所用点击窗口与置信口径，指标可由逐查询明细独立重算一致。
4. 实现基于数据规模的方法取舍器：按查询数、词典条目数、平均 token 数与驻留内存余量，在全词典精确匹配加两段式消歧与受限候选剪枝加近似消歧两条路径间选择，输出含规模观测与代价估计的取舍记录；同一观测下决策逐字节一致，所选路径完整覆盖所有查询。
5. 实现精确路径与近似路径的跨路径可比性裁决：对同一查询集合同时产出两条路径结果，输出意图一致率、槽位偏移差异与置信偏差谱，并说明差异来自候选剪枝遗漏还是消歧口径不同；当差异导致指标口径不可比时返回 E_PATH_INCOMPARABLE 并指出首个不可比查询。
6. 实现匹配比较次数与驻留内存的双重预算准入：按查询数与词典候选数估算比较代价，在总比较预算与内存上限内决定准入规模与是否降批；超限时返回 E_MATCH_BUDGET 或 E_RESOURCE_LIMIT，并以显式优先级规则在精度、内存与进度间裁决且在取舍记录中说明理由。
7. 实现标签体系与配置的版本化管理及整体替换：标签体系与词典携带单调递增版本号与内容校验和，加载时识别版本变化并整体替换旧快照而非增量合并，旧版本不得覆盖新版本且回退尝试返回 E_SNAPSHOT_ROLLBACK，损坏快照返回 E_SNAPSHOT_CORRUPT。
8. 实现四阶段异常注入与跨阶段一致性自检：对归一化、分词、槽位、意图阶段提供由输入或参数触发的注入点，每次注入产生带阶段名与业务码的记录，下游按显式策略降级并携带降级类别；自检校验归一化串、token、span 与意图可互相核对，不一致返回 E_INCONSISTENT 并指出类别。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
