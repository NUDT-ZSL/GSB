在空白工作区构建一个面向本地确定性样本的中文命名实体识别（NER）领域组件与完整示例，核心解决实体识别结果在增量更新时的依赖失效判定问题。输入为一个本地样本目录：语料 JSONL（每行含句 ID、以空格分隔的字序列与字位置）；一份 BIESO 序列标注模型参数 JSON（字嵌入哈希表、标签转移权重、发射权重、特征维度与哈希桶数）；一份词典 JSON（人物、地点、机构三类实体词条及词频），词典支持增量替换与单条增删；以及一份增量配置 JSON（并发数、最大编辑批大小、词典变更模式、失效判定指标列表、快照目录、版本号策略）。组件需完成字级特征抽取、BIESO 维特比解码、实体边界与类型抽取、基于词典的实体后校验，并在词典或模型参数变更后只重算受影响的句子与实体，输出可验证的增量与全量一致性报告。

任务环境与准备：
安装 Python 3.10 及以上版本，并安装 numpy 依赖（pip install numpy）。
准备本地样本目录，包含语料 JSONL、BIESO 模型参数 JSON、实体词典 JSON 与增量配置 JSON，全部由脚本按固定种子生成，无需外部下载。
确认工作区为空且具备可写快照目录，运行前清理旧快照以保证从空白状态开始验证。

业务要求：
1. 实现语料与参数加载层：逐行解析语料 JSONL，校验句 ID 唯一、字序列非空、字位置连续；加载模型参数与词典，校验特征维度与哈希桶数一致、标签集合完整、词条类型合法；不合法输入分别输出 E_CORPUS_INVALID、E_MODEL_SHAPE_MISMATCH 与 E_DICT_INVALID 业务码并进入失败清单，其余合法项必须继续处理。
2. 实现字级特征抽取与 BIESO 维特比解码：按当前字符、前后各一字符、词表命中长度与位置构造哈希特征，点积打分后在对数域执行 BIESO 维特比解码，输出每句最优标签序列、路径总分与逐位置候选标签得分；同分时按标签字典序决断，全程禁止随机性，同一输入与参数必须得到逐字段一致的结果。
3. 实现实体边界抽取与词典后校验：从标签序列切出实体片段并标注人物、地点、机构类型，再以词典最长匹配做边界修正与类型覆盖，冲突时按词频与词条长度决断并记录被修正项；输出每个实体的起止字位置、类型、来源（模型或词典）与置信度，同一实体不得重复计入且不得跨越句子边界。
4. 实现词条级与句级依赖指纹及精确失效判定：为每个实体计算由词条内容指纹、模型参数指纹与句内容指纹派生的缓存键，为每句记录其命中词条集合与模型版本；当词典发生单条增删或替换、或模型参数变更时，仅将引用受影响词条或模型的句子纳入重算集合，未受影响句子的实体结果必须直接复用且不得重复解码。
5. 实现版本化快照整体替换与失效识别：以 manifest 记录全局版本号、模型参数哈希、词典哈希、已完成句列表与各句结果版本，写入时先写临时目录再整体替换；启动恢复时以 manifest 版本号、模型哈希与词典哈希判断是否命中，任一不符则输出 E_CONFIG_MISMATCH 并按配置策略从一致阶段重启，快照不得出现半替换残片。
6. 实现批大小约束下的增量与全量等价性：按配置的最大编辑批大小分批应用词典编辑与模型参数变更，每批完成后执行增量重算；对同一最终输入，分批增量运行得到的全部实体结果、逐句标签序列与路径总分，必须与从空白工作区一次性全量运行的结果逐字段一致，比较须覆盖单条增删、批量替换与类型覆盖冲突三类编辑。
7. 实现并发解码与串行结果一致性：使用线程池并发执行句子解码与实体后校验，最大并发数取自配置，每个句子任务携带由句 ID 派生的稳定排序键；无论线程调度顺序如何，最终句子结果顺序、实体顺序、被修正项顺序与失败清单顺序必须与单线程按句 ID 升序执行的结果完全一致。
8. 实现异常隔离、退出语义与增量报告输出：单句在特征构造、解码或后校验阶段抛异常时记录句 ID、阶段名、业务码与异常类型并继续其余句，后续批次不得再对该句产出实体；收到可处理的退出信号时完成当前批快照原子替换与进度记录后以整数退出码 0 退出；输出 JSON 报告含各句实体清单、被修正项、重算与复用句数、版本号、配置与词典哈希及失败清单，报告以原子替换写盘。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地样本验证增量与全量实体结果逐字段一致、依赖失效精确及异常业务码与快照恢复正确。
