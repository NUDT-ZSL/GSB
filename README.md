当前是空白工作区，没有现存项目、代码或数据附件，需要从零构建一个可集成的对话级语音情感分析领域组件与完整示例，核心业务问题是逐帧特征与段级分数的增量缓存及依赖失效追溯。业务对象是本地确定性合成的多说话人对话语音：用固定种子生成若干说话人的基频、共振峰、能量包络与语速参数，按给定对话时间轴与增益叠加为 16kHz 单声道 PCM，并附逐帧真值文件（帧长 20ms，字段含 frame_index、speaker_id、valence、arousal、is_speech）、对话清单（JSONL，字段含 dialog_id、sample_rate、duration_ms、seed）与说话人注册清单（JSONL，字段含 speaker_id、ref_seed、ref_duration_ms、embedding_version）。处理链路建模为有向无环图：分帧特征节点产出逐帧能量与过零率等特征，说话人嵌入节点由注册清单估计每个说话人嵌入并逐帧指派，段级情感回归节点按说话人连续段回归 valence 与 arousal，对话级聚合节点按段时长加权汇总。每个节点产物写入本地内容寻址缓存，支持在注册样本追加、真值修正、帧移调整等局部变更时只重算受影响后缀，并能对历史分数进行追溯与重放。

任务环境与准备：
安装 Python 3.10 及以上版本，并确保 numpy 可用（无外部网络依赖，使用本地已安装包）。
在空白工作区创建项目目录，生成确定性合成对话音频、逐帧真值文件、对话清单与说话人注册清单的脚本作为任务输入。
准备本地缓存目录与输出报告目录，确保具备读写权限。
提供示例运行命令说明，示例仅依赖本地文件与本地进程，不连接任何外部服务。

业务要求：
1. 实现确定性的分帧特征图节点：按 frame_ms 与帧移切分 PCM，帧边界以样本索引精确确定，计算短时能量、过零率、谱质心与谱滚降，输出逐帧特征矩阵与帧数；同一 dialog_id、同一 seed 与同一配置下必须逐字节产出相同特征，且帧数须与逐帧真值文件一致，不一致返回 E_FRAME_COUNT_MISMATCH 并指明 dialog_id 与期望帧数。
2. 实现说话人嵌入更新与逐帧指派的图节点：由注册清单估计每个说话人的嵌入统计量，对每帧做确定性相似度打分并指派说话人，同分按 speaker_id 升序打破平局，输出逐帧标签与连续段边界；须校验标签落在对话声明的说话人集合内、段边界首尾相接且覆盖全部帧，违反返回 E_SPEAKER_SET_INVALID 或 E_SEGMENT_GAP 并指明帧位置。
3. 实现段级情感回归与对话级聚合的图节点：按说话人连续段对 valence 与 arousal 做确定性回归并给出每段置信区间，对话级按段时长加权聚合并显式记录权重口径；聚合结果须能由逐段明细与权重独立重算一致，区间上下界顺序非法返回 E_INTERVAL_INVALID，重算不一致返回 E_INCONSISTENT 并指出不一致类别。
4. 实现内容寻址缓存与缓存键构造：每个节点产物附带内容哈希写入本地缓存目录，键须纳入音频分块内容哈希、注册样本版本、帧移与切段阈值、真值修正版本与上游节点哈希；键相同必须复用，键不同必须重算，且每个缓存条目须记录其键组成明细以便诊断，缓存键与产物哈希不可互相核对时返回 E_CACHE_KEY_MISMATCH。
5. 实现增量更新的依赖失效传播：追加注册样本、修正单段真值标签、调整帧移或切段阈值时，计算受影响节点与受影响帧或段集合，复用未受影响上游缓存，仅重算受影响后缀；须输出本次重算节点清单与复用节点清单，并保证局部修改后的完整分数与在不含缓存的全量重算结果逐字节一致，不一致返回 E_INCREMENTAL_DIVERGENCE 并指出首个偏离的段。
6. 提供旧分数追溯能力：对任一此前产出的段级或对话级分数，可按其记录查询当时所用缓存键、输入版本与节点路径，并用这些键重放出相同分数；追溯链断裂或键无法复现分数时返回 E_LINEAGE_BROKEN 并指出断点节点与键，且追溯查询不得修改现有缓存或分数。
7. 实现缓存与配置的版本化整体替换与并发写控制：缓存条目与配置快照携带单调递增版本号与内容校验和，检测到版本号或校验和变化时必须整体替换旧快照而非增量修补，损坏或校验和不符返回 E_CACHE_CORRUPT 并指明条目与版本；多个并发写同一缓存键时只允许一个写入生效，后到者获得 E_CACHE_BUSY 而不阻塞覆盖已提交条目。
8. 实现配置与输入校验链路、资源上限、跨节点一致性自检及完整示例：采样率非 16000、frame_ms 非法或帧移超过帧长、重复 dialog_id、注册清单缺失 speaker_id 分别返回 E_CONFIG_INVALID、E_DUP_DIALOG 或 E_REGISTRY_INVALID 并指明字段；为驻留特征内存估算、缓存条目总量与并行重算节点数设可配置上限，超限返回 E_RESOURCE_LIMIT 或降级并标记降级类别；自检校验复用集合与重算集合无交集且并集覆盖受影响集合、各节点处理的帧或段索引口径一致，并提供命令行示例读取本地合成样本输出含逐段分数、置信区间、失效报告、追溯结果与业务码的 JSON 报告。
