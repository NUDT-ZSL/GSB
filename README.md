区域医疗信息交换平台的存储运维工程师负责把多家医院与独立检验中心共享的检验预约记录、检验结果摘要与预约附件作为对象，放置在本地机房与两个异地灾备/近线区域。每个交换对象带来源机构、检验类别、急缓等级、字节数、创建与到期时刻与内容摘要，每个区域带容量、已用水位、健康状态、网络时延与合规级别，机构目录又规定某些机构的检验结果只能落在满足对应合规级别的区域。运维工程师既要按急缓加权与网络时延算出每个对象的候选区域得分，又要在容量水位约束下避免热点区域越限；当某区域健康状态降级或水位越限时，必须只对受影响对象重解指派并给出逐对象的重定位进度，同时保证各区域引用清单与内容摘要可对账。

任务环境与准备：
在 Linux（WSL Ubuntu）下准备 Python 3 运行环境，仅使用标准库，无需安装第三方包。
在工作目录中自行组织交换存储工程样本、事件序列与输出报告的存放位置，全部样本由固定种子在本地生成，不使用真实医疗机构、线上服务或外部账号。
运行入口需能接受工程清单路径与种子参数，并按本题要求输出错误清单、指派方案、逐时刻演化、重定位计划与对账结果。

业务要求：
1. 解析交换存储工程中的机构目录、检验对象清单、区域节点声明与按逻辑时刻排列的访问与到期事件序列，校验机构、区域与对象之间的引用完整性、字节数非负、到期时刻不早于创建时刻以及急缓等级取值合法，输出带对象标识与来源机构定位的错误清单并拒绝继续处理非法工程。
2. 对每个交换对象按急缓加权系数与候选区域时延计算放置得分，同时应用网络时延上限与来源机构的合规区域要求过滤候选区域，输出每个对象的指派区域、选取得分与未入选候选区域的逐项落选原因。
3. 在容量水位阈值约束下以贪心加局部调整求解指派，使各区域承载字节数不超过总容量与水位阈值之积，标记仍然越限的区域并输出需要迁出的对象集合与迁出后预测水位。
4. 按逻辑时刻推进访问与到期事件，到期对象的引用计数递减并在归零时从区域承载集合中移除，急缓标记决定事件处理次序，输出每个逻辑时刻各区域承载字节数与水位的逐时刻演化。
5. 当区域健康状态降级或水位越限时，依据区域承载集合与合规依赖推导受影响对象集合，仅对受影响对象重解指派并生成含迁移顺序、目标区域与预计字节增量的重定位计划，未受影响对象的指派保持不变。
6. 维护各区域对象引用清单与逐对象内容摘要，按内容摘要与引用计数对账，输出不一致条目及副本归属差异，并记录首个不一致对象及其所在区域作为独立判断依据。
7. 输出放置前后的区域分布对比，包括各区域对象数、承载字节数、越限区域变化以及急缓等级在时延上限内的满足率，满足率按急缓加权系数加权统计。
8. 重定位计划按逐对象记录待迁移、已迁移与失败三类进度，迁移目标区域在迁移进行中若发生健康降级则将该对象标记为失败并给出原因码，最终各区域引用清单须与计划执行结果一致。

验收：
以手工构造的小型区域与对象清单按给定公式独立核算得分、指派、越限迁出与重定位计划，并与全量重解逐对象比对一致。
