当前是空白工作区，需要从零构建一个面向本地 Windows 环境的分布式数据并行训练检查点与恢复一致性验证工具，属于 ML 训练与推理系统方向。系统以本地确定性样本（固定随机种子的合成分类数据与一个小型多层感知机）在 4 个逻辑工作进程上执行数据并行训练，每个工作进程持有模型分片的参数副本与优化器状态，并按固定步数训练。核心业务是：在训练过程中按步创建检查点（含全部分片参数、优化器动量、随机数状态、数据游标与全局步数），并支持从任一检查点恢复训练；当训练配置发生演进（模型维度、优化器超参数、数据分片方式或检查点格式版本变化）时，必须识别状态版本差异并整体替换而非增量合并，恢复后的继续训练必须与不中断训练逐位一致。用户可通过 Tkinter 桌面界面或脚本交互查看分片状态、检查点列表与恢复校验结论，并可重复演示完整流程。

任务环境与准备：
Windows 本地环境，安装 Python 3.10 及以上与 NumPy、Tkinter（随官方安装包提供），无需 GPU 与网络访问。
在空白工作区创建项目目录，准备确定性样本数据生成脚本与演示脚本入口，确认可执行 python -m 形式启动。
预留本地磁盘目录用于检查点与临时写入，确认路径可读写并允许原子重命名。
运行前确认无其他进程占用界面演示所需资源，样本参数与随机种子以配置文件形式提供。

业务要求：
1. 实现本地确定性训练数据与模型初始化：以整数随机种子、样本数、特征维度与隐藏层维度生成固定数据集与初始参数，相同参数组合多次运行必须得到逐位一致的初始参数与批次划分；数据与参数摘要须写入训练报告，摘要不一致时以 E_INIT 业务码报告。
2. 实现 4 个逻辑工作进程上的数据并行训练循环：每步各工作进程用本地批次计算梯度，按梯度平均聚合后更新参数并递增全局步数；聚合顺序须固定不依赖进程调度，训练步数、学习率与批大小为整数参数，训练配置摘要须随步数单调变化。
3. 实现多分片检查点的原子写入：检查点包含每个工作进程的参数分片、优化器动量、随机数状态、数据游标与全局步数，写入须先落临时目录再原子替换，并在清单中记录格式版本号与内容摘要；写入中断不得留下可被误认为完整的检查点，残留须以 E_CHECKPOINT 报告。
4. 实现检查点格式版本识别与整体替换恢复：清单格式版本变化（如字段增减或摘要算法口径变化）时须识别差异并以整体替换方式重建内存状态，禁止把新旧字段增量合并；恢复后须先校验各分片摘要与清单一致，不一致以 E_RESTORE 报告并拒绝恢复。
5. 实现训练配置演进下的恢复兼容判定：当模型维度、优化器超参数或数据分片方式与检查点记录不一致时，按显式规则区分可兼容迁移（如仅学习率变化）与不可恢复（如维度变化），不可恢复须以 E_CONFIG 拒绝并列出冲突字段，可兼容迁移须在报告中标注迁移步骤与状态版本。
6. 实现恢复后续训与不中断训练的逐位一致性校验：从检查点恢复并继续训练若干步，与不中断训练同区间逐位比较参数、动量与全局步数，差异须定位到首个不一致的工作进程、参数名与步数并输出 E_DIVERGE；一致性结论须能在界面与报告中稳定重现。
7. 实现恢复后的一致性重放校验：对同一检查点在相同训练配置下重复恢复两次并重放相同步数，两次运行须得到逐位一致的结果摘要；因配置或分片方式不一致导致不可复现时须以 E_REPLAY 报告并说明不可复现的具体原因，重放不得修改原始检查点。
8. 提供 Tkinter 交互界面与可重复演示脚本：界面展示各工作进程分片摘要、检查点列表与格式版本、训练步数、恢复结论与差异定位，渲染顺序稳定；附带样本配置与演示脚本，顺序执行冷启动训练并建检查点、配置演进后恢复、恢复重放校验三个场景并输出稳定总结。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
