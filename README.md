当前为空白工作区，需要从零构建一个面向图像修复与风格迁移的本地可交互专业应用，核心业务问题是格式互操作与版本兼容。业务对象是本地确定性生成的样本：由固定种子生成的 RGB 像素数组与对应的掩码区域，修复任务把掩码区域重建，风格迁移任务把参考风格的统计特征迁移到内容图上。每次处理产出一份结果包，结果包需要同时以三个版本格式持久化并互相转换：v1（JSON，像素以 8 位量化整数与基础元数据存储，无掩码校验字段）、v2（在 v1 基础上加入掩码校验和、浮点精度标记、区域来源标记与逐区域修复置信度）、外部交换格式（自定义二进制容器，含魔数、版本头、大端存储的像素块与 CRC32 校验）。难点在于三个格式版本在量化深度、区域语义、校验字段上互不兼容，且修复与风格迁移共享中间缓存，用户切换格式版本或局部重绘时既要保证往返精度可核对，又要正确判定哪些缓存条目失效。

任务环境与准备：
安装 Python 3.10 及以上版本，并在项目虚拟环境中安装 NumPy 与 PyQt5（使用 pip 安装官方发布版本）。
确认工作目录为空，运行前由程序自行创建缓存目录、结果包目录与演示样本目录。
准备本地确定性样本生成脚本的输入参数（固定种子、图像尺寸、掩码区域），无需任何外部数据集或网络资源。
准备注入用异常输入：一个截断的二进制容器文件、一个魔数合法但版本头不支持的容器、一份超出资源预算的参数配置。
所有运行与验收在 Windows 本地完成，使用本地进程池与本地文件系统，不依赖容器或外部服务。

业务要求：
1. 实现本地确定性样本生成与修复/风格迁移核心：按固定种子生成 RGB 像素数组与掩码，修复对掩码区域做确定性区域重建，风格迁移在保留内容结构的前提下按参考统计量迁移色调；同一输入、种子与配置必须产出逐字节一致的结果，禁止依赖除固定种子与显式配置外的状态。
2. 实现 v1、v2 与二进制交换格式三者的双向转换：v1 到 v2 升级时补全掩码校验和、浮点精度标记与区域来源标记；v2 降级回 v1 时按显式声明的量化与截断规则处理超出 v1 表达能力的字段；二进制容器按魔数、版本头、大端像素块与 CRC32 序列化。任一格式往返时须输出可核对的精度损失报告，量化误差以像素为单位度量并给出最大绝对偏差，超出声明的可接受损失时返回 E_PRECISION_LOSS。
3. 实现格式版本兼容读取：读取器按魔数与版本头分派到对应解析路径，未知版本返回 E_VERSION_UNSUPPORTED，头部截断或 CRC 不符返回 E_FORMAT_CORRUPT 并指出字段偏移；读取混合格式目录时按版本分别校验必填字段类型与取值范围，缺失字段或类型不符返回 E_FIELD_INVALID，不得让一个损坏文件中断整批读取，须汇总每文件的业务码。
4. 实现修复与风格迁移共享中间产物的内容寻址缓存与依赖失效：缓存键纳入输入图内容哈希、掩码摘要、风格参考摘要、算法参数与格式版本；修改掩码、替换风格参考或切换格式版本时计算受影响缓存条目集合，仅失效并重算受影响结果，其余必须复用；须输出本次失效条目清单与复用清单，并保证局部重绘后未修改区域的像素与重绘前逐像素一致，否则返回 E_MASK_MISMATCH。
5. 实现缓存快照的版本化与整体替换：每个缓存条目与结果包携带单调递增的键版本与内容校验和，检测到格式版本或键版本变化时必须整体替换旧快照而非增量修补；损坏或校验和不符的条目在读取时返回 E_CACHE_CORRUPT 并按明确策略重建，禁止使用部分可解析的损坏数据继续计算。
6. 实现并发控制与资源上限：为单次处理的像素内存估算、缓存条目总量与并行重算任务数设可配置上限，超限时返回 E_RESOURCE_LIMIT 或按明确策略降级到受限并发并标记降级类别；多个任务并发写同一缓存键或同一结果包时须保证只有一个提交生效，并发提交冲突后到者立即获得 E_CACHE_BUSY 而不阻塞等待，且不得写坏已提交条目。
7. 实现跨模块一致性自检与异常归因：校验结果包内掩码校验和与掩码摘要可核对、格式往返后的像素与精度损失报告可重算一致、失效集合与复用集合无交集且并集覆盖全部受影响条目；检测到不一致返回 E_INCONSISTENT 并指出不一致类别与涉及的结果包标识，异常须沿链路归因到具体处理阶段。
8. 提供一个本地可交互应用与可重复演示：展示样本与掩码、修复与风格迁移结果、当前结果包格式版本、往返精度损失报告、缓存命中与失效状态、本次重算统计与最近业务错误码，允许切换 v1/v2/二进制视图并触发一次演示运行；演示使用本地确定性样本，注入一次损坏文件、一次版本不支持与一次超预算输入，全程不依赖网络、外部账号或缺失数据集。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地确定性样本验证修复与风格迁移结果、三格式往返精度报告、缓存失效与并发冲突及异常码，附运行结果。
