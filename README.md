在空白工作区构建一个面向音色克隆与发音建模场景的可集成声纹编码推理组件与完整示例，用于本地确定性合成语音样本的说话人音色嵌入提取、相似度比对与数值可信度诊断。输入为一个本地样本目录：若干由固定种子程序合成的 WAV 音频（16kHz 单声道 16bit PCM，含可控基频均值与方差、共振峰位置、能量包络与平稳底噪，不同说话人音色在共振峰与基频统计上有可控差异），一份声纹编码配置 JSON（帧长与帧移毫秒、梅尔频带数与上限频率、倒谱阶数、声纹嵌入维度与量化档位、定点小数位宽、相似度判定阈值、最低有效帧数、并发数与快照提交间隔），一份说话人对清单 JSON（声明哪些音频属于同一说话人、哪些构成跨说话人比对对），以及一份异常注入清单 JSON（按样本与阶段指定真实输入故障）。组件需完成逐帧声学特征提取、声道与发音统计汇聚、定点声纹嵌入生成、跨样本相似度比对与阈值判定，并沿特征、汇聚、量化、相似度四个环节追踪定点误差传播，输出可复现的诊断报告。核心约束是：定点位宽与量化档位必须真实改变中间整数段与最终嵌入结果，同一输入在任意并发度与任意恢复点下结果逐字段一致，且增量编辑只使受影响样本及其下游失效。

任务环境与准备：
确认 Windows 上可用 Python 3.10 及以上版本并安装 numpy；版本与安装方式由执行者自行确认
准备本地合成语音样本目录与声纹编码配置、说话人对清单、异常注入清单，全部由固定种子程序生成，不依赖任何真实录音或外部服务
确认工作区为空目录，运行产出的中间产物与报告写入工作区下的独立输出目录，不修改输入样本

业务要求：
1. 实现音频读取与逐帧声学特征提取层：扫描输入目录下全部 WAV 文件，校验容器头、采样率、声道数、位深与数据长度一致性，不合规时输出 E_AUDIO_FORMAT 并进入失败清单；按配置帧长与帧移切帧，末帧不足帧长按补零处理并标记为尾帧；对每帧计算对数能量、过零率与基频估计（基于自相关峰，峰位并列时取较小滞后），再据梅尔频带数、上限频率与倒谱阶数生成倒谱系数；所有特征以 float64 计算并按配置有效位数写出，同一音频多次运行特征必须逐帧一致。
2. 实现说话人级声学统计汇聚：按配置最低有效帧数过滤能量低于门限的静音帧后，对剩余帧的基频、倒谱系数与能量做确定性统计（均值、方差、分位数），统计量的累加顺序固定为帧序号升序，分位数在并列时采用固定插值规则；有效帧数不足最低有效帧数时输出 E_INSUFFICIENT_FRAMES 并记录样本名与有效帧数；汇聚结果须携带参与帧区间与统计量指纹，供下游失效判定使用。
3. 实现声纹嵌入的定点量化与生成：按配置声纹嵌入维度与量化档位将汇聚统计量投影为嵌入向量，投影矩阵由特征维度与配置指纹派生的固定种子生成，投影与聚合全程使用定点整数运算；量化档位与定点小数位宽必须真实改变中间整数取值范围与最终舍入结果，同一声学统计在不同位宽下应产生可区分的嵌入；每个嵌入须记录逐维舍入残差与残差绝对值和，并按固定规则做单位化。
4. 实现跨样本相似度比对与阈值判定：按说话人对清单计算同说话人对与跨说话人对的余弦相似度，余弦计算以定点整数点积与定点范数完成后再确定性舍入，相似度相同或恰等于判定阈值时按固定规则决断并在报告中标注边界样本；输出每对相似度、判定结论、边界标记与双精度参考值，跨说话人误判与同说话人漏判须分别汇总计数。
5. 实现逐级误差传播追踪：对每条样本分别以配置定点位宽与高一档位宽完整计算特征量化、统计汇聚、嵌入投影、相似度四个环节，输出各环节逐项差值与首次超过配置容差所在环节的标注；当嵌入级差值与相似度级差值给出相反的阈值判定时记 E_PRECISION_SENSITIVE 并记录该样本与对端样本；报告须能区分误差来自量化舍入还是定点累加溢出风险。
6. 实现基于内容指纹的增量失效与精确重算范围：为特征提取、统计汇聚、嵌入生成与相似度各阶段产物计算由上游内容指纹、配置指纹与位宽档位派生的缓存键，并为每个说话人对记录其引用的样本缓存键；当替换某音频、修改量化档位、定点位宽、梅尔参数或相似度阈值时，仅使受影响样本及其参与的对端相似度失效并纳入重算集合，未失效产物必须直接复用且不得重复计算，复用与重算清单须在报告中逐项列出。
7. 实现并发处理与串行结果一致性：使用线程池并发执行帧特征提取、样本统计汇聚与对级相似度计算，最大并发数取自配置；每个任务携带由文件名、帧序号或对标识与阶段名派生的稳定排序键，无论线程调度顺序与并发度如何，最终样本顺序、逐帧记录顺序、对结果顺序、失效与复用清单顺序与失败清单顺序，必须与单线程按文件名升序及对清单原序执行的结果逐字段一致。
8. 实现阶段快照整体替换、恢复判定与诊断报告输出：各阶段以临时文件写盘后整体替换提交，清单文件记录全局版本号、配置哈希、注入清单哈希、已完成阶段与游标、各产物版本；启动时以版本号与配置哈希判定是否续跑，不一致输出 E_CONFIG_MISMATCH 并拒绝续跑；收到可处理的退出信号时完成当前阶段产物原子替换与进度记录后以整数退出码 0 退出，强制终止后仅依据已完整替换的产物恢复且不得承诺生成退出报告；每次完整运行输出含逐帧特征摘要、样本嵌入、对相似度与判定、误差追踪与边界样本清单、注入项命中编号、失败清单与各阶段耗时的 JSON 报告。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地合成语音样本验证声纹嵌入与相似度判定，并核对定点误差追踪、失效复用与恢复一致性结果。
