从一个空仓库出发，需要构建一个面向跨语言检索相关性建模的本地领域数据编辑与操作应用，核心业务问题是多精度档打分时的数值精度与误差传播诊断，以及查询改写资源增量更新后的快照一致性。业务对象是本地确定性生成的多语言文档与查询集合：文档含 doc_id、doc_lang、terms 列表（含词项与词频）与 doc_len；查询含 query_id、query_lang、terms 与 top_k；另有一份跨语言桥接资源，包含语言对方向表与词项桥接表（源词项到目标词项及桥接置信度）。相关性打分链路为：查询词项桥接展开与候选排序、桥接置信度加权的 BM25 类打分、按语言分区的倒排统计归约、top-k 选择与相关性分档。系统需在 float64、float32 与定点缩放整数三档下产出可复现分数，并以 float64 为参考真值输出逐级误差谱与主导来源归因；同时桥接资源、语言对方向表与各语言分区统计以版本化快照管理，当桥接表条目修正、方向表增删或文档批次追加时，须识别受影响分区与受影响查询，复用未受影响的上游产物并整体替换旧快照。应用需支持按 query_id 查询展开候选、逐级分数明细与误差区间，并校验查询侧与批量侧结果一致。

任务环境与准备：
安装 Python 3.11 或以上，以及 NumPy（pip install numpy），无需 GPU 与外部网络。
在 Windows 本地工作区创建项目目录；本任务不依赖任何真实数据集、账号或线上服务。
准备由固定种子生成的多语言文档 JSONL、查询 JSONL 与桥接资源配置样例，生成脚本随项目一并交付以保证输入确定性。
确认本地可写缓存与快照目录，并预留足够磁盘存放倒排统计与查询结果快照。

业务要求：
1. 实现确定性的桥接展开与候选排序层：按语言对方向表与词项桥接表把查询词项展开为目标语言候选词项集合，每候选携带桥接置信度，受可配置最大候选数与置信度下限约束；同一查询、同一桥接资源版本与同一配置下必须逐字节产出相同候选集合与顺序，同分按目标词项字典序排序，置信度越界或方向缺失分别返回结构化业务码并指明 query_id 与词项。
2. 实现桥接置信度加权的打分层：对每条查询按候选词项在各语言分区倒排统计中查找并组合 BM25 类分数，同一文档被多个候选命中时按显式声明的合并规则汇总贡献，逐候选记录原始分、权重与加权贡献；最终分数必须可由明细独立重算一致，禁止依赖系统时间或浮点累加顺序的隐式不确定性。
3. 实现 float64、float32 与定点缩放整数三档共用同一算子语义的执行层，定点档缩放因子与舍入模式由配置显式给出；同一输入在不同精度档下结果差异必须仅来自精度损失本身，切换精度档不得改变候选集合与命中文档集合，缩放因子非正或舍入模式未知返回 E_CONFIG_INVALID 并指明字段。
4. 实现以 float64 为参考真值的逐级误差传播计算：输出置信度加权、分区统计归约、定点量化与 top-k 门限比较各级的绝对偏差、相对偏差、误差区间与误差放大比，并定位主导误差来源级别；偏差区间顺序非法或定点档偏差无法由缩放因子与舍入模式重算一致时返回 E_ERR_SPECTRUM_INVALID，且不得以放大容差掩盖超差。
5. 实现 top-k 选择与相关性分档的数值稳定性保护：对相关性门限提供严格比较与容差带比较两种策略及次正规数保护，保证恰好落在门限附近的文档在多精度档重复运行下判定不被舍入翻转；门限策略或容差非法分别返回对应业务码，并记录门限附近被保护的文档与跳过记录使二者与实际执行一致。
6. 实现桥接资源与语言分区统计的版本化快照及增量失效传播：桥接表、方向表与分区统计各携带单调递增版本号与内容校验和，检测到版本号或校验和变化时整体替换旧快照而非增量修补；桥接条目修正或方向表增删时识别受影响分区与受影响查询集合，复用未受影响的上游展开与打分产物，仅重算受影响后缀，并输出重算集合与复用集合且保证与全量重算逐字节一致。
7. 实现按 query_id 的查询接口与过期结果拒绝：查询返回展开候选、逐级分数明细、误差区间与相关性分档；每份结果须记录所用缓存键、桥接资源版本、精度档与节点路径，可按记录重放出相同分数与分档，当缓存键任一依赖版本已变化而结果仍来自旧键时返回 E_STALE_RESULT 并指出 query_id 与失效依赖，追溯记录缺失或重放不符返回 E_LINEAGE_BROKEN。
8. 实现并发提交控制、资源上限与跨模块一致性自检：同一时刻只允许一个资源快照或增量提交生效，并发冲突时后到者立即获得 E_STAGE_BUSY 而不阻塞等待，已完成版本不得被旧版本回退覆盖；为倒排 posting 读取总量、候选比较次数与驻留分数明细内存设可配置上限，超限返回 E_RESOURCE_LIMIT 或降级为流式打分并标记降级类别；自检校验查询侧与批量侧在同一 query_id 上的展开候选、分数与分档一致，重算集合与复用集合无交集且并集覆盖全部受影响集合。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地确定性样本验证三精度档打分、误差谱归因、桥接资源增量失效与查询侧批量侧一致性。
