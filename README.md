当前是空白工作区，没有现存项目、代码或数据附件，需要从零构建一个面向对话式检索与生成式答案的本地可交互专业应用与可重复演示，核心业务问题是答案引用格式的多版本互操作与答案片段的增量失效。业务对象是本地确定性生成的多轮对话查询清单（JSONL，字段含 conv_id、turn_no、query_text、locale、session_hint）与一个本地文档集合（每条含 doc_id、terms 词项与词频、doc_len、doc_version）。应用把一次对话式回答建模为多阶段流水：查询归一化与多轮上下文合并→多路召回（词项倒排、类别热门、确定性向量近似）→答案片段选择（抽取式片段，带文档码点span）→引用装配与答案合成。答案与引用需要同时以三种版本格式持久化并互相转换：v1 为扁平行式引用（doc_id|start|end|score 竖线分列，无置信区间与段落角色）、v2 在 v1 基础上补充置信区间、段落角色与引用顺序权重，v3 为结构化 JSON（含多轮上下文引用链与逐引用修订号）。系统须支持文档版本提升后的答案片段增量失效与引用重放，保证同一问题在同一文档版本与配置下逐字节可复现。

任务环境与准备：
确认操作系统为 Windows，可运行 Python 3.10 及以上版本（安装说明随环境提供，任务不预置已验证结论）。
安装 NumPy 用于确定性像素/张量与向量近似样本生成，不依赖 GPU、外部账号或在线站点。
在空白工作区创建项目目录，样本由固定随机种子在本地生成，包括对话查询清单、文档集合与三种格式的引用与答案样本。
准备本地持久化目录用于内容寻址缓存、阶段快照与版本表，演示只使用本地生成样本与本地进程池。

业务要求：
1. 实现确定性的查询归一化、多轮上下文合并与三路召回（词项倒排、类别热门、固定种子向量近似），召回候选按 doc_id 归并并保留每路原始分与路名；同一会话、同一文档版本与同一配置下召回集合与路名归属必须逐字节一致，同分时按 doc_id 升序打破平局，且禁止依赖系统时间或字典遍历顺序。
2. 实现答案片段选择与引用装配：从召回文档中抽取带码点起止偏移的答案片段，按置信度与覆盖度组合打分选出答案片段集合，引用须落在所属文档文本的码点范围内且同一文档同区间不得重复引用；输出逐片段分数明细使最终分数可由明细独立重算一致，偏移越界或引用重复分别返回 E_SPAN_OUT_OF_RANGE 与 E_CITE_DUP。
3. 实现 v1、v2、v3 三种引用与答案书写形式的读取器，按格式头或字段集分派解析路径；未知格式版本返回 E_FORMAT_VERSION_UNSUPPORTED，格式头截断、竖线字段数不符、必填字段缺失或数值不可解析返回 E_FORMAT_CORRUPT 并指出字段位置与所在行。
4. 实现三套书写形式的双向迁移器：v1 升级到 v2、v3 时补全置信区间、段落角色与引用顺序权重并逐项记录补全来源；v3 降级到 v1 时对 v1 无法表达的多轮上下文引用链与修订号按显式声明的丢弃或展平规则处理并输出丢弃明细；迁移后码点偏移必须在三种形式间保持一致，偏移被改写或截断返回 E_SPAN_DRIFT。
5. 实现跨格式裁决：同一答案以 v1、v2、v3 三种形式书写时，加载与迁移后必须产出相同答案片段集合、相同引用集合与相同引用排序；当 v1 表达能力不足导致语义不可完全还原时返回 E_SEMANTIC_INCOMPLETE 并列出不可还原项，禁止静默按默认值补足后声称等价。
6. 实现文档版本提升后的增量失效传播：当某文档以更高 doc_version 到达、部分词项被增删或文档被删除时，计算受影响阶段与受影响引用集合，复用未受影响的上游召回与片段产物，仅重算受影响后缀并重新装配引用；须输出本次重算集合与复用集合，且局部变更后的答案与引用须与从零完整重算的结果逐字节一致。
7. 实现引用与答案快照的版本化整体替换及并发写控制：文档版本表、引用与答案快照各携带单调递增版本号与内容校验和，检测到任一版本号或校验和变化时必须整体替换旧快照而非增量修补，旧版本不得覆盖新版本且回退尝试返回 E_SNAPSHOT_ROLLBACK，损坏或校验和不符返回 E_SNAPSHOT_CORRUPT；多个任务并发写同一缓存键时须保证只有一个写入生效，冲突方立即获得 E_STAGE_BUSY 而不阻塞等待。
8. 提供一个本地可交互的专业应用与可重复演示，并实现跨模块一致性自检：展示当前文档版本与引用格式视图、多路召回路名归属、答案片段与逐引用明细、迁移补全与丢弃记录、重算与复用集合、快照版本与最近业务错误码，允许在 v1、v2、v3 视图间切换并触发一次演示——加载本地确定性样本、执行一次回答与一次文档版本提升后的增量重算，再导入导出往返核对；自检校验各阶段 conv_id 与 doc_id 集合可核对、每条引用恰出现一次、保留集与剔除集无交集，不一致时返回 E_INCONSISTENT 并指出不一致类别与版本号。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地确定性样本验证多版本引用互操作、增量失效重算与快照整体替换的一致性及异常处理，并附可重复运行结果。
