这个项目在启动会上被定为一人完成首版，手里只有一个刚装好 Python 的空目录，既无既有代码也无样本文件。目标是交付一个面向游戏场景光照预计算与影视预览的本地离屏渲染引擎：场景由若干轴对齐介质盒（雾、玻璃板、有色水体）与若干点光源组成，渲染为二维灰度图，并对数值误差的产生与传播给出可复核的评估。输入为一份 JSON 场景描述，含每个介质盒的尺寸、消光系数、散射反照率与折射率，光源位置与辐射强度，相机位置、朝向、垂直视场角与宽高比，以及渲染分辨率、每像素超采样倍数、光线步长与最大步数、透射率截断阈值、定点标度与若干容差、分块规格、并发上限、在途采样缓冲内存上限与状态目录。全部场景参数与介质数据由随工程交付的固定种子脚本确定性生成，不依赖 GPU、渲染库或外部资源。业务上的真正难点是透射率沿光线逐步累乘：定点量化后的中间量舍入会让本应高于截断阈值的介质段被提前判定为可忽略，从而改变光线是否继续步进与最终灰度，而这种偏差又会沿采样点、像素、分块逐级放大。

任务环境与准备：
安装 Python 3.11 或 3.12（Windows 官方安装包），执行 python -m pip install "numpy>=1.26,<3"。
在工作区创建项目目录并放置随工程交付的固定种子样本生成脚本，运行一次生成场景 JSON、介质与光源数据及抖动配置。
准备可写的状态目录与输出目录，确认本地磁盘可创建临时文件并执行原子替换。
不需要 GPU、渲染库、外部服务或网络访问。

业务要求：
1. 实现场景描述解析与输入校验：读取 JSON 场景与固定种子生成的介质与光源数据，校验各介质盒尺寸与消光系数为有限正数、散射反照率落在 [0,1]、折射率为不小于 1 的有限数、光源位置在场景包围盒内且辐射强度为正、垂直视场角在 (0,180) 度内、宽高比为有限正数、定点标度为正整数，非法输入返回带 E_xxx 业务码的 JSON 错误且不产生输出文件。
2. 实现统一世界坐标下的光线与多介质求交：按轴对齐盒体求光线进出区间，把各介质区间按入射次序合并为有序区间链，重叠区间按盒声明顺序与折射率确定唯一优先归属，区间边界采样点的归属由区间中点判定而非端点判定，使同一世界位置不会因分块切分或相机微小变化而落入不同介质。
3. 实现指数透射率累积与散射贡献合成：沿光线在介质区间内按步长采样，透射率按逐段消光光学厚度的指数衰减累乘，散射项按反照率与光源可见性在每个采样点累加并按剩余透射率加权，透射率低于截断阈值或达到最大步数时终止该条光线，最终量化为 0 至 255 的整数灰度并同步输出以世界单位表示的深度。
4. 实现双精度参考与定点中间量的误差对照：同一次渲染同时以 float64 逐段累乘与按定点标度量化后的中间量计算透射率，逐采样点记录两者绝对差值，标出首次超过透射率容差的位置并归因到具体介质盒、光学厚度与步序号；最终像素通过或超限的裁定只依据定点路径，float64 结果仅作为诊断参考写入报告。
5. 实现步长与截断阈值抖动的稳定性评估：在场景给出的步长与截断阈值抖动集合上各重渲一次，对同一相机与介质计算各配置结果与基准配置的逐像素最大偏差与均方偏差，给出偏差随步长收敛或随阈值放宽发散的趋势结论，并说明因阈值提前终止而导致光线提前结束的像素计数。
6. 实现确定性分块并发渲染与内存预算：按分块规格划分超采样像素网格，用有界线程池按并发上限调度，每块只读介质、光源与相机参数并写回块私有结果，同时在途采样缓冲总量不超过描述中的内存上限，超出时按分块索引序让后续块等待而非降低超采样倍数或步长精度，任意并发度下拼装结果须与串行逐像素渲染逐像素相同。
7. 实现分块级持久化与版本识别恢复：每块完成后把该块颜色、误差统计、块内容摘要与由介质与光源参数、相机参数、步长与阈值规范化摘要构成的版本标识写入状态目录，先写同目录临时文件再整体替换，替换前比对已有分块的版本标识，标识变化时不得直接覆盖旧分块；再次启动时标识一致则复用已完成块、只渲缺失块，不一致则整幅重做。
8. 处理中断信号、摘要校验与图像原子写出：可处理终止信号只在分块边界生效并写入中断标记后以约定整数退出码退出，未完成分块不得留下可被误认为完成的结果；强制终止后仅依据已持久化且摘要有效的分块状态恢复且不承诺生成退出报告；全部完成后逐块校验内容摘要，不匹配、缺失或声明像素数与实际不符时返回 E_DIGEST 并回退补渲，校验通过后把灰度图、深度图与误差溯源报告先写临时文件再整体替换正式输出，替换前读取已有输出文件的尺寸与摘要版本信息，仅版本不同才替换。
