当前是空白工作区，没有现存项目、代码或数据附件，需要从零构建一个面向中学语文作文批改的本地可视化与诊断工作台，核心业务问题是批改词表与批改规则的增量更新及其建议依赖失效。业务对象是本地确定性生成的学生作文集合：作文清单为 JSONL，字段含 essay_id、段落列表（段落含 para_no、text、grade_band）、评语模板版本号；批改链被建模为有向无环计算图，节点依次为文本规范化（全半角与异体字映射）、分段与断句、批改规则匹配（错别字词表、标点规范规则、搭配不当规则、重复用词规则）、修改建议生成、建议置信度打分与评语合成输出。每个节点产出带内容哈希的中间产物并写入本地内容寻址缓存，命中时跳过重算。当教师修改词表条目、停用某条搭配规则、替换异体字映射表、增删作文段落或调整评语模板版本时，只有依赖这些输入的下游节点需要重算，其余节点必须复用旧缓存；但缓存键必须精确反映全部有效性依赖，否则会出现过期建议被当作当前评语展示。工作台需展示计算图拓扑、各节点缓存命中与重算状态、失效传播范围、逐条建议的来源节点路径与最近业务错误码，并允许通过输入或参数注入异常来验证失效与归因逻辑。

任务环境与准备：
安装 Python 3.11 与 pip，创建独立虚拟环境；该环境仅用于本机运行，不涉及容器化。
执行 pip install PySide6 与 numpy，确认版本可在本机导入并启动一个空白窗口；无需外部服务或网络样本。
在空白工作区准备本地样本目录：用脚本以固定种子生成作文 JSONL、错别字词表、搭配与重复用词规则列表、异体字映射表与评语模板，生成脚本与样本一并保留以便复现。
确认工作区具备可写缓存目录与持久化快照目录，并准备一组注入异常输入（异体字映射缺项、词表格式错误、空段落、重复 essay_id）用于演示。
准备运行命令记录：全量批改、词表修改后的增量批改、诊断自检入口与演示触发入口，确保均可在 Windows 命令行执行。

业务要求：
1. 实现确定性的作文批改计算图：把文本规范化、分段断句、批改规则匹配、修改建议生成、置信度打分与评语合成建成有向无环图，节点参数由配置字典决定；同一作文集合与同一配置下必须产出逐字节一致的评语与中间产物，禁止依赖系统时间、随机数或字典遍历顺序等未声明状态。
2. 实现内容寻址缓存与缓存键构造：每个节点产物附带内容哈希写入本地缓存目录，缓存键须纳入节点全部输入摘要、错别字词表与搭配规则集版本、异体字映射表版本、评语模板版本、上游节点产物哈希与节点参数；键相同的请求必须复用快照，键不同必须重算，且每个缓存条目须能列出其键的组成项以便诊断。
3. 实现增量更新的依赖失效传播：修改词表条目、停用单条搭配规则、替换异体字映射表、增删作文段落或调整评语模板版本时，计算受影响节点与受影响 essay_id 及段落集合，复用未受影响上游缓存，仅重算受影响后缀；须输出本次重算节点清单与复用节点清单，并保证局部修改不会导致未受影响段落的建议发生任何变化。
4. 实现建议来源追溯与过期结果拒绝：每条最终建议须记录其来源节点路径、所用缓存键与规则版本，可按建议反查并按这些键重放出同一建议；当缓存键所依赖的任一输入版本已变化而建议仍来自旧键时，必须返回业务码 E_STALE_SUGGESTION 并指出过期依赖项，禁止将过期建议并入当前评语。
5. 实现缓存与配置的版本化整体替换及并发写控制：缓存条目、词表与规则快照各携带单调递增版本号与内容校验和，检测到版本号或校验和变化时必须整体替换旧快照而非增量修补，损坏或校验和不符的条目在读取时返回 E_CACHE_CORRUPT 并按明确策略重算；多个任务并发写同一缓存键时须保证只有一个胜出且其余结果与胜出者一致。
6. 实现资源与并发上限控制：为单篇作文段落数、规则逐段匹配的比较次数上限、缓存条目总量与并行重算节点数设置可配置上限，超限时按明确策略返回 E_RESOURCE_LIMIT 或在受限并发下执行并标记降级类别；降级不得改变已输出建议的语义，且降级触发须在诊断报告中可见并同步修正失效传播与一致性自检所依据的集合。
7. 实现跨模块一致性自检与异常归因链路：校验计算图拓扑无环、缓存键与产物哈希互相可核对、复用节点集合与重算节点集合无交集且并集覆盖全部受影响节点；并对异体字映射缺项、词表条目格式错误、段落 text 为空、重复 essay_id 分别返回结构化业务码并归因到具体节点与 essay_id。
8. 提供一个本地可视化与诊断工作台：展示计算图拓扑、各节点缓存命中或重算状态、失效传播覆盖的作文与段落、逐条建议的来源路径与置信度、资源消耗与最近业务错误码，允许点击节点查看缓存键组成与内容哈希，并支持触发一次演示——执行全量批改、修改词表后执行增量批改并对比两次评语与建议差异。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本验证全量批改、词表增量失效传播与建议可追溯，并检查异常输入的业务码与诊断输出。
