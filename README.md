在空白工作区构建一个面向本地确定性样本的 LLM 推理前缀缓存管理工作台，核心解决多会话共享前缀的分块复用、缓存驻留调度与淘汰一致性判定问题。输入为一个本地样本目录：一份会话请求流 JSONL（每行含会话名、轮序号、系统提示词、历史对话文本与新增问题文本，文本由固定种子程序从受控词表生成以控制长度），一份分块缓存配置 JSON（分块 token 数、块内哈希与链式父哈希的派生参数、前缀匹配最短可复用块数、显存驻留预算以块数计、淘汰策略选择项、每会话可保留块数上限、并发数、快照提交间隔与可处理退出观测间隔），以及一份本地小型词表与确定性哈希嵌入规则文件。工作台需将每个会话的上下文切分为块并逐块计算内容指纹与链式父指纹，识别与既有缓存块共享的公共前缀并声明可复用范围；当驻留预算不足时按可配置淘汰策略选择被驱逐块并重算受影响的后续块；全部输出必须可由块指纹与链式依赖审计追溯，并保证任意驱逐顺序下最终块内容与从空白缓存全量构建得到的块序列一致。

任务环境与准备：
Windows 10 及以上，安装 Python 3.11 与 NumPy（pip install numpy），无需 GPU 与外部服务。
创建空白工作目录，预先写入会话请求流 JSONL、分块缓存配置 JSON、词表规则文件与注入配置 JSON 及固定种子，作为本地确定性样本。
确认工作目录可读写且支持临时文件原子替换，运行前清空历史快照与报告目录以保证首次运行基线可复现。

业务要求：
1. 实现分块与链式指纹层：将每个会话按配置的分块 token 数切分为块，块内按词表映射为确定性哈希嵌入，每块计算由块内内容与父块指纹派生的链式指纹；同一文本序列在任意切分起点与任何运行中必须得到逐块一致的链式指纹，切分边界与哈希派生参数须在报告中显式输出，空会话、超长上下文与非词表 token 分别输出 E_EMPTY_CONTEXT、E_CONTEXT_TOO_LONG 与 E_TOKEN_UNKNOWN 业务码并进入失败清单。
2. 实现共享前缀识别与复用声明：对新会话请求逐块与既有缓存块的链式指纹做匹配，取最长连续匹配段并受配置的最短可复用块数约束，输出可复用块区间与需新计算块区间；匹配过程只依赖链式指纹比对，不做全文重算；当链式指纹在非首块处命中而父链断裂时必须判定为不可复用并输出 E_CHAIN_BROKEN 事件而非静默拼接。
3. 实现按块驻留与淘汰调度器：维护驻留块的引用计数与最近使用序号，当新块加入使驻留块数超过显存驻留预算时，按配置指定的淘汰策略（最近最少使用或最少引用者优先）选择被驱逐块，同分时按链式指纹字典序决定，每次淘汰与重算都须以事件形式记录被驱逐块指纹、所属会话与受影响的后继块清单；淘汰策略取值非法时输出 E_EVICT_POLICY_INVALID 并拒绝启动。
4. 实现淘汰后的后继块失效与按需重算：被驱逐块的任意下游块必须标记失效并在下次被引用时沿链重新计算，重算所得块内容与指纹须与首次计算逐字段一致；不得复用失效块内容，也不得把未失效块重复计算，失效判定须能区分链式依赖断裂与纯预算驱逐两种成因并分别记入报告。
5. 保证驱逐顺序无关的一致性与可复现：以不同驻留预算、不同淘汰策略与不同请求到达顺序多次运行同一会话请求流，最终各会话上下文块序列、链式指纹、复用区间与失效重算清单必须与从空白缓存按请求顺序全量构建的结果一致；重复运行同一配置与请求流必须产出逐字段一致的审计报告。
6. 实现会话级快照与强制终止后的恢复判定：按配置的提交间隔将驻留块指纹表、引用计数、链式依赖图与请求游标以临时文件加原子替换写盘，快照含配置哈希、词表指纹与版本号；收到可处理的退出信号时在配置的可处理退出观测间隔内完成当前请求的块提交与快照后以整数退出码 0 退出；强制终止后仅依据已完整替换的快照恢复，快照缺失或配置哈希不符时输出 E_SNAPSHOT_STALE 并从空白缓存重建。
7. 实现异常注入与失败隔离：以独立注入配置指定空文本请求、超出保留上限的会话、命中父链断裂的请求与非法淘汰策略等异常样例，注入项编号写入报告以证明命中；单个会话在切块、指纹计算或匹配阶段抛异常时记录会话名、轮序号、阶段名、业务码与异常类型并继续其余请求，失败会话不得污染其他会话的驻留与引用计数统计。
8. 实现并发请求处理、审计报告与可重复演示：使用线程池并发处理会话请求流，最大并发数取自配置，每条请求任务携带由会话名与轮序号派生的稳定排序键，无论线程完成顺序如何，最终块序列、复用区间、驻留块集合、淘汰事件顺序与失败清单顺序必须与单线程按请求流顺序执行的结果逐字段一致；每次完整运行生成 JSON 报告，含各会话块数与可复用块数、驻留块峰值与预算利用率、淘汰与失效重算事件序列、链式指纹摘要、快照版本号、配置与词表哈希及失败清单；提供命令行交互会话支持切换淘汰策略、调整驻留预算与查询指定块依赖链，交互产生的配置变更须触发快照版本识别，回放同一请求流须与首次运行报告逐字段一致。
