某身份认证团队在 Windows 本地工作区启动一次从零开始的产品验证，为自研授权服务器搭建离线互操作验证工具，用本地确定性样本判定两代授权码与令牌记录的合并裁决是否正确。v1 为单文件扁平 JSON，记录相对过期秒、无 PKCE 的授权码与会话；v2 为分片 JSON 加 SQLite 元数据库，记录绝对毫秒时间戳、code_challenge 与 method、令牌代数与墓碑标记。工作区无既有代码与样本，全部输入由固定种子生成本地文件，不依赖真实账号、线上站点或外部网络。工具需把两代记录合并为统一令牌态视图，裁决授权码兑换、刷新令牌轮换与撤销传播，并给出可追溯的失效闭包与冲突明细。

任务环境与准备：
Windows 10/11 本地工作区，Python 3.11 或 3.12，执行 python -m venv .venv 并用 .venv\Scripts\activate 激活。
安装依赖：pip install pytest；SQLite、hashlib、json、msvcrt 使用标准库，检查点文件锁在 Windows 下基于 msvcrt 实现。
准备本地样本目录 samples/，由要求的固定种子生成器产出 v1 单文件 JSON、v2 分片 JSON 与 SQLite 元数据库、观测时钟声明文件；不下载任何外部数据，不访问网络。
先运行样本生成脚本产出确定性输入，再运行 pytest 与命令行演示；所有路径使用相对路径以便复现。

业务要求：
1. 实现两代授权码与会话样本的解析规范化层：v1 记录相对过期秒、无 PKCE 声明、扁平作用域数组；v2 记录绝对毫秒时间戳、code_challenge 与 method、令牌代数与墓碑标记。校验授权码、客户端、会话标识唯一性与时间戳单调关系，非法条目输出含来源版本、记录序号与稳定业务码的拒绝记录并继续处理其余条目。
2. 把两代记录合并为统一令牌态视图：以规范化客户端与授权码作为同一实体键，按代数与时间戳决定同一实体的权威来源，墓碑标记必须覆盖较早的非墓碑记录；当两代对同一实体的客户端、作用域或过期时刻给出不一致结论时返回 E_STATE_CONFLICT 并给出冲突字段与两侧来源，禁止静默取一侧。
3. 实现授权码兑换裁决：校验兑换到达时刻落在授权码有效窗口内（以样本声明的观测时钟为唯一真值来源，禁用系统当前时间）、授权码未被使用、客户端与重定向标识匹配、PKCE 声明与兑换时提供的 verifier 按 S256 或 plain 口径一致，分别返回 E_CODE_EXPIRED、E_CODE_REUSED、E_CLIENT_MISMATCH、E_PKCE_MISMATCH 并给出判定所依据的记录来源与代数。
4. 实现授权码重放与 PKCE 降级检测：同一授权码出现第二次兑换时必须判定为 E_CODE_REPLAY 并回溯列出两次兑换记录；当 v2 记录声明了 code_challenge 而合并后视图中兑换侧缺少 verifier，或 v1 无 PKCE 记录被 v2 带 PKCE 的较新记录整体替换时，须判定 E_PKCE_DOWNGRADE 并保留替换前后代数与两侧来源。
5. 实现刷新令牌轮换与撤销传播失效闭包：按令牌代数链计算轮换后继关系，撤销某会话或某授权码时沿会话→授权码→访问令牌→刷新令牌的依赖边计算传递失效闭包，遇到环状依赖返回 E_TOKEN_CYCLE 并列出环中实体键；失效闭包必须与撤销输入顺序无关，被墓碑覆盖的实体不得重新进入有效集合。
6. 实现检查点演进与并发写隔离：按已应用批次水位与合并视图聚合状态持久化检查点到 SQLite 与本地快照，恢复时只从最后一个完整检查点继续；检测到检查点结构版本或合并口径版本变化时须整体重建而非增量续接，不得将旧口径的失效结论与新口径混合；同一目录并发写检查点须以 Windows 文件锁串行化，锁冲突返回 E_LOCK 且不得破坏既有检查点。
7. 实现原子报告写出与强制终止后的恢复边界：裁决报告为可解析 JSON，含实体级结论、业务码、依据来源版本与代数、失效闭包与冲突字段；报告与快照均先写临时文件再整体重命名替换，替换前校验内容完整可解析；进程被强制终止后只允许恢复到最后一个完整检查点，不承诺生成退出报告，也不得残留可被误读的半写文件。
8. 交付可交互诊断工作台与确定性本地验证：提供导入、兑换裁决、撤销传播、校验检查点四类子命令与本地视图展示统一令牌态、失效闭包与冲突明细；单份样本失败不得中断同批其他样本，退出码区分全部成功、部分失败与参数错误；附固定种子样本生成器与 pytest 测试集，覆盖过期、重放、PKCE 降级、状态冲突、环状依赖、版本变化重建与强制终止恢复。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地两代样本验证合并视图、兑换与撤销裁决一致，并覆盖冲突与恢复边界。
