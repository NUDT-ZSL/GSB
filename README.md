当前是空白工作区，需要从零构建一个面向交叉组合与降维的本地可视化诊断工作台，核心业务问题是数值精度与误差传播。输入为本地确定性生成的表格或高维稠密样本：由固定种子生成的特征矩阵（字段含 row_id、若干数值列与类别列、label），以及一份降维配置，包含候选方法（PCA 主成分、随机投影、以及 PCA 之后再随机投影的两段式组合）、目标维度、随机投影的种子与投影矩阵密度、是否先做标准化、数值精度标记。工作台需把一次降维运行建模为可诊断的计算过程：标准化统计量估计→主成分或投影矩阵构造→降维坐标计算→降维后邻域与类一致性评估。每一次提交产生带版本号与内容校验和的计算快照，供交互式查询、误差谱诊断与跨方法一致性裁决。系统须保证同一输入与配置下逐字节可复现，并在精度、内存与保真度之间给出显式取舍。

任务环境与准备：
安装 Python 3.10 及以上版本，并安装 NumPy 与 SciPy（版本以能复现确定性随机数生成器为准）。
提供本地确定性样本生成脚本：用固定种子生成表格或高维稠密特征矩阵与降维配置，不依赖外部数据集或网络。
预留本地缓存与快照目录，确保可在同一工作区重复运行演示与诊断。

业务要求：
1. 实现确定性的标准化与降维核心：按配置决定是否对数值列做 z-score、类别列按固定规则编码，再执行 PCA 或随机投影；随机投影矩阵须由配置中的固定种子与投影矩阵密度确定性生成；同一输入、同一配置与同一精度标记下，降维坐标、主成分或投影矩阵必须逐字节一致，禁止依赖系统时间、字典遍历顺序或任何未声明状态。
2. 实现两段式组合路径：支持 PCA 之后再随机投影的两段式降维，中间维度与投影矩阵密度由配置给出；须记录两段各自的参数与中间维度，并校验中间维度不超过原始维度且不低于目标维度，违反分别返回 E_INTERMEDIATE_DIM 并指明配置字段。
3. 实现可切换的精度档执行层：float64、float32 与定点缩放整数三档共用同一算子语义，定点档的缩放因子与舍入模式由配置显式给出；同一输入在不同精度档下结果差异必须仅来自精度损失本身，切换精度档必须使已提交快照失效并返回 E_PRECISION_CHANGED，禁止混用不同精度档的中间量。
4. 实现逐级误差谱与主导误差来源归因：以同一输入上的 float64 全精度参考实现为真值，输出标准化、协方差或投影矩阵构造、降维坐标计算与两段式组合各级的绝对偏差、相对偏差、误差区间与误差放大比，并定位主导误差来源为标准化、投影矩阵构造或坐标计算中的哪一级；偏差超出配置容差返回 E_TOLERANCE_EXCEEDED 并指出越界元素与偏差量。
5. 实现门限判决与邻域类一致性的数值稳定性保护：对类一致率门限与方差解释率门限提供严格比较与容差带比较两种策略及次正规数保护，保证恰好落在门限附近的样本或主成分的判定在重复运行与多精度档下不被舍入翻转；门限策略变更必须在诊断报告中逐级留痕，门限或容差非法分别返回 E_CONFIG_INVALID。
6. 实现配置、统计量与误差谱的版本化快照及整体替换：标准化统计量、主成分或投影矩阵、评估统计量各携带单调递增版本号与内容校验和，提交时整体替换旧快照而非增量修补；重启加载时识别版本号或校验和变化并整体替换，旧版本不得覆盖新版本且回退尝试返回 E_SNAPSHOT_ROLLBACK，损坏或校验和不符返回 E_SNAPSHOT_CORRUPT。
7. 实现资源上限与降级执行：为降维矩阵内存估算、投影中间缓冲与特征数设可配置上限，超限时按明确策略返回 E_RESOURCE_LIMIT 或降级到随机投影等低内存路径，降级须在结果中标记降级类别且不得改变已输出坐标的可核对性；降级决策须可复现。
8. 提供本地可交互诊断工作台并实现跨方法一致性自检：展示降维路径曲线与保真度谱、逐级误差谱、门限判决留痕、快照版本与最近业务错误码；允许切换 PCA、随机投影与两段式视图并触发一次演示；自检校验同一输入下随机投影与两段式路径在相同投影参数下结果一致、单样本坐标可由方法与快照重建、评估所用坐标版本与当前快照一致，不一致返回 E_INCONSISTENT 并指出类别。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地确定性样本验证降维核心、误差谱归因、快照版本替换与跨方法一致性自检，并附运行结果。
