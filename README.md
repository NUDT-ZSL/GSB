# SRT 字幕批量修正工具

纯本地命令行工具（Python 标准库，无第三方依赖），批量读取字幕目录下的
`.srt` 文件，消除时间轴重叠、清理空文本与颠倒条目、统一时间格式与序号，
并把可再次导入剪辑软件的字幕文件和人工可读的修正记录写入输出目录。
**输入目录中的原文件只读，不会被修改。**

## 环境要求

- Windows（亦可在 macOS / Linux 运行）
- Python 3.10 及以上（已在 Python 3.14.7 上实测）

## 启动说明

```powershell
# 1) 确认 Python 版本
python --version

# 2) 在项目目录直接运行（无需安装依赖、无需容器）
python srt_fix.py <输入目录> <输出目录>
```

示例：

```powershell
python srt_fix.py D:\字幕\待处理 D:\字幕\已修正
```

- 输入目录不存在或不是目录：向标准错误输出提示，**退出码 1，且不会创建输出目录**。
- 输出目录不存在时自动创建；若已存在，同名文件会被覆盖，其他文件保留。
- 输入目录与输出目录相同时拒绝执行（避免破坏原文件），退出码 1。
- 输入目录下没有 `.srt` 文件时仍会生成一份空汇总的修正记录，退出码 0。
- 单个文件无法解析不会中断整批处理。

## 处理规则

| 场景 | 处理方式 |
| --- | --- |
| 相邻条目时间重叠 | 优先把后一条起点推到前一条终点；若会越过后一条自身终点（后一条整段被包含或终点相同），改为把前一条终点收缩到后一条起点，记录中注明“调整前一条终点” |
| 后一条起点早于前一条起点（时序倒置） | 交换相邻两条的顺序，再按重叠规则处理 |
| 结束时间早于开始时间 | 该条目标记为移除，记录序号与原时间，不影响其他条目 |
| 文本为空或仅含空白 | 该条目标记为移除，记录序号 |
| 毫秒 1~3 位（如 `,50`、`,5`） | 按整数值解析，输出统一补足三位：`,50` → `,050` |
| 时间分隔符为 `.` | 统一输出为 `HH:MM:SS,mmm` 与 ` --> ` |
| 序号不连续/重复/缺失 | 输出从 1 起连续重新编号 |
| 多行文本 | 原样逐行保留，不合并、不压缩 |
| UTF-8 BOM | 正常读取，输出不写 BOM |
| UTF-8 以外的中文编码（GB18030/GBK） | 兼容读取，输出转为 UTF-8，记录编码转换 |
| 空文件、二进制或其他无法解析的内容 | 该文件列入记录并标注“未能处理”，不影响其他文件 |
| 非 `.srt` 文件 | 直接忽略，不产生输出，也不出现在记录中 |

备注：

- 时间轴行尾部的附加信息（如 `X1:...`）会原样保留。
- 输出文件的换行风格跟随原文件（CRLF 输入得 CRLF 输出；LF 输入得 LF 输出）。
- 对已修正过的文件再次运行，输出逐字节不变（幂等）。

## 修正记录

输出目录下生成纯文本 `修正记录.txt`（UTF-8），包含：

- 每个文件的处理状态（已输出（含修正）/ 已输出（无需修正）/ 未能处理）；
- 输入/输出条目数、修正条目数；
- 每条受影响条目的**序号与原时间**，时间修正的**新旧时间值**、修改类型与调整对象；
- 移除条目的序号、原时间与移除原因；
- 序号规范化、编码转换、BOM 处理等文件级说明；
- 末尾汇总：`汇总: 成功文件数: N, 含修正文件数: M, 未能处理文件数: K`。

## 业务样例与实测结果

### 样例生成（可重复执行）

```powershell
python demo/make_samples.py
```

在 `demo/input/` 生成 5 个 SRT 与 1 个非 SRT 文件：

| 文件 | 内容 | 规模 |
| --- | --- | --- |
| `01_legal.srt` | 完全合法：序号连续、时间规范、无重叠 | 4 条 |
| `02_messy.srt` | 重叠、毫秒两位、空文本、时间颠倒、序号重复/跳号、整段嵌套 | 6 条 |
| `03_bom_multiline.srt` | UTF-8 BOM + 两行文本条目 | 2 条 |
| `04_empty.srt` | 0 字节空文件 | 0 条 |
| `05_large.srt` | 每 50 条插入一处 0.4s 重叠 | 400 条，20 KB |
| `说明.txt` | 非字幕文件，应被忽略 | — |

### 实际运行

```powershell
python srt_fix.py demo/input demo/output
```

实际控制台输出：

```text
处理完成: 成功 4 个, 含修正 3 个, 未能处理 1 个
修正记录: demo\output\修正记录.txt
```

输出目录实际内容（`04_empty.srt` 未生成，`说明.txt` 未出现）：

```text
01_legal.srt          279 bytes
02_messy.srt          234 bytes
03_bom_multiline.srt  110 bytes
05_large.srt        20983 bytes
修正记录.txt         3659 bytes
```

**02_messy.srt 输入**（序号、时间经过刻意破坏）：

```text
1

第一句：你好。

2

第二句：我们在等你。

2
00:00:06,000 --> 00:00:07,000
   

9
00:00:12,000 --> 00:00:09,000
这条时间颠倒了。

9
00:00:10,500 --> 00:00:13,000
第三句：别走太远。

7
00:00:11,000 --> 00:00:12,000
第四句：好的。
```

**02_messy.srt 输出**（无重叠、毫秒三位、两条空/颠倒条目被移除、序号 1..4）：

```text
1
00:00:01,000 --> 00:00:04,000
第一句：你好。

2
00:00:04,000 --> 00:00:06,000
第二句：我们在等你。

3
00:00:10,500 --> 00:00:11,000
第三句：别走太远。

4
00:00:11,000 --> 00:00:12,000
第四句：好的。
```

对应修正记录（节选）：

```text
===== 文件: 02_messy.srt =====
状态: 已输出（含修正）
输入条目数: 6
输出条目数: 4
修正条目数: 4
修改明细:
  序号规范化: 原序号 [1, 2, 9, 7] -> 输出序号 [1, 2, 3, 4]
  - 条目 #2（文件位置 2）: 时间已修正
      原时间: 00:00:03,50 --> 00:00:06,000
      新时间: 00:00:04,000 --> 00:00:06,000
      修改类型: 时间重叠（调整后一条起点）；时间格式规范化
      调整对象: 后一条起点
  - 条目 #2（文件位置 3）: 已移除
      原时间: 00:00:06,000 --> 00:00:07,000
      修改类型: 空文本
  - 条目 #9（文件位置 4）: 已移除
      原时间: 00:00:12,000 --> 00:00:09,000
      修改类型: 时间颠倒（结束早于开始）
  - 条目 #9（文件位置 5）: 时间已修正
      原时间: 00:00:10,500 --> 00:00:13,000
      新时间: 00:00:10,500 --> 00:00:11,000
      修改类型: 时间重叠（调整前一条终点）
      调整对象: 前一条终点
```

**其他文件**：

- `01_legal.srt`：与输入逐字节一致（SHA-256 相同），记录写着“无需修正”。
- `03_bom_multiline.srt`：输出首字节为 `1`（0x31），无 BOM；两行文本仍是两行。
- `04_empty.srt`：输出不存在，记录中标注“未能处理 / 原因: 文件为空”。
- `05_large.srt`：400 条全部保留，7 处重叠各修正一次起点；耗时约 0.2 s。
- 末尾汇总：`汇总: 成功文件数: 4, 含修正文件数: 3, 未能处理文件数: 1`。

### 错误路径实测

```powershell
python srt_fix.py D:\不存在的目录 D:\out
```

实际结果：标准错误输出 `错误: 输入路径不存在: D:\不存在的目录`，退出码 `1`，
且 `D:\out` 未被创建。
