在一台没有历史代码的机器上，需要从零实现一个本地事件总线流式集成中间件，用于在确定性样本上复现事件在通道间桥接转发时两代事件封装格式的互操作、上游偏移水位依赖与进程中断后的恢复一致性。本地 JSON 样本给出两代通道与事件格式：v1 为单文件 JSON，记录通道名、分区数、事件序号、相对产生秒数、扁平字段数组、桥接规则列表与订阅声明；v2 为分片 JSON 加 SQLite 元数据库，记录通道规范名、事件具名字段信封、绝对产生毫秒戳、通道代数、桥接依赖的上游偏移水位、墓碑标记与订阅偏移。事件需在桥接规则驱动下从上游通道按过滤与变换规则转发到下游通道，桥接位点只在上游事件已提交且变换结果摘要校验通过后推进，v1 相对秒数须换算为绝对时刻并保留换算痕迹。进程可能在任一阶段被强制终止，恢复后必须给出与不中断运行一致的转发结论与偏移水位。

任务环境与准备：
Windows 10/11，安装 Python 3.11 或更高版本，并确保 python 与 pip 在 PATH 中。
在项目根目录创建虚拟环境：python -m venv .venv，然后执行 .venv\Scripts\activate。
安装依赖：pip install flask numpy pytest；SQLite 使用 Python 标准库 sqlite3，无需额外安装。
在本地 samples 目录放置自备的 v1 单文件 JSON、v2 分片 JSON 与 SQLite 元数据样本，以及由本地脚本确定性生成的桥接规则与事件流；不依赖任何在线服务或附件。
本机具备可写本地磁盘用于 SQLite 数据库、临时表与整体替换指针，命令行以 UTF-8 输出。

业务要求：
1. 实现 v1 单文件 JSON 与 v2 分片 JSON 加 SQLite 元数据两代通道、事件、桥接规则与订阅声明的解析校验：通道名与事件序号唯一、分区数为正整数、桥接规则上下游通道存在且桥接图无环、事件扁平数组元素个数与 v1 声明一致、v2 具名字段信封校验和与逻辑时钟字段类型合法、v1 相对产生秒数为非负整数、订阅起始偏移在合法区间；非法输入返回明确业务错误码且不写入任何持久状态。
2. 实现两代事件封装的跨版本编解码与统一通道视图：同一事件在 v1 与 v2 中同时存在时依据声明的逻辑时钟与通道代数裁决最新版本，逻辑时钟相同按来源格式优先级；v1 扁平字段数组须无损转换为 v2 具名字段信封，v2 新增字段在 v1 路径读取时按声明默认语义降级并记录兼容降级清单，v1 相对秒数换算为绝对毫秒时刻须记录标度、舍入方向与舍入余量；合并后每个事件保留来源版本、原始表示与裁决依据。
3. 实现确定性的分区路由与通道日志追加：同一分区键在任意运行次数下必须落到同一分区，事件偏移按通道内追加顺序单调递增且不跳号，按单批最大条数切分批次并记录每事件偏移、载荷摘要与逻辑时钟戳；每次追加在同一事务内写入偏移、摘要与代数。
4. 实现桥接转发与上游偏移水位依赖：依据过滤条件与变换表达式把上游事件转发到下游通道，变换应用顺序与浮点运算顺序固定使结果可复现；桥接位点只在上游事件已提交且变换结果摘要校验通过后推进，上游偏移水位回退、上下游通道代数不一致或桥接规则在途变更时必须拒绝推进并返回不同业务错误码，不得部分推进。
5. 实现基于注入逻辑时钟的保留清理水位与清理裁决：保留字节上限触发清理时按最老已提交水位与所有订阅及桥接位点的最小未消费偏移裁决可清理区间，区分可物理清除与仅可标记墓碑两种情形；清理数量、保留原因与被阻塞的最慢位点须可查，逻辑时钟回拨超过容差返回业务错误码。
6. 实现强制终止后的恢复一致性：把通道日志水位、桥接转发位点、订阅偏移、保留清理水位、两代合并裁决与逻辑时钟水位以单事务原子写入 SQLite，每次通道配置提交识别版本变化并整体替换当前配置指针而非逐条覆盖；进程在追加、转发、位点回报或清理任一阶段被强制终止后，恢复路径识别已提交事件与半提交桥接位点，只重做未提交部分且不得重复计入偏移或重复转发。
7. 实现多进程并发一致性与版本化配置切换：允许多个生产者、消费者与编辑进程并行操作同一批通道，通过 SQLite 事务与文件锁保证同一事件偏移只被追加一次、同一桥接位点只被推进一次、同一订阅偏移不被并发超进且不回退，重复提交相同位点回报必须幂等；配置与规则变更产生新版本号并以临时表加版本号整体替换指针，进行中的转发必须绑定开始时的配置版本至结束。
8. 提供领域数据编辑与操作应用及可重复演示：支持 load、edit、publish、bridge、consume、resume、status、verify 子命令，edit 支持事件、桥接规则与订阅的新增、修改、删除并以补丁形式产生配置新版本；status 以稳定排序 JSON 输出各通道偏移水位、桥接位点、订阅偏移与兼容降级清单，verify 校验持久水位与重放结果一致；畸形事件、分片哈希不匹配、桥接位点回退、订阅偏移越界分别映射到不同业务错误码。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
