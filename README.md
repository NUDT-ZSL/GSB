团队把一个尚未开工的内部合规工具需求交给新成员：需要在 Windows 空工作区实现一个敏感标记合成引擎，用于判断共享目录中对象的有效敏感等级是否被多来源合成规则误判。工作区没有任何代码与样本，全部输入由随交付的固定种子脚本确定性生成：对象声明给出对象规范键、父对象引用与继承标记；标记来源声明给出受托者组层级、每条来源的授予等级与生效窗口；另有一份按逻辑时钟到达的重入批次，声明新增来源、来源撤销与受托者组迁移。引擎须沿继承链与组层级合成有效等级，识别来源撤销或组迁移后需重新裁决的对象，并输出可复核的合成依据与重入集合报告。核心难点在于：合成结果必须与重入到达顺序无关，来源撤销只在无其他未被撤销来源可达同等等级时才降级，而组迁移会让同一对象的历史授予在新组路径下重新生效，重入集合与合成结论必须同时可重放。

任务环境与准备：
安装 Python 3.11 或以上版本，确认 python 与 pytest 可用。
仅使用 Python 标准库（sqlite3、json、threading、hashlib、argparse）实现，无需安装第三方包。
在空工作区创建项目目录与固定种子样本生成脚本入口，样本生成后写入本地 data 目录与真值文件。
运行前确保工作目录具有写入 SQLite 文件、临时文件与文件锁的权限。

业务要求：
1. 实现对象声明、来源声明与重入批次的严格解析规范化层：校验对象规范键与来源声明键在各自作用域内唯一、父对象引用可解析且不构成自引用、继承标记取值合法、授予等级取值为受控枚举、重入操作序号在批次内单调，对非法记录输出含批次标识、操作序号与稳定业务码的拒绝记录并继续处理其余记录。
2. 实现沿父对象继承链与受托者组层级的有效等级合成：对象自身来源与继承来的来源按等级优先级合成，组层级中嵌套组授予须展开到成员受托者，同一受托者多条来源取最高等级并记录全部参与来源；合成结论须按规范键稳定次序给出，禁止按声明到达顺序取首个来源，当合成依据集合为空时单列业务码而非默认为最低等级。
3. 实现来源撤销与组迁移触发的重入集合计算：来源撤销时只有该对象上不存在其他未被撤销且可达同等及以上等级的来源才降级，否则保留等级并单列替代来源证据；组迁移使某受托者由旧组路径转入新组路径时，须沿新路径重新评估该受托者可达的全部对象，把等级发生变化的对象计入重入集合；检测组层级中的自引用与任意长度环并返回业务码且列出环中受托者标识，环内受托者的授予结论降级为不可判定。
4. 在 SQLite 中维护合成与重入账本，以对象规范键与受托者标识为主键记录当前有效等级、依据来源集合摘要、重入标记与已应用批次水位；每轮重入批次在单事务内推进，前置校验失败不得改动任何账本状态；当账本格局版本（组层级或等级枚举版本）变化时须整体重建而非增量续接，不得把旧组结构的合成结论与新结构混合。
5. 保证合成结论与重入集合同批次到达顺序无关：对同一组批次，任意合法应用顺序下最终有效等级、重入集合、替代来源证据与拒绝清单必须完全一致；批次操作序号或逻辑时刻相同时须以操作序号与规范键稳定排序确定次序，禁止依赖到达顺序或字典遍历；降级判定必须以账本中依据来源集合为准，不能按临时计算集给出。
6. 实现真实资源预算控制与并发批处理：并发度、单批次实测耗时上限与待处理批次队列上限均可配置，耗时以真实墙钟测量判定而非人为延迟常量，超时返回 E_TIMEOUT 并终止该批次后续操作，队列超限须拒绝入队并计入报告；超预算批次不得污染账本，其已部分写入的来源须回滚，且并发度变化下结论与串行执行完全一致。
7. 实现检查点演进与强制终止后的恢复边界：按已应用批次水位与账本摘要把检查点持久化到 SQLite 与本地快照文件，恢复时只从最后一个完整检查点继续并重放比对账本一致性以识别半写残留；检查点与重入报告均先写临时文件并在校验内容可解析后整体重命名替换，替换前须识别快照版本变化；进程被强制终止后不承诺生成退出报告，只允许恢复到最后一个完整检查点。
8. 交付可交互命令行与基于同步标记的确定性验证：提供导入、查询有效等级、导出重入报告、校验检查点四类子命令，样本生成器在真值文件中显式写入来源原始授予、组路径同步标记与撤销记录，验证只依据同步标记与组件输出比较，单份输入失败不得中断同批其他输入，退出码区分全部成功、部分失败与参数错误，业务码统一写入 JSON 报告。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地确定性样本验证有效等级合成、撤销与组迁移重入集合及到达顺序无关性，输出可重放报告。
