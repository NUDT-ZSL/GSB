材料实验与结构表征实验室的谱图模型研究员正在搭建拉曼与 X 射线衍射谱图的基础模型预训练流程。多个课题组采集的谱图会按材料体系与仪器来源汇成语料，并分别以三个格式版本交付：版本差异体现在网格单位、强度归一化方式与缺失谱段标记上。由于稀有材料体系样本稀少，混合专家网络的门控容易把 token 集中推给少数专家，造成专家塌缩与稀有材料表征退化。研究员需要一个本地离线工作台，能够把三版本谱图归一为统一 token 表示，按 top-k 路由并加入负载均衡辅助损失与容量因子约束，逐步记录专家分配、承载数与损失数值，在专家利用率持续低迷时调整路由温度并给出前后对比，最终导出可供下游微调的参数快照。

任务环境与准备：
准备 Python 3.10 运行环境，使用 pip 安装 NumPy，用于数组运算与门控前馈计算。
在全新工作目录中创建项目，提供运行入口脚本，通过命令行参数指定确定性谱图生成器种子、训练配置与输出目录。
训练配置与三个格式版本的谱图样本均由仓库内固定种子生成器产出，不依赖网络或外部数据集。

业务要求：
1. 实现三个格式版本的谱图解析与归一化：版本 A 使用波数网格厘米倒数与最大强度归一，缺失谱段以 NaN 标记；版本 B 使用纳米波长并按峰面积归一，缺失谱段以负值占位；版本 C 使用角度网格与分位数归一，缺失谱段为空字符串。将三者统一为固定长度的 token 序列与二值掩码，保证同一材料同一谱段在各版本下映射到相同 token 索引，并输出归一日志。
2. 实现前馈门控网络：对每个 token 计算各专家亲和度，按 top-k 激活并生成逐 token 的专家分配矩阵与归一化激活权重。门控参数由固定种子初始化，每步训练后更新，分配矩阵与权重需记录到实验记录中供逐步核对。
3. 实现按批的专家负载统计：统计每个专家承载的 token 数与样本数，计算专家利用率分布，当任一专家利用率持续低于配置阈值时输出包含步号与专家编号的塌缩告警。
4. 在训练目标中加入负载均衡辅助损失与路由损失，并使用容量因子限制单专家可承载的 token 数；当某专家超出容量时执行丢弃或溢出重路由，并在损失与分配结果中正确反映该约束。
5. 按材料体系与仪器来源分组输出专家专精分布报告：每组样本落在各专家的 token 占比与激活权重均值，并标记稀有材料体系中超过 80% 的 token 集中到单一专家的情形。
6. 当某专家连续若干步利用率低于阈值时，自动调整路由温度或重新初始化门控，并输出调整前后的逐专家分配矩阵、利用率数值与损失变化对比。调整策略需由配置参数控制且可复现。
7. 对同一批谱图在三个格式版本归一后执行路由与负载计算，输出一致的专家分配矩阵、专家承载数与负载均衡损失数值，并生成跨版本差异清单，列出任何不一致的 token 索引与原因分类。
8. 实现独立的参考路由与负载计算器（与训练门控分离，直接对归一谱图执行固定路由规则），逐步核对训练产生的分配矩阵、专家承载数与均衡损失，报告首个不一致的训练步及该步的路由依据。

验收：
以题内参考计算器逐步核对分配矩阵、专家承载数与均衡损失；用稀有材料、容量溢出与门控亲和度接近的样本检查塌缩告警与调整逻辑；核对三版本归一后的分配与损失一致。
