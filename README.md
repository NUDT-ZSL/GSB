当前是空白工作区，没有现存项目、代码或数据附件。需要从零构建一个面向批量矩阵乘（BMM）与 2D GEMM 的本地数据处理管线与结果验证工具，核心业务问题是多阶段算子执行过程中的状态演进与恢复一致性。业务对象是本地确定性生成的矩阵乘任务清单（JSONL，字段含 job_id、op_kind（gemm 或 bmm）、matrix_shapes、dtype、layout、seed、block_size、accum_mode），矩阵数组由固定种子驱动 NumPy 生成，不依赖任何外部模型或数据附件。系统把一次批量矩阵乘执行建模为四阶段流水：输入校验与批次语义解析→按规模选择分块策略→分块累加与补偿求和→结果聚合与偏差裁决。每个阶段产生可持久化的阶段快照，进程被强制终止后重启必须从最后一次已提交阶段继续，已提交阶段的任务不得重算，进行中未提交的中间分块必须丢弃并从该阶段起点重建，恢复后最终输出须与不间断完整运行逐元素一致。

任务环境与准备：
安装 Python 3.10 或以上版本与 NumPy（建议 1.24 及以上），不引入其他第三方依赖。
在本地空白工作区创建项目目录，准备 JSONL 格式的矩阵乘任务清单与按固定种子生成矩阵数组的样本脚本，全部数据本地确定性生成。
确保存在可写本地目录用于持久化阶段快照，并准备本地进程控制脚本用于模拟强制终止与重启。
运行环境为 Windows，命令行示例使用 Python 标准库 argparse 与本地文件系统，不依赖任何外部服务或网络。

业务要求：
1. 实现矩阵乘的统一执行入口，按清单解析 op_kind、matrix_shapes、dtype、layout、seed、block_size 与 accum_mode；对非法形状、批次维度不一致、dtype 不支持、block_size 非正、accum_mode 未知分别返回 E_SHAPE_INVALID、E_BATCH_MISMATCH、E_DTYPE_UNSUPPORTED、E_BLOCK_SIZE_INVALID、E_ACCUM_MODE_UNKNOWN，并在错误中携带 job_id 与字段名。
2. 实现基于输入规模的分块策略决策阶段：按矩阵维度与批次大小选择分块尺寸、循环顺序与是否走批量聚合路径，输出可复现的策略记录（含决策依据的维度与代价估计）；同一 job_id、同一 seed 与同一配置下决策必须逐字节一致，分块尺寸须整除或覆盖全部行与列且不得遗漏任何元素。
3. 实现分块累加与补偿求和阶段：按选定分块完成矩阵乘累加，支持可配置的补偿求和以降低舍入误差，提供可配置的次正规数保护与舍入模式，全部中间量以 float64 计算；分块路径结果须与 float64 参考实现在给定容差内一致，超出返回 E_TOLERANCE_EXCEEDED 并指出越界元素位置与偏差量。
4. 实现输入校验、策略决策、分块累加、结果聚合四个阶段的状态机，每阶段产生带单调递增版本号、已完成 job 集合与内容校验和的阶段快照，只有该阶段全部任务完成才提交；提交记录须在本地持久化存储中原子可见，同时体现阶段名、版本号与校验和，部分完成的阶段不得提交为已完成状态。
5. 实现强制终止后的恢复逻辑：重启时读取已提交阶段快照，从最后一次已提交阶段继续推进，已提交阶段的任务不得重算或重复计入；未提交的中间分块累加状态必须丢弃并从该阶段起点重建，恢复后的最终输出与逐任务摘要须与不间断完整运行逐元素一致，恢复报告须列出已提交阶段、重建阶段与丢弃的分块数量。
6. 实现快照版本变化与整体替换防护：检测到版本号或内容校验和变化时必须整体替换旧快照而非增量修补，旧版本快照不得覆盖新版本已提交阶段，回退尝试返回 E_SNAPSHOT_ROLLBACK；损坏或校验和不符的快照加载时返回 E_SNAPSHOT_CORRUPT 并指明阶段名与版本号，禁止使用部分可解析的损坏数据继续执行。
7. 实现并发提交控制与资源上限：同一时刻只允许一个阶段提交生效，并发提交冲突时后到者立即获得 E_STAGE_BUSY 而不阻塞等待；为单阶段任务数、驻留分块累加中间缓冲内存估算与分块数量设可配置上限，超限时按明确策略返回 E_RESOURCE_LIMIT 或降级到更小分块，降级须在结果中标记降级类别且不得改变已提交阶段的正确性。
8. 提供本地可交互的结果验证工具与跨模块一致性自检：展示当前阶段、快照版本、各任务完成计数、补偿求和介入次数、偏差谱与最近业务错误码；独立复核 GEMM 与 batch=1 的 BMM 结果一致、行主序与列主序结果在转置语义上可核对、各分块部分和可合并还原为整体结果，检测到不一致返回 E_INCONSISTENT 并指出类别与 job_id，并支持触发一次演示：执行批量任务、强制终止后从已提交快照恢复并对比恢复结果与完整运行结果。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
