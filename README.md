当前是空白工作区，需要从零构建一个面向 Windows 本地环境的分布式哈希连接与 Shuffle 分区计算引擎组件，聚焦数值精度与误差传播。系统以本地 JSON 文件描述两张逻辑表的列结构（整数列、浮点列、空值位图）与确定性样本行数据，以及一次连接查询（连接键、单侧或双侧过滤谓词、投影列、连接类型为 INNER）。执行阶段分两步：先按 Shuffle 分区器把两张表按连接键的稳定哈希分配到固定数量的分区（分区数由整数参数给出），再在每个分区内完成哈希连接。核心业务是：连接键与谓词中的浮点数值须以会话参数指定的定点缩放因子量化后参与哈希与比较，而连接结果中的浮点列须保留浮点参考值与定点值两份，并逐行给出量化误差界与误差来源；同时须输出每个分区的行数、哈希桶装载因子、溢出探测次数与聚合统计（计数、求和、均值）的定点表示和量化误差上界，使误差可沿 Shuffle、桶探测与聚合三段传播路径被归因。

任务环境与准备：
安装 Python 3.11 及以上版本，并安装 NumPy（建议 1.26 及以上）与标准库之外的零额外依赖；在命令行确认 python --version 与 python -c "import numpy" 可用。
在工作区根目录创建项目目录结构，自行编写本地确定性样本表 JSON、查询定义与演示脚本；所有数据与脚本均存放于本地文件系统，不访问网络或真实账户。
准备命令行运行入口与结果校验工具入口，确保在 Windows PowerShell 与 cmd 下均可通过 python 命令执行，并预留参数用于注入空值位图错位、缩放因子不合法与分区数超限。
运行演示脚本前确认工作目录可写，用于输出结构化日志与实验报告文件。

业务要求：
1. 实现本地表定义与样本数据的加载及强校验：从本地 JSON 读取两张表的列结构（整数列、浮点列、空值位图）与确定性行数据，校验表名唯一、列名合法、连接键列存在且两侧类型可比较、空值位图长度与行数一致、整数列取值在声明范围内；任一不合法须以 E_TABLE 业务码整体拒绝加载并输出出错表名、行号与列名。
2. 实现按连接键的确定性 Shuffle 分区：对连接键按稳定哈希映射到给定整数个分区，整数键与浮点键（先按会话缩放因子量化为定点整数）分别采用显式声明的哈希组合规则；相同输入在不同分区数以外的任何执行顺序与并发度下，必须使每个连接键落到同一分区并得到逐字节一致的分区摘要；分区数不是正整数或超过上限须返回 E_PART。
3. 实现定点量化基础设施与量化误差界推导：以会话参数指定的缩放因子（10 的整数幂）把浮点连接键、谓词常量与聚合输入量化为定点整数，乘除均以整数运算完成并显式声明截断方向；须对单个值的量化误差、比较判定的边界误差与累加多值的误差界给出以整数格表示的推导，并将所用缩放因子与误差界写入执行报告。
4. 实现分区内哈希连接与溢出探测：每分区为构建侧建开放寻址哈希表，按分区数与行数推导桶容量与装载因子，探测次数、溢出区访问与空值处理须逐分区统计；连接键为空值的行在 INNER 连接中不得匹配任何行，浮点键比较须以量化后的定点整数为准并记录量化后碰撞但浮点参考值不等的行对，不得将其静默视为匹配。
5. 实现连接结果的浮点双值与逐行误差归因：每条输出行的浮点投影列须同时给出浮点参考值与定点值，并标注该行误差主要来源为量化、聚合累加或两者兼有；误差归因须与分区数和执行顺序无关，同一行无论落在哪个分区都须得到相同归因结果，不一致须以 E_ATTR 报告首个不一致行标识。
6. 实现分区级与全局聚合统计的定点输出：按分区与全局分别计算计数、求和与均值，均以整数定点表示并给出量化误差上界；均值须显式定义舍入或截断方向，空值不参与求和与均值但在计数中单独统计；聚合误差界须与输入规模（行数、缩放因子）相容，相同输入多次运行必须得到同一整数结果。
7. 实现误差传播路径的三段归因报告与异常链路：报告须按 Shuffle、桶探测、聚合三段分别列出误差界贡献、受影响行数占比与主导段，主导段判定须有显式阈值规则；支持以命令行参数注入空值位图错位、缩放因子不合法、分区数超限三类异常，分别以 E_NULLMAP、E_SCALEF、E_PART 业务码报告并写入结构化日志，注入仅改变输入文件或参数。
8. 实现可重复实验脚本与结果校验工具：附带本地确定性样本表、查询与演示脚本，顺序执行小规模单分区、多分区连接与缩放因子扰动三次实验，每次输出分区统计、逐段误差界、聚合结果与主导误差段；校验工具独立读取各次报告，校验分区摘要一致性、定点聚合可重算性与误差界自洽，不一致须以 E_VERIFY 列出首个偏差项。
