在游戏场景光照预计算与影视预览中，需要从零开发一个本地离屏渲染引擎，把由透明介质（雾、玻璃板、有色水体）与若干点光源组成的场景渲染为二维灰度图像，并对渲染过程中数值误差的产生与传播给出可复核的评估。输入为一个 JSON 场景描述：介质体由若干轴对齐盒体定义，每盒给出消光系数、散射反照率与折射率；光源清单给出位置与辐射强度；相机参数给出位置、朝向、垂直视场角与宽高比；此外还有渲染分辨率、每像素超采样倍数、光线步长与最大步数、透射率截断阈值、分块规格、并发上限、在途采样缓冲内存上限与状态目录。介质栅格与期望值由程序按确定性规则生成本地样本，不依赖任何外部资源。核心难点在于透射率沿光线按指数衰减累积，误差随路径长度与介质层数放大，单精度中间量、步长选择与多介质界面次序都会显著改变结果。

任务环境与准备：
安装 Python 3.10 或以上，并安装 NumPy 1.x 或 2.x 的 Windows 可执行版本。
确认工作区为空，由程序按下述规则生成本地样本：介质盒、光源与相机参数写入一个 JSON 描述文件；介质栅格与期望透射率由固定种子派生，可重复生成。
准备状态目录与输出目录各一个，确保具备读写权限；不需要网络、账号、GPU 或任何外部资源。
准备本地验证脚本，用于触发生成样本、执行渲染、发送中断标记并比对分块摘要，不修改任何源码即可更换输入参数。

业务要求：
1. 实现场景描述解析与输入校验：读取 JSON 描述，校验各介质盒尺寸与消光系数为有限正数、散射反照率落在 [0,1]、折射率为不小于 1 的有限数、光源位置在场景包围盒内且辐射强度为正、视场角在 (0,180) 度内、步长与最大步数为正整数、分块规格完整覆盖超采样像素网格，非法输入返回带 E_xxx 业务码的 JSON 错误且不产生任何输出文件。
2. 实现统一世界坐标下的光线与多介质求交：按轴对齐盒体求光线区间，把各介质区间按入射次序合并为有序区间链，重叠区间按盒声明顺序与折射率确定唯一优先归属，区间边界处的采样点用相邻区间中点归属判定而非端点归属，交界处光学厚度既不得双重计入也不得丢失，保证结果不受分块顺序影响。
3. 实现指数透射率累积与散射贡献合成：沿光线按步长在介质区间内采样，透射率按逐段消光光学厚度的指数衰减累乘，散射项按反照率与光源可见性在每个采样点累加并按剩余透射率加权，透射率低于截断阈值或达到最大步数时终止；被终止的像素须在报告中标注截断原因并计入统计，灰度量化到 0 至 255。
4. 实现双精度参考与单精度中间量的误差对照：同一次渲染同时以 float64 逐段累乘与规格声明的单精度中间量（每步量化到规格给定有效位）计算透射率，记录两者在每个采样点的绝对差值，标出首次超过透射率容差的采样点序号、所在介质区间与像素坐标，最终输出灰度只依据 float64 结果，单精度结果仅用于误差评估。
5. 实现步长与截断阈值对结果稳定性的量化评估：在规格给出的步长与截断阈值抖动集合上各重渲一次，对同一相机与介质计算各配置结果与基准配置的逐像素最大偏差与均方偏差，给出偏差随步长收敛或随阈值放宽发散的趋势结论，趋势判定须由实际渲染数值给出而非预设。
6. 实现确定性分块并发渲染与内存上限：按分块规格把超采样像素网格分块，用有界线程池按并发上限调度，每块只读介质、光源与相机参数并写回块私有结果，同时在途采样缓冲总量不超过描述中的内存上限，超出时按分块索引序等待而非降低步长或精度；任一分块异常时取消其余待处理分块并返回首个错误。
7. 实现分块级持久化与版本识别恢复：每块完成后把该块颜色与误差统计、块内容摘要及由介质与光源参数、相机参数、步长与阈值规范化摘要构成的版本标识原子写入状态目录，先写同目录临时文件再整体替换，替换前比对已有分块版本标识，标识变化时不得直接覆盖旧分块而须先归档；再次启动时标识一致则只渲缺失块。
8. 处理中断信号、强制终止与图像原子写出：可处理终止信号只在分块边界生效，写入中断标记并以约定整数退出码退出，未完成分块不得留下可被误认为完成的结果；强制终止后重启仅依据已持久化且摘要有效的分块状态恢复且不承诺生成退出报告；全部块完成后按行序拼装灰度图与误差报告，先写临时文件再整体替换正式输出。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
