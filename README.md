Linux（WSL Ubuntu）环境，安装 Python 3.11 及以上版本
安装依赖：pip install numpy
SQLite 使用 Python 内置 sqlite3 模块
工作目录为空，所有样本由随题交付的固定种子脚本生成
不依赖网络或外部服务

业务要求：
1. 实现表描述、流式查询计划、批次到达剧本与执行配置的解析校验：表名唯一，列类型枚举合法，窗口参数为正整数，倾斜键分布比例在开区间内且合法，批次序号严格递增，注入逻辑时钟为非负整数，漂移阈值在开区间内，并行任务上限与每轮逻辑时间预算为正整数，定点标度为正整数；所有非法输入必须返回明确业务错误码，不得部分解析或静默跳过。
2. 按确定性规则生成列式批次数据：依据表描述、全局种子和批次序号生成每批列式数组，倾斜键按声明比例集中分布，相同输入在任意运行次数下必须逐位复现每批摘要与行数，并将每批摘要作为后续漂移观测和真值对照的唯一数据来源，生成过程不得依赖网络、真实数据或系统墙钟。
3. 按初始窗口聚合计划逐批推进计算，并在每个观测点从已提交批次结果导出实测窗口行数、输出基数与聚合耗时，实测观测只能依据已到达且已提交的批次，不得使用后续批次信息回填；同时以单窗口逐行精确聚合作为唯一真值通路，使两条通路在相同输入下逐值一致，任意不一致必须输出首个分歧批次和关键中间值。
4. 实现代价模型漂移判定与重优化触发裁决：以初始估计与实测观测计算偏差比，按漂移阈值与重优化冷却逻辑毫秒裁决是否触发重优化；触发时必须输出漂移来源表名、窗口标识、偏差比、所用观测批次区间、触发依据与阈值余量，未触发时不得改变执行形态；冷却窗口内重复满足条件不得重复触发。
5. 实现执行形态切换与切换代价预算裁决：切换只允许发生在窗口边界，进行中窗口必须按原形态完成到该窗口结束；在切换代价预算内按候选窗口聚合顺序与算子组合估算切换成本，选定新形态并记录被否决候选及首个否决原因，预算不足时保留原形态并返回独立业务错误码，切换后的结果必须与全量精确聚合逐值一致且不得改变已提交窗口结果。
6. 实现漂移观测与切换代价的定点换算和误差账本：对实测窗口行数、输出基数、聚合耗时与切换成本按声明定点标度换算，记录每次换算的标度、舍入方向与被舍弃余量，并累计加法与乘法误差上界；当两个候选形态的代价差小于容差且切换裁决依赖该差值时标记精度敏感，并输出误差来源链，含参与批次、换算步骤和误差上界。
7. 实现并行聚合调度与逻辑时间预算双重约束：同一轮次内按窗口分组并发执行聚合任务，同时受并行任务上限与每轮逻辑时间预算约束，每个任务启动前先估算内存占用并与剩余预算比较；预算耗尽必须放弃剩余未启动窗口并记录放弃原因，严格区分预算内未启动、启动后失败与主动放弃三类结局，已启动任务不得被截断为失败或产生部分提交。
8. 实现持久化状态与强制终止后的恢复一致性：把窗口水位、已提交批次摘要、当前执行形态指针、漂移触发记录、精度敏感标记和逻辑时钟水位以事务原子写入 SQLite，每次形态切换以版本号整体替换当前指针并拒绝版本回退；进程被强制终止后，恢复路径依据持久化状态识别已提交批次与半提交窗口，只重放缺失部分，恢复后的聚合结果与一次性连续执行逐值一致且不重复计算已提交窗口。
