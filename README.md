当前是空白工作区，没有现存项目、代码或数据附件，需要从零构建一个面向表格二分类的本地线性模型正则化训练引擎，并附可复现的实验环境。业务对象是本地确定性生成的表格样本（JSONL，字段含 row_id、若干数值列与类别列、label）以及一份训练配置：正则化类型（L2 或弹性网）、正则化强度网格（按从小到大的路径序列）、每档强度的迭代上限与收敛容差、特征标准化方式、数值精度档（float64、float32、定点缩放整数）、定点缩放因子与舍入模式、分块口径、并行 worker 数与内存与比较次数预算。引擎沿正则化路径逐档求解线性模型（坐标下降或梯度法的确定性实现），每档产出系数向量、截距、目标函数值与收敛状态；求解阶段按数据分块并行，分块归约顺序显式声明。核心矛盾在于：并行度与分块会缩短整体耗时却放大驻留内存与比较次数，定点档与更强正则化节省数值范围却会放大系数的舍入误差并改变路径单调性判定，而逐档求解过程中的中断必须能从已提交档位恢复且不得重算。输入输出、业务码与容差口径均由配置与本地确定性样本决定。

任务环境与准备：
安装 Python 3.10 及以上与 NumPy，确保可在本地启动多进程池
创建空白工作目录，准备由固定随机种子生成表格样本与训练配置的本地脚本，不依赖网络或外部数据
准备本地持久化目录用于阶段快照与缓存条目，并确认可对其注入损坏与版本回退以验证业务码

业务要求：
1. 实现确定性的特征标准化与正则化路径求解层：数值列按配置做 z-score 或 min-max，类别列按固定规则编码；从强度最大的档开始逐档用确定性求解器求解，每档输出系数向量、截距、目标函数值与收敛标记，同一输入同一配置重跑必须逐字节一致。
2. 实现基于输入规模的分块策略决策器：按样本数、特征数与当前剩余预算选择分块尺寸、归约顺序与是否走小分块降级路径，输出含决策依据的代价估计记录；同一观测下决策必须逐字节一致，且所选分块必须覆盖全部样本行、不遗漏也不重复计入。
3. 实现可切换的精度档执行层：float64、float32 与定点缩放整数三档共用同一算子语义，定点档的缩放因子与舍入模式由配置显式给出；同一输入在不同精度档下结果差异必须仅来自精度损失本身，禁止以切换精度档改变求解语义。
4. 实现并行调度层：按可配置 worker 数与每批样本数把分块分配给本地进程池执行梯度或坐标更新，分块边界、任务派发顺序与归并顺序必须确定性可复现；worker 内异常须以结构化业务码与阶段名回传主进程并归因到具体档位与分块。
5. 实现四阶段状态机与强制终止后的恢复：标准化、逐档求解、路径汇总等阶段各自产生带单调递增版本号与内容校验和的阶段快照，只有该阶段全部档位完成才提交；重启时从最后已提交档继续，已提交档的系数不得重算，未提交的中间迭代状态必须丢弃并从该档起点重建。
6. 实现快照版本变化与整体替换防护：检测到版本号或校验和变化时必须整体替换旧快照而非增量修补，旧版本快照不得覆盖新版本已提交档位，回退尝试返回 E_SNAPSHOT_ROLLBACK；损坏或校验和不符的快照在读取时返回 E_SNAPSHOT_CORRUPT 并指明阶段名与版本号。
7. 实现跨档一致性与路径单调性自检：校验相邻档位的系数范数随正则化强度单调不增（允许声明容差）、目标函数值可由系数与标准化统计量独立重算一致、标准化统计量版本与求解所用版本一致；违反分别返回 E_MONOTONICITY、E_OBJECTIVE_MISMATCH、E_VERSION_MISMATCH 并指出档位。
8. 实现并发提交控制与资源预算上限：同一时刻只允许一个阶段提交生效，并发提交冲突时后到者立即获得 E_STAGE_BUSY 而不阻塞等待；为路径档位数、单档迭代次数与驻留内存估算设可配置上限，超限返回 E_RESOURCE_LIMIT 或降级并标记降级类别，降级不得改变已提交档位结果。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地确定性样本跑完整路径并校验强制终止恢复与并行结果一致，另验证各业务码与跨档单调性自检。
