从无到有搭建时，需要实现一个本地灰度放量的观测口径变更诊断引擎，核心业务问题不是放量编排本身，而是判定“观测口径变化是否已使已提交的档位观察结论失效”，并据此给出受影响批次的精确重判集合。本地样本给出：批次档位清单（批次号、档位序号与流量比例、观察点标记）、观测事件流（事件序号、批次号、档位序号、注入逻辑时钟毫秒戳、指标名、指标值、采样口径标识与样本摘要）、口径版本包（v1 为单文件 JSON 的判据名、指标阈值、窗口长度与相对生效秒数；v2 为分片 JSON 加 SQLite 元数据的绝对生效毫秒戳、判据代数、适用档位集合与墓碑标记），以及已提交结论快照（每档位的通过或中止结论、所依据的判据版本与参与样本摘要）。另有一层本地回环 HTTP 测试服务，用于拉取各口径下的指标样本供重判对照。

任务环境与准备：
安装 Python 3.11（Windows 官网安装包，勾选加入 PATH），并执行 pip install flask；SQLite 使用 Python 标准库 sqlite3，无需额外安装。
在工作区创建样本目录，准备批次档位清单 JSON、观测事件流 JSON、v1 判据单文件 JSON、v2 判据分片 JSON 与 SQLite 元数据、已提交结论快照、判据补丁清单与异常注入清单，均作为任务输入随任务提供，不依赖网络与真实账号。
启动本地回环 HTTP 测试服务（Python 标准库实现），提供按不同采样口径返回指标样本、错误响应、畸形响应与拒绝连接的路径，供重判对照使用；运行 python -V 与 pip show flask 确认环境前置条件。

业务要求：
1. 实现档位清单、观测事件流与口径版本包的解析校验：批次号与档位序号组合唯一、流量比例严格递增且末档为 1.0、观察点标记位于档位序列内、事件序号严格递增且逻辑时钟为非负整数、采样口径标识枚举闭合、样本摘要与指标值对应、v1 判据阈值与窗口长度类型合法、v2 分片哈希与判据代数单调；非法输入须返回区分来源格式的业务错误码（如 E_BAD_V1_CRITERIA、E_BAD_V2_CRITERIA）且不写入任何持久化状态。
2. 实现口径版本包的跨版本合并与统一判据视图构建：同一判据名在 v1 与 v2 中同时存在时，依据声明的逻辑时钟与判据代数裁决最新版本，逻辑时钟相同按来源格式优先级；v1 相对生效秒数在注入逻辑时钟下换算为绝对生效毫秒时刻并记录换算标度、舍入方向与被舍弃余量，同一逻辑时钟下重复换算逐位一致；合并后每条判据保留来源版本、原始时间表示、裁决依据与适用档位集合。
3. 实现观测点结论的重新判定：对指定档位按适用判据在当前口径集合下重判通过或中止，输出参与判定的样本序号、指标值、阈值、判据版本与所用口径；原始已提交结论必须持久保留不被覆盖，重判结果以独立记录并标注与原始结论相同或相异，相异时给出首个导致翻转的样本及其两端指标差，重判所用样本只能取自已提交事件，不得引用后续到达事件。
4. 实现采样口径漂移检测与翻转归因：当某档位观测到的口径集合发生变化，且同一判据在变化前后口径下结论不同时输出漂移标记，记录变化前后口径、受影响档位、首个结论翻转事件序号与判据版本；若同一档位在多种口径下结论都一致则不得标记漂移，口径变化但阈值内结论未翻转的档位须单列为“口径已变但结论保持”，与漂移区分。
5. 实现失效闭包裁决与结论复用：以漂移标记或判据补丁提交为触发，沿“判据—档位—批次”的关系计算受影响闭包，精确标记哪些批次的重判集合非空、哪些可整批复用原结论；未受影响的批次与档位不得被重判，其结论、依据与参与样本摘要必须保持原值，失效事件须记录触发来源、被否决的复用判断与原因。
6. 实现重判轮次在判据窗口长度与样本规模变化下的判定算法取舍：依据待重判档位数、样本数与窗口长度估算开销，在逐样本精确判定与按窗口分桶采样判定之间按明确阈值切换，输出实际模式、触发条件与被否决模式原因及采样模式漏判率上界估计；采样模式只能用于预筛，凡采样模式结论与精确模式不一致的档位须以精确结论为准并标记采样模式不适用，使切换不改变最终重判集合。
7. 实现强制终止后的恢复与多进程并发幂等：把重判轮次水位、每档位原始结论与重判结论、漂移标记、失效闭包与逻辑时钟水位以事务原子写入 SQLite；进程在重判或补丁提交中途被强制终止后，恢复路径只重做未提交档位且不得覆盖已提交原始结论或重复计入失效事件；允许多个诊断实例并行处理不同批次，保证同一批次同一档位同一判据版本只提交一次重判结果，重复提交幂等，读取方只能看到完整已提交轮次。
8. 实现口径版本整体替换、异常链路隔离与可重复诊断接口：收到新口径包时比较清单版本号、判据代数下限、各分片哈希与适用档位摘要，判定完整替换、增量追加或无需操作并拒绝版本回退；观测服务连接拒绝、响应超出单请求逻辑预算、响应畸形、样本摘要不匹配、逻辑时钟回拨超容差分别映射到不同业务错误码并保留批次号、档位序号、观测序号与判据版本等诊断字段；提供 Flask 接口或等价子命令以稳定排序 JSON 输出漂移标记、失效闭包、重判集合与算法模式选择，同一输入重复运行输出逐位一致。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
