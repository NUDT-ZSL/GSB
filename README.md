某安全团队需要在离线 Windows 空白工作区从零开发一个密码协议密钥生命周期审计引擎，针对一种自研本地协议 KLP（Key Lifecycle Protocol）的确定性二进制会话记录做合规性与漏洞检测。每条会话记录由若干带阶段标记的密钥操作事件组成：参数协商、密钥派生、轮换、封存、销毁；每阶段事件携带阶段标识、算法标识、参数向量（迭代次数、盐长度、输出长度、派生层级）与阶段序号。核心难点是数据规模变化与算法取舍：在极小参数规模下需精确判定派生链各阶段的合法性与状态迁移，在大参数规模下需在可配置的真实耗时与内存预算内完成校验并给出可解释的降级结论，同时阶段状态机必须满足幂等与顺序无关的结论一致性。交付为可集成的领域组件与完整示例，含确定性样本生成器、结构化报告与命令行入口。

任务环境与准备：
Windows 10 及以上，安装 Python 3.11 与 pip，创建虚拟环境。
安装 NumPy 与 pytest，依赖在准备阶段一次性装好，执行阶段不依赖网络、账号或外部服务。
在空白工作区创建项目目录，准备生成器输出目录、报告目录与检查点目录。
确认本地文件锁与临时文件重命名在所用 Windows 文件系统上可用。
运行样本生成器产出合法与畸形样本，并使用 pytest 执行测试集。

业务要求：
1. 实现 KLP 会话记录的严格解析与规范化层：校验阶段标识白名单、算法标识白名单（HMAC-SHA256、HKDF-SHA256、PBKDF2-SHA256 三类）、阶段序号在同一会话内单调递增，参数向量字段类型与取值边界（迭代次数为正整数且不超过记录头部声明的上限、盐长度与输出长度为字节数），畸形记录须输出含记录序号的拒绝清单并继续处理后续记录。
2. 实现密钥派生阶段状态机：按协商→派生→轮换→封存→销毁的合法迁移规则判定每个会话的阶段序列，非法跳转（未协商即派生、销毁后轮换等）返回 E_TRANSITION，缺失必需阶段返回 E_INCOMPLETE，同一会话重复出现相同阶段序号而内容冲突返回 E_SEQ_CONFLICT；状态机结论须与记录到达顺序无关，处理前须按会话标识与阶段序号稳定排序。
3. 实现派生链一致性校验：依据参数向量中的派生层级重建父子派生关系，校验盐不得在同一派生链中重复、子密钥输出长度不得超出父密钥输出长度、迭代次数沿链不得递减，违规分别返回 E_SALT_REUSE、E_LENGTH_ESCALATION 与 E_ITER_REGRESSION，并给出派生链中违规节点与父子路径。
4. 实现数据规模自适应的算法取舍策略：以输入记录总字节数与派生物总数为规模观测值，在规模低于阈值时执行完整逐链校验，超过阈值时切换为分块采样校验但须在报告中显式标记降级模式与已覆盖比例；无论何种模式的结论、降级标记与采样覆盖率都必须由观测值确定，相同输入在任意运行中都产出相同结果。
5. 实现真实资源预算控制：并发度、单会话真实耗时上限与单会话派生物计算上限均可配置，耗时须以真实计时判定而非人为延迟，超时返回 E_TIMEOUT、超计算上限返回 E_BUDGET；超预算会话不得中断其余会话处理，也不得把尚未执行完的校验计入通过；并发度变化不得改变任何会话的结论与报告的稳定排序。
6. 实现检查点与状态演进恢复：按已处理会话水位与聚合结论持久化检查点，恢复时只从最后一个完整检查点继续；检查点结构版本或算法白名单版本变化时须整体重建而非增量续接，不得把旧版校验结论与新策略混合；检查点与最终报告均先写临时文件再整体重命名替换，同一工作目录并发写入以文件锁串行化，锁冲突返回 E_LOCK。
7. 实现结构化审计报告与退出码约定：报告为可解析 JSON，含文件级结论、每会话每阶段状态、业务错误码、出错偏移与降级覆盖信息；报告须原子写出并保证稳定字段顺序；单个会话解析失败不得中断同批其他会话，退出码以整数区分全部成功、部分失败与参数错误，业务码 E_xxx 统一出现在报告与 stderr 中。
8. 提供确定性本地样本生成器与 pytest 测试集：样本显式记录每个会话发送端参数向量与同步标记作为真值来源，验证端只依据同步标记与规范化参数比较；覆盖非法阶段跳转、盐复用、长度升级、迭代回退、规模阈值两侧、超时、锁冲突与强制终止恢复，测试断言业务码、派生链路径、降级覆盖与恢复后状态。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本验证状态机、派生链规则、规模降级与检查点恢复，核对报告与退出码。
