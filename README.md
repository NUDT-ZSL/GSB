美术入库环节需要一个离线工作台，把三维扫描得到的稀疏点云按多个相机视角渲染成灰度图与以世界单位表示的深度图，用于检查点云的空间分布与遮挡关系；当一批点云局部被重新扫描替换后，只补渲受影响的屏幕分块，并说明哪些分块为何失效、补渲结果是否与整幅重算逐像素一致。工作区目前没有任何代码与样本，只有一台安装 Python 的 Windows 开发机；点云、相机参数、分块配置与编辑清单全部由随工程交付的固定种子脚本确定性生成本地 JSON 与二进制点云文件，不依赖网络、真实扫描设备或外部数据集。渲染须在统一世界坐标单位下完成，输出为按固定分块网格切分的灰度图与深度图。

任务环境与准备：
确认 Windows 本地已安装 Python 3.11 或以上，并可用 python -m pip 安装依赖。
安装 NumPy 1.26 或以上：python -m pip install "numpy>=1.26"；SQLite 使用 Python 标准库 sqlite3，无需额外安装。
在空工作区中创建项目目录，随工程提供的固定种子脚本生成点云、相机参数、分块配置与编辑清单样本，所有样本写入本地子目录，不访问网络。
准备一个本地状态目录用于分块缓存与中断标记，运行示例与诊断视图前确认该目录可写；诊断视图采用本地进程内渲染，不依赖外部服务。

业务要求：
1. 实现渲染任务描述与点云文件解析校验：读取 JSON 任务与点云二进制数据，校验每点坐标、灰度与法线均为有限数、灰度落在 0 至 1、法线非零、世界尺度与坐标原点偏移为有限数、垂直视场角在 (0,180) 度内、宽高比与超采样倍数为有限正数、分块规格完整覆盖输出分辨率；非法输入返回带 E_xxx 业务码的 JSON 错误且不产生任何输出产物。
2. 实现点到超采样像素的投影与深度遮挡：按相机位置、目标点与上方向构造视图变换（上方向与视线平行时报 E_CAMERA），按垂直视场角与宽高比构造透视投影，把每个点以其世界半径投影为屏幕覆盖区域；同一超采样点被多点覆盖时按世界单位深度比较决定可见点，最近点按深度衰减写入灰度，更远点不再贡献，保证世界尺度整体缩放时相对遮挡关系不变。
3. 实现整幅坐标下的分块渲染与串行等价：按分块规格划分超采样像素网格，每块的像素结果只依赖点云、相机与渲染参数，块内对点的过滤与写入次序须与串行逐点处理等价，超采样平均降采样后拼装结果须与并发度为 1 时的结果逐像素完全相同；禁止块间共享可写缓冲或依赖块处理完成顺序。
4. 实现确定性并发调度与双预算裁决：按并发上限使用有界线程池调度分块，同时在途分块采样缓冲总量不得超过对应内存预算，超出时按分块索引序让后续块等待而非降低超采样倍数；按可注入逻辑时钟计量每轮耗时，超出单轮逻辑时间预算即结束本轮并让出，未准入分块延后，且准入序列能在相同输入下复现。
5. 实现点云局部替换后的依赖记录与失效闭包：为每块记录其覆盖的屏幕区域及投影后可能被该块采样到的点索引集合，编辑清单中的子区域替换只把与受影响点索引相交的分块标记失效，其余块复用已持久化结果；报告须逐块列出失效理由、受影响点数与重渲块数，并说明未受影响块为何可安全复用。
6. 实现分块级持久化与版本识别恢复：每块完成后把灰度、深度、点索引依赖摘要与由点云内容、相机及渲染参数规范化摘要构成的版本标识原子写入状态目录，先写同目录临时文件再整体替换；再次启动时版本标识一致则复用已完成块只补缺失块，不一致则从整幅重做，强制终止后仅依赖已持久化且摘要有效的块状态恢复且不承诺生成退出报告。
7. 处理可处理终止信号与块摘要校验：可处理终止信号只在分块边界生效，写入中断标记并以约定整数退出码退出，未完成块不得留下可被误认为完成的结果；全部块完成后逐块比对内容摘要，不匹配、缺失或声明像素数不符时返回 E_DIGEST 并只补渲该块，最终图像与深度图先写同目录临时文件再整体替换正式文件。
8. 实现并发资源上限与诊断工作台：在途分块采样缓冲总量超预算时按分块索引序等待，任一分块异常时取消其余待处理分块并返回首个错误；本地交互视图须展示投影图、深度图、分块网格与失效高亮，支持选择分块查看其失效理由、依赖点集与摘要校验结果，视图只读取已持久化的确定性结果。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
