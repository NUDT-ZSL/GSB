剧情向独立游戏的交互叙事场景里，烟雾、光晕、彩窗玻璃与贴片粒子大量以半透明元素共存，渲染时的绘制次序直接决定观众看到的色彩叠加。图形程序员需要在正式接入游戏引擎前，先在本地工作台做出可复核的排序与混合链路：按固定种子生成的叙事场景中，每个元素以三维各向异性高斯原语描述，带不透明度随深度调制的曲线和所属叙事图层，相机沿轨道逐帧采样。同批素材又分别以三种 schema 版本交付，字段命名与高斯参数编码方式各不相同，版本归一失误与排序策略失误都会表现为错误的覆盖。工作台要逐帧投影、排序、合成，并给出能定位违例的校验证据，帮助美术与程序共同判断问题出在哪一环。

任务环境与准备：
准备 Linux（WSL Ubuntu）上的 Python 3 运行环境，并安装所需的 NumPy 用于协方差变换与逐帧合成计算。
在新建的空工作目录中创建项目，场景工程、相机轨道与解析参考均由题面要求的确定性生成器产出，不依赖外部资产或网络。
工作台以可本地启动的 Python 程序入口运行，逐帧渲染结果、排序违例与归一差异输出到工作目录内的结果文件，供人工复核。

业务要求：
1. 从三种 schema 版本反序列化叙事元素，归一为统一的内部高斯模型，正确处理字段命名差异与协方差/旋转缩放两种参数编码，输出归一后每个元素的中心、旋转与缩放、不透明度、颜色、深度调制曲线采样与图层，并报告字段缺失或语义不可映射的条目。
2. 按相机轨道逐帧将三维高斯原语经视锥裁剪投影为屏幕空间椭圆，通过协方差变换给出椭圆中心、长短轴与朝向，标注被剔除或部分越界的元素及裁剪依据，每帧结果可独立重算复核。
3. 依据质心深度与椭圆重叠关系确定由远及近的透明绘制次序，在同一叙事图层内保持稳定顺序，识别深度接近或投影相互穿插的原语对并标记为排序敏感，输出可疑覆盖对清单。
4. 按绘制次序执行 alpha 混合，对每个原语按其深度调制曲线计算的实际不透明度施加贡献，逐帧输出 RGBA 合成结果，近裁剪与图层间混合边界不得出现未定义的贡献。
5. 在合成帧的重叠区域核对各原语的实际覆盖关系与绘制次序是否一致，定位排序违例像素并给出相关原语对与冲突深度，当逐原语排序与逐像素正确覆盖无法同时满足时按图层分层近似并记录降解范围。
6. 对同一叙事场景的三份 schema 版本分别归一后按同一相机轨道渲染，逐帧对比渲染结果差异，把差异归因为版本归一差异或排序策略差异并输出归一差异清单，不允许将两类差异混为一项。
7. 提供自带的确定性场景生成器，按固定种子产出含相互穿插半透明元素的工程、相机轨道与解析参考椭圆参数，解析参数须与实际生成的原语一致，供投影与排序结果对照。
8. 支持逐帧渲染与校验的中断续算，持久化已提交帧的渲染结果与排序判定，重启后从最近提交帧继续而不重放整条轨道，未提交的中间帧不得污染已提交状态。

验收：
以独立参考实现逐帧重算的投影椭圆、绘制次序与合成像素为基准，比对排序违例定位及三版本归因正确且重放可复现。
