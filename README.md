在空白工作区构建一个面向本地中文客服与工单文本的情感与风险判定交互式应用。输入为一份本地合成的 JSONL 文本样本（每行含样本 ID、原始中文句子与来源渠道，由固定种子程序从受控词表生成，覆盖正负面情感与一般、催办、投诉、风险四类风险等级），一份本地规则资源包（情感词典与程度副词表、风险关键词表与等级映射表、否定词表、规则冲突表），以及一份判定配置 JSON（词典命中权重与位置衰减系数、否定窗口长度、风险等级阈值、融合温度、交互延迟预算毫秒、线程池并发数、快照提交间隔）。应用需完成句子归一化、情感极性与强度打分、风险等级判定与融合，支持用户通过交互命令反复调整规则权重与阈值，后台以确定性流水线执行判定，前端在交互延迟预算内返回当前可用的最新判定摘要；连续编辑后最终判定结果必须与从零按相同最终输入与配置串行执行完全一致。核心难点在于延迟预算内返回的中间摘要与后台重算结果共用同一份判定状态，且预算耗尽的中间状态、可处理退出时的快照与强制终止后的恢复判定必须彼此衔接，不能出现摘要与最终结果不一致或快照版本混用。

任务环境与准备：
安装 Python 3.11 与 NumPy（版本以本地离线可用的 wheel 为准），确认 python 与 pip 可在命令行直接调用。
在空白工作区创建项目目录，按题面约定准备本地合成样本 JSONL、规则资源包与判定配置 JSON，样本与资源均由固定种子程序生成，不依赖网络或外部账号。
确认工作区具备可写的快照与临时目录，并在运行前清理历史快照以保证从空白状态开始验收。
准备一份交互编辑命令序列文本文件，用于回放权重、阈值与词条修改，命令序列内容与格式按题面交互要求自行定义并写入项目内说明。

业务要求：
1. 实现样本与资源加载层：逐行解析样本 JSONL 与规则资源包，校验样本 ID 唯一、句子非空、来源渠道在配置枚举内、情感词典权重为有限数、风险关键词到风险等级的映射不出现环；对空句、非法 JSON、未知来源渠道与非法映射分别输出 E_EMPTY_TEXT、E_BAD_RECORD、E_UNKNOWN_CHANNEL、E_RULE_CYCLE 业务码并进入失败清单，加载结果须计算资源包内容指纹供后续快照校验。
2. 实现句子归一化与情感极性强度打分：按全半角折叠、大小写折叠、连续空白合并与标点剥离归一化文本，按情感词典命中权重与位置衰减系数、程度副词放大系数与否定窗口长度内的极性翻转规则，以固定运算顺序合成情感得分并归一化到 -1 至 1；同分或同强度时按词典词形字典序确定主导贡献词，输出主导贡献词、各命中项贡献分解与归一化得分，同一输入与配置多次运行须逐字段一致。
3. 实现风险等级判定与融合裁决：依据风险关键词表命中项、各等级映射权重与配置的风险等级阈值判定风险等级，并将风险得分与情感得分按融合温度做减去最大值的稳定加权融合，得到最终风险置信度；当情感与风险指向冲突时按规则冲突表裁决并记录冲突对，同置信度按风险等级从高到低、再按样本 ID 字典序决断；输出每样本风险等级、融合置信度、情感与风险两路贡献分解及裁决依据。
4. 实现基于内容指纹的增量失效与精确重算范围：为归一化、情感打分、风险判定与融合各阶段产物计算由上游内容指纹、规则参数指纹与资源包指纹派生的缓存键，为每个词典词条与风险关键词记录引用它的样本集合；当交互命令修改权重、阈值或单条词条时，仅使引用受影响词条的样本的相关阶段及其下游失效并纳入重算集合，未失效样本必须直接复用产物且不得重复计算，复用与重算清单须可审计输出。
5. 实现交互延迟预算内的响应语义：每条交互命令触达后在配置的交互延迟预算内优先返回最近一次已完成的计算摘要（已完成样本数、当前风险等级分布、受影响样本清单与进度），预算内无法得到最新参数下的结果时返回带 E_INTERACT_BUDGET_PENDING 业务码的中间状态而非阻塞等待；预算耗尽后未完成部分转入后台继续计算并以 E_INTERACT_BUDGET_PENDING 标记其在摘要中的待定状态，延迟按单调时钟真实测量并记录到报告。
6. 保证多次交互后增量结果与串行全量执行逐字段一致：从任意初始状态执行任意编辑序列，每次命令后增量运行得到的逐样本情感得分、风险等级、融合置信度、贡献分解、样本输出顺序与失败清单顺序，必须与从空白工作区按相同最终输入与配置一次性全量串行执行的结果完全一致；比较须覆盖不同并发度与不同恢复点运行，任一字段不等即视为不一致并输出 E_INCONSISTENT。
7. 实现阶段快照整体替换、恢复一致性与可处理退出语义：各阶段产物以临时文件写盘后整体替换提交，清单文件记录全局版本号、配置哈希、资源包指纹、已完成样本列表与各阶段产物版本；启动时以版本号与配置哈希判定是否续跑，不一致输出 E_CONFIG_MISMATCH 并拒绝续跑；收到可处理的退出信号时完成当前命令的快照原子替换与进度记录后以整数退出码 0 退出，强制终止后重启仅依据清单中已完整替换的产物恢复并输出恢复点信息，不得承诺生成退出报告。
8. 实现并发处理一致性、异常隔离与诊断报告输出：使用线程池并发执行各样本的阶段计算，最大并发数取自配置，每个样本任务携带由样本 ID 与阶段名派生的稳定排序键，无论线程调度顺序与并发度如何，最终样本顺序、贡献分解顺序与失败清单顺序须与单线程按样本 ID 顺序执行一致；单样本在任一阶段抛异常时记录样本 ID、阶段名、业务码与异常类型并继续其余样本；每次完整运行输出 JSON 诊断报告，含逐样本判定结果、贡献分解、各命令响应耗时与是否超预算、复用与重算样本数、快照版本号、配置与资源包指纹及失败清单，报告以临时文件加原子替换方式写盘。
