当前是空白工作区，没有现存项目、代码或数据附件，需要从零构建一个面向 LLM 长上下文位置编码（RoPE 类旋转位置编码及其扩展变体，如位置插值、NTK 感知缩放、分块频率调整）的领域可视化与诊断工作台。业务对象是本地确定性生成的注意力打分任务清单（JSONL，字段含 case_id、seq_len、head_dim、num_heads、base_theta、pos_encoding_variant、pos_scale、block_size、causal、seed），以及由固定种子用 NumPy 生成的 Q/K/V 数组。工作台需按位置编码变体把查询与键的 token 位置映射为旋转角并对 Q/K 做旋转，再按分块完成打分与归一化，输出注意力输出与诊断数据。核心诉求是可复现验证与异常注入：同一 case 与配置必须逐字节可复现，位置尺度变化或分块变化必须能被诊断追踪，异常必须由输入或参数注入触发并可归因到具体阶段与 case；同时位置编码的累计角度、频率基准与缩放口径在跨变体时必须可核对，边界错误必须返回稳定的结构化业务码。

任务环境与准备：
安装 Python 3.11 并在虚拟环境中安装 NumPy，无需其他第三方依赖与外部服务。
确认工作目录为空工作区，创建本地样本生成脚本与缓存目录，样本由固定 seed 用 NumPy 生成，不依赖网络与真实账号。
在 Windows 上确认进程池可正常创建，并准备可触发的异常参数清单用于注入验证。

业务要求：
1. 实现确定性的旋转位置编码层：按 pos_encoding_variant、base_theta、pos_scale 为每个 token 位置计算逐维旋转角并对 Q/K 做旋转，整数维与半维配对口径显式固定；同一 case_id、同一配置与固定种子下必须逐字节产出相同的旋转角表、旋转后张量与注意力打分，禁止依赖系统时间、字典遍历顺序或未声明的全局状态。
2. 实现分块注意力打分与在线归一化路径，分块大小由 block_size 给出，causal 语义下禁止访问未来位置；分块路径的注意力输出须与不分块整段路径逐元素在声明容差内一致，并记录观测到的最大绝对偏差。
3. 实现四阶段异常注入框架：在位置角计算、Q/K 旋转、分块打分、归一化四个阶段分别提供由输入或参数触发的注入点（如 pos_scale 非正、head_dim 为奇数导致配对越界、block_size 超过 seq_len、causal 与掩码语义冲突），注入不得通过修改源码制造；每次注入须产生带阶段名、业务码与 case_id 的注入记录，注入后运行不得静默继续产生看似正常的结果。
4. 实现异常归因与降级链路：某阶段产出业务码时，下游阶段须按明确策略降级（如跳过旋转改用恒等位置、沿用上一分块的归一化统计量），降级结果必须携带降级类别与触发它的上游业务码；禁止静默吞掉异常，未被任何阶段归因的异常须汇总到结果报告的未归因列表，且注入与降级记录须可追溯到具体阶段与 case。
5. 实现位置编码变体的跨变体一致性裁决：同一 case 在相邻两种变体（如无缩放的经典 RoPE 与 pos_scale 指定的位置插值）之间，须按声明的映射关系核对旋转角与注意力打分是否满足预期关系，并输出偏差谱与所依据的变体映射说明；当配置声称等价但实测偏差超出容差时返回 E_VARIANT_MISMATCH 并指出首个偏差位置与变体名。
6. 实现数值精度与角度累计的稳定性保护：旋转角累计与分块归一的中间量以 float64 计算，对极大 seq_len 下的角度衰减提供可配置的次正规数保护与舍入模式，要求累计角度与理论角度在声明容差内可核对，并把越界情况返回 E_ANGLE_OVERFLOW；保护介入必须在诊断数据中标记。
7. 实现配置与输入校验链路及资源上限：重复 case_id、seq_len 与 Q/K 数组维度不符、head_dim 非正、base_theta 越界、dtype 不支持分别返回结构化业务码（如 E_DUP_CASE、E_SHAPE_INVALID、E_PARAM_INVALID、E_DTYPE_UNSUPPORTED）并指明字段；为单 case 序列长度、分块驻留内存估算与总比较次数设可配置上限，超限时返回 E_RESOURCE_LIMIT 或按明确策略降级并在结果中标记降级类别。
8. 实现交互式诊断工作台与可复现验证器：展示位置编码旋转角分布、分块注意力热图、四阶段注入记录与降级链路、跨变体偏差谱、资源消耗与最近业务错误码，支持用固定种子重跑并比对两次完整输出哈希一致；另需以独立验证器复核旋转角可重算、分块输出与整段输出一致、注入记录阶段与实际执行阶段吻合，检测到偏差返回 E_VERIFY_FAIL 并指出首个偏差位置与 case_id。
