这项需求没有既有代码，需要从零构建一个面向表格数据回归的梯度提升树集成领域组件与完整示例，核心业务问题是训练与推理链路的可复现验证以及异常注入下的归因诊断。业务对象是本地确定性生成的表格样本：由固定种子生成数值列与类别列特征矩阵及回归目标，另附训练配置（树数量、最大深度、学习率、行采样比例、列采样比例、叶节点最小样本数、分裂候选阈值数量、数值精度标记、随机种子）。建模链路为：特征分箱与分裂候选扫描→增益计算与分裂选择→叶权重求解→逐轮累加更新→预测与指标汇总。组件需对外暴露训练、预测、注入诊断与验证四个入口，任何被记录的结果都必须能由逐轮逐树的明细独立重算一致。

任务环境与准备：
安装 Python 3.11（Windows 64 位），确保 python 与 pip 在 PATH 中可用。
执行 pip install numpy==1.26.4 安装唯一第三方依赖，无需 GPU 与联网服务。
在空工作目录中新建子目录存放代码与本地样本，样本由固定种子在程序内生成，不提供外部数据文件。
确认本地可写入临时目录用于快照与缓存文件，运行前清理旧运行产物以避免跨次干扰。

业务要求：
1. 实现确定性的特征分箱与分裂候选扫描层：对每个数值列按候选阈值数量做分箱、对类别列按固定规则编码，输出分箱边界与逐特征候选阈值集合；同一输入、同一配置与固定种子下必须逐字节产出相同的分箱边界与候选集合，同分时按特征索引升序、再按阈值升序打破平局。
2. 实现增益计算与分裂选择层：对每个候选按配置的增益公式统计梯度与二阶导之和并计算增益，显著优于父节点增益才允许分裂，记录每次比较的两个候选与差值；须支持可配置的严格比较与容差带比较两种策略，保证恰好落在最小增益门限附近的候选在重复运行下判定不被舍入翻转。
3. 实现逐轮提升训练核心：按配置的树数量、最大深度、学习率与采样比例逐轮生成树并累加更新预测，行采样与列采样由固定种子驱动且采样序列显式可复现；同一输入与配置下逐轮损失、逐树结构与最终预测必须逐字节一致，并输出逐轮明细供独立复算。
4. 实现叶权重求解的数值稳定性策略：叶权重按负梯度之和与二阶导之和之商求解，对分母接近零的叶施加配置化下限保护，提供可切换的舍入模式与次正规数保护，保护介入与否须在逐轮报告中标记；保护阈值非法返回 E_CONFIG_INVALID 并指明字段与叶节点路径。
5. 实现逐级误差传播计算与主导来源归因：以同一输入上的 float64 全精度单轮参考实现为真值，输出量化档、增益计算、叶权重除法、学习率缩放与多轮加法累加各级的绝对偏差、相对偏差、误差区间与误差放大比，并定位主导误差来源级别；超出声明容差返回 E_TOLERANCE_EXCEEDED 并输出越界位置与偏差值。
6. 实现可复现验证器：用固定种子对同一输入与配置训练两次，比对逐轮损失、逐树结构与预测输出哈希一致，并校验各级处理的样本索引集合一致、每轮预测可由初始预测与各树贡献独立累加复算一致、误差归因可追溯至偏差明细；检测到偏差返回 E_INCONSISTENT 并指出首个偏差轮次与环节。
7. 实现四阶段异常注入框架：在分箱、增益计算、叶权重求解、预测四个阶段分别提供由输入或参数触发的注入点（如类别列取值越界、候选阈值重复、二阶导含非有限值、学习率为负），注入不得修改源码制造；每次注入须产生带阶段名、业务码与样本索引的记录，并沿异常链路传到输出。
8. 实现异常归因与降级链路：某阶段产出业务码时下游须按明确策略降级（如跳过该轮分裂沿用上一轮预测、回退到默认下限保护），降级结果必须携带降级类别与触发它的上游业务码；未被任何阶段归因的异常不得静默吞掉，须在最终报告的未归因清单中体现并返回对应业务码。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
