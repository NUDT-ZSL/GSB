在回合制战术游戏的决策辅助场景中，需要从零开发一个本地寻路与决策推演引擎，为棋盘格地形上的单位规划移动路径、估算行动代价，并以可交互的专业应用形式回放推演过程。地形由程序按确定性规则生成本地样本，包含不同地形成本系数与不可通行格。输入为本地 JSON 场景描述：地形网格与成本系数、单位起点终点、移动预算、寻路参数（启发函数权重、对角移动规则）、路径平滑参数、代价累计精度规格（定点标度与容差）、并发与内存预算上限，以及决策回放脚本。核心难点在于行动代价是沿路径逐格累加的浮点量：不同搜索顺序、启发权重与路径平滑都会改变累加次序，导致微小舍入误差沿路径传播并在预算边界判定上产生不同结论，引擎必须给出与规格严格一致的确定性代价与决策，并在交互应用中展示误差传播诊断。

任务环境与准备：
安装 Python 3.11 与 NumPy、PySide6，使用 pip 安装，不依赖网络服务与 GPU。
在工作区初始化项目目录，样本地形、单位清单与决策回放脚本由程序按确定性规则生成，无需外部附件。
确认 Windows 本地可运行交互应用与命令行入口，运行前清空并重建状态目录与输出目录。

业务要求：
1. 实现场景描述解析与输入校验：读取地形 JSON、单位清单与回放脚本，校验网格宽高为正整数、成本系数为有限正数、不可通行格坐标在网格范围内、起点终点可通行且不重叠、启发权重为有限非负数、定点标度与容差为正有限数，非法输入返回带 E_xxx 业务码的 JSON 错误且不产生任何回放产物。
2. 实现确定性代价累加与误差控制：按规格定点标度把地形成本量化为整数代价，沿路径按起点到终点的固定次序累加（不得因搜索数据结构遍历顺序变化），同时以 float64 逐格累加生成参考代价，记录两者每步差值并给出误差上界，使同一场景重复规划与不同启发权重下最终路径定点总代价完全一致、与参考代价差值不超过容差。
3. 实现带启发权重的确定性寻路：以地形代价为边权执行搜索，启发函数采用规格给定的距离度量与权重，当权重使启发超过可采纳阈值时须在报告中标注该次解可能非最优，并用规格规定的同一搜索在权重为 1 时求得的最优代价估算实际代价比，重复运行须得到逐格相同的路径与相同的展开计数。
4. 实现路径平滑与预算边界判定：按平滑参数对原始路径做确定性折线简化，平滑后路径须逐段重新核算可通行性与定代价，当总代价与移动预算之差的绝对值不超过容差时按规格规定的边界规则（倾向可达或倾向不可达由参数决定）给出唯一结论，判定须依据定点整数比较与容差而非单次浮点比较，结论与误差上界一并写入决策结果。
5. 实现决策回放脚本执行与一致状态：按回放脚本顺序应用移动、到达、预算耗尽等决策事件，逐步更新单位位置与剩余预算并产出逐决策状态快照；同一输入无论从头重放还是从中间快照继续，得到的决策序列、位置与剩余预算须逐字段一致，快照须记录由地形内容与场景参数规范化摘要构成的版本标识，标识不符则拒绝续放并从头重放。
6. 实现可交互专业应用与误差传播诊断：提供本地可交互界面，可加载场景、切换单位、逐步或连续回放决策，展示路径、逐格定点累计代价、float64 参考代价、误差上界与边界判定结论；诊断视图须定位误差首次超过指定阈值的路径位置，交互操作不得改变已记录的回放结果，界面关闭后自检须给出与命令行入口一致的回放产物摘要。
7. 实现并发场景预检与资源上限：按规格并发数用有界线程池对多个候选目标并行做可达性预检，同时在处理的地形成本缓冲总量受内存预算限制，结果按候选标识的固定归并顺序而非完成顺序汇总，任一预检失败时取消其余任务并返回首个错误，最终所选路径与串行预检结果逐字段相同。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地样本交互回放，核对路径代价误差上界、预算边界判定与中断恢复后的决策一致性。
