音频档案数字化工作室的修复工程师在把历史磁带与黑胶转录的单声道音乐录音送入降噪、去脉冲或母带重录流程之前，需要先判断这段录音究竟受到哪些劣化、严重到什么程度。问题在于削波平顶段会掩盖底噪估计，直流偏置让电平指标整体漂移，脉冲爆音又会在时域上扭曲局部包络；只用单一指标判定，容易把尚可轻度修复的录音误判为必须重新转录。工程师希望得到一份可逐段核对的评估结果：每种劣化各自的区间与分级、建议的修复流程，以及需要人工复核的临界指标，并能用录制清单里独立标注的受损区间与噪声底真值来验收。

任务环境与准备：
准备 Python 3 运行环境，并安装运行所需的 NumPy。
在仓库内放置确定性生成器脚本，按固定种子生成单声道音乐录音的 WAV 样本、受损区间与逐帧噪声底真值清单；样本总时长控制在分钟级，便于本机反复评估。
程序入口接收录音清单路径、帧长与帧移参数，输出帧级指标、受损区间、分级结果、建议流程与核对报告；运行过程只读取本地录音与清单文件，不访问网络。

业务要求：
1. 读取由确定性生成器按固定种子产出的单声道音乐录音清单，按声明的帧长与帧移分帧，逐帧计算峰值、平顶持续样本数、均值直流分量、低能量分位数噪声底与一阶差分能量突跳量；帧序列不得跨录音段拼接，帧长或帧移与采样率不能整除时，末帧按实际样本数计算并标记为不完整帧。
2. 依据逐帧平顶持续样本数与峰值占满量程比例判定削波，并区分硬削波与轻度限幅：平顶持续样本数超过给定下限且峰值比例达到硬削波阈值时标为硬削波，否则在较低峰值比例区间标为轻度限幅；将连续削波帧聚合为削波段，输出起止采样点、削波比例与类型。
3. 逐帧估计均值直流分量与噪声底电平，噪声底随乐音短时能量变化自适应更新，且更新只在非削波、非脉冲的帧上进行，避免削波平顶和爆音把底噪估计拉高；输出直流偏移段起止采样点与逐帧噪声底轨迹。
4. 用局部包络归一后的一阶差分能量突跳幅度与持续时间检测脉冲爆音，局部包络由爆音候选两侧的稳健统计量给出，避免将稳态高能量乐音误判为爆音；输出爆音起止采样点、峰值幅度与判定所用突跳幅度。
5. 按各类型指标值把削波、直流偏移、底噪与脉冲爆音分别分为轻、中、重三级，分级阈值不得互相覆盖，并汇总为录音级质量等级；再依据受损类型组合与分级映射到轻度降噪、去脉冲修复或母带重新转录三种建议流程，输出映射依据。
6. 生成按段落汇总的质量评估报告，列出每段的受损区间、类型标签、分级依据指标值与建议流程；对落在分级阈值临界带内的指标额外标记人工复核，并说明所触发的阈值条件；报告须可直接供修复工单引用。
7. 以生成器内嵌的各受损区间起止采样点与逐帧噪声底真值为独立依据，逐段核对削波、直流、底噪与爆音检测的区间边界偏差、误报漏报数与分级一致性，报告首个不一致段落及其帧级证据；真值缺失的录音段只报告检测结果并标注无法核对。
8. 对同一录音以两组合法帧长参数重复评估，核对受损区间起止采样点与分级结论在段级容许偏差内一致；不一致时输出两套参数各自的结果差异与建议复核段落，不得静默采用其中一套覆盖另一套。

验收：
对清单内各受损类型逐段核对区间、分级与建议流程，并验证自适应噪声底和双帧长结论稳定。
