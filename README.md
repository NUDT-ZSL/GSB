钟表机芯结构教学展具由三位制作人员协作完成：动画渲染员负责生成擒纵轮齿形、摆轮游丝螺旋、齿轮系齿廓与轴心圆孔等零件的连续灰阶示意图，展板编辑负责把它们排成单色教学看板，印前校对员负责在开印前判断网点效果是否可接受。当前的流程是把灰阶图直接阈值化，连续色调全部丢失，齿列与游丝的层次只剩黑白两截；改用规则网点后，齿轮的周期齿距又与网点周期相互干涉，在放大观察时出现明显龟纹，齿根与轴心边缘的细节被条带淹没。校对员还说不清某个零件上的条带究竟来自规则网点、齿形周期还是误差扩散的方向偏置，只能靠肉眼猜测返工。制作组需要一套在本机可重复运行的内核，把固定种子生成的示意灰度图与零件掩码作为输入，输出逐零件的半色调网点图、色调误差报告、条带与龟纹的定位判定和齿形细节保真核验，并对单个零件调整网点密度后做局部重算，使教学展板在近距离观看时呈现连续色调、放大观察时网点均匀且不掩盖齿廓。

任务环境与准备：
准备 Linux（WSL Ubuntu）环境与 Python 3 运行环境，并安装 NumPy 用于像素矩阵运算、灰度统计与频谱分析。
在工作区新建项目目录，放置程序入口与确定性钟表机芯示意灰度生成器；生成器按固定种子产出灰阶矩阵、零件掩码与重点细节区域标注，不读取任何外部图像。
准备样本清单与快照存储目录，用于保存不同打印线数与密度参数下的半色调网点图、误差报告与局部重算差异清单，供展板比对使用。

业务要求：
1. 读取确定性生成器按固定种子产出的钟表机芯连续灰阶图像与零件掩码，校验图像尺寸、灰阶位深、掩码标签集合与展板打印线数、墨点尺寸的一致性，按打印线数与墨点尺寸推导网点栅格间距与每零件可容纳的网点单元数，输出包含各零件灰度直方图、面积占比和网点栅格配置的解析清单，并对掩码缺失像素或标签越界给出明确的业务错误码。
2. 对每个像素按局部梯度幅值与方向自适应选择误差扩散核的权重分布，逐行量化后把量化残差按核权重精确分配给尚未处理的邻域像素，亮度方向的分配顺序与行扫描方向必须与核定义一致，保证全图量化残差总量与边界裁剪后的损失在允许范围内，输出半色调二值图像与逐像素累积误差记录。
3. 量化阈值叠加一个由像素坐标与固定种子共同确定的确定性抖动偏移，抖动幅度随零件掩码中标注的纹理类别变化，使平坦底纹不出现规则点阵、连续渐变的游丝区域保持平滑过渡，并在相同输入与种子下逐像素可复现。
4. 按零件掩码与展板打印线数计算每个零件的目标网点密度修正量，将修正量回灌到该零件的量化阈值偏移中，使齿形与轴心细节区域的实际网点疏密匹配标注要求，并输出逐零件修正前后的密度对照，避免修正量越界把某零件推向全黑或全白。
5. 以滑动窗口局部平均灰度与原始灰度图逐零件逐窗口比较，统计平均偏差、最大偏差与偏差超限窗口位置，判定各零件色调保真是否落在给定容差内，输出可复核的误差报告，报告需区分偏差来自核权重裁剪、掩码边界还是密度修正。
6. 对半色调结果逐零件做频谱峰值检测与方向性自相关分析，识别与齿形周期或网点周期相关的龟纹峰值及方向性条带所在的行列区间，将条带归因到规则网点干涉、齿形周期或误差扩散方向偏置中的具体来源，输出零件级均匀性判定与条带定位清单。
7. 在重点核验的齿形与轴心区域检查半色调网点的连通结构与齿廓边缘相对原始灰度的偏移量，统计齿根断裂、齿顶粘连与轴心圆孔闭合异常，输出细节保真核验结果，并保证在墨点尺寸变化时齿廓偏移的统计口径随之调整而不失真。
8. 支持对单个零件修改目标网点密度后仅重算该零件及其有效邻域，重算必须沿用重算边界外已固化的误差扩散状态，使未修改区域逐像素与全量重算一致、边界邻域的残差分配保持连续，并输出局部重算与全量重算的差异清单作为展板返工的判定依据。

验收：
逐零件半色调图、色调误差、条带归因与齿形保真均可与构造真值核对，单零件局部重算与全量重算在未改动区域逐像素一致。
