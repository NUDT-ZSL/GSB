这份任务书转交给新成员时，目录里只有一页关于分布漂移下重构误差校准的需求说明，尚未有可运行原型。目标是构建一个面向高维传感器数据的深度自编码器异常检测与阈值自适应系统，重点解决伪标签增量校准与异常分布漂移导致的阈值失效问题。业务对象由本地确定性脚本按固定种子生成：正常窗口来自多个时变正态分布流，并注入偶发尖峰、趋势变点与离群块作为异常；每个窗口附有重构误差基线、受污染标签以及与历史漂移事件对照的多版本阈值参数。检测链路包括窗口规范化与掩蔽补齐、欠完备自编码器重构、误差特征提取、分布漂移监测与阈值重校准，并输出窗口级异常分数、漂移归因与可回放诊断记录。系统须支持阈值模型 v1 扁平经验分位与 v2 分段分层分位两种格式互迁，能够处理批次追加、伪标签修正与漂移告警触发的局部重校准，并在强制终止后基于持久化快照恢复，交付为可集成库与完整示例。

任务环境与准备：
安装 Python 3.9 或更高版本，并安装 numpy。
提供固定种子生成样本窗口、阈值模型 v1/v2 与漂移事件记录的本地确定性脚本，脚本位于项目目录内。
确保工作目录可写，用于生成 SQLite 元数据库、快照文件与可回放诊断记录。

业务要求：
1. 实现确定性的样本窗口规范化与欠完备自编码器重构：对每个窗口按固定种子归一化并生成掩码，通过显式声明的权重矩阵逐层前向与反向得到重构窗口；同一输入、同一种子与同一配置下必须逐字节产出相同的重构误差与隐层激活。
2. 实现重构误差特征提取与可疑掩码联动阶段：从逐元素重构残差中提取均值、最大值、局部平滑残差与相邻掩码一致性四类特征，并对被掩蔽样本段按显式规则衰减贡献；任何掩码边界上的数值变化必须能追溯到具体窗口与维度。
3. 实现两代阈值模型的读取与互迁：v1 单文件 JSON 存储扁平经验分位，v2 分片 JSON 加 SQLite 按分段与层级组织分位；升级时补全分段分位默认粒度与校验和，降级时对 v2 中 v1 无法表达的分层条件按显式丢弃规则处理，并逐项记录迁移来源。
4. 实现伪标签增量校准与漂移失效传播：当新窗口被标记为异常或误报修正到达时，只对受影响分段重估分位并重算阈值带，未受影响的阈值分段与检测产物必须复用；阈值得出漂移告警时判定受影响时间窗与模块集合，输出重算与复用清单。
5. 实现基于重构误差的异常打分与分段阈值门限裁决：把重构误差特征与当前阈值带比较，输出窗口级异常分数与所属分段；门限比较须提供严格与容差带两种策略，保证重复运行及不同阈值模型视图下判定一致。
6. 实现调度计划、阈值参数、检测结果三类快照的版本化整体替换：每类快照携带单调递增版本号与内容校验和，检测到版本号或校验和变化时必须整体替换旧快照而非增量修补，回退尝试返回 E_SNAPSHOT_ROLLBACK。
7. 实现并发校准提交与算力预算准入机制：同一时刻只允许一个阈值校准提交生效，冲突后到者立即返回 E_STAGE_BUSY；对每个校准批次估计重构比较次数与驻留误差特征内存，超出预算时执行降级路径并记录裁决依据。
8. 实现强制终止后的恢复与结果可回放性：阶段快照在窗口批次边界原子落盘，重启时从最近已提交快照继续，已提交批次不得重算；每个异常判定须记录所用阈值模型版本与重校准路径，可按记录重放出相同判定结果。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
运行确定性样本验证重构、增量阈值校准与恢复后异常判定一致且可回放。

## 交付实现

本目录已包含可运行的 `drift_ae` 库、确定性生成脚本、完整示例和测试。实现说明见 `docs/ARCHITECTURE.md`，实际验证结果见 `docs/VALIDATION.md`。

完整示例：

```bash
python examples/end_to_end_demo.py --fresh
python examples/end_to_end_demo.py --fresh --state-dir artifacts/recovery-demo --crash-after 3
python examples/end_to_end_demo.py --state-dir artifacts/recovery-demo
python -m drift_ae replay artifacts/recovery-demo/diagnostics.jsonl
```

关键稳定性约定：

- 固定种子：`406`；样本为 96 个 `32 × 4` 高维传感器窗口。
- 错误码：并发冲突为 `E_STAGE_BUSY`，快照回退为 `E_SNAPSHOT_ROLLBACK`。
- 快照类型：`plan`、`threshold`、`result`，均带单调版本和 SHA-256 校验和并原子整体替换。
- 阈值格式：v1 为单文件扁平 JSON；v2 为分片 JSON + SQLite。
- 恢复边界：窗口批次提交后落盘；SIGKILL 后已提交批次只复用、不重算。
