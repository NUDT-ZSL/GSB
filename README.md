在空白工作区从零实现一个本地多集群配置分发控制面，用于在确定性样本上复现配置从全局基线到多集群目标的分发、参数换算与生效裁决链路，并专项处理其中的数值精度与误差传播问题。本地 JSON 样本给出：集群清单（集群名、区域、优先级、容量单位换算规则、是否允许差异覆盖）、分层配置模板（全局层、区域层、集群层各声明超时毫秒、重试倍率、采样率、副本权重、容量上限等数值参数），以及分发策略配置（换算定点标度、浮点容差、误差上界预算、每轮分发并发上限、重试预算、逻辑时钟步进）。控制面需把三层配置沿集群层级合并为每集群有效配置，计算派生量（最坏链路超时、有效容量、加权采样率），检测同一参数跨层不一致，并追踪浮点误差在层级合并中的传播，最终输出可复现的分发裁决报告。全部依赖本地确定性样本与本地 SQLite，不依赖任何真实集群或网络服务。

任务环境与准备：
安装 Python 3.10 或以上版本，确认标准库 sqlite3 与 json 可用。
安装 NumPy 1.24 或以上版本，用于定点换算向量化计算。
在空白工作区准备本地样本：集群清单、区域依赖、三层配置模板与逻辑时钟步进表，均为 JSON 文件。
确认工作目录可写，用于生成 SQLite 状态库与结果输出目录。

业务要求：
1. 实现集群清单与分层配置模板的解析校验：集群名与层级作用域唯一、区域引用闭合、数值参数类型合法、超时与容量为正整数、采样率与权重在合法区间、换算标度与容差为正；非法条目返回明确业务错误码且不写入任何持久化状态。
2. 实现统一换算为受控定点表示的能力：把超时毫秒、重试倍率、采样率、副本权重与容量上限各自按声明的定点标度换算，记录每项换算的标度、舍入方向与换算前原始浮点值，使相同输入多次换算逐位一致并保留误差溯源所需的原始值。
3. 实现三层配置沿集群层级合并为有效配置：按全局、区域、集群顺序覆盖同名参数，覆盖顺序与聚合顺序固定，使结果逐位可复现；每个生效参数须记录来源层级、被覆盖层级列表与合并路径，并区分被差异覆盖策略明确允许与不允许的覆盖。
4. 实现派生量计算与跨层一致性判定：沿集群层级与区域依赖计算最坏链路超时、有效容量与加权采样率，聚合顺序固定使结果可复现；同一参数在不同层的取值按定点换算后的容差裁决是否一致，不一致时输出涉及集群、层级、定值与容差余量。
5. 实现浮点误差传播检测与精度敏感标记：对每个派生量累计换算与运算误差上界，当两个集群或两个覆盖候选的派生量差值小于容差且分发裁决依赖该差值时标记为精度敏感，并输出误差来源链（参与层级、参数名与换算步骤），标记结论可复现。
6. 实现分发轮次的并行调度与预算裁决：同一轮次内按区域分组并发下发有效配置，同时受每轮并发上限与逻辑时间预算约束，预算耗尽须放弃剩余下发并记录放弃原因；已启动下发不得被截断为超时，须区分预算内未启动、启动后失败与主动放弃三类结局。
7. 实现持久化状态与强制终止后的恢复一致性：把分发轮次水位、每集群有效配置摘要、派生量、精度敏感记录与逻辑时钟水位以事务原子写入 SQLite，每轮提交识别版本变化并整体替换当前结果指针；进程被强制终止后只重算缺失部分，不得重复已完成计算或回退已提交轮次。
8. 实现多进程并发一致性与可重复命令行演示：多个控制面实例并行处理不同集群时，通过 SQLite 事务与文件锁保证同一集群同一轮次同一版本只提交一次、重复提交幂等，读取方只能看到完整已提交轮次；提供 load、distribute、explain、resume、status、verify 子命令，status 以稳定排序 JSON 输出各集群有效配置版本、精度敏感标记数与逻辑时钟水位，使用固定样本两次运行输出完全一致。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
