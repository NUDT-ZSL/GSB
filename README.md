# 回合制技能演出 · 音效落点检视卡工具

战斗策划在提交回合制技能演出前，用本工具按时间轴核对**音效落点是否踩中镜头节奏**。
读取本地技能清单 JSON，为每个技能产出一页 PNG 检视卡和一份汇总，标出音效与镜头关键帧的
贴合程度（精准 / 贴近 / 偏离）以及越界音效。样本由确定性代码生成，不含真实音频，全部本地运行。

## 环境要求

- Python 3.10 及以上（本机实测 3.10.20）
- Pillow 9.5（本机实测 9.5.0，安装在项目内 `.venv`）
- 无容器、无网络素材、无外部服务依赖

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install "Pillow==9.5.0"
# 运行测试时再装 pytest
.\.venv\Scripts\python.exe -m pip install pytest
```

## 启动说明

```powershell
# 1) 生成确定性样例清单（samples/ 下三个 JSON）
.\.venv\Scripts\python.exe scripts\generate_sample.py

# 2) 生成检视卡与汇总（输出目录可含空格/中文，不存在会自动创建）
.\.venv\Scripts\python.exe -I run.py `
    --manifest "samples\skills_manifest.json" `
    --out "输出 目录\检视卡"
```

- 推荐用根级启动器 `run.py`：在 `python -I` 隔离模式（防止当前目录被植入的 `json.py` 等
  模块劫持）下也能直接运行。
- 普通模式也可用模块方式：`python -m skill_cards --manifest ... --out ...`
- 退出码：成功 `0`；清单不可解析 / 顶层不是数组 / 文件不存在等整体拒绝场景为非零 `2`，
  且不创建输出目录、不产生任何文件。

## 清单格式

顶层必须是 JSON 数组，每个元素是一个技能对象：

```json
{
  "name": "烈焰斩",
  "duration_ms": 2000,
  "canvas": {"width": 1280, "height": 720},
  "camera_keyframes": [
    {"time_ms": 0,    "zoom": 1.0, "center": [640, 360]},
    {"time_ms": 800,  "zoom": 1.6, "center": [400, 300]},
    {"time_ms": 1600, "zoom": 1.2, "center": [700, 420]}
  ],
  "sounds": [
    400,
    {"t": 1200, "label": "爆裂音"},
    {"t": 2200, "label": "收尾误点音"}
  ]
}
```

- `sounds` 元素可以是纯数字时刻，也可以是 `{"t": 毫秒, "label": 名称}`。
- 技能名缺失/为空/全空白时，以清单位置序号 `#NN` 作为页名和文件名（序号本次输出内唯一）。
- 兼容带 UTF-8 BOM 的清单文件。

## 检视卡读图方式

每张 PNG 尺寸严格等于清单画布，自上而下：

1. **标题栏**：页名、总时长、画布、音效数、越界数。
2. **镜头缩放带**：蓝线为缩放随时间的线性插值，灰虚线为关键帧，三角为音效落点。
3. **中心点轨迹**：青线/紫线分别为中心点 x、y 的线性插值。
4. **音效落点时间轴**：灰菱形是关键帧（标注 KF 时刻），彩色三角是音效；
   右侧红框**越界区**用红色虚线三角标注超出 `[0, 总时长]` 的音效。
5. **音效明细表**：每个音效的时刻、该时刻映射出的缩放/中心点、与最近关键帧的毫秒间隔、
   贴合判定；越界音效相关计算列留空（`—`）并标红。
6. **图例**：贴合度三档配色与越界/关键帧说明。

贴合度按“音效时刻与最近关键帧的毫秒间隔”分档（阈值在 `skill_cards/model.py`）：

| 档位 | 条件 | 配色 |
|---|---|---|
| 精准 | 间隔 ≤ 50 ms | 绿 |
| 贴近 | 50 < 间隔 ≤ 150 ms | 橙 |
| 偏离 | 间隔 > 150 ms | 红 |
| 越界 | 时刻不在 `[0, duration_ms]` | 红，不参与贴合度计算 |

镜头插值规则：相邻关键帧之间缩放与中心点按时间**线性变化**；首帧之前、末帧之后
**保持最近帧的值**（钳制）。

## 输出物

- `NN_页名.png`：每技能一页检视卡，按页名（技能名）升序；页内音效按时刻升序。
- `summary.md`：汇总，含每个完成技能的音效总数/越界数与逐音效明细、跳过名单、
  未完成名单（原因随条目给出，两份名单不交叉）。内容无时间戳，重复运行逐字节一致。
- 重复运行会先清掉本工具生成的旧卡片（`NN_*.png`）并重写汇总，不残留上次条目；
  输出目录中的其他文件不会被删除。

## 目录结构

```
project97/
├─ run.py                       # 根级启动器（-I 隔离模式可用）
├─ skill_cards/
│  ├─ model.py                  # 数据结构、贴合阈值
│  ├─ camera.py                 # 线性插值、钳制、最近帧间隔、贴合分档
│  ├─ pipeline.py               # 清单校验、跳过/未完成分类、音效评估、排序

│  ├─ summary.py                # Markdown 汇总
│  └─ cli.py / __main__.py      # 命令行入口
├─ scripts/generate_sample.py   # 确定性样例生成
├─ samples/                     # 生成的样例清单（含两个非数组反例）
├─ tests/test_skill_cards.py    # 14 条 pytest，对应需求 (1)~(12)
└─ docs/运行记录.md              # 本机实际运行结果留档
```

## 需求对照

| 需求 | 实现位置 |
|---|---|
| (1) 逐技能出卡+汇总，缺陷项进跳过名单 | `pipeline.py` 结构校验、`summary.py` |
| (2) 帧间线性、首尾钳制 | `camera.py: camera_at` |
| (3) 越界标注且排除贴合度 | `pipeline.py` 音效评估、`render.py` 越界区 |
| (4) 时刻映射缩放/中心点+最近帧间隔，越界留空 | `camera.py`、`pipeline.py` |
| (5) 卡按名升序、音效按时刻升序、越界数一致 | `pipeline.py` 排序、`summary.py` 计数 |
| (6) 每技能一 PNG，尺寸=画布，越界可见 | `render.py: render_card` |
| (7) 时长/画布非正进未完成名单 | `pipeline.py` 值层校验 |
| (8) 汇总计数+两份名单不交叉+原因随行 | `pipeline.py`、`summary.py` |
| (9) 非数组/不可解析整体拒绝、非零退出、无产物 | `cli.py` |
| (10) 空格中文路径、不存在路径报错含路径 | `cli.py` |
| (11) 目录自动创建、重跑覆盖重写无残留 | `cli.py` 清理逻辑 |
| (12) 空名用唯一位置序号 | `pipeline.py: _page_name_for` |
