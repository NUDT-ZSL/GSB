当前是空白工作区，需要从零实现一个本地容器镜像分层构建与缓存管理组件，不依赖真实容器运行时与镜像仓库，以可集成的领域库加完整示例交付。本地样本提供两代构建清单：v1 为单文件 JSON，记录构建步骤序号、基础层引用、文件动作（新增/修改/删除）列表、环境变量与构建参数键值，以及一个扁平的步骤到层摘要映射；v2 为分片 JSON 加 SQLite 元数据库，记录层摘要的规范形式、分片内容哈希、绝对写入时刻毫秒戳、缓存代数、步骤缓存键与失效墓碑。组件需加载并合并两代构建清单，把每个步骤物化为内容寻址的层对象落盘，在存在 v1 与 v2 混合缓存时裁决某步骤能否复用旧层，并在构建中途被强制终止后恢复构建状态。核心矛盾是格式与版本兼容：v1 缺少缓存代数与绝对时间，只能以相对表示描述步骤优先级与写入先后，而 v2 以代数单调递增与绝对时间戳裁决新旧，两者的缓存在同一构建计划内必须给出同一个可复现的复用结论。

任务环境与准备：
确认 Windows 上可用 Python 3.11 或更高版本，并能在命令行调用 python 与 pip。
安装运行依赖：pytest 用于本地样本验证，SQLite 使用 Python 标准库 sqlite3，无需额外数据库服务。
在空白工作区准备 samples 目录，放入固定的 v1 单文件构建清单、v2 分片清单与 SQLite 元数据库样本，以及构建步骤用到的初始文件树。
确认工作区可读写本地文件系统并支持临时文件重命名，演示脚本与命令行入口均在工作区内运行。

业务要求：
1. 实现 v1 与 v2 两代构建清单的解析与校验：v1 校验步骤序号唯一且连续、基础层引用可解析、文件动作路径不越出工作区根、构建参数为字符串键值、扁平映射条目与步骤声明一致；v2 校验分片文件哈希、SQLite 元数据中的缓存代数单调、绝对写入时刻为整数毫秒、步骤缓存键格式合法、失效墓碑与步骤状态对应；非法清单必须返回不同业务错误码且不写入任何持久化状态。
2. 实现步骤的确定性物化与内容寻址落盘：按顺序应用文件新增、修改、删除动作生成每层 diff 元数据，层摘要按确定性规则计算，层对象以临时文件加重命名原子写入本地对象目录，相同内容重复物化必须得到同一摘要且不产生重复副本；层清单按步骤序号输出，包含摘要、字节大小与父层摘要，使任意层都能通过父层引用回溯到基础层。
3. 实现跨版本步骤缓存的合并与复用裁决：同一构建步骤在 v1 与 v2 缓存中同时存在时，依据清单声明的逻辑时钟与缓存代数裁决最新缓存条目，逻辑时钟相同则按来源格式优先级；v1 的相对表示须在注入逻辑时钟下换算为可比较的写入次序并记录换算标度与舍入方向；合并后每个缓存条目必须保留来源版本、原始表示与裁决依据，无法裁决时必须返回明确业务错误码而不是静默取其一。
4. 实现构建参数变化引发的缓存失效闭包：以步骤内容摘要、解析后的构建参数与父层摘要作为缓存键，构建参数或环境变量变化必须使该步骤及其全部下游步骤缓存失效，而未受影响的上游步骤缓存必须复用且物化结果逐字节不变；失效决策须输出触发来源、受影响步骤集合与被跳过的复用原因，便于诊断一次构建中哪些层是复用、哪些是重建。
5. 实现构建中断后的状态演进与恢复：把步骤阶段、已提交层摘要、缓存条目版本、逻辑时钟水位与未完成写入登记以事务原子写入 SQLite，每批提交识别版本变化并整体替换当前构建快照指针；进程在物化或缓存提交中途被强制终止后，恢复路径依据持久化状态识别已提交层与半写入临时对象，只清理无引用临时对象并继续未完成步骤，不得承诺强制终止后一定生成退出报告。
6. 实现多进程并发一致性与幂等构建：允许多个构建实例并行处理同一构建计划的不同步骤，通过 SQLite 事务与文件锁保证同一步骤同一父层摘要只被物化一次、同一缓存键只被提交一次，重复提交相同步骤结果必须幂等；读取方只能看到完整已提交的层清单与缓存条目，不得观察到父层未落盘却被引用的中间状态。
7. 实现层对象与缓存条目的引用计数与垃圾回收：对象与缓存条目按被哪些层、哪些构建快照引用的计数标识，恢复或重建后只回收零引用对象，仍被任何已提交层清单引用的对象绝不被删除；回收须与构建快照指针版本绑定，避免回收正在进行裁决的层，回收数量与保留原因须可在状态查询中审计。
8. 提供可重复的命令行接口与演示：支持 load、build、judge、resume、status、verify 子命令；judge 以稳定排序 JSON 输出每个步骤的复用结论、来源版本、换算标度与触发原因；status 输出每层摘要、缓存命中情况与回收数量；verify 校验持久化状态、对象目录与层清单的一致性；使用固定本地样本连续执行两次完整构建，第二次除耗时类字段外输出必须逐字一致。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用固定本地样本验证跨版本缓存复用裁决、参数失效闭包、并发幂等与中断恢复，两次构建输出一致。
