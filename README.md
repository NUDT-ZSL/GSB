# 播客双轨单声道剪辑合成工具

把主机位、嘉宾位两段单声道 16-bit PCM WAV（共享同一时间轴）按 CSV 剪辑清单
裁掉静音/口误区间，按时间对齐合成为一条单轨成片，并输出 UTF-8 处理报告。

- 仅使用 Python 3.10+ 标准库（`wave`、`csv`、`array`、`argparse` 等），无第三方依赖、无需网络。
- 全程不修改源 WAV 与 CSV；成片与报告都是独立新文件。
- 同一份输入重复运行，成片与报告逐字节一致（确定性可复现）。

## 1. 环境要求

- Windows + Python 3.10 及以上，命令行 `python` 可用（已在 3.10.20 验证）。
- 不使用 Docker 或其他容器。
- 建议用 `python -I` 运行（隔离模式，避免当前目录同名模块干扰）。

## 2. 文件说明

| 文件 | 作用 |
| --- | --- |
| `podcast_editor.py` | 主程序：校验输入、解析清单、合并区间、双轨对齐合成、写成片与报告 |
| `make_samples.py` | 确定性生成演示用双轨 WAV 与剪辑清单（标准库 wave） |
| `run_tests.py` | 15 条验收要求的自动化测试，现场生成全部边界夹具 |
| `verify_output.py` | 用标准 `wave` 模块独立打开成片并打印封装字段 |
| `demo/` | 演示输入与输出目录（运行生成器后出现） |

## 3. 快速开始（可复现演示）

```powershell
# 1) 生成确定性样本（8000Hz、单声道、16-bit、每轨 8000 帧 / 1.000 秒）
python -I make_samples.py demo

# 2) 执行剪辑合成
python -I podcast_editor.py `
  --host   demo/host_demo.wav `
  --guest  demo/guest_demo.wav `
  --csv    demo/edits_demo.csv `
  --output demo/output_demo.wav `
  --report demo/report_demo.txt

# 3) 独立校验成片封装字段
python -I verify_output.py

# 4) 运行全部 15 项验收测试
python -I run_tests.py
```

## 4. 命令行参数

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `--host` | 是 | 主机位 WAV 路径 |
| `--guest` | 否 | 嘉宾位 WAV 路径；缺失时清单中的嘉宾位行会被拒，主机位仍可独立成片 |
| `--csv` | 是 | 剪辑清单 CSV 路径 |
| `--output` | 是 | 成片 WAV 输出路径（不得与任何源文件同路径） |
| `--report` | 是 | UTF-8 处理报告输出路径 |

缺少任一必填参数时，`argparse` 打印用法并以退出码 `2` 退出，且不创建任何文件。

退出码约定：

- `0`：正常结束（含“清单全部无效、仅输出报告”的空结果情况）。
- `1`：输入违反硬性约束（采样率不一致、WAV 非单声道/非 16 位、文件无法读取），不产出成片。
- `2`：命令行用法错误/参数缺失。

## 5. 剪辑清单 CSV 格式

每行三个字段：`track,start,end`

- `track`：仅允许约定取值 `主机位`/`host`、`嘉宾位`/`guest`；其他名字（如 `other`）整行拒绝。
- `start`、`end`：区间起止时间，单位秒，区间为左闭右开 `[start, end)`，表示“要裁掉”的内容。
- 首行若为表头 `track,start,end`（大小写不敏感）自动跳过。
- 空行（含纯空白行）直接跳过，不计入拒绝列表。
- 秒转帧规则：起点 `floor(秒 × 采样率)`、终点 `ceil(秒 × 采样率)`，保证请求覆盖的采样帧全部被裁。

非法行不会中断整体处理，而是记录**物理行号 + 中文原因**进入报告拒绝列表：
字段数不对、数值非法、未知轨道、引用缺失轨道、起止倒置、终点越界等。

## 6. 核心处理规则

1. **采样率校验**：两轨采样率必须完全一致，否则整体拒绝（退出码 1）。
2. **格式校验**：仅接受单声道、16-bit、未压缩 PCM WAV，否则整体拒绝。
3. **区间合并**：同一轨道上重叠或首尾相接的裁剪区间先合并，重叠部分只处理一次。
4. **双轨对齐合成（主机位优先）**：按共同时间轴逐帧扫描——
   - 主机位保留则取主机位；
   - 主机位被裁、嘉宾位保留则取嘉宾位；
   - 两轨同刻都被裁则该帧不进入成片。
   因此任一瞬间只取一轨音频；两轨同刻有内容时成片与主机位逐样本一致。
5. **无算术溢出**：合成只搬运已有样本、不做加减运算，16-bit 样本（-32768..32767）
   不会溢出或回绕；满幅样本在拼接边界仍保持原值。
6. **空结果**：清单无任何有效请求、或合法裁剪覆盖全部音频时，不生成成片，仅输出报告。

## 7. 处理报告（UTF-8）

报告包含：输入文件与采样参数、空行数/合法行数/被拒行数、
按行号**单调递增**的拒绝明细、各轨合并后的裁剪区间与帧数、
成片总时长与有效片段数（或明确的空结果说明）。
报告不写入输出路径，保证同输入重复运行时报告逐字节一致。

## 8. 15 条验收要求与测试对照

`python -I run_tests.py` 全部通过（15/15）。测试在临时目录现场构造夹具，
覆盖采样率不一致、双声道/8 位 WAV、空行、缺字段、倒置、越界、重叠合并、
主机位优先、满幅拼接、缺失轨道、全无效清单、重复运行哈希一致、缺参数用法等。

| 要求 | 测试函数 | 关键断言 |
| --- | --- | --- |
| 1 采样率不一致拒绝 | `t01` | 退出码 1、中文说明、无成片 |
| 2 空行跳过/字段校验 | `t02` | 报告标物理行号，合法行仍裁剪 |
| 3 倒置/越界拒绝 | `t03` | 被拒行可查，成片不受影响 |
| 4 重叠区间合并 | `t04` | 合并为 1 段，帧数与保留段一致、无重复 |
| 5 对齐与主机位优先 | `t05` | 逐段样本等于预期轨，同刻取主机位 |
| 6 成片 WAV 合规 | `t06` | 单声道/16 位/共同采样率，wave 可重开 |
| 7 源文件不变 | `t07` | 源文件前后 SHA256 相同，成片独立路径 |
| 8 全无效空结果 | `t08` | 无成片、仅报告、明确空结果提示 |
| 9 报告行号与统计 | `t09` | 拒绝行号单调递增，统计与成片一致 |
| 10 重复运行一致 | `t10` | 两次成片与报告哈希完全相同 |
| 11 未知轨道拒绝 | `t11` | `other` 入拒绝列表，合法行不受影响 |
| 12 满幅无溢出 | `t12` | 全部样本 ∈ [-32768, 32767]，边界不回绕 |
| 13 非单声道/非16位拒绝 | `t13` | 双声道与 8 位均退出码 1、无成片 |
| 14 引用缺失轨道 | `t14` | 嘉宾位行被拒，主机位独立成片 |
| 15 CLI 用法 | `t15` | 无参数打印用法、退出码非 0、不建文件 |

## 9. 典型业务操作样例

正常合成（控制台回显）：

```text
[完成] 成片 8000 帧（1.000 秒） -> demo/output_demo.wav
[报告] demo/report_demo.txt；被拒请求 4 行。
```

报告拒绝列表示例（行号升序）：

```text
【被拒请求（按行号升序）】
- 第 7 行：区间倒置或为空：起点 0.5s 不小于终点 0.4s
- 第 8 行：未知轨道名“other”，仅允许约定取值：主机位/host、嘉宾位/guest
- 第 9 行：区间终点越界：第 12000 帧超出主机位总时长 8000 帧
- 第 10 行：字段数为 2，要求恰好 3 个字段（track,start,end）
```

采样率不匹配（硬性拒绝，退出码 1）：

```text
[拒绝] 两轨采样率不匹配，无法按同一时间轴对齐：主机位 8000 Hz（h8k.wav）；嘉宾位 16000 Hz（g16k.wav）。请先重采样为一致采样率后再处理。
```
