这套工作区还没有任何既有实现，需要在 Linux（WSL Ubuntu）环境下从零构建一个面向生成式图像编辑的本地可交互诊断工作台。业务对象由固定种子脚本确定性生成：编辑任务清单为 JSONL，每行含 edit_id、image_seed、image_shape、mask（修复区域多边形坐标）、prompt（受控词表拼装）、style_strength、iterations、block_size、dtype_profile、revision。图像由固定种子驱动生成 RGB 像素数组，文本条件向量由词频加权池化得到。编辑链路建模为五阶段有向无环图：掩码区域解析与边界上下文采样、区域内容确定性补全、风格迁移着色、边界融合与全图输出、指标聚合。核心矛盾在于区域分块编辑能加速首块可查询，但块边界处的采样权重、颜色迁移统计量与融合羽化权重必须与整幅一次编辑完全同源；同时并行调度下资源预算、编辑参数修订、强制中断恢复与误差传播需要联合诊断。全部输入由本地确定性脚本生成，不依赖真实模型、外部服务或网络。

任务环境与准备：
Linux（WSL Ubuntu）环境，Python 3.10 及以上
安装依赖：pip install numpy
随题目附送固定种子样本生成脚本 gen_samples.py，运行 python gen_samples.py --seed 0 --case_range 0 50 生成本地 JSONL 样本与参数 JSON

业务要求：
1. 实现确定性的图像生成与掩码区域解析阶段：按 image_seed 与声明形状生成 RGB 像素数组，解析修复掩码多边形为封闭区域集合，输出每区域边界像素坐标及相邻上下文，同一 image_seed 与配置下必须逐字节产出相同图像与区域边界，多边形的重复边、自交或越出画布分别返回 E_MASK_DEGENERATE、E_MASK_INTERSECT、E_MASK_OUT_OF_BOUNDS。
2. 实现区域内容确定性补全与风格迁移着色阶段：补全器基于边界上下文对掩码内像素做显式推进填充，着色器按 style_strength 与颜色迁移矩阵对补全结果做风格化，逐像素记录补全来源与颜色映射贡献，同一 edit_id 与同一 style_strength 下补全与着色必须严格可复现，style_strength 越界或迁移矩阵非法分别返回 E_STYLE_INVALID、E_TRANSFORM_INVALID。
3. 实现分块编辑与整幅一次编辑的双路径对照：按 block_size 把修复区域切分成分块执行补全与着色，每块的边界采样权重、颜色归一化统计量与边界残差处理必须与整幅一次编辑采用同一来源与同一归一化系数，逐块拼接结果与整幅结果在 float64 下逐像素一致，任何一处像素差异返回 E_BLOCK_MISMATCH 并输出首个差异坐标与两路径像素值，禁止用局部重算近似掩盖全局不一致。
4. 实现可切换数值精度档与逐级误差传播诊断：float64、float32 与定点缩放整数三档共用同一算子语义，定点档 quant_scale 与 rounding_mode 由任务显式给出；以同输入的 float64 整幅路径为参考真值，输出边界采样、分块补全、风格着色、定点量化、边界融合各级的绝对偏差、相对偏差与误差放大比，并定位主导误差来源级别；该诊断结果必须可由各级明细独立重算一致，且精度切换只能引入数值差异，不得改变区域集合或处理顺序。
5. 实现多编辑任务并行调度与资源预算准入：按可配置 worker 数和每批任务数把编辑任务分派到本地进程池，分块边界、任务派发顺序与归并顺序必须确定性可复现；为每个任务估算驻留像素内存、边界上下文缓冲和分块中间结果内存，在总驻留内存预算与单任务并发块数上限内决定准入集合，超限任务返回 E_MEMORY_BUDGET 或 E_BLOCK_CONCURRENCY，被拒绝任务不得产生部分已提交输出。
6. 实现预算冲突的显式裁决与降级路径：当扩大 block_size 减小分块数但逼近单块内存上限、提高 worker 数缩短整体耗时但放大总驻留内存、收紧分块边界校验强度减少计算开销但增加边界融合不一致风险时，按配置声明的优先级顺序在编辑质量、内存占用与进度之间裁决，输出裁决依据和受影响任务集合；降级到更小分块或串行路径时须在结果账本中标记降级类别，且降级后的拼接一致性要求不得放宽。
7. 实现编辑参数修订后的定向失效传播与缓存管理：每个阶段产物按内容哈希落盘，缓存键纳入输入图像哈希、掩码摘要、style_strength、iterations、block_size、dtype_profile、revision 与上游产物哈希；当某任务 revision 提升且仅 style_strength 变化时只重算着色、融合与指标以及该任务的分块下游，仅 mask 变化时重算该任务全部编辑阶段，未受影响任务的已提交结果必须复用；过期结果来自旧缓存键时返回 E_STALE_RESULT 并指出 edit_id 与过期字段。
8. 实现阶段检查点强制中断恢复与跨模块一致性自检，并生成可重放诊断报告：在五阶段边界及批次边界提交带单调递增版本号、已完成 edit_id 集合与内容校验和的检查点，强制终止后重启从最近已提交检查点继续，已提交阶段不得重算；自检校验分块结果与整幅参考一致、预算账本与调度记录互相可核对、重算与复用集合无交集且并集覆盖全部受影响任务，按 edit_id 查询诊断信息可与账本独立重放出一致结果；提供命令行入口输出 JSON 报告，包含分块偏差谱、精度档偏差、预算裁决记录、业务码与快照版本。
