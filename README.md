音频素材组要为游戏音频库与版权比对搭建一套本地检索工具，迁移方案刚刚定稿，工作目录仍为空，需要按新方案独立实现而不沿用旧工具的任何代码。业务对象是由随工程交付的固定种子脚本确定性生成的本地 WAV 样本：参考曲目与待检曲目均为 16bit 单声道，采样率取自 16kHz、44.1kHz、48kHz，样本中可包含变速、增益偏移、局部插入与背景噪声，并附一个 JSON 检索任务描述声明参考与待检文件清单、指纹参数（帧长、帧移、频带边界、峰值邻域、每帧峰值数）、检索参数（投票窗口、最小匹配数、得分容差、时间偏移容差、定点标度）、并发上限、在途频谱缓冲内存预算与状态目录。检索链路为分帧频谱与峰值指纹提取、指纹索引与匹配投票、候选片段聚合与时间偏移估计、边界细化与重叠消解，指纹与排序得分须在定点口径下参与判定并保留 float64 参考路径用于误差诊断。难点在于同类素材反复到达时只能重算受影响的指纹段与候选片段，并行调度与内存预算又不能改变最终排序和片段边界。

任务环境与准备：
Windows 本机安装 Python 3.11 或 3.12，使用标准库 sqlite3 与本机安装的 NumPy（例如 python -m pip install numpy），不需要外部音频库、网络或真实站点。
在空工作目录中准备随工程交付的固定种子样本生成脚本，按任务描述生成参考与待检 WAV、检索任务 JSON 与状态目录，生成结果可重复且样本文件不进入版本控制。

业务要求：
1. 实现检索任务描述与各 WAV 文件头解析校验：采样率属于允许集合、位深为 16、声道数为 1、帧长与帧移为正整数且帧移不大于帧长、频带边界严格递增且不越过奈奎斯特频率、每帧峰值数与定点标度为正整数、得分容差与时间偏移容差为非负有限数、并发上限与内存预算为正整数；非法输入返回带 E_xxx 业务码的 JSON 错误且不产生索引与报告。
2. 实现逐帧频谱与峰值指纹提取：按帧长与帧移分帧加窗后计算频谱，按频带划分与峰值邻域规格选出频谱峰值，生成以频带与帧间差为键的指纹项；帧起止采样点与源文件严格对应，变速输入的帧边界换算规则单一确定，同一曲目在任意分帧并发度下产出的指纹项集合与顺序完全相同。
3. 实现浮点参考与定点累计的得分对照：指纹匹配得分按哈希碰撞投票累计，得分同时保留 float64 参考值与定点标度下的整数值，逐次匹配记录两者差值并标出首次超过得分容差的位置；最终排名与最小匹配数判定只依据定点结果，浮点路径仅用于诊断，报告须给出定点与参考排序不一致的候选片段。
4. 实现候选片段检索与时间偏移估计：按投票窗口与最小匹配数聚合候选片段，估计待检片段相对参考片段的时间偏移，并同时给出整数帧偏移与以采样点表示的浮点参考偏移，二者换算差不得超过时间偏移容差；未被参考曲目在任何偏移覆盖到的待检只输出带业务码的说明。
5. 实现相似片段边界细化与重叠消解：按相邻帧匹配密度细化起止边界，片段在两条时间轴上均以整数采样点表示且不越界；多个候选片段重叠时按规格规则消解，消解结果须与逐候选串行处理一致，并保证同一片段不会被重复计入报告。
6. 实现增量失效与受控重算：为每段指纹记录其依赖的帧区间、频带边界与峰值邻域参数，待检曲目追加或指纹参数版本变化时只重算受影响的帧区间与候选片段，复用已持久化且摘要有效的段结果；增量检索结果与同输入从头全量检索在片段边界、偏移与定点得分上一致，报告须逐条列出受影响帧区间与失效理由。
7. 实现分块级持久化与中断恢复：按帧区间分块把指纹项、候选片段中间量与由音频内容及参数规范化摘要构成的版本标识原子写入状态目录，先写同目录临时文件再整体替换，替换前比对已有分块版本标识，标识变化时不得直接覆盖；可处理终止信号只在分块边界生效并写入中断标记后以约定整数退出码退出，强制终止后重启仅依据摘要有效的分块恢复且不承诺生成退出报告。
8. 实现并发检索与双资源上限：按并发上限使用有界线程池并行处理待检曲目的分帧频谱计算，同时在途频谱缓冲帧数与指纹中间量总量不得超过内存预算，超出预算时按曲目清单声明顺序让部分曲目等待而非降低帧长或频带精度；任一曲目异常时取消其余待处理任务并返回首个错误，报告与检索片段导出先写同目录临时文件再整体替换。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
