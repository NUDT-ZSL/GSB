一个刚启动的音频质检项目需要交付首个可运行组件，当前工作区没有代码和样本，仅有任务说明。业务对象是本地固定种子生成的 16kHz 单声道 PCM 与量化配置，PCM 由若干稳态语音段、间歇静音和增益跳变点组成，量化配置以 v1 扁平表和 v2 分片 JSON 两代格式并存，用于控制能量门限和小波子带阈值。系统需要按分块方式估计语音能量包络，把覆盖同一时间轴的两代量化门限互迁后对齐到统一时间基准，检测包络漂移并按可回溯方式输出业务码。全部输入由本地确定性脚本生成，不依赖外部网络或真实音频。

任务环境与准备：
安装 Python 3.10 或更高版本。
安装 NumPy 1.24 或更高版本，使用 pip install numpy。
提供固定种子样本生成脚本，用于本地确定性生成 16kHz 单声道 PCM 与量化配置 JSON。

业务要求：
1. 实现确定性的分块能量包络估计，按配置帧长与帧移切分 16kHz 单声道 PCM，帧边界以样本索引精确确定，每块独立计算短时能量与小波子带统计量并输出包络节段，同一输入、同一种子与配置下包络值、块边界和统计量逐字节一致，且不得依赖系统时钟或字典序。
2. 实现 v1 扁平量化门限与 v2 分片量化门限的读取器，按版本头或字段集分派解析路径，未知版本返回 E_VERSION_UNSUPPORTED，字段缺失、数值不可解析或时间轴重叠分别返回 E_FORMAT_CORRUPT 与 E_TIMELINE_OVERLAP，并输出归一化后的统一门限曲线。
3. 实现两代量化门限的双向互迁与对齐，v1 升级到 v2 时补充分量子带阈值与应用分段默认值并逐项记录补全来源，v2 降级到 v1 时对无法表达的嵌套子带结构按显式规则展平或丢弃，迁移后新旧门限必须在每个对齐窗口内产生一致的能量包络判定。
4. 实现包络漂移检测与子带来源裁决，当任一分块包络统计量的分布相较前一版本门限曲线超过容差时记录漂移事件，并定位到贡献最大的小波子带与能量段，裁决结果在 float64 和定点缩放整数双精度档下保持一致的漂移定性，漂移记录可追溯到具体 PCM 样本区间。
5. 实现基于内容寻址的分块缓存与版本化整体替换，缓存键纳入 PCM 内容哈希、量化门限版本、帧长帧移与上游包络哈希，键相同复用、键不同重算；当门限曲线或音频修订变化时整体替换旧快照而非增量修补，并输出受影响分块清单与重算范围。
6. 实现四阶段状态机与强制终止恢复，包络估计、门限互迁对齐、漂移裁决、报表导出四阶段各产生带递增版本号与内容校验和的快照，只有该阶段全部样本处理完才原子提交；重启后从最近已提交快照继续，已提交分块不得重算，未提交的中间包络与裁决状态丢弃并从阶段起点重建。
7. 实现并发提交控制与资源预算，同一时刻只允许一个门限快照或漂移裁决提交生效，冲突时后到者返回 E_STAGE_BUSY 不阻塞；为驻留包络统计量、缓存条目和并行处理分块设置可配置上限，超限时按优先级返回 E_MEMORY_BUDGET 或 E_RESOURCE_LIMIT 并降级为串行处理。
8. 实现跨模块一致性自检与追回放，最终漂移报表中每条事件记录其包络块、门限版本与预计算哈希，可依据记录重放出相同漂移类别与样本区间，自检确保分块串行处理与整段一次性处理的漂移判定和业务码一致；发现差异返回 E_INCONSISTENT 并输出首个偏差位置。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
用本地确定性样本验证两代量化门限互迁、包络漂移检测与强制终止恢复结果同一次性处理一致，并给出可回溯业务码。
