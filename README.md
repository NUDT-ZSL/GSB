在一台没有历史代码的机器上，需要从零实现一个本地训练数据管线及其结果验证工具，用于在确定性样本上复现从原始样本分片生成、内容寻址缓存、并行预取到 batch 组装的完整链路，并让每一次异常注入都能被复现与定位。本地 JSON 样本给出：数据集清单（数据集名、样本总数、特征维度、单样本字节数估计、分片大小、分片生成参数与全局种子）、分片缓存视图（已缓存分片集合、每分片字节大小、缓存代数、最近使用逻辑时钟）、训练作业描述（作业名、batch 大小、数据并行度、每 worker 预取深度、epoch 数）、逻辑时钟步进表，以及一份受控注入清单（在生成、缓存、预取、组装四个阶段注入指定异常）。管线须在全局内存预算 MiB 与每轮逻辑时间预算的双重约束下调度分片生成与预取，缓存命中复用，未命中回源生成，最终组装出无重复无缺漏的 batch 序列，并输出可逐项核对的验证报告。所有时间判定只依赖注入的逻辑时钟毫秒值，不读取系统墙钟。

任务环境与准备：
安装 Python 3.11（含标准库 sqlite3），执行 python -m pip install --upgrade numpy；无需网络服务、GPU 或外部数据集。
在本地工作区新建项目目录，准备样本 JSON：数据集清单、分片缓存视图、训练作业描述、逻辑时钟步进表与注入清单，全部为本地确定性文件。
确认当前用户对工作区目录有读写权限，以便分片缓存文件、SQLite 状态库与临时文件可原子落盘与重命名。
运行前无需启动服务；若脚本以多进程方式执行，确保 Windows 下以 python 主模块保护方式启动子进程。

业务要求：
1. 实现数据集清单、分片缓存视图、训练作业描述与注入清单的解析校验：数据集名与作业名唯一，样本总数、特征维度、分片大小为正整数且分片大小能整除样本总数，数据并行度与每 worker 预取深度为正整数，缓存代数单调，注入条目引用的阶段与目标存在，分片声明字节大小与摘要一致；非法输入必须返回明确业务错误码且不写入任何持久状态。
2. 实现分片内容寻址生成与确定性样本切分：按数据集名、分片序号、全局种子与分片生成参数确定性派生每分片的样本摘要与字节大小，相同输入重复生成必须得到逐位一致的分片清单；分片到训练样本的切分边界固定，使任意 worker 读取任意分片得到的样本内容只由 (数据集名, 分片序号, 样本序号) 决定，不受预取顺序影响。
3. 实现缓存命中裁决与回源生成的增量失效：以数据集名、分片序号、缓存代数与分片生成参数构成缓存键判定命中，命中直接复用缓存分片，未命中回源生成后写入缓存并原子登记；分片生成参数或数据集内容版本变化必须使受影响分片缓存精确失效、未受影响分片继续命中，并输出失效触发来源与被失效分片清单。
4. 实现并行预取调度与内存预算裁决：同一轮次内按数据集分组并发调度分片生成与预取，同时受全局内存预算 MiB 与每数据集并发预取上限双重约束，每候选分片先按字节估计占用并与剩余预算比较；预算不足时必须放弃剩余未启动分片并记录放弃原因，严格区分预算内未启动、启动后失败与主动放弃三类结局，已启动分片必须执行完毕。
5. 实现基于注入逻辑时钟的预取轮次推进与超时语义：分片生成耗时、预取提前量、每轮逻辑时间预算判定只依赖注入的逻辑时钟毫秒值，不读取系统墙钟；超时须由逻辑时钟推进与真实等待共同判定而非事后标注，超时须与主动放弃、执行失败使用不同业务错误码，且超时不得伪装为已完成。
6. 实现 batch 组装顺序一致性与跨 worker 无重复校验：按固定规则把各 worker 所需分片组装为 batch，batch 内样本顺序与 worker 间分片分配必须稳定且不重叠，同一 epoch 内每个样本恰好出现一次；同时以单进程串行生成与组装作为唯一真值来源，两条路径逐 batch 逐样本比对，不一致须输出首个分歧批次、样本位置与两条路径的分片来源。
7. 实现持久化状态与强制终止后的恢复一致性：把预取轮次水位、已提交分片清单、缓存条目版本、内存占用账目、batch 组装水位与逻辑时钟水位以事务原子写入 SQLite，每轮提交识别版本变化并整体替换当前调度快照指针；进程在分片生成、缓存提交或 batch 组装中途被强制终止后，恢复路径识别已提交分片与半提交账目，只重放缺失分片且不得重复计入内存占用或缓存条目，恢复后的 batch 序列与不中断运行逐样本一致。
8. 实现多进程并发一致性、幂等提交、注入异常隔离与可重复命令行验证：多个调度实例并行处理不同数据集时，通过 SQLite 事务与文件锁保证同一分片同一缓存代数只被生成提交一次、同一 batch 摘要只被记录一次，重复提交相同分片或相同 batch 结果幂等，读取方只能看到完整已提交轮次；生成摘要不匹配、缓存代数回退、逻辑时钟回拨超容差、batch 摘要冲突等注入异常分别映射到不同业务错误码并保留可诊断字段；提供 load、schedule、assemble、resume、status、verify 子命令，status 以稳定排序 JSON 输出预取水位、缓存命中数、放弃分片数与预算占用。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
