# 本地纹理浏览工具 (Local Texture Viewer)

一款基于 pygame 的本地 PNG 纹理浏览/核对工具，用于在导入引擎前检查大尺寸纹理
（≤ 4096×4096）在缩放、平移下的清晰度与局部衔接。所有视图坐标均以**纹理像素**
为准；纹理损坏或配置越界时程序保持可用。

## 1. 环境与依赖

- Python ≥ 3.10（本机实测 3.10.20）
- 依赖：

```powershell
pip install pygame pillow
```

本机已安装：pygame 2.6.1 / pillow 12.3.0。

## 2. 本地启动方式

```powershell
# 1) 生成确定性测试样本 (samples/ 下的 PNG、损坏文件与 JSON 配置)
python make_samples.py

# 2) 启动浏览器 (真实窗口)
python texture_viewer.py samples\test_2048x1024.png --config samples\config_valid.json

# 仅给纹理, 配置/状态均走默认
python texture_viewer.py samples\test_2048x1024.png

# 冒烟自检: 初始化窗口、绘制一帧、保存状态后立即退出 (无交互)
python texture_viewer.py samples\test_2048x1024.png --smoke

# 无头自动验收 (SDL dummy 驱动, 逐条覆盖 12 项验收, 全过退出码 0)
python run_acceptance_tests.py
```

命令行参数：

| 参数 | 说明 | 默认 |
|---|---|---|
| `texture` | 位置参数，PNG 纹理路径（≤4096×4096） | 必填 |
| `--config` | JSON 配置：窗口尺寸/初始缩放/网格间距 | 内置默认 |
| `--state` | 视图状态 JSON（退出保存、启动恢复） | `view_state.json` |
| `--smoke` | 绘制一帧后退出，用于自动化自检 | 关闭 |

## 3. 操作方式

| 操作 | 行为 |
|---|---|
| 鼠标滚轮 | 以鼠标位置为中心缩放，范围 1/8 × ~ 8 ×，触界后视图不再变化 |
| 左键拖拽 | 平移视图，内容跟随鼠标；视图不越出纹理，到边停止，无纹理外空白 |
| `G` | 切换网格叠加，状态栏同步显示「网格:开/关」 |
| `M` | 在视图中心对应的纹理坐标添加红色关注点；视图未变化时再按移除最近一点 |
| `Esc` / 窗口关闭 | 退出并保存当前视图状态 |

纹理小于视口时该轴自动居中，余部填充深色背景，仍不出现“纹理外可平移空白”。

## 4. 配置 JSON（`--config`）

缺项或取值非法/越界时逐项回退默认值，程序正常启动。

```json
{
  "window_width": 1024,
  "window_height": 768,
  "initial_scale": 2.0,
  "grid_spacing": 64
}
```

也支持 `"window_size": [w, h]`。默认值：窗口 **800×600**、初始缩放 **1.0**、
网格间距 **128**（纹理像素）。

## 5. 视图状态 JSON（退出保存 / 启动恢复）

退出时写入；下次启动自动恢复缩放、视图左上角纹理坐标与关注点：

```json
{
  "scale": 4.0,
  "view_left": 380.0,
  "view_top": 263.8,
  "markers": [[400.0, 285.0], [460.5, 340.2]]
}
```

文件损坏、字段缺失或取值越界时，按默认视图启动，并在状态栏前缀提示
`[已忽略无效视图状态]`。

## 6. 工程文件

| 文件 | 作用 |
|---|---|
| `texture_viewer.py` | 主程序：加载、缩放/平移、网格、关注点、状态持久化、错误兜底 |
| `make_samples.py` | 确定性生成测试纹理、损坏 PNG 与各类配置 |
| `run_acceptance_tests.py` | 无头验收脚本，逐条覆盖 12 项验收 |
| `capture_shots.py` | 渲染关键场景截图到 `test_work/shots/` |
| `samples/` | 确定性样本（`test_2048x1024.png`、`broken.png`、配置等） |

### 关键设计点

- **坐标以纹理像素为准**：内部只保存缩放倍数与视口中心的纹理坐标，屏幕位置
  统一由 `纹理坐标 × scale + 偏移` 换算，网格与关注点因此天然与缩放无关地对齐。
- **缩放以鼠标为锚点**：缩放前后保持鼠标下方纹理点不动；到达 1/8 或 8 倍边界
  时直接返回，视图（含可见范围）完全不变。
- **边界约束**：每次平移/缩放后 `_clamp_view` 约束视口中心，保证可见区域落在
  纹理内；纹理小于视口则居中锁死。
- **健壮性**：Pillow 先 `verify()` 再 `load()` 双重校验，失败进入错误模式但
  事件循环继续，窗口仍可关闭；配置与状态的每个字段独立校验、独立回退。
