小团队在 Linux（WSL Ubuntu）工作区首次落地搜索推荐前端链路组件，当前目录无任何代码。业务围绕多路稀疏召回融合的并行调度与数值精度诊断：固定种子脚本生成文档与查询批次，每路召回使用不同稀疏特征，融合打分在浮点与定点双精度路径间传播误差。输入含文档 JSONL（doc_id、terms、doc_len）、查询 JSONL（query_id、terms、top_k）、词项权重表与四路召回配置（倒排、前缀、类别热门、向量近似）。同分依据 doc_id 升序，不同精度路径误差仅由数值损失引起，缓存键随配置或索引变化失效。

任务环境与准备：
安装 Python 3.10 以上版本，使用 pip 安装 NumPy 与标准库 SQLite3；工作目录初始为空，仅保留该任务交付的固定种子样本生成脚本。

业务要求：
1. 实现确定性的四路召回打分：按配置权重计算词项倒排、词项前缀、类别热门与向量近似四路分数，同分时按 doc_id 升序打破平局，并记录每路原始分、归一化分与加权贡献，使最终分数可由逐项明细独立重算一致。
2. 实现跨路候选对齐与去重：按 doc_id 归并四路候选，保留每路原始分与路名，去重口径在“保留最高归一化分”与“保留首路命中”之间由配置选择，并确保最终候选集无重复且路名归属与原始分记录完整。
3. 实现候选分数计算与融合的可切换精度档：float64 与定点缩放整数两档共用同一算子语义，定点档缩放因子与舍入模式由配置显式给出，切换精度档不得改变候选顺序与去重结果，只允许分数出现数值差异。
4. 实现以 float64 全精度路径为参考真值的误差传播诊断：输出候选分数、归一化、加权融合与 top-k 门限比较各级的绝对偏差、相对偏差与误差放大比，定位主导误差来源并记录门限附近的数值稳定性保护。
5. 实现并行调度与双重资源预算准入：按可配置 worker 数与每批查询数分派到本地进程池执行召回与融合，分块边界与归并顺序确定性可复现；为总候选预算与驻留内存设上限，超限时返回 E_RECALL_BUDGET 或 E_RESOURCE_LIMIT。
6. 实现召回统计与融合权重的增量失效传播：当四路召回配置、词项权重表或文档批次修订时，按内容寻址缓存键计算受影响模块与查询集合，复用未受影响上游已提交结果，仅重算受影响后缀并输出重算与复用清单。
7. 实现融合结果与配置快照的版本化及并发提交控制：每类统计快照与缓存产物携带单调递增版本号与内容校验和，检测到版本号或校验和变化时必须整体替换旧快照，并确保同一时刻只允许一个快照提交生效。
8. 实现输入校验与跨模块一致性自检：重复 query_id、文档词项越界、配置权重非正、预算值非正分别返回结构化业务码并指明字段，自检校验四路处理文档集合一致、最终分数可重算、重算与复用集合覆盖全部受影响查询。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地确定性样本验证四路召回融合打分、精度档误差账本、并行预算裁决与缓存失效传播，并检查跨模块一致性。

## 交付实现

本仓库已按上述要求落地 `sr_pipeline` 包，不使用任何容器环境。

### 快速开始

```bash
pip install -r requirements.txt
python scripts/generate_sample.py
python -m unittest discover -s tests -t .
python scripts/run_demo.py
python scripts/collect_metrics.py
```

### 目录结构

```
sr_pipeline/
  errors.py       结构化业务码（E_DUP_QUERY_ID / E_RECALL_BUDGET 等）
  precision.py    float64 与定点缩放整数同语义算子（四种舍入模式）
  samplegen.py    固定种子样本生成（seed=20261126）
  config.py       类型化配置与 JSON/JSONL 加载
  validate.py     输入校验与字段级错误定位
  index.py        倒排/前缀/类别热度/归一化向量索引
  recall.py       四路确定性召回与平局 doc_id 升序
  fusion.py       min-max 归一化、两种去重口径、加权融合与门限保护
  diagnose.py     四级误差传播账本（raw/normalized/weighted/final）
  scheduler.py    进程池并行、确定性分块、候选与内存双重预算
  cache.py        内容寻址缓存、增量失效、SQLite 版本化快照
  selfcheck.py    文档集合/可重算/覆盖一致性自检
  pipeline.py     端到端编排
scripts/          样本生成、演示、指标收集、失效演示
tests/            32 个 unittest 用例
docs/DESIGN.md    技术设计与口径说明
docs/VALIDATION.md 实际验证命令与结果
```

### 关键设计约束

- 同分一律按 `doc_id` 升序，浮点与定点路径共用同一套算子协议
- 切换精度档只允许分数出现数值差异，顺序或去重变化即抛 `E_PRECISION_DRIFT`
- 缓存键为输入内容 SHA-256 的级联哈希，上游修订自动传播到下游
- 快照提交在单事务内整体替换，带单调版本号、校验和与乐观并发控制
