# 本地回环端口说明

仿真台仅监听 `127.0.0.1`，不访问任何外部网络服务。

## 端口分配规则

- 默认基准端口：`29500`（可用 `--base-port` 修改，合法范围 1024–65527）。
- 工作进程 rank `r` 监听端口 `base_port + r`，因此 4–8 个进程占用
  连续区间 `[base_port, base_port + workers - 1]`，默认即 `29500–29503`
  （8 进程时最多 `29500–29507`）。
- 环拓扑：rank `r` 向 rank `(r+1) % N` 的端口发起 TCP 连接。

## 演示前清理占用端口

```bash
python -m ddp_sim ports            # 检查默认区间占用情况
fuser -k 29500/tcp 29501/tcp 29502/tcp 29503/tcp   # 如有占用则清理
```

端口被占用时工作进程启动失败，系统以业务码 `E_PORT` 报告具体端口与
rank，并写入结构化日志 `runs/<run>/worker-<rank>.jsonl`。
