## 4. 插值/贴合度手工对账（需求 2、3、4）

工具输出（取自 `summary.md`）与手工推算逐项一致：

- **烈焰斩 · 1200ms（爆裂音）**，位于关键帧 800ms(zoom 1.6, center 400,300)
  与 1600ms(zoom 1.2, center 700,420) 正中间，r=0.5：
  - zoom = 1.6 + (1.2-1.6)×0.5 = **1.4** ✓
  - center = (400+300×0.5, 300+120×0.5) = **(550, 360)** ✓
  - 最近帧间隔 = min(400, 400) = **400ms，偏离** ✓
- **烈焰斩 · 800ms**：落在关键帧上 → zoom **1.6**、center **(400,300)**、间隔 **0，精准** ✓
- **烈焰斩 · 2200ms**：> 总时长 2000 → **越界**，缩放/中心/间隔全部留空 `—`，不参与贴合度 ✓
- **冰霜新星 · 0ms**：早于首帧 300ms → 钳制为首帧值 zoom **1.1**、center **(512,320)**，
  间隔 |0-300| = **300ms** ✓
- **冰霜新星 · 650ms**：帧 300(1.1, 512,320)→1000(2.0, 300,200)，r=350/700=0.5：
  zoom = **1.55**、center = **(406, 260)**、最近帧间隔 **350ms** ✓
- **冰霜新星 · -100ms**：负值越界，标红且不计算 ✓
- **雷霆一击 · 1200ms**：晚于末帧 500ms → 钳制为末帧值 zoom **1.8**、center **(200,400)** ✓
- **雷霆一击 · 620ms（雷鸣）**：间隔 |620-500| = **120ms → 贴近（橙）** ✓

汇总越界总数 **2**（烈焰斩 1 + 冰霜新星 1），与两张卡片页头标注、明细表逐页核对一致。

幂等与重写（需求 11）实测：

- 删除整个输出目录后运行，目录自动重建、5 张卡与汇总重新生成。
- 连续两次运行主清单：`summary.md` 两次 SHA-256 完全相同
  （实测 `BED7CBA4...B2A02`），PNG 数量恒为 5，无重复条目。
- 换成只含 1 个技能的清单再跑同一输出目录：旧的 5 张卡被清理为 1 张，
  汇总中不再出现“烈焰斩”等旧技能名；随后恢复主清单运行即回到 5 张。
