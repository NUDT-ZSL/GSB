# 技术设计说明

## 1. 处理流水线

每个页面按固定 DAG 执行：

```text
PNG bytes
  -> detect: grayscale + threshold + projection segmentation
  -> roles: body-height reference + density + periodicity + role priority
  -> columns: horizontal clustering + gap merge + spanning detection
  -> order: column-first or region-first + spanning boundaries
  -> page report
```

页面任务之间只共享只读配置；阶段产物按页写入独立文件。最终结果按页名字典序合并，因此线程调度不影响输出。

## 2. PNG 解码

解码器验证：

1. 8 字节 PNG 签名；
2. 首个块必须为 IHDR；
3. 每个块的 CRC32；
4. 仅接受 8 位、非交错、压缩/滤波方法为 0 的 PNG；
5. 支持灰度、RGB、灰度 Alpha、RGBA 四种像素模式；
6. 尺寸必须与元数据一致；
7. IDAT 解压长度必须与扫描线尺寸严格一致；
8. 支持 PNG 的五种行滤波类型。

RGB/RGBA 使用整数亮度 `(299R + 587G + 114B) // 1000`，计算时提升为 32 位无符号整数以避免溢出。任何失败均转为 `E_IMAGE_FORMAT` 页面失败。

## 3. 块检测

### 3.1 缩放档位

`full/half/quarter` 对应步长 1/2/4。降采样使用最小值池化，而不是平均值，以保留合成文本的细笔画。检测框最终映射回原图坐标。

### 3.2 投影切分

对二值掩码执行：

1. 计算活跃行；
2. 合并间隔不大于 `projection_analysis_window` 的活跃行；
3. 在每个行带内计算活跃列并同样合并；
4. 在行带×列带区域中再次切分内部行，处理不同高度并排块和同列堆叠块；
5. 收缩到实际墨迹边界；
6. 用原图尺度下的最小宽高过滤噪声；
7. 按 `(y, x, w, h)` 排序并分配稳定块 ID。

每个块记录 `bbox`、`ink_density`（二值墨迹占比）和 `horizontal_projection_periodicity`。周期性指标取块内部逐行墨迹计数去均值后的归一化自相关最大值，滞后范围为 2 到块高三分之一（上限 32）。

## 4. 角色判定

### 4.1 正文中位高度

先排除页面顶部/底部带内的块，再选择密度处于文本区间且低于图片阈值的中心区域块，取其高度中位数。若没有满足条件的块，依次退回中心区域全部块、页面全部块。参考值为 1 是安全下限。

### 4.2 评分

每个块的指标为：

- `height_ratio_to_body_median = block_height / body_median_height`；
- `ink_density`；
- `horizontal_projection_periodicity`；
- `center_y_ratio` 与页眉/页脚带标志。

四类角色的得分由配置阈值直接参与构造：

- `header_footer`：落入顶部或底部带时得到高基础分，否则按到边界带距离扣分；
- `image`：密度达到图片阈值时得到高分，并因周期性低得到小幅加分；
- `title`：高度比落入标题区间时得到基础分，越接近区间中心得分越高；
- `body`：高度比落入正文区间时得到基础分，周期性达到阈值时得到文本行奖励。

选择最高分角色。分数保留 6 位小数；若最高分相同，按 `role_priority` 的固定顺序裁决。每个块报告最高分角色、被否决的次优角色、全部指标和四类候选分数，因此角色结果可审计且可重复。

## 5. 分栏推断

### 5.1 种子与栏组

以正文块为主要种子；若没有正文块，则使用除页眉页脚外的块。按纵坐标、横坐标稳定排序后，依据水平区间重叠比例将种子聚为栏组。相邻栏组若水平间距小于 `gap_threshold`，合并为一个栏组并记录合并裁决。

每个栏组记录 `x0/x1`、宽度、成员块、种子块、种子块数和宽度稳定性。稳定性定义为 `max(0, 1 - 总体标准差/均值)`。

### 5.2 通栏块

当页面至少有两个栏组，且块宽占栏组总跨度达到 `spanning_width_ratio`、同时实际覆盖至少两个栏组时，标为 `spanning`。通栏块不属于普通栏组成员，而是记录 `covered_column_groups`，在阅读顺序中作为纵向边界使用。

### 5.3 冲突裁决

块重叠多个栏组但未达到通栏宽度时，按以下字典序选择：

```text
栏宽稳定性降序
-> 种子块数降序
-> 重合比例降序
-> 栏组 ID 升序
```

完全无水平重合时，先按最近距离，再按稳定性、种子块数和栏组 ID。每次冲突均记录候选指标、胜出栏组、裁决规则和原因。

关闭分栏后返回一个真实 `c0` 组，包含全部块，所有块 `spanning=false`。

## 6. 阅读顺序

### 6.1 通栏边界

所有通栏块按 `(y, x, block_id)` 排序，构成页面纵向边界。普通块的边界带编号为“起点不晚于其纵坐标的通栏块数量”。输出顺序为：

```text
band 0 普通块 -> span 0 -> band 1 普通块 -> span 1 -> ...
```

这使顶部通栏标题先于正文、位于中部的通栏图块隔断上下正文、底部通栏块位于其上方正文之后，并使后续序号整体顺延。

### 6.2 分栏优先

同一通栏边界带内，先按栏组从左到右，再按 `(y, x, block_id)` 排序。稳定键完整展开，坐标相同的情况由块 ID 决定。

### 6.3 区域优先

同一通栏边界带内，先以 `region_band_tolerance` 将纵坐标接近的块归入同一纵带，再在带内按 `(x, y, block_id)` 排序，最后按纵带顺序输出。

每条阅读顺序记录均包含规则、栏组、通栏覆盖区、坐标和可读依据字符串。

## 7. 规模自适应策略

策略选择只依赖最终输入与配置的可复现指标，不依赖历史运行状态：

- 页面数；
- 元数据中的期望阅读条目数/页数（以及布局画像中的平均块数）；
- 平均栏组数；
- 单批次页数预算；
- 线程池大小。

预置策略：

| 策略 | 检测 | 分栏 | 排序 | 精度先验 |
|---|---|---|---|---|
| `full_resolution` | 步长 1 | 配置值 | 请求规则 | 1.00 |
| `balanced_resolution` | 步长 2 | 配置值 | 请求规则 | 0.82 |
| `fast_resolution` | 步长 4 | 关闭 | `region_first` | 0.55 |

评分由精度先验、页面压力惩罚、结构复杂度和相对工作量共同构成。记录中包含每个候选的分数组成、触发条件、实际触发项、估算每页工作量、批次数和相对全分辨率工作量。默认 16 页样本的压力为 0.25，选择全分辨率路径。

## 8. 缓存 DAG

四个缓存键逐级派生：

```text
detect_key  = H(stage, version, image_sha256, detection_params, resolution_step)
roles_key   = H(stage, version, detect_key, role_params)
columns_key = H(stage, version, roles_key, column_params, effective_column_switch)
order_key   = H(stage, version, columns_key, rule, region_tolerance)
```

由此得到真实失效范围：

- 替换图像：该页四阶段全部失效；
- 修改二值化阈值、最小尺寸或投影窗口：检测及其下游失效；
- 修改分栏间距/重合/通栏阈值：栏组与排序失效；
- 修改角色阈值：角色、栏组与排序失效；
- 修改排序规则：仅排序失效；
- 修改并发数：页面内容产物不变。

缓存读取先检查清单映射，再校验阶段文件中的页名、阶段名、键、产物版本和 payload 哈希。任何一项不匹配都会重算并记录原因。未失效检测产物不会触发 PNG 解码。

## 9. 快照

每个阶段产物先写入同目录临时文件，执行 `flush`、`fsync` 后通过 `os.replace` 整体替换。阶段文件写入后，清单也以同样方式原子替换。

清单记录：

- 清单格式版本与引擎版本；
- 全局版本号；
- 完整配置哈希与参数哈希；
- 页面尺寸；
- 已完成、失败、待处理页面；
- 每页每阶段缓存键与产物版本；
- 完成数量与进度状态。

默认严格模式在配置哈希变化时返回 `E_CONFIG_MISMATCH`。`--allow-config-change` 是显式的配置演进模式；即使允许演进，引擎版本和页面尺寸仍必须兼容，缓存键仍负责选择性失效。

## 10. 并发、排序与优雅停止

页面按相对页名字典序排序后分块提交线程池。每个阶段任务都有 `page_name::stage_name` 稳定键。每块完成后按页名重排再合并，失败清单最后统一排序。

每批最多运行 `thread_pool_workers` 个页面。收到 SIGINT/SIGTERM 或程序化停止请求时，已启动批次会全部完成，随后写阶段产物与进度清单，不再提交新批次。此时运行状态为 `interrupted`、业务码包含 `E_GRACEFUL_STOP`，进程退出码为 0；后续使用同一快照即可续跑。

## 11. 报告与真值校验

页面报告把检测、角色、栏组和排序产物合并为唯一逐页结构。缓存复用决定单独放在 `reuse_recompute`，因此增量运行与全量运行可以做“页面内容产物逐字段一致”比较，而不受缓存诊断和耗时差异干扰。

真值校验按边界框匹配块，再比较角色、栏组和当前规则下的序号。真值同时保存 `reading_index_by_rule`，因此切换排序规则后仍可直接验收。
