# 连接算子运行时重优化组件 — 技术说明

## 模块结构（`reopt/`）

| 模块 | 职责 | 对应业务要求 |
| --- | --- | --- |
| `errors.py` | 业务错误码（1xxx 校验 / 2xxx 注入 / 3xxx 运行时裁决） | 1、5、8 |
| `schema.py` | 表描述、初始计划、批次剧本、配置的解析校验；谓词推导 | 1 |
| `datagen.py` | 确定性列式批次生成（SHA-256 派生种子），倾斜键按比例集中 | 2 |
| `executor.py` | 三种连接算法、逐批管线执行、单流嵌套循环真值、偏差定位 | 3 |
| `drift.py` | 定点偏差比、漂移阈值与冷却裁决，输出漂移来源/区间/余量 | 4 |
| `reoptimizer.py` | 候选枚举、实测基数/选择率代价估计、预算内切换裁决 | 5、6 |
| `ledger.py` | 误差账本：标度、舍入方向、被舍弃余量、加/乘误差上界 | 6 |
| `state.py` | SQLite 事务原子写入 + fcntl 文件锁，版本化形态指针 | 7、8 |
| `runner.py` | 批次编排：生成→提交→执行→观测→漂移→切换（单事务） | 3-8 |
| `cli.py` | `load` / `run` / `inject` / `resume` / `status` / `verify` | 8 |

## 关键设计

- **定点可复现**：选择率、偏差比、代价均以 `fp_scale` 标度整数计算，每次换算
  在误差账本登记（标度、舍入方向、被舍弃余量），同一观测序列任意运行次数
  得到逐位一致的触发结论。
- **批次即事务**：每个批次的提交、观测、漂移触发、形态切换在一个
  `BEGIN IMMEDIATE` 事务内完成，外加文件锁；强制终止不留部分状态，
  恢复只重放水位（连续已提交前缀）之后的批次，观测 `INSERT OR IGNORE` 幂等。
- **形态切换**：仅发生在批次边界（批次按原形态执行完毕后），以版本号整体
  替换形态指针并拒绝版本回退；候选须严格优于当前形态且在切换代价预算内，
  预算不足保留原形态并返回 `E3001`；被否决候选记录首个否决原因。
- **结果一致性**：最终结果摘要对列名规范排序后计算，与连接顺序无关，
  切换后累计结果与不切换情形在相同批次上摘要一致（测试断言）。
- **真值比对**：单流嵌套循环在已提交批次上计算唯一真值，逐行（排序多重集）
  比对；偏差由 `locate_deviation` 定位到首个不一致的连接步。

## 业务错误码

- 1xxx 校验：`1001` 表名重复、`1002` NDV 非法、`1003` 列宽非法、
  `1004` 谓词列缺失、`1005` 类型不可比、`1006` 批次序号非递增、
  `1007` 行数为负、`1008` 时钟为负、`1009` 算法不在枚举、
  `1010` 未知表、`1011` 行数非法、`1012` 配置非法、`1013` 注入清单非法
- 2xxx 注入：`2001` 生成阶段摘要不匹配、`2002` 观测阶段样本为零、
  `2003` 切换阶段预算非法
- 3xxx 运行时：`3001` 切换预算不足、`3002` 形态版本回退、
  `3003` 批次冲突、`3004` 未装载、`3005` 真值不一致

## 实际验证结果（2026-11-24，本机 Python 3.10.12）

- `python3 -m pytest tests/ -q`：**40 passed**（约 7s，全部确定性，无网络）。
- CLI 演示（`samples/`）：`load` → `run` 提交批次 1-6，触发 3 次漂移
  （首次：seq=2，来源表 B、连接键 k_ab，偏差比 680000/阈值 250000，
  观测区间 [1,2]），发生 2 次形态切换（v1→v2 在批次 2 边界切换为
  B⋈C⋈A/hash，v2→v3 在批次 4 边界），`verify` 通过（6 批次摘要与真值一致），
  账本条目 147 条。
- 注入演示（`samples/injections.json`）：切换阶段非法预算 → 退出码非零，
  业务码 `2003`，水位与形态指针回滚保持不变（watermark=1，form_version=1）。
- 强制终止恢复：批次执行中途与形态切换中途模拟 kill 均无部分状态，
  `resume` 后状态与一次性运行逐位一致（测试 `test_recovery.py`）。
- 并发一致性：3 个进程并行推进同一状态目录，同一批次同一形态版本只提交
  一次，形态版本严格递增，观测无重复（测试 `test_concurrency.py`）。
