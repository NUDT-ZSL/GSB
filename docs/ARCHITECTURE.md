# 处理链架构与口径说明

## 1. 三版本归一化（`normalizer.py`）

| 版本 | 音高编码 | 时刻单位 | 参考速度曲线采样 |
| --- | --- | --- | --- |
| v1 | MIDI 整数 | 毫秒 | 按秒 |
| v2 | 音名加八度 | 拍 | 按拍 |
| v3 | 音名加八度 | 毫秒 | 按拍 |

- 音名（含 `Bb3` 等降号别名）与 MIDI 整数互转，统一为 MIDI 编号并保留音名。
- 毫秒时刻按记录元数据 `base_bpm` 换算：`beat = ms / 1000 * bpm / 60`。
- 按秒采样曲线先把秒坐标换算为拍坐标，再线性插值到统一等间隔拍网格。
- 输出 `NormalizedRecord`，保留声部（`rh`/`lh`）、音符时值、练习日期、难点标注与内嵌真值。

## 2. 瞬时速度与 LOWESS 平滑（`smoothing.py`）

- 瞬时速度：`tempo_i = duration_beats / IOI_beats * 60`（BPM），首音用后向间隔。
- LOWESS：三立方核局部加权线性最小二乘，半窗带宽与网格步长来自配置，
  窗口点数不足时自动扩大到最近邻窗口；左右手分别建模。

## 3. 突变与节奏偏移检测（`detection.py`）

- 滚动窗口平稳性：相邻窗口 Welch t 检验，低于 p 值阈值的网格点合并标记。
- 变点：滚动基线均值漂移 CUSUM（局部均值/标准差标准化），
  两侧均值差超过 `tempo_jump_bpm` 才输出速度突变区间（含方向与 BPM 偏移量）。
- 节奏偏移：实际相邻音间隔与参考曲线期望间隔
  （`duration / (ref_bpm/60)`）的相对偏差超过 `rhythm_offset_ratio`，
  区分 `drag`（拖拍）与 `rush`（抢拍）。

## 4. 趋势 + AR 组合预测（`forecast.py`）

- 趋势项：分位数断点的分段线性截断幂基最小二乘拟合。
- 残差项：Yule-Walker 估计固定阶数 AR 系数，并向平稳域收缩，
  保证伴随矩阵特征根在单位圆内，多步预测不发散。
- 预测区间：t 分位数 × 经验一步预测残差尺度（含 MAD 稳健尺度）
  × AR psi 权重累积 × 区间膨胀系数；输出名义水平、经验覆盖率与参数摘要。

## 5. 稳健异常判定（`robust.py`）

- 滚动原点一步预测残差经中位数 + MAD（×1.4826）稳健标准化，
  超过 `z_threshold` 的网格点按 `merge_gap_beats` 合并为异常片段，
  每段附证据窗口（原始观测、预测值、残差、标准化值）。

## 6. 评分与陪练建议（`scoring.py`）

- 段落评分 = 变点数权重 + 平均区间宽度权重 + 异常占比权重，
  按阈值映射 high / medium / low 优先级，按学生分组并按段落分降序排序。

## 7. 跨版本一致性（`cross_version.py`）

- 比对逐段曲线最大 BPM 偏差、预测区间起止拍偏差、异常片段定位偏差；
  任一指标超配置容差即进入 `manual_review` 人工复核清单。

## 8. 真值核验与注入（`validation.py` / `injection.py`）

- 生成器把真实 BPM 反推为实际相邻音间隔，真值网格与演奏时刻同坐标，
  平滑曲线、预测区间与异常清单均可与内嵌真值、教师难点标注直接核对。
- 支持注入故意提速（rush）、停顿（pause）、跳音（skip）片段验证判定逻辑。
