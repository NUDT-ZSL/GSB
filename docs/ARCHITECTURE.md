# 多设备动捕录音后期处理引擎 — 技术说明

## 1. 设计总览

纯 Python 3.10+ 标准库加 NumPy 实现，不依赖任何外部音频库或在线资源。

| 模块 | 职责 |
| --- | --- |
| `errors.py` | 业务码 `E_FORMAT/E_RATE/E_MISSING/E_SYNC/E_BUDGET/E_WR/E_INTR` 与 JSON 错误 |
| `wavio.py` | PCM 16/24bit WAV 头解析、float64 解码、小端三字节 24bit 封装 |
| `session.py` | 会话 JSON 数据模型与全部确定性校验 |
| `sync.py` | 搜索窗脉冲峰值检测、最小二乘偏移/漂移估计、降级规则 |
| `timeline.py` | 参考时间轴映射、逐采样线性插值、时间片归并与缝隙标记 |
| `loudness.py` | 整数毫秒窗口对齐、加权均方能量、绝对/相对双门限 |
| `dynamics.py` | 逐段 RMS/峰值/响度范围、预算判定与增益/压限建议 |
| `resample.py` | 有理数比重采样与输出帧数理论值校验 |
| `scheduler.py` | 有界线程池 + 内存预算准入 + 声明顺序提交 + 失败取消 |
| `state.py` | 快照标识、段摘要 sha256 校验、中断标记、恢复识别 |
| `commit.py` | 音频/报告双临时文件、版本判定、失败整体回滚 |
| `report.py` | 确定性 JSON 报告（无时间戳/主机名，键排序） |
| `pipeline.py` / `cli.py` | 端到端编排、信号处理与退出码 |

## 2. 时钟同步模型

脉冲理论时刻以“相对段起点的毫秒数”写在会话中。检测在段内局部采样坐标进行：

```
n_obs = drift_coeff * n_theory + offset + 残差
drift_coeff = 1 + drift_rate
```

阶数 1 用普通最小二乘拟合斜率与截距；观测点少于 2 个时按会话规则降级为
阶数 0（仅偏移，取 `mean(n_obs - n_theory)`），并在报告记录降级依据与缺失
标记区间；零观测抛 `E_SYNC`，绝不补点。检测峰值必须高于会话 `peak_threshold`
（默认 0.5），避免低幅背景音被误判为同步标记。

偏移同时按设备采样点与参考采样点报告，参考域整数偏移四舍五入。

## 3. 参考时间轴与拼接

逆映射把参考采样点位置换算回设备浮点采样位置，线性插值同时完成漂移补偿与
采样率换算：

```
device_pos = offset + drift_coeff * (ref_pos - seg_start_ref) * dev_rate / ref_rate
```

每个输出参考采样点距离其理论映射网格不超过 1 个参考采样点。段按声明顺序
归并，重叠区先声明者优先；未覆盖帧填零并进入 `gap_mask`，缝隙区间与每个
时间片的归属帧数、空片结果都写入报告。

## 4. 门限响度

窗口起点 `i * window_ms * ref_rate / 1000`，严格整数毫秒对齐。先按绝对门限
筛选，再以通过绝对门限窗口的平均能量减去相对门限形成动态门限；积分响度只
统计两级都通过的窗口。末尾短窗按 `tail_rule`（include/drop）处理，全静音
返回能量 0 与 `-inf dBFS` 的确定结果。每窗附带段归属（含缝隙帧数）。

## 5. 调度与内存预算

主线程按设备段声明顺序提交，受并发上限与“在途原始 PCM + float64 采样 +
检测视图”估算总量双约束；预算不足时靠后的段等待，不缩窗、不降精度。
单段即超预算直接 `E_BUDGET`。任一段失败时取消所有尚未开始的段，已在途段
允许跑完并持久化合法结果，再返回声明顺序上的首个错误。

## 6. 一致性提交与恢复

音频与报告分别写 `.tmp` 临时文件；仅当现有报告快照标识不同才替换。替换前
备份旧文件，任一替换失败立即回滚，保证不会只更新其一，失败统一 `E_WR`。

快照标识只哈希影响音频结果的输入（会话处理参数、段相对路径与各 WAV 的
sha256），不含输出目录、并发度、内存预算等环境字段。段摘要带 sha256，
恢复时校验失败即丢弃。中断信号只在段/时间片边界生效，写 `interrupt.flag`
并以退出码 130 返回；下次运行仅在中断标记存在时复用已完成段，否则清空
快照目录从头重做。

## 7. 确定性保证

所有浮点归并按声明顺序在主线程执行，线程池只承担相互独立的解码/检测；
报告键排序、不含环境易变量；因此任意并发度与内存预算下，输出 WAV 字节与
报告字节与并发度 1 完全一致（见 `docs/VALIDATION.md`）。
