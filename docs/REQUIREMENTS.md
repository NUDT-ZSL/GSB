某医学影像后处理小组的体数据分割原型此前只停留在方案讨论，工作区里还没有任何可运行代码，需要先把一条能在 Windows 本地跑通的分块分割与掩码编辑工作台落地。业务对象由本地确定性脚本按固定种子生成：体数据目录（每张切片为整型二维数组，含已知组织灰度区间与注入的噪声与伪影）、真值掩码（仅用于评估，不得参与分割决策），以及一份 JSON 任务描述，声明各轴体素间距、分块规格、区域生长阈值、形态学后处理参数、并行度、单轮逻辑时间预算与在途像素缓冲内存预算。真实难点在于：分割须按分块网格并行推进并守住内存与单轮时间预算，而分块边界处的区域生长种子与形态学核都要在整幅坐标系下取真值，否则拼接出的掩码会出现一像素宽的错分带；操作者修订部分块后，还必须精确判定哪些块依赖失效，并保证增量结果与从头全量分割逐体素一致。

任务环境与准备：
安装 Python 3.11 与 pip，执行 pip install numpy==1.26.4 PyQt5==5.15.10，均为本地 wheel 安装，无网络运行时依赖。
提供确定性样本生成脚本入口，按固定种子在本地输出体数据切片、真值掩码与任务描述 JSON，不依赖外部数据集或附件。
运行前确认工作目录可写并预留状态目录与临时文件目录，Windows 下路径使用 pathlib 处理。

业务要求：
1. 实现任务描述与体数据解析校验：读取 JSON 与切片目录，校验三维尺寸与各轴体素间距为有限正数、分块规格能完整覆盖体数据边界、阈值区间满足下限小于上限、形态学核尺寸为奇数正整数、并行度与内存预算为正整数，非法输入返回带 E_xxx 业务码的 JSON 错误且不产生任何输出。
2. 实现整幅坐标系下的分块分割内核：区域生长的种子候选与阈值判定只依赖整幅体素坐标与任务参数，块边界处的邻域判定须跨块取真值而非退化为块内局部，形态学膨胀与腐蚀在块边界补边后计算再裁回，使每条输出体素的分割结果与整幅串行分割完全一致。
3. 实现并行分块调度与双预算准入：按并行度使用有界线程池调度待分割分块，同时处于计算中的像素缓冲总量不得超过内存预算，按可注入逻辑时钟计量每轮耗时，超出单轮逻辑时间预算即结束本轮并让出未准入分块，使任意并行度下的轮次数与准入序列可复现。
4. 实现人工修订的依赖记录与失效判定：为每个分块记录其对体素数据区间、区域生长阈值、形态学参数与相邻块边界补边的依赖，操作者对某块掩码做修订后只把依赖关系可达的分块标记为失效，其余块复用已持久化结果，并给出每个失效块的具体失效理由。
5. 实现增量重算与全量结果一致性：只对失效分块重算并在相邻保留块边界处做掩码衔接，增量结果与同输入从头全量分割在掩码上逐体素相同；真值掩码只用于评估报告中的重合度统计，分割决策与增量判定不得读取真值掩码。
6. 实现分块级持久化与版本识别：每块完成后把掩码数据、块内容摘要与由体数据内容及全部参数规范化摘要构成的版本标识原子写入状态目录，先写同目录临时文件再整体替换；再次启动时版本标识一致则复用已完成块，标识变化时须归档旧版本而非直接覆盖，摘要不符时返回 E_DIGEST 并回退补算。
7. 处理可处理终止信号与强制终止的恢复边界：外部可发送可处理终止信号使任务在分块边界写入中断标记并以约定整数退出码退出，未完成分块不得留下可被误认为完成的结果；强制终止后重启仅依据已持久化且摘要有效的分块恢复，不承诺生成退出报告。
8. 实现交互诊断视图与结果原子导出：本地桌面视图展示切片掩码叠加、分块网格、失效块高亮与逐块状态，支持选择分块查看其修订与依赖来源、查看评估报告中的重合度与失效统计；导出掩码与报告先写临时文件再整体替换，替换前读取已有输出的版本标识，版本不同才替换。
