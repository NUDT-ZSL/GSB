团队要在 Windows 本地空目录中交付一个面向游戏包装印刷与海报输出的半色调分块处理组件，目前只有需求说明，尚无任何代码与样本。业务对象是本地固定种子脚本生成的连续调灰度原图与 JSON 岗位配置：每个岗声明输出分辨率、挂网线数、网角、网点形状、油墨色调与覆盖上限，组件需按岗把灰度原图通过网点函数转换为二值或有限级网点图，再按分块网格切片输出与整幅拼接。真实难点在于半色调本质是空间频率叠加：网点相位与网角一旦按块内局部原点起算，拼贴后会出现可见的摩尔纹与四分之一的网点错位；而按整幅坐标计算，块缓存又必须证明其与整幅逐像素同口径。组件还须在可处理终止与强制终止后恢复出确定结果，并对注入异常给出可区分业务码。

任务环境与准备：
确认 Windows 本地已安装 Python 3.11 及以上并可使用标准库，命令行执行 python --version 确认版本。
安装 NumPy：在项目根目录执行 python -m pip install "numpy>=1.26"，用于灰度数组、网目相位与频谱计算。
创建空项目目录及 samples、state、out 三个子目录；随工程提供的固定种子脚本负责生成本地灰度原图、岗位配置与异常清单，不依赖网络或外部素材。
运行前确认 samples 下 JSON 与图像由固定种子脚本一次性生成完毕，并检查 state 与 out 初始为空以复现首次交互结果。

业务要求：
1. 实现岗位配置与灰度原图解析校验：读取本地 JSON 岗位配置与灰度原图清单，校验输出分辨率为正整数、挂网线数为有限正数、网角在 [0,90) 度内、网点形状属于允许集合、油墨覆盖上限在 [0,1]、分块网格行列数能整除输出分辨率，非法输入返回带 E_xxx 业务码的 JSON 错误且不写出任何网点图。
2. 实现整幅坐标系下的网点函数：按挂网线数换算网目间距，把每个输出像素中心经网角旋转后落入网目单元，单元内相位只依赖该像素整幅坐标、网角与线数，与分块划分、遍历顺序和线程调度无关；同一岗位重复生成整幅网点图须逐像素完全相同，并给出网目间距与相位的解析式说明用于复核。
3. 实现网点形状与油墨覆盖到灰度级的映射：按单元内相位与灰度的乘积关系生成圆形、椭圆与方形三种网点，再按岗位覆盖上限截断后量化为有限级网点值；量化级数与截断次序在整条链路中保持单一确定口径，同岗位在任意分块并发度下逐像素量化结果相同。
4. 实现分块切片与整幅同口径裁决：按分块网格逐块生成切片，块的网目相位、网角旋转与量化均以整幅坐标计算，接缝处相邻块共享边界像素须取同一整幅真值；所有切片按整幅坐标拼装后与同参数整幅直接生成逐像素相同，不一致时给出首个不一致像素的整幅坐标、所属分块与两侧网点值并返回 E_CONSIST。
5. 实现跨分辨率重采样与摩尔纹诊断：当岗位输出分辨率与原图分辨率不一致时按有理数比做确定性重采样后再挂网，并对拼接结果计算频谱能量在挂网频率附近邻域的聚集度，报告须给出各岗位的摩尔纹风险指标与是否超过配置阈值的结论，且仅覆盖有效输出区域的像素。
6. 实现分块级持久化与版本识别恢复：每块完成后把网点图切片、该块的整幅偏移与覆盖范围、块内容摘要及由岗位配置与原图内容规范化摘要构成的版本标识原子写入状态目录，先写同目录临时文件再整体替换；再次启动时版本标识一致则复用已完成块只补缺失块，标识变化时须先归档旧块而不得直接覆盖。
7. 实现异常注入驱动的错误链路验证：按异常清单在指定岗位注入非法网角、分块不能整除输出分辨率、缺失网点形状声明与损坏的已持久化块摘要，组件须对受影响岗位返回可区分的业务码并继续处理其余岗位，最终报告须汇总注入项、受影响业务码与已成功岗位数，且失败岗位不得留下半成品网点图。
8. 实现并发分块生成与资源上限及原子导出：按并发上限使用有界线程池调度待算分块，同时在途分块网点缓冲总量受内存预算约束，超出时按岗位标识与分块索引序让后续块等待而非降低量化级数或网目精度；可处理终止信号只在分块边界生效并以约定整数退出码退出，强制终止后仅依据已持久化且摘要有效的分块恢复，最终网点图与报告先写临时文件再整体替换。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
使用本地样本验证分块拼贴与整幅网点逐像素一致、跨分辨率诊断、缓存版本识别与异常业务码。
