# 离线多通道声场合成链路 — 技术说明

## 1. 目标与范围

给定六面体录制棚、若干发声点与多通道扬声器阵列，链路完成两件事：

1. 用镜像声源法（Image Source Method, ISM）逐频段重建棚内冲激响应（IR）；
2. 把每个声源的干信号与宽带 IR 卷积，合成多通道环绕声 WAV。

验收核心是**能量守恒与误差可溯源**：吸声系数、路径衰减、频段增益、滤波器
系数与能量全部先量化到 Q24 定点域，以整数参与累乘与“能量是否可忽略”的裁定；
同一量同时维护 float64 参考路径，仅用于诊断报告，不参与任何业务裁定。

## 3. 定点数学与双路径

* 标度 `Q = 2^24`；定点乘法 `(a*b)//Q`，卷积对每个乘积累加后整除 Q，
  全程使用 Python 任意精度整数，杜绝 int64 溢出。
* 冲激响应定点缓冲使用 `numpy.object`（元素为 Python `int`），加法满足
  结合律，因此**任意分块顺序、任意并发度**合并后逐采样点完全相同。
* float64 参考按镜像声源索引与 `BlockId` 字典序的规范顺序求和，结果可重复。
* 能量裁定：`energy_q = Σ x_q²`（整数），与定点阈值比较；float64 结果只写报告。
* 容差：采样点幅度容差 `AMP_RESIDUAL_TOL=2e-8`，单镜像能量容差
  `ENERGY_RESIDUAL_TOL=1e-12`，可忽略能量阈值 `1e-10`（内部换算 Q48 整数阈值）。

## 4. 镜像声源枚举与去重

* 对每个声源按反射次数展开六面墙序列笛卡尔积；镜像位置由逐墙反射公式
  `x' = 2b - x` 得到。
* 不同墙序列可能落到同一展开格点（如 `x- -> x+` 与 `x+ -> x-`）。
  用整数格点键 `cell = round(image_pos / room_size)` 去重，保留
  `(阶数, 反射面序列, 声源标识)` 字典序最小的一条，保证同一反射路径只枚举一次。
* 全局排序仍以该三元组字典序决胜，枚举序号连续，重复运行逐镜像一致。
* 每个镜像携带每频段的反射链吸声乘积（定点逐步累乘 + float64 一次乘积）。

## 5. 分数延迟与逐频段 IR

* 8 抽头 Hann 加窗 sinc，线性相位 FIR，群延迟 `(N-1)/2 = 3.5` 采样点。
* 理论延迟 `d = distance / c * fs` 拆为整数偏移 `D = ceil(d - 3.5)` 与
  分数延迟 `f = d - D - 3.5 ∈ [0,1)`，保证 `D + 3.5 + f ≥ d`，即整数偏移
  不短于理论延迟。
* 频段幅度权重 `= 1/distance × 吸声链乘积 × 频段增益`，定点路径逐步
  `mul_q`，float64 路径直接相乘。
* 频段采用半开区间划分（边界数 + 1 个频段），每个镜像在每个频段恰好计入
  一次，边界处不丢能量、不重复计入。

## 6. 残差溯源（真实记录，非重演）

* 每个镜像叠加后立即比较当前定点缓冲与 float64 参考，越限采样点写入
  `ContributionRecord`（镜像序号、阶数、频段、扬声器、采样点、双路径值与
  本次贡献）。这些记录随分块持久化，溯源只读记录，不重新计算。
* 报告给出首个越限的频段、采样点、阶数、镜像序号与贡献集合。
* 放大路径判定：
  `chain_component = mean|定点贡献 - 浮点贡献|`，
  `summation_component = max(聚合残差 - chain_component, 0)`；
  前者大则判为“吸声累乘放大”，否则判为“频段求和放大”。

## 7. 分块、持久化与版本识别

* 分块键 `(频段, 阶数, 扬声器)`，样本场景共 `5 × 3 × 6 = 90` 块。
* 每块写 `*.npz`（双路径 IR + 残差记录）与 `*.json`（版本号、能量摘要、
  逐镜像诊断）。先写同目录临时文件再 `os.replace` 整体替换；只有数据与
  元数据双齐全且版本号匹配才被视为完成。
* 版本标识 = SHA-256(规格常量 + 规范化场景 JSON + 干信号内容哈希 + 种子)。
* 启动时版本一致则复用完成块、只补缺失块；不一致则整体清空状态目录重建，
  禁止新旧版本 IR 混用。

## 8. 并发、预算与中断

* 有界 `ThreadPoolExecutor(max_workers=场景声明值)`。
* `BudgetGate` 按 BlockId 字典序 FIFO 发放内存许可；预算不足时后续块确定
  性等待，不降低定点标度、不缩短滤波器；单块即超预算直接 `E_BUDGET` 失败。
* 任一分块异常设置取消事件，等待在边界的块跳过，首个错误原样上抛。
* SIGINT/SIGTERM 仅在分块边界被观察：当前块要么完整落盘、要么不留痕迹；
  写 `interrupted.json` 后以退出码 3 退出。强杀（SIGKILL/任务管理器）无
  清理机会，但因“临时文件 + 原子替换 + 双元数据”不会产生伪完成块。

## 9. 输出与原子替换

* `soundfield_multichannel.wav`：定点 Q24 混音缩放到 int16 PCM 的正式输出。
* `soundfield_multichannel.wav.meta.json`：版本号、采样率、声道、帧数与
  内容 SHA-256。替换前先比对，仅版本/内容变化才替换，失败保留旧文件。
* `soundfield_float64_reference.wav`：float64 参考路径的诊断 WAV。
* `residual_report.json`：业务码、版本、逐镜像裁定、首次越限与溯源结论。

## 10. Windows 环境说明

* 代码仅依赖 Python 标准库与 `numpy==1.26.4`，全部路径使用 `pathlib`，
  原子替换使用 `os.replace`（Windows NTFS 支持），无 POSIX 专属调用。
* Windows 命令行确认：`python --version`（需 3.11+）、`pip --version`，
  安装 `pip install numpy==1.26.4`。
* Windows 可移植信号为 SIGINT（Ctrl+C / CTRL_BREAK）；SIGTERM 在
  Windows 不可靠，代码在缺失平台属性时自动跳过注册。
* 本仓库实际验证运行于 Linux + Python 3.10（语法保持 3.10/3.11 兼容），
  Windows 3.11 上的命令与行为与本文档一致。
