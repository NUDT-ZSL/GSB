当前是空白工作区，没有现存项目、代码或数据附件，需要从零构建一个面向多模态图文生成的本地可交互专业应用与可重复演示。业务对象是本地确定性生成的图文条件生成任务：图像侧由固定种子生成初始像素块，文本侧由受控词表拼装的描述经词频加权池化得到条件向量，二者按显式声明的条件融合口径合成初始场，再按配置步数做确定性迭代更新并聚合为最终图像。用户以交互方式按区域预览：先请求中心区域块，再请求其余区域的块。核心矛盾是区域分块生成可显著缩短首块可查询耗时，但块边界处的条件融合系数、邻域耦合与迭代更新次序若与全局一次生成口径不一致，就会在边界产生可观测差异；块越小边界耦合态越多、风险越大。应用需在首块耗时、块划分与一致性校验强度之间做出显式裁决并保留可追溯记录。图生图变体下，用户提供的参考图作为初始场锚点，其锚定强度决定后续迭代向参考图统计量回归的程度。

任务环境与准备：
确认本地已安装 Python 3.10 及以上版本，并可在命令行直接调用 python。
安装 NumPy（如 pip install numpy），不安装任何深度学习框架或图像编解码第三方库，图像以内存字节数组表示。
准备本地确定性样本：由固定种子生成的图文条件清单、固定尺寸参考图与生成配置（画布尺寸、迭代步数、块网格候选、锚定强度、耗时预算与资源上限），全部随项目生成，不依赖外部下载。
在 Windows 本地文件系统上创建工作目录用于存放快照与块清单，确保进程可读写；演示与校验均以本地循环计时观测耗时，不使用网络或真实模型服务。

业务要求：
1. 实现确定性的条件生成流水线：图像侧种子像素块生成、文本条件池化、条件融合为初始场、逐步迭代更新、结果聚合成图像五个阶段串联，帧尺寸、迭代步数与精度配置由输入给出；同一图文输入、种子与配置下必须逐字节产出相同的条件向量、初始场、各步中间场与最终图像，禁止依赖系统时间、字典遍历顺序或任何未声明随机源。
2. 实现按区域分块生成与已就绪块查询：按可配置块网格把图像切块并逐块生成迭代场，对外提供已就绪块清单与像素区间；首块可查询耗时以本地生成循环的实际处理计时作为观测，并按块内像素数、迭代步数与邻域耦合规模给出估算记录，超预算返回 E_LATENCY_BUDGET 并附带已完成块与未完成块编号。
3. 实现分块生成与全局一次生成的逐字节一致性：块边界处的条件融合系数、邻域耦合与迭代更新次序必须与全局口径采用同一来源与同一归一化，逐块拼接结果与一次性全局生成结果逐像素相同；检测到差异返回 E_BLOCK_MISMATCH 并输出首个不一致块的块号与像素位置，禁止通过放宽比较或补丁式覆盖掩盖差异。
4. 实现首块耗时与一致性的取舍裁决：当块过大使首块耗时超出预算、块过小使边界耦合态增多并放大一致性风险时，须按显式优先级规则在块划分、耗时预算与一致性校验强度之间裁决，并在生成计划中记录裁决依据、所选块网格、估算首块耗时与校验档位，同一配置下裁决结果必须逐字节可复现。
5. 实现图生图参考图锚定：以本地输入参考图作为初始场锚点，后续迭代按配置锚定强度向参考图统计量回归；须校验锚定强度在合法区间内、参考图与生成画布尺寸匹配，违反分别返回 E_ANCHOR_STRENGTH 与 E_ANCHOR_SHAPE，并输出各块相对锚点的偏差谱与主导偏差块。
6. 实现生成快照的版本化与整体替换：条件融合参数、块划分计划与已就绪块清单各携带单调递增版本号与内容校验和，提交时整体替换旧快照而非增量修补；重启加载时识别版本号或校验和变化并整体替换，损坏或校验和不符返回 E_SNAPSHOT_CORRUPT 并指明快照种类与版本号，旧版本不得覆盖新版本。
7. 实现并发区域预览请求与资源上限控制：多个块预览请求可并发执行，同一时刻只允许一个块划分计划提交生效，并发提交冲突时后到者立即获得 E_STAGE_BUSY 而不阻塞等待；为单次生成像素总量、单块驻留内存与并发生成任务数设可配置上限，超限返回 E_RESOURCE_LIMIT 或降级到更细块网格并标记降级类别。
8. 提供一个本地可交互的专业应用与可重复演示：展示当前生成阶段、块就绪进度、首块实际观测耗时、块网格选取与裁决依据、快照版本、一致性校验结论与最近业务错误码；支持切换块网格并触发一次演示运行——按中心区域块预览后再切换块网格重跑，两次完整图像须逐像素一致。
