本任务从空目录启动，当前 Linux（WSL Ubuntu）工作区没有任何既有代码、样本或附件，全部输入由随工程交付的固定种子脚本在本地确定性生成，不依赖真实模型、外部服务或网络。业务对象是面向 GEMM 与 BMM 矩阵乘的算子执行任务清单（JSONL，每行含 job_id、op_kind（gemm/bmm）、matrix_shapes、dtype、layout、seed、block_size、alpha、beta、revision），矩阵数组由固定种子驱动 NumPy 确定性生成。核心业务问题是任务以增量批次持续到达，且矩阵数组、分块参数 alpha、beta 或 dtype 可被修订，需要精确判定哪些已算分块产物失效、仅重算受影响后缀，并保证增量结果与从零全量重算逐字节一致。系统把一次算子执行建模为多阶段有向无环计算图：输入校验与分块计划→分块乘加累加→结果聚合与校验→诊断报告输出。需要维护内容寻址缓存、两代结果账本（v1 单文件 JSON 扁平行，v2 分片 JSON 加 SQLite 元数据）、版本化快照与强制终止恢复机制，并以可交互的本地诊断工作台交付。

任务环境与准备：
WSL Ubuntu 环境，Python 3.10 或 3.11。
创建项目目录并安装依赖：python3 -m venv venv && source venv/bin/activate && pip install numpy==1.26.4。
编写题目内所指固定种子样本生成脚本，确保矩阵数据和任务清单确定性输出。

业务要求：
1. 实现 GEMM 与 BMM 的统一执行入口，按任务清单解析 op_kind、matrix_shapes、dtype、layout、seed、block_size、alpha、beta 与 revision，对非法形状、批次维度不一致、dtype 不支持、layout 非法或 block_size 非正分别返回 E_SHAPE_INVALID、E_DTYPE_UNSUPPORTED、E_LAYOUT_INVALID 或 E_BLOCK_INVALID，且同一 job_id 与配置下策略记录必须逐字节可复现。
2. 实现分块乘加累加核心，按 block_size 切分矩阵并遵循显式声明的循环顺序与累加顺序，支持 alpha 缩放与可选 beta 累加，中间量以 float64 计算并提供补偿求和的次正规数保护，分块路径结果必须与 float64 参考实现在给定容差内一致，超出容差时返回 E_TOLERANCE_EXCEEDED 并输出首个偏差元素位置。
3. 建立输入校验与分块计划、分块乘加累加、结果聚合与校验三类节点的内容寻址缓存，缓存键须纳入矩阵数组内容哈希、op_kind、matrix_shapes、dtype、layout、block_size、alpha、beta 与上游产物哈希；键相同必须复用快照，键不同必须重算，并提供入口可按 job_id 查询缓存命中与键组成。
4. 实现增量更新依赖失效传播，当新批次到达、某 job 的 revision 提升且矩阵内容变化、或 block_size、alpha、beta、dtype 被修订时，计算受影响节点与受影响 job 集合，复用未受影响上游缓存，仅重算受影响后缀；须保证增量结果与从零全量重算逐字节一致，并输出本次重算集合、复用集合及二者覆盖范围自检。
5. 实现双版本结果账本写入与互迁，v1 为单文件 JSON 扁平行记录相对提交秒数、job_id 与输出摘要；v2 为分片 JSON 加 SQLite 元数据记录绝对逻辑毫秒、算法规格代数、输入摘要与结果哈希；v1 升级到 v2 时补全代数与哈希默认值并逐项记录补全来源，v2 降级到 v1 时对无法表达的代数与哈希按显式丢弃规则处理，迁移后同 job 在双账本中的结果语义必须一致。
6. 实现四阶段状态机与强制终止恢复，每个阶段（校验计划、乘加累加、聚合校验、报告导出）产生带单调递增版本号、已完成 job 集合与内容校验和的持久化快照，只有该阶段全部 job 完成才原子提交；重启时从最近已提交阶段继续，已提交 job 不得重算或重复计入，未提交中间分块必须丢弃并从阶段起点重建，恢复后结果须与不间断运行一致。
7. 实现并发提交控制与资源预算上限，同一时刻只允许一个阶段快照或一次增量提交生效，并发冲突时后到者立即获得 E_STAGE_BUSY 而不阻塞等待；为单阶段任务数、驻留分块乘加中间缓冲内存估算与并行重算任务数设可配置上限，超限时返回 E_RESOURCE_LIMIT 或降级为更小分块并标记降级类别。
8. 实现输入与配置校验、跨模块一致性自检及可交互诊断工作台，重复 job_id、matrix_shapes 与矩阵数据维度不符、revision 回退、账本版本号倒退分别返回结构化业务码；自检校验各阶段处理的 job 集合一致、缓存键与产物哈希互相可核对、重算与复用集合无交集且并集覆盖全部受影响 job，并提供本地应用展示计算图、命中或重算状态、双侧账本视图、偏差谱与最近业务码。
