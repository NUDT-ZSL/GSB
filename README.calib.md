# 多波段行星表面反射率标定与真彩合成工作台

从固定种子生成的观测工程出发，完成暗电流/暗角校正、辐射传输线性定标、
反射率换算、波段配准、真彩合成、不可信波段标记、增量重算与快照持久化。
仅依赖 Python 3 + NumPy，样本由 `calib/generator.py` 按固定种子确定性产出。

## 结构

- `calib/generator.py`  确定性观测工程生成器（原始 DN、暗电流帧、暗角参数、
  定标板坐标与已知反射率、逐波段几何、传感器增益与位深、区域真值）
- `calib/pipeline.py`   校正、最小二乘定标（RANSAC 内点共识 + 迭代剔除）、
  反射率换算、相位相关配准、真彩合成
- `calib/engine.py`     参数版本化缓存、增量重算、不可信标记、快照保存/恢复
- `demo.py`             本地交互演示入口（逐波段查看、替换重算、后台不阻塞退出）
- `validate.py`         验收脚本（67 项检查）

## 运行

```bash
python3 validate.py            # 全部验收检查
python3 demo.py --root workdir # 交互演示（输入 help 查看命令）
```

演示命令示例：

```
show red refl                  # 查看 red 波段反射率图（ASCII）与区域偏差
solve nir                      # 查看 nir 两点求解的自由度记录
composite                      # 真彩合成与不可信波段替换记录
replace-vignette blue 0.10 0.05
recompute                      # 后台增量重算，仅 blue 受影响
exit                           # 重算进行中也可退出，重开从最近完整快照恢复
```

## 关键设计

- 版本识别只依据标定参数快照内容（定标点 + 暗角参数 + 数据版本）的 SHA-1，
  不看文件时间；未受影响波段复用缓存，结果逐字节一致。
- 饱和（过曝）定标点先验剔除并记录；云影等粗差点经 RANSAC 内点共识加
  迭代剔除，逐轮记录点位与残差；仅剩两点时仍求解并记录自由度为 0。
- 真彩合成对反射率截断到 [0,1]，截断前数值保留供偏差统计；不可信波段
  的通道用可信波段替换并在记录中可查。
- 快照损坏或字段缺失时拒绝加载并指出缺失项，不用默认值静默续算。
